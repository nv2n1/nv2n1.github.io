BB Code Introduction

BBCode (Bulletin Board Code) is a lightweight markup language used to format messages in Internet forums. Introduced in 1998, it uses square bracket tags (e.g., [b]bold[/b]) that are translated into HTML before display.

Basic Grammar

BBCode tags follow the pattern [tag]content[/tag] or [tag=value]content[/tag] for tags with parameters. Common tags include:

  • Text formatting: [b] bold, [i] italic, [u] underline, [s] strikethrough
  • Links: [url]https://example.com[/url] or [url=https://example.com]link text[/url]
  • Images: [img]https://example.com/image.png[/img]
  • Quotes: [quote]text[/quote] or [quote="author"]text[/quote]
  • Code: [code]code here[/code] for monospaced formatting
  • Lists: [list][*]item 1[*]item 2[/list] (ordered: [list=1])
  • Tables: [table][tr][th]header[/th][/tr][tr][td]cell[/td][/tr][/table]
  • Colors/sizes: [color=red]text[/color], [size=14]text[/size]

Tags can be nested (e.g., [b][i]bold italic[/i][/b]), but must be properly closed in reverse order.
