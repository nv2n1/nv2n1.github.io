munlock(3)

mUnlock – unlock a mutex.

Synopsis

#include <util/ulocks.h>
NEOERR *mUnlock(pthread_mutex_t *mutex);

Arguments

mutex – mutex to unlock.

Description

Unlocks the mutex <mutex>.

MT-Level: Safe.

Return Value

None.
