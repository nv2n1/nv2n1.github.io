userisdnctl(8)

userisdnctl – Control and setup ISDN parameters

Synopsis

userisdnctl interface options

Description

This tool fetches the interface configuration parameters for the ISDN and then calls the apropriate scripts to take the requested action, or report the interface status.

Options

interface
The interface to be used (will search interface parameters at /etc/sysconfig/ifcfg-INTERFACE)
dial
Dial a connection calling the isdndial
hangup
Finish an existing connection using the isdnhangup
status
Show the status of an existing connection calling the isdnstatus
report
Report the interface status by returning 0 if the interface status looks good and 1 otherwise

See Also

isdnctrl(4), isdninfo(4)

Security

userisdnctl needs to be setuid root
