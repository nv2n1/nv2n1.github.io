trace-cmd-options(1)

trace-cmd-options – list available options from trace-cmd plugins

SYNOPSIS

trace-cmd options

DESCRIPTION

The trace-cmd(1) options command will examine all the trace-cmd plugins that are used by trace-cmd report(1) and list them.
