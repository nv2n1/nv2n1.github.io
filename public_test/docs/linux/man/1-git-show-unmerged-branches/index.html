git-show-unmerged-branches(1)

git-show-unmerged-branches – Show unmerged branches

SYNOPSIS

git-show-unmerged-branches

DESCRIPTION

Show all branches not merged in to current HEAD.

EXAMPLES

$ git show-unmerged-branches
