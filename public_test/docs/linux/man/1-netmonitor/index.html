netmonitor(1)

netmonitor – Network Bandwidth Monitor

SYNOPSIS

netmonitor [options…..]

DESCRIPTION

netmonitor is a console application that monitors network interfaces. It displays the transfer rate (upload and download) for each device and the data consumed by each device. The main features of netmon are low resource usage, a simple yet effective design, and an easy to understand tabular output. It displays values whose units change dynamically to scale with the value. Its compact display fits in a 9×66 size terminal window.

GENERAL OPTIONS

–config
Starts the configuration program.
–compact
Removes the spacing lines between each devices.
–help
Displays the help menu.

FORCE UNIT OPTIONS

–forceTKB
Forces the total units to Kilobytes
–forceTMB
Forces the total units to Megabytes
–forceTGB
Forces the total units to Gigabytes
–forceRKB
Forces the data rate units to Kilobytes
–forceRMB
Forces the data rate units to Megabytes
–forceRGB
Forces the data rate units to Gigabytes

BUGS

Forcing a data rate that is to low for the data values will cause destortion to the display.
