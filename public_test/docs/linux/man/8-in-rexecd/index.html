in-rexecd(8)

rexecd – remote execution server

Synopsis

rexecd [ -D ]

Options

Rexec accepts one option:

-D
Disable reverse DNS look up and in the log will be used client IP addresses.

Description

Rexecd is the server for the rexec(3) routine. The server provides remote execution facilities with authentication based on user names and passwords.
