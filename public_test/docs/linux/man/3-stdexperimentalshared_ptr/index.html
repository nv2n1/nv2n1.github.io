stdexperimentalshared_ptr(3)

std::experimental::shared_ptr - std::experimental::shared_ptr

Synopsis

Defined in header <experimental/memory> template< class T > class shared_ptr; (library fundamentals TS) std::experimental::shared_ptr is a modified version of std::shared_ptr that adds support for arrays.
