stdshared_lockrelease(3)

std::shared_lock<Mutex>::release - std::shared_lock<Mutex>::release

Synopsis

mutex_type* release() noexcept; (since C++14) Breaks the association of the associated mutex, if any, and *this. No locks are unlocked. If the *this held ownership of the associated mutex prior to the call, the caller is now responsible to unlock the mutex.

Parameters

(none)

Return value

Pointer to the associated mutex or NULL if there was no associated mutex.
