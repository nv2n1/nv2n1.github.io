babeltrace-log(1)

babeltrace-log — Babeltrace Log Converter

SYNOPSIS

babeltrace-log [OPTIONS] OUTPUT

DESCRIPTION

Convert for a text log (read from standard input) to CTF.

This program follow the usual GNU command line syntax with long options starting with two dashes. Below is a summary of the available options.

OUTPUT
Output trace path
-t
With timestamps (format: [sec.usec] string )

babeltrace(1), lttng(1), lttng-ust(3), lttng-sessiond(8)
