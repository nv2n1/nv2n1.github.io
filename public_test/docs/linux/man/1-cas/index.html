cas(1)

cas – c aMule statistics

SYNOPSIS

_untranslated[-o] _untranslated[-p] [-c <path>]

_untranslated[-h]

DESCRIPTION

cas is a program for displaying the contents of your aMule online signature file to console (in a human readable form). For this to work, you must enable the "Online Signature" option in aMule’s preferences.

Writes the online signature picture. You can optionally append =<PATH> to this option, to specify the location it should be written to.
HTML page with stats and picture. You can optionally append =<PATH> to this option, to specify the location it should be written to.
[ -c <path>, –config-dir=<path> ]
Read config from <path> instead of home
Prints a short usage description.

Without any options, it prints online signature data to stdout.

cas was written by Pedro de Oliveira <falso [at] rdk.homeip.net>

FILES

stat.png
tmp.html
