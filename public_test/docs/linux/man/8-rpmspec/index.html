rpmspec(8)

rpmspec – RPM Spec Tool

Synopsis

Querying Spec Files:

rpmspec {-q|–query} [select-options] [query-options] SPEC_FILE …

select-options

 [–rpms]
 [–srpms]

query-options

 [–qf,–queryformat QUERYFMT]
 [–target TARGET_PLATFORM]
 

Query Options

The general form of an rpm spec query command is rpm {-q|–query} [select-options] [query-options] You may specify the format that the information should be printed in. To do this, you use the
 –qf|–queryformat QUERYFMT option, followed by the QUERYFMT format string. See rpm(8) for details.

Select Options

 –rpms Operate on the binary package header(s).
 –srpm Operate on the source package header(s).
