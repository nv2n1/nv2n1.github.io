nessus-rmuser(8)

nessus-rmuser – removes a user from the nessusd userbase

Synopsis

nessus-rmuser [<login>]

Description

The Nessus Security Scanner comes with its own user base which contains the list of who can use the services of nessusd, and what restriction (or rules) each user has. nessus-rmuser is a simple program which will remove user from the proper nessusd configuration files, as well as its data (saved KBs and saved sessions).
