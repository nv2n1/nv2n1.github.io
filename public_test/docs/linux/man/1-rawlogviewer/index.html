rawlogviewer(1)

RawLogViewer – GUI dataset viewer and editor

Synopsis

RawLogViewer [dataset.rawlog]

Description

A complete GUI viewer and editor of robotic datasets.

Bugs

Please report bugs at http://sourceforge.net/tracker/?group_id=205280&atid=993006

See Also

The application wiki page at http://babel.isa.uma.es/mrpt/index.php/Applications

Authors

RawLogViewer is part of the Mobile Robot Programming Toolkit (MRPT), and was originally written by the MAPIR laboratory (University of Malaga).

This manual page was written by Jose Luis Blanco <joseluisblancoc [at] gmail.com>.
