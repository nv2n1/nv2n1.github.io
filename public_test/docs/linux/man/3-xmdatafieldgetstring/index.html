xmdatafieldgetstring(3)

XmDataFieldGetString — A DataField function that accesses the string value

Synopsis

#include <Xm/DataF.h>
char * XmDataFieldGetString(
Widget widget);

Description

XmDataFieldGetString accesses the string value of the DataField widget. The application is responsible for freeing the storage associated with the string by calling XtFree.

widget
Specifies the DataField widget ID

For a complete definition of DataField and its associated resources, see XmDataField(3).

Return

Returns a character pointer to the string value of the DataField widget. This returned value is a copy of the value of the XmNvalue resource. Returns an empty string if the length of the DataField widget’s string is 0 (zero).

Related

XmDataField(3) and XmDataFieldGetStringWcs(3).
