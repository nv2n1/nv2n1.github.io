geographiclib-get-geoids(8)

geographiclib-get-geoids — a GeographicLib administrative tool

Description

geographiclib-get-geoids downloads and installs the geoids datasets used by GeographicLib, <http://geographiclib.sf.net>. For documentation, supply the -h option:
 geographiclib-get-geoids -h By default, the datasets are installed in /usr/share/GeographicLib/geoids and the script requires write access to this directory.
