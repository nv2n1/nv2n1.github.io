gnutls_ia_generate_challenge(3)

gnutls_ia_generate_challenge – API function

SYNOPSIS

#include <gnutls/extra.h>

int gnutls_ia_generate_challenge(gnutls_session_t session, size_t buffer_size, char * buffer);

ARGUMENTS

gnutls_session_t session
is a gnutls_session_t structure.
size_t buffer_size
size of output buffer.
char * buffer
pre-allocated buffer to contain buffer_size bytes of output.

DESCRIPTION

Generate an application challenge that the client cannot control or predict, based on the TLS/IA inner secret.

RETURN VALUE

Returns 0 on success, or an negative error code.
