tcumttest(1)

tcutest – test cases of the on-memory database API

DESCRIPTION

The command `tcumttest‘ is a utility for facility test under multi-thread situation. This command is used in the following format. `rnum‘ specifies the number of iterations. `bnum‘ specifies the number of buckets.

tcumttest combo [-rnd]tnumrnum[bnum] [-tr]
Peform storing, retrieving, and removing in turn.

tcumttest typical [-nc][-rr num]tnumrnum[bnum] [-tr]

Perform typical operations selected at random.

Options feature the following.

-rnd : select keys at random.
-nc : omit the comparison test.
-rr num : specifiy the ratio of reading operation by percentage.
-tr : use on-memory tree database object.

This command returns 0 on success, another on failure.
