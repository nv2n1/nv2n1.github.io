sas_rphy_add(9)

sas_rphy_add – add a SAS remote PHY to the device hierarchy

Synopsis

int sas_rphy_add(struct sas_rphy *rphy);

Arguments

rphy

The remote PHY to be added

Description

Publishes a SAS remote PHY to the rest of the system.
