gnutls_psk_netconf_derive_key(3)

gnutls_psk_netconf_derive_key – derive PSK Netconf key from password

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_psk_netconf_derive_key(const char * password, const char * psk_identity, const char * psk_identity_hint, gnutls_datum_t * output_key);

ARGUMENTS

const char * password
zero terminated string containing password.
const char * psk_identity
zero terminated string with PSK identity.
const char * psk_identity_hint
zero terminated string with PSK identity hint.
gnutls_datum_t * output_key
output variable, contains newly allocated *data pointer.

DESCRIPTION

This function will derive a PSK key from a password, for use with the Netconf protocol.

RETURNS

GNUTLS_E_SUCCESS on success, or an error code.

SINCE

2.4.0
