ldns_getaddrinfo(3)

ldns_getaddrinfo

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

uint16_t ldns_getaddrinfo(ldns_resolver *res, ldns_rdf *node, ldns_rr_class c, ldns_rr_list **list);

DESCRIPTION

ldns_getaddrinfo()
This function is a wrapper function for ldns_get_rr_list_name_by_addr and ldns_get_rr_list_addr_by_name. It’s name is from the getaddrinfo() library call. It tries to mimic that call, but without the lowlevel stuff. .br res: The resolver. If this value is NULL then a resolver will be created by ldns_getaddrinfo. .br node: the name or ip address to look up .br c: the class to look in .br list: put the found RR’s in this list .br Returns the number of RR found.
