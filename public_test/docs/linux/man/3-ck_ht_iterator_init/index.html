ck_ht_iterator_init(3)

ck_ht_iterator_init – initialize hash table iterator

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_ht.h

ck_ht_iterator_t iterator = CK_HT_ITERATOR_INITIALIZER

Ft void Fn ck_ht_iterator_init ck_ht_iterator_t *iterator

DESCRIPTION

The Fn ck_ht_iterator_init function will initialize the object pointed to by the Fa iterator argument. Alternatively, an iterator may be statically initialized by assigning it the CK_HT_ITERATOR_INITIALIZER value.

An iterator is used to iterate through hash table entries with the ck_ht_next3 function.

RETURN VALUES

The Fn ck_ht_iterator_init function does not return a value.

ERRORS

This function will not fail.
