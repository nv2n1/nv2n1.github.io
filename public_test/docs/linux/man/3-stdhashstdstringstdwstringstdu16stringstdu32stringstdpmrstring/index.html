The template specializations of std::hash for the various string classes allow users to obtain hashes of strings. These hashes equal the hashes of corresponding std::basic_string_view classes: If S is one of these string types, SV is the corresponding    (since C++17) string view type, and s is an object of type S, then std::hash<S>()(s) == std::hash<SV>()(SV(s)).

Example

The following code shows one possible output of a hash function used on a string: // Run this code

#include <iostream>
#include <string>
#include <functional>
int main()
{
std::string s = "Stand back! I’ve got jimmies!";
std::hash<std::string> hash_fn;
size_t hash = hash_fn(s);
std::cout << hash << ‘\n’;
}

Output:

 325378910
