gtg(1)

gtg – Getting Things Gnome!, an organizer for the GNOME desktop

SYNOPSIS

gtg

DESCRIPTION

Getting Things GNOME! is an organizer for the GNOME desktop environment. GTG focuses on usability and ease of use. Its main objective is to provide a simple and yet flexible organization tool for life and work.

GTG uses a very handy system for creating and editing tasks. The task editor can automatically recognize metadata such as tags and subtasks only by the use of a very simple syntax.
