assogiate(1)

assoGiate – modify the detection and display of file types

SYNOPSIS

assogiate [options]

DESCRIPTION

File Types Editor (assoGiate) is an editor of the file types database for GNOME. It allows users to modify the detection and display of file types.

For full documentation, see the File Types Editor Manual in GNOME help.

OPTIONS

–help
Display a summary of available command-line options.
–user
Display the user database even if run as the root user. By default, the system database is displayed for the root user.

This program also acceps all standard GTK+ options, which follow the usual GNU command line syntax.

CONFORMING TO

Shared MIME Info Specification <http://www.freedesktop.org/wiki/Specifications/shared-mime-info-spec>.

Icon Theme Specification <http://www.freedesktop.org/wiki/Specifications/icon-theme-spec>.
