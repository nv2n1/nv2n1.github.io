gcaps(1)

gcaps – report available graphcaps

SYNOPSIS

gcaps [ -V ]

DESCRIPTION

gcaps is a simple script that reports all the available graphcaps for use in metafile translation by the metafile translator ctrans(1NCARG).

OPTIONS

-V
Print the version number and then exit.

ENVIRONMENT

NCARG_ROOT
Path to root of NCAR Graphics installation.
NCARG_LIB
If set this variable contains the path to the installed NCAR Graphics libraries. NCARG_LIB overrides NCARG_ROOT.

FILES

$NCARG_ROOT/lib/ncarg/graphcaps/*
The graphcaps.
$NCARG_LIB/ncarg/graphcaps/*
The graphcaps.

SEE ALSO

fcaps(1NCARG), ctrans(1NCARG), ictrans(1NCARG), graphcap(5NCARG)
