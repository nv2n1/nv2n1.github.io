mat_getlibraryversion(3)

Mat_GetLibraryVersion – Get the version of the matio library

Synopsis

Fd #include <matio.h> Ft void Fo Mat_GetLibraryVersion Fa int *major Fa int *minor Fa int *release Fc

Description

The Fn Mat_GetLibraryVersion function returns the major, minor, and release version numbers of the library. These can be used to check that the version specified in the header by MATIO_MAJOR_VERSION, MATIO_MINOR_VERSION, and MATIO_RELEASE_LEVEL.
