beagle-imlogviewer(8)

beagle-imlogviewer

Synopsis

beagle-imlogviewer –client <CLIENT> [options] <log file or directory>

Description

Beagle tool to the logs of instant messaging programs.

Options

–client
Client that the log belongs to (e.g. gaim).
–highlight-search
Words to highlight in the buffer.
–search
Search query to filter hits on.
–help
Display a summary of command-line options
