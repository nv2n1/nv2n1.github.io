undocumented(3)

undocumented – undocumented library functions

Synopsis

Undocumented library functions

Description

This man page mentions those library functions which are implemented in the standard libraries but not yet documented in man pages.

Solicitation

If you have information about these functions, please look in the source code, write a man page (using a style similar to that of the other Linux section 3 man pages), and send it to mtk.manpages [at] gmail.com for inclusion in the next man page release.
