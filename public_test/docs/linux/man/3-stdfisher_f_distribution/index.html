stdfisher_f_distribution(3)

std::fisher_f_distribution - std::fisher_f_distribution

Synopsis

Defined in header <random>
template< class RealType = double >  (since C++11)
class fisher_f_distribution;

Produces random numbers according to the f-distribution:       p(x;m,n) =       Γ((m+n)/2)       Γ(m/2) Γ(n/2)       (m/n)m/2       x(m/2)-1       (1+       mx       n       )-(m+n)/2 m and n are the degrees_of_freedom. std::fisher_f_distribution satisfies all requirements of RandomNumberDistribution

Template parameters

RealType - The result type generated by the generator. The effect is undefined if this is not one of float, double, or long double.
