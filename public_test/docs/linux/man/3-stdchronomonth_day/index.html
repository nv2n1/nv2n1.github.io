stdchronomonth_day(3)

std::chrono::month_day - std::chrono::month_day

Synopsis

Defined in header <chrono> class month_day; (since C++20) The class month_day represents a specific day of a specific month, of some yet to be specified year. month_day is a TriviallyCopyable StandardLayoutType.
