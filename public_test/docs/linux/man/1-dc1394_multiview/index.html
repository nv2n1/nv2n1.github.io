dc1394_multiview(1)

dc1394_multiview – display format0 camera video

SYNOPSIS

dc1394_multiview [–fps=[1,3,15,30]] [–res=[0,1,2]] [–device=/dev/video1394/x]

DESCRIPTION

View format0-only camera video from one or more cameras.

OPTIONS

–fps
frames per second. default is 7. The 30 fps setting is incompatible with the 640×480 RGB8 resolution setting.
–res
resolution. 0 is 320×240 (default), 1 = 640×480 YUV4:1:1, 2 = 640×480 RGB8
–device
specifies video1394 device to use (optional). default is /dev/video1394/<port#>
–help
print help message

KEYBOARD CONTROLS

set framerate to 1.875 fps
