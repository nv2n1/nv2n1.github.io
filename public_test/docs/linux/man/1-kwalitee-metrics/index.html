kwalitee-metrics(1)

kwalitee-metrics - list details of all kwalitee metrics installed on the system

VERSION

version 1.15

DESCRIPTION

Dumps all of the kwalitee metrics, along with their source class, currently installed on the system.

If "–verbose" or "-v" is passed as an argument, the ’error’ and ‘remedy’ strings for the metric are included, as a sort of documentation (the only kind programmatically available).
