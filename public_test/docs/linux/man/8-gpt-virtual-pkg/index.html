gpt-virtual-pkg(8)

gpt-virtual-pkg – Link external software into a GPT managed installation installation.

Synopsis

gpt-virtual-pkg [options]

Description

gpt-virtual-pkg Link external packages into a globus site installation. The script uses a description file to create the softlinks. The format of this file is defined in the file virtual_package.dtd.

Options

-installpath
Overrides $GLOBUS_LOCATION to point to a globus site installation.
-prefix
Specifies the installation location of the external package
-flavor
Specifies the build flavor of the external package.
-filelist=file
Specifies the file containing the list of installed files..
-gptfile=file
Specifies the file containing the GPT packaging data.
-help
Print a brief help message and exits.
-man
Prints the manual page and exits.
