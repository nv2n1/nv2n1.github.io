unicode_script(3)

unicode_script – unicode script property

Synopsis

#include <courier-unicode.h>
unicode_script_t unicode_script(unicode_char ch);

Description

unicode_script() looks up the “script”

property of the specified unicode character, and returns it. The unicode_script_t enumeration encodes possible unicode script values. unicode_script_unknown gets returned for a unicode character with an unknown script property.
