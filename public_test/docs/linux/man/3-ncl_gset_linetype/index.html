ncl_gset_linetype(3)

gset_linetype (Set line type) – sets the line type to solid or various dashed patterns.

Synopsis

#include <ncarg/gks.h>

void gset_linetype(Gint linetype);

Description

linetype
(Input) – The type of polyline to be drawn. Options are:
< 0
Implementation dependent (not used in NCAR GKS-0A)
1
Solid line (default)
2
Dashed line
3
Dotted line
4
Dashed dotted line
≥ 5
Reserved for registration or future standardization (not used in NCAR GKS-0A)

Access

To use the GKS C-binding routines, load the ncarg_gks and ncarg_c libraries.
