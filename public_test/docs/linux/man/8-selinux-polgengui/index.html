selinux-polgengui(8)

selinux-polgengui – SELinux Policy Generation Tool

Synopsis

selinux-polgengui

Description

selinux-polgengui is a graphical tool, which can be used to create a framework for building SELinux Policy.

Options

None

Files

/usr/bin/selinux-polgengui

Examples

To run the program type: selinux-polgengui

See Also

selinux(1), sepolicy(8), sepolicy-generate(8)
