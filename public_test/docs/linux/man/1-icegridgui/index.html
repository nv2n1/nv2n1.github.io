icegridgui(1)

icegrid-gui – graphical user interface to IceGrid

SYNOPSIS

icegrid-gui [OPTIONS]…

DESCRIPTION

Graphical user interface for IceGrid administration.

Full documentation of this tool is available online from the help menu.
