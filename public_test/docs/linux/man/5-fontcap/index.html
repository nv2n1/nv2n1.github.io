fontcap(5)

fontcap - A list of supported NCAR Graphics font definition files for use with ctrans and Plotchar.

Description

font1 A very simple ASCII font.

font2 Character fontcap for: HERSHEY:CARTOGRAPHIC_ROMAN

font3 Character fontcap for: HERSHEY:CARTOGRAPHIC_GREEK

font4 Character fontcap for: HERSHEY:SIMPLEX_ROMAN

font5 Character fontcap for: HERSHEY:SIMPLEX_GREEK

font6 Character fontcap for: HERSHEY:SIMPLEX_SCRIPT

font7 Character fontcap for: HERSHEY:COMPLEX_ROMAN

font8 Character fontcap for: HERSHEY:COMPLEX_GREEK

font9 Character fontcap for: HERSHEY:COMPLEX_SCRIPT

font10 Character fontcap for: HERSHEY:COMPLEX_ITALIC

font11 Character fontcap for: HERSHEY:COMPLEX_CYRILLIC

font12 Character fontcap for: HERSHEY:DUPLEX_ROMAN

font13 Character fontcap for: HERSHEY:TRIPLEX_ROMAN

font14 Character fontcap for: HERSHEY:TRIPLEX_ITALIC

font15 Character fontcap for: HERSHEY:GOTHIC_GERMAN

font16 Character fontcap for: HERSHEY:GOTHIC_ENGLISH

font17 Character fontcap for: HERSHEY:GOTHIC_ITALIAN

font18 Character fontcap for: HERSHEY:MATH_SYMBOLS

font19 Character fontcap for: HERSHEY:SYMBOL_SET1

font20 Character fontcap for: HERSHEY:SYMBOL_SET2

font21 Character fontcap for: NCAR:HELVETICA (filled font for Plotchar)

font22 Character fontcap for: NCAR:HELVETICA-BOLD (filled font for Plotchar)

font25 Character fontcap for: NCAR:TIMES-ROMAN (filled font for Plotchar)

font26 Character fontcap for: NCAR:TIMES-BOLD (filled font for Plotchar)

font29 Character fontcap for: NCAR:COURIER (filled font for Plotchar)

font30 Character fontcap for: NCAR:COURIER-BOLD (filled font for Plotchar)

font33 Character fontcap for: NCAR:GREEK (filled font for Plotchar)

font34 Character fontcap for: NCAR:MATH-SYMBOLS (filled font for Plotchar)

font35 Character fontcap for: NCAR:TEXT-SYMBOLS (filled font for Plotchar)

font36 Character fontcap for: NCAR:WEATHER1 (filled font for Plotchar)

font37 Character fontcap for: NCAR:WEATHER2 (filled font for Plotchar)

For ctrans, it is possible to set the desired font using the FONTCAP environment variable.

See Also

Online: ctrans(1NCARG), fontc(5NCARG), ncarg_env(5NCARG)

Hardcopy: NCAR Graphics Fundamentals, UNIX Version
