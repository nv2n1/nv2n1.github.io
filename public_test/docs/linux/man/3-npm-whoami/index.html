npm-whoami(3)

npm-whoami — Display npm username

Synopsis

npm.commands.whoami(args, callback)

Description

Print the username config to standard output. ‘args’ is never used and callback is never called with data. ‘args’ must be present or things will break. This function is not useful programmatically
