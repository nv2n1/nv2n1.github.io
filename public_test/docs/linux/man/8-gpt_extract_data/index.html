gpt_extract_data(8)

gpt_extract_data – Print out package metadata as shell variables

Synopsis

gpt_extract_data [–name –version –build_env ] pkg_data_file

Description

gpt_extract_data Print out package metadata as shell variables.

Options

name
Print out GPT_NAME= the name of the package.
version
Print out version numbers as GPT_MAJOR_VERSION, GPT_MINOR_VERSION and GPT_AGE_VERSION variables.
build_env
Print out build environment as GPT_CFLAGS, GPT_INCLUDES, and GPT_LIBS.
