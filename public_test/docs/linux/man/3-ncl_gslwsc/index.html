ncl_gslwsc(3)

GSLWSC (Set linewidth scale factor) - sets the linewidth scale factor, or relative thickness of a polyline.

Synopsis

CALL GSLWSC (LWIDTH)

C-Binding Synopsis

#include <ncarg/gks.h>

void gset_linewidth(Gdouble linewidth);

Description

LWIDTH
(Real, Input) - A scale factor to control the linewidth of the polyline to be drawn. It must be greater than or equal to 0. LWIDTH is applied to the nominal linewidth on a given device and the linewidths are mapped to the nearest available linewidth representable on that device. By default LWIDTH = 1.0, so setting LWIDTH = 2.0 will double line width on most devices.

Access

To use GKS routines, load the NCAR GKS-0A library ncarg_gks.
