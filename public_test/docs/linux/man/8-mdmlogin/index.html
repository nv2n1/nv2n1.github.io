mdmlogin(8)

mdmlogin – MDM Display Manager greeting window

Synopsis

mdmlogin

Description

mdmlogin is invoked by mdm(8). It displays a GNOME login window and obtains a login/password combination from the user. This is then sent to the controlling mdm process for verification.

See Also

mdm(8)
