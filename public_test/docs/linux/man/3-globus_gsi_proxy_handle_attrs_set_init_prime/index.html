Detailed Description

Handle attributes are used to control additional features of the GSI Proxy handle. These features are operation independent.

Currently there are no attributes.

See Also:

globus_gsi_proxy_handle_t

typedef struct globus_l_gsi_proxy_handle_attrs_s* globus_gsi_proxy_handle_attrs_t

Handle Attributes. A GSI Proxy handle attributes type is used to associate immutable parameter values with a Handle Management handle. A handle attributes object should be created with immutable parameters and then passed to the proxy handle init function globus_gsi_proxy_handle_init().

Initialize Attributes. Initialize GSI Proxy Handle Attributes.
