stdbitset(3)

std::bitset - std::bitset

Synopsis

Defined in header <bitset>
template< std::size_t N >
class bitset;

The class template bitset represents a fixed-size sequence of N bits. Bitsets can be manipulated by standard logic operators and converted to and from strings and integers. bitset meets the requirements of CopyConstructible and CopyAssignable.

Template parameters

N - the number of bits to allocate storage for
