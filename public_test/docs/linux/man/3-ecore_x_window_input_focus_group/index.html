EAPI Ecore_X_Window ecore_x_window_focus_get (void)

Gets the window that has focus.

Returns:

The window that has focus.

Returns the window that has the focus. If an error aoocured, 0 is returned, otherwise the function returns the window that has focus.

To use this function, you must call before, and in order, ecore_x_get_input_focus_prefetch(), which sends the GetInputFocus request, then ecore_x_get_input_focus_fetch(), which gets the reply.
