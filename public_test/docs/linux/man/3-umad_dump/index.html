umad_dump(3)

umad_dump – dump umad buffer to stderr

Synopsis

#include <infiniband/umad.h>
void umad_dump(void *umad);

Description

umad_dump() dumps the given umad buffer to stderr.

Return Value

umad_dump() returns no value.
