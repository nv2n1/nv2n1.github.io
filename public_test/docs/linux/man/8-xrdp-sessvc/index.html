xrdp-sessvc(8)

xrdp-sessvc – xrdp session supervisor

Syntax

xrdp-sessvc x_pid wm_pid

Description

xrdp-sessvc is the xrdp(8) session supervisor, which monitors the running X server and Windows Manager. As soon as one of them quits, the other process is terminated as well.
This program is only executed internally by xrdp-sesman(8).

Options

x_pid
The process ID of the forked X server to monitor.
wm_pid
The process ID of the forked Window Manager to monitor.

See Also

xrdp-sesrun(8). for more info on xrdp see http://www.xrdp.org/
