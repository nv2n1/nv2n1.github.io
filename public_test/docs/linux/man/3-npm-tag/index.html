npm-tag(3)

npm-tag — Tag a published version

Synopsis

npm.commands.tag(package [at] version, tag, callback)

Description

Tags the specified version of the package with the specified tag, or the –tag config if not specified. The ‘package [at] version’ is an array of strings, but only the first two elements are currently used. The first element must be in the form package [at] version, where package is the package name and version is the version number (much like installing a specific version). The second element is the name of the tag to tag this version with. If this parameter is missing or falsey (empty), the default froom the config will be used. For more information about how to set this config, check man 3 npm-config for programmatic usage or man npm-config for cli usage.
