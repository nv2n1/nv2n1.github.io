mipv6(7)

mipv6 – Linux Mobile IPv6 protocol extensions

Synopsis

#include <netinet/in.h>
#include <netinet/ip6.h>
#include <netinet/icmp6.h>
#include <netinet/ip6mh.h>

Description

Linux 2.6.* and 3.* optionally implements extensions for Mobile IPv6 protocol in the IPv6 stack.

See Also

mip6d.conf(5), mipv6(7), RFC6275: Mobility Support in IPv6 RFC3776: Using IPsec to Protect Mobile IPv6 Signaling Between Mobile Nodes and Home Agents RFC4877: Mobile IPv6 Operation with IKEv2 and the Revised IPsec Architecture RFC3963: Network Mobility (NEMO) Basic Support Protocol
