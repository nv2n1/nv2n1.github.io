gnome-rdp(1)

gnome-rdp – Remote Desktop Client for the GNOME Desktop

SYNOPSIS

gnome-rdp [–start-hidden|-m] [–version|-v] [–help|-h]

DESCRIPTION

This manual page documents briefly the gnome-rdp command.

Gnome-RDP is a front-end to rdesktop, tightvnc and ssh. Supported protocols: RDP, VNC and SSH. The above-mentioned applications are required for running. Gnome-RDP can be run with Mono runtime.

OPTIONS

-m –start-hidden
Start minimized to tray.
-v –version
Displays the version of the program.
-h –help
Displays the help screen of program.

FILES

~/.gnome-rdp.db
