shorewall6-vardir(5)

vardir – Shorewall6 file

Synopsis

/etc/shorewall6/vardir

Description

This file does not exist by default. You may create the file if you want to change the directory used by Shorewall6 to store state information, including compiled firewall scripts. By default, the directory used is /var/lib/shorewall6/.

The file contains a single variable assignment:

VARDIR=directory

where directory is the name of a directory. If you add this file, you should copy the files from /var/lib/shorewall6 to the new directory before performing a shorewall6 restart.

Example

VARDIR=/root/shorewall6

Files

/etc/shorewall6/vardir
