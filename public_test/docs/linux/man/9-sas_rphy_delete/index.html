sas_rphy_delete(9)

sas_rphy_delete – remove and free SAS remote PHY

Synopsis

void sas_rphy_delete(struct sas_rphy *rphy);

Arguments

rphy

SAS remote PHY to remove and free

Description

Removes the specified SAS remote PHY and frees it.
