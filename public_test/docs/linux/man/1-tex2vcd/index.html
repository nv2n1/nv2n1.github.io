tex2vcd(1)

tex2vcd - Coverts TEXSIM AET files to VCD

SYNTAX

mvl2vcd <filename.aet>

DESCRIPTION

Converts AET files to VCD on stdout. This is experimental as it is not a complete implementation and is not intended for general use.
