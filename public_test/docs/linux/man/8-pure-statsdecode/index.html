pure-statsdecode(8)

pure-statsdecode – Show human-readable dates from a "stats" logfile

Syntax

pure-statsdecode filename
pure-statsdecode –

Description

This program decodes Pure-FTPd’s "stats" log files and converts timestamps into human-readable dates.

Options

–
means to read the standard input.
filename
is a log file produced with pure-ftpd -O ftpstats:/path/to/logfile

Examples

To run this program the standard way type: pure-statsdecode /var/log/pureftpd.log > /tmp/pureftpd.humanlog Alternativly you can run it as: cat /var/log/pureftpd.log | pure-statsdecode – | gzip –best > /tmp/pureftpd.humanlog.gz
