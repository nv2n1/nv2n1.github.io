chatzilla(1)

chatzilla – standalone Mozilla IRC client, no browsers attached

SYNOPSIS

chatzilla [-h] [-chat URL]

DESCRIPTION

ChatZilla is normally used as part of SeaMonkey, or an extension to other browsers. However, it can also run under XULRunner, allowing ChatZilla to be used standalone, independent of a web browser.

OPTIONS

-h, –help
display a short help text
-chat, –chat
open the specified irc url

EXAMPLES

Open fedora support channel on freenode:
chatzilla -chat irc://freenode/fedora
