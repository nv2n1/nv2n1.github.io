vm-dump-metrics(1)

vm-dump-metrics – Dump VM metrics.

SYNOPSIS

vm-dump-metrics [ OPTION ]

DESCRIPTION

vm-dump-metrics reads virtualization hosts provided metrics decription and dumps output

OPTIONS

-f, –dest <file> Specify a dump file to be used instead of <stdout>

XML Format of Content

The content is an XML document containing host provided. The format is quite simple and is illustrated below.

 <metrics>
<metric type=’real64′ context=’host’>
  <name>TotalCPUTime</name>
  <value>846.600000</value>
</metric>
<metric type=’uint64′ context=’host’>
  <name>PageInRate</name>
  <value>0.000000</value>
</metric>
<metric type=’uint64′ context=’host’>
  <name>PageFaultRate</name>
  <value>0.000000</value>
</metric>
<metric type=’uint64′ context=’host’>
  <name>PagedOutMemory</name>
  <value>6885044</value>
</metric>
<metric type=’uint64′ context=’host’>
  <name>PagedInMemory</name>

</metric>
