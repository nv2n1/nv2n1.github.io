ck_array_remove(3)

ck_array_remove – attempt immediate or deferred removal of a pointer from an array

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_array.h Ft bool Fn ck_array_remove ck_array_t *array void *pointer

DESCRIPTION

The Fn ck_array_remove 3 function will attempt to remove the value of Fa pointer into the array pointed to by Fa array . The operation is also free to apply the operation immediately if there is an opportunity for elimination with a pending (uncommitted) put operation. If no elimination was possible, the function may require to allocate more memory.

RETURN VALUES

This function returns true if the remove operation succeeded. It will return false otherwise due to internal allocation failures or because the value did not exist.
