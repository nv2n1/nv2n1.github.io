icestormmigrate(1)

icestormmigrate – Utility for migration of IceStorm database.

SYNOPSIS

icestormmigrate <path-to-recovered.db> db

DESCRIPTION

The icestormmigrate utility upgrades a 3.1 or 3.2 IceStorm database environment to a 3.3 or superior IceStorm database environment. For details about icestormmigrate consult:
"http://doc.zeroc.com/display/Ice/Upgrading+your+Application+from+Ice+3.2+or+Earlier+Releases".
