stdchronoceilstdchronoduration(3)

std::chrono::ceil(std::chrono::duration) - std::chrono::ceil(std::chrono::duration)

Synopsis

Defined in header<chrono>
    template <class ToDuration, class Rep, class Period>
    (since C++ 17)
        constexpr ToDuration ceil(const duration<Rep, Period> &d);

Returns the smallest duration t representable in ToDuration that is greater or equal to d. The function does not participate in the overload resolution unless ToDuration is an instance of std::chrono::duration.

Parameters

d - duration to convert

Return value

d rounded up to a duration of type ToDuration.

Possible implementation

  template <class T> struct is_duration : std::false_type {};   template <class Rep, class Period> struct is_duration<       std::chrono::duration<Rep, Period>> : std::true_type {};

  template <class To, class Rep, class Period,             class = enable_if_t<is_duration<To>{}>>   constexpr To ceil(const std::chrono::duration<Rep, Period>& d)   {       To t = std::chrono::duration_cast<To>(d);       if (t < d)           return t + To{1};       return t;   }
