bcfg2-remote(8)

bcfg2-remote – Connect to a bcfg2 agent and trigger client execution

Synopsis

bcfg2-remote [-d <debug level>] [-H <agent host>] [-C <configfile>] [-k <ssl key>] [-p <agent tcp port>]

Description

bcfg2-remote connects to a client agent, uses the server certificate for authentication, and causes that client to run the bcfg2 client code with the options specified on the client.

Options

-d debuglevel

Set debug level (0-40).

-H hostname

Connect to the agent on the specified host.

-C configfile

Use the specified bcfg2.conf.

-k sslkey

Use the ssl certificate at the following path.

-p port

Connect to the agent on the specified TCP port.
