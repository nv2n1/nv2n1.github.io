xrdp-sesman(8)

xrdp-sesman – xrdp(8) session manager

Syntax

xrdp-sesman [–nodaemon|–kill|–help]

Description

xrdp-sesman is xrdp(8) session manager.
It manages user sessions by authenticating the user and starting the appropriate Xserver.

Options

-n, –nodaemon
Starts xrdp-sesman in foreground instead of starting it as a daemon.
-k, –kill
Kills running xrdp-sesman daemon.
-h, –help
Output help information and exit.

Files

${SESMAN_BIN_DIR}/sesman
${SESMAN_BIN_DIR}/sesrun
${SESMAN_CFG_DIR}/sesman.ini
${SESMAN_LOG_DIR}/sesman.log
${SESMAN_PID_DIR}/sesman.pid
