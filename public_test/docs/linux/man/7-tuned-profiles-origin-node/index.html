tuned-profiles-origin-node(7)

tuned-profiles-origin-node – description of profiles provided for OpenShift

Description

These profiles are provided for OpenShift nodes. They provide performance optimizations for OpenShift Nodes running on either bare metal (origin-node-host) or virtual machines (origin-node-guest).

Profiles

The following profiles are provided:

origin-node-host
Profile optimized for OpenShift hosts (bare metal). It is based on throughput-performance profile. It additionally increases SELinux AVC cache, PID limit and tunes netfilter connections tracking.
origin-node-guest
Profile optimized for virtual OpenShift guests. It is based on virtual-guest profile. It additionally increases SELinux AVC cache, PID limit and tunes netfilter connections tracking.

Files

/etc/tuned/* /usr/lib/tuned/*
