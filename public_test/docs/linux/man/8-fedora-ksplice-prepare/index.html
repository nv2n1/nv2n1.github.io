fedora-ksplice-prepare(8)

fedora-ksplice-prepare – Prepare kernel sources for KSplice

Synopsis

fedora-ksplice-prepare [OPTIONS] [KERNELVERSION]

Description

Download the source rpm of the currently installed kernel and prepare the kernel for applying a patch with ksplice.

If you specified the KERNELVERSION argument, the sources for the specified kernel version will be downloaded.

Options

–clean
Clean up the directory in which the kernel source RPMs are downloaded
–enablerepo <repository>
Enable repository <repository>
