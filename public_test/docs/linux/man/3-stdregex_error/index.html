stdregex_error(3)

std::regex_error – std::regex_error

Synopsis

Defined in header <regex>
class regex_error; (since C++11)
Defines the type of exception object thrown to report errors in the regular expressions library.

Example

// Run this code

#include <regex>
#include <iostream>
int main()
{
    try {
        std::regex re("[a-b][a");
    } catch (const std::regex_error &e) {
        std::cout << "regex_error caught: " << e.what() << '
';
        if (e.code() == std::regex_constants::error_brack) {
            std::cout << "The code was error_brack
";
        }
    }
}

Possible output:

  regex_error caught: The expression contained mismatched [ and ].
  The code was error_brack
