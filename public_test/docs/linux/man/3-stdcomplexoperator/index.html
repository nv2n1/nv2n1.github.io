Assigns new values to the contents.

  1. Assigns x to the real part of the complex number. Imaginary part is set to zero. 2,3) Assigns cx.real() and cx.imag() to the real and the imaginary parts of the complex number respectively.

Parameters

x - value to assign cx - complex value to assign

*this
