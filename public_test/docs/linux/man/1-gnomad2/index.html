gnomad2(1)

gnomad2 – transfer files between a host and a Creative Labs Nomad Jukebox, Zen jukebox or Dell Digital Jukebox (DJ).

SYNOPSIS

gnomad2 [OPTION]…

DESCRIPTION

Gnomad 2 is a GUI built on top of GTK/GNOME 2, id3lib and libnjb that makes it possible to transfer tracks and files from/to a Creative Nomad Jukebox (all brands) and the Dell DJ. It is designed much like an ordinary graphical FTP program, in commander-style.

OPTIONS

-D[DEBUGLEVEL]
A debug level is a number between 1 and 15, identical to the debug level value of libnjb.
–load-modules=[MODULE]…
Dynamic modules to load

Display brief usage message
