  1. Atomically replaces the value pointed to by obj with the value of desr as if by obj->store(desr)
  2. Atomically replaces the value pointed to by obj with the value of desr as if by obj->store(desr, order)

Parameters

obj - pointer to the atomic object to modify desr - the value to store in the atomic object order - the memory synchronization ordering for this operation: only std::memory_order_relaxed, std::memory_order_release and std::memory_order_seq_cst are permitted.
