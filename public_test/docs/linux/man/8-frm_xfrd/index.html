frm_xfrd(8)

frm_xfrd – File Residency Manager transfer daemon

Synopsis

frm_xfrd [options]

Description

The frm_xfrd daemon automatically copies files in and out of the data server. It is part of the File Residency Manager software suite. Usage synopsis can be displayed by typing "frm_xfrd -h". Complete HTML documentation can be found at

http://xrootd.org/doc/prod/frm_config.htm

Notes

Documentation for all components associated with frm_xfrd can be found at http://xrootd.org/docs.html

Diagnostics

Configuration errors yield an error message and a non-zero exit status. The program never exits upon success. Use the kill command or "/etc/init.d/frm_xfrd stop" to terminate the program.

License

License terms can be displayed by typing "xrootd -H".

Support Level

The frm_xfrd daemon is supported by the xrootd collaboration. Contact information can be found at

http://xrootd.org/contact.html
