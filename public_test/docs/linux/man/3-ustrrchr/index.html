ustrrchr(3)

ustrrchr – Finds the last occurrence of a character in a string. Allegro game programming library.

Synopsis

#include <allegro.h>
char *ustrrchr(const char *s, int c);

Description

Finds the last occurrence of the character `c’ in the string `s’. Example:

char *p = ustrrchr("one,two,three,four", ',');

Return Value

Returns a pointer for the last occurrence of `c’ in `s’, or NULL if no match was found.

See Also

uconvert(3), ustrchr(3), ustrstr(3), ustrpbrk(3), ustrtok(3)
