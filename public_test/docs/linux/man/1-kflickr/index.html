kflickr(1)

kflickr – stand-alone flickr.com photo uploader for KDE

SYNOPSIS

kflickr [–help] [–help-qt] [–help-kde] [–help-all] [–author] [–license] [-v] [ URL(s) ]

DESCRIPTION

kflickr Provides a GUI which may be used to modify photo attributes before sending loaded photo files to the users flickr.com photo stream. Allows editing of the most common attributes as well as sending photos directory to a specified photo stream associated with the users account.

OPTIONS

–help
Display command line options.
–help-qt
Display QT specific command line options.
–help-kde
Display KDE specific command line options.
–help-all
Display help on all command line options.
–author
Display information on the application author.
-v
Display application version
–license
Display license information.
URL(s)
List of photos to load.

FILES

~/.kde/share/config/kflickrrc

Per user configuration file.
