ck_ht_entry_empty(3)

ck_ht_entry_empty – determine whether entry contains a key-value pair

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_ht.h Ft bool Fn ck_ht_entry_empty ck_ht_entry_t *entry

DESCRIPTION

The Fn ck_ht_entry_empty function will return false if Fa entry points to a valid key-value pair. If Fa entry does not point to a valid key-value pair it returns true. It is expected that the object pointed to by Fa entry was initialized by a preceding call to the ck_ht_entry_set family of functions, the ck_ht_get_spmc3 function or the ck_ht_set_spmc3 function.

ERRORS

Behavior is undefined if Fa entry has not been initialized.
