night_filter(1)

night_filter – select filter or print current one

SYNOPSIS

 night_filter [-f filter] [-list]

DESCRIPTION

The options are as follows:

options:

        info print current filter

-f
 set filter, one from -list
-list
list of defined filters
-init
(re)initialize filter wheel
-p
show progress indicator
-host
address:port internet address server, default: local connect

ENVIRONMENT

Setting of environment variable NIGHTVIEW_HOST is equivalent to -host option.
