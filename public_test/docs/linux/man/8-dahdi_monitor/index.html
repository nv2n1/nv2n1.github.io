dahdi_monitor(8)

dahdi_monitor – checks the rx/tx levels of DAHDI channels

Synopsis

dahdi_monitor channel number [-v] [-f FILE]

Description

dahdi_monitor monitors a DAHDI channel. It gives you a visual representation of the sound strengths and makes it easy to see if the received or transmitted signals are too high or out of balance

Options

The first (mandatory) parameter is the number of the channel to monitor.

-v

Display visual audio levels.

-f FILE

Write output to FILE

Some extra, yet undocumented, options.

See Also

dahdi_tool(8), dahdi_cfg(8), asterisk(8).
