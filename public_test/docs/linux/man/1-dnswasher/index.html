dnswasher(1)

dnswasher – A PowerDNS nameserver debugging tool

SYNOPSIS

dnswasher [infile] [outfile]

DESCRIPTION

dnswasher takes an infile in PCAP format and writtes out outfile also in PCAP format. It copies all network traffic found in infile to outfile except for non DNS traffic. This might be handy when creating bug reports or test cases for DNS software e.g. PowerDNS.

OPTIONS

None.

SEE ALSO

pcap(3PCAP), tcpdump(8)
