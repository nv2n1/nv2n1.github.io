mongoc_stream_socket_new(3)

mongoc_stream_socket_new() – Creates a new mongoc_stream_socket_t using the mongoc_socket_t provided.

Synopsis

mongoc_stream_t *
mongoc_stream_socket_new (mongoc_socket_t *socket);

Parameters

socket
A mongoc_socket_t \&.

Creates a new mongoc_stream_socket_t using the mongoc_socket_t provided.

NOTE

This function transfers ownership of socket to the newly allocated stream.

Returns

A newly allocated mongoc_stream_socket_t that should be freed with mongoc_stream_destroy(3) when no longer in use.
