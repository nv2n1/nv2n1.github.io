ncl_gset_linewidth(3)

gset_linewidth (Set linewidth scale factor) – sets the linewidth scale factor, or relative thickness of a polyline.

Synopsis

#include <ncarg/gks.h>

void gset_linewidth(Gdouble linewidth);

Description

linewidth
(Input) – A scale factor to control the linewidth of the polyline to be drawn. It must be greater than or equal to 0. linewidth is applied to the nominal linewidth on a given device and the linewidths are mapped to the nearest available linewidth representable on that device.

By default linewidth = 1.0, so setting linewidth = 2.0 will double line width on most devices.

Access

To use the GKS C-binding routines, load the ncarg_gks and ncarg_c libraries.
