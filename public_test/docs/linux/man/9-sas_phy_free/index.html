sas_phy_free(9)

sas_phy_free – free a SAS PHY

Synopsis

void sas_phy_free(struct sas_phy *phy);

Arguments

phy

SAS PHY to free

Description

Frees the specified SAS PHY.

Note

This function must only be called on a PHY that has not successfully been added using sas_phy_add.
