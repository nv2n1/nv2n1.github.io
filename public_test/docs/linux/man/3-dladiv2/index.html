subroutine dladiv (double precisionA, double precisionB, double precisionC, double precisionD, double precisionP, double precisionQ)

DLADIV performs complex division in real arithmetic, avoiding unnecessary overflow.

Purpose:


DLADIV performs complex division in real arithmetic
        a +
    i *b
        p +
    i *q = -- -- -- -- -c + i * d
                                    The algorithm is due to Michael Baudin and
           Robert L.Smith and can be found in the paper "A Robust Complex Division in Scilab"

 

Parameters:

A
          A is DOUBLE PRECISION

B

          B is DOUBLE PRECISION

C

          C is DOUBLE PRECISION

D

          D is DOUBLE PRECISION
          The scalars a, b, c, and d in the above expression.

P

          P is DOUBLE PRECISION

Q

          Q is DOUBLE PRECISION
          The scalars p and q in the above expression.
