<h2 class="name">NAME</h2>
<p> timer_delete &#8211; delete a POSIX per-process timer </p>
<h2>SYNOPSIS</h2>
<pre><code>
#include &lt;time.h&gt;
int timer_delete(timer_t timerid);
</code></pre>
<p> Link with <i>-lrt</i>. </p>
<p> Feature Test Macro Requirements for glibc (see <code><a href="/docs/linux/man/7-feature_test_macros/">feature_test_macros</a></code>(7)): </p>
<p> <code>timer_delete</code>(): _POSIX_C_SOURCE&nbsp;&gt;=&nbsp;199309L</p>
<h2>DESCRIPTION</h2>
<p> <code>timer_delete</code>() deletes the timer whose ID is given in <i>timerid</i>. If the timer was armed at the time of this call, it is disarmed before being deleted. The treatment of any pending signal generated by the deleted timer is unspecified.</p>
<h2>RETURN VALUE</h2>
<p> On success, <code>timer_delete</code>() returns 0. On failure, -1 is returned, and <i>errno</i> is set to indicate the error.</p>
<h2>ERRORS</h2>
<dl>
<dt><code>EINVAL</code></p>
<dd> <i>timerid</i> is not a valid timer ID.</dl>
<h2>VERSIONS</h2>
<p> This system call is available since Linux 2.6.</p>
<h2>CONFORMING TO</h2>
<p> POSIX.1-2001, POSIX.1-2008.</p>
