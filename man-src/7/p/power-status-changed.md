<p>power-status-changed &#8211; event signalling change of power status</p>
<h2>Synopsis</h2>
<p><code>power-status-changed</code> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>power-status-changed</code> event is generated by the Upstart <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon when it receives the SIGPWR signal, this has been typically generated by UPS monitoring software such as <code><a href="/docs/linux/man/8-powstatd/">powstatd</a></code>(8) </p>
<p> This event is not handled in the default Upstart configuration.</p>
<h2>Example</h2>
<p>A task to be run on change of power status might use: </p>
<dl>
<dd>
<pre>start on power-status-changed</pre>
</dl>
