<p>filesystem &#8211; event signalling that filesystems have been mounted</p>
<h2>Synopsis</h2>
<p><code>filesystem</code> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>filesystem</code> event is generated by the <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) daemon after it has mounted all filesystems listed in <code><a href="/docs/linux/man/5-fstab/">fstab</a></code>(5). <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) emits this event as an informational signal, services and tasks started or stopped by this event will do so in parallel with other activity.</p>
<h2>Example</h2>
<p>A service that wishes to be running once filesystems are mounted might use: </p>
<dl>
<dd>
<pre>start on filesystem</pre>
</dl>
