<p>frysk &#8211; The Frysk Debugging, Tracing, and Monitoring Tool Suite</p>
<h2>Description</h2>
<p>The Frysk Tool Suite provides a collection of command line and gnome utilities for the debugging, tracing, and monitoring of user programs.</p>
