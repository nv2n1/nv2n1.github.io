<p>urfkill &#8211; RFKill Switches Management</p>
<h2>Description</h2>
<p>urfkill provides an interface to enumerate rfkill switches on the system and control system-wide rfkill switches management. Any application can access the <i>org.freedesktop.URfkill</i> service on the system message bus. Some operations (such as setting soft block on the device) is restricted using PolicyKit.</p>
