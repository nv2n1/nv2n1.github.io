<p>upstart-events &#8211; Well-known Upstart events summary</p>
<h2>Event Summary</h2>
<p>This manual page summarises well-known events generated by Upstart running both as the <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon (process ID 1) and a Session Init (process that supervises a user session). </p>
<p> It is not an exhaustive list of all possible events, but rather details a standard set of events expected to be generated on any Ubuntu system running Upstart. </p>
<p> The primary tables, <code>Table 1</code> and <code>Table 2</code>, encode the well-known system and session events respectively, along with the type of each event (listed in <code>Table 3</code>), the emitter of the event (see <code>Table 4</code>) and the approximate time at which the event could be generated. Additionally, the <i>Note</i> column indexes into <code>Table 5</code> for further details on a particular event. </p>
<p> See <code><a href="/docs/linux/man/8-init/">init</a></code>(8) for a table summarising job goals and possible state transitions. </p>
<p> Note that some events listed in <code>Table 1</code> <i>may</i> be available to session jobs (depending on when the Session Init starts). Those events that are available will be prefixed with <i>:sys:</i>. See <code><a href="/docs/linux/man/8-upstart-event-bridge/">upstart-event-bridge</a></code>(8) for further details. </p>
<p> The <i>Ref</i> (Reference) column is used to refer to individual events succinctly in the <i>Time</i> column. </p>
<p> Note that the &#8216;&lt;&#8216; and &#8216;&gt;&#8217; characters in the <i>Time</i> column denote that the event in the <i>Event</i> column occurs respectively before or after the event specified in the <i>Time</i> column (for example, the <code><a href="/docs/linux/man/7-mounting/">mounting</a></code>(7) event occurs &quot;at some time&quot; after the <code><a href="/docs/linux/man/7-startup/">startup</a></code>(7) event, and the <code><a href="/docs/linux/man/7-virtual-filesystems/">virtual-filesystems</a></code>(7) event occurs after the last <code><a href="/docs/linux/man/7-mounted/">mounted</a></code>(7) event relating to a virtual filesystem has been emitted). </p>
<p> For further details on events, consult the manual pages and the system job configuration files, usually located in <i>/etc/init</i>. </p>
