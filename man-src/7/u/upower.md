<p>UPower &#8211; System-wide Power Management</p>
<h2>Description</h2>
<p>UPower provides an interface to enumerate power sources on the system and control system-wide power management. Any application can access the <i>org.freedesktop.UPower</i> service on the system message bus.</p>
