<p>socket &#8211; event signalling that a socket connection has been made</p>
<h2>Synopsis</h2>
<p><code>socket</code> <code>PROTO</code>=<i>PROTO</i> <code>PORT</code>=<i>PORT</i> <code>ADDR</code>=<i>ADDR</i> </p>
<p> <code>socket</code> <code>PROTO</code>=<i>PROTO</i> <code>SOCKET_PATH</code>=<i>PATH</i></p>
<h2>Description</h2>
<p>The <code>socket</code> event is generated by the <code><a href="/docs/linux/man/8-upstart-socket-bridge/">upstart-socket-bridge</a></code>(8) daemon when a socket connection is made whose details match the socket event condition and environment specified in a jobs <code>start on</code> or <code>stop on</code> stanza. </p>
<p> When an incoming connection is detected, the file descriptor representing the socket is passed to the job in question to allow it to <code><a href="/docs/linux/man/2-accept/">accept</a></code>(2) the connection. Additionally, the environment variable <code>UPSTART_EVENTS</code> will contain the name of the event (&quot;socket&quot;) and the environment variable <code>UPSTART_FDS</code> will contain the number of the file descriptor corresponding to the listening socket.</p>
<h2>Examples</h2>
<h3>Internet (IPv4) socket</h3>
<p>Start web server when first client connects from localhost:</p>
<dl>
<dd>
<pre>start on socket PROTO=inet PORT=80 ADDR=127.0.0.1</pre>
</dl>
<h3>Internet (IPv6) socket</h3>
<p>Start job when a client connects from localhost:</p>
<dl>
<dd>
<pre>start on socket PROTO=inet6 PORT=80 ADDR=::1</pre>
</dl>
<h3>Local socket</h3>
<dl>
<dd>
<pre>start on socket PROTO=unix SOCKET_PATH=/var/run/.s.pgsql.1234</pre>
</dl>
<h3>Abstract socket</h3>
<dl>
<dd>
<pre>start on socket PROTO=unix SOCKET_PATH=@/at/upstart/example</pre>
</dl>
