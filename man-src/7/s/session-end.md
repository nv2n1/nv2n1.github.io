<p>session-end &#8211; event signalling session shutdown</p>
<h2>Synopsis</h2>
<p><code>session-end</code> <code>TYPE</code>=<i>TYPE</i></p>
<h2>Description</h2>
<p>The <code>session-end</code> event is generated by the Upstart <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon when running as a Session Init (where its pid is not 1) when requested to stop. The <code>TYPE</code> environment variable will be set to either <i>shutdown</i> when the Session Init has received the <i>SIGTERM</i> signal, or <i>logout</i> when the Session Init has processed the <code>com.ubuntu.Upstart0_6.EndSession()</code> D-Bus method call. </p>
