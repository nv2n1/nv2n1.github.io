<p>DROP_USER &#8211; remove a database role</p>
<h2>Synopsis</h2>
<pre>DROP USER [ IF EXISTS ] <i>name</i> [, ...]</pre>
<h2>Description</h2>
<p><code>DROP USER</code> is simply an alternate spelling of DROP ROLE (<code><a href="/docs/linux/man/7-drop_role/">DROP_ROLE</a></code>(7)).</p>
<h2>Compatibility</h2>
<p>The <code>DROP USER</code> statement is a PostgreSQL extension. The SQL standard leaves the definition of users to the implementation.</p>
