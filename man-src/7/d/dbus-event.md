<p>dbus &#8211; event signalling that a dbus signal has been emitted</p>
<h2>Synopsis</h2>
<p><code>dbus</code> <code>[</code><i></i><code>BUS</code>=<i>BUS_NAME</i><code>]</code> <code>SIGNAL</code>=<i>SIGNAL</i> <code>INTERFACE</code>=<i>INTERFACE</i> <code>OBJPATH</code>=<i>PATH</i> <code>SENDER</code>=<i>SENDER</i> <code>DESTINATION</code>=<i>DESTINATION</i> <code>ARG0</code>=<i>VALUE</i> <code>ARGN</code>=<i>VALUE</i></p>
<h2>Description</h2>
<p>The <code>dbus</code> event is generated by the <code><a href="/docs/linux/man/8-upstart-dbus-bridge/">upstart-dbus-bridge</a></code>(8) daemon when a D-Bus signal is emitted whose details match the <i>dbus</i> event condition and environment specified in a job&#8217;s <code>start on</code> or <code>stop on</code> stanza is modified. Arguments that are simple types (string, int, etc.) are translated into strings and placed as parameters on the event with the pattern ARG and the number representing the placement in the event prototype. Parameters that are not a simple type are skipped, with the number being incremented the same. The <code>BUS</code> parameter is optional and only set if the <code><a href="/docs/linux/man/8-upstart-dbus-bridge/">upstart-dbus-bridge</a></code>(8) daemon is started with the <code>&#8211;bus-name</code> parameter. The value of <code>BUS</code> will be the same as the value passed as the parameter. </p>
<h2>Examples</h2>
<dl>
<dt>start on dbus SIGNAL=NameAcquired INTERFACE=org.freedesktop.DBus OBJPATH=/org/freedesktop/DBus SENDER=org.freedesktop.DBus ARG0=com.mycorp.foo</p>
<dd>Start job when a particular <i>NameAcquired</i> D-Bus signal is received.</dl>
