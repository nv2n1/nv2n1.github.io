<p>DROP_GROUP &#8211; remove a database role</p>
<h2>Synopsis</h2>
<pre>DROP GROUP [ IF EXISTS ] <i>name</i> [, ...]</pre>
<h2>Description</h2>
<p><code>DROP GROUP</code> is now an alias for DROP ROLE (<code><a href="/docs/linux/man/7-drop_role/">DROP_ROLE</a></code>(7)).</p>
<h2>Compatibility</h2>
<p>There is no <code>DROP GROUP</code> statement in the SQL standard.</p>

<p>DROP ROLE (<code><a href="/docs/linux/man/7-drop_role/">DROP_ROLE</a></code>(7)) </p>
