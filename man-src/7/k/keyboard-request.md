<p>keyboard-request &#8211; event signalling console press of Alt-UpArrow</p>
<h2>Synopsis</h2>
<p><code>keyboard-request</code> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>keyboard-request</code> event is generated by the Upstart <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon when the keyboard request key combination (typically Alt-UpArrow) is pressed on the console. </p>
<p> The support for this event depends on your kernel configuration. Suggested use for this event includes spawning a new login console when pressed, or for secure attention key support. </p>
<p> This event is not handled in the default Upstart configuration.</p>
<h2>Example</h2>
<p>A task to be run on the keyboard request might use: </p>
<dl>
<dd>
<pre>start on keyboard-request</pre>
</dl>
