<p>iso_8859-6 &#8211; ISO 8859-6 character set encoded in octal, decimal, and hexadecimal</p>
<h2>Description</h2>
<p>The ISO 8859 standard includes several 8-bit extensions to the ASCII character set (also known as ISO 646-IRV). ISO 8859-6 encodes the characters used in the Arabic language.</p>

<h2>Notes</h2>
