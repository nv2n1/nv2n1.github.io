<p>zmq_null &#8211; no security or confidentiality</p>
<h2>Synopsis</h2>
<p>The NULL mechanism is defined by the ZMTP 3.0 specification: m[blue]<code><a rel="nofollow" href="http://rfc.zeromq.org/spec:23">http://rfc.zeromq.org/spec:23</a></code>m[]. This is the default security mechanism for ZeroMQ sockets.</p>
