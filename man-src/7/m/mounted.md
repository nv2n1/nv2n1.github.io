<p>mounted &#8211; event signalling that a filesystem has been mounted</p>
<h2>Synopsis</h2>
<p><code>mounted</code> <code>DEVICE</code>=<i>DEVICE</i> <code>MOUNTPOINT</code>=<i>MOUNTPOINT</i> <code>TYPE</code>=<i>TYPE</i> <code>OPTIONS</code>=<i>OPTIONS</i> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>mounted</code> event is generated by the <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) daemon after it has mounted a filesystem. <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) will wait for all services started by this event to be running, all tasks started by this event to have finished and all jobs stopped by this event to be stopped before emitting any other events related to this filesystem or continuing with other filesystems depending on this one. </p>
<p> The <code>DEVICE</code>, <code>MOUNTPOINT</code>, <code>TYPE</code> and <code>OPTIONS</code> environment variables contain the values of the <code><a href="/docs/linux/man/5-fstab/">fstab</a></code>(5) fields for this mountpoint.</p>
<h2>Example</h2>
<p>A tool that should be run after mounting the <i>/tmp</i> filesystem might use: </p>
<dl>
<dd>
<pre>start on mounted MOUNTPOINT=/tmp
task</pre>
</dl>
