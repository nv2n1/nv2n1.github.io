<p>all-swaps &#8211; event signalling that all swap partitions have been activated</p>
<h2>Synopsis</h2>
<p><code>all-swaps</code> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>all-swaps</code> event is generated by the <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) daemon after it has activated all swap partitions listed in <code><a href="/docs/linux/man/5-fstab/">fstab</a></code>(5). <code><a href="/docs/linux/man/8-mountall/">mountall</a></code>(8) emits this event as an informational signal, services and tasks started or stopped by this event will do so in parallel with other activity. </p>
<p> When this event occurs, common filesystems such as <i>/usr</i> may not be mounted.</p>
<h2>Example</h2>
<p>A service that wishes to be running once swap partitions are activated might use: </p>
<dl>
<dd>
<pre>start on all-swaps</pre>
</dl>
