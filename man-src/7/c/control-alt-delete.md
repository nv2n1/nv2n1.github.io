<p>control-alt-delete &#8211; event signalling console press of Control-Alt-Delete</p>
<h2>Synopsis</h2>
<p><code>control-alt-delete</code> [<i>ENV</i>]&#8230;</p>
<h2>Description</h2>
<p>The <code>control-alt-delete</code> event is generated by the Upstart <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon when the Control-Alt-Delete key combination is pressed on the console. </p>
<p> Typically this combination is used to safely reboot the machine. </p>
<p> In the default Upstart configuration handling of this event is provided by the <i>/etc/init/control-alt-delete.conf</i> task which runs the <code><a href="/docs/linux/man/8-shutdown/">shutdown</a></code>(8) tool.</p>
<h2>Example</h2>
<p>A task to be run on Control-Alt-Delete might use: </p>
<dl>
<dd>
<pre>start on control-alt-delete</pre>
</dl>
