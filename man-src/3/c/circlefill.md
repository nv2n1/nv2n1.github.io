<h2>NAME</h2>
<p> circlefill &#8211; Draws a filled circle. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void circlefill(BITMAP *bmp, int x, int y, int radius, int color);</code></p>
<h2>DESCRIPTION</h2>
<p> Draws a filled circle with the specified centre and radius. </p>
