<h2 class="name">NAME</h2>
<p> cbrt, cbrtf, cbrtl &#8211; cube root function </p>
<h2>SYNOPSIS</h2>
<pre><code>
#include &lt;math.h&gt;
double cbrt(double x);
float cbrtf(float x);
long double cbrtl(long double x);
</code></pre>

<h2>DESCRIPTION</h2>
<p> These functions return the (real) cube root of <i>x</i>. This function cannot fail; every representable real value has a representable real cube root.</p>
<h2>RETURN VALUE</h2>
<p> These functions return the cube root of <i>x</i>. </p>
<p> If <i>x</i> is +0, -0, positive infinity, negative infinity, or NaN, <i>x</i> is returned.</p>
<h2>ERRORS</h2>
<p> No errors occur.</p>
