<h2>Function/Subroutine Documentation</h2>
<h3>subroutine clatzm (characterSIDE, integerM, integerN, complex, dimension( * )V, integerINCV, complexTAU, complex, dimension( ldc, * )C1, complex, dimension( ldc, * )C2, integerLDC, complex, dimension( * )WORK)</h3>
<p> <code>CLATZM</code> </p>
<p> <code>Purpose: </code></p>
<dl>
<dt>
<dd>
<pre><code>
This routine is deprecated and has been replaced by routine CUNMRZ.CLATZM applies a Householder matrix generated by CTZRQF to a matrix.Let P = I - tau * u * u * *H, u = (1),
                                                                                                                                           (v)
                                                                                                                                               where v is an(m - 1) vector if SIDE = 'L',
                                                                                                                                           or a(n - 1) vector if SIDE = 'R'.If SIDE equals 'L', let C = [C1] 1 [C2] m - 1 n Then C is overwritten by P * C.If SIDE equals 'R', let C = [ C1, C2 ] m 1 n - 1 Then C is overwritten by C * P.
</code></pre>
<p>&nbsp;<wbr></dl>
<p> <code>Parameters:</code></p>
<dl>
<dt>
<dd> <i>SIDE</i> </p>
<pre>
          SIDE is CHARACTER*1
          = 'L': form P * C
          = 'R': form C * P
</pre>
<p> <i>M</i> </p>
<pre>
          M is INTEGER
          The number of rows of the matrix C.
</pre>
<p> <i>N</i> </p>
<pre>
          N is INTEGER
          The number of columns of the matrix C.
</pre>
<p> <i>V</i> </p>
<pre>
          V is COMPLEX array, dimension
                  (1 + (M-1)*abs(INCV)) if SIDE = 'L'
                  (1 + (N-1)*abs(INCV)) if SIDE = 'R'
          The vector v in the representation of P. V is not used
          if TAU = 0.
</pre>
<p> <i>INCV</i> </p>
<pre>
          INCV is INTEGER
          The increment between elements of v. INCV &lt;&gt; 0
</pre>
<p> <i>TAU</i> </p>
<pre>
          TAU is COMPLEX
          The value tau in the representation of P.
</pre>
<p> <i>C1</i> </p>
<p>C1 is COMPLEX array, dimension(LDC, N) if SIDE = &#8216;L'(M, 1) if SIDE = &#8216;R&#8217; On entry, the n &#8211; vector C1 if SIDE = &#8216;L&#8217;, or the m &#8211; vector C1<br />
                                                                                                                            if SIDE = &#8216;R&#8217;.On exit,<br />
                                          the first row of P *C if SIDE = &#8216;L&#8217;, or the first<br />
                                                                                   column of C *P if SIDE = &#8216;R&#8217;.</p>
<p> <i>C2</i> </p>
<pre><code>
C2 is COMPLEX array, dimension(LDC, N) if SIDE = 'L'(LDC, N - 1) if SIDE = 'R' On entry, the(m - 1) x n matrix C2 if SIDE = 'L', or the
                                                                                                                                     m x(n - 1) matrix C2 if SIDE = 'R'.On exit,
                                          rows 2 : m of P *C if SIDE = 'L', or columns 2 : m of C *P
                                                                                           if SIDE = 'R'.
</code></pre>
<p> <i>LDC</i> </p>
<pre>
          LDC is INTEGER
          The leading dimension of the arrays C1 and C2.
          LDC &gt;= max(1,M).
</pre>
<p> <i>WORK</i> </p>
<pre>
          WORK is COMPLEX array, dimension
                      (N) if SIDE = 'L'
                      (M) if SIDE = 'R'
</pre>
