<h2>NAME</h2>
<p> curl_version &#8211; returns the libcurl version string</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;curl/curl.h&gt;</code> </p>
<p> <code>char *curl_version( );</code></p>
<h2>DESCRIPTION</h2>
<p> Returns a human readable string with the version number of libcurl and some of its important components (like OpenSSL version).</p>
<h2>RETURN VALUE</h2>
<p> A pointer to a zero terminated string.</p>
