<h2>NAME</h2>
<p> check_cpu &#8211; Detects the CPU type. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void check_cpu();</code></p>
<h2>DESCRIPTION</h2>
<p> Detects the CPU type, setting the following global variables. You don&#8217;t normally need to call this, because allegro_init() will do it for you. </p>
