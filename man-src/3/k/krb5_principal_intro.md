<h2 class="name">NAME</h2>
<p> krb5_principal_intro &#8211; The principal handing functions. A Kerberos principal is a email address looking string that contains two parts separated by The second part is the kerberos realm the principal belongs to and the first is a list of 0 or more components. For example </p>
<pre><code>
lha[at] SU.SE
        host /
    hummel.it.su.se[at] SU.SE
        host /
    admin[at] H5L.ORG
</code></pre>
