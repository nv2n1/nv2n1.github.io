<h2>DESCRIPTION</h2>
<p> The Fn krb5_digest_alloc function allocatates the Fa digest structure. The structure should be freed with Fn krb5_digest_free when it is no longer being used. </p>
<p> Fn krb5_digest_alloc returns 0 to indicate success. Otherwise an kerberos code is returned and the pointer that Fa digest points to is set to <code>NULL</code> </p>
<p> Fn krb5_digest_free free the structure Fa digest .</p>
