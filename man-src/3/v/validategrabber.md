XMLTV::ValidateGrabber - Validates an XMLTV grabber 

<h2>Description</h2>Utility library that validates that a grabber properly implements the capabilities described at 

 <a rel="nofollow" HREF="http://wiki.xmltv.org/index.php/XmltvCapabilities">http://wiki.xmltv.org/index.php/XmltvCapabilities</a> 

 The ValidateGrabber call first asks the grabber which capabilities it claims to support and then validates that it actually does support these capabilities.
<h2>Exported Functions</h2>All these functions are exported on demand.
<dl COMPACT><dt>ConfigureGrabber
<dd><pre> ConfigureGrabber( &quot;./tv_grab_new&quot;, &quot;./tv_grab_new.conf&quot; )</pre><dt>ValidateGrabber
<dd>Run the validation for a grabber. 

 <pre> ValidateGrabber( &quot;tv_grab_new&quot;, &quot;./tv_grab_new&quot;, &quot;./tv_grab_new.conf&quot;, 
 &quot;/tmp/new_&quot;, &quot;./blib/share&quot;, 0 )</pre>ValidateGrabber takes the following parameters:
<dl COMPACT><dd><dl COMPACT><dt>&bull;
<dd>a short name for the grabber. This is only used when printing error messages.
<dt>&bull;
<dd>the command to run the grabber.
<dt>&bull;
<dd>the name of a configuration-file for the grabber.
<dt>&bull;
<dd>a file-prefix that is added to all output-files.
<dt>&bull;
<dd>a path to a directory with metadata for the grabber. This path is passed to the grabber via the --share option if the grabber supports the capability 'share'. undef if no --share parameter shall be used.
<dt>&bull;
<dd>a boolean specifying if the --cache parameter shall be used for grabbers that support the 'cache' capability.</dl></dl><dl COMPACT><dd>ValidateGrabber returns a list of errors that it found with the grabber. Each error takes the form of a keyword:
<dl COMPACT><dt>noparamcheck
<dd>The grabber accepts any parameter without returning an error-code.
<dt>noversion
<dd>The grabber returns an error when run with --version.
<dt>nodescription
<dd>The grabber returns an error when run with --description.
<dt>nocapabilities
<dd>The grabber returns an error when run with --capabilities.
<dt>nobaseline
<dd>The grabber does not list 'baseline' as one of its supported capabilities.
<dt>nomanualconfig
<dd>The grabber does not list 'manualconfig' as one of its supported capabilities.
<dt>noconfigurationfile
<dd>The specified configuration-file does not exist.
<dt>graberror
<dd>The grabber returned with an error-code when asked to grab data.
<dt>notquiet
<dd>The grabber printed something to <font SIZE="-1">STDERR</font> even though the --quiet option was used.
<dt>outputdiffers
<dd>The grabber produced different output when called with different combinations of --output and --quiet.
<dt>caterror
<dd>tv_cat returned an error-code when we asked it to process the output from the grabber.
<dt>sorterror
<dd>tv_sort found errors in the data generated by the grabber. Probably overlapping programmes.
<dt>notadditive
<dd>grabbing data for tomorrow first and then for the day after tomorrow and concatenating them does not yield the same result as grabbing the data for tomorrow and the day after tomorrow at once.</dl></dl><dl COMPACT><dd>Additionally, the list of errors will contain error keywords from XMLTV::ValidateFile if the xmltv-file generated by the grabber was not valid. 

 If no errors are found, an empty list is returned.</dl></dl><h2>Copyright</h2>Copyright (C) 2006 Mattias Holmlund.
