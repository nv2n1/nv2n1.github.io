<p>zmq_socket_monitor &#8211; monitor socket events</p>
<h2>Synopsis</h2>
<pre><code>int zmq_socket_monitor(void *socket, char *endpoint, int events);</code></pre>
<h2>Description</h2>
<p>The <i>zmq_socket_monitor()</i> method lets an application thread track socket events (like connects) on a ZeroMQ socket. Each call to this method creates a <i>ZMQ_PAIR</i> socket and binds that to the specified inproc:// <i>endpoint</i>. To collect the socket events, you must create your own <i>ZMQ_PAIR</i> socket, and connect that to the endpoint. </p>
<p> The <i>events</i> argument is a bitmask of the socket events you wish to monitor, see <i>Supported events</i> below. To monitor all events, use the event value ZMQ_EVENT_ALL. </p>
<p> Each event is sent as two frames. The first frame contains an event number (16 bits), and an event value (32 bits) that provides additional data according to the event number. The second frame contains a string that specifies the affected TCP or IPC endpoint. </p>
<dl>
<dd>
<pre>The _zmq_socket_monitor()_ method supports only connection-oriented
transports, that is, TCP, IPC, and TIPC.</pre>
</dl>
<h2>Supported Events</h2>
<h3>Zmq_Event_Connected</h3>
<p>The socket has successfully connected to a remote peer. The event value is the file descriptor (FD) of the underlying network socket. Warning: there is no guarantee that the FD is still valid by the time your code receives this event.</p>
<h3>Zmq_Event_Connect_Delayed</h3>
<p>A connect request on the socket is pending. The event value is unspecified.</p>
<h3>Zmq_Event_Connect_Retried</h3>
<p>A connect request failed, and is now being retried. The event value is the reconnect interval in milliseconds. Note that the reconnect interval is recalculated at each retry.</p>
<h3>Zmq_Event_Listening</h3>
<p>The socket was successfully bound to a network interface. The event value is the FD of the underlying network socket. Warning: there is no guarantee that the FD is still valid by the time your code receives this event.</p>
<h3>Zmq_Event_Bind_Failed</h3>
<p>The socket could not bind to a given interface. The event value is the errno generated by the system bind call.</p>
<h3>Zmq_Event_Accepted</h3>
<p>The socket has accepted a connection from a remote peer. The event value is the FD of the underlying network socket. Warning: there is no guarantee that the FD is still valid by the time your code receives this event.</p>
<h3>Zmq_Event_Accept_Failed</h3>
<p>The socket has rejected a connection from a remote peer. The event value is the errno generated by the accept call.</p>
<h3>Zmq_Event_Closed</h3>
<p>The socket was closed. The event value is the FD of the (now closed) network socket.</p>
<h3>Zmq_Event_Close_Failed</h3>
<p>The socket close failed. The event value is the errno returned by the system call. Note that this event occurs only on IPC transports.</p>
<h3>Zmq_Event_Disconnected</h3>
<p>The socket was disconnected unexpectedly. The event value is the FD of the underlying network socket. Warning: this socket will be closed.</p>
<h3>Zmq_Event_Monitor_Stopped</h3>
<p>Monitoring on this socket ended.</p>
<h2>Return Value</h2>
<p>The <i>zmq_socket_monitor()</i> function returns a value of 0 or greater if successful. Otherwise it returns -1 and sets <i>errno</i> to one of the values defined below.</p>
<h2>Errors</h2>
<p><code>ETERM</code></p>
<dl>
<dd>The 0MQ <i>context</i> associated with the specified <i>socket</i> was terminated.</dl>
<p> <code>EPROTONOSUPPORT</code></p>
<dl>
<dd>The requested <i>transport</i> protocol is not supported. Monitor sockets are required to use the inproc:// transport.</dl>
<p> <code>EINVAL</code></p>
<dl>
<dd>The endpoint supplied is invalid.</dl>
<h2>Example</h2>
<p><code>Monitoring client and server sockets</code>. </p>
<pre><code>//  Read one event off the monitor socket; return value and address
//  by reference, if not null, and event number by value. Returns -1
//  in case of error.

static int
get_monitor_event(void *monitor, int *value, char **address)
{
    //  First frame in message contains event number and value
    zmq_msg_t msg;
    zmq_msg_init(&amp;msg);
    if (zmq_msg_recv(&amp;msg, monitor, 0) == -1)
        return -1; //  Interruped, presumably
    assert(zmq_msg_more(&amp;msg));

    uint8_t *data = (uint8_t *)zmq_msg_data(&amp;msg);
    uint16_t event = *(uint16_t *)(data);
    if (value)
        *value = *(uint32_t *)(data + 2);

    //  Second frame in message contains event address
    zmq_msg_init(&amp;msg);
    if (zmq_msg_recv(&amp;msg, monitor, 0) == -1)
        return -1; //  Interruped, presumably
    assert(!zmq_msg_more(&amp;msg));

    if (address) {
        uint8_t *data = (uint8_t *)zmq_msg_data(&amp;msg);
        size_t size = zmq_msg_size(&amp;msg);
        *address = (char *)malloc(size + 1);
        memcpy(*address, data, size);
        *address[size] = 0;
    }
    return event;
}

int main(void)
{
    void *ctx = zmq_ctx_new();
    assert(ctx);

    //  We'll monitor these two sockets
    void *client = zmq_socket(ctx, ZMQ_DEALER);
    assert(client);
    void *server = zmq_socket(ctx, ZMQ_DEALER);
    assert(server);

    //  Socket monitoring only works over inproc://
    int rc = zmq_socket_monitor(client, &quot;tcp://127.0.0.1:9999&quot;, 0);
    assert(rc == -1);
    assert(zmq_errno() == EPROTONOSUPPORT);

    //  Monitor all events on client and server sockets
    rc = zmq_socket_monitor(client, &quot;inproc://monitor-client&quot;, ZMQ_EVENT_ALL);
    assert(rc == 0);
    rc = zmq_socket_monitor(server, &quot;inproc://monitor-server&quot;, ZMQ_EVENT_ALL);
    assert(rc == 0);

    //  Create two sockets for collecting monitor events
    void *client_mon = zmq_socket(ctx, ZMQ_PAIR);
    assert(client_mon);
    void *server_mon = zmq_socket(ctx, ZMQ_PAIR);
    assert(server_mon);

    //  Connect these to the inproc endpoints so they'll get events
    rc = zmq_connect(client_mon, &quot;inproc://monitor-client&quot;);
    assert(rc == 0);
    rc = zmq_connect(server_mon, &quot;inproc://monitor-server&quot;);
    assert(rc == 0);

    //  Now do a basic ping test
    rc = zmq_bind(server, &quot;tcp://127.0.0.1:9998&quot;);
    assert(rc == 0);
    rc = zmq_connect(client, &quot;tcp://127.0.0.1:9998&quot;);
    assert(rc == 0);
    bounce(client, server);

    //  Close client and server
    close_zero_linger(client);
    close_zero_linger(server);

    //  Now collect and check events from both sockets
    int event = get_monitor_event(client_mon, NULL, NULL);
    if (event == ZMQ_EVENT_CONNECT_DELAYED)
        event = get_monitor_event(client_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_CONNECTED);
    event = get_monitor_event(client_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_MONITOR_STOPPED);

    //  This is the flow of server events
    event = get_monitor_event(server_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_LISTENING);
    event = get_monitor_event(server_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_ACCEPTED);
    event = get_monitor_event(server_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_CLOSED);
    event = get_monitor_event(server_mon, NULL, NULL);
    assert(event == ZMQ_EVENT_MONITOR_STOPPED);

    //  Close down the sockets
    close_zero_linger(client_mon);
    close_zero_linger(server_mon);
    zmq_ctx_term(ctx);

    return 0;
}
