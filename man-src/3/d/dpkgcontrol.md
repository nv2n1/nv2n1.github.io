Dpkg::Control - parse and manipulate official control-like information 

<h2>Description</h2>The Dpkg::Control object is a smart version of Dpkg::Control::Hash. It associates a type to the control information. That type can be used to know what fields are allowed and in what order they must be output. 

 The types are constants that are exported by default. Here's the full list:
<dl COMPACT><dt><font SIZE="-1">CTRL_UNKNOWN</font>
<dd>This type is the default type, it indicates that the type of control information is not yet known.
<dt><font SIZE="-1">CTRL_INFO_SRC</font>
<dd>Corresponds to the first block of information in a <i>debian/control</i> file in a Debian source package.
<dt><font SIZE="-1">CTRL_INFO_PKG</font>
<dd>Corresponds to subsequent blocks of information in a <i>debian/control</i> file in a Debian source package.
<dt><font SIZE="-1">CTRL_INDEX_SRC</font>
<dd>Corresponds to an entry in a <i>Sources</i> file of a source package repository.
<dt><font SIZE="-1">CTRL_INDEX_PKG</font>
<dd>Corresponds to an entry in a <i>Packages</i> file of a binary package repository.
<dt><font SIZE="-1">CTRL_PKG_SRC</font>
<dd>Corresponds to a .dsc file of a Debian source package.
<dt><font SIZE="-1">CTRL_PKG_DEB</font>
<dd>Corresponds to the <i>control</i> file generated by dpkg-gencontrol (<i>DEBIAN/control</i>) and to the same file inside .deb packages.
<dt><font SIZE="-1">CTRL_FILE_CHANGES</font>
<dd>Corresponds to a .changes file.
<dt><font SIZE="-1">CTRL_FILE_VENDOR</font>
<dd>Corresponds to a vendor file in <tt>$Dpkg::CONFDIR</tt>/origins/.
<dt><font SIZE="-1">CTRL_FILE_STATUS</font>
<dd>Corresponds to an entry in dpkg's <i>status</i> file ($Dpkg::ADMINDIR/status).
<dt><font SIZE="-1">CTRL_CHANGELOG</font>
<dd>Corresponds to the output of dpkg-parsechangelog.</dl><h2>Functions</h2>All the methods of Dpkg::Control::Hash are available. Those listed below are either new or overridden with a different behaviour.
<dl COMPACT><dt>my $c = Dpkg::Control-&gt;new(%opts)
<dd>If the ``type'' option is given, it's used to setup default values for other options. See <i>set_options()</i> for more details.
<dt>$c-&gt;set_options(%opts)
<dd>Changes the value of one or more options. If the ``type'' option is changed, it is used first to define default values for others options. The option ``allow_pgp'' is set to 1 for <font SIZE="-1">CTRL_PKG_SRC</font> and <font SIZE="-1">CTRL_FILE_CHANGES</font> and to 0 otherwise. The option ``drop_empty'' is set to 0 for <font SIZE="-1">CTRL_INFO_PKG</font> and <font SIZE="-1">CTRL_INFO_SRC</font> and to 1 otherwise. The option ``name'' is set to a textual description of the type of control information. 

 The output order is also set to match the ordered list returned by Dpkg::Control::Fields::field_ordered_list($type).
<dt>$c-&gt;<i>get_type()</i>
<dd>Returns the type of control information stored. See the type parameter set during <i>new()</i>.</dl><h2>Changes</h2><h3>Version 1.00</h3>Mark the module as public.
