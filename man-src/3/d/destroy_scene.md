<h2>NAME</h2>
<p> destroy_scene &#8211; Deallocates the memory used by a scene. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void destroy_scene();</code></p>
<h2>DESCRIPTION</h2>
<p> Deallocate memory previously allocated by create_scene. Use this to avoid memory leaks in your program. </p>
