<p>Data::UUID &#8211; OSSP uuid Backward Compatibility Perl Binding </p>
<h2>Description</h2>
<p><code>Data::UUID</code> is the <font SIZE="-1"><code>OSSP</code></font><code> uuid</code> backward compatibility Perl binding to the <font SIZE="-1">API</font> of the original <code>Data::UUID</code> module. It allows other <code>Data::UUID</code> based Perl modules to run with <code>OSSP::uuid</code> without changes.</p>
<h2>See Also</h2>
<p><code>OSSP::uuid</code>.</p>
<h2>History</h2>
<p>The backward compatibility Perl binding <code>Data::UUID</code> for <font SIZE="-1"><code>OSSP</code></font><code> uuid</code> was originally implemented in 2004 by Piotr Roszatycki &lt;dexter [at] debian.org&gt;. It was later cleaned up and speed optimized in December 2005 by David Wheeler &lt;david [at] justatheory.com&gt;.</p>
