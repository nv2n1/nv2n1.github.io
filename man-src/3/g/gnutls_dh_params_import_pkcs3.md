<h2>NAME</h2>
<p> gnutls_dh_params_import_pkcs3 &#8211; API function</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;gnutls/gnutls.h&gt;</code> </p>
<p> <code>int gnutls_dh_params_import_pkcs3(gnutls_dh_params_t </code><i>params</i><code>, const gnutls_datum_t * </code><i>pkcs3_params</i><code>, gnutls_x509_crt_fmt_t </code><i>format</i><code>);</code></p>
<h2>ARGUMENTS</h2>
<dl>
<dt>gnutls_dh_params_t params</p>
<dd> A structure where the parameters will be copied to</p>
<dt>const gnutls_datum_t * pkcs3_params</p>
<dd> should contain a PKCS3 DHParams structure PEM or DER encoded</p>
<dt>gnutls_x509_crt_fmt_t format</p>
<dd> the format of params. PEM or DER.</dl>
<h2>DESCRIPTION</h2>
<p> This function will extract the DHParams found in a PKCS3 formatted structure. This is the format generated by &quot;openssl dhparam&quot; tool. </p>
<p> If the structure is PEM encoded, it should have a header of &quot;BEGIN DH PARAMETERS&quot;.</p>
<h2>RETURNS</h2>
<p> On success, <code>GNUTLS_E_SUCCESS</code> (0) is returned, otherwise a negative error code is returned.</p>
