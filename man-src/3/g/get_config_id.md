<h2>NAME</h2>
<p> get_config_id &#8211; Retrieves a driver ID from a configuration file. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>int get_config_id(const char *section, const char *name, int def);</code></p>
<h2>DESCRIPTION</h2>
<p> Reads a 4-letter driver ID variable from the current config file. See the comments about get_config_string(). </p>
