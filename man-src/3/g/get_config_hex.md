<h2>NAME</h2>
<p> get_config_hex &#8211; Retrieves a hexadecimal value from the configuration file. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>int get_config_hex(const char *section, const char *name, int def);</code></p>
<h2>DESCRIPTION</h2>
<p> Reads an integer variable from the current config file, in hexadecimal format. See the comments about get_config_string(). </p>
