<p>GSTREAM_DATE_STR</p>
<h2>Synopsis</h2>
<p><code>#include &lt;<a href="file:/usr/include/gstream.h">gstream.h</a>&gt;</code> </p>
<p> <code>char GSTREAM_DATE_STR[]</code></p>
<h2>Description</h2>
<p>This will contain the year of the current version of the library. For example, for version 1.0 of the library, this string will be &quot;1999&quot;. </p>
<p> (For version 19.43 it will probably be &quot;3061&quot; :-) </p>
