<h2>NAME</h2>
<p> gnutls_x509_crq_deinit &#8211; API function</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;gnutls/x509.h&gt;</code> </p>
<p> <code>void gnutls_x509_crq_deinit(gnutls_x509_crq_t </code><i>crq</i><code>);</code></p>
<h2>ARGUMENTS</h2>
<dl>
<dt>gnutls_x509_crq_t crq</p>
<dd> The structure to be initialized</dl>
<h2>DESCRIPTION</h2>
<p> This function will deinitialize a PKCS<code>10</code> certificate request structure.</p>
