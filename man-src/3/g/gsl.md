<h2>NAME</h2>
<p> gsl &#8211; GNU Scientific Library</p>
<h2>SYNOPSIS</h2>
<p> #include &lt;gsl/&#8230;&gt;</p>
<h2>DESCRIPTION</h2>
<p> The GNU Scientific Library (GSL) is a collection of routines for numerical computing. The routines are written from scratch by the GSL team in C, and present a modern Applications Programming Interface (API) for C programmers, allowing wrappers to be written for very high level languages. </p>
<p> The library covers the following areas,</p>
<dl>
<dt>
<pre>
<dd>Complex Numbers
Roots of Polynomials
Special Functions
Vectors and Matrices
Permutations
Combinations
Sorting
BLAS Support
Linear Algebra
Eigensystems
Fast Fourier Transforms
Quadrature
Random Numbers
Quasi-Random Sequences
Random Distributions
Statistics
Histograms
N-Tuples
Monte Carlo Integration
Simulated Annealing
Differential Equations
Interpolation
Numerical Differentiation
Chebyshev Approximations
Series Acceleration
Discrete Hankel Transforms
Root-Finding
Minimization
Least-Squares Fitting
Physical Constants
IEEE Floating-Point
</pre>
</dl>
<p> For more information please consult the GSL Reference Manual, which is available as an info file. You can read it online using the shell command <code>info gsl-ref </code> (if the library is installed). </p>
<p> Please report any bugs to <code>bug-gsl [at] gnu.org.</code> </p>
