<h2>NAME</h2>
<p> get_clip_rect &#8211; Returns the clipping rectangle of a bitmap. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void get_clip_rect(BITMAP *bitmap, int *x1, int *y1, int *x2, int *y2);</code></p>
<h2>DESCRIPTION</h2>
<p> Returns the clipping rectangle for the specified bitmap. </p>
