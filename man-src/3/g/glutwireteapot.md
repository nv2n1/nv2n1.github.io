<p><code>glutWireTeapot</code> &#8211; Draw a wireframe teapot.</p>
<h2>Library</h2>
<p>OpenGLUT &#8211; geometry</p>
<h2>Synopsis</h2>
<p>In openglut.h Ft void Fn glutWireTeapot GLdouble size</p>
<h2>Parameters</h2>
<p>Bf Em<br />
&nbsp;<wbr>size Ef<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>Scale factor.</p>
<h2>Description</h2>
<p>This function draws the standard Teapot in wireframe using OpenGL evaluators. This is the classic &quot;Utah Teapot&quot; of computer graphics. The base should lie in the xy-plane with &quot;up&quot; being along the positive z axis. </p>
<p> This is derived from SGI code. It should also be the same as the teapot modeled by Martin Newell in 1975. </p>
