<h2>NAME</h2>
<p> get_clip_state &#8211; Tells if clipping is on for a bitmap. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>int get_clip_state(BITMAP *bitmap)</code></p>
<h2>DESCRIPTION</h2>
<p> Returns non-zero if clipping is turned on for the specified bitmap and zero otherwise. </p>
