<h2 class="name">NAME</h2>
<p> Server &#8211; <code>globus_xio_server_create()</code> causes a mode_e listener to be created and listened upon. <code>globus_xio_server_register_accept()</code> performs an asynchronous accept(). <code>globus_xio_server_register_close()</code> cleans up the internal resources associated with the mode_e server. </p>
<p> All accepted handles inherit all mode_e specific attributes set in the attr to <code>globus_xio_server_create()</code> </p>
