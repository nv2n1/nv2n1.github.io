<p>umad_size &#8211; get the size of umad buffer</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;infiniband/umad.h&gt;

size_t umad_size(void);</code></pre>
<h2>Description</h2>
<p><code>umad_size()</code> returns the size of umad buffer (in bytes).</p>
<h2>Return Value</h2>
<p><code>umad_size()</code> returns the size of umad buffer (in bytes).</p>
