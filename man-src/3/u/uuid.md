<p>uuid &#8211; DCE compatible Universally Unique Identifier library</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;uuid.h&gt;</code></pre>
<h2>Description</h2>
<p>The UUID library is used to generate unique identifiers for objects that may be accessible beyond the local system. This library generates UUIDs compatible with those created by the Open Software Foundation (OSF) Distributed Computing Environment (DCE) utility <code>uuidgen</code>. </p>
<p> The UUIDs generated by this library can be reasonably expected to be unique within a system, and unique across all systems. They could be used, for instance, to generate unique HTTP cookies across multiple web servers without communication between the servers, and without fear of a name clash.</p>
<h2>Conforming To</h2>
<p>This library generates UUIDs compatible with OSF DCE 1.1, and hash based UUIDs V3 and V5 compatible with RFC-4122.</p>
