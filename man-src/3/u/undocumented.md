<p>undocumented &#8211; undocumented library functions</p>
<h2>Synopsis</h2>
<p>Undocumented library functions</p>
<h2>Description</h2>
<p>This man page mentions those library functions which are implemented in the standard libraries but not yet documented in man pages.</p>
<h3>Solicitation</h3>
<p>If you have information about these functions, please look in the source code, write a man page (using a style similar to that of the other Linux section 3 man pages), and send it to <code>mtk.manpages [at] gmail.com</code> for inclusion in the next man page release.</p>
