<h2>NAME</h2>
<p> libdavix &#8211; shared library for HTTP I/O <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt> </p>
<h2>DESCRIPTION</h2>
<p> libdavix is a C++ shared library for high performance remote I/O and resources management with HTTP Based protocols. </p>
<p> libdavix aims to be a complete, reliable and performant I/O layer for Cloud, Grid and Web storage systems.<br />
 It supports the protocol Http (http(s)://), WebDav (dav(s)://) and S3 (s3(s)://). </p>
<p> See libdavix doxygen documentation for more details. </p>
