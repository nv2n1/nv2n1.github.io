Lintian::Architecture -- Lintian API for handling architectures and wildcards 

<h2>Synopsis</h2><pre> use Lintian::Architecture qw(:all);
 
 print &quot;arch\n&quot; if is_arch ('i386');
 print &quot;wildcard\n&quot; if is_arch_wildcard ('any');
 print &quot;either arch or wc\n&quot; if is_arch_or_wildcard ('linux-any');
 foreach my $arch (expand_arch_wildcard ('any')) {
 print &quot;any expands to $arch\n&quot;;
 }</pre><h2>Description</h2>Lintian <font SIZE="-1">API</font> for checking and expanding architectures and architecture wildcards. The functions are backed by a data file, so it may be out of date (use private/refresh-archs to update it). 

 Generally all architecture names are in the format ``$os-$arch'' and wildcards are ``$os-any'' or ``any-$cpu'', though there are exceptions:
<dl COMPACT><dt>&bull;
<dd>``all'' is the ``architecture independent'' architecture. 

 Source: Policy X5.6.8 (v3.9.3)
<dt>&bull;
<dd>``any'' is a wildcard matching any architecture except ``all''. 

 Source: Policy X5.6.8 (v3.9.3)
<dt>&bull;
<dd>All other cases of ``$arch'' are short for ``linux-$arch'' 

 Source: Policy X11.1 (v3.9.3)</dl>
 

 Note that the architecture and cpu name are not always identical (example architecture ``armhf'' has cpu name ``arm'').
<h2>Functions</h2>The following methods are exportable:
<dl COMPACT><dt>is_arch_wildcard ($wc)
<dd>Returns a truth value if <tt>$wc</tt> is a known architecture wildcard. 

 Note: 'any' is considered a wildcard and not an architecture.
<dt>is_arch ($arch)
<dd>Returns a truth value if <tt>$arch</tt> is (an alias of) a Debian machine architecture <font SIZE="-1">OR</font> the special value ``all''. It returns a false value for architecture wildcards (including ``any'') and unknown architectures.
<dt>is_arch_or_wildcard ($arch)
<dd>Returns a truth value if <tt>$arch</tt> is either an architecture or an architecture wildcard. 

 Shorthand for: 

 <pre> is_arch ($arch) || is_arch_wildcard ($arch)</pre><dt>expand_arch_wildcard ($wc)
<dd>Returns a list of architectures that this wildcard expands to. No order is guaranteed (even between calls). Returned values must not be modified. 

 Note: This list is based on the architectures in Lintian's data file. However, many of these are not supported or used in Debian or any of its derivatives. 

 The returned values matches the list generated by dpkg-architecture -L, so the returned list may use (e.g.) ``amd64'' for ``linux-amd64''.
<dt>wildcard_includes_arch ($wc, $arch)
<dd>Returns a truth value if <tt>$arch</tt> is included in the list of architectures that <tt>$wc</tt> expands to. 

 This is generally faster than 

 <pre> grep { $_ eq $arch } expand_arch_wildcard ($wc)</pre>It also properly handles cases like ``linux-amd64'' and ``amd64'' being aliases. 

</dl>
