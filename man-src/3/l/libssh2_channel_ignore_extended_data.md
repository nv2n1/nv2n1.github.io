<h2>NAME</h2>
<p> libssh2_channel_ignore_extended_data &#8211; convenience macro for <i><a href="/docs/linux/man/3-libssh2_channel_handle_extended_data/">libssh2_channel_handle_extended_data</a>(3)</i> calls</p>
<h2>SYNOPSIS</h2>
<p> #include &lt;libssh2.h&gt; </p>
<p> libssh2_channel_ignore_extended_data(arguments) </p>
<h2>DESCRIPTION</h2>
<p> This function is deprecated. Use the <i><a href="/docs/linux/man/3-libssh2_channel_handle_extended_data2/">libssh2_channel_handle_extended_data2</a>(3)</i> function instead! </p>
