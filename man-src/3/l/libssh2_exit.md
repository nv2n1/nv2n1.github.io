<h2>NAME</h2>
<p> libssh2_exit &#8211; global library deinitialization</p>
<h2>SYNOPSIS</h2>
<p> #include &lt;libssh2.h&gt; </p>
<p> void libssh2_exit(void);</p>
<h2>DESCRIPTION</h2>
<p> Exit the libssh2 functions and free&#8217;s all memory used internal.</p>
<h2>AVAILABILITY</h2>
<p> Added in libssh2 1.2.5</p>
