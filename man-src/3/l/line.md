<h2>NAME</h2>
<p> line &#8211; Draws a line onto the bitmap. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void line(BITMAP *bmp, int x1, int y1, int x2, int y2, int color);</code></p>
<h2>DESCRIPTION</h2>
<p> Draws a line onto the bitmap, from point (x1, y1) to (x2, y2). </p>
