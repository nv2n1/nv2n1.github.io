<h2>DESCRIPTION</h2>
<p> These library functions are part of <code><a href="/docs/linux/man/1-netpbm/">Netpbm</a></code>(1) </p>
<h3>TYPES AND CONSTANTS</h3>
<p> Each <code>gray</code> should contain only the values between <code>0</code> and <code>PGM_OVERALLMAXVAL</code>. </p>
<p> <code>PGM_OVERALLMAXVAL</code> is the maximum value of a maxval in a PGM file. <code>PGM_MAXMAXVAL</code> is the maximum value of a maxval in a PGM file that is compatible with the PGM format as it existed before April 2000. It is also the maximum value of a maxval that results in the minimum possible raster size for a particular image. I.e an image with a maxval higher than <code>PGM_MAXMAXVAL</code> cannot be read or generated by old PGM processing programs and requires more file space. </p>
<p> <code>PGM_FORMAT </code> is the format code for a Plain PGM format image file. <code>RPGM_FORMAT</code> is the format code for a Raw PGM format image file. <code>PGM_TYPE </code> is the format type code for the PGM formats. <code>PGM_FORMAT_TYPE</code> is a macro that generates code to compute the format type code of a PBM or PGM format from the format code which is its argument. </p>
<h3>INITIALIZATION</h3>
<p> <code>pgm_init()</code> is obsolete (at least since Netpbm 9.25 (March 2002)). Use <code>pm_proginit()</code> instead. </p>
<p> <code>pgm_init()</code> is identical to <code>pm_proginit</code>. </p>
<h3>MEMORY MANAGEMENT</h3>
<p> <code>pgm_allocarray()</code> allocates an array of grays. </p>
<p> <code>pgm_allocrow()</code> allocates a row of the given number of grays. </p>
<p> <code>pgm_freearray()</code> frees the array allocated with <code>pgm_allocarray()</code> containing the given number of rows. </p>
<p> <code>pgm_freerow()</code> frees a row of grays allocated with <code>pgm_allocrow()</code>. </p>
<h3>READING FILES</h3>
<p> If a function in this section is called on a PBM format file, it translates the PBM file into a PGM file on the fly and functions as if it were called on the equivalent PGM file. The <i>format</i> value returned by <code>pgm_readpgminit()</code> is, however, not translated. It represents the actual format of the PBM file. </p>
<p> <code>pgm_readpgminit()</code> reads the header of a PGM file, returning all the information from the header and leaving the file positioned just after the header. </p>
<p> <code>pgm_readpgmrow()</code> reads a row of grays into the <i>grayrow </i> array. <i>format</i>, <i>cols</i>, and <i>maxval </i> are the values returned by <code>pgm_readpgminit()</code>. </p>
<p> <code>pgm_readpgm()</code> reads an entire PGM image into memory, returning the allocated array as its return value and returning the information from the header as <i>rows</i>, <i>cols</i>, and <i>maxval</i>. This function combines <code>pgm_readpgminit()</code>, <code>pgm_allocarray()</code>, and <code>pgm_readpgmrow()</code>. </p>
<p> <code>pgm_readpgminit()</code> and <code>pgm_readpgm</code> abort the program with a message to Standard Error if the PGM image header is not syntactically valid, including if it contains a number too large to be processed using the system&#8217;s normal data structures (to wit, a number that won&#8217;t fit in a C &#8216;int&#8217;). </p>
<h3>WRITING FILES</h3>
<p> <code>pgm_writepgminit()</code> writes the header for a PGM file and leaves it positioned just after the header. </p>
<p> <i>forceplain</i> is a logical value that tells <code>pgm_writepgminit() </code> to write a header for a plain PGM format file, as opposed to a raw PGM format file. </p>
<p> <code>pgm_writepgmrow()</code> writes the row <i>grayrow</i> to a PGM file. For meaningful results, <i>cols</i>, <i>maxval</i>, and <i>forceplain</i> must be the same as was used with <code>pgm_writepgminit()</code>. </p>
<p> <code>pgm_writepgm()</code> write the header and all data for a PGM image. This function combines <code>pgm_writepgminit()</code> and <code>pgm_writepgmrow()</code>. </p>
<h3>MISCELLANEOUS</h3>
<p> <code>pgm_nextimage()</code> positions a PGM input file to the next image in it (so that a subsequent <code>pgm_readpgminit()</code> reads its header). </p>
<p> <code>pgm_nextimage()</code> is analogous to <code>pbm_nextimage()</code>, but works on PGM and PBM files. </p>
<p> <code>pgm_check() </code> checks for the common file integrity error where the file is the wrong size to contain all the image data. </p>
<p> <code>pgm_check() </code> is analogous to <code>pbm_check()</code>, but works on PGM and PBM files. </p>
