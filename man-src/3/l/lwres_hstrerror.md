<h2 class="name">NAME</h2>
<p> lwres_herror, lwres_hstrerror &#8211; lightweight resolver error message generation </p>
<h2>SYNOPSIS</h2>
<pre><code>
#include &lt;lwres/netdb.h&gt;
</code></pre>
<dl>
<dt> <code>void lwres_herror(const char&nbsp;<wbr>*</code><i>s</i><code>);</code></p>
<dt> <code>const char * lwres_hstrerror(int&nbsp;<wbr></code><i>err</i><code>);</code></dl>
<h2>DESCRIPTION</h2>
<p> <code>lwres_herror()</code></p>
<dd>prints the string <i>s</i> on <code>stderr</code> followed by the string generated by <code>lwres_hstrerror()</code> for the error code stored in the global variable <code>lwres_h_errno</code>. </p>
<p> <code>lwres_hstrerror()</code> returns an appropriate string for the error code gievn by <i>err</i>. The values of the error codes and messages are as follows: </p>
<p> <code>NETDB_SUCCESS</code></p>
<dl>
<dt>
<dd> Resolver Error 0 (no error)</dl>
<p> <code>HOST_NOT_FOUND</code></p>
<dl>
<dt>
<dd> Unknown host</dl>
<p> <code>TRY_AGAIN</code></p>
<dl>
<dt>
<dd> Host name lookup failure</dl>
<p> <code>NO_RECOVERY</code></p>
<dl>
<dt>
<dd> Unknown server error</dl>
<p> <code>NO_DATA</code></p>
<dl>
<dt>
<dd> No address associated with name</dl>
<h2>RETURN VALUES</h2>
<p> The string Unknown resolver error is returned by <code>lwres_hstrerror()</code> when the value of <code>lwres_h_errno</code> is not a valid error code.</p>
