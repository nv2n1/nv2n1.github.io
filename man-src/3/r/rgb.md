<p>RGB &#8211; Single palette entry. Allegro game programming library.</p>
<h2>Synopsis</h2>
<p><code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>typedef struct RGB</code></p>
<h2>Description</h2>
<pre> unsigned char r, g, b;</pre>
<p>Palette entry. It contains an additional field for the purpose of padding but you should not usually care about it. Read chapter &quot;Palette routines&quot; for a description on how to obtain/use this structure. </p>
