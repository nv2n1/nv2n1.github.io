resources - Additional resources The main QuantLib resource is the QuantLib web site (

<a rel="nofollow" HREF="http://quantlib.org">http://quantlib.org</a>). Additional resources available from the above site include:
<dl><dt>*
<dd>current news (<a rel="nofollow" HREF="http://sourceforge.net/news/?group_id=12740">http://sourceforge.net/news/?group_id=12740</a>);
<dt>*
<dd>the QuantLib mailing lists and forums (<a rel="nofollow" HREF="http://quantlib.org/mailinglists.shtml">http://quantlib.org/mailinglists.shtml</a>);
<dt>*
<dd>the QuantLib programming style guidelines (<a rel="nofollow" HREF="http://quantlib.org/style.shtml">http://quantlib.org/style.shtml</a>);
<dt>*
<dd>a link to the QuantLib project page on SourceForge.net (<a rel="nofollow" HREF="http://sourceforge.net/projects/quantlib">http://sourceforge.net/projects/quantlib</a>);
<dt>*
<dd>links to pages for bug reports (<a rel="nofollow" HREF="http://sourceforge.net/tracker/?group_id=12740">http://sourceforge.net/tracker/?group_id=12740</a>&amp;atid=112740), patch submissions (<a HREF="http://sourceforge.net/tracker/?group_id=12740">http://sourceforge.net/tracker/?group_id=12740</a>&amp;atid=312740), and feature requests (<a HREF="http://sourceforge.net/tracker/?group_id=12740">http://sourceforge.net/tracker/?group_id=12740</a>&amp;atid=362740);
<dt>*
<dd>a page (<a rel="nofollow" HREF="http://quantlib.org/extensions.shtml)">http://quantlib.org/extensions.shtml)</a> about how to use QuantLib in other languages/platforms;
<dt>*
<dd>as well as links to additional quantitative finance resources.</dl>
