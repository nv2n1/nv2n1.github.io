<h2>Synopsis</h2>
<pre>typedef struct _mongoc_stream_gridfs_t mongoc_stream_gridfs_t</pre>
<p>The <code>mongoc_stream_gridfs_t</code> class is an implementation of <code>mongoc_stream_t</code> for files stored in GridFS. It allows for transparently streaming GridFS files from a MongoDB server. </p>
