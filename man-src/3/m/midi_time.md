<h2>NAME</h2>
<p> midi_time &#8211; The current position in the MIDI file, in seconds. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>extern volatile long midi_time;</code></p>
<h2>DESCRIPTION</h2>
<p> Contains the position in seconds in the currently playing midi. This is useful if you want to display the current song position in seconds, not as beat number. </p>
