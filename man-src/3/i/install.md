<h2 class="name">NAME</h2>
<p> install &#8211; Installation Before installing QuantLib, make sure that you have a working Boost installation; see </p>
<p><a rel="nofollow" href="http://www.boost.org/more/getting_started.html">http://www.boost.org/more/getting_started.html</a> for instructions.</p>
<h2>Linux/Unix/Mac OS X/Cygwin</h2>
<p> A tarball of the source distribution is available from </p>
<p>&nbsp;<wbr><a rel="nofollow" href="http://quantlib.org/download.shtml">http://quantlib.org/download.shtml</a> </p>
<p> After uncompressing the sources:</p>
<dl>
<dt>1.</p>
<dd> `cd&#8217; to the QuantLib directory and type `./configure&#8217; to configure the package for your system; see the <code>User configuration</code> section for configuration options.</p>
<dt>2.</p>
<dd> Type `make&#8217; to compile the package.</p>
<dt>3.</p>
<dd> Type `make install&#8217; to install the library. This might require administrative privileges.</dl>
<h2>Win32</h2>
<p> An installer for the source distribution is available at </p>
<p>&nbsp;<wbr><a rel="nofollow" href="http://quantlib.org/download.shtml">http://quantlib.org/download.shtml</a> </p>
<p> Before compiling the library, you might want to edit the file &#8216;ql/userconfig.hpp&#8217;; see the <code>User configuration</code> section for details. </p>
<p> Projects files are supplied for building the library with Microsoft Visual C++ 7.1, 8.0 and 9.0 and with Dev-C++. </p>
