<h2>NAME</h2>
<p> is_trans_font &#8211; Returns TRUE if a font uses transparency. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>int is_trans_font(FONT *f)</code></p>
<h2>DESCRIPTION</h2>
<p> This function checks if the given font is a color font using draw_trans_sprite to render glyphs.</p>
<h2>RETURN VALUE</h2>
<p> Returns TRUE if the font uses transparency, FALSE if it does not. </p>
