<h2>NAME</h2>
<p> bson_get_micro_version() &#8211; Get the third number in libbson&#8217;s MAJOR.MINOR.MICRO release version.</p>
<h2>SYNOPSIS</h2>
<pre><code>
int bson_get_micro_version(void);
</code></pre>
<h2>DESCRIPTION</h2>
<p> Get the third number in libbson&#8217;s MAJOR.MINOR.MICRO release version. </p>
<h2>RETURNS</h2>
<p> The value of <code>BSON_MICRO_VERSION</code> when Libbson was compiled. </p>
