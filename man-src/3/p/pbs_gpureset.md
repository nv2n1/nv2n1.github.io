<p>pbs_ gpureset &#8211; reset GPU error counts</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

#include &lt;pbs_ifl.h&gt;</code></pre>
<pre>int pbs_ gpureset(int connect, char&nbsp;<wbr>*mom_node, int gpu_id, int ecc_perm, int ecc_vol)</pre>
<h2>Description</h2>
<p>Issue a batch request for the pbs_mom to reset the ECC counts on one of it&#8217;s Nvidia GPUs. The GPU&#8217;s error count is reset by sending a <i>GPU Control</i> batch request to the batch server. </p>
<p> The argument, <i> specifies the host within the cluster on which the GPU is located. The argument is the name of a host that is a member of the cluster of hosts managed by the server. </p>
<p> The argument, specifies ID of the GPU on the MOM node. </p>
<p> The argument, specifies whether or not to reset the GPU&#8217;s permanent ECC error count. Value of </i><code>1</code> resets, value of <code>0</code> does not. </p>
<p> The argument, <i> specifies whether or not to reset the GPU&#8217;s volatile ECC error count. Value of </i><code>1</code> resets, value of <code>0</code> does not. </p>
<p> This call requires PBS Operator or Manager privilege. It also requires that Torque be configured with &#8211;enable-nvidia-gpu.</p>
<h2>See Also</h2>
<p><a href="//www.systutorials.com/docs/linux/man/1B-qgpureset/">qgpureset</a>(1B)</p>
<h2>Diagnostics</h2>
<p>When the batch request generated by the <code>pbs_ gpureset</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
