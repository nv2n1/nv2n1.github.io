<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_statque</code>() function has been completed successfully by a batch server, the routine will return a pointer to the batch_status structure. Otherwise, a null pointer is returned and the error code is set in the global integer pbs_errno.</p>
