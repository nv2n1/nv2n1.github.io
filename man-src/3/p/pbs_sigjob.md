<p>pbs_sigjob &#8211; send a signal to a pbs batch job</p>

<h2>Description</h2>
<p>Issue a batch request to send a signal to a batch job. </p>
<p> A <i>Signal Job</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). If the batch job is in the <code>running</code> state, the batch server will send the job the signal number corresponding to the signal named in <i> When the asynchronous </i><code>pbs_sigjobasync</code>() call is used, the server will reply before passing the signal request to the pbs_mom. </p>
<p> The argument, <i> identifies which job is to be signaled, it is specified in the form: </i><code> </p>
<p> If the name of the signal is not a recognized signal name on the execution host, no signal is sent and an error is returned. If the job is not in the running</code> state, no signal is sent and an error is returned. </p>
<p> The parameter, <i> is reserved for implementation defined extensions. </i></p>

<h2>Diagnostics</h2>
<p>When the batch request generated by the <code>pbs_sigjob</code>() or <code>pbs_sigjobasync</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
