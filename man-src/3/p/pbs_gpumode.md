<p>pbs_gpumode &#8211; change GPU mode</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

#include &lt;pbs_ifl.h&gt;</code></pre>
<pre>int pbs_gpumode(int connect, char&nbsp;<wbr>*mom_node, int gpu_id, int gpu_mode)</pre>
<h2>Description</h2>
<p>Issue a batch request for the pbs_mom to change the mode on one of it&#8217;s Nvidia GPUs. The GPU&#8217;s mode is changed by sending a <i>GPU Control</i> batch request to the batch server. This call requires PBS Operator or Manager privilege. It also requires that Torque be configured with &#8211;enable-nvidia-gpu. The argument, <i> specifies the host within the cluster on which the GPU is located. The argument is the name of a host that is a member of the cluster of hosts managed by the server. The argument, specifies ID of the GPU on the MOM node. The argument, specifies new mode of the GPU. Valid Nvidia GPU modes are:</p>
<dl>
<dd>
<dl>
<dt>0</p>
<dd>&#8211; Normal mode.</p>
<dt>1</p>
<dd>&#8211; COMPUTE exclusive thread mode (only one COMPUTE thread is allowed to run on the GPU).</p>
<dt>2</p>
<dd>&#8211; COMPUTE prohibited mode (no COMPUTE contexts are allowed to run on the GPU).</p>
<dt>3</p>
<dd>&#8211; COMPUTE exclusive process mode (only one COMPUTE process is allowed to run on the GPU). This mode is new with Nvidia driver version 270.</dl>
<h2>See Also</h2>
<p><a href="//www.systutorials.com/docs/linux/man/1B-qgpumode/">qgpumode</a>(1B)</p>
<h2>Diagnostics</h2>
<p>When the batch request generated by the <code>pbs_gpumode</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
