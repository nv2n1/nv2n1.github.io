<p>pbs_statserver &#8211; obtain status of a pbs batch server</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

#include &lt;pbs_ifl.h&gt;</code></pre>

char/ *extend)

</code></pre>
<h2>Description</h2>
<p>Issue a batch request to obtain the status of a batch server. A <i>Status Server</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). The parameter, <i> is a pointer to an attrl </i> structure which is defined in pbs_ifl.h as:  The <i> </i> list is terminated by the first entry where <code> is a null pointer. If </code><i> is given, then only the attributes in the list are returned by the server. Otherwise, all the attributes of the server are returned. When an list is specified, the </i><code> member is a pointer to a attribute name as listed in <a href="/docs/linux/man/3-pbs_alter/">pbs_alter</a>(3) and <a href="/docs/linux/man/3-pbs_submit/">pbs_submit</a>(3). The member is only used if the name member is ATTR_l, otherwise it should be a pointer to a null string. The member should aways be a pointer to a null string. The parameter, </code><i> is reserved for implementation defined extensions. The return value is a pointer to a list of batch_status structures, which is defined in pbs_ifl.h as:  It is up the user to free the space when no longer needed, by calling <code>pbs_statfree</code>(). </p>

<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_statserver</code>() function has been completed successfully by a batch server, the routine will return a pointer to a batch_status structure. Otherwise, a null pointer is returned and the error code is set in pbs_errno.</p>
