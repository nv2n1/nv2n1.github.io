<p>POLYTYPE_FLAT &#8211; Polygon rendering mode type Allegro game programming library.</p>
<h2>Synopsis</h2>
<p><code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>#define POLYTYPE_FLAT</code></p>
<h2>Description</h2>
<p>A simple flat shaded polygon, taking the color from the `c&#8217; value of the first vertex. This polygon type is affected by the drawing_mode() function, so it can be used to render XOR or translucent polygons. </p>
