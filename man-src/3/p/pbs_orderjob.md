<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_orderjob</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
