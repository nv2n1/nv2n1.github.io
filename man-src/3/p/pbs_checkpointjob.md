<p>pbs_checkpointjob &#8211; checkpoint a pbs batch job</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

<h2>Description</h2>
<p>Issue a batch request to checkpoint a batch job. </p>
<p> For <i>pbs_checkpointjob()</i> a &quot;Checkpoint Job&quot; batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). The server will reply when the job has completed the checkpoint operation. Checkpointing is only allowed for jobs that are marked as checkpointable. </p>
<p> These requests requires that the issuing user have operator or administrator privilege. </p>

<p> The argument, </code><i> is reserved for implementation defined extensions. </i></p>

<h2>Diagnostics</h2>
<p>When the batch request generated by the <code>pbs_checkpointjob</code>() functions has been completed successfully by a batch server, the routines will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
