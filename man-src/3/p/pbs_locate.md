<p>pbs_locjob &#8211; locate current location of a pbs batch job</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

<h2>Description</h2>
<p>Issue a batch request to locate a batch job. If the server currently manages the batch job, or knows which server does currently manage the job, it will reply with the location of the job. </p>
<p> A <i>Locate Job</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). </p>
<p> The argument, <i> identifies which job is to be located, it is specified in the form: </i><code> </p>
<p> The argument, </code><i> is reserved for implementation defined extensions. It is not currently used by this function. </p>
<p> The return value is a pointer to a character sting which contains the current location if known. The syntax of the location string is: </i><code> If the location of the job is not known, the return value is the NULL pointer. </code></p>

<h2>Diagnostics</h2>
<p>When the batch request generated by the <code>pbs_locjob</code>() function has been completed successfully by a batch server, the routine will return a non null pointer to the destination. Otherwise, a null pointer is returned. The error number is set in pbs_errno.</p>
