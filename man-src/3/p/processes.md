<h2>Detailed Description</h2>
<p>The classes <code>QuantLib::StochasticProcess</code> and <code>QuantLib::StochasticProcess1D</code> provide the interface for a generic stochastic process. A number of specific processes is contained in the ql/Processes directory.</p>
