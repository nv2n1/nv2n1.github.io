<p>pr29_4z &#8211; API function</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pr29.h&gt;
int pr29_4z(const uint32_t *in);</code></pre>
<h2>Arguments</h2>
<dl>
<dt>const uint32_t * in</p>
<dd>zero terminated array of Unicode code points.</dl>
<h2>Description</h2>
<p>Check the input to see if it may be normalized into different strings by different NFKC implementations, due to an anomaly in the NFKC specifications.</p>
<h2>Return Value</h2>
<p>Returns the <code>Pr29_rc</code> value <code>PR29_SUCCESS</code> on success, and <code>PR29_PROBLEM</code> if the input sequence is a &quot;problem sequence&quot; (i.e., may be normalized into different strings by different implementations).</p>
