<p>pbs_msgjob &#8211; record a message for a running pbs batch job</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

</code></pre>
<h2>Description</h2>
<p>Issue a batch request to write a message in an output file of a batch job. </p>
<p> A <i>Message Job</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). </p>
<p> The argument, <i> identifies the job to which the message is to be sent; it is specified in the form: </i><code> </p>
<p> The parameter, </code><i> indicates the file or files to which the message string is to be written. The following values are defined in pbs_ifl.h:</p>
<dl>
<dd>
<dl>
<dt>#define MSG_ERR 2</p>
<dd>directs the message to the standard error stream of the job.</p>
<dt>#define MSG_OUT 1</p>
<dd>directs the message to the standard output stream of the job.</dl>
</dl>
<p> The parameter, is the message string to be written. </p>
<p> The parameter, is reserved for implementation defined extensions. </i></p>

<p><a href="//www.systutorials.com/docs/linux/man/1B-qmsg/">qmsg</a>(1B) and <a href="//www.systutorials.com/docs/linux/man/3B-pbs_connect/">pbs_connect</a>(3B)</p>
<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_msgjob</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
