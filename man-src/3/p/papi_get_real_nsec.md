<p>PAPI_get_real_nsec &#8211; </p>
<p> Get real time counter value in nanoseconds.</p>
<h2>Synopsis</h2>
<h2>Detailed Description</h2>
<p>This function returns the total real time passed since some arbitrary starting point. The time is returned in nanoseconds. This call is equivalent to wall clock time. </p>
