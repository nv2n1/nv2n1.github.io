<h2>Description</h2>
<p>Issue a batch request to obtain the status of a specified batch job or a set of jobs at a destination. A <i>Status Job</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). The parameter, <i> may be either a job identifier or a destination identifier. If is a job identifier, it is the identifier of the job for which status is requested. It is specified in the form: </i><code> If </code><i> is a destination identifier, it specifies that status of all jobs at the destination (queue) which the user is authorized to see be returned. If is the null pointer or a null string, the status of each job at the server which the user is authorized to see is returned. The parameter, is a pointer to an attrl </i> structure which is defined in pbs_ifl.h as:  The <i> </i> list is terminated by the first entry where <code> is a null pointer. If </code><i> is given, then only the attributes in the list are returned by the server. Otherwise, all the attributes of a job are returned. When an list is specified, the </i><code> member is a pointer to a attribute name as listed in <a href="/docs/linux/man/3-pbs_alter/">pbs_alter</a>(3) and <a href="/docs/linux/man/3-pbs_submit/">pbs_submit</a>(3). The member is only used if the name member is ATTR_l, otherwise it should be a pointer to a null string. The member should aways be a pointer to a null string. The parameter, </code><i> is reserved for implementation defined extensions. TORQUE 2.0.0p1 added the #define&#8217;d constant string EXECQUEONLY to only retrieve jobs in execution queues. The return value is a pointer to a list of batch_status</i> structures or the null pointer if no jobs can be queried for status. <h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_statjob</code>() function has been completed successfully and the status of each job has been returned by the batch server, the routine will return a pointer to the list of batch_status structures. If no jobs were available to query or an error occurred, a null pointer is returned. The global integer pbs_errno should be examined to determine the cause.</p>
