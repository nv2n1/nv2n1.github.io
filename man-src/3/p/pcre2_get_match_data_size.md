<p>PCRE2 &#8211; Perl-compatible regular expressions (revised API)</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pcre2.h&gt;</code></pre>
<pre><code>PCRE2_SIZE pcre2_get_match_data_size(pcre2_match_data *</code><i>match_data</i>);</pre>
<h2>Description</h2>
<p>This function returns the size, in bytes, of the match data block that is its argument. There is a complete description of the PCRE2 native API in the <code>pcre2api</code> page and a description of the POSIX API in the <code>pcre2posix</code> page. </p>
