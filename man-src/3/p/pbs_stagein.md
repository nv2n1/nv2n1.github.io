<p>pbs_stagein &#8211; request that files for a pbs batch job be staged in.</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

<h2>Description</h2>
<p>Issue a batch request to start the stage in of files specified in the stagein attribute of a batch job. </p>
<p> A <i>stage in</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). </p>
<p> This request directs the server to begin the stage in of files specified in the job&#8217;s stage in attribute. This request requires that the issuing user have operator or administrator privilege. </p>
<p> The argument, <i> identifies which job for which file staging is to begin. It is specified in the form: </i><code> </p>
<p> The argument, </code><i> if not the null pointer or null string, specifies the location where the job will be run and hence to where the files will be staged. The location is the name of a host in the the cluster managed by the server. If the job is then directed to run at different location, the run request will be rejected. </p>
<p> The argument, is reserved for implementation defined extensions. </i></p>

<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_stagein</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
