<p>page_cert &#8211; The basic certificate The basic hx509 cerificate object in hx509 is hx509_cert. The hx509_cert object is representing one X509/PKIX certificate and associated attributes; like private key, friendly name, etc. A hx509_cert object is usully found via the keyset interfaces (<code>Certificate store operations</code>), but its also possible to create a certificate directly from a parsed object with <code>hx509_cert_init()</code> and <code>hx509_cert_init_data()</code>. See the library functions here: <code>hx509 certificate functions</code> </p>
