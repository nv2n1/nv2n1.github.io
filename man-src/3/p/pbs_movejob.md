<p>pbs_movejob &#8211; move a pbs batch job to a new destination</p>

<h2>Description</h2>
<p>Issue a batch request to move a job to a new destination. The job is removed from the present queue and instantiated in a new queue. </p>
<p> A <i>Move Job</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). </p>
<p> The <i> parameter identifies which job is to be moved; it is specified in the form: </i><code> </p>
<p> The </code><i> parameter specifies the new destination for the job. It is specified as: </i><code> If </code><i> is a null pointer or a null string, the destination will be the default queue at the current server. If specifies a queue but not a server, the destination will be the named queue at the current server. If specifies a server but not a queue, the destination will be the default queue at the named server. If specifies both a queue and a server, the destination is that queue at that server. </p>
<p> A job in the </i><code>Running ,</code> <code>Transiting ,</code> or <code>Exiting</code> state cannot be moved. </p>
<p> The parameter, <i> is reserved for implementation defined extensions. </i></p>

<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_movejob</code>() function has been completed successfully by a batch server, the routine will return 0 (zero). Otherwise, a non zero error is returned. The error number is also set in pbs_errno.</p>
