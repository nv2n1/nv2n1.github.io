<p>pbs_statnode &#8211; obtain status of pbs nodes</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pbs_error.h&gt;

#include &lt;pbs_ifl.h&gt;</code></pre>
<p> <code> struct batch_status *pbs_statnode(int connect, char&nbsp;<wbr>*id, struct attrl&nbsp;<wbr>*attrib, char&nbsp;<wbr>*extend) void pbs_statfree(struct batch_status *psj) </code></p>
<h2>Description</h2>
<p>Issue a batch request to obtain the status of a PBS node or nodes. A <i>Status Node</i> batch request is generated and sent to the server over the connection specified by <i> which is the return value of </i><code>pbs_connect</code>(). The <i> is the name of a node or the null string. If specifies a node name, the status of that node will be returned. If the is a null string (or null pointer), the status of all nodes at the server will be returned. In TORQUE 2.1.0, if the starts with a &quot;:&quot; and followed by a node property, all nodes with that property are returned; creating a &quot;node group&quot; functionality. The string &quot;:ALL&quot; is specially handled and is the same as passing a null string. The parameter, is a pointer to an attrl </i> structure which is defined in pbs_ifl.h as:  The <i> </i> list is terminated by the first entry where <code> is a null pointer. If </code><i> is given, then only the attributes in the list are returned by the server. Otherwise, all the attributes of a node are returned. When an list is specified, the </i><code> member is a pointer to a attribute name. The supported attribute names relating to nodes are &quot;state&quot;, &quot;properties&quot;, &quot;np&quot;, &quot;ntype&quot;, &quot;jobs&quot;, &quot;status&quot;, and &quot;note&quot;. The member is not used and must be a pointer to a null string. The member should aways be a pointer to a null string. The parameter, </code><i> is reserved for implementation defined extensions. The return value is a pointer to a list of batch_status</i> structures, which is defined in pbs_ifl.h as:  It is up the user to free the structure when no longer needed, by calling <code>pbs_statfree</code>(). </p>

<h2>Diagnostics</h2>
<p>When the batch request generated by <code>pbs_statnode</code>() function has been completed successfully by a batch server, the routine will return a pointer to the batch_status structure. Otherwise, a null pointer is returned and the error code is set in the global integer pbs_errno.</p>
