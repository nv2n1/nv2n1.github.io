<p>POLYTYPE_ATEX_MASK_LIT, POLYTYPE_PTEX_MASK_LIT &#8211; Polygon rendering mode type Allegro game programming library.</p>
<h2>Synopsis</h2>
<p><code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>#define POLYTYPE_ATEX_MASK_LIT</code> </p>
<p> <code>#define POLYTYPE_PTEX_MASK_LIT</code></p>
<h2>Description</h2>
<p>Like POLYTYPE_ATEX_LIT and POLYTYPE_PTEX_LIT, but zero texture map pixels are skipped, allowing parts of the texture map to be transparent. </p>
