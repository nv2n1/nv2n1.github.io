<p>PCRE &#8211; Perl-compatible regular expressions</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;pcre.h&gt;
void pcre_free_study(pcre_extra *extra);
void pcre16_free_study(pcre16_extra *extra);
void pcre32_free_study(pcre32_extra *extra);</code></pre>
<h2>Description</h2>
<p>This function is used to free the memory used for the data generated by a call to <code>pcre[16|32]_study()</code> when it is no longer needed. The argument must be the result of such a call. There is a complete description of the PCRE native API in the <code>pcreapi</code> page and a description of the POSIX API in the <code>pcreposix</code> page. </p>
