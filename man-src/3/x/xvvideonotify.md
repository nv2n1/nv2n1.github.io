<p>XvVideoNotify &#8211; event generated for video processing</p>
<h2>Synopsis</h2>
<p><code>#include &lt;X11/extensions/Xvlib.h&gt;</code> </p>
<p>&nbsp;<wbr>&nbsp;<wbr>typedef union&nbsp;<wbr>{<br />
&nbsp;<wbr>int type;<br />
&nbsp;<wbr>XvVideoNotifyEvent xvvideo;<br />
&nbsp;<wbr>XvPortNotifyEvent xvport;<br />
&nbsp;<wbr>long pad[24];<br />
&nbsp;<wbr>&nbsp;<wbr>}&nbsp;<wbr>XvEvent; </p>
<p>&nbsp;<wbr>&nbsp;<wbr>typedef struct&nbsp;<wbr>{<br />
&nbsp;<wbr>int type;<br />
&nbsp;<wbr>unsigned long serial;<br />
&nbsp;<wbr>Bool send_event;<br />
&nbsp;<wbr>Display&nbsp;<wbr>*display;<br />
&nbsp;<wbr>Drawable drawable;<br />
&nbsp;<wbr>unsigned long reason;<br />
&nbsp;<wbr>XvPortID port_id;<br />
&nbsp;<wbr>Time time;<br />
&nbsp;<wbr>&nbsp;<wbr>}&nbsp;<wbr>XvVideoNotifyEvent; </p>
<dl COMPACT>
<dt><i>type</i></p>
<dd>Specifies the type of event: <code>XvVideoNotify</code>.</p>
<dt><i>serial</i></p>
<dd>Number of the last request processed by the server.</p>
<dt><i>send_event</i></p>
<dd>True if the event was generated by a SendEvent request.</p>
<dt><i>display</i></p>
<dd>A pointer to the display the event was read from.</p>
<dt><i>drawable</i></p>
<dd>The drawable for which the event was generated.</p>
<dt><i>reason</i></p>
<dd>The reason the event was generated: <code>XvStarted</code>, <code>XvStopped</code>, <code>XvPreempted</code>, <code>XvBusy</code>, <code>XvHardError</code>.</p>
<dt><i>port_id</i></p>
<dd>The port processing the video for which the event was generated.</dl>
<h2>Description</h2>
<p><code>XvVideoNotify</code> events are generated when video is started, stopped, preempted by another video request, ignored because the port is grabbed by another client, or interrupted because of a hard transmission or reception error.</p>
