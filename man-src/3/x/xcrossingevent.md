<p>XCrossingEvent &#8211; EnterNotify and LeaveNotify event structure </p>
<h2>Structures</h2>

<p> When you receive these events, the structure members are set as follows. </p>
<p> The type member is set to the event type constant name that uniquely identifies it. For example, when the X server reports a <code>GraphicsExpose</code> event to a client application, it sends an <code>XGraphicsExposeEvent</code> structure with the type member set to <code>GraphicsExpose</code>. The display member is set to a pointer to the display the event was read on. The send_event member is set to <code>True</code> if the event came from a <code>SendEvent</code> protocol request. The serial member is set from the serial number reported in the protocol but expanded from the 16-bit least-significant bits to a full 32-bit value. The window member is set to the window that is most useful to toolkit dispatchers. </p>
<p> The window member is set to the window on which the <code>EnterNotify</code> or <code>LeaveNotify</code> event was generated and is referred to as the event window. This is the window used by the X server to report the event, and is relative to the root window on which the event occurred. The root member is set to the root window of the screen on which the event occurred. </p>
<p> For a <code>LeaveNotify</code> event, if a child of the event window contains the initial position of the pointer, the subwindow component is set to that child. Otherwise, the X server sets the subwindow member to <code>None</code>. For an <code>EnterNotify</code> event, if a child of the event window contains the final pointer position, the subwindow component is set to that child or <code>None</code>. </p>
<p> The time member is set to the time when the event was generated and is expressed in milliseconds. The x and y members are set to the coordinates of the pointer position in the event window. This position is always the pointer&#8217;s final position, not its initial position. If the event window is on the same screen as the root window, x and y are the pointer coordinates relative to the event window&#8217;s origin. Otherwise, x and y are set to zero. The x_root and y_root members are set to the pointer&#8217;s coordinates relative to the root window&#8217;s origin at the time of the event. </p>
<p> The same_screen member is set to indicate whether the event window is on the same screen as the root window and can be either <code>True</code> or <code>False</code>. If <code>True</code>, the event and root windows are on the same screen. If <code>False</code>, the event and root windows are not on the same screen. </p>
<p> The focus member is set to indicate whether the event window is the focus window or an inferior of the focus window. The X server can set this member to either <code>True</code> or <code>False</code>. If <code>True</code>, the event window is the focus window or an inferior of the focus window. If <code>False</code>, the event window is not the focus window or an inferior of the focus window. </p>
<p> The state member is set to indicate the state of the pointer buttons and modifier keys just prior to the event. The X server can set this member to the bitwise inclusive OR of one or more of the button or modifier key masks: <code>Button1Mask</code>, <code>Button2Mask</code>, <code>Button3Mask</code>, <code>Button4Mask</code>, <code>Button5Mask</code>, <code>ShiftMask</code>, <code>LockMask</code>, <code>ControlMask</code>, <code>Mod1Mask</code>, <code>Mod2Mask</code>, <code>Mod3Mask</code>, <code>Mod4Mask</code>, <code>Mod5Mask</code>. </p>
<p> The mode member is set to indicate whether the events are normal events, pseudo-motion events when a grab activates, or pseudo-motion events when a grab deactivates. The X server can set this member to <code>NotifyNormal</code>, <code>NotifyGrab</code>, or <code>NotifyUngrab</code>. </p>
<p> The detail member is set to indicate the notify detail and can be <code>NotifyAncestor</code>, <code>NotifyVirtual</code>, <code>NotifyInferior</code>, <code>NotifyNonlinear</code>, or <code>NotifyNonlinearVirtual</code>.</p>
