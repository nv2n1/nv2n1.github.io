<p><code>XmRenditionUpdate</code> &#8212; A convenience function that modifies resources</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>void XmRenditionUpdate</code>(
<code>XmRendition rendition</code>,
<code>ArgList arglist</code>,
<code>Cardinal argcount</code>);</pre>
<h2>Description</h2>
<p><code>XmRenditionUpdate</code> modifies resources in the specified rendition.</p>
<dl COMPACT>
<dt><i>rendition</i></p>
<dd>Specifies the rendition.</p>
<dt><i>arglist</i></p>
<dd>Specifies the argument list.</p>
<dt><i>argcount</i></p>
<dd>Specifies the number of attribute/value pairs in the argument list (<i>arglist</i>).</dl>
