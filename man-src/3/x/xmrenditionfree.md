<p><code>XmRenditionFree</code> &#8212; A convenience function that frees a rendition</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>void XmRenditionFree</code>(
<code>XmRendition rendition</code>);</pre>
<h2>Description</h2>
<p><code>XmRenditionFree</code> recovers memory used by <i>rendition</i>.</p>
<dl COMPACT>
<dt><i>rendition</i></p>
<dd>Specifies the rendition to be freed.</dl>
