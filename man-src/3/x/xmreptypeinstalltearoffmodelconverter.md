<p><code>XmRepTypeInstallTearOffModelConverter</code> &#8212; A representation type manager function that installs the resource converter for XmNtearOffModel.</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/RepType.h&gt;
<code>void XmRepTypeInstallTearOffModelConverter</code>(<code>void</code>)</pre>
<h2>Description</h2>
<p><code>XmRepTypeInstallTearOffModelConverter</code> installs the resource converter that allows values for the <code>XmNtearOffModel</code> resource to be specified in resource default files.</p>
