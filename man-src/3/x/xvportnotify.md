<p>XvPortNotify &#8211; event generated when port attributes change</p>
<h2>Synopsis</h2>
<p><code>#include &lt;X11/extensions/Xvlib.h&gt;</code> </p>
<p>&nbsp;<wbr>&nbsp;<wbr>typedef union&nbsp;<wbr>{<br />
&nbsp;<wbr>int type;<br />
&nbsp;<wbr>XvVideoNotifyEvent xvvideo;<br />
&nbsp;<wbr>XvPortNotifyEvent xvport;<br />
&nbsp;<wbr>long pad[24];<br />
&nbsp;<wbr>&nbsp;<wbr>}&nbsp;<wbr>XvEvent; </p>
<p>&nbsp;<wbr>&nbsp;<wbr>typedef struct&nbsp;<wbr>{<br />
&nbsp;<wbr>int type;<br />
&nbsp;<wbr>unsigned long serial;<br />
&nbsp;<wbr>Bool send_event;<br />
&nbsp;<wbr>Display&nbsp;<wbr>*display;<br />
&nbsp;<wbr>XvPortID port_id;<br />
&nbsp;<wbr>Time time;<br />
&nbsp;<wbr>Atom attribute;<br />
&nbsp;<wbr>long value;<br />
&nbsp;<wbr>&nbsp;<wbr>}&nbsp;<wbr>XvPortNotifyEvent; </p>
<dl COMPACT>
<dt><i>type</i></p>
<dd>Specifies the type of event: XvPortNotify.</p>
<dt><i>serial</i></p>
<dd>Number of the last request processed by the server.</p>
<dt><i>send_event</i></p>
<dd>True if the event was generated by a SendEvent request.</p>
<dt><i>display</i></p>
<dd>A pointer to the display the event was read from.</p>
<dt><i>port_id</i></p>
<dd>The port whose attribute has changed.</p>
<dt><i>attribute</i></p>
<dd>An atom specifying the attribute that changed.</p>
<dt><i>value</i></p>
<dd>The new value of the attribute.</dl>
<h2>Description</h2>
<p>XvPortNotify events are generated when a port attribute is set using the <code><a href="/docs/linux/man/3-xvsetportattribute/">XvSetPortAttribute</a></code>(3) function.</p>
