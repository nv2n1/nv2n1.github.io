<p><code>XmListDeleteAllItems</code> &#8212; A List function that deletes all items from the list</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/List.h&gt;
<code>void XmListDeleteAllItems</code>(
<code>Widget widget</code>);</pre>
<h2>Description</h2>
<p><code>XmListDeleteAllItems</code> deletes all items from the list.</p>
<dl COMPACT>
<dt><i>widget</i></p>
<dd>Specifies the ID of the List from whose list the items are deleted</dl>
