<p><code>XmTabFree</code> &#8212; A convenience function that frees a tab</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>void XmTabFree</code>(
<code>XmTab tab</code>);</pre>
<h2>Description</h2>
<p><code>XmTabFree</code> frees the memory associated with the specified tab.</p>
<dl COMPACT>
<dt><i>tab</i></p>
<dd>Specifies the tab to be freed.</dl>
