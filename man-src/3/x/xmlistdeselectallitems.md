<p><code>XmListDeselectAllItems</code> &#8212; A List function that unhighlights and removes all items from the selected list</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/List.h&gt;
<code>void XmListDeselectAllItems</code>(
<code>Widget widget</code>);</pre>
<h2>Description</h2>
<p><code>XmListDeselectAllItems</code> unhighlights and removes all items from the selected list.</p>
<dl COMPACT>
<dt><i>widget</i></p>
<dd>Specifies the ID of the List widget from whose list all selected items are deselected</dl>
<p> For a complete definition of List and its associated resources, see <code><a href="/docs/linux/man/3-xmlist/">XmList</a></code>(3).</p>
