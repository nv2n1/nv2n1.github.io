<p>XcmsCCCOfColormap, XcmsSetCCCOfColormap &#8211; query and modify CCC of a colormap </p>
<h2>Syntax</h2>
<dl COMPACT>
<dd>XcmsCCC XcmsCCCOfColormap(Display *<i>display</i>, Colormap <i>colormap</i>);</p>
<dd>XcmsCCC XcmsSetCCCOfColormap(Display *<i>display</i>, Colormap <i>colormap</i>, XcmsCCC <i>ccc</i>);</dl>
<h2>Arguments</h2>
<dl COMPACT>
<dt><i>display</i></p>
<dd>Specifies the connection to the X server.</p>
<dt><i>ccc</i></p>
<dd>Specifies the CCC.</p>
<dt><i>colormap</i></p>
<dd>Specifies the colormap.</dl>
<h2>Description</h2>
<p>The <code>XcmsCCCOfColormap</code> function returns the CCC associated with the specified colormap. Once obtained, the CCC attributes can be queried or modified. Unless the CCC associated with the specified colormap is changed with <code>XcmsSetCCCOfColormap</code>, this CCC is used when the specified colormap is used as an argument to color functions. </p>
<p> The <code>XcmsSetCCCOfColormap</code> function changes the CCC associated with the specified colormap. It returns the CCC previously associated with the colormap. If they are not used again in the application, CCCs should be freed by calling <code>XcmsFreeCCC</code>. Several colormaps may share the same CCC without restriction; this includes the CCCs generated by Xlib with each colormap. Xlib, however, creates a new CCC with each new colormap.</p>
