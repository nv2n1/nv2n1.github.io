<p><code>XmTabListTabCount</code> &#8212; A convenience function that counts the number of tabs</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>Cardinal XmTabListTabCount</code>(
<code>XmTabList tablist</code>);</pre>
<h2>Description</h2>
<p><code>XmTabListTabCount</code> counts the number of tabs in the specified <i>tablist</i>.</p>
<dl COMPACT>
<dt><i>tablist</i></p>
<dd>Specifies the tab list.</dl>
<h2>Return</h2>
<p>Returns the number of tabs in <i>tablist</i>.</p>
