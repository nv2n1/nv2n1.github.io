<p><code>XmTabStackGetSelectedTab</code> &#8212; A TabStack function that returns the widget ID of the currently selectedtab</p>

<pre>#include &lt;Xm/TabStack.h&gt;
<code>Widget XmTabStackGetSelectedTab</code>(
<code>Widget widget</code>);</pre>
<h2>Description</h2>
<p><code>XmTabStackGetSelectedTab</code> returns the widget ID of the currently selected tab.</p>

<dt><i>widget</i></p>
<dd>Specifies the TabStack widget ID</dl>
