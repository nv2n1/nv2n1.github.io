<p><code>XmRenderTableFree</code> &#8212; A render table function that recovers memory</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>void XmRenderTableFree</code>(
<code>XmRenderTable table</code>);</pre>
<h2>Description</h2>
<p><code>XmRenderTableFree</code> frees the memory associated with the specified render <i>table</i>.</p>
<dl COMPACT>
<dt><i>table</i></p>
<dd>Specifies the table to be freed.</dl>
