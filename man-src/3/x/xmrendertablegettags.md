<p><code>XmRenderTableGetTags</code> &#8212; A convenience function that gets rendition tags</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
<code>int XmRenderTableGetTags</code>(
<code>XmRenderTable table</code>,
<code>XmStringTag **tag_list</code>);</pre>
<h2>Description</h2>
<p><code>XmRenderTableGetTags</code> searches the specified <i>table</i> for the <code>XmNtag</code> resources of all the renditions (<code>XmRendition</code>s) entries. These tag resources are then composed into an array.</p>
<dl COMPACT>
<dt><i>table</i></p>
<dd>Specifies the table containing the <code>XmRendition</code>s.</p>
<dt><i>tag_list</i></p>
<dd>Is the array of <code>XmStringTags</code> generated by this function. The function allocates space to hold the returned tags and to hold the <i>tag_list</i> itself. The application is responsible for managing this allocated space. This application can recover this allocated space by calling <code>XtFree</code> once for each of the returned tags, and then calling <code>XtFree</code> on the returned <i>tag_list</i> variable itself.</dl>
<h2>Return</h2>
<p>Returns the number of tags in <i>tag_list</i>.</p>
