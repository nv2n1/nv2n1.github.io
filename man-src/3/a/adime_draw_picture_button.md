<h2>NAME</h2>
<p> adime_draw_picture_button</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/adime.h">adime.h</a>&gt;</code> </p>
<p> <code>void adime_draw_picture_button(BITMAP *bmp, int x1, int y1, int x2, int y2,</code> <code>int face,int xlight, int light, int dark, int xdark,</code> <code>BITMAP *sprite)</code></p>
<h2>DESCRIPTION</h2>
