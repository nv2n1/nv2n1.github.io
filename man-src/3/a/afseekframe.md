<p>afSeekFrame, afTellFrame &#8211; update or access the current sample frame position for a track in an audio file </p>
<h2>Synopsis</h2>
<pre>#include &lt;audiofile.h&gt;</pre>
<pre>AFframecount afSeekFrame(AFfilehandle file, int track,
 AFframecount frameOffset);</pre>
<pre>AFframecount afTellFrame(AFfilehandle file, int track);</pre>
<h2>Parameters</h2>
<p><i>file</i> is a valid audio file handle created by <code><a href="/docs/linux/man/3-afopenfile/">afOpenFile</a></code>(3). </p>
<p> <i>track</i> identifies an audio track within the file. track is always AF_DEFAULT_TRACK for all currently supported audio file formats. </p>
<p> <i>frameOffset</i> is a sample frame offset. Valid sample frame offsets must be greater than or equal to zero and strictly less than the number of sample frames contained within the specified audio track. The special value -1 is also allowed.</p>
<h2>Description</h2>
<p>afSeekFrame moves the logical file position for a specified audio track to a desired sample frame location. If frameOffset is -1, afSeekFrame will not modify the current file offset and will instead return the current file position. </p>
<p> afTellFrame returns current file position in sample frames.</p>
<h2>Return Value</h2>
<p>On success, afSeekFrame and afTellFrame will return the current file position as measured in sample frames from the start of the audio track. On failure, afSeekFrame and afTellFrame will return the value -1.</p>
<h2>Errors</h2>
<p>The following errors can be generated by afSeekFrame or afTellFrame: </p>
<p> AF_BAD_FILEHANDLE</p>
<dl COMPACT>
<dd>file does not represent a valid file handle.</dl>
<p> AF_BAD_TRACK</p>
<dl COMPACT>
<dd>track does not identify a valid track.</dl>
<p> AF_BAD_LSEEK</p>
<dl COMPACT>
<dd>A call to lseek failed.</dl>
