<h2>NAME</h2>
<p> add_clip_rect &#8211; Intersects a bitmap&#8217;s clipping rectangle with the given area. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void add_clip_rect(BITMAP *bitmap, int x1, int y1, int x2, int y2);</code></p>
<h2>DESCRIPTION</h2>
<p> Sets the clipping rectangle of the specified bitmap as the intersection of its current clipping rectangle and the rectangle described by the four coordinates. </p>
