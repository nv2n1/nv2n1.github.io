<h2>NAME</h2>
<p> ax25_aton, ax25_aton_entry, ax25_aton_arglist, ax25_ntoa, ax25_cmp, ax25_validate &#8211; AX25 Address manipulation routines</p>
<h2>SYNOPSIS</h2>
<pre><code>
#include &lt;netax25/ax25.h&gt;
int ax25_aton(const char *cp, struct full_sockaddr_ax25 *fsap);
int ax25_aton_arglist(const char **cp, struct full_sockaddr_ax25 *fsap);
int ax25_aton_entry(const char *cp, char *axp);
char *ax25_ntoa(ax25_address *axp);
int ax25_cmp(ax25_address *ax1, ax25_address *ax2);
int ax25_validate(char *axp);
char *ax25_config_file(const char *filename);
</code></pre>
<h2>DESCRIPTION</h2>
<p> <code>ax25_aton()</code> takes the ASCII string <i>cpFP that is in the format callsign</i> [[<i>V</i>|<i>VIA</i>] <i>callsign</i> &#8230;] and stores it in <i>fsap</i> in network format. </p>
<p> <code>ax25_aton_entry()</code> takes the ASCII string of a callsign <i>cp</i> and stores it in network format in <i>axp</i>. </p>
<p> <code>ax25_aton_arglist()</code> takes a NULL terminated array of strings <i>cp</i> and stores it <i>fsap</i> in network format. </p>
<p> <code>ax25_ntoa()</code> takes a network format address <i>axp</i> and returns the ASCII representation. The string is returned in a statically allocated buffer, which subsequent calls will overwrite. </p>
<p> The <code>ax25_cmp()</code> function compares the two ax25 addresses, <i>ax1</i> and <i>ax2</i>, that are in network format and determines wether they are identical, differ only by their SSIDs or are different. </p>
<p> The <code>ax25_validate</code> function checks to see if the address <i>axp</i> in network format is a correctly formatted address.</p>
<h2>RETURN VALUE</h2>
<p> The <code>ax25_aton()</code> and <code>ax25_aton_arglist()</code> functions return -1 if an error occurs otherwise the length of the returned structure. </p>
<p> The <code>ax25_aton_entry()</code> function returns -1 if an error occurs otherwise zero. </p>
<p> The <code>ax25_cmp()</code> function returns 0 if the two addresses are identical, 1 if they are different or 2 is only the SSIDs are different. </p>
<p> The <code>ax25_validate</code> function returns TRUE if the callsign is valid or FALSE if it is not.</p>
