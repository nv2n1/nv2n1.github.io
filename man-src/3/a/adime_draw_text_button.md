<h2>NAME</h2>
<p> adime_draw_text_button</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/adime.h">adime.h</a>&gt;</code> </p>
<p> <code>void adime_draw_text_button(BITMAP *bmp, int x1, int y1, int x2, int y2,</code> <code>int face_color, int text_color,</code> <code>int xlight, int light, int dark, int xdark,</code> <code>const FONT *f, const char *text)</code></p>
<h2>DESCRIPTION</h2>
<p> Draws a button with a text on it, at the given position of the bitmap and using the given colors and font. </p>
