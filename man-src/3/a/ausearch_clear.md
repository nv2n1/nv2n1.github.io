<h2>NAME</h2>
<p> ausearch_clear &#8211; clear search parameters</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;auparse.h&gt;</code> </p>
<p> void ausearch_clear(auparse_state_t *au); </p>
<h2>DESCRIPTION</h2>
<p> ausearch_clear clears any search parameters stored in the parser instance and frees memory associated with it. </p>
<h2>RETURN VALUE</h2>
<p> None. </p>
