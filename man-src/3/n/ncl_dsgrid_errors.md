dsgrid_errors - This document briefly describes all the errors reported from Dsgrid. 

<h2>Description</h2>Each entry below includes the error number and its meaning.
<dl COMPACT><dt> 1
<dd>Error number out of range.
<dt> 2
<dd>Insufficient data in gridded region to triangulate.
<dt> 3
<dd>Array dimension out of range.
<dt> 4
<dd>Parameter name not known.
<dt> 5
<dd>Cannot open error file.
<dt> 6
<dd>Error allocating memory for input points.
<dt> 7
<dd>Fortran DOUBLE PRECISION entries are not supported on UNICOS.
<dt> 9
<dd>Error allocating memory for array of distances between input points.
<dt>10
<dd>Error allocating memory for weights.
<dt>11
<dd>Error allocating memory for distance ordering vector.
<dt>12
<dd>Error allocating memory for output array.
<dt>13
<dd>Number of input points must be greater than 2.
<dt>14
<dd>No original data values within the specified distance - interpolated value set to missing value flag.</dl><h2>See Also</h2>dsgrid, dsgrid_params, dsgrid2s, dsgrid3s, dsgrid2d, dsgrid3d, dspnt2s, dspnt2d, dspnt3s, dspnt3d
