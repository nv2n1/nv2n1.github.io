<p><code>npm-bin</code> &#8212; Display npm bin folder</p>
<h2>Synopsis</h2>
<pre>npm.commands.bin(args, cb)</pre>
<h2>Description</h2>
<p>Print the folder where npm will install executables. This function should not be used programmatically. Instead, just refer to the <code>npm.bin</code> member. </p>
