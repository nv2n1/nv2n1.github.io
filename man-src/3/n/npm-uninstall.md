<p><code>npm-uninstall</code> &#8212; uninstall a package programmatically</p>
<h2>Synopsis</h2>
<pre>npm.commands.uninstall(packages, callback)</pre>
<h2>Description</h2>
<p>This acts much the same ways as uninstalling on the command-line. The &#8216;packages&#8217; parameter is an array of strings. Each element in the array is the name of a package to be uninstalled. Finally, &#8216;callback&#8217; is a function that will be called when all packages have been uninstalled or when an error has been encountered. </p>
