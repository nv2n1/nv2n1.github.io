csagrid_errors - This document briefly describes all the errors reported from Csagrid. 

<h2>Description</h2>Each entry below includes the error number and its meaning.
<dl COMPACT><dt> 33
<dd>Internal error in matrix computation, contact a consultant.
<dt> 34
<dd>Failure in matrix computation, usually indicates insufficient number of input data.
<dt> 35
<dd>Internal error in matrix computation, contact a consultant.
<dt>102
<dd>Number of knots is less than 4.
<dt>103
<dd>Input data range is zero.
<dt>104
<dd>Partial derivative order out of range zero to two.
<dt>105
<dd>Insufficient number of input data.
<dt>106
<dd>Insufficient work space (Fortran entry only).
<dt>107
<dd>Failure in matrix computation, usually indicates insufficient number of input data.
<dt>202
<dd>Number of knots is less than 4 in some coordinate direction.
<dt>203
<dd>Insufficient workspace.</dl><h2>See Also</h2>csagrid, csa1s, csa1xs, csa2s, csa2xs, csa2ls, csa2lxs, csa3s, csa3xs, csa3ls, csa3lxs, c_csa1s, c_csa1xs, c_csa2s, c_csa2xs, c_csa2ls, c_csa2lxs, c_csa3s, c_csa3xs, c_csa3ls, c_csa3lxs.
