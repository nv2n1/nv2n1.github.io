NNPNTEND - terminate interpolation in single point mode

<h2>Synopsis</h2>

CALL NNPNTEND ()

<h2>Usage</h2>

This subroutine terminates single point mode. It should be called after entering single point mode using NNPNTINITS and interpolating at individual points with NNPNTS.

<h2>Access</h2>

To use NNPNTEND, load the NCAR Graphics library ngmath.
