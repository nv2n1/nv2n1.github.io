<p><code>npm-root</code> &#8212; Display npm root</p>
<h2>Synopsis</h2>
<pre>npm.commands.root(args, callback)</pre>
<h2>Description</h2>
<p>Print the effective <code>node_modules</code> folder to standard out. &#8216;args&#8217; is never used and callback is never called with data. &#8216;args&#8217; must be present or things will break. This function is not useful programmatically. </p>
