c_nnpntendd - exit single point mode 

<h2>Function Prototype</h2>void c_nnpntendd();
<h2>Synopsis</h2>void c_nnpntendd();
<h2>Usage</h2>This function terminates single point mode. It should be called after entering single point mode using c_nnpntinitd and interpolating at individual points with c_nnpntd.
<h2>Access</h2>To use c_nnpntendd, load the NCAR Graphics library ngmath.
<h2>See Also</h2>natgrid, natgrid_params, c_natgridd, c_nnpntinitd, c_nnpntd.
