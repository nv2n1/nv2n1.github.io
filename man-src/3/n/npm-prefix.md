<p><code>npm-prefix</code> &#8212; Display prefix</p>
<h2>Synopsis</h2>
<pre>npm.commands.prefix(args, callback)</pre>
<h2>Description</h2>
<p>Print the prefix to standard out. &#8216;args&#8217; is never used and callback is never called with data. &#8216;args&#8217; must be present or things will break. This function is not useful programmatically </p>
