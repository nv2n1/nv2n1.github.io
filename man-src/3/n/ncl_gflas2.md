GFLAS2 - Terminates putting plotting instructions to disk and resumes putting plotting instructions to the the output stream. A call to GFLAS2 can only be made after a previous call to GFLAS1. 

<h2>Synopsis</h2>CALL GFLAS2
<h2>C-Binding Synopsis</h2>#include &lt;ncarg/ncargC.h&gt; 

 void c_gflas2()
<h2>Description</h2>None.
<h2>Examples</h2>Use the ncargex command to see the following relevant examples: ccpmovi, tgflas, fgke02.
<h2>Access</h2>To use GFLAS2 or c_gflas2, load the NCAR Graphics libraries ncarg, ncarg_gks, and ncarg_c, preferably in that order.
<h2>See Also</h2>Online: gflash, gflas1, gflas3, gflas4, ncarg_cbind.
