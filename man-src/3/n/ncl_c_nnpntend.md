c_nnpntend - exit single point mode 

<h2>Function Prototype</h2>void c_nnpntend();
<h2>Synopsis</h2>void c_nnpntend ();
<h2>Usage</h2>This function terminates single point mode.
<h2>Access</h2>To use c_nnpntend, load the NCAR Graphics library ngmath. It should be called after entering single point mode using c_nnpntinits and interpolating at individual points with c_nnpnts.
