<p><code>npm-update</code> &#8212; Update a package</p>
<h2>Synopsis</h2>
<pre>npm.commands.update(packages, callback)</pre>
<p>Updates a package, upgrading it to the latest version. It also installs any missing packages. The &#8216;packages&#8217; argument is an array of packages to update. The &#8216;callback&#8217; parameter will be called when done or when an error occurs. </p>
