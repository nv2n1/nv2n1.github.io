<p><code>npm-start</code> &#8212; Start a package</p>
<h2>Synopsis</h2>
<pre>npm.commands.start(packages, callback)</pre>
<h2>Description</h2>
<p>This runs a package&#8217;s &quot;start&quot; script, if one was provided. npm can run tests on multiple packages. Just specify multiple packages in the <code>packages</code> parameter. </p>
