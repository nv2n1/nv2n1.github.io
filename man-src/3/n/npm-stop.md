<p><code>npm-stop</code> &#8212; Stop a package</p>
<h2>Synopsis</h2>
<pre>npm.commands.stop(packages, callback)</pre>
<h2>Description</h2>
<p>This runs a package&#8217;s &quot;stop&quot; script, if one was provided. npm can run stop on multiple packages. Just specify multiple packages in the <code>packages</code> parameter. </p>
