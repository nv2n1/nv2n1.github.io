<p><code>npm-outdated</code> &#8212; Check for outdated packages</p>
<h2>Synopsis</h2>
<pre>npm.commands.outdated([packages,] callback)</pre>
<h2>Description</h2>
<p>This command will check the registry to see if the specified packages are currently outdated. If the &#8216;packages&#8217; parameter is left out, npm will check all packages. </p>
