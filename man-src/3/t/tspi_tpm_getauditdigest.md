<p>Tspi_TPM_GetAuditDigest &#8211; retrieve the audit digest.</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;tss/tspi.h&gt;</code>
<code>TSS_RESULT Tspi_TPM_GetAuditDigest(TSS_HTPM </code><i>hTpm</i><code>, TSS_HKEY </code><i>hKey</i><code>,</code>
<code> TSS_BOOL </code><i>closeAudit</i><code>, UINT32* </code><i>pulAuditDigestSize</i><code>,</code>
<code> BYTE** </code><i>prgbAuditDigest</i><code>, TPM_COUNTER_VALUE* </code><i>pCounterValue</i><code>,</code>
<code> TSS_VALIDATION* </code><i>pValidationData</i><code>, UINT32* </code><i>ordSize</i><code>,</code>
<code> UINT32** </code><i>ordList</i><code>);</code></pre>
<h2>Description</h2>
<p><code>Tspi_TPM_GetAuditDigest</code> is used to retrieve the audit digest. The audit digest may be signed or unsigned. If the audit digest is signed (hKey is non-NULL) then the current audit digest, the current audit counter and, optionally, the hash of the audited ordinal list and a signature are returned. If the audit digest is not signed (hKey is NULL) then the current audit digest, the current audit counter and the full list of audited ordinals is returned.</p>
<h2>Parameters</h2>
<h3>hTpm</h3>
<p>Handle of the TPM object. </p>
<h3>hKey</h3>
<p>Handle of the signature key object (the handle can be NULL). </p>
<h3>closeAudit</h3>
<p>A flag indicating whether or not to close the current audit digest after it is signed. This parameter is ignored if <i>hKey</i> is NULL. </p>
<h3>pulAuditDigestSize</h3>
<p>Pointer to the size of the returned audit digest. </p>
<h3>prgbAuditDigest</h3>
<p>Pointer to a buffer that holds the returned audit digest. </p>
<h3>pCounterValue</h3>
<p>Pointer to a TPM_COUNTER_VALUE structure that holds the returned audit counter. </p>
<h3>pValidationData</h3>
<p>Pointer to a validation data structure. The validation data structure provides external information required to compute the signature. On input, the fields representing the ExternalData must contain an anti-replay nonce that will be used in the signing operation. On output, this structure provides a buffer containing the data used to compute the validation data and a buffer containing the validation data (a signature generated by signing the data using the key referenced by <i>hKey</i>). If this parameter is NULL then the TSS will perform the validation. This parameter is ignored if <i>hKey</i> is NULL. </p>
<h3>ordSize</h3>
<p>Pointer to the number of ordinals in the returned audited ordinal list. This parameter is ignored if <i>hKey</i> is non-NULL. </p>
<h3>ordList</h3>
<p>Pointer to a buffer that holds the returned audited ordinal list. This parameter is ignored if <i>hKey</i> is non-NULL.</p>
<h2>Return Codes</h2>
<p><code>Tspi_TPM_GetAuditDigest</code> returns TSS_SUCCESS on success, otherwise one of the following values are returned:</p>
<dl COMPACT>
<dt><font SIZE="-1">TSS_E_INVALID_HANDLE</font></p>
<dd>
<dt><font SIZE="-1">TSS_E_BAD_PARAMETER</font></p>
<dd>
<dt><font SIZE="-1">TSS_E_INTERNAL_ERROR &#8211; An error occurred internal to the TSS.</font></p>
<dd></dl>
<h2>Conforming To</h2>
<p><code>Tspi_TPM_GetAuditDigest</code> conforms to the Trusted Computing Group Software Specification Version 1.2</p>
