<p><code>TopLevelShell</code> &#8212; The TopLevelShell widget class</p>
<h2>Synopsis</h2>
<pre>#include &lt;Xm/Xm.h&gt;
#include &lt;X11/Shell.h&gt;</pre>
<h2>Description</h2>
<p>TopLevelShell is used for normal top-level windows such as any additional top-level widgets an application needs.</p>
<h3>Classes</h3>
<p>TopLevelShell inherits behavior and resources from <code>Core</code>, <code>Composite</code>, <code>Shell</code>, <code>WMShell</code>, and <code>VendorShell</code>. </p>
<p> The class pointer is <code>topLevelShellWidgetClass</code>. </p>
<p> The class name is <code>TopLevelShell</code>.</p>
<h3>New Resources</h3>
<p>The following table defines a set of widget resources used by the programmer to specify data. The programmer can also set the resource values for the inherited classes to set attributes for this widget. To reference a resource by name or by class in a <code>.Xdefaults</code> file, remove the <code>XmN</code> or <code>XmC</code> prefix and use the remaining letters. To specify one of the defined values for a resource in a <code>.Xdefaults</code> file, remove the <code>Xm</code> prefix and use the remaining letters (in either lowercase or uppercase, but include any underscores between words). The codes in the access column indicate if the given resource can be set at creation time (C), set by using <code>XtSetValues</code> (S), retrieved by using <code>XtGetValues</code> (G), or is not applicable (N/A). </p>

<dl COMPACT>
<dt><code>XmNiconic</code></p>
<dd>If True when the widget is <i>created</i>, specifies that the widget should start as an icon when it is realized. A value of False indicates that the widget is not to be realized as an icon. This resource will only override the <code>XmNinitialState</code> resource when specified in the call that creates the widget.</p>
<dt><code>XmNiconName</code></p>
<dd>Specifies the short form of the application name to be displayed by the window manager when the application is iconified. When <code>XtGetValues</code> is called on this resource, the returned value is a pointer to the actual resource value and should not be freed.</p>
<dt><code>XmNiconNameEncoding</code></p>
<dd>Specifies a property type that represents the encoding of the <code>XmNiconName</code> string. If a language procedure has been set, the default is None; otherwise, the default is <code>XA_STRING</code>. When the widget is realized, if the value is None, the corresponding name is assumed to be in the current locale. The name is passed to <code>XmbTextListToTextProperty</code> with an encoding style of <code>XStdICCTextStyle</code>. The resulting encoding is <code>STRING</code> if the name is fully convertible to <code>STRING</code>, otherwise <code>COMPOUND_TEXT</code>. The values of the encoding resources are not changed; they remain None.</dl>
