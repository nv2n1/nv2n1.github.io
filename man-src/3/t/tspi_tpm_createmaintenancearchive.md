<h2>Name</h2>
<p>Tspi_TPM_CreateMaintenanceArchive &#8211; create the TPM manufacturer specific maintenance archive data. </p>
<h2>Synopsis</h2>
<pre><code>#include &lt;tss/platform.h&gt;</code>
<code>#include &lt;tss/tcpa_defines.h&gt;</code>
<code>#include &lt;tss/tcpa_typedef.h&gt;</code>
<code>#include &lt;tss/tcpa_struct.h&gt;</code>
<code>#include &lt;tss/tss_typedef.h&gt;</code>
<code>#include &lt;tss/tss_structs.h&gt;</code>
<code>#include &lt;tss/tspi.h&gt;</code>
<code>TSS_RESULT Tspi_TPM_CreateMaintenanceArchive(TSS_HTPM </code><i>hTPM</i><code>, TSS_BOOL </code><i>fGenerateRndNumber</i><code>,</code>
<code> UINT32* </code><i>pulRndNumberLength</i><code>, BYTE** </code><i>prgbRndNumber</i><code>,</code>
<code> UINT32* </code><i>pulArchiveDataLength</i><code>, BYTE** </code><i>prgbArchiveData</i><code>);</code></pre>
<h2>Description</h2>
<p><code>Tspi_TPM_CreateMaintenanceArchive</code> creates the TPM Manufacturer specific maintenance archive data. <code>This command is not currently implemented by any manufacturer</code>. </p>
<h2>Parameters</h2>
<h3>hTPM</h3>
<p>The <i>hTPM</i> parameter is used to specify the handle of the TPM object.</p>
<h3>fGenerateRndNumber</h3>
<p>The <i>fGenerateRndNumber</i> parameter determines how the random number is generated. If TRUE, a random number is generated by the TPM and returned. If FALSE, a random number is calculated based on the owner secret.</p>
<h3>pulRndNumberLength</h3>
<p>The <i>pulRndNumberLength</i> parameter receives the length in bytes of the <i>prgbRndNumber</i> parameter. This is 0 if <i>fGenerateRndNumber</i> is FALSE.</p>
<h3>prgbRndNumber</h3>
<p>The <i>prgbRndNumber</i> parameter receives a pointer to the random number data attributes. This is NULL if <i>fGenerateRndNumber</i> is FALSE.</p>
<h3>pulArchiveDataLength</h3>
<p>The <i>pulArchiveDataLength</i> parameter receives the length in bytes of the <i>prgbArchiveData</i> parameter.</p>
<h3>prgbArchiveData</h3>
<p>The <i>prgbArchiveData</i> parameter receives a pointer to the archive data. </p>
<h2>Return Codes</h2>
<p><code>Tspi_TPM_CreateMaintenanceArchive</code> returns TSS_SUCCESS on success, otherwise one of the following values is returned:</p>
<dl COMPACT>
<dt><font SIZE="-1">TSS_E_INVALID_HANDLE</font></p>
<dd><i>hTPM</i> is not a valid handle. </p>
<dt><font SIZE="-1">TSS_E_INTERNAL_ERROR</font></p>
<dd>An internal SW error has been detected. </p>
<dt><font SIZE="-1">TSS_E_BAD_PARAMETER</font></p>
<dd>One or more parameters is bad. </p>
<dt><font SIZE="-1">TSS_E_NOTIMPL</font></p>
<dd>The function is not implemented. </p>
</dl>
