<p>Tk_SetAppName &#8211; Set the name of an application for &#8216;send&#8217; commands </p>
<h2>Synopsis</h2>
<pre><code>#include &lt;tk.h&gt;</code>
const char *
<code>Tk_SetAppName</code>(<i>tkwin, name</i>)</pre>
<h2>Arguments</h2>
<dl COMPACT>
<dd>Tk_Window <i>tkwin</i> (in) Token for window in application. Used only to select a particular application.</p>
<dd>const char <i>*name</i> (in) Name under which to register the application. </p>
</dl>
<h2>Description</h2>
<p><code>Tk_SetAppName</code> associates a name with a given application and records that association on the display containing with the application&#8217;s main window. After this procedure has been invoked, other applications on the display will be able to use the <code>send</code> command to invoke operations in the application. If <i>name</i> is already in use by some other application on the display, then a new name will be generated by appending &#8220;<code> #2</code>&#8221; to <i>name</i>; if this name is also in use, the number will be incremented until an unused name is found. The return value from the procedure is a pointer to the name actually used. </p>
<p> If the application already has a name when <code>Tk_SetAppName</code> is called, then the new name replaces the old name. </p>
<p> <code>Tk_SetAppName</code> also adds a <code>send</code> command to the application&#8217;s interpreter, which can be used to send commands from this application to others on any of the displays where the application has windows. </p>
<p> The application&#8217;s name registration persists until the interpreter is deleted or the <code>send</code> command is deleted from <i>interp</i>, at which point the name is automatically unregistered and the application becomes inaccessible via <code>send</code>. The application can be made accessible again by calling <code>Tk_SetAppName</code>. </p>
<p> <code>Tk_SetAppName</code> is called automatically by <code>Tk_Init</code>, so applications do not normally need to call it explicitly. </p>
<p> The command <code>tk appname</code> provides Tcl-level access to the functionality of <code>Tk_SetAppName</code>. </p>
<h2>Keywords</h2>
<p>application, name, register, send command</p>
