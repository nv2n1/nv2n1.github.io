<h2>NAME</h2>
<p> exdata &#8211; Accessing the contents of datafiles. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exdata</code></p>
<h2>DESCRIPTION</h2>
<p> This program demonstrates how to access the contents of an Allegro datafile (created by the grabber utility). The example loads the file `example.dat&#8217;, then blits a bitmap and shows a font, both from this datafile. </p>
