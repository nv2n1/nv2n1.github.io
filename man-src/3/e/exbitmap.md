<h2>NAME</h2>
<p> exbitmap &#8211; Loading and displaying PCX and BMP files. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exbitmap</code></p>
<h2>DESCRIPTION</h2>
<p> This program demonstrates how to load and display a bitmap file. You have to use this example from the command line to specify as first parameter a graphic file in one of Allegro&#8217;s supported formats. If the file is loaded successfully, it will be displayed until you press a key. </p>
