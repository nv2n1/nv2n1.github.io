<h2>NAME</h2>
<p> exscale &#8211; Loading PCX files and bitmap stretching. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exscale</code></p>
<h2>DESCRIPTION</h2>
<p> This example demonstrates how to use PCX files, palettes and stretch blits. It loads a PCX file, sets its palette and does some random stretch_blits. Don&#8217;t worry &#8211; it&#8217;s VERY slowed down using vsync(). </p>
