<h2>NAME</h2>
<p> exhello &#8211; Simple graphical &quot;hello world&quot; program. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exhello</code></p>
<h2>DESCRIPTION</h2>
<p> This is a very simple program showing how to get into graphics mode and draw text onto the screen. </p>
