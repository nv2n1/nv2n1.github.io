<h2>NAME</h2>
<p> exflame &#8211; How to write directly to video memory improving performance. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exflame</code></p>
<h2>DESCRIPTION</h2>
<p> This program demonstrates how to write directly to video memory. It implements a simple fire effect, first by calling getpixel() and putpixel(), then by accessing video memory directly a byte at a time, and finally using block memory copy operations. </p>
