<h2>NAME</h2>
<p> exscroll &#8211; Mode-X hardware scrolling and split screens. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exscroll</code></p>
<h2>DESCRIPTION</h2>
<p> This program demonstrates how to use hardware scrolling. The scrolling should work on anything that supports virtual screens larger than the physical screen. </p>
