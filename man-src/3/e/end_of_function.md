<p>END_OF_FUNCTION &#8211; Locks the code used by a timer. Allegro game programming library.</p>
<h2>Synopsis</h2>
<p><code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Macro END_OF_FUNCTION(function_name);</code></p>
<h2>Description</h2>
<p>Due to interrupts, you are required to lock all the code used by your timer routines. See the description of install_int_ex() for a more detailed explanation and usage example. </p>
