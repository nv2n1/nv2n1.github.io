<h2>NAME</h2>
<p> exscn3d &#8211; Using the 3d scene functions. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exscn3d</code></p>
<h2>DESCRIPTION</h2>
<p> This program demonstrates how to use scanline sorting algorithm in Allegro (create_scene, clear_scene, &#8230; functions). It also provides an example of how to use the 3D clipping function. The example consists of a flyby through a lot of rotating 3d cubes. </p>
