<h2>NAME</h2>
<p> exjoy &#8211; Detecting, calibrating and using joystick input. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>Example exjoy</code></p>
<h2>DESCRIPTION</h2>
<p> This program uses the Allegro library to detect and read the value of a joystick. The output of the program is a small target sight on the screen which you can move. At the same time the program will tell you what you are doing with the joystick (moving or firing). </p>
