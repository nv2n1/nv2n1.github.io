<h2>NAME</h2>
<p> ellipsefill &#8211; Draws a filled ellipse. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void ellipsefill(BITMAP *bmp, int x, int y, int rx, int ry, int color);</code></p>
<h2>DESCRIPTION</h2>
<p> Draws a filled ellipse with the specified centre and radius. </p>
