<p>FcWeightFromOpenType &#8211; Convert from OpenType weight values to fontconfig ones </p>
<h2>Synopsis</h2>
<p><code>#include &lt;fontconfig/fontconfig.h&gt; </p>
<p> int FcWeightFromOpenType (int</code><i>ot_weight</i><code>); </code></p>
<h2>Description</h2>
<p><code>FcWeightFromOpenType</code> is like <code>FcWeightFromOpenTypeDouble</code> but with integer arguments. Use the other function instead.</p>
