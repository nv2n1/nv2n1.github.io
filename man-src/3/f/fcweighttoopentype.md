<p>FcWeightToOpenType &#8211; Convert from fontconfig weight values to OpenType ones </p>
<h2>Synopsis</h2>
<p><code>#include &lt;fontconfig/fontconfig.h&gt; </p>
<p> int FcWeightToOpenType (int</code><i>ot_weight</i><code>); </code></p>
<h2>Description</h2>
<p><code>FcWeightToOpenType</code> is like <code>FcWeightToOpenTypeDouble</code> but with integer arguments. Use the other function instead.</p>
