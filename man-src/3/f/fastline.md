<h2>NAME</h2>
<p> fastline &#8211; Faster version of line(). Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void fastline(BITMAP *bmp, int x1, int y1, int x2, int y2, int color);</code></p>
<h2>DESCRIPTION</h2>
<p> Faster version of the previous function. Note that pixel correctness is not guaranteed for this function. </p>
