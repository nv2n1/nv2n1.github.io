<h2>NAME</h2>
<p> fixed &#8211; Fixed point integer to replace floats. Allegro game programming library.</p>
<h2>SYNOPSIS</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>typedef long fixed</code></p>
<h2>DESCRIPTION</h2>
<p> This is a fixed point integer which can replace float with similar results and is faster than float on low end machines. Read chapter &quot;Fixed point math routines&quot; for the full explanation. </p>
