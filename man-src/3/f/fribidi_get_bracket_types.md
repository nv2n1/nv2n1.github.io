<h2 class="name">NAME</h2>
 

 fribidi_get_bracket_types - get bracketed characters 

<h2>SYNOPSIS</h2>

 <b> #include &lt;fribidi.h&gt; 

 extern void fribidi_get_bracket_types 
 ( 
 <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>const FriBidiChar *str,
 
 <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>const FriBidiStrIndex len,
 
 <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>const FriBidiCharType *types,
 
 <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>FriBidiBracketType *btypes
 
 ); </b>

<h2>PARAMETERS</h2>

<dl>
<dt><b>const FriBidiChar *str</b>
<dd> Input string.
<dt><b>const FriBidiStrIndex len</b>
<dd> Input string length.
<dt><b>const FriBidiCharType *types</b>
<dd> Input bidi types. 

 Since there are 23 possible values for a <b>const FriBidiCharType</b>, they are not all listed here.
<dt><b>FriBidiBracketType *btypes</b>
<dd> Output bracketed characters.</dl>

<h2>DESCRIPTION</h2>

 This function finds the bracketed characters of an string of characters. See fribidi_get_bracket() for more information about the bracketed characters returned by this function.
