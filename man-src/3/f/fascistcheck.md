<p>FascistCheck &#8211; a pro-active password checker library</p>
<h2>Synopsis</h2>
<p><code>#include &lt;crack.h&gt;</code> </p>
<p> <code>static char const CRACKLIB_DICTPATH[] = &nbsp;<wbr>&#8230;;</code> </p>
<p> <code>extern char const *</code><br />
 <code>FascistCheck(char const passwd[], char const dictpath[]);</code></p>
<h2>Description</h2>
<p>cracklib is a library containing the <code>FascistCheck</code> C function which may be used in a &quot;passwd&quot; like program. The idea is simple: try to prevent users from choosing passwords that could be guessed by &quot;crack&quot; by filtering them out, at source. cracklib is an offshoot of the the version 5 of the &quot;crack&quot; software and contains a considerable number of ideas nicked from the new software. </p>
<p> The first formal argument <code>password</code> is the potential password. The second formal argument <code>dictpath</code> is the full path name + filename prefix of the cracklib dictionary database. <code>FascistCheck</code> returns the NULL pointer for a good password, or a pointer to a diagnostic string if it is a weak password. </p>
<p> The database is in a binary format generated by the utilities <code><a href="/docs/linux/man/8-crack_mkdict/">crack_mkdict</a></code>(8) and <code><a href="/docs/linux/man/8-crack_packer/">crack_packer</a></code>(8). On a Debian system the database is located in the directory defined by the static constant <code>CRACKLIB_DICTPATH</code> and is set to /var/cache/cracklib/cracklib_dict. None of the subroutines in the cracklib libraries have this location hard-coded into their implementations. It is generated daily with the program /etc/cron.daily/cracklib.</p>
<h2>Files</h2>
<dl COMPACT>
<dt><i>/var/cache/cracklib/cracklib_dict.[hwm|pwd|pwi]</i></p>
<dd>cracklib dictionary database files used by utilities.</p>
<dt><i>/etc/cron.daily/cracklib</i></p>
<dd>cracklib daily cron program to rebuild the cracklib dictionary database.</p>
<dt><i>/etc/cracklib/cracklib.conf</i></p>
<dd>cracklib configuration file used by the cracklib daily cron program to rebuild the cracklib dictionary database.</p>
<dt><i>/usr/sbin/crack_mkdict</i></p>
<dd>cracklib shell script to create initial list of words for dictionary database.</p>
<dt><i>/usr/share/doc/cracklib2-dev/examples</i></p>
<dd>Example <code><a href="/docs/linux/man/1-cc/">cc</a></code>(1) source files that show how <code>FascistCheck</code> is used.</dl>
