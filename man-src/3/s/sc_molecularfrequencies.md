<h2>Constructor &amp; Destructor Documentation</h2>
<h3>sc::MolecularFrequencies::MolecularFrequencies (const <code>Ref</code>&lt; <code>KeyVal</code> &gt; &amp;)</h3>
<p>The <code>KeyVal</code> constructor. .IP &quot;mole&quot; 1c A <code>MolecularEnergy</code> object. If this is not given then molecule must be given. </p>
<dl>
<dt>molecule</p>
<dd>A <code>Molecule</code> object. If this is not given then mole must be given.</dl>
<dl>
<dt>point_group</p>
<dd>A <code>PointGroup</code> object. This is the <code>point</code> group used to compute the finite displacements. Since some <code>MolecularEnergy</code> objects cannot handle changes in the molecule&#8217;s <code>point</code> group, the molecule must be given $C_1$ symmetry for frequency calculations. In this case, the point_group keyword can be given to reduce number of the displacements needed to compute the frequencies. If this is not given then the <code>point</code> group of the molecule is used.</dl>
<dl>
<dt>debug</p>
<dd>An integer which, if nonzero, will cause extra output.</dl>
<dl>
<dt>displacement</p>
<dd>The amount that coordinates will be displaced. The default is 0.001.</dl>
