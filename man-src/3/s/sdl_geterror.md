<p>SDL_GetError &#8211; Get SDL error string</p>
<h2>Synopsis</h2>
<p><code>#include &quot;SDL/SDL.h&quot; </p>
<p> char *SDL_GetError</code>(<code>void</code>);</p>
<h2>Description</h2>
<p><code>SDL_GetError</code> returns a NULL terminated string containing information about the last internal SDL error.</p>
<h2>Return Value</h2>
<p><code>SDL_GetError</code> returns a string containing the last error.</p>
