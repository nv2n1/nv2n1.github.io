std::any::has_value - std::any::has_value

<h2>Synopsis</h2>

bool has_value() const noexcept; <i>(since C++17)</i> 
Checks whether the object contains a value. 

<h2>Parameters</h2>

<i>(none)</i>

<h2>Return value</h2>

true if instance contains a value, otherwise false.
