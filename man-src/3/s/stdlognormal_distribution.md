std::lognormal_distribution - std::lognormal_distribution

<h2>Synopsis</h2>

<pre><code>Defined in header &lt;random&gt;

template&lt; class RealType = double &gt;  (since C++11)

class lognormal_distribution;</code></pre> 
The lognormal_distribution random number distribution produces random numbers x &gt; 0 according to a log-normal_distribution: 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;f(x; m,s) = 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;1 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;sx 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;√ 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;2 π 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;exp⎛ 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;⎜ 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;⎝- 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;(ln x - m)2 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;2s2 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;⎞ 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;⎟ 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;⎠ 
The parameters m and s are, respectively, the mean and standard deviation of the natural logarithm of x. 
std::lognormal_distribution satisfies all requirements of RandomNumberDistribution

<h2>Example</h2>

// Run this code <pre><code>#include &lt;iostream&gt;

#include &lt;iomanip&gt;

#include &lt;string&gt;

#include &lt;map&gt;

#include &lt;random&gt;

#include &lt;cmath&gt;

int main()

{
    std::random_device rd;
    std::mt19937 gen(rd());
    std::lognormal_distribution&lt;&gt; d(1.6, 0.25);
    std::map&lt;int, int&gt; hist;
    for (int n = 0; n &lt; 10000; ++n) {
        ++hist[std::round(d(gen))];
    }
    for (auto p : hist) {
        std::cout &lt;&lt; std::fixed &lt;&lt; std::setprecision(1) &lt;&lt; std::setw(2)
                  &lt;&lt; p.first &lt;&lt; ' ' &lt;&lt; std::string(p.second / 200, '*') &lt;&lt; '\n';
    }
}
</code></pre>
