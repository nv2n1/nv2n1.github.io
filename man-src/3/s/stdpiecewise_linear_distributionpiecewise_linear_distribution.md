Constructs new piecewise linear distribution object.<br />
1) Constructs a distribution object with n = 1, ρ0 = 1, b0 = 0, and b1 = 1.<br />
2) Constructs a distribution object from iterators over the and interval sequence [first_i, last_i) and a matching weight sequence starting at first_w.<br />
3) Constructs a distribution object where the intervals are taken from the initializer list ilist and the weights generated by the function fw.<br />
4) Constructs a distribution object with the fw intervals distributed uniformly over [xmin, xmax]<br />
5) Constructs a distribution object initialized with the parameters param. </p>
