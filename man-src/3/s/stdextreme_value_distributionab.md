<h2>Synopsis</h2>
<p>RealType a() const; <code>(1)</code> <i>(since C++11)</i><br />
RealType b() const; <code>(2)</code> <i>(since C++11)</i><br />
Returns the parameters the distribution was constructed with.<br />
1) Returns the a distribution parameter (location). The default value is 1.0.<br />
2) Returns the b distribution parameter (scale). The default value is 0.0. </p>
