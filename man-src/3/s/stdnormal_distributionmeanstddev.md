<p>std::normal_distribution&lt;RealType&gt;::mean,stddev &#8211; std::normal_distribution&lt;RealType&gt;::mean,stddev</p>
<h2>Synopsis</h2>
<p>RealType mean() const; <code>(1)</code> <i>(since C++11)</i><br />
RealType stddev() const; <code>(2)</code> <i>(since C++11)</i><br />
Returns the parameters the distribution was constructed with.<br />
1) Returns the mean μ distribution parameter. The mean specifies the location of the peak. The default value is 0.0.<br />
2) Returns the deviation σ distribution parameter. The default value is 1.0. </p>
<h2>Parameters</h2>
<p><i>(none)</i></p>
<h2>Return value</h2>
<p>1) The mean μ distribution parameter.<br />
2) The deviation σ distribution parameter. </p>
