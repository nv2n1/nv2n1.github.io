std::swap - std::swap

<h2>Synopsis</h2>

<pre><code>Defined in header&lt;algorithm&gt;(until C++ 11)

    Defined in header&lt;utility&gt;(since C++ 11)

        template &lt;class T&gt;
        (until C++ 11)

            void swap(T &amp;a, T &amp;b);

template &lt;class T&gt;
(since C++ 11)

    void swap(T &amp;a, T &amp;b) noexcept(/* see below */);
(until C++ 20)

    template &lt;class T&gt;
    (1)(since C++ 20)

        constexpr void swap(T &amp;a, T &amp;b) noexcept(/* see below */);

template &lt;class T2, std::size_t N&gt;
(since C++ 11)

    void swap(T2 (&amp;a)[N], T2 (&amp;b)[N]) noexcept(/* see below */);
(2)(until C++ 20)

    template &lt;class T2, std::size_t N&gt;
    (since C++ 20)

        constexpr void swap(T2 (&amp;a)[N], T2 (&amp;b)[N]) noexcept(/* see below */);</code></pre> 
Exchanges the given values. 
1) Swaps the values a and b. 
This overload does not participate in overload resolution unless std::is_move_constructible_v&lt;T&gt; &amp;&amp; std::is_move_assignable_v&lt;T&gt; is true. 
<i>(since C++17)</i> 
2) Swaps the arrays a and b. In effect calls std::swap_ranges(a, a+N, b). 
This overload does not participate in overload resolution unless std::is_swappable_v&lt;T2&gt; is true. 
<i>(since C++17)</i> 

<h2>Parameters</h2>

a, b - the values to be swapped

<h2>Type requirements</h2>

- 
T must meet the requirements of MoveAssignable and MoveConstructible. 
- 
T2 must meet the requirements of Swappable.

<h2>Return value</h2>

<i>(none)</i> 

<h2>Exceptions</h2>

1) 

 
<i>(none)</i> <i>(until C++11)</i> 
noexcept specification: 
noexcept( 
std::is_nothrow_move_constructible&lt;T&gt;::value &amp;&amp; <i>(since C++11)</i> 
std::is_nothrow_move_assignable&lt;T&gt;::value 
) 

 
2) 

 
noexcept specification: 
noexcept(noexcept(swap(*a, *b))) <i>(until C++17)</i> 
The lookup for the identifier swap in the exception specification finds this function template in addition to anything found by the usual lookup rules, making the exception specification equivalent to C++17 std::is_nothrow_swappable. 
noexcept specification: <i>(since C++17)</i> 
noexcept(std::is_nothrow_swappable_v&lt;T2&gt;)

<h2>Complexity</h2>

1) Constant 
2) Linear in N

<h2>Specializations</h2>

std::swap may be specialized_in_namespace_std for program-defined types, but such specializations are not found by ADL (the namespace std is not the associated namespace for the program-defined type). <i>(until C++20)</i> 

 
The expected way to make a program-defined type swappable is to provide a non-member function swap in the same namespace as the type: see Swappable for details.
