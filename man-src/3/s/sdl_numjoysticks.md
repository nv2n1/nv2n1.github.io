<p>SDL_NumJoysticks &#8211; Count available joysticks.</p>
<h2>Synopsis</h2>
<p><code>#include &quot;SDL.h&quot; </p>
<p> int SDL_NumJoysticks</code>(<code>void</code>);</p>
<h2>Description</h2>
<p>Counts the number of joysticks attached to the system.</p>
<h2>Return Value</h2>
<p>Returns the number of attached joysticks</p>
