<p>SDL_LoadBMP &#8211; Load a Windows BMP file into an SDL_Surface.</p>
<h2>Synopsis</h2>
<p><code>#include &quot;SDL.h&quot; </p>
<p> SDL_Surface *SDL_LoadBMP</code>(<code>const char *file</code>);</p>
<h2>Description</h2>
<p>Loads a surface from a named Windows BMP file.</p>
<h2>Return Value</h2>
<p>Returns the new surface, or <code>NULL</code> if there was an error.</p>
