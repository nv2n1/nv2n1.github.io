std::strftime - std::strftime

<h2>Synopsis</h2>

<pre><code>Defined in header&lt;ctime&gt;

    std::size_t strftime(char *str, std::size_t count, const char *format, const std::tm *time);</code></pre> 
Converts the date and time information from a given calendar time time to a null-terminated multibyte character string str according to format string format. Up to count bytes are written. 

<h2>Parameters</h2>

str - pointer to the first element of the char array for output 
count - maximum number of bytes to write 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;pointer to a null-terminated multibyte character string specifying the format of conversion. 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;The format string consists of zero or more conversion specifiers and ordinary characters (except %). All ordinary characters, including the terminating null character, are copied to the output string without modification. Each conversion specification begins with % character, optionally followed by E or O modifier (ignored if unsupported by the locale), followed by the character that determines the behavior of the specifier. The following format specifiers are available:

time - pointer to the date and time information to be converted

<h2>Return value</h2>

The number of bytes written into the character array pointed to by str not including the terminating '\0' on success. If count was reached before the entire string could be stored, 0 is returned and the contents are undefined.
