<p>std::experimental::pmr::monotonic_buffer_resource::do_deallocate &#8211; std::experimental::pmr::monotonic_buffer_resource::do_deallocate</p>
<h2>Synopsis</h2>
<p>virtual void do_deallocate(void* p, std::size_t bytes, std::size_t alignment); (library fundamentals TS)<br />
This function has no effect. Memory used by a monotonic_buffer_resource, as its name indicates, increases monotonically until the resource is destroyed. </p>
<h2>Exceptions</h2>
