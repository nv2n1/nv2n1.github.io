<p>set_mouse_sprite_focus &#8211; Sets the mouse sprite focus. Allegro game programming library.</p>
<h2>Synopsis</h2>
<p> <code>#include &lt;<a href="file:/usr/include/allegro.h">allegro.h</a>&gt;</code> </p>
<p> <code>void set_mouse_sprite_focus(int x, int y);</code></p>
<h2>Description</h2>
<p> The mouse focus is the bit of the pointer that represents the actual mouse position, ie. the (mouse_x, mouse_y) position. By default this is the top left corner of the arrow, but if you are using a different mouse pointer you might need to alter it. </p>
