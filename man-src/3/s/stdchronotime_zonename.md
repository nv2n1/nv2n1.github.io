std::chrono::time_zone::name - std::chrono::time_zone::name

<h2>Synopsis</h2>

std::string_view name() const noexcept; <i>(since C++20)</i> 
Obtains the name of this time zone. 

<h2>Return value</h2>

The name of this time zone (e.g., &quot;America/New_York&quot;).
