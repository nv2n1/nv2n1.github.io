<p>SDL_FillRect &#8211; This function performs a fast fill of the given rectangle with some color</p>
<h2>Synopsis</h2>
<p><code>#include &quot;SDL.h&quot; </p>
<p> int SDL_FillRect</code>(<code>SDL_Surface *dst, SDL_Rect *dstrect, Uint32 color</code>);</p>
<h2>Description</h2>
<p>This function performs a fast fill of the given rectangle with <code>color</code>. If <code>dstrect</code> is <code>NULL</code>, the whole surface will be filled with <code>color</code>. </p>
<p> The color should be a pixel of the format used by the surface, and can be generated by the <i>SDL_MapRGB</i> or <i>SDL_MapRGBA</i> functions. If the color value contains an alpha value then the destination is simply &quot;filled&quot; with that alpha information, no blending takes place. </p>
<p> If there is a clip rectangle set on the destination (set via <i>SDL_SetClipRect</i>) then this function will clip based on the intersection of the clip rectangle and the <code>dstrect</code> rectangle and the dstrect rectangle will be modified to represent the area actually filled.</p>
<h2>Return Value</h2>
<p>This function returns <code>0</code> on success, or <code>-1</code> on error.</p>
