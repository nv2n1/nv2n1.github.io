std::discrete_distribution&lt;IntType&gt;::probabilities - std::discrete_distribution&lt;IntType&gt;::probabilities

<h2>Synopsis</h2>

std::vector&lt;double&gt; probabilities() const; <i>(since C++11)</i> 
Obtains a std::vector&lt;double&gt; containing the individual probabilities of each integer that is generated by this distribution. 

<h2>Parameters</h2>

<i>(none)</i>

<h2>Return value</h2>

An object of type std::vector&lt;double&gt; 

<h2>Example</h2>

// Run this code <pre><code>#include &lt;iostream&gt;

#include &lt;vector&gt;

#include &lt;random&gt;

int main()

{
    std::discrete_distribution&lt;&gt; d({40, 10, 10, 40});
    std::vector&lt;double&gt; p = d.probabilities();
    for (auto n : p)
        std::cout &lt;&lt; n &lt;&lt; ' ';
    std::cout &lt;&lt; '\n';
}
</code></pre>

<h2>Output:</h2>

&nbsp;<wbr>&nbsp;0.4 0.1 0.1 0.4
