<p>std::generate_n &#8211; std::generate_n</p>
<h2>Synopsis</h2>
<pre><code>Defined in header&lt;algorithm&gt;

    template &lt;class OutputIt, class Size, class Generator&gt;
    (until C++ 11)

        void generate_n(OutputIt first, Size count, Generator g);

template &lt;class OutputIt, class Size, class Generator&gt;
(since C++ 11)

    OutputIt generate_n(OutputIt first, Size count, Generator g);
(1)(until C++ 20)

    template &lt;class OutputIt, class Size, class Generator&gt;
    (since C++ 20)

        constexpr OutputIt generate_n(OutputIt first, Size count, Generator g);

template &lt;class ExecutionPolicy, class ForwardIt, class Size, class Generator&gt;
(2)(since C++ 17)

    ForwardIt generate_n(ExecutionPolicy &amp;&amp;policy, ForwardIt first, Size count, Generator g);</code></pre>
<p>1) Assigns values, generated by given function object g, to the first count elements in the range beginning at first, if count&gt;0. Does nothing otherwise.<br />
2) Same as <code>(1)</code>, but executed according to policy. This overload only participates in overload resolution if std::is_execution_policy_v&lt;std::decay_t&lt;ExecutionPolicy&gt;&gt; is true </p>
<h2>Parameters</h2>
<p>first &#8211; the beginning of the range of elements to generate<br />
count &#8211; number of the elements to generate<br />
policy &#8211; the execution policy to use. See execution_policy for details.<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;generator function object that will be called.<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;The signature of the function should be equivalent to the following:<br />
g &#8211;<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;Ret fun(); </p>
<p>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;The type Ret must be such that an object of type OutputIt can be dereferenced and assigned a value of type Ret.</p>
<h2>Type requirements</h2>
<p>&#8211;<br />
OutputIt must meet the requirements of LegacyOutputIterator.<br />
&#8211;<br />
ForwardIt must meet the requirements of LegacyForwardIterator.</p>
<h2>Return value</h2>
<p><i>(none)</i> <i>(until C++11)</i><br />
Iterator one past the last element assigned if count&gt;0, first otherwise. <i>(since C++11)</i> </p>
<h2>Complexity</h2>
<p>Exactly count invocations of g() and assignments, for count&gt;0.</p>
<h2>Exceptions</h2>
<p>The overload with a template parameter named ExecutionPolicy reports errors as follows: </p>
<p>* If execution of a function invoked as part of the algorithm throws an exception and ExecutionPolicy is one of the standard_policies, std::terminate is called. For any other ExecutionPolicy, the behavior is implementation-defined.<br />
* If the algorithm fails to allocate memory, std::bad_alloc is thrown.</p>
<h2>Possible implementation</h2>
<p>&nbsp;<wbr>&nbsp;template&lt; class OutputIt, class Size, class Generator &gt;<br />
&nbsp;<wbr>&nbsp;OutputIt generate_n( OutputIt first, Size count, Generator g )<br />
&nbsp;<wbr>&nbsp;{<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;for( Size i = 0; i &lt; count; i++ ) {<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;*first++ = g();<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;}<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;return first;<br />
&nbsp;<wbr>&nbsp;}</p>
