<p>SPI_pop &#8211; pop SPI stack to return from recursive SPI usage </p>
<h2>Synopsis</h2>
<pre>void SPI_pop(void)</pre>
<h2>Description</h2>
<p><code>SPI_pop</code> pops the previous environment from the SPI call stack. See <code>SPI_push</code>.</p>
