std::experimental::any::empty - std::experimental::any::empty

<h2>Synopsis</h2>

bool empty() const noexcept; (library fundamentals TS) 
Checks whether the object contains a value. 

<h2>Parameters</h2>

<i>(none)</i>

<h2>Return value</h2>

true if instance is empty, otherwise false.
