<p>std::filesystem::path::make_preferred &#8211; std::filesystem::path::make_preferred</p>
<h2>Synopsis</h2>
<p>path&amp; make_preferred() <code>(1)</code> <i>(since C++17)</i><br />
Converts all directory separators in the generic-format view of the path to the preferred directory separator.<br />
For example, on Windows, where \ is the preferred separator, the path foo/bar will be converted to fooar. </p>
