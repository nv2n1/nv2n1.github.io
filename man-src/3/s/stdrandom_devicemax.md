<p>std::random_device::max &#8211; std::random_device::max</p>
<h2>Synopsis</h2>
<pre><code>static constexpr result_type max();  (since C++11)</code></pre>
<p>Returns the maximum value potentially generated by the random-number engine. This value is equal to std::numeric_limits&lt;unsigned int&gt;::max(). </p>
<h2>Parameters</h2>
<p><i>(none)</i></p>
<h2>Return value</h2>
<p>The maximum potentially generated value. </p>
