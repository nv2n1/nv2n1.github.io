<p>std::gamma_distribution&lt;RealType&gt;::alpha,beta &#8211; std::gamma_distribution&lt;RealType&gt;::alpha,beta</p>
<h2>Synopsis</h2>
<p>RealType alpha() const; <code>(1)</code> <i>(since C++11)</i><br />
RealType beta() const; <code>(2)</code> <i>(since C++11)</i><br />
Returns the distribution parameters the distribution has been constructed with.<br />
1) Returns the α distribution parameter. It is also known as the shape parameter. The default value is 1.0.<br />
2) Returns the β distribution parameter. It is also known as the scale parameter. The default value is 1.0. </p>
<h2>Parameters</h2>
<p><i>(none)</i></p>
<h2>Return value</h2>
<p>1) Floating point value identifying the α parameter<br />
2) Floating point value identifying the β parameter </p>
