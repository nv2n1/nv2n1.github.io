strequate - map a list of characters to the same value

<h2>Synopsis</h2>

<pre><code>#include &lt;your-opts.h&gt;

cc[...] - o outfile infile.c - lopts[...] void strequate(char const *ch_list);
</code></pre>

<h2>Description</h2>

Each character in the input string get mapped to the first character in the string. This function name is mapped to option_strequate so as to not conflict with the POSIX name space.
<dl><dt><i>ch_list</i>
<dd>characters to equivalence 

<h2>Errors</h2>

none.
