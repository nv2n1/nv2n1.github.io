<p>std::srand &#8211; std::srand</p>
<h2>Synopsis</h2>
<pre><code>Defined in header&lt;cstdlib&gt;

    void srand(unsigned seed);</code></pre>
<p>Seeds the pseudo-random number generator used by std::rand() with the value seed.<br />
If rand() is used before any calls to srand(), rand() behaves as if it was seeded with <a href="/docs/linux/man/1-srand/">srand</a><code>(1)</code>.<br />
Each time rand() is seeded with the same seed, it must produce the same sequence of values.<br />
srand() is not guaranteed to be thread-safe. </p>
<h2>Parameters</h2>
<p>seed &#8211; the seed value</p>
<h2>Return value</h2>
<p><i>(none)</i> </p>
<h2>Notes</h2>
<p>Generally speaking, the pseudo-random number generator should only be seeded once, before any calls to rand(), at the start of the program. It should not be repeatedly seeded, or reseeded every time you wish to generate a new batch of pseudo-random numbers.<br />
Standard practice is to use the result of a call to time<code>(0)</code> as the seed. However, time() returns a time_t value, and time_t is not guaranteed to be an integral type. In practice, though, every major implementation defines time_t to be an integral type, and this is also what POSIX requires. </p>
<h2>Example</h2>
<p>// Run this code </p>
<pre><code>#include &lt;cstdlib&gt;

#include &lt;iostream&gt;

#include &lt;ctime&gt;
int main()

{
    std::srand(std::time(0)); // use current time as seed for random generator
    int random_variable = std::rand();
    std::cout &lt;&lt; &quot;Random value on [0 &quot; &lt;&lt; RAND_MAX &lt;&lt; &quot;]: &quot;
              &lt;&lt; random_variable &lt;&lt; '
';
}
</code></pre>
