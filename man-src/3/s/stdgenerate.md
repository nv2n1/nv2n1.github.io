<p>std::generate &#8211; std::generate</p>
<h2>Synopsis</h2>
<pre><code>Defined in header&lt;algorithm&gt;

    template &lt;class ForwardIt, class Generator&gt;
    (until C++ 20)

        void generate(ForwardIt first, ForwardIt last, Generator g);

template &lt;class ForwardIt, class Generator&gt;
(1)(since C++ 20)

    constexpr void generate(ForwardIt first, ForwardIt last, Generator g);

template &lt;class ExecutionPolicy, class ForwardIt, class Generator&gt;
(2)(since C++ 17)

    void generate(ExecutionPolicy &amp;&amp;policy, ForwardIt first, ForwardIt last, Generator g);</code></pre>
<p>1) Assigns each element in range [first, last) a value generated by the given function object g.<br />
2) Same as <code>(1)</code>, but executed according to policy. This overload only participates in overload resolution if std::is_execution_policy_v&lt;std::decay_t&lt;ExecutionPolicy&gt;&gt; is true. </p>
<h2>Parameters</h2>
<p>first, last &#8211; the range of elements to generate<br />
policy &#8211; the execution policy to use. See execution_policy for details.<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;generator function object that will be called.<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;The signature of the function should be equivalent to the following:<br />
g &#8211;<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;Ret fun(); </p>
<p>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;The type Ret must be such that an object of type ForwardIt can be dereferenced and assigned a value of type Ret.</p>
<h2>Type requirements</h2>
<p>&#8211;<br />
ForwardIt must meet the requirements of LegacyForwardIterator.</p>
<h2>Return value</h2>
<p><i>(none)</i> </p>
<h2>Complexity</h2>
<p>Exactly std::distance(first, last) invocations of g() and assignments.</p>
<h2>Exceptions</h2>
<p>The overload with a template parameter named ExecutionPolicy reports errors as follows: </p>
<p>* If execution of a function invoked as part of the algorithm throws an exception and ExecutionPolicy is one of the standard_policies, std::terminate is called. For any other ExecutionPolicy, the behavior is implementation-defined.<br />
* If the algorithm fails to allocate memory, std::bad_alloc is thrown.</p>
<h2>Possible implementation</h2>
<p>&nbsp;<wbr>&nbsp;template&lt;class ForwardIt, class Generator&gt;<br />
&nbsp;<wbr>&nbsp;void generate(ForwardIt first, ForwardIt last, Generator g)<br />
&nbsp;<wbr>&nbsp;{<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;while (first != last) {<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;*first++ = g();<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;}<br />
&nbsp;<wbr>&nbsp;}</p>
<h2>Example</h2>
<p>// Run this code </p>
<pre><code>#include &lt;algorithm&gt;

#include &lt;iostream&gt;

#include &lt;vector&gt;
int f()

{
    static int i = 1;
    return i++;
}
int main()

{
    std::vector&lt;int&gt; v(5);
    std::generate(v.begin(), v.end(), f);
    std::cout &lt;&lt; &quot;v: &quot;;
    for (auto iv : v) {
        std::cout &lt;&lt; iv &lt;&lt; &quot; &quot;;
    }
    std::cout &lt;&lt; &quot;
&quot;;
    // Initialize with default values 0,1,2,3,4 from a lambda function
    // Equivalent to std::iota(v.begin(), v.end(), 0);
    std::generate(v.begin(), v.end(), [n = 0]() mutable { return n++; });
    std::cout &lt;&lt; &quot;v: &quot;;
    for (auto iv : v) {
        std::cout &lt;&lt; iv &lt;&lt; &quot; &quot;;
    }
    std::cout &lt;&lt; &quot;
&quot;;
}
</code></pre>
<h2>Output:</h2>
<p>&nbsp;<wbr>&nbsp;v: 1 2 3 4 5<br />
&nbsp;<wbr>&nbsp;v: 0 1 2 3 4</p>
