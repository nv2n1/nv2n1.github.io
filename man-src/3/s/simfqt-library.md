<p>simfqt-library &#8211; </p>
<pre> C++ Simulated Fare Quote System Library</pre>
<h2>Synopsis</h2>
<pre><code>#include &lt;simfqt/...&gt;
</code></pre>
<h2>Description</h2>
<p>SimFQT aims at providing a clean API and a simple implementation, as a C++ library, of a Travel-oriented fare engine. It corresponds to the simulated version of the real-world Fare Quote or pricing System. SimFQT makes an extensive use of existing open-source libraries for increased functionality, speed and accuracy. In particular the Boost (C++ Standard Extensions: <a rel="nofollow" href="http://www.boost.org)">http://www.boost.org)</a> library is used. The library covers the following areas:</p>
<dl>
<dt>&bull;</p>
<dd>Calculation of fare from statistics on tickets/coupons</p>
<dt>&bull;</p>
<dd>Fare rules: storage, engine, management</p>
<dt>&bull;</p>
<dd>Retrieval of fares for specific booking requests or product assesment</p>
<dt>&bull;</p>
<dd>Fare rule sets: storage, engine, management</dl>
