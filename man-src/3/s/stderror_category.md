<p>std::error_category &#8211; std::error_category</p>
<h2>Synopsis</h2>
<p>Defined in header &lt;system_error&gt;<br />
class error_category; <i>(since C++11)</i><br />
std::error_category serves as the base class for specific error category types, such as std::system_category, std::iostream_category, etc. Each specific category class defines the error_code &#8211; error_condition mapping and holds the explanatory strings for all error_conditions. The objects of error category classes are treated as singletons, passed by reference. </p>
