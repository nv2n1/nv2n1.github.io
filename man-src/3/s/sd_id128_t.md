<p>sd-id128, sd_id128_t, SD_ID128_MAKE, SD_ID128_CONST_STR, SD_ID128_FORMAT_STR, SD_ID128_FORMAT_VAL, sd_id128_equal &#8211; APIs for processing 128-bit IDs</p>
<h2>Synopsis</h2>
<pre><code>#include &lt;systemd/sd-id128.h&gt;





pkg-config --cflags --libs libsystemd</code></pre>
<h2>Description</h2>
<dd>sd-id128.h provides APIs to process and generate 128-bit ID values. The 128-bit ID values processed and generated by these APIs are a generalization of OSF UUIDs as defined by m[blue]<code>RFC 4122</code>m[]<font SIZE="-2">[1]</font> but use a simpler string format. These functions impose no structure on the used IDs, much unlike OSF UUIDs or Microsoft GUIDs, but are fully compatible with those types of IDs. See <code><a href="/docs/linux/man/3-sd_id128_to_string/">sd_id128_to_string</a></code>(3), <code><a href="/docs/linux/man/3-sd_id128_randomize/">sd_id128_randomize</a></code>(3) and <code><a href="/docs/linux/man/3-sd_id128_get_machine/">sd_id128_get_machine</a></code>(3) for more information about the implemented functions. A 128-bit ID is implemented as the following union type:</p>
<dl>
<dd>
<pre>typedef union sd_id128 {
 uint8_t bytes[16];
 uint64_t qwords[2];
} sd_id128_t;</pre>
</dl>
<p> This union type allows accessing the 128-bit ID as 16 separate bytes or two 64-bit words. It is generally safer to access the ID components by their 8-bit array to avoid endianness issues. This union is intended to be passed call-by-value (as opposed to call-by-reference) and may be directly manipulated by clients. A couple of macros are defined to denote and decode 128-bit IDs: <code>SD_ID128_MAKE()</code> may be used to denote a constant 128-bit ID in source code. A commonly used idiom is to assign a name to a 128-bit ID using this macro: int main(int argc, char *argv[])<br />
{<br />
    sd_id128_t a, b, c;<br />
    a = SD_ID128_MAKE(ee, 89, be, 71, bd, 6e, 43, d6, 91, e6, c5, 5d, eb, 03, 02, 07);<br />
    b = SD_ID128_MAKE(f2, 28, 88, 9c, 5f, 09, 44, 15, 9d, d7, 04, 77, 58, cb, e7, 3e);<br />
    c = a;<br />
    assert(sd_id128_equal(a, c));<br />
    assert(!sd_id128_equal(a, b));<br />
    return 0;<br />
} <code>SD_ID128_CONST_STR()</code> may be used to convert constant 128-bit IDs into constant strings for output. The following example code will output the string &quot;fc2e22bc6ee647b6b90729ab34a250b1&quot;: int main(int argc, char *argv[])<br />
{<br />
    sd_id128_t a, b, c;<br />
    a = SD_ID128_MAKE(ee, 89, be, 71, bd, 6e, 43, d6, 91, e6, c5, 5d, eb, 03, 02, 07);<br />
    b = SD_ID128_MAKE(f2, 28, 88, 9c, 5f, 09, 44, 15, 9d, d7, 04, 77, 58, cb, e7, 3e);<br />
    c = a;<br />
    assert(sd_id128_equal(a, c));<br />
    assert(!sd_id128_equal(a, b));<br />
    return 0;<br />
} <code>SD_ID128_FORMAT_STR</code> and <code>SD_ID128_FORMAT_VAL()</code> may be used to format a 128-bit ID in a <code><a href="/docs/linux/man/3-printf/">printf</a></code>(3) format string, as shown in the following example: int main(int argc, char *argv[])<br />
{<br />
    sd_id128_t a, b, c;<br />
    a = SD_ID128_MAKE(ee, 89, be, 71, bd, 6e, 43, d6, 91, e6, c5, 5d, eb, 03, 02, 07);<br />
    b = SD_ID128_MAKE(f2, 28, 88, 9c, 5f, 09, 44, 15, 9d, d7, 04, 77, 58, cb, e7, 3e);<br />
    c = a;<br />
    assert(sd_id128_equal(a, c));<br />
    assert(!sd_id128_equal(a, b));<br />
    return 0;<br />
} Use <code>sd_id128_equal()</code> to compare two 128-bit IDs: </p>
<pre><code>int main(int argc, char *argv[])
{
    sd_id128_t a, b, c;
    a = SD_ID128_MAKE(ee, 89, be, 71, bd, 6e, 43, d6, 91, e6, c5, 5d, eb, 03, 02, 07);
    b = SD_ID128_MAKE(f2, 28, 88, 9c, 5f, 09, 44, 15, 9d, d7, 04, 77, 58, cb, e7, 3e);
    c = a;
    assert(sd_id128_equal(a, c));
    assert(!sd_id128_equal(a, b));
    return 0;
}</code></pre>
<p> Note that new, randomized IDs may be generated with <code><a href="/docs/linux/man/1-journalctl/">journalctl</a></code>(1)&#8217;s <code>&#8211;new-id</code> option.</p>
<h2>Notes</h2>
<p>These APIs are implemented as a shared library, which can be compiled and linked to with the <code>libsystemd</code>&nbsp;<wbr><code><a href="/docs/linux/man/1-pkg-config/">pkg-config</a></code>(1) file.</p>
