ida_init - initialize ida handle

<h2>Synopsis</h2>

<pre><code>void ida_init(struct ida *ida);</code></pre>

<h2>Arguments</h2>

<i>ida</i>
<dl><dd><dd>ida handle</dl>

<h2>Description</h2>

This function is use to set up the handle (<i>ida</i>) that you will pass to the rest of the functions.
