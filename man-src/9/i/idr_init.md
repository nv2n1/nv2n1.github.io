idr_init - initialize idr handle

<h2>Synopsis</h2>

<pre><code>void idr_init(struct idr *idp);</code></pre>

<h2>Arguments</h2>

<i>idp</i>
<dl><dd><dd>idr handle</dl>

<h2>Description</h2>

This function is use to set up the handle (<i>idp</i>) that you will pass to the rest of the functions.
