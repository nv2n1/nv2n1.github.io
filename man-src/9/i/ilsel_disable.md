<p>ilsel_disable &#8211; Disable an ILSEL set</p>
<h2>Synopsis</h2>
<pre><code>void ilsel_disable(unsigned int irq);</code></pre>
<h2>Arguments</h2>
<p><i>irq</i></p>
<dl>
<dd>
<dd>Bit position for ILSEL set value (retval from enable routines)</dl>
<h2>Description</h2>
<p>Disable a previously enabled ILSEL set.</p>
