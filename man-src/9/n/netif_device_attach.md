netif_device_attach - mark device as attached

<h2>Synopsis</h2>

<pre><code>void netif_device_attach(struct net_device *dev);</code></pre>

<h2>Arguments</h2>

<i>dev</i>
<dl><dd><dd>network device</dl>

<h2>Description</h2>

Mark device as attached from system and restart if needed.
