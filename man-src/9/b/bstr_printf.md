<p>bstr_printf &#8211; Format a string from binary arguments and place it in a buffer </p>
<h2>SYNOPSIS</h2>
<dl>
<dt><code>int bstr_printf(char&nbsp;<wbr>*&nbsp;<wbr></code><i>buf</i><code>, size_t&nbsp;<wbr></code><i>size</i><code>, const char&nbsp;<wbr>*&nbsp;<wbr></code><i>fmt</i><code>, const u32&nbsp;<wbr>*&nbsp;<wbr></code><i>bin_buf</i><code>);</code></dt>
</dl>
<h2>ARGUMENTS</h2>
<p> <i>buf</i> </p>
<dl>
<dd>  </dd>
<dd> <p> The buffer to place the result into </p>
 </dd></dl>
<p> <i>size</i> </p>
<dl>
<dd> <p> The size of the buffer, including the trailing null space </p>
 </dd></dl>
<p> <i>fmt</i> </p>
<dl>
<dd> <p> The format string to use </p>
 </dd></dl>
<p> <i>bin_buf</i> </p>
<dl>
<dd> <p> Binary arguments for the format string </p>
 </dd></dl>
<h2>DESCRIPTION</h2>
<p>This function like C99 vsnprintf, but the difference is that vsnprintf gets arguments from stack, and bstr_printf gets arguments from <i>bin_buf</i> which is a binary buffer that generated by vbin_printf. </p>
<p>The format follows C99 vsnprintf, but has some extensions: see vsnprintf comment for details. </p>
<p>The return value is the number of characters which would be generated for the given input, excluding the trailing &#8216;\0&#8217;, as per ISO C99. If you want to have the exact number of characters written into <i>buf</i> as return value (not including the trailing &#8216;\0&#8217;), use <code>vscnprintf</code>. If the return is greater than or equal to <i>size</i>, the resulting string is truncated.  </p>
