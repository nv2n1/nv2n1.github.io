<p>bstr_printf &#8211; Format a string from binary arguments and place it in a buffer</p>
<h2>Synopsis</h2>
<pre><code>int bstr_printf(char *buf, size_t size, const char *fmt, const u32 *bin_buf);</code></pre>
<h2>Arguments</h2>
<p><i>buf</i></p>
<dl>
<dd>
<dd>The buffer to place the result into</dl>
<p> <i>size</i></p>
<dl>
<dd>The size of the buffer, including the trailing null space</dl>
<p> <i>fmt</i></p>
<dl>
<dd>The format string to use</dl>
<p> <i>bin_buf</i></p>
<dl>
<dd>Binary arguments for the format string</dl>
<h2>Description</h2>
<p>This function like C99 vsnprintf, but the difference is that vsnprintf gets arguments from stack, and bstr_printf gets arguments from <i>bin_buf</i> which is a binary buffer that generated by vbin_printf. </p>
<p> The format follows C99 vsnprintf, but has some extensions: see vsnprintf comment for details. </p>
