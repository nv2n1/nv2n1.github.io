strspn - Calculate the length of the initial substring of <i>s</i> which only contain letters in <i>accept</i>

<h2>Synopsis</h2>

<pre><code>size_t strspn(const char *s, const char *accept);</code></pre>

<h2>Arguments</h2>

<i>s</i>
<dl><dd><dd>The string to be searched</dl>
 

 <i>accept</i>
<dl><dd>The string to search for</dl>
