<p>struct_skb_shared_hwtstamps &#8211; hardware time stamps</p>
<h2>Synopsis</h2>
<pre><code>struct skb_shared_hwtstamps {
    ktime_t hwtstamp;
};</code></pre>
<h2>Members</h2>
<p>hwtstamp</p>
<dl>
<dd>hardware time stamp transformed into duration since arbitrary point in time</dl>
<h2>Description</h2>
<p>Software time stamps generated by <code>ktime_get_real</code> are stored in skb-&gt;tstamp. </p>
<p> hwtstamps can only be compared against other hwtstamps from the same device. </p>
<p> This structure is attached to packets as part of the skb_shared_info. Use <code>skb_hwtstamps</code> to get a pointer.</p>
