simple_strtoll - convert a string to a signed long long

<h2>Synopsis</h2>

<pre><code>long long simple_strtoll(const char *cp, char **endp, unsigned int base);</code></pre>

<h2>Arguments</h2>

<i>cp</i>
<dl><dd><dd>The start of the string</dl>
 

 <i>endp</i>
<dl><dd>A pointer to the end of the parsed string will be placed here</dl>
 

 <i>base</i>
<dl><dd>The number base to use</dl>

<h2>Description</h2>

This function is obsolete. Please use kstrtoll instead.
