strnchr - Find a character in a length limited string

<h2>Synopsis</h2>

<pre><code>char *strnchr(const char *s, size_t count, int c);</code></pre>

<h2>Arguments</h2>

<i>s</i>
<dl><dd><dd>The string to be searched</dl>
 

 <i>count</i>
<dl><dd>The number of characters to be searched</dl>
 

 <i>c</i>
<dl><dd>The character to search for</dl>
