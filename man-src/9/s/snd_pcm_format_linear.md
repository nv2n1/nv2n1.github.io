snd_pcm_format_linear - Check the PCM format is linear

<h2>Synopsis</h2>

<pre><code>int snd_pcm_format_linear(snd_pcm_format_t format);</code></pre>

<h2>Arguments</h2>

<i>format</i>
<dl><dd><dd>the format to check</dl>

<h2>Return</h2>

1 if the given PCM format is linear, 0 if not.
