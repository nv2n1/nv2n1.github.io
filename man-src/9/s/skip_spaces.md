skip_spaces - Removes leading whitespace from <i>str</i>.

<h2>Synopsis</h2>

<pre><code>char *skip_spaces(const char *str);</code></pre>

<h2>Arguments</h2>

<i>str</i>
<dl><dd><dd>The string to be stripped.</dl>

<h2>Description</h2>

Returns a pointer to the first non-whitespace character in <i>str</i>.
