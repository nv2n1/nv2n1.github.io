strreplace - Replace all occurrences of character in string.

<h2>Synopsis</h2>

<pre><code>char *strreplace(char *s, char old, char new);</code></pre>

<h2>Arguments</h2>

<i>s</i>
<dl><dd><dd>The string to operate on.</dl>
 

 <i>old</i>
<dl><dd>The character being replaced.</dl>
 

 <i>new</i>
<dl><dd>The character <i>old</i> is replaced with.</dl>

<h2>Description</h2>

Returns pointer to the nul byte at the end of <i>s</i>.
