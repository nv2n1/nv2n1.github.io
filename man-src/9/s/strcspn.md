strcspn - Calculate the length of the initial substring of <i>s</i> which does not contain letters in <i>reject</i>

<h2>Synopsis</h2>

<pre><code>size_t strcspn(const char *s, const char *reject);</code></pre>

<h2>Arguments</h2>

<i>s</i>
<dl><dd><dd>The string to be searched</dl>
 

 <i>reject</i>
<dl><dd>The string to avoid</dl>
