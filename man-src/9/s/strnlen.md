strnlen - Find the length of a length-limited string

<h2>Synopsis</h2>

<pre><code>size_t strnlen(const char *s, size_t count);</code></pre>

<h2>Arguments</h2>

<i>s</i>
<dl><dd><dd>The string to be sized</dl>
 

 <i>count</i>
<dl><dd>The maximum number of bytes to search</dl>
