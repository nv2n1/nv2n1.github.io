<p>i740 &#8211; Intel i740 video driver</p>
<h2>Synopsis</h2>
<pre><code>Section N'34'DeviceN'34'</code>
<code> Identifier N'34'</code><i>devname</i><code>N'34'</code>
<code> Driver N'34'i740N'34'</code>
&nbsp;<wbr>&nbsp;<wbr>...
<code>EndSection</code></pre>
<h2>Description</h2>
<p><code>i740</code> is an Xorg driver for Intel i740 video cards.</p>
<h2>Supported Hardware</h2>
<p>The <code>i740</code> driver supports Intel 740 based cards. A list of cards reported to work is provided in the README file with the driver source.</p>
<h2>Configuration Details</h2>
<p>Please refer to <a href="/docs/linux/man/5-xorg-conf/">xorg.conf</a>(5) for general configuration details. This section only covers configuration details specific to this driver. </p>
<p> The driver auto-detects all device information necessary to initialize the card. </p>
<p> However, if you have problems with auto-detection, you can specify:</p>
<dl>
<dt><code>VideoRam</code><i> &#8211; in kilobytes</i></p>
<dd>
<dt><code>DacSpeed</code><i> &#8211; in MHz</i></p>
<dd>
<dt><code>MemBase</code><i> &#8211; physical address of the linear framebuffer</i></p>
<dd>
<dt><code>IOBase</code><i> &#8211; physical address of the memory mapped IO registers</i></p>
<dd></dl>
<p> The following driver <code>options</code> are supported on all chipsets:</p>
<dl>
<dt><code>Option N&#8217;34&#8217;NoAccelN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Disable or enable 2D acceleration. Default: acceleration is enabled.</p>
<dt><code>Option N&#8217;34&#8217;SWCursorN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Request a software cursor (hardware is default). Default: off</p>
<dt><code>Option N&#8217;34&#8217;SDRAMN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Force the use of SDRAM timings. Default: off</p>
<dt><code>Option N&#8217;34&#8217;SGRAMN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Force the use of SGRAM timings. Default: off</p>
<dt><code>Option N&#8217;34&#8217;SlowRamN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Force the use of slower ram timings. Default: off</p>
<dt><code>Option N&#8217;34&#8217;Dac6BitN&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Force the use of a 6 Bit Dac (8 Bit is the default). Default: off</p>
<dt><code>Option N&#8217;34&#8217;UsePION&#8217;34&#8217; N&#8217;34&#8217;</code><i>boolean</i><code>N&#8217;34&#8217;</code></p>
<dd>Force the use of programmed IO (Memory mapped is the default). Default: off</dl>
<p> Note: the i740 X server should automatically detect whether your card has SGRAM or SDRAM. Use the N&#8217;34&#8217;sgramN&#8217;34&#8217; and N&#8217;34&#8217;sdramN&#8217;34&#8217; options if it is incorrectly detected.</p>
