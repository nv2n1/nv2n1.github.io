<p>NCAR Graphics environment variables</p>
<h2>Synopsis</h2>
<p>What follows is an alphabetical list of all the NCAR Graphics environment variables and what they mean. <code>NCARG_BIN</code>, if set, indicates where the NCAR Graphics binaries are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/bin). <code>NCARG_CONFIG</code>, if set, indicates where the NCAR Graphics configuration files are installed (these are needed by site installers only). This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/config). <code>NCARG_DATA</code>, if set, indicates where the NCAR Graphics example data files are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/data). <code>NCARG_DATABASE</code>, if set, indicates where the NCAR Graphics database files are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/database). <code>NCARG_DOC</code>, if set, indicates where the NCAR Graphics PostScript documentation is installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/doc). <code>NCARG_EXAMPLES</code>, if set, indicates where some of the NCAR Graphics examples are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/examples). <code>NCARG_FONTCAP</code>, if set, indicates the default NCAR Graphics fontcap to be used. <code>NCARG_FONTCAPS</code>, if set, indicates where the NCAR Graphics fontcaps are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/fontcaps). <code>NCARG_GKS_BUFSIZE</code> provides you with control over how CGM output is buffered. <code>NCARG_GKS_DEBUG</code>, if set, will result in debugging information about the GKS I/O subsystem being output to stdout. <code>NCARG_GKS_GENCGM</code> allows you to request that the NCAR GKS package generate binary encoded CGM rather than NCGM (the NCAR private encoding of binary encoded CGM). <code>NCARG_GKS_OUTPUT</code> allows you to specify what file or process CGM output is directed to. <code>NCARG_GKS_PSOUTPUT</code> allows you to specify what file any PostScript output from NCAR GKS is directed to (stdout is allowed). <code>NCARG_GKS_PDFOUTPUT</code> allows you to specify what file any PDF output from NCAR GKS is directed to (stdout is allowed). <code>NCARG_GRAPHCAP</code>, if set, indicates the default NCAR Graphics graphcap to be used. <code>NCARG_GRAPHCAPS</code>, if set, indicates where the NCAR Graphics graphcaps are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/graphcaps). <code>NCARG_HLUEX</code>, if set, indicates where the NCAR Graphics HLU examples are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/hluex). <code>NCARG_INCLUDE</code>, if set, indicates where the NCAR Graphics include files are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/include). <code>NCARG_LIB</code>, if set, indicates where the NCAR Graphics libraries are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib). <code>NCARG_MAN</code>, if set, indicates where the NCAR Graphics man pages are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/man). <code>NCARG_NCARG</code>, if set, indicates where the NCAR Graphics examples, databases, resource files, etc. are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg). <code>NCARG_NCLEX</code>, if set, indicates where the NCAR Graphics NCL examples are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/nclex). <code>NCARG_NGURL</code>, if set, indicates where the file that contains the URL to the NCAR Graphics documentation is installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/ngwww/ngurl). <code>NCARG_NGWWW</code>, if set, indicates where the NCAR Graphics HTML documentation is installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/ngwww). <code>NCARG_RESFILES</code>, if set, indicates where the NCAR Graphics resource files are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/resfiles). <code>NCARG_ROOT</code>, indicates the parent directory where all of the NCAR Graphics binaries, libraries, include files, man pages, examples, etc. are installed. This environment variable must be set by anybody who wants to run NCAR Graphics (or you can optionally set NCARG_LIB, NCARG_BIN, and NCARG_INCLUDE). <code>NCARG_SYSRESFILE</code>, if set, indicates where the NCAR Graphics system resource file is installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/sysappres). <code>NCARG_TESTS</code>, if set, indicates where the NCAR Graphics test examples are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/tests). <code>NCARG_TMP</code>, if set, indicates where NCAR Graphics temporary files should be written. <code>NCARG_TUTORIAL</code>, if set, indicates where the NCAR Graphics tutorial examples are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/tutorial). <code>NCARG_USRRESFILE</code>, if set, indicates where the NCAR Graphics user resource file is installed. This environment variable doesn&#8217;t need to be set unless you want to override the default (~/.hluresfile). <code>NCARG_XAPP</code>, if set, indicates where the NCAR Graphics X application default files are installed. This environment variable takes precedence over NCARG_ROOT and doesn&#8217;t need to be set unless you want to override the default ($NCARG_ROOT/lib/ncarg/xapp). </p>
