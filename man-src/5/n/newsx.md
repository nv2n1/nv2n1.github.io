<p>newsx.conf &#8211; newsx standard profile </p>
<h2>Description</h2>
<p><code>newsx.conf</code> is a profile file read by <i><a href="/docs/linux/man/8-newsx/">newsx</a></i>(8) before processing the command line arguments. It contains standard <i><a href="/docs/linux/man/8-newsx/">newsx</a></i>(8) command line options. The leading dashes for options are mandatory. Several lines may be used. Blank lines and lines starting with a &#8216;#&#8217; will be treated as comments. Note that it is also possible to have profile information for a specific newsspool. See <i><a href="/docs/linux/man/5-newsx-conf/">newsx.conf</a></i>(5). </p>
<h2>Files</h2>
<dl>
<dt>/usr/lib/news/newsx.conf</p>
