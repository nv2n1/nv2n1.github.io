<p>inittab &#8211; init daemon configuration</p>
<h2>Synopsis</h2>
<p><code>/etc/inittab</code></p>
<h2>Description</h2>
<p>The <i>/etc/inittab</i> file was the configuration file used by the original System V <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon. </p>
<p> The Upstart <code><a href="/docs/linux/man/8-init/">init</a></code>(8) daemon does not use this file, and instead reads its configuration from files in <i>/etc/init</i>. See <code><a href="/docs/linux/man/5-init/">init</a></code>(5) for more details.</p>
