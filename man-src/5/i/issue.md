<p>issue &#8211; prelogin message and identification file</p>
<h2>Description</h2>
<p><i>/etc/issue</i> is a text file which contains a message or system identification to be printed before the login prompt. It may contain various <code>@</code><i>char</i> and <code>\</code><i>char</i> sequences, if supported by the <code>getty</code>-type program employed on the system.</p>
<h2>Files</h2>
<p><i>/etc/issue</i></p>
