info - readable online documentation

<h2>Description</h2>

The Info file format is an easily-parsable representation for online documents. It can be read by <i><a HREF="/docs/linux/man/1-emacs/">emacs</a>(1)</i> and <i><a HREF="/docs/linux/man/1-info/">info</a>(1)</i> among other programs. 

 Info files are usually created from <i><a HREF="/docs/linux/man/5-texinfo/">texinfo</a>(5)</i> sources by <i><a HREF="/docs/linux/man/1-makeinfo/">makeinfo</a>(1)</i>, but can be created from scratch if so desired. 

 For a full description of the Texinfo language and associated tools, please see the Texinfo manual (written in Texinfo itself). Most likely, running this command from your shell: <pre>info texinfo</pre>or this key sequence from inside Emacs: <pre>M-x info RET m texinfo RET</pre>will get you there.
