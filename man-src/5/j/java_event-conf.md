<p>java_event.conf &#8211; configuration file for libreport.</p>
<h2>Description</h2>
<p>This configuration file provides definitions of events for Java exception. </p>
<p> By default the file contains definition for <i>post-create</i> and <i>report-gui</i> events.</p>
