<p>bitlbee.conf &#8211; configuration file for <code></p>
<p><a href="/docs/linux/man/8-bitlbee/">bitlbee</a></code>(8)</p>
<h2>Description</h2>
<p>This file contains system-wide settings for the <code><a href="/docs/linux/man/8-bitlbee/">bitlbee</a></code>(8) program. For more information about the file syntax, please read the example configuration file which comes with the program. The default file contains lots of comments which explain all the available options.</p>
