<p>tn5250rc &#8211; tn5250 and lp5250d configuration file</p>
<h2>Description</h2>
<p>The <code>tn5250rc</code> file contains groups of options for <code>tn5250</code> and <code>lp5250d</code>. When a hostname is passed to one of these programs, the named group is looked up in <code>tn5250rc</code>, and any options given in that group are processed. If a named group is found, and defines a <code>host</code> option, that option specifies the server. Otherwise, the host parameter to the program is used. A group of options looks like this: </p>
<pre><code>groupname {
    +boolean
    option=value
    ...

}</code></pre>
<p> Each group of options starts with the group name, followed by a left brace (curly bracket) character. Following lines should have one option on each line. The last line of the group has a single right brace. The global <code>tn5250rc</code> file may be overridden by the user&#8217;s <code>~/.tn5250rc</code> file.</p>
<h2>Options</h2>
<p>The options given here may be used inside a section of the configuration file, or on the <code>tn5250</code> or <code>lp5250d</code> command line. Most options take the form <i>OPTION</i>=<i>VALUE</i>. Options listed with a leading <code>+</code>/<code>&#8211;</code> can be either turned on (<i>+OPTION</i>) or off (<i>-OPTION</i>).</p>
<h3>Common Options</h3>
<p>These options apply to both printer and display emulation sessions.</p>
<dl>
<dt><code>host=</code><i>URL</i></p>
<dd>Set the host to connect to. The <i>URL</i> is of the form [<i>PROTOCOL</i>:]<i>HOSTNAME</i>[:<i>PORT</i>]. The default protocol, if not supplied, is <code>tn5250</code>. See <code>Protocols</code> below for descriptions of the available protocols.</p>
<dt><code>map=</code><i>CCSID</i></p>
<dd>Set the translation table between ASCII and EBCDIC. This should match the CCSID of the interactive job. The default is <code>37</code>. See <code>Translation Maps</code> below for more information.</p>
<dt><code>env.DEVNAME=</code><i>NAME</i></p>
<dd>Set the device name for the AS/400 to assign to the 5250 session. This should be up to ten characters long and consist of only letters and numbers. It will be converted to uppercase and used as the name of the 5250-compatible device on the AS/400. There may only be one session active with any given name at one time.</p>
<dt><code>trace=</code><i>TRACEFILE</i></p>
<dd>Log all actions to <i>TRACEFILE</i>. This file will get very large, and may contain sensitive information such as the password used to log in.</p>
<dt><code>+</code>/<code>-ssl_verify_server</code></p>
<dd>If set, then verify that the server&#8217;s certificate was issued by a CA in the file given by the <code>ssl_ca_file</code> option. If the certificate&#8217;s issuer cannot be verified, do not connect to the server.</p>
<dt><code>ssl_ca_file=</code><i>CAFILE</i></p>
<dd>Specify the file containing the certificate for the CA that issued the server&#8217;s certificate. If the server certificate is self-signed, <i>CAFILE</i> should contain the certificate displayed by the <code>Digital Certificate Manager</code> option <i>Copy and paste certificate</i>.</p>
<dt><code>ssl_cert_file=</code><i>CERTFILE</i></p>
<dd>Specify the file containing the personal certificate, in PEM format. This must be a certificate associated with your user profile on the AS/400 by <code>DCM</code>.</p>
<dt><code>ssl_pem_pass=</code><i>PASSWORD</i></p>
<dd>If the personal certificate given by <code>ssl_cert_file</code> is password protected, the password may be given here to bypass the password prompt.</dl>
<h3>Display Options</h3>
<p>These options are specific to <code>tn5250</code> and <code>xt5250</code>.</p>
<dl>
<dt><code>+</code>/<code>-underscores</code></p>
<dd>Force or disable the use of underscore characters instead of the underline attribute, for terminals that do not support underlining but where <code>tn5250</code> does not work this out itself.</p>
<dt><code>+</code>/<code>-ruler</code></p>
<dd>Turn the ruler feature on or off. When enabled, the row and column of the cursor will be highlighted.</p>
<dt><code>env.TERM=</code><i>MODEL</i></p>
<dd>Set the terminal model name for the emulation session to use. The default depends on whether the terminal supports colour, and whether it is large enough to support the large terminal size. See <code>Display Types</code> below for valid model names.</p>
<dd>The default model emulated is an <code>IBM-3179-2</code>, a 24&#215;80 colour terminal.</p>
<dt><code>font_80=</code><i>FONT</i></p>
<dd>If <code>tn5250</code> is running in an xterm, sets the font to change to when the terminal is in 80 column mode. This should be a valid X font name, such as can be chosen with <code>xfontsel</code>.</p>
<dt><code>font_132=</code><i>FONT</i></p>
<dd>If the emulated terminal has a size of 27&#215;132, set the font to use in 132 column mode, as for the <code>font_80</code> option.</p>
<dt><code>beep_command=</code><i>COMMAND</i></p>
<dd>If present, will run the supplied command instead of using the terminal beep.</p>
<dt><code>+</code>/<code>-uninhibited</code></p>
<dd>If enabled, automatically resets the input inhibited state when cursor movement keys or function keys are pressed. The default is disabled.</p>
<dt><code>env.</code><i>VARIABLE</i><code>=</code><i>VALUE</i></p>
<dd>Set any other environment variables controlling the terminal session. A list of relevant variables is given in section 5 of <code>RFC2877</code>.</dl>
<h3>Printer Options</h3>
<dl>
<dt><code>outputcommand=</code><i>COMMAND</i></p>
<dd>Set the command that will be run to receive printer output. The default command is `<code>scs2ascii |lpr</code>&#8216;.</p>
<dt><code>env.IBMMFRTYPMDL=</code><i>NAME</i></p>
<dd>Set the name of the host print transform description to use on the AS/400. This is the same as the MFRTYPMDL parameter on the CRTDEVPRT command. See the CL Reference or the online help for a list of valid values.</p>
<dt><code>env.</code><i>VARIABLE</i><code>=</code><i>VALUE</i></p>
<dd>Set any other environment variables controlling the printer session. A list of relevant variables is given in section 7 of <code>RFC2877</code>. More generally, the variables are the parameters of the <code>CRTDEVPRT</code> command, with a prefix of <code>IBM</code>.</dl>
<h2>Option Values</h2>
<h3>Protocols</h3>
<p>The supported protocols for the emulation session are listed below.</p>
<dl>
<dt><code>telnet</code></p>
<dd>Connect to the AS/400 using a normal unencrypted telnet connection. <code>tn5250</code> is an alias for <code>telnet</code>.</p>
<dt><code>ssl</code></p>
<dd>Connect securely using an encrypted SSL session. This option is only available if <code>tn5250</code> was compiled with SSL support.</p>
<dt><code>debug</code></p>
<dd>Instead of connecting to a server, replay the trace generated by the <code>trace</code> option. The path to the trace file should be given instead of the hostname.</dl>

<h2>Examples</h2>
<p>Define a connection named <code>dsp01</code> that connects to the machine <code>iseries.example.com</code>, using the German CCSID, a 132 column terminal, and printing underscore characters instead of using underlines. secure01 {<br />
    host = iseries.example.com<br />
    +ssl_verify_server<br />
    ssl_ca_file = cacert.pem<br />
    ssl_cert_file = jbloggs.pem</p>
<p>} Define a printer connection, using host print transform to produce PCL output for an HP Laserjet compatible printer. secure01 {<br />
    host = iseries.example.com<br />
    +ssl_verify_server<br />
    ssl_ca_file = cacert.pem<br />
    ssl_cert_file = jbloggs.pem</p>
<p>} Define a secure SSL session, checking the server&#8217;s certificate against the CA certificare stored in <code>cacert.pem</code>, and using the client certificate in <code>jbloggs.pem</code> to sign on automatically. </p>
<pre><code>secure01 {
    host = iseries.example.com
    +ssl_verify_server
    ssl_ca_file = cacert.pem
    ssl_cert_file = jbloggs.pem

}</code></pre>
