fontcap - A list of supported NCAR Graphics font definition files for use with ctrans and Plotchar.

<h2>Description</h2>

<i>font1</i> A very simple ASCII font. 

 <i>font2</i> Character fontcap for: HERSHEY:CARTOGRAPHIC_ROMAN 

 <i>font3</i> Character fontcap for: HERSHEY:CARTOGRAPHIC_GREEK 

 <i>font4</i> Character fontcap for: HERSHEY:SIMPLEX_ROMAN 

 <i>font5</i> Character fontcap for: HERSHEY:SIMPLEX_GREEK 

 <i>font6</i> Character fontcap for: HERSHEY:SIMPLEX_SCRIPT 

 <i>font7</i> Character fontcap for: HERSHEY:COMPLEX_ROMAN 

 <i>font8</i> Character fontcap for: HERSHEY:COMPLEX_GREEK 

 <i>font9</i> Character fontcap for: HERSHEY:COMPLEX_SCRIPT 

 <i>font10</i> Character fontcap for: HERSHEY:COMPLEX_ITALIC 

 <i>font11</i> Character fontcap for: HERSHEY:COMPLEX_CYRILLIC 

 <i>font12</i> Character fontcap for: HERSHEY:DUPLEX_ROMAN 

 <i>font13</i> Character fontcap for: HERSHEY:TRIPLEX_ROMAN 

 <i>font14</i> Character fontcap for: HERSHEY:TRIPLEX_ITALIC 

 <i>font15</i> Character fontcap for: HERSHEY:GOTHIC_GERMAN 

 <i>font16</i> Character fontcap for: HERSHEY:GOTHIC_ENGLISH 

 <i>font17</i> Character fontcap for: HERSHEY:GOTHIC_ITALIAN 

 <i>font18</i> Character fontcap for: HERSHEY:MATH_SYMBOLS 

 <i>font19</i> Character fontcap for: HERSHEY:SYMBOL_SET1 

 <i>font20</i> Character fontcap for: HERSHEY:SYMBOL_SET2 

 <i>font21</i> Character fontcap for: NCAR:HELVETICA (filled font for Plotchar) 

 <i>font22</i> Character fontcap for: NCAR:HELVETICA-BOLD (filled font for Plotchar) 

 <i>font25</i> Character fontcap for: NCAR:TIMES-ROMAN (filled font for Plotchar) 

 <i>font26</i> Character fontcap for: NCAR:TIMES-BOLD (filled font for Plotchar) 

 <i>font29</i> Character fontcap for: NCAR:COURIER (filled font for Plotchar) 

 <i>font30</i> Character fontcap for: NCAR:COURIER-BOLD (filled font for Plotchar) 

 <i>font33</i> Character fontcap for: NCAR:GREEK (filled font for Plotchar) 

 <i>font34</i> Character fontcap for: NCAR:MATH-SYMBOLS (filled font for Plotchar) 

 <i>font35</i> Character fontcap for: NCAR:TEXT-SYMBOLS (filled font for Plotchar) 

 <i>font36</i> Character fontcap for: NCAR:WEATHER1 (filled font for Plotchar) 

 <i>font37</i> Character fontcap for: NCAR:WEATHER2 (filled font for Plotchar) 

 For ctrans, it is possible to set the desired font using the <i>FONTCAP</i> environment variable.
