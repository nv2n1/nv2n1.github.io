<p>fzdefaults.xml &#8211; Default options for FileZilla</p>
<h2>Synopsis</h2>
<p><code>/etc/filezilla/fzdefaults.xml</code><br />
 <code>~/.filezilla/fzdefaults.xml</code></p>
<h2>Description</h2>
<p>This configuration file can be used to specify some system-wide default options for FileZilla:</p>
<dl>
<dt>*</p>
<dd>Location of user&#8217;s settings directory</p>
<dt>*</p>
<dd>Predefined list of Sitemanager entries</p>
<dt>*</p>
<dd>Kiosk mode to prevent FileZilla from saving any passwords</p>
<dt>*</p>
<dd>Disabling of update check capablity Please search for the file <code>fzdefaults.xml.example</code> for further information. It is often found in the /usr/share/filezilla/docs directory.</dl>
