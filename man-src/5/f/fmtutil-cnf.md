<p>fmtutil.cnf &#8211; configuration file for fmtutil </p>
<h2>Description</h2>
<p>The <i>fmtutil.cnf</i> file contains the configuration information for <code><a href="/docs/linux/man/8-fmtutil/">fmtutil</a></code>(8). Each line contains the name of the format (e.g., &#8220;tex&#8221;, &#8220;latex&#8221;, &#8220;omega&#8221;), the name of the engine that is used by that format (e.g., &#8220;tex&#8221;, &#8220;etex&#8221;, &#8220;omega&#8221;), the pattern file (e.g., <i>language.dat</i>, <i>language.def</i>), and any arguments (name of an <i>.ini</i> file). Fields are separated by whitespace and complete lines can be commented out with &#8220;#&#8221;. The &#8220;pattern file&#8221; field cannot be used to define a file that is used while building the format. It tells <code>fmtutil</code> which files (separated by commas) the format creation procedure reads and it has an effect to the options <i>&#8211;showhyphen</i> and <i>&#8211;byhyphen</i>. If the format has no way to customize hyphenation, a &#8220;-&#8221; can be used to indicate this. </p>
<h2>Notes</h2>
<p>The <code><a href="/docs/linux/man/1-tex/">tex</a></code>(1) and <code><a href="/docs/linux/man/1-amstex/">amstex</a></code>(1) formats always load <i>hyphen.tex</i>. No customization by a pattern file is available for these formats. Therefore, the pattern-file field for the <code>tex</code> and <code>amstex</code> is usually indicated to be empty (&#8220;-&#8221;). You can, however, build customized formats on top of plain <code><a href="/docs/linux/man/1-tex/">tex</a></code>(1) or <code><a href="/docs/linux/man/1-amstex/">amstex</a></code>(1) by using <i>bplain.tex</i> instead of <i>plain.tex</i> (b for the <i>Babel</i> system). See, for example, the <i>bplain.ini</i> file for the bplain format). <code><a href="/docs/linux/man/1-etex/">etex</a></code>(1) loads <i>language.def</i>, not <i>language.dat</i>. Symbolic links to the correct engines (e.g., bplain -&gt; tex) are generated by the <code><a href="/docs/linux/man/8-texlinks/">texlinks</a></code>(8) script. Remember to run <code><a href="/docs/linux/man/8-texlinks/">texlinks</a></code>(8) if you run <code><a href="/docs/linux/man/8-fmtutil/">fmtutil</a></code>(8) yourself, rather than using the FORMATS option in <code><a href="/docs/linux/man/8-texconfig/">texconfig</a></code>(8). </p>
