<p>fb.modes &#8211; frame buffer modes file</p>
<h2>Description</h2>
<p><i>/etc/fb.modes</i> contains an unlimited number of video mode descriptions. The general format of a video mode is: </p>
<p> mode</p>
<dl>
<dd>geometry &lt;<i>xres</i>&gt; &lt;<i>yres</i>&gt; &lt;<i>vxres</i>&gt; &lt;<i>vyres</i>&gt; &lt;<i>depth</i>&gt;<br />
 timings &lt;<i>pixclock</i>&gt; &lt;<i>left</i>&gt; &lt;<i>right</i>&gt; &lt;<i>upper</i>&gt; &lt;<i>lower</i>&gt; &lt;<i>hslen</i>&gt; &lt;<i>vslen</i>&gt;<br />
 <code>options</code> &lt;<i>value</i>&gt;</dl>
<p> endmode</p>
<h2>Options</h2>
<p>geometry options:</p>
<dl>
<dd>
<dl>
<dt><i>xres</i></p>
<dd>visible horizontal resolution (in pixels)</p>
<dt><i>yres</i></p>
<dd>visible vertical resolution (in pixels)</p>
<dt><i>vxres</i></p>
<dd>virtual horizontal resolution (in pixels)</p>
<dt><i>vyres</i></p>
<dd>virtual vertical resolution (in pixels)</p>
<dt><i>depth</i></p>
<dd>display depth (in bits per pixel)</dl>
</dl>
<p> timing options:</p>
<dl>
<dd>
<dl>
<dt><i>pixclock</i></p>
<dd>length of one pixel (in picoseconds)</p>
<dt><i>left</i></p>
<dd>left margin (in pixels)</p>
<dt><i>right</i></p>
<dd>right margin (in pixels)</p>
<dt><i>upper</i></p>
<dd>upper margin (in pixel lines)</p>
<dt><i>lower</i></p>
<dd>lower margin (in pixel lines)</p>
<dt><i>hslen</i></p>
<dd>horizontal sync length (in pixels)</p>
<dt><i>vslen</i></p>
<dd>vertical sync length (in pixel lines)</dl>
</dl>
<p> other options:</p>
<dl>
<dd>the first value of this options is the default</p>
<dl>
<dt><i></i><code>hsync</code>&nbsp;<wbr>{<i>low</i>|<i>high</i>}</p>
<dd>the horizontal sync polarity</p>
<dt><i></i><code>vsync</code>&nbsp;<wbr>{<i>low</i>|<i>high</i>}</p>
<dd>the vertical sync polarity</p>
<dt><i></i><code>csync</code>&nbsp;<wbr>{<i>low</i>|<i>high</i>}</p>
<dd>the composite sync polarity</p>
<dt><i></i><code>extsync</code>&nbsp;<wbr>{<i>false</i>|<i>true</i>}</p>
<dd>enable or disable external resync. If enabled the sync timings are not generated by the frame buffer device and must be provided externally instead. Note that this option may not be supported by every frame buffer device</p>
<dt><i></i><code>laced</code>&nbsp;<wbr>{<i>false</i>|<i>true</i>}</p>
<dd>enable or disable interlace. If enabled the display will be split in two frames, each frame contains only even and odd lines respectively. These two frames will be displayed alternating, this way twice the lines can be displayed and the vertical frequency for monitor stays the same, but the visible vertical frequency gets halved</p>
<dt><i></i><code>double</code>&nbsp;<wbr>{<i>false</i>|<i>true</i>}</p>
<dd>enable or disable doublescan. If enabled every line will be displayed twice and this way the horizontal frequency can easily be doubled, so that the same resolution can be displayed on different monitors, even if the horizontal frequency specification differs. Note that this option may not be supported by every frame buffer device</dl>
</dl>

<p> The area bordered with `#&#8217; is the visible display area. Horizontal and vertical frequencies can now easily be calculated, for this the sum of horizontal or vertical values are important</p>
<dl>
<dd>htotal&nbsp;<wbr>=&nbsp;<wbr>left&nbsp;<wbr>+&nbsp;<wbr>xres&nbsp;<wbr>+&nbsp;<wbr>right&nbsp;<wbr>+&nbsp;<wbr>hslen<br />
 vtotal&nbsp;<wbr>=&nbsp;<wbr>upper&nbsp;<wbr>+&nbsp;<wbr>yres&nbsp;<wbr>+&nbsp;<wbr>lower&nbsp;<wbr>+&nbsp;<wbr>vslen </p>
</dl>
<p> The length of one line can now be calculated with pixclock</p>
<dl>
<dd>line&nbsp;<wbr>=&nbsp;<wbr>pixclock&nbsp;<wbr>*&nbsp;<wbr>htotal </p>
</dl>
<p> and we have the horizontal frequency</p>
<dl>
<dd>hfreq&nbsp;<wbr>=&nbsp;<wbr>1E12&nbsp;<wbr>/&nbsp;<wbr>line&nbsp;<wbr>=&nbsp;<wbr>1E12&nbsp;<wbr>/&nbsp;<wbr>(pixclock&nbsp;<wbr>*&nbsp;<wbr>htotal) </p>
</dl>
<p> To get the vertical frequency vtotal must eventually adjusted. If the display is laced, vtotal must be halved or if the display is a doublescan one, vtotal must be doubled. Now we can calculate the length of one frame</p>
<dl>
<dd>if&nbsp;<wbr>(lace)&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>vtotal&nbsp;<wbr>/=&nbsp;<wbr>2<br />
 if&nbsp;<wbr>(double)&nbsp;<wbr>vtotal&nbsp;<wbr>*=&nbsp;<wbr>2 </p>
<p> frame&nbsp;<wbr>=&nbsp;<wbr>vtotal&nbsp;<wbr>*&nbsp;<wbr>line </p>
</dl>
<p> and we get also the vertical frequency</p>
<dl>
<dd>vfreq&nbsp;<wbr>=&nbsp;<wbr>1E12&nbsp;<wbr>/&nbsp;<wbr>frame&nbsp;<wbr>=&nbsp;<wbr>hfreq&nbsp;<wbr>/&nbsp;<wbr>vtotal </p>
</dl>
