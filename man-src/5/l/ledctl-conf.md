ledctl.conf - Configuration file for Intel(R) Enclosure LED Utilities.

<h2>Description</h2>

This feature is not yet implemented. The Intel(R) Enclosure <font SIZE="-1">LED</font> Utilities does not use a configuration file at the moment. The name and location of file has been reserved for feature improvements.
