<p>locale.gen &#8211; Configuration file for locale-gen</p>
<h2>Description</h2>
<p>The file <code>/etc/locale.gen</code> lists the locales that are to be generated by the <code>locale-gen</code> command. Each line is of the form: </p>
<pre><code>&lt;locale&gt; &lt;charset&gt;</code></pre>
<p> where &lt;locale&gt; is one of the locales given in <code>/usr/share/i18n/locales</code> and &lt;charset&gt; is one of the character sets listed in <code>/usr/share/i18n/charmaps</code> The <code>locale-gen</code> command will generate all the locales, placing them in <code>/usr/lib/locale</code>. </p>
