<p><code>dovecot.conf</code> &#8211; The configuration file for dovecot imap and pop3 server </p>
<h2>Full Path</h2>
<p><code>/etc/dovecot.conf</code></p>
<h2>Description</h2>
<p>The dovecot.conf file is a configuration file for the <code><a href="/docs/linux/man/1-dovecot/">dovecot</a></code>(1) imap and pop3 server. The dovecot.conf configuration file contains description to all available options. Some of these options are described also in offline wiki documentation placed in /usr/share/doc/dovecot*/wiki/. For backup purposes unmodified version of dovecot.conf can be found in /usr/share/doc/dovecot-&lt;version&gt;/example-config/dovecot.conf.default </p>
