<p>redis.conf, sentinel.conf &#8211; redis server configuration files. </p>
<h2>Parameters</h2>
<dl>
<dt>All empty lines or lines beginning with &#8216;#&#8217; are ignored.</p>
<dd>
<dt>See inline comments for parameters description.</p>
<dd></dl>
<h2>Description</h2>
<dl>
<dt><code>redis-server</code> read the configuration file passed as first argument.</p>
<dd>
