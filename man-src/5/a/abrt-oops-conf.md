abrt-oops.conf - Configuration file for ABRT's Kernel Oops extractor

<h2>Description</h2>

The configuration file consists of items in the format &quot;Option = Value&quot;. The following items are recognized: 

 OnlyFatalMCE = <i>yes</i> / <i>no</i> If you want to see only fatal MCEs, set to &quot;yes&quot;. Defaults is <i>yes</i>: detect only fatal ones.
