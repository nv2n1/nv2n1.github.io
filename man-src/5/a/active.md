<p>active &#8211; List of newsgroups carried by the server</p>
<h2>Description</h2>
<p>The file <i>pathdb</i>/active lists the newsgroups carried by <font SIZE="-1">INN</font>. This file is generally maintained using <i><a href="/docs/linux/man/8-ctlinnd/">ctlinnd</a></i>(8) to create and remove groups, or by letting <i><a href="/docs/linux/man/8-controlchan/">controlchan</a></i>(8) do so on the basis of received control messages; this file is then updated and a backup stored in <i>pathdb</i>/active.old. Note that the <i><a href="/docs/linux/man/5-newsgroups/">newsgroups</a></i>(5) file normally contains the descriptions of the newsgroups carried by the news server. The <i>active</i> file should not be edited directly without throttling <code>innd</code>, and must be reloaded using <code>ctlinnd</code> before <code>innd</code> is unthrottled. Editing it directly even with those precautions may make it inconsistent with the overview database and won&#8217;t update <i>active.times</i>, so <code>ctlinnd</code> should be used to make modifications whenever possible. Each newsgroup should be listed only once. Each line specifies one group. The order of groups does not matter. Within each newsgroup, received articles for that group are assigned monotonically increasing numbers as unique names. If an article is posted to newsgroups not mentioned in this file, those newsgroups are ignored. If none of the newsgroups listed in the Newsgroups: header of an article are present in this file, the article is either rejected (if <i>wanttrash</i> is false in <i>inn.conf</i>), or is filed into the newsgroup <tt>&quot;junk&quot;</tt> and, when <tt>&quot;Aj&quot;</tt> is not set in the <i>newsfeeds</i> feed pattern, only propagated to sites that receive the <tt>&quot;junk&quot;</tt> newsgroup (if <i>wanttrash</i> is true). Each line of this file consists of four fields separated by a space: </p>
<pre><code>&lt;name&gt; &lt;high&gt; &lt;low&gt; &lt;status&gt;</code></pre>
<p> The first field is the name of the newsgroup. The newsgroup <tt>&quot;junk&quot;</tt> is special, as mentioned above. The newsgroup <tt>&quot;control&quot;</tt> and any newsgroups beginning with <tt>&quot;control.&quot;</tt> are also special; control messages are filed into a control.* newsgroup named after the type of control message if that group exists, and otherwise are filed into the newsgroup <tt>&quot;control&quot;</tt> (without regard to what newsgroups are listed in the Newsgroups: header). If <i>mergetogroups</i> is set to true in <i>inn.conf</i>, newsgroups that begin with <tt>&quot;to.&quot;</tt> are also treated specially; see <i><a href="/docs/linux/man/8-innd/">innd</a></i>(8). The second field is the highest article number that has been used in that newsgroup. The third field is the lowest article number in the group; this number is not guaranteed to be accurate, and should only be taken to be a hint. It is normally updated nightly as part of the expire process; see <i><a href="/docs/linux/man/8-news-daily/">news.daily</a></i>(8) and look for <tt>&quot;lowmark&quot;</tt> or <tt>&quot;renumber&quot;</tt> for more details. Note that because of article cancellations, there may be gaps in the numbering sequence. If the lowest article number is greater than the highest article number, then there are no articles in the newsgroup. In order to make it possible to update an entry in-place without rewriting the entire file, the second and third fields are padded out with leading zeros to make them a fixed width. The fourth field contains one of the following status: </p>
<pre> y Local postings and articles from peers are allowed.
 m The group is moderated and all postings must be approved.
 n No local postings are allowed, only articles from peers.
 j Articles from peers are filed in the junk group instead.
 x No local postings, and articles from peers are ignored.
 =foo.bar Articles are filed in the group foo.bar instead.</pre>
<p>If a newsgroup has the <tt>&quot;j&quot;</tt> status, no articles will be filed in that newsgroup. Local postings are not accepted; if an article for that newsgroup is received from a remote site, and if it is not crossposted to some other valid group, it will be filed into the <tt>&quot;junk&quot;</tt> newsgroup instead. This is different than simply not listing the group, since the article will still be accepted and can be propagated to other sites, and the <tt>&quot;junk&quot;</tt> group can be made available to readers if wished. If the &lt;status&gt; field begins with an equal sign, the newsgroup is an alias. Articles cannot be posted to that newsgroup, but they can be received from other sites. Any articles received from peers for that newsgroup are treated as if they were actually posted to the group named after the equal sign. Note that the Newsgroups: header of the articles is not modified. (Alias groups are typically used during a transition and are typically created manually with <i><a href="/docs/linux/man/8-ctlinnd/">ctlinnd</a></i>(8).) An alias should not point to another alias. Note that <i>readers.conf</i> can be configured so that local posts to newsgroups with status <tt>&quot;j&quot;</tt>, <tt>&quot;n&quot;</tt> or <tt>&quot;x&quot;</tt> are accepted.</p>
<h2>Minimal Active File</h2>
<p>For <code>innd</code> to be able to start, the three groups <tt>&quot;control&quot;</tt>, <tt>&quot;control.cancel&quot;</tt> and <tt>&quot;junk&quot;</tt> need to be in the <i>active</i> file. Besides, if <i>mergetogroups</i> is set to true in <i>inn.conf</i>, the newsgroup <tt>&quot;to&quot;</tt> also needs to exist. </p>
<p> The minimal <i>active</i> file shipped with <font SIZE="-1">INN</font> is: </p>
<pre> control 0000000000 0000000001 n
 control.cancel 0000000000 0000000001 n
 control.checkgroups 0000000000 0000000001 n
 control.newgroup 0000000000 0000000001 n
 control.rmgroup 0000000000 0000000001 n
 junk 0000000000 0000000001 n</pre>
<p>(Note that the second and the third field may differ if the news server has already been in use.) </p>
<p> There are more control.* pseudogroups here than needed by <code>innd</code> to start; the corresponding control messages will be filed into them. The <tt>&quot;n&quot;</tt> status is so that users cannot post directly to these groups (control messages should only be posted to the groups that they affect). If you do not want these groups to be visible to clients, do not delete them but simply hide them in <i><a href="/docs/linux/man/5-readers-conf/">readers.conf</a></i>(5). </p>
<p> To create additional groups after the server is running, you can use <tt>&quot;ctlinnd newgroup&quot;</tt>. You can also synchronize your newsgroup list to that of another server by using <i><a href="/docs/linux/man/8-actsync/">actsync</a></i>(8) or get the <i>active</i> file of another <font SIZE="-1">NNTP</font> server with <i><a href="/docs/linux/man/1-getlist/">getlist</a></i>(1). And do not forget to update your <i>newsgroups</i> file, which can be automatically done thanks to <code>docheckgroups</code> called with the <code>-u</code> flag.</p>
