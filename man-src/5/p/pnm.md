pnm - portable anymap file format

<h2>Description</h2>

The <i>pnm</i> programs operate on portable bitmaps, graymaps, and pixmaps, produced by the <i>pbm, pgm,</i> and <i>ppm</i> segments. There is no file format associated with <i>pnm</i> itself.
