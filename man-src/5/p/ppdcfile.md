<p>ppdcfile &#8211; cups ppd compiler source file format (deprecated)</p>
<h2>Description</h2>
<p>The CUPS PPD compiler reads meta files that contain descriptions of one or more PPD files to be generated by <code><a href="/docs/linux/man/1-ppdc/">ppdc</a></code>(1). This man page provides a quick reference to the supported keywords and should be used in conjunction with the online help for CUPS. The source file format is plain ASCII text that can be edited using your favorite text editor. Comments are supported using the C (/* &#8230; */) and C++ (// &#8230;) comment mechanisms. Printer driver information can be grouped and shared using curly braces ({ &#8230; }); PPD files are written when a close brace or end-of-file is seen and a PCFileName directive has been defined. </p>

<h2>Notes</h2>
<p>PPD files are deprecated and will no longer be supported in a future feature release of CUPS. Printers that do not support IPP can be supported using applications such as <code><a href="/docs/linux/man/1-ippeveprinter/">ippeveprinter</a></code>(1).</p>
