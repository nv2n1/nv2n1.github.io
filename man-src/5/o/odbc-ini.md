<p>/etc/odbc.ini, $HOME/.odbc.ini &#8211; unixODBC data sources configuration</p>
<h2>Description</h2>
<p><code>/etc/odbc.ini</code> is text configuration file for the system wide ODBC data sources (i. e. database connections). <code>$HOME/.odbc.ini</code> contains the configuration for user-specific data sources. </p>
