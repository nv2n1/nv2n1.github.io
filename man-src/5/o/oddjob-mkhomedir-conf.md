<p>oddjob-mkhomedir.conf &#8211; system message bus configuration for oddjob-mkhomedir</p>
<h2>Description</h2>
<p>The /etc/dbus-1/system.d/<i>oddjob-mkhomedir.conf</i> configuration file specifies D-Bus-level access controls for the <i>com.redhat.oddjob_mkhomedir</i> service, in particular which users can invoke methods provided by the service. For more information, please see the D-Bus documentation. </p>
