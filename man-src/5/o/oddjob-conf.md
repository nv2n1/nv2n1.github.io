<p>oddjob.conf &#8211; configuration for oddjob for the system message bus</p>
<h2>Description</h2>
<p>The /etc/dbus-1/system.d/<i>oddjob.conf</i> configuration file specifies D-Bus-level access controls for the <i>com.redhat.oddjob</i> service, in particular which users can invoke methods provided by the service. For more information, please see the D-Bus documentation. </p>
