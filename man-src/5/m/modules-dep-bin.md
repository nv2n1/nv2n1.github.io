<p>modules.dep, modules.dep.bin &#8211; Module dependency information</p>
<h2>Synopsis</h2>
<p>/lib/modules/modules.dep </p>
<p> /lib/modules/modules.dep.bin</p>
<h2>Description</h2>
<p>modules.dep.bin is a binary file generated by <code>depmod</code> listing the dependencies for every module in the directories under /lib/modules/<i>version</i>. It is used by kmod tools such as <code>modprobe</code> and libkmod. </p>
<p> Its text counterpart is located in the same directory with the name modules.dep. The text version is maintained only for easy of reading by humans and is in no way used by any kmod tool. </p>
<p> These files are not intended for editing or use by any additional utilities as their format is subject to change in the future. You should use the <code><a href="/docs/linux/man/8-modinfo/">modinfo</a></code>(8) command to obtain information about modules in a future proof and compatible fashion rather than touching these files.</p>
