<p>MGL &#8211; MathGL script.</p>
<h2>Description</h2>
<p><code>MGL</code> script is textual file which contain commands for making scientific graphics using MathGL library. Is is primarily designed for quick viewing or processing data files as well as produce high-quality plots as output. MGL support animation by defining special comments in file. </p>
<p> For a full description of MGL script language please see the MathGL manual.</p>
