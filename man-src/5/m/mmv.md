<p><code>mmv</code> &#8211; Memory Mapped Values for Performance Co-Pilot</p>
<h2>Synopsis</h2>
<p><i>$PCP_TMP_DIR/mmv/&lt;file&gt;</i></p>
<h2>Description</h2>
<p>The files in <i>$PCP_TMP_DIR/mmv</i> are generated by <i>mmv_stats_init</i>() function from <code>libpcp_mmv</code> library. There could be multiple files in this directory, each file representing a single source of the performance metrics. The metrics are harvested by the <i>mmv</i> PMDA which exports them to the rest of the Performance Co-Pilot infrastructure.</p>
