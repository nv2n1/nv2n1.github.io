<p> <code>mmv</code> - Memory Mapped Values for Performance Co-Pilot  </p>
<h2>SYNOPSIS</h2>
<p> <i>$PCP_TMP_DIR/mmv/&lt;file&gt;</i>  </p>
<h2>DESCRIPTION</h2>
<p> The files in <i>$PCP_TMP_DIR/mmv</i> are generated by <i>mmv_stats_init</i>() function from <code>libpcp_mmv</code> library. There could be multiple files in this directory, each file representing a single source of the performance metrics. The metrics are harvested by the <i>mmv</i> PMDA which exports them to the rest of the Performance Co-Pilot infrastructure.  </p>

<p>The generation numbers are timestamps at the time of file creation, and must match for the file to be considered by the MMV PMDA. </p>
<p>The flags can specify ways in which the client would like the MMV PMDA to behave &#8211; e.g. the MMV_FLAG_PROCESS flag specifies that only if the process identified by PID is currently running should those values be exported. </p>
<p>Finally, if set, the cluster identifier is a hint to the MMV PMDA as to what cluster should be used with this application when forming the individual metric identifiers. A performance metric identifier (see <i><a href="/docs/linux/man/3-PMDA/">PMDA</a></i>(3)) consists of the PMDA domain number, the cluster number, and the individual item numbers described in the Metrics section. </p>
