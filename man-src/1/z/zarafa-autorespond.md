<h2 class="name">NAME</h2>
<p> zarafa-autorespond &#8211; Vacation message response script. </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>zarafa-autorespond</code></dl>
<h2>DESCRIPTION</h2>
<dd>Script will be called by <code>zarafa-dagent</code> when the user enabled a vacation message. </p>
<p> This script should not be executed from the command line.</p>
