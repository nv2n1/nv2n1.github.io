<h2 class="name">NAME</h2>
<p> over &#8211; pretty print and scroll source code on terminal</p>
<h2>SYNOPSIS</h2>
<p> over [FILE]&#8230; </p>
<h2>DECRIPTION</h2>
<p> Pretty print source code in the FILEs. The language is guessed with the <code>states</code> program and <code>enscript</code> is used to do the formatting. The highlighting rules are defined in `/usr/share/enscript/hl/enscript.st&#8217;. </p>
<p> The FILEs are paged through <code>less</code> for more convenient display. </p>
<h2>FILES</h2>
<pre>
/usr/share/enscript/hl/enscript.st      rules for various languages
</pre>
