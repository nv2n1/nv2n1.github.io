<h2 class="name">NAME</h2>
<p> openpgpkey &#8211; Create and verify RFC-TBD OPENPGPKEY DNS records </p>
<h2>SYNTAX</h2>
<p> openpgpkey [<code>&#8211;fetch</code> | <code>&#8211;verify</code>] [<code>&#8211;insecure</code>] [<code>&#8211;resolv.conf /PATH/TO/RESOLV.CONF</code>] <i>user [at] domain</i> </p>
<p> openpgpkey [<code>&#8211;create</code>] [<code>&#8211;insecure</code>] [<code>&#8211;resolv.conf /PATH/TO/RESOLV.CONF</code>] [<code>&#8211;output {rfc,generic,both}</code>] [<code>&#8211;uid &lt;uid&gt;</code>] [<code>&#8211;keyid &lt;keyid&gt;</code>] <i>user [at] domain</i></p>
<h2>DESCRIPTION</h2>
<p> openpgpkey generates RFC-TBD OPENPGPKEY DNS records. To generate these records for older nameserver implementations that do not yet support the OPENPGPKEY record, specify <i>&#8211;output generic</i> to output the openpgpkey data in Generic Record (RFC-3597) format. Records are generated by taking all keys with the specified email address associated with it from the user&#8217;s local GnuPG keychain. </p>
<p> Verification of OPENPGPKEY records is done by comparing the keyid and fingerprint of the OPENPGPKEY obtained from DNS with the version in the local GnuPG keychain.</p>
<h2>OPTIONS</h2>
<p> <code>&#8211;fetch</code></p>
<dl>
<dt>
<dd> Fetch an OPENPGPKEY public key record from DNS</dl>
<p> <code>&#8211;create</code></p>
<dl>
<dt>
<dd> Create an OPENPGPKEY DNS record</dl>
<p> <code>&#8211;verify</code></p>
<dl>
<dt>
<dd> Verify a public key from the local GPG keyring with the OPENPGPKEY DNS record</dl>
<p> <code>&#8211;resolvconf</code> FILE</p>
<dl>
<dt>
<dd> Specify a custom resolv.conf file (default: /etc/resolv.conf)</dl>
<p> <code>&#8211;output</code> rfc | generic | both</p>
<dl>
<dt>
<dd> Output format of OPENPGPKEY record. &quot;OPENPGPKEY&quot; for rfc, &quot;TYPE61&quot; for generic (default: generic)</dl>
<p> If neither create or verify is specified, create is used.</p>
<h2>REQUIREMENTS</h2>
<p> openpgpkey requires the following python libraries: unbound, gnupg and argparse. It also requires gnupg which provides the gpg command.</p>
<h2>BUGS</h2>
<p> none known</p>
<h2>EXAMPLES</h2>
<p> typical usage: </p>
<p> openpgpkey &#8211;fetch paul [at] nohats.ca &gt; paul.pubkey </p>
<p> openpgpkey &#8211;verify paul [at] nohats.ca </p>
<p> openpgpkey &#8211;create paul [at] nohats.ca</p>
