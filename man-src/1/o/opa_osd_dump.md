<h2>NAME</h2>

 opa_osd_dump 

 

 

 Prints the current contents of the distributed SA shared memory database.

<h2>Syntax</h2>

 opa_osd_dump [--verbose <i>arg</i>| -v <i>arg</i>]

<h2>Options</h2>

 

<dl>
<dt>--help
<dd> Produces full help text. 

<dt>--verbose/-v <i>arg</i>
<dd> Specifies the logging level to perform. Range = 1 - 7. 

</dl>

<h2>Example</h2>

 opa_osd_dump #8217gt;opasadb_contents
