<h2 class="name">NAME</h2>
<p> optex &#8211; OPmac and Plain TeX for LuaTeX engine. </p>
<h2>SYNOPSIS</h2>
<p> <code>optex</code> [ first line ]</p>
<h2>DESCRIPTION</h2>
<p> This manual page was derived from the manual page for LaTeX and is not meant to be exhaustive. The complete documentation for this version of TeX can be found in the info file or manual <i>Web2C: A TeX implementation</i>. </p>
<p> <code>OpTeX </code> is LuaTeX macro package initialized as the LuaTeX format optex.fmt. It is based on Plain TeX macros by Donlad Knuth and on OPmac macros from csplain package. For more information about it see <a rel="nofollow" href="http://petr.olsak.net/optex">http://petr.olsak.net/optex</a> web page.</p>
