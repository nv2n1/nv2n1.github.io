<h2 class="name">NAME</h2>
<p> odtest &#8211; test cases for QDBM Odeum</p>
<h2>SYNOPSIS</h2>
<p> <code>odtest write</code> [-tune <i>ibnum</i> <i>idnum</i> <i>cbnum</i> <i>csiz</i>] <i>name</i> <i>dnum</i> <i>wnum</i> <i>pnum</i><br />
 <code>odtest read</code> <i>name</i><br />
 <code>odtest combo</code> <i>name</i><br />
 <code>odtest wicked</code> <i>name dnum</i> </p>
<h2>DESCRIPTION</h2>
<p> The command `odtest&#8217; is a utility for facility test and performance test. Check a database generated by the command or measure the execution time of the command. This command is used in the following format. `name&#8217; specifies a database name. `dnum&#8217; specifies the number of the documents. `wnum&#8217; specifies the number of words per document. `pnum&#8217; specifies the number of patterns of words. </p>
<dl>
<dt><code>odtest write [-tune ibnum idnum cbnum csiz] name dnum wnum pnum</code></p>
<dd> Store documents with random attributes and random words.</p>
<dt><code>odtest read name</code></p>
<dd> Retrieve all documents of the database above.</p>
<dt><code>odtest combo name</code></p>
<dd> Perform combination test of various operations.</p>
<dt><code>odtest wicked name dnum</code></p>
<dd> Perform updating operations selected at random.</dl>
<p> Options feature the following. </p>
<dl>
<dt>
<dd> <code>-tune ibnum idnum cbnum csiz</code> : set tuning parameters.</dl>
<p> This command returns 0 on success, another on failure. The environment variable `QDBMDBGFD&#8217; specifies the file descriptor to output the history of updating the variable `dpecode&#8217;. </p>
