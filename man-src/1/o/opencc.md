<h2>NAME</h2>
<p> opencc &#8211; simplified-traditional chinese conversion tool</p>
<h2>DESCRIPTION</h2>
<p> Open Chinese Convert (OpenCC) Command Line Tool</p>
<h3>Usage:</h3>
<dl>
<dt>
<dd>opencc [-i input_file] [-o output_file] [-c config_file]</p>
<dt> <code>-i</code></p>
<dd>Read original text from input_file.</p>
<dt> <code>-o</code></p>
<dd>Write converted text to output_file.</p>
<dt> <code>-c</code></p>
<dd>Load dictionary configuration from config_file.</p>
<dt>
<dd> Note:</p>
<dt>
<dd> Text from standard input will be read if input_file is not set and will be written to standard output if output_file is not set.</p>
<dt>
<dd> Default configuration(zhs2zht.ini) will be load if config_file is not set.</dl>
