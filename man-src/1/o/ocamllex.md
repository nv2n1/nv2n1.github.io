<h2 class="name">NAME</h2>
<p> ocamllex &#8211; The OCaml lexer generator</p>
<h2>SYNOPSIS</h2>
<p> <code>ocamllex</code> [ <code>-o</code><i>&nbsp;<wbr>output-file</i> ] [ <code>-ml</code> ] <i>filename.mll</i> </p>
<h2>DESCRIPTION</h2>
<p> The <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1) command generates OCaml lexers from a set of regular expressions with associated semantic actions, in the style of <code><a href="/docs/linux/man/1-lex/">lex</a></code>(1). </p>
<p> Running <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1) on the input file <i>lexer</i>.mll produces OCaml code for a lexical analyzer in file <i>lexer</i>.ml. </p>
<p> This file defines one lexing function per entry point in the lexer definition. These functions have the same names as the entry points. Lexing functions take as argument a lexer buffer, and return the semantic attribute of the corresponding entry point. </p>
<p> Lexer buffers are an abstract data type implemented in the standard library module Lexing. The functions Lexing.from_channel, Lexing.from_string and Lexing.from_function create lexer buffers that read from an input channel, a character string, or any reading function, respectively. </p>
<p> When used in conjunction with a parser generated by <code><a href="/docs/linux/man/1-ocamlyacc/">ocamlyacc</a></code>(1), the semantic actions compute a value belonging to the type token defined by the generated parsing module. </p>
<h2>OPTIONS</h2>
<p> The <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1) command recognizes the following options:</p>
<dl>
<dt><code>-ml</code></p>
<dd> Output code that does not use OCaml&#8217;s built-in automata interpreter. Instead, the automaton is encoded by OCaml functions. This option is mainly useful for debugging <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1), using it for production lexers is not recommended.</p>
<dt><code>-o</code><i>&nbsp;<wbr>output-file</i></p>
<dd> Specify the name of the output file produced by <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1). The default is the input file name, with its extension replaced by .ml.</p>
<dt><code>-q</code></p>
<dd> Quiet mode. <code><a href="/docs/linux/man/1-ocamllex/">ocamllex</a></code>(1) normally outputs informational messages to standard output. They are suppressed if option <code>-q</code> is used.</p>
<dt><code>-v</code>&nbsp;<wbr>or<code>&nbsp;<wbr>-version</code></p>
<dd> Print version string and exit.</p>
<dt><code>-vnum</code></p>
<dd> Print short version number and exit.</p>
<dt><code>-help</code>&nbsp;<wbr>or<code>&nbsp;<wbr>&#8211;help</code></p>
<dd> Display a short usage summary and exit. </p>
</dl>
