<h2 class="name">NAME</h2>
<p> scl2trd &#8211; Convert .scl disk images to .trd. </p>
<h2>SYNOPSIS</h2>
<p> <code>scl2trd</code> <i>sclfile trdfile</i></p>
<h2>DESCRIPTION</h2>
<p> scl2trd converts a .scl disk file to a 80 track, double sided (640 KB) .trd disk file.</p>
<h2>OPTIONS</h2>
<dl>
<dt><i>sclfile</i></p>
<dd> specifies a .scl file whose contents are to be converted.</p>
<dt><i>trdfile</i></p>
<dd> specifies a .trd file to create.</dl>
<h2>BUGS</h2>
<p> None known.</p>
