<h2 class="name">NAME</h2>
<p> setfattr &#8211; set extended attributes of filesystem objects </p>
<h2>SYNOPSIS</h2>
<pre><code>
setfattr[-h] - n name[-v value] pathname... setfattr[-h] - x name pathname... setfattr[-h]-- restore = file
</code></pre>
<h2>DESCRIPTION</h2>
<p> The <code>setfattr</code> command associates a new <i>value</i> with an extended attribute <i>name</i> for each specified file.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-n</code> <i>name</i>, <code>&#8211;name</code>=<i>name</i></p>
<dd> Specifies the name of the extended attribute to set.</p>
<dt><code>-v</code> <i>value</i>, <code>&#8211;value</code>=<i>value</i></p>
<dd> Specifies the new value of the extended attribute. There are three methods available for encoding the value. If the given string is enclosed in double quotes, the inner string is treated as text. In that case, backslashes and double quotes have special meanings and need to be escaped by a preceding backslash. Any control characters can be encoded as a backslash followed by three digits as its ASCII code in octal. If the given string begins with 0x or 0X, it expresses a hexadecimal number. If the given string begins with 0s or 0S, base64 encoding is expected. Also see the &#8211;encoding option of <a href="/docs/linux/man/1-getfattr/">getfattr</a>(1).</p>
<dt><code>-x</code> <i>name</i>, <code>&#8211;remove</code>=<i>name</i></p>
<dd> Remove the named extended attribute entirely.</p>
<dt><code>-h</code>, <code>&#8211;no-dereference</code></p>
<dd> Do not follow symlinks. If <i>pathname</i> is a symbolic link, it is not followed, but is instead itself the inode being modified.</p>
<dt><code>&#8211;restore</code>=<i>file</i></p>
<dd> Restores extended attributes from file. The file must be in the format generated by the <code>getfattr</code> command with the <code>&#8211;dump</code> option. If a dash (<i>&#8211;</i>) is given as the file name, <code>setfattr</code> reads from standard input.</p>
<dt><code>&#8211;raw</code></p>
<dd> Do not decode the attribute value. Can be used to set values obtained with <code>getfattr &#8211;only-values</code>.</p>
<dt><code>&#8211;version</code></p>
<dd> Print the version of <code>setfattr</code> and exit.</p>
<dt><code>&#8211;help</code></p>
<dd> Print help explaining the command line options.</p>
<dt><code>&#8212;</code></p>
<dd> End of command line options. All remaining parameters are interpreted as file names, even if they start with a dash character.</dl>
