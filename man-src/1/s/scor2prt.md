<h2 class="name">NAME</h2>
<p> scor2prt &#8211; source-parts separation program for pmx, a MusiXTeX preprocessor </p>
<h2>SYNOPSIS</h2>
<p> <code>scor2prt</code> basename<i>[.pmx]</i></p>
<h2>DESCRIPTION</h2>
<p> scor2prt is part of <a href="/docs/linux/man/1-pmx/">pmx</a>(1), a preprocessor for MusiXTeX. It can automatically create parts from a score by generating a set of .pmx files, one for each part, from a single .pmx file for the score. The appearance of the parts can be controlled by special commands in the main file. Read the PMX Manual for more information about that.</p>
