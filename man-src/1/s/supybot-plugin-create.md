<h2>NAME</h2>
<p> supybot-plugin-create &#8211; A wizard for creating Supybot plugins</p>
<h2>SYNOPSIS</h2>
<p> <code>supybot-plugin-create</code> [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>supybot-plugin-create</code> is a wizard that creates a template python source file for a new <i><a href="/docs/linux/man/1-supybot/">supybot</a></i>(1) plugin.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;version</code></p>
<dd> Show version of program.</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>-n</code><i> NAME</i>, &#8211;name=<i>NAME</i></p>
<dd> Sets the name for the plugin.</p>
<dt><code>-t</code>, <code>&#8211;thread</code></p>
<dd> Makes the plugin threaded.</p>
<dt><code>&#8211;real-name=</code><i>REALNAME</i></p>
<dd> Specify what real name the copyright is assigned to.</dl>
