<h2>NAME</h2>
<p> <code>system-config-language</code>&nbsp;<wbr>&#8211; A graphical interface for modifying the system language.</p>
<h2>DESCRIPTION</h2>
<p>This tool will allow user to add language support. When used to add support for any language, this tool will use yum and install the required packages to use desktop in your preferred language. This will also change the locale of the root user only. </p>
<p> This project is available at <a rel="nofollow" href="http://fedorahosted.org/system-config-language">http://fedorahosted.org/system-config-language</a> </p>
