<h2 class="name">NAME</h2>
<p> select-default-iwrap &#8211; Selects the user default ispell dictionary for use with ispell-wrapper </p>
<h2>SYNOPSIS</h2>
<pre>
 select-default-iwrap
</pre>
<h2>DESCRIPTION</h2>
<p> Selects the user default ispell dictionary for use with ispell-wrapper, putting the selected value in <i>~/.ispell-default</i>.</p>
