<h2>NAME</h2>
<p> sndfile-convert &#8211; convert a sound files from one format to another</p>
<h2>SYNOPSIS</h2>
<p> <code>sndfile-convert</code> [encoding] input_file output_file </p>
<p> <code>sndfile-convert</code> &#8211;help</p>
<h2>DESCRIPTION</h2>
<p> sndfile-convert converts sound files from one format to another using libsndfile (<a rel="nofollow" href="http://www.mega-nerd.com/libsndfile/)">http://www.mega-nerd.com/libsndfile/)</a> to read and write the data. </p>
<p> The format of the output file is determined by the filename extension of the output file. </p>
<p> The optional encoding parameter allows setting of the data encoding for the output file. Run &quot;sndfile-convert &#8211;help&quot; for more information.</p>
