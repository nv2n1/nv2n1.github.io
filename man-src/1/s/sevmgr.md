<h2 class="name">NAME</h2>
<p> sevmgr &#8211; </p>
<pre>
      Command-line interpreter for the C++ Simulation-Oriented Discrete Event Management Library
</pre>
<h2>SYNOPSIS</h2>
<p> <code>sevmgr</code> [&#8211;prefix] [-v|&#8211;version] [-h|&#8211;help] [-l|&#8211;log &lt;path-to-output-log-file&gt;]</p>
<h2>DESCRIPTION</h2>
<p> <i>sevmgr</i> is a small program showing how to use the SEvMgr library. </p>
<p> <i>sevmgr</i> accepts the following options: </p>
<p> <code>&#8211;prefix</code> </p>
<p>&nbsp;<wbr>Show the SEvMgr installation prefix. </p>
<p> <code>-v</code>, <code>&#8211;version</code> </p>
<p>&nbsp;<wbr>Print the currently installed version of SEvMgr on the standard output. </p>
<p> <code>-h</code>, <code>&#8211;help</code> </p>
<p>&nbsp;<wbr>Produce that message and show usage. </p>
<p> <code>-l</code>, <code>&#8211;log</code> &lt;path-to-output-log-file&gt; </p>
<p>&nbsp;<wbr>Path&nbsp;<wbr>(absolute or relative)&nbsp;<wbr>of the output log file. </p>
<p> See the output of the `sevmgr &#8211;help&#8217; command for default options.</p>
