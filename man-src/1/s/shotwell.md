<h2 class="name">NAME</h2>
<p> shotwell &#8211; Digital photo manager</p>
<h2>SYNOPSIS</h2>
<p> <code>shotwell </code>[<i>OPTION</i>]&#8230; [<i>FILE</i>] </p>
<h2>DESCRIPTION</h2>
<p> Shotwell is a digital photo organizer designed for the GNOME desktop environment. It allows you to import photos from disk or camera, organize them in various ways, view them in full-window or fullscreen mode, and export them to share with others. </p>
<h2>OPTIONS</h2>
<p> <code>-h, &#8211;help</code> Show help options </p>
<p> <code>-d, &#8211;datadir=DIRECTORY</code></p>
<dl>
<dt>
<dd> Path to Shotwell&#8217;s private data</dl>
<p> <code>&#8211;no-runtime-monitoring</code></p>
<dl>
<dt>
<dd> Do not monitor library directory at runtime for changes</dl>
<p> <code>-f, &#8211;fullscreen</code></p>
<dl>
<dt>
<dd> Open the viewer mode in fullscreen. Has no effect in library mode.</dl>
<p> <code>&#8211;no-startup-progress</code></p>
<dl>
<dt>
<dd> Don&#8217;t display startup progress meter</dl>
<p> <code>-V, &#8211;version</code></p>
<dl>
<dt>
<dd> Show the application&#8217;s version</dl>
<p> <code>&#8211;display=DISPLAY</code></p>
<dl>
<dt>
<dd> X display to use</dl>
<h2>EXAMPLES</h2>
<p> <code>shotwell</p>
<dl>
<dt>
<dd> </code>Opens Shotwell with the user&#8217;s library.</dl>
<p> <code>shotwell </code><i>FILE</p>
<dl>
<dt>
<dd> </i>Opens an image file for direct editing. File is not imported into library and unsaved changes are lost on close.</dl>
