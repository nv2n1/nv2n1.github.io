<h2>NAME</h2>
<p> synce-list-programs &#8211; shows a list of all installed programs </p>
<h2>SYNOPSIS</h2>
<p> <code>synce-list-programs</code> [-d <i>LEVEL</i>] [-p <i>DEVNAME</i>] [-h] </p>
<h2>OPTIONS</h2>
<dl>
<dt>-d <i>LEVEL</i></p>
<dd> Set debug log level:</p>
<dt>
<dd> 0 &#8211; No logging (default)</p>
<dt>
<dd> 1 &#8211; Errors only</p>
<dt>
<dd> 2 &#8211; Errors and warnings</p>
<dt>
<dd> 3 &#8211; Everything </p>
<dt>-p <i>DEVNAME</i></p>
<dd> Use the device with the given name, instead of the default. </p>
<dt>-h</p>
<dd> Display help message. </p>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>synce-list-programs</code> shows a list of all programs installed on a device connected through SynCE. </p>
