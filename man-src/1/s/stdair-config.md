<h2 class="name">NAME</h2>
<p> stdair-config &#8211; Configuration Script for the C++ Standard Airline IT Object Library</p>
<h2>SYNOPSIS</h2>
<p> <code>stdair-config</code> [&#8211;prefix] [&#8211;version] [&#8211;libs] [&#8211;cflags]</p>
<h2>DESCRIPTION</h2>
<p> <i>stdair-config</i> is a tool that is used by configure to determine the compiler and linker flags that should be used to compile and link programs that use <i>StdAir</i>. It is also used internally by the .m4 macros, that are included with <i>StdAir</i>, for GNU autoconf.</p>
<h2>OPTIONS</h2>
<p> <i>stdair-config</i> accepts the following options: </p>
<p> <code>&#8211;help</code> </p>
<p>&nbsp;<wbr>Display this help and exit </p>
<p> <code>&#8211;prefix</code> </p>
<p>&nbsp;<wbr>Show the StdAir installation prefix. </p>
<p> <code>&#8211;version</code> </p>
<p>&nbsp;<wbr>Print the currently installed version of StdAir on the standard output. </p>
<p> <code>&#8211;libs</code> </p>
<p>&nbsp;<wbr>Print the linker flags that are necessary to link with the StdAir library. </p>
<p> <code>&#8211;cflags</code> </p>
<p>&nbsp;<wbr>Print the compiler flags that are necessary to compile with the StdAir library. </p>
<p> <code>&#8211;sampledir</code> </p>
<p>&nbsp;<wbr>Show where the&nbsp;<wbr>(StdAir CSV)&nbsp;<wbr>sample files are located. </p>
<p> <code>&#8211;mandir</code> </p>
<p>&nbsp;<wbr>Show where the manual pages are located. </p>
<p> <code>&#8211;infodir</code> </p>
<p>&nbsp;<wbr>Show where the information pages are located. </p>
<p> <code>&#8211;docdir</code> </p>
<p>&nbsp;<wbr>Show the documentation base directory. </p>
<p> <code>&#8211;htmldocpath</code> </p>
<p>&nbsp;<wbr>Show where the HTML documentation is located. </p>
<p> <code>&#8211;refmanpath</code> </p>
<p>&nbsp;<wbr>Show where the PDF documentation is located.</p>
