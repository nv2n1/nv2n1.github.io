<h2>NAME</h2>
<p> smidiff &#8211; check differences between a pair of SMI or SPPI modules</p>
<h2>SYNOPSIS</h2>
<p> <code>smidiff</code> [ <code>-Vhsm</code> ] [ <code>-c </code><i>file</i> ] [ <code>-l </code><i>level</i> ] [ <code>-i </code><i>error-pattern</i> ] [ <code>-p </code><i>module</i> ] <i>oldmodule newmodule</i></p>
<h2>DESCRIPTION</h2>
<p> The <code>smidiff</code> program is used to check differences between a pair of SMI MIB modules or SPPI PIB modules. E.g., it can be used to detect changes in updated MIB modules that can cause interoperability problems with existing implementations. SMIv1/v2 and SPPI style MIB/PIB modules are supported. </p>
<p> Note that conformance statements are currently not checked. </p>
<p> Messages describing the differences are written to the standard output channel while error and warning messages generated by the parser are written to the standard error channel.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-V, &#8211;version</code></p>
<dd> Show the smidump version and exit.</p>
<dt><code>-h, &#8211;help</code></p>
<dd> Show a help text and exit.</p>
<dt><code>-s, &#8211;severity</code></p>
<dd> Show the error severity in brackets before error messages.</p>
<dt><code>-m, &#8211;error-names</code></p>
<dd> Show the error names in braces before error messages.</p>
<dt><code>-c </code><i>file</i><code>, &#8211;config=</code><i>file</i></p>
<dd> Read <i>file</i> instead of any other (global and user) configuration file.</p>
<dt><code>-p </code><i>module</i><code>, &#8211;preload=</code><i>module</i></p>
<dd> Preload the module <i>module</i> before reading the main module(s). This may be helpful if an incomplete main module misses to import some definitions.</p>
<dt><code>-l </code><i>level</i><code>, &#8211;level=</code><i>level</i></p>
<dd> Report errors and warnings up to the given severity <i>level</i>. See the <a href="/docs/linux/man/1-smilint/">smilint</a>(1) manual page for a description of the error levels. The default error level is 3.</p>
<dt><code>-i </code><i>prefix</i><code>, &#8211;ignore=</code><i>prefix</i></p>
<dd> Ignore all errors that have a tag which matches <i>prefix</i>.</p>
<dt><i>oldmodule</i></p>
<dd> The original module.</p>
<dt><i>newmodule</i></p>
<dd> The updated module.</dl>
<p> If a module argument represents a path name (identified by containing at least one dot or slash character), this is assumed to be the exact file to read. Otherwise, if a module is identified by its plain module name, it is searched according to libsmi internal rules. See <code><a href="/docs/linux/man/3-smi_config/">smi_config</a>(3)</code> for more details.</p>
