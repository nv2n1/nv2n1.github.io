<h2 class="name">NAME</h2>
<p> sirtopnm &#8211; convert a Solitaire file into a portable anymap </p>
<h2>SYNOPSIS</h2>
<p> <code>sirtopnm</code> [<i>sirfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a Solitaire Image Recorder file as input. Produces a portable anymap as output. The type of the output file depends on the input file &#8211; if it&#8217;s an MGI TYPE 17 file, a <i>pgm</i> file is written. If it&#8217;s an MGI TYPE 11 file, a <i>ppm</i> file is written. The program tells you which type it is writing.</p>
