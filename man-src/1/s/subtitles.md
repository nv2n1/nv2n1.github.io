<h2>NAME</h2>
<p> subtitles &#8211; display subtitles within xawtv.</p>
<h2>SYNOPSIS</h2>
<p> <code>subtitles [ -help | -tty ] &lt;page&gt;</code></p>
<h2>DESCRIPTION</h2>
<p> <code>subtitles</code> fetches the given teletext page with the alevt-cap utility and displays it using xawtv-remote in an endless loop. It&#8217;s most useful for pages which carry subtitles for the current TV program. It&#8217;s page 150 in Germany.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-help</code></p>
<dd> print a short help text.</p>
<dt><code>-tty</code></p>
<dd> dump a copy of the videotext page to the tty.</dl>
