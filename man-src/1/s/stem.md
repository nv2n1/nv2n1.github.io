<h2>NAME</h2>
<p> stem &#8211; Stem Documentation </p>
<p> Stem is a Python controller library for <i>Tor</i>. With it you can use Tor&#8217;s <i>control protocol</i> to script against the Tor process, or build things such as <i>arm</i>. Stem&#8217;s latest version is <code>1.4.1</code> (released May 18th, 2015). <i></i><i></i><i></i><i></i><i></i><i></i>.SH AUTHOR Damian Johnson (atagar [at] torproject.org)</p>
