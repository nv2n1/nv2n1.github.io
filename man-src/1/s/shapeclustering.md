<h2 class="name">NAME</h2>
<p> shapeclustering &#8211; shape clustering training for Tesseract </p>
<h2>SYNOPSIS</h2>
<p> shapeclustering -D <i>output_dir</i> -U <i>unicharset</i> -O <i>mfunicharset</i> -F <i>font_props</i> -X <i>xheights</i> <i>FILE</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> <a href="/docs/linux/man/1-shapeclustering/">shapeclustering</a>(1) takes extracted feature .tr files (generated by <a href="/docs/linux/man/1-tesseract/">tesseract</a>(1) run in a special mode from box files) and produces a file <code>shapetable</code> and an enhanced unicharset. This program is still experimental, and is not required (yet) for training Tesseract.</p>
<h2>OPTIONS</h2>
<p> -U <i>FILE</i></p>
<dl>
<dt>
<dd> The unicharset generated by <a href="/docs/linux/man/1-unicharset_extractor/">unicharset_extractor</a>(1).</dl>
<p> -D <i>dir</i></p>
<dl>
<dt>
<dd> Directory to write output files to.</dl>
<p> -F <i>font_properties_file</i></p>
<dl>
<dt>
<dd> (Input) font properties file, where each line is of the following form, where each field other than the font name is 0 or 1: </p>
<dl>
<dt>
<dd>
<pre>
'font_name' 'italic' 'bold' 'fixed_pitch' 'serif' 'fraktur'
</pre>
</dl>
</dl>
<p> -X <i>xheights_file</i></p>
<dl>
<dt>
<dd> (Input) x heights file, each line is of the following form, where xheight is calculated as the pixel x height of a character drawn at 32pt on 300 dpi. [ That is, if base x height + ascenders + descenders = 133, how much is x height? ] </p>
<dl>
<dt>
<dd>
<pre>
'font_name' 'xheight'
</pre>
</dl>
</dl>
<p> -O <i>FILE</i></p>
<dl>
<dt>
<dd> The output unicharset that will be given to <a href="/docs/linux/man/1-combine_tessdata/">combine_tessdata</a>(1).</dl>
