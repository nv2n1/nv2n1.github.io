<h2 class="name">NAME</h2>
<p> <code>scalap</code> &#8211; Scala class file decoder for the Scala 2 language </p>
<h2>SYNOPSIS</h2>
<p> <code>scalap</code> [ &lt;<i>options</i>&gt; ] &lt;<i>class name</i>&gt;</p>
<h2>PARAMETERS</h2>
<dl>
<dt>&lt;<i>options</i>&gt;</p>
<dd> Command line options. See <code>OPTIONS</code> below.</p>
<dt>&lt;<i>class name</i>&gt;</p>
<dd> Full-qualified name of a class to be decoded (such as hello.HelloWorld).</dl>
<h2>DESCRIPTION</h2>
<p> The <code>scalap</code> tool reads a class file generated by theScala compiler, and displays object and class definitions. </p>
<p> By default, <code>scalap</code> looks for the given class file in the current directory. You can specify a separate classpath with <code>-classpath</code> (see <code>OPTIONS</code>, below).</p>
<h2>OPTIONS</h2>
<p> The decoder has a set of standard options that are supported on the current development environment and will be supported in future releases.</p>
<h3>Standard Options</h3>
<dl>
<dt><code>-help</code></p>
<dd> Display this usage message.</p>
<dt><code>-private</code></p>
<dd> Print private definitions.</p>
<dt><code>-verbose</code></p>
<dd> Print out additional information.</p>
<dt><code>-version</code></p>
<dd> Print product version and exit.</p>
<dt><code>-cp</code> | <code>-classpath</code></p>
<dd> Specify where to find user class files.</dl>
<h2>EXAMPLES</h2>
<dl>
<dt>Display definitions for a generated class file</p>
<dd> <code>scalap</code> hello.HelloWorld</dl>
<h2>EXIT STATUS</h2>
<p> <code>scalap</code> returns a zero exist status if it succeeds to process the specified input files. Non zero is returned in case of failure.</p>
