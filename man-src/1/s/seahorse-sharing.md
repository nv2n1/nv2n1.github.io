<h2 class="name">NAME</h2>
<p> seahorse-sharing &#8211; public pgp key sharing</p>
<h2>SYNOPSIS</h2>
<p> <code>seahorse-sharing</code> [ <i>OPTION</i>&#8230; ] </p>
<h2>DESCRIPTION</h2>
<p> Seahorse is a GNOME application for managing encryption keys. </p>
<p> This is the daemon program which shares your keys over the network if so desired. </p>
<h2>OPTIONS</h2>
<h3>Help options</h3>
<dl>
<dt><code>-?, &#8211;help</code></p>
<dd> Show summary of all options and exit.</p>
<dt><code>&#8211;usage</code></p>
<dd> Display brief usage message and exit. </p>
</dl>
<h3>Application options</h3>
<dl>
<dt><code>-d, &#8211;no-daemonize</code></p>
<dd> Do not daemonize seahorse-sharing. </p>
</dl>
<h3>Additional options</h3>
<p> In addition, the usual GTK+ and GNOME command line options apply. See the output of &#8211;help for details. </p>
<h2>VERSION</h2>
<p> This man page describes <code>seahorse-sharing</code> version 0.9.x. </p>
