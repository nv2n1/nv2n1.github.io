<h2 class="name">NAME</h2>
<p> simul-beacons &#8211; Robot dataset simulator </p>
<h2>SYNOPSIS</h2>
<p> simul-beacons <i>config_file.ini</i></p>
<h2>DESCRIPTION</h2>
<p> <code>simul-beacons</code> is a command-line application which generates a synthetic rawlog of a simulated robot as it follows a predefined path and observes a set of beacons (through range-only measurements).</p>
