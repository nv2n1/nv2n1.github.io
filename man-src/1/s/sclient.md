<h2>NAME</h2>
<p> sclient &#8211; sample Kerberos version 5 client</p>
<h2>SYNOPSIS</h2>
<p> <code>sclient</code> <i>remotehost</i></p>
<h2>DESCRIPTION</h2>
<p> sclient is a sample application, primarily useful for testing purposes. It contacts a sample server <i><a href="/docs/linux/man/8-sserver/">sserver</a>(8)</i> and authenticates to it using Kerberos version 5 tickets, then displays the server&#8217;s response.</p>
