<h2 class="name">NAME</h2>
<p> software-properties-gtk &#8211; Software Sources List editor </p>
<h2>SYNOPSIS</h2>
<p> software-properties-gtk [options]</p>
<h2>DESCRIPTION</h2>
<p> Software Sources List editor</p>
<h2>OPTIONS</h2>
<h3>Options:</h3>
<dl>
<dt><code>&#8211;debug </code></p>
<dd> Print some debug information to the command line</p>
<dt><code>&#8211;massive-debug </code></p>
<dd> Print a lot of debug information to the command line</p>
<dt><code>&#8211;no-update </code></p>
<dd> No update on repository change (useful if called from an external program)</p>
<dt><code>&#8211;enable-component &lt;name&gt;</code></p>
<dd> Enable the specified component of the distro&#8217;s repositories [component_arg]</p>
<dt><code>&#8211;open-tab</code></p>
<dd> Open specific tab number on startup</p>
<dt><code>&#8211;enable-ppa &lt;name&gt;</code></p>
<dd> Enable PPA with the given name [ppa_arg]</dl>
<h3>Generic options:</h3>
<dl>
<dt><code>&#8211;help </code></p>
<dd> Show help about options </p>
</dl>
