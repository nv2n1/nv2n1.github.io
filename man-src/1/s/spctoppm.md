<h2 class="name">NAME</h2>
<p> spctoppm &#8211; convert an Atari compressed Spectrum file into a portable pixmap </p>
<h2>SYNOPSIS</h2>
<p> <code>spctoppm</code> [<i>spcfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads an Atari compressed Spectrum file as input. Produces a portable pixmap as output.</p>
