<h2 class="name">NAME</h2>
<p> sputoppm &#8211; convert an Atari uncompressed Spectrum file into a portable pixmap </p>
<h2>SYNOPSIS</h2>
<p> <code>sputoppm</code> [<i>spufile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads an Atari uncompressed Spectrum file as input. Produces a portable pixmap as output.</p>
