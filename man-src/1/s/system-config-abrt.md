<h2 class="name">NAME</h2>
 

 system-config-abrt - GUI tool to configure ABRT 

<h2>SYNOPSIS</h2>

 

 <i>system-config-abrt</i>

<h2>DESCRIPTION</h2>

 

 <i>system-config-abrt</i> is a graphical tool that provides to users comfortable way for changing ABRT's configuration files from one place.
