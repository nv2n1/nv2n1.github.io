<h2 class="name">NAME</h2>
<p> system-tools-backends &#8211; message dispatcher for system-tools-backends </p>
<h2>SYNOPSIS</h2>
<p> <code>system-tools-backends</code></p>
<h2>DESCRIPTION</h2>
<p> System Tools Backends are a set of cross-platform modules for Linux and other Unix systems. The backends provide an common DBus interface to all platforms to modify or read the system configuration in a distro independent fashion. </p>
<p> This program is a lightweight DBus message dispatcher. It does not take any options.</p>
