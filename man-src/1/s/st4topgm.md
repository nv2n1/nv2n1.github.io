<h2 class="name">NAME</h2>
<p> st4topgm &#8211; convert an SBIG ST4 format file into a portable graymap </p>
<h2>SYNOPSIS</h2>
<p> <code>st4topgm</code> [<i>st4file</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads an an image file in the native format used by the SBIG ST-4 astronomical CCD camera, and produces a portable graymap as output. Additional information on SBIG cameras and documentation of the file format is available at the Web site: <code><a rel="nofollow" href="http://www.sbig.com/">http://www.sbig.com/</a></code></p>
