<h2 class="name">NAME</h2>
<p> seahorse &#8211; Passwords and Keys </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>seahorse</code> [OPTIONS&#8230;] [FILES&#8230;]</dl>
<h2>DESCRIPTION</h2>
<dd>Seahorse is a graphical interface for managing and using encryption keys, passwords and certificates. Currently it supports PGP keys (using GPG/GPGME) and SSH keys. Its goal is to provide an easy to use Key Management Tool, along with an easy to use interface for encryption operations.</p>
