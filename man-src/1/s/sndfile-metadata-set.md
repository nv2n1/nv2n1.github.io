<h2>NAME</h2>
<p> sndfile-metadata-get &#8211; retrieve metadata from a sound file<br />
 sndfile-metadata-set &#8211; set metadata in a sound file</p>
<h2>SYNOPSIS</h2>
<p> <code>sndfile-metadata-get</code> [options] file<br />
 <code>sndfile-metadata-set</code> [options] file<br />
 <code>sndfile-metadata-set</code> [options] input-file output-file </p>
<h2>DESCRIPTION</h2>
<p> sndfile-metadata-get and sndfile-metadata-set use libsndfile (<a rel="nofollow" href="http://www.mega-nerd.com/libsndfile/)">http://www.mega-nerd.com/libsndfile/)</a> to retrieve metadata from or set metadata in a sound file. </p>
<p> Run &quot;sndfile-metadata-get &#8211;help&quot; or &quot;sndfile-metadata-set &#8211;help&quot; for more information </p>
