<h2>NAME</h2>
<p> sys_basher &#8211; manual page for sys_basher version 2.0.2</p>
<h2>SYNOPSIS</h2>
<p> <code>sys_basher</code> [<i>OPTIONS</i>]</p>
<h2>DESCRIPTION</h2>
<p> sys_basher (c)2006-2015 Polybus Systems Corp., Westford, MA, USA</p>
<dl>
<dt>
<dd> Sys_basher is a multithreaded hardware exerciser. Sys_basher tests CPU, memory and disk I/O reliability. It also measures low level system performance.</dl>
<h3>options:</h3>
<dl>
<dt><code>-d</code>,&#8211;disk</p>
<dd> Run disk tests</p>
<dt><code>-dmi</code> filename</p>
<dd> DMI binary file generated by dmidecode <code>&#8211;dump-bin</code> filename The DMI (BIOS) file allows sys_basher to determine which DIMM is bad The default DMI file is in <i>/var/sys_basher/bios.bin</i></p>
<dt><code>-du</code>,&#8211;dutycyle</p>
<dd> Dutycycle n Duty cycle in percent, the default is 100 Inserts Sleeps between tests to reduce the overall CPU duty cycle</p>
<dt><code>-f</code>,&#8211;fast</p>
<dd> Skip the memory tests, just run the disk, fp and memory bandwidth tests.</p>
<dt><code>-fp</code>,&#8211;fp</p>
<dd> Run floating point tests</p>
<dt><code>-h</code>,&#8211;help</p>
<dd> Print this help message</p>
<dt><code>-ho</code> #,&#8211;hours #</p>
<dd> Run for at least # hours.</p>
<dt><code>-i</code>,&#8211;int</p>
<dd> Run integer tests</p>
<dt><code>-l</code> #,&#8211;loops #</p>
<dd> Number of iterations.</p>
<dt><code>-mb</code>,&#8211;mbandwidth</p>
<dd> Run memory bandwidth</p>
<dt><code>-m</code>,&#8211;mem [abprwv]</p>
<dd> Run memory tests</p>
<dt>No argument</p>
<dd> Run all memory tests</p>
<dt>a</p>
<dd> Address = Data tests</p>
<dt>b</p>
<dd> Bank tests</p>
<dt>p</p>
<dd> Fixed pattern tests</p>
<dt>r</p>
<dd> Random data tests</p>
<dt>w</p>
<dd> Walking Ones/Zeros data tests</p>
<dt>v</p>
<dd> Bit reversed address tests</p>
<dt><code>-mi</code>,&#8211;minutes #</p>
<dd> Run for at least # minutes.</p>
<dt><code>-p</code> n0..nx,&#8211;path n0..nx</p>
<dd> Directory path(s) for the disk tests, upto 32 paths maybe specified. The default path is ./</p>
<dt><code>-r</code> name,&#8211;report name</p>
<dd> Report file name, generate name.rpt and name_xx.csv. Default is sys_basher.rpt and sys_basher_xx.csv</p>
<dt><code>-s</code>,&#8211;swap</p>
<dd> Force use of swap space. This option is incredibly slow.</p>
<dt><code>-st</code>,&#8211;stop</p>
<dd> Stop on Error, Exits if error found.</p>
<dt><code>-t</code>,&#8211;totalmem #</p>
<dd> Allocate total ram &#8211; (n * 1M) for testing. If <code>-totalmem</code> is not called then the free space is used.</p>
<dt><code>-th</code> #,&#8211;threads #</p>
<dd> Maximum number of threads. Spawn 1-n threads, the default is the number of CPUs.</p>
<dt><code>-ts</code> #,&#8211;tstart #</p>
<dd> Starting thread count, after the initial calibration pass loop from tstart to threads, the default is 1</p>
<dt><code>-v</code>,&#8211;verbose</p>
<dd> Verbose, print detailed results, for memory tests prints address and data info for the first 16 errors, default is PASS/FAIL only.</p>
<dt><code>-vv</code>,&#8211;vverbose</p>
<dd> Very Very verbose, for memory tests run a second check pass to help determine if it&#8217;s a read or write problem</p>
<dt><code>-ve</code>,&#8211;version</p>
<dd> Version</dl>
<p> The default is to run all tests unless at least one individual test group is selected. Report and log files:</p>
<dl>
<dt>
<dd> The default report and log names are sys_basher.rpt and sys_basher.log The the default name can be overridden with the <code>-r</code> switch.</p>
<dt>report_name.log</p>
<dd> Running log. Syncs are executed after each test so that this file can be preserved up to the point of a crash.</p>
<dt>report_name.rpt</p>
<dd> Summary report file.</p>
<dt>report_name_#_threads.csv</p>
<dd> Comma separated report files for each thread count. These files can be read into a spreadsheet.</p>
<dt>
<dd> RHEL7/CentOS7/SL7 systems have an aggressive OOM killer which sometimes interferes with sys_basher.</p>
<dt>
<dd> You can disable the OOM killer for sys_basher by running (as root) sys_basher_disable_oom after starting sys_basher </p>
</dl>
