<h2 class="name">NAME</h2>
<p> stg-next &#8211; Print the name of the next patch </p>
<h2>SYNOPSIS</h2>
<pre>
<i>stg</i> next
</pre>
<h2>DESCRIPTION</h2>
<p> Print the name of the next patch.</p>
<h2>OPTIONS</h2>
<p> -b BRANCH, &#8211;branch BRANCH</p>
<dl>
<dt>
<dd> Use BRANCH instead of the default branch.</dl>
