<h2 class="name">NAME</h2>
 

 scpr - The scpr program is used to print out objects in checkpoint files.

<h2>Running scpr</h2>

 

 

 scpr takes the following command line options followed by a list of files. 

<dl>
<dt>-o <i>val</i>
<dd> Print the object with the name val. Object names take the form '&lt;classname&gt;:&lt;ordinal_number&gt;'. At least one file and object name must be given.
<dt>-memorygrp <i>val</i>
<dd> Which memory group to use.
<dt>-threadgrp <i>val</i>
<dd> Which thread group to use.
<dt>-messagegrp <i>val</i>
<dd> Which message group to use.
<dt>-W <i>val</i>
<dd> Set the working directory.
<dt>-d
<dd> Turn on debugging.
<dt>-v
<dd> Print the version.
<dt>-w
<dd> Print the warranty.
<dt>-L
<dd> Print the license.
<dt>-h
<dd> Print this help.</dl>
