<h2 class="name">NAME</h2>
<p> spatch &#8211; apply a semantic patch file to a set of C files</p>
<h2>SYNOPSIS</h2>
<p> <code>spatch</code> <code>-sp_file</code> <i>&lt;SP&gt;</i> <i>&lt;files&gt;</i> <code>[-o </code> <i>&lt;outfile&gt;</i> <code>] </code> <code>[-iso_file </code> <i>&lt;iso&gt;</i> <code>] </code> <code>[</code> <i>options</i> <code>]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>spatch</code> is a program matching and transformation tool for C. The programmer describes the code to match and the transformation to perform as a semantic patch, which looks like a standard patch, but can transform multiple files at any number of code sites. </p>
<p> Further information about spatch is available at <code><a rel="nofollow" href="http://www.emn.fr/x-info/coccinelle">http://www.emn.fr/x-info/coccinelle</a></code>. </p>
<h2>OPTIONS</h2>
<p> Here is a summary of the most commonly used options: </p>
<dl>
<dt><code>-sp_file </code><i>&lt;file&gt;</i></p>
<dd> the semantic patch file</p>
<dt><code>-dir </code><i>&lt;dir&gt;</i></p>
<dd> process all files in directory recursively</p>
<dt><code>-iso_file </code><i>&lt;file&gt;</i></p>
<dd> (default=/usr/local/share/coccinelle/standard.iso)</p>
<dt><code>-macro_file </code><i>&lt;file&gt;</i></p>
<dd> (default=/usr/local/share/coccinelle/standard.h)</p>
<dt><code>-debug </code></p>
<dd> print some information to help debug the matching process</p>
<dt><code>-all_includes </code></p>
<dd> causes all available include files to be used</p>
<dt><code>-no_includes </code></p>
<dd> causes not even local include files to be used</p>
<dt><code>-I </code><i>&lt;dir&gt;</i></p>
<dd> the directory containing the include files</p>
<dt><code>-include_headers </code></p>
<dd> process header files independently</p>
<dt><code>-use_glimpse </code></p>
<dd> works with -dir, use information generated by glimpseindex</p>
<dt><code>-o </code><i>&lt;file&gt;</i></p>
<dd> the output file. If none is specified, a patch is generated on the standard output</p>
<dt><code>-inplace </code></p>
<dd> do the modification on the file directly</p>
<dt><code>-outplace </code></p>
<dd> store modifications in a .cocci_res file</p>
<dt><code>-version </code></p>
<dd> show the version of spatch</p>
<dt><code>-date </code></p>
<dd> show the date on which spatch was compiled</p>
<dt><code>-shorthelp </code></p>
<dd> see short list of options</p>
<dt><code>-longhelp </code></p>
<dd> see all the available options in different categories</p>
<dt><code>-help, &#8211;help </code></p>
<dd> show summary of options. </p>
</dl>
<h2>EXAMPLES</h2>
<p>&nbsp;<wbr>&nbsp;<wbr>./spatch -sp_file foo.cocci foo.c </p>
<p> Apply the semantic patch foo.cocci to the C file foo.c. The semantic patch is applied modulo a set of isomorphisms contained in standard.iso (standard.iso is by default located in /usr/local/share/coccinelle/standard.iso). A patch showing the effect of the application, if any, will be generated on the standard output. </p>
<p>&nbsp;<wbr>&nbsp;<wbr>./spatch -sp_file foo.cocci foo.c -o&nbsp;<wbr>/tmp/newfoo.c </p>
<p> The same as the above, except that a modified version of foo.c is stored in /tmp/newfoo.c. </p>
<p> It is also possible to apply spatch to all of the C files in a directory: </p>
<p>&nbsp;<wbr>&nbsp;<wbr>./spatch -cocci_file foo.cocci -dir foodir .&nbsp;<wbr> </p>
<p> If the semantic patch is not working as expected, the option -debug shows selection of information about the application of a semantic patch to a file or directory. </p>
<h2>FILES</h2>
<p> <i>/usr/local/share/coccinelle/standard.iso</i></p>
<dl>
<dt>
<dd> This file contains the default set of isomorphisms.</dl>
<p> <i>/usr/local/share/coccinelle/standard.h</i></p>
<dl>
<dt>
<dd> This file contains the default set of macro hints. </p>
</dl>

</dl>
