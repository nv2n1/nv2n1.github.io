<h2 class="name">NAME</h2>
<p> pbmtoptx &#8211; convert a portable bitmap into Printronix printer graphics </p>
<h2>SYNOPSIS</h2>
<p> <code>pbmtoptx</code> [<i>pbmfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a portable bitmap as input. Produces a file of Printronix printer graphics as output. </p>
<p> Note that there is no ptxtopbm tool &#8211; this transformation is one way.</p>
