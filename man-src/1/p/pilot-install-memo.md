<h2>NAME</h2>
<p> pilot-install-memo &#8211; Installs a new Memo Pad entry onto your Palm handheld.</p>
<h2>SECTION</h2>
<p> pilot-link: Userland conduits </p>
<h2>SYNOPSIS</h2>
<p>&nbsp;<wbr><i>pilot-install-memo</i>&nbsp;<wbr>[<code>-p</code>|<code>&#8211;port</code>&nbsp;<wbr>&lt;<code>port</code>&gt;]&nbsp;<wbr>[<code>&#8211;version</code>]&nbsp;<wbr>[<code>-q</code>|<code>&#8211;quiet</code>]&nbsp;<wbr>[<code>-?</code>|<code>&#8211;help</code>]&nbsp;<wbr>[<code>&#8211;usage</code>]&nbsp;<wbr>[<code>-c</code>|<code>&#8211;category</code>&nbsp;<wbr>&nbsp;<wbr><code>name</code>]&nbsp;<wbr>[<code>-r</code>|<code>&#8211;replace</code>]&nbsp;<wbr>[<code>-t</code>|<code>&#8211;title</code>]&nbsp;<wbr>[<code>-f</code>|<code>&#8211;file</code>&nbsp;<wbr>&nbsp;<wbr><code>STRING</code>&nbsp;<wbr>&#8230;] </p>
<h2>DESCRIPTION</h2>
<p>&nbsp;<wbr><i>pilot-install-memo</i>&nbsp;<wbr>allows the user to write one or more files as a new memo or memos, respectively, onto the Palm handheld. </p>
<h2>OPTIONS</h2>

&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr> </p>

<p> File containing the target memo entry. Append other filenames to install one memo per file. </p>
<p>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr><code>-r</code>,&nbsp;<wbr><code>&#8211;replace</code><br />

<p> Replace all memos in the category specified by the <code>-c</code> <i>category</i> option. </p>

<p> Use the filename as the title for the memo. (Normally, the first line of a memo is used as the title if one is not supplied with the <code>-t</code> option). </p>

<h2>USAGE</h2>
<p> The program will connect to the Palm handheld, and create memo entries for each file(s) given on the commandline into the Memo Pad application on the Palm. </p>

<h2>BUGS</h2>
<h3>Known Bugs</h3>
<p> The Palm Device has a maximum length of 4,096 bytes (4k) on memopad entries, if you wish to retain the ability to edit the Memo (add/remove/change data within the memo) on the Palm itself. You can create a memo entry of 65,490 bytes in size (the absolute maximum) if you do not need to edit the memo entry any further on the Palm device itself. Any memo larger than 4,096 bytes and less than 65,490 bytes will not be editable on the Palm itself. Consider these memo entries &quot;read-only&quot;. </p>
<p> This is not specifically a &quot;bug&quot;, but a limitation in the PalmOS design itself. </p>
