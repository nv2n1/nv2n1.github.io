<h2 class="name">NAME</h2>
<p> pnmtoplainpnm &#8211; convert portable any map to plain (ASCII) anymap format </p>
<h2>SYNOPSIS</h2>
<p> <code>pnmtoplainpnm</code> [<i>pnmfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a portable anymap as input, either from the named file or if no file named, from Standard Input. Writes out the image in plain (ASCII) anymap format to Standard Output. Of the three plain anymap formats, this program generates the one that corresponds naturally to the one of the three anymap formats that is the input (PBM for PBM, etc.).</p>
