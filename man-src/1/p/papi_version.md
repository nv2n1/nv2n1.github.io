<h2 class="name">NAME</h2>
 

 papi_version - papi_version utility. 

 file version.c 

<h2>Name</h2>

 

 papi_version - provides version information for papi.

<h2>Synopsis</h2>

 

 papi_version

<h2>Description</h2>

 

 papi_version is a PAPI utility program that reports version information about the current PAPI installation.

<h2>Bugs</h2>

 

 There are no known bugs in this utility. If you find a bug, it should be reported to the PAPI Mailing List at ptools-perfapi [at] ptools.org.
