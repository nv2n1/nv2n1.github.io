<h2 class="name">NAME</h2>
<p> pooltype &#8211; display a WEB pool file </p>
<h2>SYNOPSIS</h2>
<p> <code>pooltype</code> <i>pool_file_name</i></p>
<h2>DESCRIPTION</h2>
<p> This manual page is not meant to be exhaustive. The complete documentation for this version of TeX can be found in the info file or manual <i>Web2C: A TeX implementation</i>. </p>
<p> The <code>pooltype</code> program translates a (program-oriented) Web string pool file to a (human-oriented) text file. </p>
<p> The <i>pool_file_name</i> must be complete; no adding of default extensions or path searching is done.</p>
