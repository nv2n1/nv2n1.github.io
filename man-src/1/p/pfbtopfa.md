<h2 class="name">NAME</h2>
<p> pfbtopfa &#8211; Convert Postscript .pfb fonts to .pfa format using ghostscript </p>
<h2>SYNOPSIS</h2>
<p> <code>pfbtopfa</code> <i>input.pfb</i> <i>[output.pfa]</i></p>
<h2>DESCRIPTION</h2>
<p> This script invokes <code><a href="/docs/linux/man/1-gs/">gs</a></code>(1) to convert a .pfb file into a .pfa file.</p>
