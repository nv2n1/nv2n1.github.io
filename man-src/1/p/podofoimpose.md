<h2 class="name">NAME</h2>
<p> podofoimpose &#8211; A powerful PDF imposition tool</p>
<h2>SYNOPSIS</h2>
<p> <code>podofoimpose</code> Input Output Plan [Interpretor] </p>
<h2>DESCRIPTION</h2>
<p> <code>podofoimpose</code> is one of the command line tools from the PoDoFo library that provide several useful operations to work with PDF files. It can do imposition of the final output according to the specified imposition plan. </p>
<h2>OPTIONS</h2>
<p> <code>Input</code></p>
<dl>
<dt>
<dd> PDF file or a file which contains a list of PDF file paths.</dl>
<p> <code>Output</code></p>
<dl>
<dt>
<dd> Resulting PDF file.</dl>
<p> <code>Plan</code></p>
<dl>
<dt>
<dd> Imposition plan file.</dl>
<p> <code>[Interpretor]</code></p>
<dl>
<dt>
<dd> Imposition interpretor. It can be &quot;native&quot; (default value) or &quot;lua&quot;.</dl>
