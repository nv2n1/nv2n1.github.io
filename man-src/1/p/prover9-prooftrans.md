<h2>NAME</h2>
<p> prooftrans &#8211; tool for transforming Prover9 proofs</p>
<h2>SYNOPSIS</h2>
<p> <code>prooftrans</code> [<i>parents_only</i>] [<i>expand</i>] [<i>renumber</i>] [<i>striplabels</i>] [<i>-f file</i>]<br />
 <code>prooftrans</code> xml [<i>expand</i>] [<i>renumber</i>] [<i>striplabels</i>] [<i>-f file</i>]<br />
 <code>prooftrans</code> ivy [<i>renumber</i>] [<i>-f file</i>]<br />
 <code>prooftrans</code> hints [<i>-label label</i>] [<i>expand</i>] [<i>striplabels</i>] [<i>-f file</i>]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>prooftrans</code> command. </p>
<p> <code>prooftrans</code> can extract proofs from <code><a href="/docs/linux/man/1-prover9/">prover9</a></code>(1) output files and transform them in various ways. </p>
<h2>OPTIONS</h2>
<p> A summary of options is included below.</p>
<dl>
<dt><code>renumber</code></p>
<dd> Renumber steps.</p>
<dt><code>parents_only</code></p>
<dd> Simplify justifications by listing only parents.</p>
<dt><code>expand</code></p>
<dd> Expand all steps, turning secondary justifications into explicit steps.</p>
<dt><code>xml</code></p>
<dd> Produce proofs in XML.</p>
<dt><code>ivy</code></p>
<dd> Produce proofs for checking by the IVY proof checker.</p>
<dt><code>hints</code></p>
<dd> Produce hints for guiding subsequent searches.</p>
<dt><code>-label </code><i>label</i></p>
<dd> Attach label attributes to the hint clauses consisting of the string <i>label</i> and a sequence number generated by prooftrans.</p>
<dt><code>-f </code><i>file</i></p>
<dd> Take input from <i>file</i> instead of from standard input.</dl>
