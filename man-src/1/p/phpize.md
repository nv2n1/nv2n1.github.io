<h2>NAME</h2>
<p> phpize &#8211; prepare a PHP extension for compiling</p>
<h2>SYNOPSIS</h2>
<p> <code>phpize</code> [options] </p>
<h2>DESCRIPTION</h2>
<p> <code>phpize</code> is a shell script to prepare PHP extension for compiling.</p>
<h2>OPTIONS</h2>
<dl>
<dt>
<dd> <code>&#8211;clean</code> Remove all created files</p>
<dt>
<dd> <code>&#8211;help</code> Prints usage information</p>
<dt>
<dd> <code>&#8211;version</code></p>
<dt>
<dd> <code>-v</code> Prints API version information</p>
<dt>
<dd></dl>
