<h2 class="name">NAME</h2>
<p> podofotxt2pdf &#8211; convert plain text files into PDF files</p>
<h2>SYNOPSIS</h2>
<p> <code>podofotxt2pdf</code> [-fontname &lt;name&gt;] [-utf8] [inputfile] [outputfile] </p>
<h2>DESCRIPTION</h2>
<p> <code>podofotxt2pdf</code> is one of the command line tools from the PoDoFo library that provide several useful operations to work with PDF files. It can convert a plain text file into a PDF file. </p>
<h2>OPTIONS</h2>
<p> <code>-fontname</code> &lt;name&gt;</p>
<dl>
<dt>
<dd>
<p> Use the font &lt;name&gt;.</dl>
<p> <code>-utf8</code></p>
<dl>
<dt>
<dd>
<p> specifies that the input text is UTF8 encoded instead of Windows ANSI encoding.</dl>
<p> <code>[inputfile]</code></p>
<dl>
<dt>
<dd>
<p> Input PDF file.</dl>
<p> <code>[outputfile]</code></p>
<dl>
<dt>
<dd>
<p> Output PDF file.</dl>
