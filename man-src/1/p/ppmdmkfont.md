<h2 class="name">NAME</h2>
<p> ppmdmkfont &#8211; Create Ppmdfont &#8216;standard&#8217;.</p>
<h2>SYNOPSIS</h2>
<p> <code>ppmdmkfont</code> </p>
<h2>DESCRIPTION</h2>
<p> This program is part of <code><a href="/docs/linux/man/1-netpbm/">Netpbm</a></code>(1) </p>
<p> <code>ppmdmkfont</code> creates the &#8216;standard&#8217; Ppmdfont font as a Ppmdfont file. It has no input; it always generates identical files. </p>
<p> (There are no arguments or options) </p>
<p> This program is useful mainly as an example for creating other fonts. <code>libnetpbm</code> has the &#8216;standard&#8217; font built in. </p>
<p> See <code>Libnetpbm</code>PPM<code>Drawing</code>Function Manual (1)<br />
&nbsp;<wbr>for details on Ppmdfont files. </p>
