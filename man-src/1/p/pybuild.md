<h2 class="name">NAME</h2>
<p> pybuild &#8211; invokes various build systems for requested Python versions in order to build modules and extensions </p>
<h2>SYNOPSIS</h2>
<p> pybuild [ACTION] [BUILD SYSTEM ARGUMENTS] [DIRECTORIES] [OPTIONS]</p>
<h2>DEBHELPER COMMAND SEQUENCER INTEGRATION</h2>
<dl>
<dt>&bull;</p>
<dd> build depend on <i>dh-python</i>,</p>
<dt>&bull;</p>
<dd> build depend on <i>python3-all</i>, <i>python-all-dbg</i>, <i>pypy</i>, etc. (for all supported Python interpreters, pybuild will use it to create a list of interpreters to build for),</p>
<dt>&bull;</p>
<dd> add <i>&#8211;buildsystem=pybuild</i> to dh&#8217;s arguments in debian/rules,</p>
<dt>&bull;</p>
<dd> if more than one binary package is build: add debian/python-foo.install files, or <i>export PYBUILD_NAME=modulename</i> (modulename will be used to guess binary package prefixes), or <i>export PYBUILD_DESTDIR</i> env. variables in debian/rules </p>
<p> debian/rules file example: </p>
<pre>
#! /usr/bin/make -f
export PYBUILD_NAME=foo
%:
       dh $@ --with python2,python3 --buildsystem=pybuild
</pre>
</dl>
<h2>OPTIONS</h2>
<p> Most options can be set (in addition to command line) via environment variables. PyBuild will check:</p>
<dl>
<dt>&bull;</p>
<dd> PYBUILD_OPTION_VERSIONED_INTERPRETER (f.e. PYBUILD_CLEAN_ARGS_python3.2)</p>
<dt>&bull;</p>
<dd> PYBUILD_OPTION_INTERPRETER (f.e. PYBUILD_CONFIGURE_ARGS_python3-dbg)</p>
<dt>&bull;</p>
<dd> PYBUILD_OPTION (f.e. PYBUILD_INSTALL_ARGS)</dl>
<h3>optional arguments</h3>
<dl>
<dt><code>-h</code>,<code> &#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-v</code>,<code> &#8211;verbose</code></p>
<dd> turn verbose mode on</p>
<dt><code>-q</code>,<code> &#8211;quiet</code></p>
<dd> doesn&#8217;t show external command&#8217;s output</p>
<dt><code>-q</code><i>q</i>,<code>&nbsp;&#8211;really-quiet</code></p>
<dd> be quiet</p>
<dt><code>&#8211;version</code></p>
<dd> show program&#8217;s version number and exit</dl>
<h3>ACTION</h3>
<p> The default is to build, install and test the library using detected build system version by version. Selecting one of following actions, will invoke given action for all versions &#8211; one by one &#8211; which (contrary to the default action) in some build systems can overwrite previous results.</p>
<dl>
<dt><code>&#8211;detect</code></p>
<dd> return the name of detected build system</p>
<dt><code>&#8211;clean</code></p>
<dd> clean files using auto-detected build system specific methods</p>
<dt><code>&#8211;configure</code></p>
<dd> invoke configure step for all requested Python versions</p>
<dt><code>&#8211;build</code></p>
<dd> invoke build step for all requested Python versions</p>
<dt><code>&#8211;install</code></p>
<dd> invoke install step for all requested Python versions</p>
<dt><code>&#8211;test</code></p>
<dd> invoke tests for auto-detected build system</p>
<dt><code>&#8211;list-systems</code></p>
<dd> list available build systems and exit</p>
<dt><code>&#8211;print</code></p>
<dd> print pybuild&#8217;s internal parameters</dl>
<h3>TESTS</h3>
<p> unittest&#8217;s discover from standard library (available in Python 2.7 and &gt;= 3.2) is used in test step by default.</p>
<dl>
<dt><code>&#8211;test-nose</code></p>
<dd> use nose module in test step, remember to add python-nose and/or python3-nose to Build-Depends</p>
<dt><code>&#8211;test-pytest</code></p>
<dd> use pytest module in test step, remember to add python-pytest and/or python3-pytest to Build-Depends</p>
<dt><code>&#8211;test-tox</code></p>
<dd> use tox command in test step, remember to add python-tox to Build-Depends. Requires tox.ini file</dl>
<h3>testfiles</h3>
<p> Tests are invoked from within build directory to make sure newly built files are tested instead of source files. If test suite requires other files in this directory, you can list them in <i>debian/pybuild.testfiles</i> file (you can also use <i>debian/pybuild-pythonX.testfiles</i> or <i>debian/pybuild-pythonX.Y.testfiles</i>) and files listed there will be copied before test step and removed before install step. By default only <i>test</i> and <i>tests</i> directories are copied to build directory.</p>
<h3>BUILD SYSTEM ARGUMENTS</h3>
<p> Additional arguments passed to the build system. &#8211;system=custom requires complete command in &#8211;foo-args parameters.</p>
<dl>
<dt><code>&#8211;before-clean</code><i>&nbsp;COMMAND</i></p>
<dd> invoked before the clean command</p>
<dt><code>&#8211;clean-args</code><i>&nbsp;ARGUMENTS</i></p>
<dd> arguments added to clean command generated by build system plugin</p>
<dt><code>&#8211;after-clean</code><i>&nbsp;COMMAND</i></p>
<dd> invoked after the clean command</p>
<dt><code>&#8211;before-configure</code><i>&nbsp;COMMAND</i></p>
<dd> invoked before the configure command</p>
<dt><code>&#8211;configure-args</code><i>&nbsp;ARGUMENTS</i></p>
<dd> arguments added to configure command generated by build system plugin</p>
<dt><code>&#8211;after-configure</code><i>&nbsp;COMMAND</i></p>
<dd> invoked after the configure command</p>
<dt><code>&#8211;before-build</code><i>&nbsp;COMMAND</i></p>
<dd> invoked before the build command</p>
<dt><code>&#8211;build-args</code><i>&nbsp;ARGUMENTS</i></p>
<dd> arguments added to build command generated by build system plugin</p>
<dt><code>&#8211;after-build</code><i>&nbsp;COMMAND</i></p>
<dd> invoked after the build command</p>
<dt><code>&#8211;before-install</code><i>&nbsp;COMMAND</i></p>
<dd> invoked before the install command</p>
<dt><code>&#8211;install-args</code><i>&nbsp;ARGUMENTS</i></p>
<dd> arguments added to install command generated by build system plugin</p>
<dt><code>&#8211;after-install</code><i>&nbsp;COMMAND</i></p>
<dd> invoked after the install command</p>
<dt><code>&#8211;before-test</code><i>&nbsp;COMMAND</i></p>
<dd> invoked before the test command</p>
<dt><code>&#8211;test-args</code><i>&nbsp;ARGUMENTS</i></p>
<dd> arguments added to test command generated by build system plugin</p>
<dt><code>&#8211;after-test</code><i>&nbsp;COMMAND</i></p>
<dd> invoked after the test command</dl>
<h3>variables that can be used in <i>ARGUMENTS</i> and <i>COMMAND</i></h3>
<dl>
<dt>&bull;</p>
<dd> <i>{version}</i> will be replaced with current Python version, you can also use <i>{version.major}</i>, <i>{version.minor}</i>, etc.</p>
<dt>&bull;</p>
<dd> <i>{interpreter}</i> will be replaced with current interpreter, you can also use <i>{interpreter.include_dir}</i></p>
<dt>&bull;</p>
<dd> <i>{dir}</i> will be replaced with sources directory,</p>
<dt>&bull;</p>
<dd> <i>{destdir}</i> will be replaced with destination directory,</p>
<dt>&bull;</p>
<dd> <i>{home_dir}</i> will be replaced with temporary HOME directory, where plugins can keep their data (.pybuild/interpreter_version/ by default),</p>
<dt>&bull;</p>
<dd> <i>{build_dir}</i> will be replaced with build directory</p>
<dt>&bull;</p>
<dd> <i>{install_dir}</i> will be replaced with install directory.</p>
<dt>&bull;</p>
<dd> <i>{package}</i> will be replaced with suggested package name, if &#8211;name (or PYBUILD_NAME) is set to <i>foo</i>, this variable will be replaced to <i>python-foo</i>, <i>python3-foo</i> or <i>pypy-foo</i> depending on interpreter which is used in given iteration.</dl>
<h3>DIRECTORIES</h3>
<dl>
<dt><code>-d</code><i>&nbsp;DIR</i>,<code>&nbsp;&#8211;dir</code><i>&nbsp;DIR</i></p>
<dd> set source files directory &#8211; base for other relative dirs [by default: current working directory]</p>
<dt><code>&#8211;dest-dir</code><i>&nbsp;DIR</i></p>
<dd> set destination directory [default: debian/tmp]</p>
<dt><code>&#8211;ext-dest-dir</code><i>&nbsp;DIR</i></p>
<dd> set destination directory for .so files</p>
<dt><code>&#8211;ext-pattern</code><i>&nbsp;PATTERN</i></p>
<dd> regular expression for files that should be moved if &#8211;ext-dest-dir is set [default: <i>.so(.[^/]*)?$</i>]</p>
<dt><code>&#8211;ext-sub-pattern</code><i>&nbsp;PATTERN</i></p>
<dd> regular expression for part of path/filename matched in &#8211;ext-pattern that should be removed or replaced with &#8211;ext-sub-repl</p>
<dt><code>&#8211;ext-sub-repl</code><i>&nbsp;PATTERN</i></p>
<dd> replacement for matches in &#8211;ext-sub-pattern</p>
<dt><code>&#8211;install-dir</code><i>&nbsp;DIR</i></p>
<dd> set installation directory [default: &#8230;/dist-packages]</p>
<dt><code>&#8211;name</code><i>&nbsp;NAME</i></p>
<dd> use this name to guess destination directories (depending on interpreter, &quot;foo&quot; sets debian/python-foo, debian/python3-foo, debian/python3-foo-dbg, etc.)</dl>
<h3>variables that can be used in <i>DIR</i></h3>
<dl>
<dt>&bull;</p>
<dd> <i>{version}</i> will be replaced with current Python version,</p>
<dt>&bull;</p>
<dd> <i>{interpreter}</i> will be replaced with selected interpreter.</dl>
<h3>LIMITATIONS</h3>
<dl>
<dt><code>-s</code><i>&nbsp;SYSTEM</i>,<code>&nbsp;&#8211;system</code><i>&nbsp;SYSTEM</i></p>
<dd> select a build system [default: auto-detection]</p>
<dt><code>-p</code><i>&nbsp;VERSIONS</i>,<code>&nbsp;&#8211;pyver</code><i>&nbsp;VERSIONS</i></p>
<dd> build for Python VERSIONS. This option can be used multiple times. Versions can be separated by space character. The default is all Python 3.X supported versions.</p>
<dt><code>-i</code><i>&nbsp;INTERPRETER</i>,<code>&nbsp;&#8211;interpreter</code><i>&nbsp;INTERPRETER</i></p>
<dd> change interpreter [default: python{version}]</p>
<dt><code>&#8211;disable</code><i>&nbsp;ITEMS</i></p>
<dd> disable action, interpreter, version or any mix of them. Note that f.e. python3 and python3-dbg are two different interpreters, &#8211;disable test/python3 doesn&#8217;t disable python3-dbg&#8217;s tests.</dl>
<h3>disable examples</h3>
<dl>
<dt>&bull;</p>
<dd> <i>&#8211;disable test/python2.5-dbg</i> &#8211; disables tests for python2.5-dbg</p>
<dt>&bull;</p>
<dd> <i>&#8211;disable &#8216;2.4 2.7&#8217;</i> &#8211; disables all actions for version 2.4 and 2.7</p>
<dt>&bull;</p>
<dd> <i>PYBUILD_DISABLE_python2=1</i> &#8211; disables all actions for Python 2.X</p>
<dt>&bull;</p>
<dd> <i>PYBUILD_DISABLE_python3.3=test</i> &#8211; disables tests for Python 3.3</p>
<dt>&bull;</p>
<dd> <i>PYBUILD_DISABLE=test/python3.3</i> &#8211; same as above</p>
<dt>&bull;</p>
<dd> <i>PYBUILD_DISABLE=configure/python3 2.4 pypy</i> &#8211; disables configure action for all python3 interpreters, all actions for version 2.4, and all actions for pypy</dl>
