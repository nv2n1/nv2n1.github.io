<h2 class="name">NAME</h2>
<p> pycolor &#8211; Colorize a python file or stdin using ANSI and print to stdout. </p>
<h2>SYNOPSIS</h2>
<p> <code>pycolor</code> [<i>options</i>] [<i>file</i>]</p>
<h2>DESCRIPTION</h2>
<p> Prints a colorized version of the input file (or standard input if no file is given, or the file name &#8211; is given) to standard out.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Output a brief help message.</p>
<dt><code>-s, &#8211;scheme &lt;scheme&gt;</code></p>
<dd> Give the color scheme to use. Currently only Linux (default), LightBG, and NOColor are implemented.</dl>
