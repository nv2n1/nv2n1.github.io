<h2>NAME</h2>
<p> pltek &#8211; review a Tektronix vector file.</p>
<h2>SYNOPSIS</h2>
<p> <code>pltek</code> <i>file</i></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>pltek</code> command. </p>
<p> <code>pltek</code> is a program that review a Tektronix vector file whose name is given as argument.</p>
