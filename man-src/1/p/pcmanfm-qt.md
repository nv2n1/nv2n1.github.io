<h2>NAME</h2>
<p> PCManFM-Qt &#8211; A lightweight Qt-based file manager for X Window.</p>
<h2>SYNOPSIS</h2>
<p> pcmanfm-qt [OPTION&#8230;] [FILE1, FILE2,&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> PCMan File Manager Qt (<code>PCManFM-Qt</code>) is an extremely fast, lightweight, yet feature-rich file manager with tabbed browsing. It is the default file manager for the lightweight desktop environment <code>LXQt</code>.</p>
<h2>OPTIONS</h2>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show help options</dl>
<h3>Application Options:</h3>
<dl>
<dt><code>-p</code>, <code>&#8211;profile</code>=<i>,PROFILE/</i></p>
<dd> Set name of configuration profile</p>
<dt><code>-d</code>, <code>&#8211;daemon-mode</code></p>
<dd> Run PCManFM as a daemon</p>
<dt><code>&#8211;quit</code></p>
<dd> Quit PCManFM</p>
<dt><code>&#8211;desktop</code></p>
<dd> Launch desktop manager</p>
<dt><code>&#8211;desktop-off</code></p>
<dd> Turn off desktop manager if it&#8217;s running</p>
<dt><code>&#8211;desktop-pref</code>=<i>,NAME/</i></p>
<dd> Open desktop preference dialog on the page with the specified name</p>
<dt><code>-w</code>, <code>&#8211;set-wallpaper</code>=<i>,FILE/</i></p>
<dd> Set desktop wallpaper from image FILE</p>
<dt><code>&#8211;wallpaper-mode</code>=<i>,MODE/</i></p>
<dd> Set mode of desktop wallpaper. MODE=(color|stretch|fit|center|tile)</p>
<dt><code>&#8211;show-pref</code>=<i>,NAME/</i></p>
<dd> Open Preferences dialog on the page with the specified name</p>
<dt><code>-n</code>, <code>&#8211;new-window</code></p>
<dd> Open new window</p>
<dt><code>-f</code>, <code>&#8211;find-files</code></p>
<dd> Open Find Files utility</dl>
