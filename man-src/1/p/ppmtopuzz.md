<h2 class="name">NAME</h2>
<p> ppmtopuzz &#8211; convert a portable pixmap into an X11 &quot;puzzle&quot; file </p>
<h2>SYNOPSIS</h2>
<p> <code>ppmtopuzz</code> [<i>ppmfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a portable pixmap as input. Produces an X11 &quot;puzzle&quot; file as output. A &quot;puzzle&quot; file is for use with the <i>puzzle</i> program included with the X11 distribution &#8211; <i>puzzle</i>&#8216;s <code>-picture</code> flag lets you specify an image file.</p>
