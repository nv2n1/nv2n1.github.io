<h2 class="name">NAME</h2>
<p> podofoimgextract &#8211; Extract all images from a PDF file</p>
<h2>SYNOPSIS</h2>
<p> <code>podofoimgextract</code> [inputfile] [outputdirectory] </p>
<h2>DESCRIPTION</h2>
<p> <code>podofoimgextract</code> is one of the command line tools from the PoDoFo library that provide several useful operations to work with PDF files. Itw can extract all images from a PDF file into the specified output directory. </p>
