<h2 class="name">NAME</h2>
<p> perl586delta &#8211; what is new for perl v5.8.6 </p>
<h2>DESCRIPTION</h2>
<p> This document describes differences between the 5.8.5 release and the 5.8.6 release.</p>
<h2>Incompatible Changes</h2>
<p> There are no changes incompatible with 5.8.5.</p>
<h2>Core Enhancements</h2>
<p> The perl interpreter is now more tolerant of UTF-16-encoded scripts. </p>
<p> On Win32, Perl can now use non-IFS compatible LSPs, which allows Perl to work in conjunction with firewalls such as McAfee Guardian. For full details see the file <i></i><font SIZE="-1"><i>README</i></font><i>.win32</i>, particularly if you&#8217;re running Win95.</p>
<h2>Modules and Pragmata</h2>
<dl>
<dt>&bull;</p>
<dd> With the <tt>&quot;base&quot;</tt> pragma, an intermediate class with no fields used to messes up private fields in the base class. This has been fixed.</p>
<dt>&bull;</p>
<dd> Cwd upgraded to version 3.01 (as part of the new PathTools distribution)</p>
<dt>&bull;</p>
<dd> Devel::PPPort upgraded to version 3.03</p>
<dt>&bull;</p>
<dd> File::Spec upgraded to version 3.01 (as part of the new PathTools distribution)</p>
<dt>&bull;</p>
<dd> Encode upgraded to version 2.08</p>
<dt>&bull;</p>
<dd> ExtUtils::MakeMaker remains at version 6.17, as later stable releases currently available on <font SIZE="-1">CPAN</font> have some issues with core modules on some core platforms.</p>
<dt>&bull;</p>
<dd> I18N::LangTags upgraded to version 0.35</p>
<dt>&bull;</p>
<dd> Math::BigInt upgraded to version 1.73</p>
<dt>&bull;</p>
<dd> Math::BigRat upgraded to version 0.13</p>
<dt>&bull;</p>
<dd> MIME::Base64 upgraded to version 3.05</p>
<dt>&bull;</p>
<dd> POSIX::sigprocmask function can now retrieve the current signal mask without also setting it.</p>
<dt>&bull;</p>
<dd> Time::HiRes upgraded to version 1.65</dl>
<h2>Utility Changes</h2>
<p> Perl has a new -dt command-line flag, which enables threads support in the debugger.</p>
<h2>Performance Enhancements</h2>
<p> <tt>&quot;reverse sort ...&quot;</tt> is now optimized to sort in reverse, avoiding the generation of a temporary intermediate list. </p>
<p> <tt>&quot;for (reverse @foo)&quot;</tt> now iterates in reverse, avoiding the generation of a temporary reversed list.</p>
<h2>Selected Bug Fixes</h2>
<p> The regexp engine is now more robust when given invalid utf8 input, as is sometimes generated by buggy <font SIZE="-1">XS</font> modules. </p>
<p> <tt>&quot;foreach&quot;</tt> on threads::shared array used to be able to crash Perl. This bug has now been fixed. </p>
<p> A regexp in <tt>&quot;STDOUT&quot;</tt>&#8216;s destructor used to coredump, because the regexp pad was already freed. This has been fixed. </p>
<p> <tt>&quot;goto &amp;&quot;</tt> is now more robust &#8211; bugs in deep recursion and chained <tt>&quot;goto &amp;&quot;</tt> have been fixed. </p>
<p> Using <tt>&quot;delete&quot;</tt> on an array no longer leaks memory. A <tt>&quot;pop&quot;</tt> of an item from a shared array reference no longer causes a leak. </p>
<p> <tt>&quot;eval_sv()&quot;</tt> failing a taint test could corrupt the stack &#8211; this has been fixed. </p>
<p> On platforms with 64 bit pointers numeric comparison operators used to erroneously compare the addresses of references that are overloaded, rather than using the overloaded values. This has been fixed. </p>
<p> <tt>&quot;read&quot;</tt> into a UTF8-encoded buffer with an offset off the end of the buffer no longer mis-calculates buffer lengths. </p>
<p> Although Perl has promised since version 5.8 that <tt>&quot;sort()&quot;</tt> would be stable, the two cases <tt>&quot;sort {$b cmp $a}&quot;</tt> and <tt>&quot;sort {$b &lt;=&gt; $a}&quot;</tt> could produce non-stable sorts. This is corrected in perl5.8.6. </p>
<p> Localising <tt>$^D</tt> no longer generates a diagnostic message about valid -D flags.</p>
<h2>New or Changed Diagnostics</h2>
<p> For -t and -T,<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;Too late for&nbsp;&#8220;-T&#8221;&nbsp;option has been changed to the more informative<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;&#8220;-T&#8221;&nbsp;is on the&nbsp;#!&nbsp;line, it must also be used on the command line</p>
<h2>Changed Internals</h2>
<p> From now on all applications embedding perl will behave as if perl were compiled with -DPERL_USE_SAFE_PUTENV. See &#8220;Environment access&#8221; in the <i></i><font SIZE="-1"><i>INSTALL</i></font><i></i> file for details. </p>
<p> Most <tt>&quot;C&quot;</tt> source files now have comments at the top explaining their purpose, which should help anyone wishing to get an overview of the implementation.</p>
<h2>New Tests</h2>
<p> There are significantly more tests for the <tt>&quot;B&quot;</tt> suite of modules.</p>
<h2>Reporting Bugs</h2>
<p> If you find what you think is a bug, you might check the articles recently posted to the comp.lang.perl.misc newsgroup and the perl bug database at <a rel="nofollow" href="http://bugs.perl.org.">http://bugs.perl.org.</a> There may also be information at <a rel="nofollow" href="http://www.perl.org,">http://www.perl.org,</a> the Perl Home Page. </p>
<p> If you believe you have an unreported bug, please run the <code>perlbug</code> program included with your release. Be sure to trim your bug down to a tiny but sufficient test case. Your bug report, along with the output of <tt>&quot;perl -V&quot;</tt>, will be sent off to perlbug [at] perl.org to be analysed by the Perl porting team. You can browse and search the Perl 5 bugs at <a rel="nofollow" href="http://bugs.perl.org/">http://bugs.perl.org/</a></p>
