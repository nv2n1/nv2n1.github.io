<h2 class="name">NAME</h2>
<p> profile2map &#8211; Fuse profiler output converter </p>
<h2>SYNOPSIS</h2>
<p> <code>profile2map</code> <i>infile outfile</i></p>
<h2>DESCRIPTION</h2>
<p> profile2map converts Fuse profiler output into Z80-style map format.</p>
<h2>OPTIONS</h2>
<dl>
<dt><i>infile</i></p>
<dd> specifies the Fuse profiler output to be converted.</p>
<dt><i>outfile</i></p>
<dd> specifies the Z80 map file for output.</dl>
<h2>BUGS</h2>
<p> None known.</p>
