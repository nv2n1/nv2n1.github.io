<h2>NAME</h2>
<p> poconflicts &#8211; Conflict finder for Gettext PO localization files.</p>
<h2>SYNOPSIS</h2>
<p> <code>poconflicts </code>[&#8211;version] [-h|&#8211;help] [&#8211;manpage] [&#8211;progress <i>PROGRESS</i>] [&#8211;errorlevel <i>ERRORLEVEL</i>] [-i|&#8211;input] <i>INPUT</i> [-x|&#8211;exclude <i>EXCLUDE</i>] [-o|&#8211;output] <i>OUTPUT</i> [-I|&#8211;ignore-case] [-v|&#8211;invert] [&#8211;accelerator <i>ACCELERATORS</i>]</p>
<h2>DESCRIPTION</h2>
<p> See: <a rel="nofollow" href="http://docs.translatehouse.org/projects/translate-toolkit/en/latest/commands/poconflicts.html">http://docs.translatehouse.org/projects/translate-toolkit/en/latest/commands/poconflicts.html</a> for examples and usage instructions.</p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;version</p>
<dd> show program&#8217;s version number and exit</p>
<dt>-h/&#8211;help</p>
<dd> show this help message and exit</p>
<dt>&#8211;manpage</p>
<dd> output a manpage based on the help</p>
<dt>&#8211;progress</p>
<dd> show progress as: dots, none, bar, names, verbose</p>
<dt>&#8211;errorlevel</p>
<dd> show errorlevel as: none, message, exception, traceback</p>
<dt>-i/&#8211;input</p>
<dd> read from INPUT in po format</p>
<dt>-x/&#8211;exclude</p>
<dd> exclude names matching EXCLUDE from input paths</p>
<dt>-o/&#8211;output</p>
<dd> write to OUTPUT in po format</p>
<dt>-I/&#8211;ignore-case</p>
<dd> ignore case distinctions</p>
<dt>-v/&#8211;invert</p>
<dd> invert the conflicts thus extracting conflicting destination words</p>
<dt>&#8211;accelerator</p>
<dd> ignores the given accelerator characters when matching </p>
</dl>
