<h2 class="name">NAME</h2>
<p> pl2pm &#8211; Rough tool to translate Perl4 .pl files to Perl5 .pm modules. </p>
<h2>SYNOPSIS</h2>
<p> <code>pl2pm</code> <i>files</i></p>
<h2>DESCRIPTION</h2>
<p> <code>pl2pm</code> is a tool to aid in the conversion of Perl4-style .pl library files to Perl5-style library modules. Usually, your old .pl file will still work fine and you should only use this tool if you plan to update your library to use some of the newer Perl 5 features, such as AutoLoading.</p>
<h2>LIMITATIONS</h2>
<p> It&#8217;s just a first step, but it&#8217;s usually a good first step.</p>
