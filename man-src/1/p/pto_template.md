<h2 class="name">NAME</h2>
<p> pto_template &#8211; Apply a template file </p>
<h2>SYNOPSIS</h2>
<p> <code>pto_template</code> [options] input.pto</p>
<h2>DESCRIPTION</h2>
<p> <code>pto_template</code> adds a template file to <font SIZE="-1">PTO</font></p>
<h2>USAGE</h2>
<pre>
   pto_template --template=template.pto
</pre>
<h2>OPTIONS</h2>
<dl>
<dt><code>-o</code> | &#8211;output=file.pto</p>
<dd> Output Hugin <font SIZE="-1">PTO</font> file. Default: &lt;filename&gt;_template.pto</p>
<dt><code>&#8211;template=template.pto</code></p>
<dd> Apply the given template file.</p>
<dt><code>-h</code> | &#8211;help</p>
<dd> Shows this help</dl>
