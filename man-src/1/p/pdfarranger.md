<h2 class="name">NAME</h2>
<p> PDF Arranger &#8211; Application for PDF Merging, Rearranging, Splitting, and Cropping </p>
<h2>SYNOPSIS</h2>
<p> <code>pdfarranger [file1] [file2] &#8230;</code></p>
<h2>DESCRIPTION</h2>
<p> <code>PDF Arranger</code> is a small python-gtk application, which helps the user to merge or split pdf documents and rearrange their pages using an interactive and intuitive graphical interface. In the current version, page rotation and cropping is also supported. PDF Arranger is a frontend for pikepdf.</p>
<h2>OPTIONS</h2>
<p> Currently PDF Arranger doesn&#8217;t receive any options.</p>
<h2>FILES</h2>
<p> $HOME/.config/pdfarranger/config.ini</p>
<h2>ENVIRONMENT</h2>
<p> All gtk related environment variables.</p>
<h2>DIAGNOSTICS</h2>
