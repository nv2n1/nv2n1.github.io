<h2 class="name">NAME</h2>
<p> <code>plist &#8211; list contents of output files generated by AS</code></p>
<h2>SYNTAX</h2>
<p> <code>plist</code> [ file name ] </p>
<h2>DESCRIPTION</h2>
<p> PLIST is a program to list the contents of code output files generated by AS, a cross assembler for a variety of microprocessors and -controllers. PLIST takes only one argument: the name of the file to list. If [ name ] does not have an extension, the default extension &#8216;.p&#8217; will be added automatically. The output consists of a single line for each record in the file, listing the target processor, target address space, number of code/data bytes, and start/stop address. Note that the difference between the start and stop address need not equal the number of bytes, since there are target processors whose memory is not bytewise-organized. The records that specify entry address and file creator have a different layout and therefore have a little bit different look in PLIST&#8217;s output. </p>
<p> PLIST does not accept multiple file arguments; processing of several files must be done with individual calls. </p>
<h2>COMMAND-LINE PARAMETERS</h2>
<p> none. </p>
<h2>NATIONAL LANGUAGE SUPPORT</h2>
<p> plist supports national languages in the same way as AS. See the manual page for <a href="/docs/linux/man/1-asl/">asl</a>(1) for more information about this. </p>
<h2>RETURN CODES</h2>
<p> <code>plist</code> may return with the following codes:</p>
<dl>
<dt><code>0</code></p>
<dd> no errors.</p>
<dt><code>1</code></p>
<dd> incorrect command line parameters.</p>
<dt><code>2</code></p>
<dd> I/O-error.</p>
<dt><code>3</code></p>
<dd> An input file had an incorrect format. </p>
</dl>
<h2>EXAMPLES</h2>
<p> To list the contents of a code file <code>file1.p,</code> use: </p>
<p> <code>plist file1</code> </p>
<p> There aren&#8217;t more meaningful examples, as PLIST does not have any command line parameters. </p>
<h2>TIPS</h2>
<p> If PLIST is started without any argument, it will prompt for a file&#8217;s name. </p>

<p> PLIST originally appeared as an AS tool in 1992, written in Borland-Pascal, and was ported to C and UNIX in 1996. </p>
