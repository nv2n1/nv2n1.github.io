<h2 class="name">NAME</h2>
 

 papi_component_avail - papi_component_avail utility. 

 file component.c 

<h2 class="name">NAME</h2>
 

 

 papi_native_avail - provides detailed information for PAPI native events. 

<h2>Synopsis</h2>

 

<h2>Description</h2>

 

 papi_component_avail is a PAPI utility program that reports information about the components papi was built with.

<h2>Options</h2>

 

<dl>
<dt>&bull;
<dd> -h help message
<dt>&bull;
<dd> -d provide detailed information about each component.</dl>
 

<h2>Bugs</h2>

 

 There are no known bugs in this utility. If you find a bug, it should be reported to the PAPI Mailing List at ptools-perfapi [at] ptools.org.
