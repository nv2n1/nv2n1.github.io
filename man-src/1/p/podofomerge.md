<h2 class="name">NAME</h2>
<p> podofomerge &#8211; merge several PDF files</p>
<h2>SYNOPSIS</h2>
<p> <code>podofomerge</code> [inputfile1] [inputfile2] [outputfile] </p>
<h2>DESCRIPTION</h2>
<p> <code>podofomerge</code> is one of the command line tools from the PoDoFo library that provide several useful operations to work with PDF files. It can merge several PDF files. </p>
