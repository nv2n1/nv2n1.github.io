<p>PythonNWSSleighWorker &#8211; Executes the Python NWS Sleigh Worker</p>
<h2>Synopsis</h2>
<p><code>PythonNWSSleighWorker</code></p>
<h2>Description</h2>
<p>This script is executed on the worker machines, possibly via ssh, to start the Python NWS sleigh workers. It is executed when constructing a Sleigh object, and is intended for internal use.</p>
