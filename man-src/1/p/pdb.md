<h2 class="name">NAME</h2>
<p> pdb2.7 &#8211; the Python debugger </p>
<h2>SYNOPSIS</h2>
<p> <code>pdb2.7</code> <i>script [&#8230;]</i></p>
<h2>DESCRIPTION</h2>
<p> See /usr/lib/python2.7/pdb.doc for more information on the use of pdb. When the debugger is started, help is available via the help command.</p>
<h2>SEE ALSO</h2>
<p> <a href="/docs/linux/man/1-python2-7/">python2.7</a>(1). Chapter 9 of the Python Library Reference (The Python Debugger). Available in the python2.7-doc package at /usr/share/doc/python2.7/html/lib/module-pdb.html. </p>
