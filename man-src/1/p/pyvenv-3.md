<h2 class="name">NAME</h2>
<p> pyvenv-3.3 &#8211; create virtual python environments </p>
<h2>DESCRIPTION</h2>
<p> usage: venv [-h] [&#8211;system-site-packages] [&#8211;symlinks] [&#8211;clear] [&#8211;upgrade]</p>
<dl>
<dt>
<dd> ENV_DIR [ENV_DIR &#8230;]</dl>
<p> Creates virtual Python environments in one or more target directories.</p>
<h3>positional arguments:</h3>
<dl>
<dt>ENV_DIR</p>
<dd> A directory to create the environment in.</dl>
<h3>optional arguments:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>&#8211;system-site-packages</code></p>
<dd> Give the virtual environment access to the system site-packages dir.</p>
<dt><code>&#8211;symlinks</code></p>
<dd> Attempt to symlink rather than copy.</p>
<dt><code>&#8211;clear</code></p>
<dd> Delete the environment directory if it already exists. If not specified and the directory exists, an error is raised.</p>
<dt><code>&#8211;upgrade</code></p>
<dd> Upgrade the environment directory to use this version of Python, assuming Python has been upgraded in-place. </p>
</dl>
