<h2 class="name">NAME</h2>
<p> pjtoppm &#8211; convert an HP PaintJet file to a portable pixmap </p>
<h2>SYNOPSIS</h2>
<p> <code>pjtoppm</code> [<i>paintjet</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads an HP PaintJet file as input and converts it into a portable pixmap. This was a quick hack to save some trees, and it only handles a small subset of the paintjet commands. In particular, it will only handle enough commands to convert most raster image files.</p>
