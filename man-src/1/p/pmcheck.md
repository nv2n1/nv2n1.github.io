<h2 class="name">NAME</h2>
 

 pmcheck - check that Perl is set up correctly for Perl modules 

<h2>DESCRIPTION</h2>

 pmcheck checks that Perl is correctly set up for Perl modules. For now, pmcheck just verifies that the entries in <tt>@INC</tt> are existing readable directories.
