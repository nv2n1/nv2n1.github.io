<h2 class="name">NAME</h2>
<p> ppmtoneo &#8211; convert a portable pixmap into an Atari Neochrome .neo file </p>
<h2>SYNOPSIS</h2>
<p> <code>ppmtoneo</code> [<i>ppmfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a portable pixmap as input. Produces an Atari Neochrome .neo file as output.</p>
