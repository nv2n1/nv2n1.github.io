<h2 class="name">NAME</h2>
<p> psfgettable &#8211; extract the embedded Unicode character table from a console font </p>
<h2>SYNOPSIS</h2>
<p> <code>psfgettable</code> <i>fontfile</i> [<i>outfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>psfgettable</code> extracts the embedded Unicode character table from a .psf format console font into a human readable ASCII file of the format used by <code><a href="/docs/linux/man/1-psfaddtable/">psfaddtable</a></code>(1). If the font file name is a single dash (-), the font is read from standard input.</p>
