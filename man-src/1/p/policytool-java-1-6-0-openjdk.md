<p>policytool &#8211; PolicyTool Administration GUI Utility </p>
<p> <code>policytool</code> reads and writes a plain text policy file based on user input via the utility GUI. </p>
<h2>Synopsis</h2>
<dl COMPACT>
<dd>
<dl COMPACT>
<dt>&nbsp;<wbr></p>
<dd>
<dt>Run the policytool Administrator&#8217;s utility</p>
<dd><tt>policytool</tt></p>
<dt>Run policytool and load the specified policy file</p>
<dd><tt>policytool</tt><i>[-file&nbsp;<wbr></i><i>filename</i><i>]</i></p>
<dt>&nbsp;<wbr></p>
<dd>
<dt>where:</p>
<dd>
<dl COMPACT>
<dd>
<dl COMPACT>
<dt>file</p>
<dd>directs <i>policytool</i> to load a local policy file</p>
<dt>filename</p>
<dd>The file name</dl>
</dl>
</dl>
</dl>
<h2>Description</h2>
<p><code>policytool</code> is a GUI that allows users to create and manage policy files. For details, see <i>the Policytool Users Guide</i> @ <a rel="nofollow" href="http://java.sun.com/javase/6/docs/technotes/guides/security/PolicyGuide.html.">http://java.sun.com/javase/6/docs/technotes/guides/security/PolicyGuide.html.</a> </p>
<h2>Options</h2>
<dl COMPACT>
<dd>
<dl COMPACT>
<dt>file</p>
<dd>Loads <i>filename</i>.</dl>
</dl>
