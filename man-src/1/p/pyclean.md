<h2 class="name">NAME</h2>
<p> pyclean &#8211; removes .pyc and .pyo files </p>
<h2>SYNOPSIS</h2>
<p> pyclean [-p PACKAGE | DIR_OR_FILE]</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;version</code></p>
<dd> show program&#8217;s version number and exit</p>
<dt><code>-h</code>,<code> &#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-v</code>,<code> &#8211;verbose</code></p>
<dd> turn verbose more one</p>
<dt><code>-q</code>,<code> &#8211;quiet</code></p>
<dd> be quiet</p>
<dt><code>-p</code><i>&nbsp;PACKAGE</i>,<code>&nbsp;&#8211;package=</code><i>PACKAGE</i></p>
<dd> specify Debian package name to clean (combining with DIR_OR_FILE will additionally limit list of files)</dl>
