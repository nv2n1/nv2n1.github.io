<h2 class="name">NAME</h2>
<p> po2xml &#8211; Translates an DocBook XML file using a PO file </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>po2xml</code> [<i>original-XML</i><i>translated-PO</i>]</dl>
<h2>DESCRIPTION</h2>
<p> <code>po2xml</code></p>
<dd>is a command-line tool that translates the DocBook XML file <i>original-XML</i> using the gettext message file <i>translated-PO</i>. The resulting translated XML file is sent to standard output. </p>
<p> This utility is part of the KDE Software Development Kit.</p>
