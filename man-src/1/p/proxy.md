<h2 class="name">NAME</h2>
<p> proxy &#8211; Display the proxy server that should be used to reach a given a network resource </p>
<h2>SYNOPSIS</h2>
<p> proxy</p>
<h2>DESCRIPTION</h2>
<p> Display the proxy server that should be used to reach a given a network resource. </p>
<p> libproxy is a library that provides automatic proxy configuration management using different backends.</p>
<h2>EXAMPLE</h2>
<p> <code>echo <a rel="nofollow" href="http://www.example.com/">http://www.example.com/</a> | proxy</code><br />
