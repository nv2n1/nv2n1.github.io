<h2>NAME</h2>
<p> pilot-foto &#8211; Palm &#8216;Foto&#8217; Image Installer/Remover/Fetcher/Converter</p>
<h2>SECTION</h2>
<p> pilot-link: Userland conduits </p>
<h2>SYNOPSIS</h2>
<p>&nbsp;<wbr><i>pilot-foto</i>&nbsp;<wbr>[<code>-p</code>|<code>&#8211;port</code>&nbsp;<wbr>&lt;<code>port</code>&gt;]&nbsp;<wbr>[<code>&#8211;version</code>]&nbsp;<wbr>[<code>-?</code>|<code>&#8211;help</code>]&nbsp;<wbr>[<code>-q</code>|<code>&#8211;quiet</code>]&nbsp;<wbr>[<code>&#8211;usage</code>]&nbsp;<wbr>[<code>-d</code>|<code>&#8211;delete</code>]&nbsp;<wbr>[<code>&#8211;delete-all</code>]&nbsp;<wbr>[<code>-i</code>|<code>&#8211;install</code>]&nbsp;<wbr>[<code>-l</code>|<code>&#8211;list</code>]&nbsp;<wbr>[<code>-f</code>|<code>&#8211;fetch</code>]&nbsp;<wbr>[<code>-F</code>|<code>&#8211;fetch-all</code>]&nbsp;<wbr>[<code>-c</code>|<code>&#8211;convert</code>] </p>
<h2>DESCRIPTION</h2>
<p> This is a palm conduit to fetch, install, or remove, Foto files from a Palm. It can also convert *.jpg.pdb files that have already been fetched from the Palm to jpeg files. </p>
<p> Delete all, or named fotos from handheld. </p>
<p> Install one, or many jpeg images to handheld. </p>
<p> List all jpeg files and thumbnails on handheld. </p>
<p> Fetch all jpeg files, or certain ones by name. </p>
<p> Tries to detect if a file really is a jpeg and refuses to install it, if it is not. </p>
<p> pilot-foto allows you to do multiple operations in one sync. For instance, delete test.jpg and install test.jpg. </p>
<h2>USAGE</h2>
<p> pilot-foto -p &lt;port&gt; [options] <i>file</i> </p>

<h2>PROBLEMS</h2>
<p> Palm has not published their database format for the thumbnails. So, pilot-foto puts a generic penguin thumbnail for every image uploaded. Fotos can be accessed by a named list on the handheld as well as the thumbnails. This has been tried on a couple of handhelds. It is possible that a foreign palm or different model will not like it. </p>
<p> To get a thumbnail image you can copy the jpegs to the memory card. If you copy them back to the handheld they will have a new thumbnail that matches the jpeg. </p>

<h2>BUGS</h2>
<p> If a jpeg is installed with the same name as one already on the palm you will have 2 thumbnails pointing to the same jpeg. The new jpeg will overwrite the old jpeg. </p>
<p> If the thumbnail fails to install then the jpeg should be removed. It is not. </p>
