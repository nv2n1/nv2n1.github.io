<h2 class="name">NAME</h2>
<p> pbmtogo &#8211; convert a portable bitmap into compressed GraphOn graphics </p>
<h2>SYNOPSIS</h2>
<p> <code>pbmtogo</code> [<i>pbmfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a portable bitmap as input. Produces 2D compressed GraphOn graphics as output. Be sure to set up your GraphOn with the following modes: 8 bits / no parity; obeys no XON/XOFF; NULs are accepted. These are all on the Comm menu. Also, remember to turn off tty post processing. Note that there is no gotopbm tool.</p>
