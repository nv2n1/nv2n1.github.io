<h2 class="name">NAME</h2>
<p> pdftools &#8211; analyze PDF files, change image colors</p>
<h2>SYNOPSIS</h2>
<p> <code>pdftools</code> [ <i>OPTION</i> &#8230; ] &lt;file&gt; [ &lt;file&gt; &#8230; ] </p>
<h2>DESCRIPTION</h2>
<p> <code>pdftools</code> analyzes PDF files and changes image colors. It is used by the ConTeXt programs. The image-processing features are not documented here (since I don&#8217;t understand what they do). </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Print the available options.</p>
<dt><code>&#8211;analyzefile</code></p>
<dd> Print statistics about each PDF file, including size, number of xforms, annotations, links, etc.</p>
<dt><code>&#8211;info</code></p>
<dd> Print, in XML format, information about the PDF files. It gives the number of pages, producer, author, subject, creation date, bounding boxes, &#8230; See also <code><a href="/docs/linux/man/1-pdfinfo/">pdfinfo</a></code>(1).</p>
<dt><code>&#8211;countpages</code></p>
<dd> Print the number of pages in each PDF file. </p>
</dl>
