<h2>NAME</h2>
<p> cinnamon-screensaver-command &#8211; controls Cinnamon screensaver</p>
<h2>SYNOPSIS</h2>
<p> <code>cinnamon-screensaver-command</code> [<i>OPTION&#8230;</i>]</p>
<h2>DESCRIPTION</h2>
<p> cinnamon-screensaver-command is a tool for controlling an already running instance of cinnamon-screensaver.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;exit</code></p>
<dd> Causes the screensaver to exit gracefully</p>
<dt><code>-q, &#8211;query</code></p>
<dd> Query the state of the screensaver</p>
<dt><code>-t, &#8211;time</code></p>
<dd> Query the length of time the screensaver has been active</p>
<dt><code>-l, &#8211;lock</code></p>
<dd> Tells the running screensaver process to lock the screen immediately</p>
<dt><code>-a, &#8211;activate</code></p>
<dd> Turn the screensaver on (blank the screen)</p>
<dt><code>-d, &#8211;deactivate</code></p>
<dd> If the screensaver is active then deactivate it (un-blank the screen)</p>
<dt><code>-V, &#8211;version</code></p>
<dd> Version of this application</dl>
