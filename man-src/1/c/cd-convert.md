<h2>NAME</h2>
<p> cd-it8 &#8211; Color Manager Testing Tool</p>
<h2>SYNOPSIS</h2>
<p> <code>cd-it8</code> [ <code>&#8211;verbose</code> ]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>cd-it8</code> command. </p>
<p> <code>cd-it8</code> allows an administrator to create IT8 files, such as <i>.ti3</i>, <i>.ccmx</i> in various ways.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Show summary of options.</dl>
