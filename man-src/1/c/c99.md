<h2 class="name">NAME</h2>
<p> c99 &#8211; ANSI (1999) C compiler </p>
<h2>SYNOPSIS</h2>
<p> <code>c99</code> <i></i>[-pedantic] [-pedantic-errors] [-D_ANSI_SOURCE] options &#8230;</p>
<h2>DESCRIPTION</h2>
<p> Calls the C compiler (cc) with the given <code>options ,</code> using a C language environment compatible with the -ansiC specification. </p>
<p> This includes proper handling of trigraphs, disabling non-ANSI compiler features (such as <code>asm ,</code> <code>typeof ,</code> and the $ character in identifiers), and definition of the preprocessor symbol __STRICT_ANSI__ . </p>
<p> The status of C99 features implemented in GCC is described at <i><a rel="nofollow" href="http://gcc.gnu.org/gcc-11/c99status.html">http://gcc.gnu.org/gcc-11/c99status.html</a></i></p>
<h2>SEE ALSO</h2>
<p> <a href="/docs/linux/man/1-cc/">cc</a>(1) for a description of all options.</p>
<h2>HISTORY</h2>
<p> Appeared in NetBSD 1.4 .</p>
<h2>BUGS</h2>
<p> Since <code>c99</code> is a shell wrapper script to <code>cc ,</code> compile errors are prefixed by &quot;cc:&quot;. </p>
