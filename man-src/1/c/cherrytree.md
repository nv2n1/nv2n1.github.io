<h2>NAME</h2>
<p> cherrytree &#8211; a hierarchical note taking application</p>
<h2>SYNOPSIS</h2>
<p> <code>cherrytree [filepath [-n nodename] [-x export_to_html_dir]]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>cherrytree</code> is a hierarchical note taking application, featuring rich text, syntax highlighting, images handling, hyperlinks, import/export with support for multiple formats, support for multiple languages, and more.</p>
