<h2 class="name">NAME</h2>
 

 certmaster-request -- requests SSL certs from a certmaster Fedora Unified Network Controller. 

<h2>SYNOPSIS</h2>

 certmaster-request [--server certmaster.example.com] [--port port] [ --wait infinite/seconds ]
