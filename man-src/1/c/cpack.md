<h2 class="name">NAME</h2>
<p> cpack &#8211; CPack Command-Line Reference </p>
<h2>SYNOPSIS</h2>
<pre>
cpack [&lt;options&gt;]
</pre>
<h2>DESCRIPTION</h2>
<p> The <code>cpack</code> executable is the CMake packaging program. It generates installers and source packages in a variety of formats. </p>
<p> For each installer or package format, <code>cpack</code> has a specific backend, called &quot;generator&quot;. A generator is responsible for generating the required inputs and invoking the specific package creation tools. These installer or package generators are not to be confused with the makefile generators of the <code>cmake</code> command. </p>
<p> All supported generators are specified in the <code>cpack-generators</code> manual. The command <code>cpack &#8211;help</code> prints a list of generators supported for the target platform. Which of them are to be used can be selected through the <code>CPACK_GENERATOR</code> variable or through the command-line option <code>-G</code>. </p>
<p> The <code>cpack</code> program is steered by a configuration file written in the <code>CMake language</code>. Unless chosen differently through the command-line option <code>&#8211;config</code>, the file <code>CPackConfig.cmake</code> in the current directory is used. </p>
<p> In the standard CMake workflow, the file <code>CPackConfig.cmake</code> is generated by the <code>cmake</code> executable, provided the <code>CPack</code> module is included by the project&#8217;s <code>CMakeLists.txt</code> file.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-G &lt;generators&gt;</code></p>
<dd> <code>&lt;generators&gt;</code> is a semicolon-separated list of generator names. <code>cpack</code> will iterate through this list and produce package(s) in that generator&#8217;s format according to the details provided in the <code>CPackConfig.cmake</code> configuration file. If this option is not given, the <code>CPACK_GENERATOR</code> variable determines the default set of generators that will be used.</p>
<dt><code>-C &lt;configs&gt;</code></p>
<dd> Specify the project configuration(s) to be packaged (e.g. <code>Debug</code>, <code>Release</code>, etc.), where <code>&lt;configs&gt;</code> is a semicolon-separated list. When the CMake project uses a multi-configuration generator such as Xcode or Visual Studio, this option is needed to tell <code>cpack</code> which built executables to include in the package. The user is responsible for ensuring that the configuration(s) listed have already been built before invoking <code>cpack</code>.</p>
<dt><code>-D &lt;var&gt;=&lt;value&gt;</code></p>
<dd> Set a CPack variable. This will override any value set for <code>&lt;var&gt;</code> in the input file read by <code>cpack</code>.</p>
<dt><code>&#8211;config &lt;configFile&gt;</code></p>
<dd> Specify the configuration file read by <code>cpack</code> to provide the packaging details. By default, <code>CPackConfig.cmake</code> in the current directory will be used.</p>
<dt><code>&#8211;verbose, -V</code></p>
<dd> Run <code>cpack</code> with verbose output. This can be used to show more details from the package generation tools and is suitable for project developers.</p>
<dt><code>&#8211;debug</code></p>
<dd> Run <code>cpack</code> with debug output. This option is intended mainly for the developers of <code>cpack</code> itself and is not normally needed by project developers.</p>
<dt><code>&#8211;trace</code></p>
<dd> Put the underlying cmake scripts in trace mode.</p>
<dt><code>&#8211;trace-expand</code></p>
<dd> Put the underlying cmake scripts in expanded trace mode.</p>
<dt><code>-P &lt;packageName&gt;</code></p>
<dd> Override/define the value of the <code>CPACK_PACKAGE_NAME</code> variable used for packaging. Any value set for this variable in the <code>CPackConfig.cmake</code> file will then be ignored.</p>
<dt><code>-R &lt;packageVersion&gt;</code></p>
<dd> Override/define the value of the <code>CPACK_PACKAGE_VERSION</code> variable used for packaging. It will override a value set in the <code>CPackConfig.cmake</code> file or one automatically computed from <code>CPACK_PACKAGE_VERSION_MAJOR</code>, <code>CPACK_PACKAGE_VERSION_MINOR</code> and <code>CPACK_PACKAGE_VERSION_PATCH</code>.</p>
<dt><code>-B &lt;packageDirectory&gt;</code></p>
<dd> Override/define <code>CPACK_PACKAGE_DIRECTORY</code>, which controls the directory where CPack will perform its packaging work. The resultant package(s) will be created at this location by default and a <code>_CPack_Packages</code> subdirectory will also be created below this directory to use as a working area during package creation.</p>
<dt><code>&#8211;vendor &lt;vendorName&gt;</code></p>
<dd> Override/define <code>CPACK_PACKAGE_VENDOR</code>.</p>
<dt><code>&#8211;help,-help,-usage,-h,-H,/?</code></p>
<dd> Print usage information and exit. </p>
<p> Usage describes the basic command line interface and its options.</p>
<dt><code>&#8211;version,-version,/V [&lt;f&gt;]</code></p>
<dd> Show program name/version banner and exit. </p>
<p> If a file is specified, the version is written into it. The help is printed to a named &lt;f&gt;ile if given.</p>
<dt><code>&#8211;help-full [&lt;f&gt;]</code></p>
<dd> Print all help manuals and exit. </p>
<p> All manuals are printed in a human-readable text format. The help is printed to a named &lt;f&gt;ile if given.</p>
<dt><code>&#8211;help-manual &lt;man&gt; [&lt;f&gt;]</code></p>
<dd> Print one help manual and exit. </p>
<p> The specified manual is printed in a human-readable text format. The help is printed to a named &lt;f&gt;ile if given.</p>
<dt><code>&#8211;help-manual-list [&lt;f&gt;]</code></p>
<dd> List help manuals available and exit. </p>
<p> The list contains all manuals for which help may be obtained by using the <code>&#8211;help-manual</code> option followed by a manual name. The help is printed to a named &lt;f&gt;ile if given.</p>
<dt><code>&#8211;help-command &lt;cmd&gt; [&lt;f&gt;]</code></p>
<dd> Print help for one command and exit. </p>
<p> The <code><a href="/docs/linux/man/7-cmake-commands/">cmake-commands</a>(7)</code> manual entry for <code>&lt;cmd&gt;</code> is printed in a human-readable text format. The help is printed to a named &lt;f&gt;ile if given.</p>
<dt><code>&#8211;help-command-list [&lt;f&gt;]</code></p>
