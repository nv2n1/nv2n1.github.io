<h2 class="name">NAME</h2>
 

 certmaster -- hands out certificates to programs that want them, like certmaster-request or users of the certmaster API 

<h2>SYNOPSIS</h2>

 certmaster (it's a daemon and takes no arguments)

<h2>DESCRIPTION</h2>

 See <a rel="nofollow" HREF="https://fedorahosted.org/certmaster">https://fedorahosted.org/certmaster</a> 

 Certmaster is a daemon that runs on a ``master'' machine to hand out certificates to machines that want them. Certificates can then be used by applications like func. 

 Certmaster is configured by /etc/certmaster/certmaster.conf
