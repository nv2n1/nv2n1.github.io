<h2>SYNOPSIS</h2>
<p> cargo package [OPTIONS]</p>
<h2>DESCRIPTION</h2>
<p> Assemble the local package into a distributable tarball.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, &#8211;help</code></dt>
<dd> Print this message.</dd>
<dl>
</dl>
<dt><code>-l, &#8211;list</code></dt>
<dd> Print files included in a package without making one.</dd>
<dl>
</dl>
<dt><code>&#8211;no-verify</code></dt>
<dd> Don&#8217;t verify the contents by building them.</dd>
<dl>
</dl>
<dt><code>&#8211;no-metadata</code></dt>
<dd> Ignore warnings about a lack of human-usable metadata.</dd>
<dl>
</dl>
<dt><code>&#8211;manifest-path </code>PATH</dt>
<dd> Path to the manifest to compile.</dd>
<dl>
</dl>
<dt><code>-v, &#8211;verbose</code></dt>
<dd> Use verbose output.</dd>
<dl>
</dl>
<dt><code>-q, &#8211;quiet</code></dt>
<dd> No output printed to stdout.</dd>
<dl>
</dl>
<dt><code>&#8211;color </code>WHEN</dt>
<dd> Coloring: auto, always, never.</dd>
<dl>
</dl>
</dl>
