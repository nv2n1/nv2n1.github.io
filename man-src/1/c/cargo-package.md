<h2 class="name">NAME</h2>
<p> cargo-package &#8211; Create a distributable tarball </p>
<h2>SYNOPSIS</h2>
<p> cargo package [OPTIONS]</p>
<h2>DESCRIPTION</h2>
<p> Assemble the local package into a distributable tarball.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Print this message.</p>
<dl>
<dt>
<dd></dl>
<dt><code>-l, &#8211;list</code></p>
<dd> Print files included in a package without making one.</p>
<dl>
<dt>
<dd></dl>
<dt><code>&#8211;no-verify</code></p>
<dd> Don&#8217;t verify the contents by building them.</p>
<dl>
<dt>
<dd></dl>
<dt><code>&#8211;no-metadata</code></p>
<dd> Ignore warnings about a lack of human-usable metadata.</p>
<dl>
<dt>
<dd></dl>
<dt><code>&#8211;manifest-path </code>PATH</p>
<dd> Path to the manifest to compile.</p>
<dl>
<dt>
<dd></dl>
<dt><code>-v, &#8211;verbose</code></p>
<dd> Use verbose output.</p>
<dl>
<dt>
<dd></dl>
<dt><code>-q, &#8211;quiet</code></p>
<dd> No output printed to stdout.</p>
<dl>
<dt>
<dd></dl>
<dt><code>&#8211;color </code>WHEN</p>
<dd> Coloring: auto, always, never.</p>
<dl>
<dt>
<dd></dl>
</dl>
