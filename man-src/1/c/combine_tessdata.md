<h2 class="name">NAME</h2>
<p> combine_tessdata &#8211; combine/extract/overwrite Tesseract data </p>
<h2>SYNOPSIS</h2>
<p> <code>combine_tessdata</code> [<i>OPTION</i>] <i>FILE</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> <a href="/docs/linux/man/1-combine_tessdata/">combine_tessdata</a>(1) is the main program to combine/extract/overwrite tessdata components in [lang].traineddata files. </p>
<p> To combine all the individual tessdata components (unicharset, DAWGs, classifier templates, ambiguities, language configs) located at, say, /home/$USER/temp/eng.* run: </p>
<dl>
<dt>
<dd>
<pre>
combine_tessdata /home/$USER/temp/eng.
</pre>
</dl>
<p> The result will be a combined tessdata file /home/$USER/temp/eng.traineddata </p>
<p> Specify option -e if you would like to extract individual components from a combined traineddata file. For example, to extract language config file and the unicharset from tessdata/eng.traineddata run: </p>
<dl>
<dt>
<dd>
<pre>
combine_tessdata -e tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset
</pre>
</dl>
<p> The desired config file and unicharset will be written to /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset </p>
<p> Specify option -o to overwrite individual components of the given [lang].traineddata file. For example, to overwrite language config and unichar ambiguities files in tessdata/eng.traineddata use: </p>
<dl>
<dt>
<dd>
<pre>
combine_tessdata -o tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharambigs
</pre>
</dl>
<p> As a result, tessdata/eng.traineddata will contain the new language config and unichar ambigs, plus all the original DAWGs, classifier templates, etc. </p>
<p> Note: the file names of the files to extract to and to overwrite from should have the appropriate file suffixes (extensions) indicating their tessdata component type (.unicharset for the unicharset, .unicharambigs for unichar ambigs, etc). See k*FileSuffix variable in ccutil/tessdatamanager.h. </p>
<p> Specify option -u to unpack all the components to the specified path: </p>
<dl>
<dt>
<dd>
<pre>
combine_tessdata -u tessdata/eng.traineddata /home/$USER/temp/eng.
</pre>
</dl>
<p> This will create /home/$USER/temp/eng.* files with individual tessdata components from tessdata/eng.traineddata.</p>
<h2>OPTIONS</h2>
<p> <code>-e</code> <i>.traineddata</i> <i>FILE</i>&#8230;: Extracts the specified components from the .traineddata file </p>
<p> <code>-o</code> <i>.traineddata</i> <i>FILE</i>&#8230;: Overwrites the specified components of the .traineddata file with those provided on the comand line. </p>
<p> <code>-u</code> <i>.traineddata</i> <i>PATHPREFIX</i> Unpacks the .traineddata using the provided prefix.</p>
<h2>CAVEATS</h2>
<p> <i>Prefix</i> refers to the full file prefix, including period (.)</p>
<h2>COMPONENTS</h2>
<p> The components in a Tesseract lang.traineddata file as of Tesseract 3.02 are briefly described below; For more information on many of these files, see m[blue]<code><a rel="nofollow" href="https://github.com/tesseract-ocr/tesseract/wiki/TrainingTesseract">https://github.com/tesseract-ocr/tesseract/wiki/TrainingTesseract</a></code>m[] </p>
<p> lang.config</p>
<dl>
<dt>
<dd> (Optional) Language-specific overrides to default config variables.</dl>
<p> lang.unicharset</p>
<dl>
<dt>
<dd> (Required) The list of symbols that Tesseract recognizes, with properties. See <a href="/docs/linux/man/5-unicharset/">unicharset</a>(5).</dl>
<p> lang.unicharambigs</p>
<dl>
<dt>
<dd> (Optional) This file contains information on pairs of recognized symbols which are often confused. For example, <i>rn</i> and <i>m</i>.</dl>
<p> lang.inttemp</p>
<dl>
<dt>
<dd> (Required) Character shape templates for each unichar. Produced by <a href="/docs/linux/man/1-mftraining/">mftraining</a>(1).</dl>
<p> lang.pffmtable</p>
<dl>
<dt>
<dd> (Required) The number of features expected for each unichar. Produced by <a href="/docs/linux/man/1-mftraining/">mftraining</a>(1) from <code>.tr</code> files.</dl>
<p> lang.normproto</p>
<dl>
<dt>
<dd> (Required) Character normalization prototypes generated by <a href="/docs/linux/man/1-cntraining/">cntraining</a>(1) from <code>.tr</code> files.</dl>
<p> lang.punc-dawg</p>
<dl>
<dt>
<dd> (Optional) A dawg made from punctuation patterns found around words. The &quot;word&quot; part is replaced by a single space.</dl>
<p> lang.word-dawg</p>
<dl>
<dt>
<dd> (Optional) A dawg made from dictionary words from the language.</dl>
<p> lang.number-dawg</p>
<dl>
<dt>
<dd> (Optional) A dawg made from tokens which originally contained digits. Each digit is replaced by a space character.</dl>
<p> lang.freq-dawg</p>
<dl>
<dt>
<dd> (Optional) A dawg made from the most frequent words which would have gone into word-dawg.</dl>
<p> lang.fixed-length-dawgs</p>
<dl>
<dt>
<dd> (Optional) Several dawgs of different fixed lengths &#8212; useful for languages like Chinese.</dl>
<p> lang.cube-unicharset</p>
<dl>
<dt>
<dd> (Optional) A unicharset for cube, if cube was trained on a different set of symbols.</dl>
<p> lang.cube-word-dawg</p>
<dl>
<dt>
<dd> (Optional) A word dawg for cube&#8217;s alternate unicharset. Not needed if Cube was trained with Tesseract&#8217;s unicharset.</dl>
<p> lang.shapetable</p>
<dl>
<dt>
<dd> (Optional) When present, a shapetable is an extra layer between the character classifier and the word recognizer that allows the character classifier to return a collection of unichar ids and fonts instead of a single unichar-id and font.</dl>
<p> lang.bigram-dawg</p>
<dl>
<dt>
<dd> (Optional) A dawg of word bigrams where the words are separated by a space and each digit is replaced by a <i>?</i>.</dl>
