<h2 class="name">NAME</h2>
<p> cd-fix-profile &#8211; Color Manager Testing Tool </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>cd-fix-profile</code> [<code>&#8211;verbose</code>]</dl>
<h2>DESCRIPTION</h2>
<dd>This manual page documents briefly the <code>cd-fix-profile</code> command. </p>
<p> <code>cd-fix-profile</code> allows an administrator to modify and fix ICC profiles on their system. </p>
<p> The program will also repair common errors found in profiles.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (&#8216;-&#8216;). A summary of options is included below. </p>
<p> <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show summary of options.</dl>
<p> <code>&#8211;description</code></p>
<dl>
<dt>
<dd> Sets the profile description.</dl>
<p> <code>&#8211;copyright</code></p>
<dl>
<dt>
<dd> Sets the profile copyright.</dl>
<p> <code>&#8211;model</code></p>
<dl>
<dt>
<dd> Sets the profile model.</dl>
<p> <code>&#8211;manufacturer</code></p>
<dl>
<dt>
<dd> Sets the profile manufacturer.</dl>
