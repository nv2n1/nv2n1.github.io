<h2>NAME</h2>
<p> <code>chkhelp</code> &#8211; check performance metrics help text files</p>
<h2>SYNOPSIS</h2>
<p> <code>$PCP_BINADM_DIR/chkhelp</code> [<code>-eHiOp</code>] [<code>-n</code> <i>pmnsfile</i>] [<code>-v</code> <i>version</i>] <i>helpfile</i> [<i>metricname</i> &#8230;]</p>
<h2>DESCRIPTION</h2>
<p> <code>chkhelp</code> checks the consistency of Performance Co-Pilot help text files generated by <code><a href="/docs/linux/man/1-newhelp/">newhelp</a></code>(1) and used by Performance Metric Domain Agents (PMDAs). The checking involves scanning the files, and optionally displaying selected entries. </p>
<p> The files <i>helpfile</i><code>.dir</code> and <i>helpfile</i><code>.pag</code> are created by <code><a href="/docs/linux/man/1-newhelp/">newhelp</a></code>(1), and are assumed to already exist. </p>
<p> Without any options or <i>metricname</i> arguments, <code>chkhelp</code> silently verifies the structural integrity of the help files. </p>
<p> If any <i>metricname</i> arguments are specified, then the help entries for only the corresponding metrics will be processed. </p>
<p> If no <i>metricname</i> arguments are specified, then at least one of the options <code>-i</code> or <code>-p</code> must be given. The <code>-i</code> option causes entries for all instance domains to be processed (ignoring entries for performance metrics). The <code>-p</code> option causes entries for all metrics to be displayed (ignoring entries for instance domains). </p>
<p> When metric entries are to be processed (via either the <i>metricname</i> arguments or the <code>-p</code> option or the <code>-i</code> option), the <code>-O</code> and <code>-H</code> options request the display of the one-line and verbose help text respectively. The default is <code>-O</code>. </p>
<p> Although historically there have been multiple help text file formats, the only format currently supported using the <code>-v</code> option is <i>version</i> 2, and this is the default if no <code>-v</code> flag is provided. </p>
<p> Normally <code>chkhelp</code> operates on the default Performance Metrics Name Space (PMNS), however if the <code>-n</code> option is specified an alternative namespace is loaded from the file <i>pmnsfile</i>. </p>
<p> The <code>-e</code> option provides an existence check where all of the specified metrics from the PMNS (note, not from <i>helpfile</i>) are scanned, and only the names of the metrics for which <code>no</code> help text exists are reported. The <code>-e</code> option is mutually exclusive with the <code>-i</code> and/or <code>-p</code> options.</p>
<h2>PCP ENVIRONMENT</h2>
<p> Environment variables with the prefix <code>PCP_</code> are used to parameterize the file and directory names used by PCP. On each installation, the file <i>/etc/pcp.conf</i> contains the local values for these variables. The <code>$PCP_CONF</code> variable may be used to specify an alternative configuration file, as described in <code><a href="/docs/linux/man/5-pcp-conf/">pcp.conf</a></code>(5).</p>

<h2>DIAGNOSTICS</h2>
<p> There are all sorts of reasons a help database may be inconsistent, the most likely is that a performance metric in the database is not defined in the loaded PMNS. </p>
