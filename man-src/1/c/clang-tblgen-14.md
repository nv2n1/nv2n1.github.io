<h2 class="name">NAME</h2>
<p> clang-tblgen &#8211; Description to C++ Code for Clang </p>
<h2>SYNOPSIS</h2>
<p> <code>clang-tblgen</code> [<i>options</i>] [<i>filename</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>clang-tblgen</code> is a program that translates compiler-related target description (<code>.td</code>) files into C++ code and other output formats. Most users of LLVM will not need to use this program. It is used only for writing parts of the compiler. </p>
<p> Please see tblgen &#8211; Description to C++ Code for a description of the <i>filename</i> argument and options, including the options common to all <code>*-tblgen</code> programs.</p>
