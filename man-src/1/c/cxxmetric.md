<h2 class="name">NAME</h2>
<p> cxxmetric &#8211; Simple source metrics for C and C++ </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>cxxmetric</code> [<i>file</i>]</dl>
<h2>DESCRIPTION</h2>
<dd>cxxmetric counts lines of code, comment and blank space and calculates various other statistics for each given source file. Source files must be in C or C++. </p>
<p> This utility is part of the KDE Software Development Kit.</p>
