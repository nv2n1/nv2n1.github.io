<dl>
<dt> <code>cxxmetric</code> [<i>file</i>]</dt></dl>
<dd>cxxmetric counts lines of code, comment and blank space and calculates various other statistics for each given source file. Source files must be in C or C++. </dd>
<p> This utility is part of the KDE Software Development Kit.</p>
