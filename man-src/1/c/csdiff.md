<h2>NAME</h2>
<p> csdiff &#8211; manual page for csdiff 1.3.2</p>
<h2>SYNOPSIS</h2>
<p> <code>csdiff</code> [<i>options</i>] <i>old.err new.err, where options are:</i></p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>-x</code> [ <code>&#8211;fixed</code> ]</p>
<dd> print fixed defects (just swaps the arguments)</p>
<dt><code>-z</code> [ <code>&#8211;ignore-path</code> ]</p>
<dd> ignore directory structure when matching</p>
<dt><code>-i</code> [ <code>&#8211;show-internal</code> ]</p>
<dd> include internal warnings in the output</p>
<dt><code>-q</code> [ <code>&#8211;quiet</code> ]</p>
<dd> do not report any parsing errors</p>
<dt><code>-c</code> [ <code>&#8211;coverity-output</code> ]</p>
<dd> write the result in Coverity format</p>
<dt><code>-j</code> [ <code>&#8211;json-output</code> ]</p>
<dd> write the result in JSON format</p>
<dt><code>-s</code> [ <code>&#8211;file-rename</code> ] arg</p>
<dd> account the file base-name change, [OLD,NEW] (*testing*)</p>
<dt><code>&#8211;color</code></p>
<dd> use colorized console output (default if connected to a terminal)</p>
<dt><code>&#8211;no-color</code></p>
<dd> do not use colorized console output</p>
<dt><code>&#8211;help</code></p>
<dd> produce help message</p>
<dt><code>&#8211;version</code></p>
<dd> print version </p>
</dl>
