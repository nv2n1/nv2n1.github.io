<h2>NAME</h2>
<p> CGDB &#8211; manual page for CGDB 0.6.8</p>
<h2>DESCRIPTION</h2>
<h3>CGDB Usage:</h3>
<dl>
<dt>
<dd> cgdb [cgdb options] [&#8211;] [gdb options]</dl>
<h3>CGDB Options:</h3>
<dl>
<dt><code>&#8211;version</code></p>
<dd> Print version information and then exit.</p>
<dt><code>&#8211;help</code></p>
<dd> Print help (this message) and then exit.</p>
<dt><code>-d</code></p>
<dd> Set debugger to use.</p>
<dt><code>&#8212;</code></p>
<dd> Marks the end of CGDB&#8217;s options.</dl>
