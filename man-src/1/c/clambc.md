<h2>NAME</h2>
<p> clambc &#8211; Bytecode Analysis and Testing Tool</p>
<p> clambc &lt;file&gt; [function] [param1 &#8230;]</p>
<dl>
<dt><code>&#8211;help</code> <code>-h</code></dt>
<dd> Show help</dd>
<dt><code>&#8211;version</code> <code>-V</code></dt>
<dd> Show version</dd>
<dt><code>&#8211;debug</code></dt>
<dd> Show debug</dd>
<dt><code>&#8211;force-interpreter</code> <code>-f</code></dt>
<dd> Force using the interpreter instead of the JIT</dd>
<dt><code>&#8211;trust-bytecode</code> <code>-t</code></dt>
<dd> Trust loaded bytecode (default yes)</dd>
<dt><code>&#8211;info</code> <code>-i</code></dt>
<dd> Print information about bytecode</dd>
<dt><code>&#8211;printsrc</code> <code>-p</code></dt>
<dd> Print bytecode source</dd>
<dt><code>&#8211;printbcir</code> <code>-c</code></dt>
<dd> Print IR of bytecode signature</dd>
<dt><code>&#8211;input</code> <code>-r</code></dt>
<dd> Input file to run the bytecode on</dd>
<dt><code>&#8211;trace</code> &lt;level&gt; <code>-T</code></dt>
<dd> Set bytecode trace level 0..7 (default 7)</dd>
<dt><code>&#8211;no-trace-showsource</code></dt>
<dd> Don&#8217;t show source line during tracing</dd>
<dt><code>&#8211;statistics=bytecode</code></dt>
<dd> Collect and print bytecode execution statistics</dd>
<dt>file</dt>
<dd> file to test</dd></dl>
