<h2>NAME</h2>
<p> clambc &#8211; Bytecode Analysis and Testing Tool</p>
<h2>SYNOPSIS</h2>
<p> clambc &lt;file&gt; [function] [param1 &#8230;]</p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>&#8211;help</code> <code>-h</code></p>
<dd> Show help</p>
<dt><code>&#8211;version</code> <code>-V</code></p>
<dd> Show version</p>
<dt><code>&#8211;debug</code></p>
<dd> Show debug</p>
<dt><code>&#8211;force-interpreter</code> <code>-f</code></p>
<dd> Force using the interpreter instead of the JIT</p>
<dt><code>&#8211;trust-bytecode</code> <code>-t</code></p>
<dd> Trust loaded bytecode (default yes)</p>
<dt><code>&#8211;info</code> <code>-i</code></p>
<dd> Print information about bytecode</p>
<dt><code>&#8211;printsrc</code> <code>-p</code></p>
<dd> Print bytecode source</p>
<dt><code>&#8211;printbcir</code> <code>-c</code></p>
<dd> Print IR of bytecode signature</p>
<dt><code>&#8211;input</code> <code>-r</code></p>
<dd> Input file to run the bytecode on</p>
<dt><code>&#8211;trace</code> &lt;level&gt; <code>-T</code></p>
<dd> Set bytecode trace level 0..7 (default 7)</p>
<dt><code>&#8211;no-trace-showsource</code></p>
<dd> Don&#8217;t show source line during tracing</p>
<dt><code>&#8211;statistics=bytecode</code></p>
<dd> Collect and print bytecode execution statistics</p>
<dt>file</p>
<dd> file to test</dl>
