<h2>NAME</h2>
<p> cslinker &#8211; manual page for cslinker 1.3.2</p>
<h2>SYNOPSIS</h2>
<p> <code>cslinker</code> [<i>options</i>] <i>proj.err </i>[&#8230;]<i>, where options are:</i></p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>&#8211;cwelist</code> arg</p>
<dd> (re)assign CWE numbers to defects by the given CSV list</p>
<dt><code>&#8211;inifile</code> arg</p>
<dd> load scan properties from the given INI file</p>
<dt><code>&#8211;mapfile</code> arg</p>
<dd> load defect IDs from comma-separated mapfile</p>
<dt><code>-q</code> [ <code>&#8211;quiet</code> ]</p>
<dd> do not report non-fatal errors</p>
<dt><code>&#8211;help</code></p>
<dd> produce help message</p>
<dt><code>&#8211;version</code></p>
<dd> print version </p>
</dl>
