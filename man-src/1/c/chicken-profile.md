<h2 class="name">NAME</h2>
<p> chicken-profile &#8211; generate a report from profile-information</p>
<h2>SYNOPSIS</h2>
<p> <code>chicken-profile</code> [ <i>filename</i> | <i>option &#8230;</i> ] </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-sort-by-calls</code></p>
<dd> Sort output by call frequency. </p>
<dt><code>-sort-by-time</code></p>
<dd> Sort output by procedure execution time. </p>
<dt><code>-sort-by-avg</code></p>
<dd> Sort output by average procedure execution time. </p>
<dt><code>-sort-by-name</code></p>
<dd> Sort output alphabetically by procedure name. </p>
<dt><code>-no-unused</code></p>
<dd> Remove procedures that are never called. </p>
<dt><code>-help</code></p>
<dd> Show usage information. </p>
</dl>
<h2>DESCRIPTION</h2>
<p> <i>chicken-profile reads in profiling information generated by CHICKEN Scheme</i> programs compiled with the <code>-profile</code> option, and generates a table listing function names and their execution times. </p>
