<h2 class="name">NAME</h2>
<p> <code>check-language-support</code> &#8211; returns the list of missing packages in order to provide a complete language environment </p>
<h2>SYNOPSIS</h2>
<p> <code>check-language-support</code> [<i>options</i>]</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-l</code> LANGUAGE, <code>&#8211;language</code>=<i>LANGUAGE</i></p>
<dd> target language code &#8211; if omitted, check for all languages on the system</p>
<dt><code>-d</code> DATADIR, <code>&#8211;datadir</code>=<i>DATADIR</i></p>
<dd> use an alternative data directory instead of the default <code>/usr/share/language-selector</code></p>
<dt><code>-a</code>, <code>&#8211;all</code></p>
<dd> check all available languages</p>
<dt><code>&#8211;show-installed</code></p>
<dd> show installed packages as well as missing ones</dl>
