<h2 class="name">NAME</h2>
<p> cvslastlog &#8211; Prints the log entry for the last commit for a file. </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>cvslastlog</code> [<i>filename</i>]</dl>
<h2>DESCRIPTION</h2>
<p> <code>cvslastlog</code></p>
<dd>shows the log associated with the last CVS commit for the given file. It depends on the version of the local file, not the one on the server. </p>
<p> This utility is part of the KDE Software Development Kit.</p>
