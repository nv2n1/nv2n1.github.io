<h2>NAME</h2>
<p> cshtml &#8211; manual page for cshtml 1.3.2</p>
<h2>SYNOPSIS</h2>
<p> <code>cshtml</code> [<i>options</i>] <i>proj.js, where options are:</i></p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>&#8211;defect-url-template</code> arg</p>
<dd> e.g. <a rel="nofollow" href="http://localhost/index.php?proj=%d">http://localhost/index.php?proj=%d</a>&amp;defect=%d</p>
<dt><code>&#8211;diff-base</code> arg</p>
<dd> use the given list of defects as diff base</p>
<dt><code>&#8211;plain-text-url</code> arg</p>
<dd> generate a link to plain-text version</p>
<dt> <code>&#8211;scan-props-placement</code> arg (=bottom) placement of the table with scan properties: top, bottom, none</p>
<dt><code>-q</code> [ <code>&#8211;quiet</code> ]</p>
<dd>
<dd>do not report any parsing errors</p>
<dt><code>&#8211;help</code></p>
<dd> produce help message</p>
<dt><code>&#8211;version</code></p>
<dd> print version </p>
</dl>
