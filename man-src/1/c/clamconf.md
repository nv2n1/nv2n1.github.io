<h2>NAME</h2>
<p> clamconf &#8211; Clam AntiVirus configuration utility</p>
<h2>SYNOPSIS</h2>
<p> clamconf [options]</p>
<h2>DESCRIPTION</h2>
<p> clamconf displays the values of configuration options.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Display help and exit.</p>
<dt><code>-V, &#8211;version</code></p>
<dd> Display software version and exit.</p>
<dt><code>-c DIR, &#8211;config-dir DIR</code></p>
<dd> Search for configuration files clamd.conf and freshclam.conf in DIR.</p>
<dt><code>-n, &#8211;non-default</code></p>
<dd> Only print non-default settings.</p>
<dt><code>-g CONFIG_NAME, &#8211;generate-config=CONFIG_NAME</code></p>
<dd> Generate example configuration file.</dl>
