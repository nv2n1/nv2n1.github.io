<h2>NAME</h2>
<p> cpupower-info &#8211; Shows processor power related kernel or hardware configurations</p>
<h2>SYNOPSIS</h2>
<p> <code> cpupower info [ -b ]</code> </p>
<h2>DESCRIPTION</h2>
<p> <code>cpupower info </code> shows kernel configurations or processor hardware registers affecting processor power saving policies. </p>
<p> Some options are platform wide, some affect single cores. By default values of core zero are displayed only. cpupower &#8211;cpu all cpuinfo will show the settings of all cores, see <a href="/docs/linux/man/1-cpupower/">cpupower</a>(1) how to choose specific cores. </p>
