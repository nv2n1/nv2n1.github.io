<p>checkXML &#8211; An XML lint tool for KDE DocBook XML documents. </p>
<h2>Synopsis</h2>
<dl>
<dt> <code>checkXML</code> [<i>filename</i>]</dl>
<h2>Description</h2>
<p><code>checkXML</code></p>
<dd>is a tool to check for syntax errors in KDE DocBook XML files. It can also be used for other DocBook based XML files, but you should use the less specific <a href="/docs/linux/man/1-xmllint/">xmllint</a>(1) tool if you are not writing or otherwise working on KDE documentation.</p>
