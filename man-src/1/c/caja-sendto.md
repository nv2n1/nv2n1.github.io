<h2>NAME</h2>
<p> caja-sendto &#8211; convenience application to send a file via email or instant messenger</p>
<h2>SYNOPSIS</h2>
<p> <code>caja-sendto</code> [<i>OPTIONS</i> <i>|</i> <i>FILES&#8230;</i>]</p>
<h2>DESCRIPTION</h2>
<p> Send FILE(s) via email or instant messenger. </p>
<p> A dialog window presents a choice of carrier application and recipient of the file(s). Recipent names can be selected from a list or autocompleted. The selected application is then opened with the file(s) and recipient ready for transfer. </p>
<p> The application is intented to integrate with caja and is written for the MATE graphical desktop.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-?, &#8211;help</code></p>
<dd> Show a help message listing all the options and their meanings.</dl>
