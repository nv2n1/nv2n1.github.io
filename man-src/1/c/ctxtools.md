<h2 class="name">NAME</h2>
<p> ctxtools &#8211; clean up temporary ConTeXt files, install latest ConTeXt</p>
<h2>SYNOPSIS</h2>
<p> <code>ctxtools</code> [ <i>OPTION</i> &#8230; ] </p>
<h2>DESCRIPTION</h2>
<p> <code>ctxtools</code> is useful for dealing with ConTeXt source and generated files and for installing new versions of ConTeXt. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Print the available options.</p>
<dt><code>&#8211;purgefiles</code></p>
<dd> Get rid of many temporary files generated by ConTeXt. You can give the <code>&#8211;all</code> option to remove a larger fraction of those files, and the <code>&#8211;recurse</code> option to remove these files also in subdirectories.</p>
<dt><code>&#8211;contextversion</code></p>
<dd> Show the date of the ConTeXt macros and the format file. Useful after upgrading ConTeXt (perhaps using <code>&#8211;updatecontext</code>) to check whether the new formats and macros are visible to the TeX path searches (see <code><a href="/docs/linux/man/1-kpsewhich/">kpsewhich</a></code>(1).</p>
<dt><code>&#8211;updatecontext</code></p>
<dd> Download the latest ConTeXt distribution and install it in the TEXMFLOCAL tree (see <code><a href="/docs/linux/man/1-kpsewhich/">kpsewhich</a></code>(1) for information on TeX path searching). TEXMFLOCAL usually points to a system-wide location. If you want to install the new ConTeXt in your home directory (i.e. an install for one user), then set the TEXMFLOCAL environment variable while running <code>ctxtools</code>. For example, using the syntax of the Bourne shell <code><a href="/docs/linux/man/1-sh/">sh</a></code>(1): </p>
<pre>
TEXMFLOCAL=$HOME/texmf ctxtools --updatecontext
</pre>
<dt><code>&#8211;documentation</code></p>
<dd> Generate a <i>.ted</i> file from the source file. See also the <code>&#8211;module</code> option to <code><a href="/docs/linux/man/1-texexec/">texexec</a></code>(1).</p>
<dt><code>&#8211;patternfiles</code> [languagecode]</p>
<dd> Generate pattern files. You can also give the <code>&#8211;all</code>, <code>&#8211;xml</code>, and <code>&#8211;utf8</code> options. </p>
</dl>
<h2>ENVIRONMENT</h2>
<dl>
<dt>TEXMFLOCAL</p>
<dd> Used by <tt>--updatecontext</tt> to decide where to install the distribution. </p>
</dl>
