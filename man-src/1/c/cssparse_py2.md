<h2 class="name">NAME</h2>
<p> <code>cssparse</code> &#8211; A CSS parser. </p>
<h2>SYNOPSIS</h2>
<p> <code>cssparse</code> [<i>options</i>&#8230;] [<i>path</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> Script version of cssutils.parseString(), cssutils.parseFile() and cssutils.parseUrl(). The combined CSS is outputed to <code>stdout</code>. Logging is directed to <code>stderr</code>.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d</code>, <code>&#8211;debug</code></p>
<dd> Activate debugging output.</p>
<dt><code>-e</code><i> ENCODING</i>, <code>&#8211;encoding</code>=<i>ENCODING</i></p>
<dd> Encoding of the file or override encoding found.</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Display help message and exit.</p>
<dt><code>-m</code>, <code>&#8211;minify</code></p>
<dd> Minify parsed CSS.</p>
<dt><code>-s</code><i> SOMESTRING</i>, <code>&#8211;string</code>=<i>SOMESTRING</i></p>
<dd> Parse given string.</p>
<dt><code>-u</code><i> URL</i>, <code>&#8211;url</code>=<i>URL</i></p>
<dd> Parse the given <i>URL</i>.</dl>
