<h2 class="name">NAME</h2>
<p> csc &#8211; driver program for the CHICKEN Scheme compiler</p>
<h2>SYNOPSIS</h2>
<p> <code>csc</code> [ <i>filename</i> | <i>option &#8230;</i> ] </p>
<h2>DESCRIPTION</h2>
<p> <i>csc</i> is a program that invokes the <i>CHICKEN</i> compiler and the host systems C compiler to generate an executable from a Scheme source file or C files generated by <i>CHICKEN</i> For a list of options enter <code>csc -help</code> </p>
<h2>ENVIRONMENT VARIABLES</h2>
<dl>
<dt><code>CSC_OPTIONS</code></p>
<dd> Can hold default options that should be passed to every invocation of <code>csc</code> </p>
<dt><code>CHICKEN_PREFIX</code></p>
<dd> An alternative installation prefix, where the Scheme-to-C translator and any support files and libraries are located. Defaults to the installation time prefix given when configuring the system. </p>
</dl>
