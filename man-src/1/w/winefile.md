<h2 class="name">NAME</h2>
<p> winefile &#8211; Wine File Manager </p>
<h2>SYNOPSIS</h2>
<p> <code>winefile</code><i> path</i></p>
<h2>DESCRIPTION</h2>
<p> <code>winefile</code> is the Wine file manager, with a similar design to early Microsoft Windows explorer.</p>
<h2>USAGE</h2>
<p> You can pass winefile either a Unix or Win32 path, for example: </p>
<p> Using a Unix path: <code>winefile /mnt/hda1</code> </p>
<p> Using a Win32 path: <code>winefile C:\windows\</code> </p>
<h2>BUGS</h2>
<p> Bugs can be reported on the <code>Wine bug tracker</code></p>
<h2>AVAILABILITY</h2>
<p> <code>winefile</code> is part of the Wine distribution, which is available through WineHQ, the <code>Wine development headquarters</code></p>
