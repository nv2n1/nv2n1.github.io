<h2>NAME</h2>
<p> wpd2text &#8211; convert WordPerfect document into plain text</p>
<h2>SYNOPSIS</h2>
<p> <code>wpd2text</code> [<i>OPTION</i>] <i>&lt;WordPerfect Document&gt;</i></p>
<h2>OPTIONS</h2>
<p> <code>&#8211;info</code> Display document metadata instead of the text <code>&#8211;help</code> Shows this help message <code>&#8211;password</code> &lt;password&gt; Try to decrypt password protected document <code>&#8211;version</code> Output wpd2text version </p>
