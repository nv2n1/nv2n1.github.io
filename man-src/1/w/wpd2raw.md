<h2>NAME</h2>
<p> wpd2raw &#8211; debug the conversion library</p>
<h2>SYNOPSIS</h2>
<p> <code>wpd2raw</code> [<i>OPTION</i>] <i>&lt;WordPerfect Document&gt;</i></p>
<h2>OPTIONS</h2>
<p> <code>&#8211;callgraph</code> Display the call graph nesting level <code>&#8211;help</code> Shows this help message <code>&#8211;password</code> &lt;password&gt; Try to decrypt password protected document <code>&#8211;version</code> Output wpd2raw version </p>
