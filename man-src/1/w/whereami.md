<h2>NAME</h2>
<p> whereami-1.0 &#8211; displays work location </p>
<h2>SYNOPSIS</h2>
<dl>
<dt><code>whereamiR [OPTIONS</code>]</p>
<dd>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>whereami</code> displays information about the machine(location) you are working on. Information like terminal name, present working directory, host name, and the host IP address. This is extremely useful for those who tend to work remotely on several machines at the same time. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d &#8211;dir</code></p>
<dd>
&nbsp;<wbr>display current working directory</p>
<dt><code>-h &#8211;help </code></p>
<dd>
&nbsp;<wbr>show this help</p>
<dt><code>-i &#8211;hostip </code></p>
<dd>
&nbsp;<wbr>display machines IP address</p>
<dt><code>-n &#8211;hostname </code></p>
<dd>
&nbsp;<wbr>display machine name</p>
<dt><code>-t &#8211;ttyname </code></p>
<dd>
&nbsp;<wbr>display terminal name</p>
<dt><code>-v &#8211;version </code></p>
<dd>
&nbsp;<wbr>display version information </p>
</dl>
