<h2 class="name">NAME</h2>
<p> wbmptopbm &#8211; convert a wireless bitmap (wbmp) file to a portable bitmap (pbm) </p>
<h2>SYNOPSIS</h2>
<p> <code>wbmptopbm</code> [<i>wbmpfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a wbmp file as input. Produces a portable bitmap as output.</p>
<h2>LIMITATIONS</h2>
<p> Currently only WBMP type 0 is recognized. This is the only type specified in the WAP 1.1 specifications.</p>
