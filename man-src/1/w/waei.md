<h2 class="name">NAME</h2>
<p> waei &#8211; Japanese-English dictionary </p>
<h2>SYNOPSIS</h2>
<p> <code>waei</code> [<i>options</i>]<i> pattern</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> A Japanese-English dictionary that is a drop-in replacement for gjiten. </p>
<p> This is the console version of <code>gwaei.</code></p>
<h2>OPTIONS</h2>
<dl>
<dt>-e, &#8211;exact</p>
<dd> Do not display less relevant results</p>
<dt>-d, &#8211;dictionary name</p>
<dd> Search using a chosen dictionary</p>
<dt>-l, &#8211;list</p>
<dd> Show available dictionaries for searches</p>
<dt>-i, &#8211;install</p>
<dd> List installable dictionaries</p>
<dt>-i, &#8211;install dictionary</p>
<dd> Install dictionary</p>
<dt>-u, &#8211;uninstall</p>
<dd> List uninstallable dictionaries</p>
<dt>-u, &#8211;uninstall dictionary</p>
<dd> Uninstall dictionary</p>
<dt>-s, &#8211;sync</p>
<dd> Sync installed dictionaries using rsync</p>
<dt>-v, &#8211;version</p>
<dd> Check the waei version info</p>
<dt>-q, &#8211;quiet</p>
<dd> Display less information</p>
<dt>-h, &#8211;help</p>
<dd> Display help</dl>
