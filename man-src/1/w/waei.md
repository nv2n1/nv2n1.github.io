<p> <code>waei</code> [<i>options</i>]<i> pattern</i>&#8230;</p>
<p> A Japanese-English dictionary that is a drop-in replacement for gjiten. </p>
<p> This is the console version of <code>gwaei.</code></p>
<h2>OPTIONS</h2>
<dl>
<dt>-e, &#8211;exact</dt>
<dd> Do not display less relevant results</dd>
<dt>-d, &#8211;dictionary name</dt>
<dd> Search using a chosen dictionary</dd>
<dt>-l, &#8211;list</dt>
<dd> Show available dictionaries for searches</dd>
<dt>-i, &#8211;install</dt>
<dd> List installable dictionaries</dd>
<dt>-i, &#8211;install dictionary</dt>
<dd> Install dictionary</dd>
<dt>-u, &#8211;uninstall</dt>
<dd> List uninstallable dictionaries</dd>
<dt>-u, &#8211;uninstall dictionary</dt>
<dd> Uninstall dictionary</dd>
<dt>-s, &#8211;sync</dt>
<dd> Sync installed dictionaries using rsync</dd>
<dt>-v, &#8211;version</dt>
<dd> Check the waei version info</dd>
<dt>-q, &#8211;quiet</dt>
<dd> Display less information</dd>
<dt>-h, &#8211;help</dt>
<dd> Display help</dd></dl>
