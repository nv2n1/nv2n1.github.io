<h2>NAME</h2>
<p> jack_monitor_client &#8211; The JACK Audio Connection Kit example client</p>
<h2>SYNOPSIS</h2>
<p> <code>jack_monitor_client</code> client-name </p>
<p> The client-name must be the name of a existing client that monitoring is to be enabled for.</p>
<h2>DESCRIPTION</h2>
<p> <code>jack_monitor_client</code> is an example client for the JACK Audio Connection Kit. It enables monitoring for the specified client.</p>
