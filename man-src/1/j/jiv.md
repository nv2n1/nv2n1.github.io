<h2 class="name">NAME</h2>
<p> jiv &#8211; Image display utility</p>
<h2>SYNOPSIS</h2>
<p> <code>jiv</code> [<i>options</i>] [<i>file</i>&#8230;<i>]</i> </p>
<h2>DESCRIPTION</h2>
<p> The <code>jiv</code> command displays a JPEG-2000 image on an X display. Use the arrow keys for scrolling and &lt; and &gt; for zooming. Please use the &#8211;help command line switch and the JasPer Software Reference Manual for more information. </p>
