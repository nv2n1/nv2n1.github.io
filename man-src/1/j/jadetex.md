<h2 class="name">NAME</h2>
<p> jadetex &#8211; processing tex files produced by the TeX backend of Jade. </p>
<h2>SYNOPSIS</h2>
<p> <code>jadetex</code> [ first line ]</p>
<h2>DESCRIPTION</h2>
<p> This manual page was derived from the manual page for LaTeX and is not meant to be exhaustive. The complete documentation for this version of TeX can be found in the info file or manual <i>Web2C: A TeX implementation</i>. </p>
<p> JadeTeX is a TeX macro package, not a modification to the TeX source program, so all the capabilities described in <code><a href="/docs/linux/man/1-tex/">tex</a></code>(1) are present. <code>pdfjadetex</code> is the PDFTeX version of the jadeTeX format.</p>
