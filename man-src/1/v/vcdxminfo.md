<h2>NAME</h2>
<p> vcdxminfo &#8211; manual page for vcdxminfo 0.7.24</p>
<h2>SYNOPSIS</h2>
<p> <code>vcdxminfo</code> [<i>OPTION</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>-i</code>, <code>&#8211;generic-info</code></p>
<dd> show generic information</p>
<dt><code>-a</code>, <code>&#8211;dump-aps</code></p>
<dd> dump APS data</p>
<dt><code>&#8211;relaxed-aps</code></p>
<dd> relax APS constraints</p>
<dt><code>-o</code>, <code>&#8211;output-file</code>=<i>FILE</i></p>
<dd> file for XML output</p>
<dt><code>-p</code>, <code>&#8211;progress</code></p>
<dd> show progress</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> be verbose</p>
<dt><code>-q</code>, <code>&#8211;quiet</code></p>
<dd> show only critical messages</p>
<dt><code>&#8211;gui</code></p>
<dd> enable GUI mode</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> display version and copyright information and exit</dl>
<h3>Help options:</h3>
<dl>
<dt>-?, <code>&#8211;help</code></p>
<dd> Show this help message</p>
<dt><code>&#8211;usage</code></p>
<dd> Display brief usage message</dl>
