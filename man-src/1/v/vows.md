<h2>NAME</h2>
<p> vows &#8211; Asynchronous behavior-driven development (BDD) framework</p>
<h2>SYNOPSIS</h2>
<p> Usage: vows [FILE, &#8230;] [options]</p>
<h2>DESCRIPTION</h2>
<p> Vows is an asynchronous behavior-driven development (BDD) framework for Node.js. </p>
<p> Vows was built from the ground up to test asynchronous code. It executes your tests in parallel when it makes sense, and sequentially when there are dependencies. Emphasis was put on speed of execution, clarity and user experience.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Enable verbose output</p>
<dt><code>-w</code>, <code>&#8211;watch</code></p>
<dd> Watch mode</p>
<dt><code>-s</code>, <code>&#8211;silent</code></p>
<dd> Don&#8217;t report</p>
<dt><code>-i</code>, <code>&#8211;isolate</code></p>
<dd> Run each test in it&#8217;s own vows process</p>
<dt><code>-m</code></p>
<dd> PATTERN Only run tests matching the PATTERN string</p>
<dt><code>-r</code></p>
<dd> PATTERN Only run tests matching the PATTERN regexp</p>
<dt><code>&#8211;json</code></p>
<dd> Use JSON reporter</p>
<dt><code>&#8211;spec</code></p>
<dd> Use Spec reporter</p>
<dt><code>&#8211;tap</code></p>
<dd> Use TAP reporter</p>
<dt><code>&#8211;dot-matrix</code></p>
<dd> Use Dot-Matrix reporter</p>
<dt><code>&#8211;xunit</code></p>
<dd> Use xUnit reporter</p>
<dt><code>&#8211;cover-plain</code></p>
<dd> Print plain coverage map if detected</p>
<dt><code>&#8211;cover-html</code></p>
<dd> Write coverage map to &quot;coverage.html&quot;</p>
<dt><code>&#8211;cover-json</code></p>
<dd> Write unified coverage map to &quot;coverage.json&quot;</p>
<dt><code>&#8211;cover-xml</code></p>
<dd> Write coverage map to &quot;coverage.xml&quot; in Emma xml</p>
<dt><code>&#8211;no-color</code></p>
<dd> Don&#8217;t use terminal colors</p>
<dt><code>&#8211;version</code></p>
<dd> Show version</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> You&#8217;re staring at it</dl>
