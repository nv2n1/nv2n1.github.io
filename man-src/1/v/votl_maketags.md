<h2 class="name">NAME</h2>
<p> vo_maketags &#8211; build TAGS for vim outliner </p>
<h2>SYNOPSIS</h2>
<p> <code>vo_maketags</code> [<i>filename</i>]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>vo_maketags</code> Perl script. </p>
<p> <code>vo_maketags</code> is a <code><a href="/docs/linux/man/1-perl/">perl</a></code>(1) script that creates tag file which works with <code>vimoutliner</code> (<code><a href="/docs/linux/man/1-vim/">vim</a></code>(1) plugin for editing outlines).</p>
<h2>OPTIONS</h2>
<p> <code>vo_maketags</code> script called just with filename of the processed outline, which is a top of the hierarchy of linked outlines.</p>
