<h2 class="name">NAME</h2>
<p> vltest &#8211; test cases for QDBM Villa</p>
<h2>SYNOPSIS</h2>
<p> <code>vltest write</code> [-int] [-cz|-cy|-cx] [-tune <i>lrecmax</i> <i>nidxmax</i> <i>lcnum</i> <i>ncnum</i>] [-fbp <i>num</i>] <i>name</i> <i>rnum</i><br />
 <code>vltest read</code> [-int] <i>name</i><br />
 <code>vltest rdup</code> [-int] [-cz|-cy|-cx] [-cc] [-tune <i>lrecmax</i> <i>nidxmax</i> <i>lcnum</i> <i>ncnum</i>] [-fbp <i>num</i>] <i>name</i> <i>rnum</i> <i>pnum</i><br />
 <code>vltest combo</code> [-cz|-cy|-cx] <i>name</i><br />
 <code>vltest wicked</code> [-c] [-cz|-cy|-cx] <i>name</i> <i>rnum</i> </p>
<h2>DESCRIPTION</h2>
<p> The command `vltest&#8217; is a utility for facility test and performance test. Check a database generated by the command or measure the execution time of the command. This command is used in the following format. `name&#8217; specifies a database name. `rnum&#8217; specifies the number of the records. </p>
<dl>
<dt><code>vltest write [-int] [-cz|-cy|-cx] [-tune lrecmax nidxmax lcnum ncnum] [-fbp num] name rnum</code></p>
<dd> Store records with keys of 8 bytes. They change as `00000001&#8242;, `00000002&#8217;&#8230;</p>
<dt><code>vltest read [-int] [-vc] name</code></p>
<dd> Retrieve all records of the database above.</p>
<dt><code>vltest rdup [-int] [-cz|-cy|-cx] [-cc] [-tune lrecmax nidxmax lcnum ncnum] [-fbp num] name rnum pnum</code></p>
<dd> Store records with partway duplicated keys using duplicate mode.</p>
<dt><code>vltest combo [-cz|-cy|-cx] name</code></p>
<dd> Perform combination test of various operations.</p>
<dt><code>vltest wicked [-c] [-cz|-cy|-cx] name rnum</code></p>
<dd> Perform updating operations selected at random.</dl>
<p> Options feature the following. </p>
<dl>
<dt>
<dd> <code>-int</code> : treat keys and values as objects of `int&#8217;, and use comparing function `VL_CMPINT&#8217;.<br />
 <code>-cz</code> : compress leaves in the database with ZLIB.<br />
 <code>-cy</code> : compress leaves in the database with LZO.<br />
 <code>-cx</code> : compress leaves in the database with BZIP2.<br />
 <code>-vc</code> : refer to volatile cache.<br />
 <code>-cc</code> : select `VL_DCAT&#8217; or `VL_DDUP&#8217; at random.<br />
 <code>-tune lrecmax nidxmax lcnum ncnum</code> : set tuning parameters.<br />
 <code>-fbp num</code> : set the size of the free block pool.<br />
 <code>-c</code> : perform comparison test with map of Cabin.</dl>
<p> This command returns 0 on success, another on failure. The environment variable `QDBMDBGFD&#8217; specifies the file descriptor to output the history of updating the variable `dpecode&#8217;. </p>
