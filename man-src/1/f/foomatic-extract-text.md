<h2>NAME</h2>
<p> foomatic-extract-text &#8211; Generate .po files from Foomatic UI strings</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>foomatic-extract-text</code> </p>
</dl>
<h2>DESCRIPTION</h2>
<dd>The <code>foomatic-extract-text</code> command generates .po files from the UI strings in the currently installed Foomatic database. </p>
<p> It is not intended to be called directly by the user. </p>
