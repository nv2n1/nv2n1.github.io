<h2>NAME</h2>

 fts-transfer-delete

<h2>SYNOPSIS</h2>

 fts-transfer-delete [options]

<h2>DESCRIPTION</h2>

 fts-transfer-delete is a tool for deleting files using the GRID File Transfer Service 3.
