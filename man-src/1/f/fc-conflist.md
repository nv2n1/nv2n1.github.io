<h2 class="name">NAME</h2>
<p> fc-conflist &#8211; Show the ruleset files information on the system </p>
<h2>SYNOPSIS</h2>
<p> <code>fc-conflist</code> [ <code>-Vh</code> ] </p>
<p>&nbsp;[&nbsp;<code>&#8211;version</code>&nbsp;]&nbsp;<wbr>&nbsp;[&nbsp;<code>&#8211;help</code>&nbsp;]&nbsp;</p>
<h2>DESCRIPTION</h2>
<p> <code>fc-conflist</code> shows the ruleset files&#8217; information being installed on the system.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-V</code></p>
<dd> Show version of the program and exit.</p>
<dt><code>-h</code></p>
<dd> Show summary of options.</dl>
<h2>RETURN CODES</h2>
<p> <code>fc-conflist</code> returns error code 0 for successful parsing, or 1 if any errors occured or if at least one font face could not be opened.</p>
