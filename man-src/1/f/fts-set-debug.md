<h2>NAME</h2>

 fts-set-debug

<h2>SYNOPSIS</h2>

 fts-set-debug [options] LEVEL

<h2>DESCRIPTION</h2>

 fts-set-debug is a tool for setting the debug mode to one of the possible levels: 0, 1, 2 or 3 for a source SE, destination SE or a SE pair.
