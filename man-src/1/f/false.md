<h2 class="name">NAME</h2>
<p> false &#8211; do nothing, unsuccessfully </p>
<h2>SYNOPSIS</h2>
<p> <code>false</code> [<i>,ignored command line arguments/</i>]<br />
 <code>false</code> <i>,OPTION/</i></p>
<h2>DESCRIPTION</h2>
<p> Exit with a status code indicating failure.</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> output version information and exit</dl>
<p> NOTE: your shell may have its own version of false, which usually supersedes the version described here. Please refer to your shell&#8217;s documentation for details about the options it supports.</p>
