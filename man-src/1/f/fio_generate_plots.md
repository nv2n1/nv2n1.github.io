<h2 class="name">NAME</h2>
<p> fio_generate_plots &#8211; Generate plots for Flexible I/O Tester </p>
<h2>SYNOPSIS</h2>
<p> <code>fio_generate_plots</code> title </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>fio_generate_plots</code> command. This manual page was written for the Debian distribution because the original program does not have a manual page. </p>
<p> <code>fio_generate_plots</code> is a shell script that uses gnuplot to generate plots from fio run with &#8211;latency-log (-l) and/or &#8211;bandwidth-log (-w). It expects the log files that fio generated in the current directory.</p>
<h2>OPTIONS</h2>
<p> The script takes the title of the plot as only argument. It does not offer any additional options.</p>
