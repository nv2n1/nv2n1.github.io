<h2>NAME</h2>
<p> foomatic-cleanupdrivers &#8211; Remove driver entries with no command line</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>foomatic-cleanupdrivers</code> [<i>DBDIR</i>] </p>
</dl>
<h2>DESCRIPTION</h2>
<dd>The <code>foomatic-cleanupdrivers</code> command removes all driver XML files which have an empty command line. </p>
<p> It is not intended to be called directly by the user. </p>
