<h2 class="name">NAME</h2>
<p> flatpak-document-unexport &#8211; Stop exporting a file </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>flatpak document-unexport</code> [OPTION&#8230;] FILE</dl>
<h2>DESCRIPTION</h2>
<dd>Removes the document id for the file from the document portal. This will make the document unavailable to all sandboxed applications.</p>
<h2>OPTIONS</h2>
<p> The following options are understood: </p>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show help options and exit.</dl>
<p> <code>-v</code>, <code>&#8211;verbose</code></p>
<dl>
<dt>
<dd> Print debug information during command processing.</dl>
<p> <code>&#8211;ostree-verbose</code></p>
<dl>
<dt>
<dd> Print OSTree debug information during command processing.</dl>
