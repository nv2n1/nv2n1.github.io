<h2 class="name">NAME</h2>
<p> fwupdmgr &#8211; firmware update manager client utility </p>
<h2>SYNOPSIS</h2>
<p> fwupdmgr [CMD]</p>
<h2>DESCRIPTION</h2>
<p> fwupdmgr is a command line fwupd client intended to be used interactively. The output between versions of fwupd is not guaranteed to be stable.</p>
<h2>OPTIONS</h2>
<p> The fwupdmgr command takes various options depending on the action. Run <code>fwupdmgr &#8211;help</code> for the full list.</p>
<h2>EXIT STATUS</h2>
<p> Commands that successfully execute will return &quot;0&quot;, but commands that have no actions but successfully execute will return &quot;2&quot;.</p>
