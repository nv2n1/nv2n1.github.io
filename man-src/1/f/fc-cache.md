<h2 class="name">NAME</h2>
<p> fc-cache &#8211; build font information cache files </p>
<h2>SYNOPSIS</h2>
<p> <code>fc-cache</code> [ <code>-EfrsvVh</code> ] [ <code>&#8211;error-on-no-fonts</code> ] [ <code>&#8211;force</code> ] [ <code>&#8211;really-force</code> ] [ <code> [ -y </code><i>dir</i><code> ] [ &#8211;sysroot </code><i>dir</i><code> ] </code> ] [ <code>&#8211;system-only</code> ] [ <code>&#8211;verbose</code> ] [ <code>&#8211;version</code> ] [ <code>&#8211;help</code> ] [ <i>dir</i><i>&#8230;</i> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>fc-cache</code> scans the font directories on the system and builds font information cache files for applications using fontconfig for their font handling. </p>
<p> If directory arguments are not given, <code>fc-cache</code> uses each directory in the current font configuration. Each directory is scanned for font files readable by FreeType. A cache is created which contains properties of each font and the associated filename. This cache is used to speed up application startup when using the fontconfig library. </p>
<p> Note that <code>fc-cache</code> must be executed once per architecture to generate font information customized for that architecture.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-E</code></p>
<dd> Raise an error if there are no fonts in <i>dir</i> or directories in the configuration if not given.</p>
<dt><code>-f</code></p>
<dd> Force re-generation of apparently up-to-date cache files, overriding the timestamp checking.</p>
<dt><code>-r</code></p>
<dd> Erase all existing cache files and rescan.</p>
<dt><code>-s</code></p>
<dd> Only scan system-wide directories, omitting the places located in the user&#8217;s home directory.</p>
<dt><code>-v</code></p>
<dd> Display status information while busy.</p>
<dt><code>-y</code></p>
<dd> Prepend <i>dir</i> to all paths for scanning.</p>
<dt><code>-h</code></p>
<dd> Show summary of options.</p>
<dt><code>-V</code></p>
<dd> Show version of the program and exit.</p>
<dt><i>dir</i></p>
<dd> Directory to scan for fonts.</dl>
<h2>RETURN CODES</h2>
<p> <code>fc-cache</code> returns zero if the caches successfully generated. otherwise non-zero.</p>
<h2>FILES</h2>
<dl>
<dt><i>%cachedir%/*-%arch%.cache-%version%</i></p>
<dd> These files are generated by <code>fc-cache</code> and contain maps from file names to font properties. They are read by the fontconfig library at application startup to locate appropriate fonts.</dl>
