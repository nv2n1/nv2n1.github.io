<h2>NAME</h2>
<p> freehoo &#8211; manual page for freehoo messenger</p>
<h2>SYNOPSIS</h2>
<p> <code>freehoo</code> [<i>OPTION</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> Freehoo is a free console based messenger for Yahoo IM Service with GNU Bash like tab completion / editing and GNU Emacs like extensibility.</p>
<dl>
<dt><code>-s</code>, <code>&#8211;status</code>=<i>STATUS</i></p>
<dd> Default login status number</p>
<dt><code>-u</code>, <code>&#8211;user</code>=<i>YAHOOID</i></p>
<dd> User login account name</p>
<dt>-?, <code>&#8211;help</code></p>
<dd> Give this help list</p>
<dt><code>&#8211;usage</code></p>
<dd> Give a short usage message</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print program version</dl>
<p> Mandatory or optional arguments to long options are also mandatory or optional for any corresponding short options.</p>
<h2>REPORTING BUGS</h2>

<dd> <code>info freehoo</code></dl>
