<h2>NAME</h2>
<p> foomatic-perl-data &#8211; generate Perl data structures from XML</p>
<h2>SYNOPSIS</h2>
<p> <code>foomatic-perl-data</code> [ <i>-O</i> ] [ <i>-C</i> ] [ <i>-P</i> ] [ <i>-D</i> ] [ <i>-o option=setting</i> ] [ <i>-o &#8230;</i> ] [ <i>-v</i> ] [ <i>filename</i> ] </p>
<h3>Options</h3>
<p> <code>-O</code> Parse overview XML data </p>
<p> <code>-C</code> Parse printer/driver combo XML data (default) </p>
<p> <code>-P</code> Parse printer entry XML data </p>
<p> <code>-D</code> Parse driver entry XML data </p>
<p> <code>-o</code><i>&nbsp;<wbr>option=setting</i> Default option settings for the generated Perl data (combo only) </p>
<p> <code>-v</code> Verbose (debug) mode </p>
<p> <code>filename</code> Read input from a file and not from standard input </p>
<h2>EXIT STATUS</h2>
<p> <code>foomatic-perl-data</code> returns &#8230; </p>
