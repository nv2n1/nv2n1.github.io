<h2 class="name">NAME</h2>
<p>&nbsp;<wbr>fotoxx &#8211; digital photo editor and collection manager</p>
<h2>SYNOPSIS</h2>
<p>&nbsp;<wbr><code>fotoxx</code>&nbsp;<wbr>[&nbsp;<wbr><code>-v</code>&nbsp;<wbr>]&nbsp;<wbr>[&nbsp;<wbr><code>-l</code>&nbsp;<wbr><i>code</i>&nbsp;<wbr>]&nbsp;<wbr>[&nbsp;<wbr><i>file</i>&nbsp;<wbr>|&nbsp;<wbr><i>directory</i>&nbsp;<wbr>] </p>
<h2>DESCRIPTION</h2>
<p>&nbsp;<wbr>Fotoxx is a graphical menu-driven program which operates in&nbsp;<wbr><br />
&nbsp;<wbr>its own window. Organize and administer a collection of images,&nbsp;<wbr><br />
&nbsp;<wbr>search for images, edit images, perform utility functions. </p>
<h2>OVERVIEW</h2>
<p> Edit functions include:<br />
&nbsp;<wbr>&#8211; Flatten brightness distribution&nbsp;<wbr>(a sometimes quick fix)<br />
&nbsp;<wbr>&#8211; Brightness and color adjustments using movable curves<br />
&nbsp;<wbr>&#8211; Trim, Rescale, Rotate&nbsp;<wbr>(any angle)<br />
&nbsp;<wbr>&#8211; Warp&nbsp;<wbr>(stretch/distort image by dragging the mouse)<br />
&nbsp;<wbr>&#8211; Sharpen, Blur, Noise reduction, Red-eye removal<br />
&nbsp;<wbr>&#8211; Panorama and HDR composites&nbsp;<wbr>(hand-held photos OK)<br />
&nbsp;<wbr>&#8211; Artful transformations&nbsp;<wbr>(simulated drawing or painting)<br />
&nbsp;<wbr>&#8211; Pixel edit with variable brush and blending<br />
&nbsp;<wbr>&#8211; Add tags, dates, and star-ratings to images </p>
<p> Utility functions include:<br />
&nbsp;<wbr>&#8211; Search images by tags, dates, star-ratings, file names<br />
&nbsp;<wbr>&#8211; Rename images using a base name and sequence number<br />
&nbsp;<wbr>&#8211; Slide-show mode: full screen, keyboard navigation<br />
&nbsp;<wbr>&#8211; Batch convert multiple RAW files to tiff-48<br />
&nbsp;<wbr>&#8211; Select images from the navigator and burn a CD or DVD </p>
<h2>OPTIONS</h2>
<p> Command line options<br />
&nbsp;<wbr><code>-v</code>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>type version and exit<br />
&nbsp;<wbr><code>-l</code>&nbsp;<wbr><i>code</i>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>specify locale&nbsp;<wbr>(de, fr, zh_CN &#8230;)<br />
&nbsp;<wbr><i>file</i>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>initial image file to view or edit<br />
&nbsp;<wbr><i>directory</i>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>initial directory of image files<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>(File&nbsp;<wbr>&gt;&nbsp;<wbr>Open menu will start here) </p>
