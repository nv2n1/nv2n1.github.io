<p>FRA &#8211; Example of using QuantLib</p>
<h2>Synopsis</h2>
<p><code>FRA</code></p>
<h2>Description</h2>
<p><code>FRA</code> is an example of using the <i>QuantLib</i> interest-rate model framework. </p>
<p> <code>FRA</code> values a forward-rate agreement (FRA) at different forward dates under two yield curve assumptions. It thereby illustrates how set up a term structure, and to use it to price a simple forward-rate agreement.</p>
