<h2 class="name">NAME</h2>
<p> flatpak-documents &#8211; List exported files </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>flatpak documents</code> [OPTION&#8230;] [APPID]</dl>
<h2>DESCRIPTION</h2>
<dd>Lists exported files, with their document id and the full path to their origin. If an APPID is specified, only the files exported to this app are listed.</p>
<h2>OPTIONS</h2>
<p> The following options are understood: </p>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show help options and exit.</dl>
<p> <code>-v</code>, <code>&#8211;verbose</code></p>
<dl>
<dt>
<dd> Print debug information during command processing.</dl>
<p> <code>&#8211;ostree-verbose</code></p>
<dl>
<dt>
<dd> Print OSTree debug information during command processing.</dl>
