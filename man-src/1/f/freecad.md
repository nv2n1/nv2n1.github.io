<h2 class="name">NAME</h2>
<p> freecad &#8211; An extensible Open Source CAx program for Unix/X11 </p>
<h2>SYNOPSIS</h2>
<p> <code>freecad</code> [<i>options</i>]<i> files</i><br />
 <code>freecadcmd</code> [<i>options</i>]<i> files</i></p>
<h2>DESCRIPTION</h2>
<p> <code>FreeCAD</code> is an Open Source CAx RAD based on OpenCasCade, Qt and Python. It features some key concepts like macro recording, workbenches, ability to run as a server and dynamically loadable application extensions and it is designed to be platform independent.</p>
<h2>USAGE</h2>
<p> <code>freecad</code> starts with a GUI while <code>freecadcmd</code> is only a pure command line version that starts a Python interpreter.</p>
<h2>OPTIONS</h2>
<p> These programs follow the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of the options supported by <code>freecad</code> is included below.</p>
<h3>Generic options</h3>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>-v, &#8211;version</code></p>
<dd> Show version of program.</p>
<dt><code>-c, &#8211;console</code></p>
<dd> Start in console mode.</p>
<dt><code>&#8211;response-file</code> <i>arg</i></p>
<dd> Can be specified with &#8216;@name&#8217;, too. </p>
</dl>
<h3>Configuration</h3>
<dl>
<dt><code>-l, &#8211;write-log</code></p>
<dd> Write a log file.</p>
<dt><code>-t, &#8211;run-test</code> <i>arg</i></p>
<dd> Test level.</p>
<dt><code>-M, &#8211;module-path</code> <i>arg</i></p>
<dd> Additional module path.</p>
<dt><code>-P, &#8211;python-path</code> <i>arg</i></p>
<dd> Additional Python path.</dl>
