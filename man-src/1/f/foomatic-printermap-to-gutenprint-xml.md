<h2>NAME</h2>
<p> foomatic-printermap-to-gutenprint-xml &#8211; Updates Gutenprint driver XML file</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>foomatic-printermap-to-gutenprint-xml</code> </p>
</dl>
<h2>DESCRIPTION</h2>
<dd>This command updates the driver XML file for the Gutenprint driver to the state of the foomatic-printermap file in the Gutenprint source tree. Used to update the driver XML file for Gutenprint in the OpenPrinting database. </p>
<p> It is very unlikely you need to do this. </p>
