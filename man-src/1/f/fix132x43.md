<h2>NAME</h2>
<p> fix132x43 &#8211; fix problems with certain (132 column) graphics modes dump the state of the card as the svgalib chipset driver sees it.</p>
<h2>SYNOPSIS</h2>
<p> <code>fix132x43</code><i> options</i> </p>
<h2>DESCRIPTION</h2>
<p> This program tries to fix problems with extended textmodes on some cards. The problem is that for 132&#215;43 textmode, some BIOS&#8217;s set the vertical display end register to 349 (350), instead of 343 (344 = 3 * 8 scanlines). Because in Linux textmode video memory is usually filled with old text that has already scrolled away (this includes the area below the 43rd textmode line, which changes when the console scrolls), the top half of a constantly changing irrelevant text line is visible at the bottom of the screen, which is very annoying. </p>
<p> This program sets the VGA Vertical Display End register to the proper value. </p>
<p> This problem is at least present in the BIOS of most Cirrus Logic 542x based cards, and some WD90C03x based cards. </p>
<p> The <code>LINES</code> environment variable is used to detect 43 or 44 line consoles. </p>
<h2>OPTIONS</h2>
<p> You have to specify exactly one of the following options:</p>
<dl>
<dt><code>-f</code></p>
<dd> Fix problem of annoying changing line of text at bottom of screen.</p>
<dt><code>-v</code></p>
<dd> Switch to 9 line characters (400 line frame, 70 Hz).</p>
<dt><code>-w</code></p>
<dd> Switch to 11 line characters (480 line frame, 60 Hz). </p>
<p> <code>fix132x43</code> does not usually provide this option but it can be enabled in the source of <code>fix132x43.</code> </p>
<dt><code>-r</code></p>
<dd> Switch to 8 line characters again (350 line frame, 70 Hz).</dl>
<p> This utility is part of svgalib and can be found in the <i>utils/</i> subdirectory of the original svgalib distribution. However, it is not installed by default, s.t. it is unclear where you can find it if your svgalib was install linux distribution. </p>
<p> In case of any such problem, simply get an svgalib distribution from the net. You don&#8217;t need to install it. Just <code>make</code> in the <i>utils/</i> subdirecty. As of this writing, <i>svgalib-1.2.12.tar.gz</i> is the latest version and can be retrieved by ftp from <i>sunsite.unc.edu</i> at <i>/pub/Linux/libs/graphics</i> and <i>tsx-11.mit.edu</i> at <i>/pub/linux/sources/libs</i> which will most probably be mirrored by a site close to you. </p>
