<h2>NAME</h2>
<p> foomatic-nonumericalids &#8211; Convert numerical printer IDS to clear-text IDs  </p>
<dl>
<dt><code>foomatic-nonumericalids</code><dd> <p> This script changes all old cryptic numerical printer IDs from the old PostGreSQL time to clear-text printer IDs in the installed Foomatic database. </p>
<p> It is very unlikely you need to do this. </p>
