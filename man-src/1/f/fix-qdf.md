<h2 class="name">NAME</h2>
<p> fix-qdf &#8211; repair PDF files in QDF form after editing </p>
<h2>SYNOPSIS</h2>
<p> <code>fix-qdf</code> &lt; <i>infilename</i> &gt; <i>outfilename</i></p>
<h2>DESCRIPTION</h2>
<p> The fix-qdf program is part of the qpdf package. </p>
<p> The fix-qdf program reads a PDF file in QDF form and writes out the same file with stream lengths, cross-reference table entries, and object stream offset tables regenerated. </p>
<p> For details about fix-qdf and about PDF files in QDF mode, please see the qpdf manual, which can be found at <a rel="nofollow" href="https://qpdf.readthedocs.io.">https://qpdf.readthedocs.io.</a></p>
