<h2>NAME</h2>
<p> kodi-wiiremote &#8211; Wiimote Remote Control Client for Kodi</p>
<h2>DESCRIPTION</h2>
<p> This script is the Kodi remote control client that will allow Kodi to be controlled by a Wiimote.</p>
<h3>Arguments:</h3>
<dl>
<dt> <code>&#8211;disable-mouseemulation</code></p>
<dt> <code>&#8211;disable-reconnect</code></p>
<dt> <code>&#8211;disable-nunchuck</code></p>
<dt> <code>&#8211;address</code> ADDRESS</p>
<dt> <code>&#8211;port</code> PORT</p>
<dt> <code>&#8211;btaddr</code> MACADDRESS</p>
<dt><code>&#8211;deadzone-x</code> DEADX</p>
<dd> | Number between 0 &#8211; 100 (Default: 50)</p>
<dt><code>&#8211;deadzone-y</code> DEADY</p>
<dd> | Number between 0 &#8211; 100 (Default: 30)</p>
<dt><code>&#8211;deadzone</code> DEAD</p>
<dd> | Sets both X and Y too the number</p>
<dt><code>&#8211;smoothing-samples</code> SAMPLE</p>
<dd> | Number 1 counts as Off (Default: 16)</p>
<dt><code>&#8211;joystick-map</code> JOYMAP</p>
<dd> | The string ID for the joymap (Default: WiiRemote) </p>
</dl>
