<h2>NAME</h2>
<p> kodi-wiiremote &#8211; Wiimote Remote Control Client for Kodi</p>
<h2>DESCRIPTION</h2>
<p> This script is the Kodi remote control client that will allow Kodi to be controlled by a Wiimote.</p>
<h3>Arguments:</h3>
<dl>
<dt> <code>&#8211;disable-mouseemulation</code></dt>
<dt> <code>&#8211;disable-reconnect</code></dt>
<dt> <code>&#8211;disable-nunchuck</code></dt>
<dt> <code>&#8211;address</code> ADDRESS</dt>
<dt> <code>&#8211;port</code> PORT</dt>
<dt> <code>&#8211;btaddr</code> MACADDRESS</dt>
<dt><code>&#8211;deadzone-x</code> DEADX</dt>
<dd> | Number between 0 &#8211; 100 (Default: 50)</dd>
<dt><code>&#8211;deadzone-y</code> DEADY</dt>
<dd> | Number between 0 &#8211; 100 (Default: 30)</dd>
<dt><code>&#8211;deadzone</code> DEAD</dt>
<dd> | Sets both X and Y too the number</dd>
<dt><code>&#8211;smoothing-samples</code> SAMPLE</dt>
<dd> | Number 1 counts as Off (Default: 16)</dd>
<dt><code>&#8211;joystick-map</code> JOYMAP</dt>
<dd> | The string ID for the joymap (Default: WiiRemote) </dd>
</dl>
