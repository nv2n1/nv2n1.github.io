<h2>NAME</h2>
<p> kazehakase &#8211; Gecko based web browser using GTK</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>kazehakase</code> [<i>OPTION&#8230;</i>] [<i>URL&#8230;</i>] </p>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>kazehakase</code> is a web browser using the Mozilla rendering and networking engines. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-a </code><i>ACTION</i>, <code>&#8211;action </code><i>ACTION</i></p>
<dd>
<dd>Invoke the action in kazehakase. </p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> Show the version. </p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show this help. </p>
</dl>
<h2>EXAMPLES</h2>
<dl>
<dt>kazehakase &#8211;action &quot;KzWindowTabPopup/TabCopyTitle 1 3&quot;</p>
<dd> Copy the title of the 3rd tab in the 1st window. </p>
</dl>
