<h2>NAME</h2>
<p> keepass &#8211; password manager</p>
<h2>SYNOPSIS</h2>
<p> <code>keepass</code></p>
<h2>DESCRIPTION</h2>
<p> <code>KeePass</code> is a free/open-source password manager or safe which helps you to manage your passwords in a secure way. You can put all your passwords in one database, which is locked with one master key or a key file. So you only have to remember one single master password to unlock the whole database. The databases are encrypted using AES-256.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;auto-type</code></p>
<dd> invokes global auto-type</p>
<dt><code>&#8211;lock-all</code></p>
<dd> lock databases of all KeePass instances</p>
<dt><code>&#8211;unlock-all</code></p>
<dd> unlock databases of all KeePass instances</p>
<dt><code>&#8211;exit-all</code></p>
<dd> exit all KeePass instances</dl>
