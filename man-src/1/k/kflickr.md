<h2>NAME</h2>
<p> kflickr &#8211; stand-alone flickr.com photo uploader for KDE</p>
<h2>SYNOPSIS</h2>
<p> <code>kflickr [&#8211;help] [&#8211;help-qt] [&#8211;help-kde] [&#8211;help-all] [&#8211;author] [&#8211;license] [-v] [</code> <i>URL(s)</i> <code>]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>kflickr</code> Provides a GUI which may be used to modify photo attributes before sending loaded photo files to the users flickr.com photo stream. Allows editing of the most common attributes as well as sending photos directory to a specified photo stream associated with the users account.</p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;help</p>
<dd> Display command line options.</p>
<dt>&#8211;help-qt</p>
<dd> Display QT specific command line options.</p>
<dt>&#8211;help-kde</p>
<dd> Display KDE specific command line options.</p>
<dt>&#8211;help-all</p>
<dd> Display help on all command line options.</p>
<dt>&#8211;author</p>
<dd> Display information on the application author.</p>
<dt>-v</p>
<dd> Display application version</p>
<dt>&#8211;license</p>
<dd> Display license information.</p>
<dt>URL(s)</p>
<dd> List of photos to load.</dl>
