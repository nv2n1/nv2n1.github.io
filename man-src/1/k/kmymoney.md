<h2 class="name">NAME</h2>
<p> kmymoney &#8211; the personal finances manager for KDE </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>kmymoney</code> [<code>Generic Options</code>] [<code>Qt Options</code>] [<code>KDE Options</code>] [<code>Options</code>] [<code>File</code>]</dl>
<h2>DESCRIPTION</h2>
<dd>KMyMoney is the Personal Finance Manager for the KDE environment. It provides the functions required to balance your checkbooks, manage your personal loans and categories your incomes and expenses using a checkbook style graphical user interface.</p>

<h2>ENVIRONMENT</h2>
<p> $<code>KDE_LANG</code></p>
<dl>
<dt>
<dd> Language locale setting to use. This option makes it possible to set another language environment for a program than what is the default. The correct language pack for this language has to be installed for this option to work. The default language when there is none set is en_US. When deciding upon a language, the following resources are looked up, in order: <code>KDE_LANG</code>, configuration file, <code>LC_CTYPE</code>, <code>LC_MESSAGES</code>, <code>LC_ALL</code>, <code>LANG</code>.</dl>
<p> $<code>KDE_UTF8_FILENAMES</code></p>
<dl>
<dt>
<dd> Assume that all filenames are in UTF-8 format regardless of the current language setting. Otherwise the filename format is defined by the language.</dl>
<p> $<code>KDE_MULTIHEAD</code></p>
<dl>
<dt>
<dd> If this variable has the value true multihead multiple display mode is enabled. The KDE display will be shared over more than one screen.</dl>
<p> $<code>DISPLAY</code></p>
<dl>
<dt>
<dd> Specifies the X display to run KDE on.</dl>
<p> $<code>SESSION_MANAGER</code></p>
<dl>
<dt>
<dd> The session manager to use. This option is set automatically by KDE and is a network path to the session manager socket.</dl>
<p> $<code>HOME</code></p>
<dl>
<dt>
<dd> Path to the home directory for the current user.</dl>
<p> $<code>KDEHOME</code></p>
<dl>
<dt>
<dd> The KDE per-user setting directory.</dl>
