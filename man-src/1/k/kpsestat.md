<h2 class="name">NAME</h2>
<p> kpsestat &#8211; compute octal mode from mode of existing file </p>
<h2>SYNOPSIS</h2>
<p> <code>kpsestat</code> <i>mode</i> <i>file</i></p>
<h2>DESCRIPTION</h2>
<p> <code>kpsestat</code> prints the octal permission of <i>file</i> modified according to <i>mode</i> on standard output. The <i>mode</i> parameter accepts a subset of the symbolic permissions accepted by <code><a href="/docs/linux/man/1-chmod/">chmod</a></code>(1). Use <code>=</code> as the mode to obtain the unchanged permissions.</p>
<h2>OPTIONS</h2>
<p> <code>kpsestat</code> accepts the following options:</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Print help message and exit.</p>
<dt><code>&#8211;version</code></p>
<dd> Print version information and exit.</dl>
