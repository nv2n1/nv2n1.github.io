<h2>NAME</h2>
<p> kodi-j2meremote &#8211; Java Bluetooth Phone Remote Control Client for Kodi</p>
<h2>DESCRIPTION</h2>
<p> This script is the Kodi remote control client that will allow Kodi to be controlled by a Java Bluetooth Phone.</p>
<h2>USAGE</h2>
<p> Usage for kodi-j2meremote</p>
<h3>Arguments:</h3>
<dl>
<dt><code>&#8211;address</code> ADDRESS</p>
<dd> (default: localhost)</p>
<dt><code>&#8211;port</code> PORT</p>
<dd> (default: 9777)</p>
<dt><code>&#8211;help</code></p>
<dd> (Brings up this message) </p>
</dl>
