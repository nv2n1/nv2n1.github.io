<h2>NAME</h2>
<p> kodi.bin &#8211; Kodi main executable</p>
<h2>SYNOPSIS</h2>
<p> <code>kodi.bin</code> [<i>OPTION</i>]&#8230; [<i>FILE</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> This is the main executable that will run Kodi.</p>
<h3>Arguments:</h3>
<dl>
<dt><code>-fs</code></p>
<dd> Runs Kodi in full screen</p>
<dt><code>&#8211;standalone</code></p>
<dd> Kodi runs in a stand alone environment without a window manager and supporting applications. For example, that enables network settings.</p>
<dt><code>-p</code> or <code>&#8211;portable</code></p>
<dd> Kodi will look for configurations in install folder instead of ~/.kodi</p>
<dt><code>&#8211;legacy-res</code></p>
<dd> Enables screen resolutions such as PAL, NTSC, etc.</p>
<dt><code>-l</code> or <code>&#8211;lircdev</code></p>
<dd> LircDevice to use. See &#8211;help output for the default.</p>
<dt><code>-n</code> or <code>&#8211;nolirc</code></p>
<dd> do not use Lirc, aka no remote input.</dl>
