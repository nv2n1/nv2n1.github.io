<h2>NAME</h2>
<dl>
<dt><code>kdig</code></p>
<dd> &#8211; Advanced DNS lookup utility (libknot equivalent of ISC dig)</dl>
<h2>SYNOPSIS</h2>
<p> <code>kdig</code> [<i>common-settings</i>] [<i>query</i> [<i>settings</i>]]&#8230;</p>
<dl>
<dt><code>kdig -h</code></p>
<dd></dl>
<h2>DESCRIPTION</h2>
<p> This utility sends one or more DNS <i>queries</i> to a nameserver. Each query can have individual <i>settings</i>, or it can be specified globally via <i>common-settings</i>, which must precede <i>query</i> specification.</p>
<dl>
<dt><i>query</i></p>
<dd> <i>name</i> | <code>-q</code> <i>name</i> | <code>-x</code> <i>address</i> | <code>-G</code> <i>tapfile</i></p>
<dt><i>common-settings, settings</i></p>
<dd> [<i>class</i>] [<i>type</i>] [<code>@</code><i>server</i>]&#8230; [<i>options</i>]</p>
<dt><i>name</i></p>
<dd> Is a domain name that is to be looked up.</p>
<dt><i>server</i></p>
<dd> Is a domain name or an IPv4 or IPv6 address of the nameserver to send a query to. An additional port can be specified using address:port ([address]:port for IPv6 address) or address [at] port or address#port notation. If no server is specified, the servers from <code>/etc/resolv.conf</code> are used.</p>
<dt>If no arguments are provided, <code>kdig</code> sends <i>NS</i> query for the root zone.</p>
<dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-4</code></p>
<dd> Use IPv4 protocol only.</p>
<dt><code>-6</code></p>
<dd> Use IPv6 protocol only.</p>
<dt><code>-b</code><i>&nbsp;<wbr>address</i></p>
<dd> Set the source IP address of the query to <i>address</i>. The address must be a valid address for local interface or :: or 0.0.0.0. Optional port can be specified in the same format as <i>server</i> value.</p>
<dt><code>-c</code><i>&nbsp;<wbr>class</i></p>
<dd> Set query class (e.g. <i>CH</i>, <i>CLASS4</i>). An explicit variant of <i>class</i> specification. The default class is <i>IN</i>.</p>
<dt><code>-d</code></p>
<dd> Enable debug messages if any.</p>
<dt><code>-h</code>,&nbsp;<wbr><code>&#8211;help</code></p>
<dd> Print short help.</p>
<dt><code>-k</code><i>&nbsp;<wbr>keyfile</i></p>
<dd> Use TSIG or SIG-0 key stored in a file <i>keyfile</i> to authenticate the request. Supported file format is the same as generated by ISC <code>dnssec-keygen</code>. The key comprises of public (.key extension) and private part (.private extension). Either of these file names or a name without the extension can be specified as <i>keyfile</i> parameter.</p>
<dt><code>-p</code><i>&nbsp;<wbr>port</i></p>
<dd> Set nameserver port number or service name to send a query to. The default port is <i>53</i>.</p>
<dt><code>-q</code><i>&nbsp;<wbr>name</i></p>
<dd> Set query name. An explicit variant of <i>name</i> specification.</p>
<dt><code>-t</code><i>&nbsp;<wbr>type</i></p>
<dd> Set query type (e.g. <i>NS</i>, <i>IXFR=12345</i>, <i>TYPE65535</i>). An explicit variant of <i>type</i> specification. The default type is <i>A</i>. It is also possible to use <i>NOTIFY</i> parameter to send a notify message.</p>
<dt><code>-v</code>,&nbsp;<wbr><code>&#8211;version</code></p>
<dd> Print program version.</p>
<dt><code>-x</code><i>&nbsp;<wbr>address</i></p>
<dd> Send reverse (<i>PTR</i>) query for IPv4 or IPv6 <i>address</i>. Correct name, class and type is set automatically.</p>
<dt><code>-y </code>[<i>algo:</i>]<i>keyname:key</i></p>
<dd> Use TSIG key with a name <i>keyname</i> to authenticate the request. The <i>algo</i> part specifies the algorithm (the default is hmac-md5) and <i>key</i> specifies the shared secret encoded in Base64.</p>
<dt><code>-E</code><i>&nbsp;<wbr>tapfile</i></p>
<dd> Export a dnstap trace of the query and response messages received to the file <i>tapfile</i>.</p>
<dt><code>-G</code><i>&nbsp;<wbr>tapfile</i></p>
<dd> Generate message output from a previously saved dnstap file <i>tapfile</i>.</p>
<dt><code>+</code>[<code>no</code>]<code>multiline</code></p>
<dd> Wrap long records to more lines and improve human readability.</p>
<dt><code>+</code>[<code>no</code>]<code>short</code></p>
<dd> Show record data only.</p>
<dt><code>+</code>[<code>no</code>]<code>aaflag</code></p>
<dd> Set AA flag.</p>
<dt><code>+</code>[<code>no</code>]<code>tcflag</code></p>
<dd> Set TC flag.</p>
<dt><code>+</code>[<code>no</code>]<code>rdflag</code></p>
<dd> Set RD flag.</p>
<dt><code>+</code>[<code>no</code>]<code>recurse</code></p>
<dd> Same as <code>+</code>[<code>no</code>]<code>rdflag</code></p>
<dt><code>+</code>[<code>no</code>]<code>raflag</code></p>
<dd> Set RA flag.</p>
<dt><code>+</code>[<code>no</code>]<code>zflag</code></p>
<dd> Set zero flag bit.</p>
<dt><code>+</code>[<code>no</code>]<code>adflag</code></p>
<dd> Set AD flag.</p>
<dt><code>+</code>[<code>no</code>]<code>cdflag</code></p>
<dd> Set CD flag.</p>
<dt><code>+</code>[<code>no</code>]<code>dnssec</code></p>
<dd> Set DO flag.</p>
<dt><code>+</code>[<code>no</code>]<code>all</code></p>
<dd> Show all packet sections.</p>
<dt><code>+</code>[<code>no</code>]<code>qr</code></p>
<dd> Show query packet.</p>
<dt><code>+</code>[<code>no</code>]<code>header</code></p>
<dd> Show packet header.</p>
<dt><code>+</code>[<code>no</code>]<code>opt</code></p>
<dd> Show EDNS pseudosection.</p>
<dt><code>+</code>[<code>no</code>]<code>question</code></p>
<dd> Show question section.</p>
<dt><code>+</code>[<code>no</code>]<code>answer</code></p>
<dd> Show answer section.</p>
<dt><code>+</code>[<code>no</code>]<code>authority</code></p>
<dd> Show authority section.</p>
<dt><code>+</code>[<code>no</code>]<code>additional</code></p>
<dd> Show additional section.</p>
<dt><code>+</code>[<code>no</code>]<code>tsig</code></p>
<dd> Show TSIG pseudosection.</p>
<dt><code>+</code>[<code>no</code>]<code>stats</code></p>
<dd> Show trailing packet statistics.</p>
<dt><code>+</code>[<code>no</code>]<code>class</code></p>
<dd> Show DNS class.</p>
<dt><code>+</code>[<code>no</code>]<code>ttl</code></p>
<dd> Show TTL value.</p>
<dt><code>+</code>[<code>no</code>]<code>tcp</code></p>
<dd> Use TCP protocol (default is UDP for standard query and TCP for AXFR/IXFR).</p>
<dt><code>+</code>[<code>no</code>]<code>fail</code></p>
<dd> Stop querying next nameserver if SERVFAIL response is received.</p>
<dt><code>+</code>[<code>no</code>]<code>ignore</code></p>
<dd> Don&#8217;t use TCP automatically if truncated reply is received.</p>
<dt><code>+</code>[<code>no</code>]<code>nsid</code></p>
<dd> Request nameserver identifier (NSID).</p>
<dt><code>+</code>[<code>no</code>]<code>edns=</code>N</p>
<dd> Use EDNS version (default is 0).</p>
<dt><code>+noidn</code></p>
<dd> Disable IDN transformation to ASCII and vice versa. IDNA2003 support depends on libidn availability during project building!</p>
<dt><code>+generic</code></p>
<dd> Use the generic representation format when printing resource record types and data.</p>
<dt><code>+client=</code><i>SUBN</i></p>
<dd> Set EDNS client subnet SUBN=IP/prefix.</p>
<dt><code>+time=</code><i>T</i></p>
<dd> Set wait for reply interval in seconds (default is 5 seconds). This timeout applies to each query try.</p>
<dt><code>+retry=</code><i>N</i></p>
<dd> Set number (&gt;=0) of UDP retries (default is 2). This doesn&#8217;t apply to AXFR/IXFR.</p>
<dt><code>+bufsize=</code><i>B</i></p>
<dd> Set EDNS buffer size in bytes (default is 512 bytes).</dl>
<h2>NOTE</h2>
<p> Options <code>-k</code> and <code>-y</code> cannot be used mutually.</p>
<h3>Missing features with regard to ISC dig</h3>
<p> Options <code>-f</code> and <code>-m</code> and query options: <code>+split=</code><i>W</i>,&nbsp;<wbr><code>+tries=</code><i>T</i>,&nbsp;<wbr><code>+ndots=</code><i>D</i>, <code>+domain=</code><i>somename</i>,<code>+trusted-key=</code><i>####</i>, <code>+</code>[<code>no</code>]<code>vc</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>search</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>showsearch</code>, <code>+</code>[<code>no</code>]<code>defname</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>aaonly</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>cmd</code>, <code>+</code>[<code>no</code>]<code>identify</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>comments</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>rrcomments</code>, <code>+</code>[<code>no</code>]<code>onesoa</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>besteffort</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>sigchase</code>, <code>+</code>[<code>no</code>]<code>topdown</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>nssearch</code>,&nbsp;<wbr><code>+</code>[<code>no</code>]<code>trace.</code></p>
<dl>
<dt>Per-user file configuration via ${HOME}/.digrc.</p>
<dd></dl>
<h2>EXAMPLES</h2>
<p> <code>Example 1. Get A record for example.com:</code></p>
<dl>
<dt># kdig example.com A</p>
<dd>
<dt><code>Example 2. Perform AXFR for zone example.com from the server 192.0.2.1:</code></p>
<dd>
<dt># kdig example.com -t AXFR @192.0.2.1</p>
<dd>
<dt><code>Example 3. Get A record for example.com from 192.0.2.1 and reverse lookup for address 2001:DB8::1 from 192.0.2.2. Both using TCP protocol:</code></p>
<dd>
<dt># kdig +tcp example.com -t A @192.0.2.1 -x 2001:DB8::1 @192.0.2.2</p>
<dd></dl>
