<h2>NAME</h2>
<p> kasumi &#8211; a personal dictionary manager for Anthy</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>kasumi</code> [<i>options</i>] </p>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>kasumi</code> is a personal dictionary manager for Anthy. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code> <code>&#8211;help</code></p>
<dd>
<dd>Show summary of options </p>
<dt><code>-v</code> <code>&#8211;version</code></p>
<dd> Show Kasumi&#8217;s version and copyright information </p>
<dt><code>-m</code> <code>&#8211;manage</code></p>
<dd> Run Kasumi in Manage mode. You may abbreviate this option </p>
<dt><code>-a</code> <code>&#8211;add</code></p>
<dd> Run Kasumi in Add mode. </p>
<dt><code>-e</code> <code>&#8211;exclusive</code></p>
<dd> Run Kasumi in Exclusive mode. </p>
<dt><code>&#8211;sound val</code></p>
<dd> Set default sound entry (only in Add mode) </p>
<dt><code>&#8211;spelling val</code></p>
<dd> Set default spelling entry (only in Add mode) </p>
<dt><code>&#8211;wordclass val</code></p>
<dd> Set default word class entry (only in Add mode) </p>
<dt><code>-i</code> <code>&#8211;import</code></p>
<dd> Import selected text as a spelling </p>
<dt><code>-I</code> <code>&#8211;ignore</code></p>
<dd> Ignore selected text </p>
<dt><code>-E</code> <code>&#8211;eucjp</code></p>
<dd> Use EUC-JP encoding for dictionary </p>
</dl>
