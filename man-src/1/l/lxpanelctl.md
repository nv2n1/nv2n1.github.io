<p>lxpanelctl &#8211; controller for lxpanel.</p>
<h2>Synopsis</h2>
<dl>
<dt> <code>lxpanelctl</code> {command}</dl>
<h2>DESCRIPTION</h2>
<dd>This manual page documents briefly the <code>lxpanelctl</code> command. </p>
<p> <code>lxpanelctl</code> is a program that controls lxpanel.</p>
<h2>COMMANDS</h2>
<p> <code>menu</code></p>
<dl>
<dt>
<dd> show system menu</dl>
<p> <code>run</code></p>
<dl>
<dt>
<dd> show run dialog</dl>
<p> <code>restart</code></p>
<dl>
<dt>
<dd> restart lxpanel</dl>
<p> <code>exit</code></p>
<dl>
<dt>
<dd> exit lxpanel</dl>
