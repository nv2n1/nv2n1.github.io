<h2>NAME</h2>
<p> lda-schema-to-gconf &#8211; A script which converts keyfile-based schemas into GConf schemas for libdesktop-agnostic. </p>
<h2>SYNOPSIS</h2>
<p> <code>lda-schema-to-gconf</code> </p>
<h2>DESCRIPTION</h2>
<p> <code>lda-schema-to-gconf</code> is a script which converts keyfile-based schemas into GConf schemas. It is used for libraries and programs which use libdesktop-agnostic&#8217;s configuration library. </p>
