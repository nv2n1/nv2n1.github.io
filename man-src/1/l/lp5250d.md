<h2>NAME</h2>
<p> lp5250d &#8211; start an AS/400 printer session</p>
<h2>SYNOPSIS</h2>
<p> <code>lp5250d</code> [<i>OPTIONS</i>] <i>HOSTNAME</i></p>
<h2>DESCRIPTION</h2>
<p> <code>lp5250d</code> connects to an AS/400 over TCP/IP and provides a printer session emulating an IBM 3812 printer. The printer session works with <code>scs2ascii</code> and host print transform on the AS/400 to print AS/400 spooled files on a local printer. </p>
<p> To end a printer session, send it a <i>SIGTERM</i> signal with <code><a href="/docs/linux/man/1-kill/">kill</a></code>(1). </p>
<p> Printing support requires named session support, which is available for most recent versions of OS/400, but is only supplied with V4R3 and later versions. For V3R2, V3R7, V4R1 and V4R2, please see informational APAR II10918.</p>
<h2>OPTIONS</h2>
<p> Additional <code>lp5250d</code> options are described in the <code><a href="/docs/linux/man/5-tn5250rc/">tn5250rc</a></code>(5) man page.</p>
<dl>
<dt><code>-u</code>, <code>&#8211;user=</code><i>USER</i></p>
<dd> run lp5250d as <i>USER</p>
<dt></i><code>-H</code>, <code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> output version information and exit</dl>
<h2>EXAMPLES</h2>
<dl>
<dt><i>lp5250d env.DEVNAME=LINPRT1 env.IBMMFRTYPMDL=&#8217;*HP4&#8242; as400sys</i></p>
<dd> Connect to <i>as400sys</i> as the printer <i>LINPRT1</i>, using host print transform on the AS/400 to print to an HP Laserjet or compatible using lpr.</p>
<dt><i>lp5250d env.DEVNAME=LINPRT1 env.IBMMFRTYPMDL=&#8217;*OKI184IBM&#8217; outputcommand=&#8221;scs2ascii | lpr -Poki&#8217; as400sys</i></p>
<dd> Print to an Okidata Microline 184 Turbo on the local print queue named `<code>oki</code>&#8216;.</p>
<dt><i>lp5250d env.DEVNAME=PSPRT outputcommand=&#8217;scs2ps &gt; scs$$.ps&#8217; as400sys</i></p>
<dd> Convert spooled files into PostScript&#174; files.</dl>
