<h2 class="name">NAME</h2>
<p> lz &#8211; gunzips and shows a listing of a gzip&#8217;d tar&#8217;d archive </p>
<h2>SYNOPSIS</h2>
<p> <code>lz </code> <i>file</i></p>
<h2>DESCRIPTION</h2>
<p> <code>lz</code> provides a listing of a gzip&#8217;d tar&#8217;d archive, that is a <code><a href="/docs/linux/man/1-tar/">tar</a></code>(1) archive compressed with the <code><a href="/docs/linux/man/1-gzip/">gzip</a></code>(1) utility. It is not strictly necessary on Debian GNU/Linux, because the GNU <code><a href="/docs/linux/man/1-tar/">tar</a></code>(1) program provides the same capability with the command </p>
<p> <code>tar -tzf</code> <i>file</i> </p>
<p> but this utility is provided in the mtools package for other platforms and is retained here for completeness. </p>
