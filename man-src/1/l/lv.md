<h2>NAME</h2>
<p> lv &#8211; a Powerful Multilingual File Viewer / Grep</p>
<h2>SYNOPSIS</h2>
<p> <code>lv, lgrep</code><br />
 <code>lv</code> -h<br />
 <code>lv</code> -V<br />
 <code>lv</code> [-acdfgiklmnqsuvz] [+acdfgiklmnqsuvz] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[-A<i>coding-system</i>]&nbsp;<wbr>[-I<i>coding-system</i>]&nbsp;<wbr>[-K<i>coding-system</i>] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[-O<i>coding-system</i>]&nbsp;<wbr>[-P<i>coding-system</i>]&nbsp;<wbr>[-D<i>coding-system</i>] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[-Ss<i>seq</i>]&nbsp;<wbr>[-Sr<i>seq</i>]&nbsp;<wbr>[-Sb<i>seq</i>]&nbsp;<wbr>[-Su<i>seq</i>]&nbsp;<wbr>[-Sh<i>seq</i>] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[-T<i>number</i>]&nbsp;<wbr>[-W<i>width</i>]&nbsp;<wbr>[-H<i>height</i>]&nbsp;<wbr>[-E&#8217;<i>editor&#8217;</i>]&nbsp;<wbr>[-+] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[+<i>number</i>]&nbsp;<wbr>[+/<i>grep-pattern</i>] </p>
<p>&nbsp;<wbr>&nbsp;<wbr>[-]&nbsp;<wbr>(<i>grep-pattern</i>)&nbsp;<wbr>[<i>files &#8230;</i>]</p>
<h2>DESCRIPTION</h2>
<dl>
<dt><i>Multilingual file viewer</i></p>
<dd> <i>lv</i> is a powerful multilingual file viewer. Apparently, lv looks like <i>less</i> (1), a representative file viewer on UNIX as you know, so UNIX people (and <i>less</i> people on other OSs) don&#8217;t have to learn a burdensome new interface. lv can be used on MSDOS ANSI terminals and almost all UNIX platforms. lv is a currently growing software, so your feedback is welcome and helpful for us to refine the future lv.</p>
<dt><i>Multiple coding systems</i></p>
<dd> lv can decode and encode multilingual streams through many coding systems, for example, ISO 2022 based coding systems such as iso-2022-jp, and EUC (Extended Unix Code) like euc-japan. Furthermore, localized coding systems such as shift-jis, big5 and HZ are also supported. lv can be used not only as a file viewer but also as a coding-system translation filter like <i>nkf</i> (1) and <i>tcs</i> (1).</p>
<dt><i>Multilingual regular expressions / Multilingual grep</i></p>
<dd> lv can recognize multi-bytes patterns as regular expressions, and lv also provides multilingual <i>grep</i> (1) functionality by giving it another name, <i>lgrep</i>. Pattern matching is conducted in the charset level, so an EUC fragment, for example, can be found in the ISO 2022 tailored streams, of course.</p>
<dt><i>Supporting the Unicode standard</i></p>
<dd> lv provides Unicode facilities which enables you to handle Unicode streams encoded in UTF-7 or UTF-8, and lv can also convert their code-points between Unicode and other charsets. So you can display Unicode or foreign texts on your terminal, using the code conversion function to your favorite charsets via Unicode. (However, MSDOS version of lv has none of the Unicode facility.)</p>
<dt><i>ANSI escape sequence through</i></p>
<dd> lv can recognize ANSI escape sequences for text decoration. So you can look ANSI-decorated streams such as colored source codes generated by another software just like intended image on ANSI terminals.</p>
<dt><i>Completely original</i></p>
<dd> lv is a completely original software including no code drawn from <i>less</i> and <i>grep</i> and other programs at all.</dl>
<h2>OPTIONS</h2>
<dl>
<dt>-A&lt;<i>coding-system</i>&gt;</p>
<dd> Set all coding systems to <i>coding-system</i>.</p>
<dt>-I&lt;<i>coding-system</i>&gt;</p>
<dd> Set input coding system to <i>coding-system</i>.</p>
<dt>-K&lt;<i>coding-system</i>&gt;</p>
<dd> Set keyboard coding system to <i>coding-system</i>. If it is not set, output coding system will be applied to it.</p>
<dt>-O&lt;<i>coding-system</i>&gt;</p>
<dd> Set output coding system to <i>coding-system</i>.</p>
<dt>-P&lt;<i>coding-system</i>&gt;</p>
<dd> Set pathname coding system to <i>coding-system</i>.</p>
<dt>-D&lt;<i>coding-system</i>&gt;</p>
<dd> Set default (fall-back) coding system to <i>coding-system</i>.</p>
<dt>coding-system:</p>
<dd> a: auto-select<br />
 c: iso-2022-cn<br />
 j: iso-2022-jp<br />
 k: iso-2022-kr<br />
 ec: euc-china<br />
 ej: euc-japan<br />
 ek: euc-korea<br />
 et: euc-taiwan<br />
 u7: UTF-7<br />
 u8: UTF-8<br />
 l1..9: iso-8859-1..9<br />
 l0: iso-8859-10<br />
 lb,ld,le,lf,lg: iso-8859-11,13,14,15,16<br />
 s: shift-jis<br />
 b: big5<br />
 h: HZ<br />
 r: raw mode</p>
<dt>Examples:</p>
<dd> -Il2: input coding system is iso-8859-2<br />
 -Ks: keyboard coding system is shift-jis<br />
 -Oek: output coding system is euc-korea<br />
 -Ab: all coding systems are big5</p>
<dt>Coding-system translations / Code-points conversions:</p>
<dd> iso-2022-cn, -jp, -kr can be converted into euc-china or -taiwan, euc-japan, euc-korea, respectively (and vice versa). shift-jis uses the same internal code-points as iso-2022-jp and euc-japan. </p>
<p> Since big5 characters can be converted into CNS 11643-1992 with negligible incompleteness, big5 streams can be translated into iso-2022-cn or euc-taiwan (and vice versa) with code-points conversion. Note that the iso-2022-cn referred here is not GB sequence, only just CNS one. You should remember that lv cannot translate big5 into GB directly. </p>
<p> The search function of lv may not work correctly when lv additionally performs &#8220;code-points&#8221; conversion (not &#8220;coding-system&#8221; translation), because visible code and internal code are different from each other. lv will try to avoid this problem with converting charsets of search patterns automatically, but this function is not always perfect.</p>
<dt>-W&lt;<i>number</i>&gt;</p>
<dd> Screen width</p>
<dt>-H&lt;<i>number</i>&gt;</p>
<dd> Screen height</p>
<dt>-E'&lt;<i>editor</i>&gt;&#8217; (default &#8216;vi -c %d&#8217;)</p>
<dd> Editor name (default &#8216;vi -c %d&#8217;)<br />
 &#8220;%d&#8221; means the line number of current position in a file.</p>
<dt>-q</p>
<dd> Assert there is delete/insert-lines control.<br />
 Please set this option on a MSDOS ANSI terminal that has capability to delete and/or insert lines. As to termcap and terminfo version, it will be set automatically.</p>
<dt>-Ss&lt;<i>seq</i>&gt;</p>
<dd> Set ANSI Standout sequence to <i>seq</i> (default &quot;7&quot;)</p>
<dt>-Sr&lt;<i>seq</i>&gt;</p>
<dd> Set ANSI Reverse sequence to <i>seq</i> (default &quot;7&quot;)</p>
<dt>-Sb&lt;<i>seq</i>&gt;</p>
<dd> Set ANSI Blink sequence to <i>seq</i> (default &quot;5&quot;)</p>
<dt>-Su&lt;<i>seq</i>&gt;</p>
<dd> Set ANSI Underline sequence to <i>seq</i> (default &quot;4&quot;)</p>
<dt>-Sh&lt;<i>seq</i>&gt;</p>
<dd> Set ANSI Highlight sequence to <i>seq</i> (default &quot;1&quot;) </p>
<p> These sequences are inserted between &#8220;ESC [&#8221; and &#8220;m&#8221; to construct full ANSI escape sequences. </p>
<dt>-T&lt;<i>number</i>&gt;</p>
<dd> Set Threshold-code which divides Unicode code-points in two regions. Characters belonging to the lower region are assumed to have a width of one, and the higher characters are equated to a width of two. (Default: 12288, = 0x3000)</p>
<dt>-m</p>
<dd> Force Unicode code-points which have the same glyphs as iso-8859-* to be Mapped to iso-8859-* in a conversion from Unicode to another character set which also has the corresponding code-points, in particular, Asian charsets. </p>
<dt>-a</p>
<dd> Adjust character set for search pattern (default)</p>
<dt>-c</p>
<dd> Allow ANSI escape sequences for text decoration (Color)</p>
<dt>-d, -i</p>
<dd> Make regexp-searches ignore case (case folD search) (default)</p>
<dt>-f</p>
<dd> Substitute Fixed strings for regular expressions</p>
<dt>-k</p>
<dd> Convert X0201 Katakana to X0208 while decoding</p>
<dt>-l</p>
<dd> Allow physical lines of each logical line printed on the screen to be concatenated for cut and paste after screen refresh</p>
<dt>-s</p>
<dd> Force old pages to be swept out from the screen Smoothly</p>
<dt>-u</p>
<dd> Unify several character sets, eg. JIS X0208 and C6226. In addition, lv equates ISO 646 variants, eg. JIS X0201-Roman, and unknown charsets with ASCII.</p>
<dt>-g</p>
<dd> Turn on lgrep mode.</p>
<dt>-n</p>
<dd> Prefix each line of output with the line number within its input file on lgrep.</p>
<dt>-v</p>
<dd> Invert the sense of matching on lgrep.</p>
<dt>-z</p>
<dd> Enable HZ auto-detection (also enabled by run-time C-t). </p>
<dt>-+</p>
<dd> Clear all options<br />
 You can also turn OFF specified options, using &#8220;+&lt;option&gt;&#8221; like +c, +d, &#8230; +z.</p>
<dt>&#8211;</p>
<dd> Treat the following arguments as filenames</p>
<dt><i>grep-pattern</i></p>
<dd> lv works like <i>grep</i> (1) when its name is <i>lgrep</i></p>
<dt>+<i>number</i></p>
<dd> Jump to the specified line immediately when lv is invoked.</p>
<dt>+/<i>grep-pattern</i></p>
<dd> Search the specified pattern immediately when lv is invoked.</p>
<dt>-V</p>
<dd> Show lv version</p>
<dt>-h</p>
<dd> Show this help</dl>
<h2>CONFIGURATION</h2>
<p> Options can be described in configuration file &#8220;.lv&#8221; (&#8220;_lv&#8221; on MSDOS) located at you HOME directory. If and only if you use MSDOS, you can locate &#8220;_lv&#8221; at current working directory. They can be also described in the environment variable LV. Every configuration will be overloaded in this order if there is. Command line options are always read finally.</p>
<h2>COMMAND KEY BINDINGS</h2>
<dl>
<dt>0..9:</p>
<dd> Argument</p>
<dt>g, &lt;:</p>
<dd> Jump to the line number (default: top of the file)</p>
<dt>G, &gt;:</p>
<dd> Jump to the line number (default: bottom of the file)</p>
<dt>p:</p>
<dd> Jump to the percentage position in line numbers (0-100)</p>
<dt>b, C-b:</p>
<dd> Previous page</p>
<dt>u, C-u:</p>
<dd> Previous half page</p>
<dt>k, w, C-k, y, C-y, C-p:</p>
<dd> Previous line</p>
<dt>j, C-j, e, C-e, C-n, CR:</p>
<dd> Next line</p>
<dt>d, C-d:</p>
<dd> Next half page</p>
<dt>f, C-f, C-v, SP:</p>
<dd> Next page</p>
<dt>F:</p>
<dd> Jump to the end of file, and wait for a data to be appended to the file until interrupted.</p>
<dt>/&lt;string&gt;:</p>
<dd> Find a string in the forward direction (regular expression)</p>
<dt>?&lt;string&gt;:</p>
<dd> Find a string in the backward direction (regular expression)</p>
<dt>n:</p>
<dd> Repeat previous search in forward direction</p>
<dt>N:</p>
<dd> Repeat previous search in backward direction (not REVERSE)</p>
<dt>C-l:</p>
<dd> Redisplay all lines</p>
<dt>r, C-r:</p>
<dd> Refresh screen and memory</p>
<dt>R:</p>
<dd> Reload current file</p>
<dt>:n:</p>
<dd> Examine the next file</p>
<dt>:p:</p>
<dd> Examine the previous file</p>
<dt>t:</p>
<dd> Toggle input coding systems</p>
<dt>T:</p>
<dd> Toggle input coding systems reversely</p>
<dt>C-t:</p>
<dd> Toggle HZ decoding mode</p>
<dt>v:</p>
<dd> Launch the editor defined by option -E</p>
<dt>C-g, =:</p>
<dd> Show file information (filename, position, coding system)</p>
<dt>V:</p>
<dd> Show LV version</p>
<dt>C-z:</p>
<dd> Suspend (call SHELL or &#8220;command.com&#8221; under MSDOS)</p>
<dt>q, Q:</p>
<dd> Quit</p>
<dt>UP/DOWN:</p>
<dd> Previous/Next line</p>
<dt>LEFT/RIGHT:</p>
<dd> Previous/Next half page</p>
<dt>PageUp/PageDown:</p>
<dd> Previous/Next page</dl>
<h2>HOW TO INPUT SEARCH STRINGS?</h2>
<dl>
<dt>C-m, Enter:</p>
<dd> Enter the current string</p>
<dt>C-h, BS, DEL:</p>
<dd> Delete one character (backspace)</p>
<dt>C-u:</p>
<dd> Cancel the current string and try again</p>
<dt>C-p:</p>
<dd> Restore a few old strings incrementally (history)</p>
<dt>C-g:</p>
<dd> Quit</dl>
<h2>REGULAR EXPRESSION</h2>
<p> Special characters are ^, $, ., *, +, ?, [, ^, -, ], \. \| specifies an alternative. \(, \) is a grouping construct. \1 and \2 matches any charset consists of one- or two- column(s) characters respectively. Mutually overlapping ranges (or charset) are not guaranteed.</p>
