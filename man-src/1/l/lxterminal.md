<h2 class="name">NAME</h2>
<p> lxterminal &#8211; a lightweight terminal emulator based on GTK+ for the LXDE desktop. </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>lxterminal</code> [<code>options</code>&#8230;]</dl>
<h2>DESCRIPTION</h2>
<dd>This manual page documents briefly the <code>lxterminal</code> command. </p>
<p> <code>lxterminal</code> is a program that provides a terminal emulator for the desktop, usually for LXDE. It is a lightweight GTK+ 2.x based desktop panel.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below. </p>
<p> <code>-e </code><i>STRING</i> <code>&#8211;command=</code><i>STRING</i></p>
<dl>
<dt>
<dd> Execute the argument to this option inside the terminal.</dl>
<p> <code>-t </code><i>STRING</i> <code>&#8211;title=</code><i>STRING</i></p>
<dl>
<dt>
<dd> Set the terminal&#8217;s title.</dl>
<p> <code>&#8211;working-directory=</code><i>DIRECTORY</i></p>
<dl>
<dt>
<dd> Set the terminal&#8217;s working directory.</dl>
<p> <code>&#8211;geometry=</code><i>CHARACTERS</i><code>x</code><i>LINES</i></p>
<dl>
<dt>
<dd> Set the terminal&#8217;s size in characters and lines.</dl>
<p> <code>-l</code> <code>&#8211;loginshell</code></p>
<dl>
<dt>
<dd> Executes login shell.</dl>
