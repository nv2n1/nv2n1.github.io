<h2>NAME</h2>
<p> lxc-checkconfig &#8211; check the current kernel for lxc support</p>
<h2>SYNOPSIS</h2>
<p> <code>lxc-checkconfig</code></p>
<h2>DESCRIPTION</h2>
<p> <code>lxc-checkconfig</code> check the current kernel for lxc support</p>
<h2>EXAMPLES</h2>
<dl>
<dt>lxc-checkconfig</p>
<dd> check the current kernel. CONFIG can be set in the environment to an alternate location.</dl>
