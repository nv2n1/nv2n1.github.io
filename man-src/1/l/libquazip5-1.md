<h2 class="name">NAME</h2>
<p> quazip &#8211; C++/Qt wrapper for UNZIP/ZIP </p>
<h2>SYNOPSIS</h2>
<p> <code>quazip</code></p>
<h2>DESCRIPTION</h2>
<p> <code>QuaZIP</code> is a simple C++ wrapper over Gilles Vollant&#8217;s ZIP/UNZIP package that can be used to access ZIP archives. It uses Trolltech&#8217;s Qt toolkit. <code>QuaZIP</code> allows you to access files inside ZIP archives using QIODevice API, and that means that you can also use QTextStream, QDataStream or whatever you would like to use on your zipped files. <code>QuaZIP</code> provides complete abstraction of the ZIP/UNZIP API, for both reading from and writing to ZIP archives.</p>
