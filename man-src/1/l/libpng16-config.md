<p> libpng16-config &#8211; get information about installed libpng library </p>
<h2>SYNOPSIS</h2>
<p> <code>libpng16-config</code> [<i>OPTION</i>] &#8230;</p>
<h2>DESCRIPTION</h2>
<p> Provides information about libpng library. </p>
<p> Known values for OPTION are:</p>
<dl>
<dt><code>&#8211;prefix</code></dt>
<dd> print libpng prefix</dd>
<dt><code>&#8211;libdir</code></dt>
<dd> print path to directory containing library</dd>
<dt><code>&#8211;libs</code></dt>
<dd> print library linking information</dd>
<dt><code>&#8211;ccopts</code></dt>
<dd> print compiler options</dd>
<dt><code>&#8211;cppflags</code></dt>
<dd> print pre-processor flags</dd>
<dt><code>&#8211;cflags</code></dt>
<dd> print preprocessor flags, I_opts, and compiler options</dd>
<dt><code>&#8211;I_opts</code></dt>
<dd> print &quot;-I&quot; include options</dd>
<dt><code>&#8211;L_opts</code></dt>
<dd> print linker &quot;-L&quot; flags for dynamic linking</dd>
<dt><code>&#8211;R_opts</code></dt>
<dd> print dynamic linker &quot;-R&quot; or &quot;-rpath&quot; flags</dd>
<dt><code>&#8211;ldopts</code></dt>
<dd> print linker options</dd>
<dt><code>&#8211;ldflags</code></dt>
<dd> print linker flags (ldopts, L_opts, R_opts, and libs)</dd>
<dt><code>&#8211;static</code></dt>
<dd> revise subsequent outputs for static linking</dd>
<dt><code>&#8211;help</code></dt>
<dd> print this help and exit</dd>
<dt><code>&#8211;version</code></dt>
<dd> print version information</dd></dl>
