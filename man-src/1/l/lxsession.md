<h2>NAME</h2>
<p> lxsession &#8212; a lightweight X session manager</p>
<h2>SYNOPSIS</h2>
<p> <code>lxsession</code></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>lxsession</code> command. </p>
<p> <code>lxsession</code> is a program that provides a X11 session manager. It is the default X11 session manager of LXDE.<br />
&nbsp;<wbr> </p>
<p> A session manager is used to automatically start a set of applications and set up a working desktop environment. Moreover, when the user logout, it remembers the applications in use, and restart them the next time you login.<br />
&nbsp;<wbr></p>
