<h2 class="name">NAME</h2>
<p> libpng16-config &#8211; get information about installed libpng library </p>
<h2>SYNOPSIS</h2>
<p> <code>libpng16-config</code> [<i>OPTION</i>] &#8230;</p>
<h2>DESCRIPTION</h2>
<p> Provides information about libpng library. </p>
<p> Known values for OPTION are:</p>
<dl>
<dt><code>&#8211;prefix</code></p>
<dd> print libpng prefix</p>
<dt><code>&#8211;libdir</code></p>
<dd> print path to directory containing library</p>
<dt><code>&#8211;libs</code></p>
<dd> print library linking information</p>
<dt><code>&#8211;ccopts</code></p>
<dd> print compiler options</p>
<dt><code>&#8211;cppflags</code></p>
<dd> print pre-processor flags</p>
<dt><code>&#8211;cflags</code></p>
<dd> print preprocessor flags, I_opts, and compiler options</p>
<dt><code>&#8211;I_opts</code></p>
<dd> print &quot;-I&quot; include options</p>
<dt><code>&#8211;L_opts</code></p>
<dd> print linker &quot;-L&quot; flags for dynamic linking</p>
<dt><code>&#8211;R_opts</code></p>
<dd> print dynamic linker &quot;-R&quot; or &quot;-rpath&quot; flags</p>
<dt><code>&#8211;ldopts</code></p>
<dd> print linker options</p>
<dt><code>&#8211;ldflags</code></p>
<dd> print linker flags (ldopts, L_opts, R_opts, and libs)</p>
<dt><code>&#8211;static</code></p>
<dd> revise subsequent outputs for static linking</p>
<dt><code>&#8211;help</code></p>
<dd> print this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> print version information</dl>
