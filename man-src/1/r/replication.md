<p>Replication &#8211; Example of using QuantLib</p>
<h2>Synopsis</h2>
<p><code>Replication</code></p>
<h2>Description</h2>
<p><code>Replication</code> is an example of using the <i>QuantLib</i> derivative modeling framework. </p>
<p> <code>Replication</code> uses the CompositeInstrument class to statically replicate a down-and-out barrier options.</p>
