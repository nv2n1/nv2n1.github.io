<h2>NAME</h2>
<p> rosversion &#8211; rosverion command</p>
<h2>SYNOPSIS</h2>
<p> <code>rosversion</code> &lt;<i>stack</i>&gt; | <i>-d</i></p>
<h2>DESCRIPTION</h2>
<p> The <code>rosversion</code> command prints version information for ROS stacks and can also print the name of the active ROS distribution. </p>
<p> rosversion takes in a single ROS stack name as an argument, or a <code>-d</code> option with no arguments to print the distribution version instead. If the version number for a stack is not known, &quot;&lt;unversioned&gt;&quot; will be printed instead.</p>
<h2>OPTIONS</h2>
<p> <code>-d</code> Print codename for current ROS distribution.</p>
