<h2 class="name">NAME</h2>
<p> rundig &#8211; sample script to create a search database for ht://Dig </p>
<h2>SYNOPSIS</h2>
<p> <code>rundig</code> <i>[options]</i></p>
<h2>DESCRIPTION</h2>
<p> <i>rundig</i> is a sample script to create a search database for the ht://Dig search engine.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-v</code></p>
<dd> Verbose mode. This increases the verbosity of the program.</p>
<dt><code>-a</code></p>
<dd> Use alternate work files.</p>
<dt><code>-s</code></p>
<dd> Print statistics about the dig after completion</p>
<dt><code>-c configfile</code></p>
<dd> Use alternate config file.</p>
<dt><code>+i</code></p>
<dd> Use incremental digging instead non-incremental</dl>
