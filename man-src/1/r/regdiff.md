<h2 class="name">NAME</h2>
<p> regdiff &#8211; Diff program for Windows registry files </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>regdiff</code> [&#8211;help] [&#8211;backend=BACKEND] [&#8211;credentials=CREDENTIALS] [location]</dl>
<h2>DESCRIPTION</h2>
<dd>regdiff compares two Windows registry files key by key and value by value and generates a text file that contains the differences between the two files. </p>
<p> A file generated by regdiff can later be applied to a registry file by the regpatch utility. </p>
<p> regdiff and regpatch use the same file format as the regedit32.exe utility from Windows.</p>
<h2>OPTIONS</h2>
<p> &#8211;help</p>
<dl>
<dt>
<dd> Show list of available options.</dl>
<p> &#8211;backend BACKEND</p>
<dl>
<dt>
<dd> Name of backend to load. Possible values are: creg, regf, dir and rpc. The default is <i>dir</i>. </p>
<p> This argument can be specified twice: once for the first registry file and once for the second.</dl>
<p> &#8211;credentials=CREDENTIALS</p>
<dl>
<dt>
<dd> Credentials to use, if any. Password should be separated from user name by a percent sign. </p>
<p> This argument can be specified twice: once for the first registry file and once for the second.</dl>
<h2>VERSION</h2>
<p> This man page is correct for version 4.0 of the Samba suite.</p>
