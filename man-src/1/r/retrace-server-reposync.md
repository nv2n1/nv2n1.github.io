<h2 class="name">NAME</h2>
<p> retrace-server-reposync &#8211; Maintains local repository cache for Retrace server. </p>
<h2>SYNOPSIS</h2>
<p> <i>retrace-server-reposync</i> distribution version architecture</p>
<h2>DESCRIPTION</h2>
<p> The tool downloads new packages from public repositories to a local repository cache. A proper plugin for every distribution needs to be installed in plugins directory (by default <i>/usr/share/retrace-server/plugins</i>). Should be set up in root&#8217;s or retrace&#8217;s crontab to run every day.</p>
