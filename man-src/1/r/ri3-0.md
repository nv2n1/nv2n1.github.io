<p>UNIX</p>
<h2>Name</h2>
<p><code>ri</code> &#8211; Ruby API reference front end </p>
<h2>Synopsis</h2>
<p><code>ri</code> [-<code>ahilTv </code>[-<code>d </code><i>DIRNAME</i> ] ] [-<code>f </code><i>FORMAT</i> ] [-<code>w </code><i>WIDTH</i> ] [-<code>&#8211; </code>[<code>no- pager</code> ] ] [-<code>-server </code>[= <i>PORT </i>] ] [-<code>&#8211; </code>[<code>no- list-doc-dirs</code> ] ] [-<code>-no-standard-docs</code> ] [-<code>&#8211; </code>[<code>no- Bro system | site | gems | home Brc</code> ] ] [-<code>&#8211; </code>[<code>no- profile</code> ] ] [-<code>-dump = </code><i>CACHE</i> ] [<i>name &#8230;</i> ]</p>
<h2>Description</h2>
<p><code>ri</code> is a command-line front end for the Ruby API reference. You can search and read the API reference for classes and methods with <code>ri.</code> </p>
<p> <code>ri</code> is a part of Ruby. </p>
<p> <i>name</i> can be:</p>
<dl COMPACT>
<dt><code>Class | Module | Module::Class</code></dt>
<dd>
</dd><dt><code>Class::method | Class#method | Class.method | method</code></dt>
<dd>
</dd><dt><code>gem_name: | gem_name:README | gem_name:History</code></dt>
<dd></dd></dl>
<p> All class names may be abbreviated to their minimum unambiguous form. If a name is ambiguous, all valid options will be listed. </p>
<p> A `.&#8217; matches either class or instance methods, while #method matches only instance and ::method matches only class methods. </p>
<p> README and other files may be displayed by prefixing them with the gem name they&#8217;re contained in. If the gem name is followed by a `:&#8217; all files in the gem will be shown. The file name extension may be omitted where it is unambiguous. </p>
<p> For example: </p>
<blockquote>
<pre>ri Fil
ri File
ri File.new
ri zip
ri rdoc:README</pre>
</blockquote>
<p> Note that shell quoting or escaping may be required for method names containing punctuation: </p>
<blockquote>
<pre>ri 'Array.[]'
ri compact\!</pre>
</blockquote>
<p> To see the default directories <code>ri</code> will search, run: </p>
<blockquote>
<pre>ri --list-doc-dirs</pre>
</blockquote>
<p> Specifying the &#8211;<code>-system , &#8211;site , &#8211;home , &#8211;gems</code> or &#8211;<code>-doc-dir</code> options will limit <code>ri</code> to searching only the specified directories. </p>
<p> <code>ri</code> options may be set in the <code>RI</code> environment variable. </p>
<p> The <code>ri</code> pager can be set with the <code>RI_PAGER</code> environment variable or the <code>PAGER</code> environment variable. </p>
<h2>Options</h2>
<dl COMPACT>
<dt><code>-i</code></dt>
<dd>
</dd><dt><code>&#8212; </code>[<code>no- interactive</code> ]</dt>
<dd>In interactive mode you can repeatedly look up methods with autocomplete. </dd>
<dt><code>-a</code></dt>
<dd>
</dd><dt><code>&#8212; </code>[<code>no- all</code> ]</dt>
<dd>Show all documentation for a class or module. </dd>
<dt><code>-l</code></dt>
<dd>
</dd><dt><code>&#8212; </code>[<code>no- list</code> ]</dt>
<dd>List classes <code>ri</code> knows about. </dd>
<dt><code>&#8212; </code>[<code>no- pager</code> ]</dt>
<dd>Send output to a pager, rather than directly to stdout. </dd>
<dt><code>-T</code></dt>
<dd>Synonym for &#8211;<code>-no-pager</code> </dd>
<dt><code>-w </code><i>WIDTH</i></dt>
<dd>
</dd><dt><code>&#8211;width = </code><i>WIDTH</i></dt>
<dd>Set the width of the output. </dd>
<dt><code>&#8211;server </code>[= <i>PORT </i>]</dt>
<dd>Run RDoc server on the given port. The default port is~8214. </dd>
<dt><code>-f </code><i>FORMAT</i></dt>
<dd>
</dd><dt><code>&#8211;format = </code><i>FORMAT</i></dt>
<dd>Use the selected formatter. The default formatter is <code>bs</code> for paged output and <code>ansi</code> otherwise. Valid formatters are: <code>ansi , bs , markdown , rdoc</code> </dd>
<dt><code>-h</code></dt>
<dd>
</dd><dt><code>&#8211;help</code></dt>
<dd>Show help and exit. </dd>
<dt><code>-v</code></dt>
<dd>
</dd><dt><code>&#8211;version</code></dt>
<dd>Output version information and exit.</dd></dl>
<p> Data source options:</p>
<dl COMPACT>
<dt><code>&#8212; </code>[<code>no- list-doc-dirs</code> ]</dt>
<dd>List the directories from which <code>ri</code> will source documentation on stdout and exit. </dd>
<dt><code>-d </code><i>DIRNAME</i></dt>
<dd>
</dd><dt><code>&#8211;doc-dir = </code><i>DIRNAME</i></dt>
<dd>List of directories from which to source documentation in addition to the standard directories. May be repeated. </dd>
<dt><code>&#8211;no-standard-docs</code></dt>
<dd>Do not include documentation from the Ruby standard library, site_lib installed gems, or ~/.rdoc Use with &#8211;<code>-doc-dir</code> </dd>
<dt><code>&#8212; </code>[<code>no- system</code> ]</dt>
<dd>Include documentation from Ruby&#8217;s standard library. Defaults to true. </dd>
<dt><code>&#8212; </code>[<code>no- site</code> ]</dt>
<dd>Include documentation from libraries installed in site_lib Defaults to true. </dd>
<dt><code>&#8212; </code>[<code>no- gems</code> ]</dt>
<dd>Include documentation from RubyGems. Defaults to true. </dd>
<dt><code>&#8212; </code>[<code>no- home</code> ]</dt>
<dd>Include documentation stored in ~/.rdoc Defaults to true.</dd></dl>
<p> Debug options:</p>
<dl COMPACT>
<dt><code>&#8212; </code>[<code>no- profile</code> ]</dt>
<dd>Run with the Ruby profiler. </dd>
<dt><code>&#8211;dump = </code><i>CACHE</i></dt>
<dd>Dump data from an ri cache or data file.</dd></dl>
<h2>Environment</h2>
<dl COMPACT>
<dt><code>RI</code></dt>
<dd>Options to prepend to those specified on the command-line. </dd>
<dt><code>RI_PAGER</code></dt>
<dd>
</dd><dt><code>PAGER</code></dt>
<dd>Pager program to use for displaying. </dd>
<dt><code>HOME</code></dt>
<dd>
</dd><dt><code>USERPROFILE</code></dt>
<dd>
</dd><dt><code>HOMEPATH</code></dt>
<dd>Path to the user&#8217;s home directory.</dd></dl>
<h2>Files</h2>
<dl COMPACT>
<dt><code>~/.rdoc </code></dt>
<dd>Path for ri data in the user&#8217;s home directory. </dd>
</dl>
