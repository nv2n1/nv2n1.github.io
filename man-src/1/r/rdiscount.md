<h2>NAME</h2>
<p> <code>rdiscount</code> &#8212; humane markup to HTML conversion tool</p>
<h2>SYNOPSIS</h2>
<p> <code>rdiscount</code> [<i>file</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> The <code>rdiscount</code> utility reads one or more <a href="/docs/linux/man/7-markdown/">markdown</a>(7)-formatted text <i>file</i>s and writes HTML to standard output. With no <i>file</i>, or when <i>file</i> is &#8216;-&#8216;, <code>rdiscount</code> reads source text from standard input.</p>
<h2>RETURN VALUES</h2>
<p> The <code>rdiscount</code> utility exits 0 on success, and &gt; 0 if an error occurs.</p>
