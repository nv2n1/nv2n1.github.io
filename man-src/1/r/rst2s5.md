<h2 class="name">NAME</h2>
<p> rst2s5 &#8211; convert reST documents to S5 slides </p>
<h2>SYNOPSIS</h2>
<p> rst2s5 [options] [&lt;source&gt; [&lt;destination&gt;]]</p>
<h2>DESCRIPTION</h2>
<p> Generates S5 (X)HTML slideshow documents from standalone reStructuredText sources. Reads from &lt;source&gt; (default is stdin) and writes to &lt;destination&gt; (default is stdout). See &lt;<i><a rel="nofollow" href="http://docutils.sf.net/docs/user/config.html">http://docutils.sf.net/docs/user/config.html</a></i>&gt; for the full reference.</p>

<h3>S5 Slideshow Specific Options</h3>
<p> For the S5/HTML writer, the &#8211;no-toc-backlinks option (defined in General Docutils Options above) is the default, and should not be changed.</p>
<dl>
<dt><code>&#8211;theme=</code><i>&lt;name&gt;</i></p>
<dd> Specify an installed S5 theme by name. Overrides &#8211;theme-url. The default theme name is &quot;default&quot;. The theme files will be copied into a &quot;ui/&lt;theme&gt;&quot; directory, in the same directory as the destination file (output HTML). Note that existing theme files will not be overwritten (unless &#8211;overwrite-theme- files is used).</p>
<dt><code>&#8211;theme-url=</code><i>&lt;URL&gt;</i></p>
<dd> Specify an S5 theme URL. The destination file (output HTML) will link to this theme; nothing will be copied. Overrides &#8211;theme.</p>
<dt><code>&#8211;overwrite-theme-files</code></p>
<dd> Allow existing theme files in the <code>ui/&lt;theme&gt;</code> directory to be overwritten. The default is not to overwrite theme files.</p>
<dt><code>&#8211;keep-theme-files</code></p>
<dd> Keep existing theme files in the <code>ui/&lt;theme&gt;</code> directory; do not overwrite any. This is the default.</p>
<dt><code>&#8211;view-mode=</code><i>&lt;mode&gt;</i></p>
<dd> Set the initial view mode to &quot;slideshow&quot; [default] or &quot;outline&quot;.</p>
<dt><code>&#8211;hidden-controls</code></p>
<dd> Normally hide the presentation controls in slideshow mode. This is the default.</p>
<dt><code>&#8211;visible-controls</code></p>
<dd> Always show the presentation controls in slideshow mode. The default is to hide the controls.</p>
<dt><code>&#8211;current-slide</code></p>
<dd> Enable the current slide indicator (&quot;1 / 15&quot;). The default is to disable it.</p>
<dt><code>&#8211;no-current-slide</code></p>
<dd> Disable the current slide indicator. This is the default. </p>
</dl>
