<h2>NAME</h2>
<p> rasview &#8211; Raster file previewer for the X Window System.</p>
<h2>SYNOPSIS</h2>
<p> <code>rasview</code> [ <code>-toolkitoption</code><i> &#8230;</i> ] [ <code>-ifmt</code><i> format</i> ] [ <code>-movie</code> ] [ <code>-pal</code><i> palette_file</i> ] [ <code>-quiet</code> ] [ <code>-Version</code> ] [ <i>file.ext</i> | <code>&#8211;</code> ] </p>
<h2>DESCRIPTION</h2>
<p> <code>rasview</code> displays raster imagery from a file into an X window. By default rasview determines the format of an image file by looking at its file name extension. For example, an xwd (X11 Window Dump) file might be named <code>foo.xwd</code>. </p>
<p> Raster image file formats come in a variety of flavors. <code>rasview</code> attempts to support 8-bit-indexed, and 24-bit-direct encodings of the image formats listed below. Similarly, only output devices with 8-bit or 24-bit depth are supported. <code>rasview </code> attempts to select an X11 Visual which best matches the encoding of the image file. A PseudoColor visual class is preferred for 8-bit-indexed imagery, while a DirectColor visual class is preferred for 24-bit-direct encoded imagery. In the case of 24-bit-direct encodings, if the output device only has 8-bit color the imagery is color-quantized down to 8 bits. </p>
<p> In general raster files contain only a single image. <code>rasview </code> is able to display multiple-image raster files if they were created by the concatenation of single-image files with the <code>rascat(1NCARG)</code> utility or if they were generated by <code>ctrans(1NCARG)</code>. Multi-frame image files generated by other means are not guaranteed to be displayable by <code>rasview</code>. </p>
<p> See <code>ras_formats(5NCARG)</code> for a list of supported image formats.</p>
<h2>OPTIONS</h2>
<p> <code>rasview</code> accepts all of the standard X Toolkit command line options (see <a href="/docs/linux/man/7-x11/">X11</a>(7)). <code>rasview</code> also accepts the following options:</p>
<dl>
<dt><code>-ifmt</code><i> format</i></p>
<dd> Specify the input file format. <i>format</i> is one of the aforementioned file name extensions (without the &quot;.&quot;, e.g. <code>xwd).</code> When this option is specified file name extensions are not necessary and are ignored if present. All input files must have the same format.</p>
<dt><code>-movie</code></p>
<dd> Normally when processing multi-image raster files, <code>rasview </code> waits for a mouse click before proceeding to the next frame. When this option is used <code>rasview</code> immediately advances the frame after <code>rasview</code> has completed drawing it.</p>
<dt><code>-pal</code><i> palette_file</i></p>
<dd> Use the color palette contained in the file <i>palette_file</i>. for displaying images. This palette will override the color palette stored with the image.</p>
<dt>
<dd> See <code>ras_palette(5NCARG)</code> for a description of palette file forats.</p>
<dt><code>-quiet</code></p>
<dd> Operate in quiet mode.</p>
<dt><code>-Version</code></p>
<dd> Print the version number and then exit.</p>
<dt><code>&#8211;</code></p>
<dd> Read rasterfile from standard input (-ifmt option required).</dl>
