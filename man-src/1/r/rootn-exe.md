<p>rootn.exe &#8211; ROOT interpretor memory managed backend </p>
<h2>Description</h2>
<p>This executable is linked with <code>libNew</code>, unlike <i>root.exe</i>, which makes it appropriate for if one wants to use memory mapped file, <code>TMapFile</code>, and so on. In all other aspects, it&#8217;s the same as the <i><a href="/docs/linux/man/1-root/">root</a></i>(1) executable.</p>
