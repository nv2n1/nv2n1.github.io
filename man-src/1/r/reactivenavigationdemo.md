<p>ReactiveNavigationDemo &#8211; GUI demo of robot reactive navigation </p>
<h2>Synopsis</h2>
<p>ReactiveNavigationDemo</p>
<h2>Description</h2>
<p>A program to demonstrate the usage of the mrpt reactivenav library. It allow the user to set an arbitrary target and then simulate the robot actions to try to reach the target. </p>
<p> The movements take into account the arbitrary shape of the robot, and a set of kinematically-constrained trajectories.</p>
