<h2 class="name">NAME</h2>
<p> rst2man &#8211; generate unix manpages from reStructured text </p>
<h2>SYNOPSIS</h2>
<p> rst2man [options] [&lt;source&gt; [&lt;destination&gt;]]</p>
<h2>DESCRIPTION</h2>
<p> Generates plain unix manual documents. Reads from &lt;source&gt; (default is stdin) and writes to &lt;destination&gt; (default is stdout). See &lt;<i><a rel="nofollow" href="http://docutils.sf.net/docs/user/config.html">http://docutils.sf.net/docs/user/config.html</a></i>&gt; for the full reference.</p>
<h2>OPTIONS</h2>
<h3>General Docutils Options</h3>
<dl>
<dt><code>&#8211;title=</code><i>TITLE</i></p>
<dd> Specify the document title as metadata.</p>
<dt><code>&#8211;generator</code>,<code> -g</code></p>
<dd> Include a &quot;Generated by Docutils&quot; credit and link.</p>
<dt><code>&#8211;no-generator</code></p>
<dd> Do not include a generator credit.</p>
<dt><code>&#8211;date</code>,<code> -d</code></p>
<dd> Include the date at the end of the document (UTC).</p>
<dt><code>&#8211;time</code>,<code> -t</code></p>
<dd> Include the time &amp; date (UTC).</p>
<dt><code>&#8211;no-datestamp</code></p>
<dd> Do not include a datestamp of any kind.</p>
<dt><code>&#8211;source-link</code>,<code> -s</code></p>
<dd> Include a &quot;View document source&quot; link.</p>
<dt><code>&#8211;source-url=</code><i>&lt;URL&gt;</i></p>
<dd> Use &lt;URL&gt; for a source link; implies &#8211;source-link.</p>
<dt><code>&#8211;no-source-link</code></p>
<dd> Do not include a &quot;View document source&quot; link.</p>
<dt><code>&#8211;toc-entry-backlinks</code></p>
<dd> Link from section headers to TOC entries. (default)</p>
<dt><code>&#8211;toc-top-backlinks</code></p>
<dd> Link from section headers to the top of the TOC.</p>
<dt><code>&#8211;no-toc-backlinks</code></p>
<dd> Disable backlinks to the table of contents.</p>
<dt><code>&#8211;footnote-backlinks</code></p>
<dd> Link from footnotes/citations to references. (default)</p>
<dt><code>&#8211;no-footnote-backlinks</code></p>
<dd> Disable backlinks from footnotes and citations.</p>
<dt><code>&#8211;section-numbering</code></p>
<dd> Enable section numbering by Docutils. (default)</p>
<dt><code>&#8211;no-section-numbering</code></p>
<dd> Disable section numbering by Docutils.</p>
<dt><code>&#8211;strip-comments</code></p>
<dd> Remove comment elements from the document tree.</p>
<dt><code>&#8211;leave-comments</code></p>
<dd> Leave comment elements in the document tree. (default)</p>
<dt><code>&#8211;strip-elements-with-class=</code><i>&lt;class&gt;</i></p>
<dd> Remove all elements with classes=&quot;&lt;class&gt;&quot; from the document tree. Warning: potentially dangerous; use with caution. (Multiple-use option.)</p>
<dt><code>&#8211;strip-class=</code><i>&lt;class&gt;</i></p>
<dd> Remove all classes=&quot;&lt;class&gt;&quot; attributes from elements in the document tree. Warning: potentially dangerous; use with caution. (Multiple-use option.)</p>
<dt><code>&#8211;report=</code><i>&lt;level&gt;</i>,<code>&nbsp;-r</code><i>&nbsp;&lt;level&gt;</i></p>
<dd> Report system messages at or higher than &lt;level&gt;: &quot;info&quot; or &quot;1&quot;, &quot;warning&quot;/&quot;2&quot; (default), &quot;error&quot;/&quot;3&quot;, &quot;severe&quot;/&quot;4&quot;, &quot;none&quot;/&quot;5&quot;</p>
<dt><code>&#8211;verbose</code>,<code> -v</code></p>
<dd> Report all system messages. (Same as &quot;&#8211;report=1&quot;.)</p>
<dt><code>&#8211;quiet</code>,<code> -q</code></p>
<dd> Report no system messages. (Same as &quot;&#8211;report=5&quot;.)</p>
<dt><code>&#8211;halt=</code><i>&lt;level&gt;</i></p>
<dd> Halt execution at system messages at or above &lt;level&gt;. Levels as in &#8211;report. Default: 4 (severe).</p>
<dt><code>&#8211;strict</code></p>
<dd> Halt at the slightest problem. Same as &quot;&#8211;halt=info&quot;.</p>
<dt><code>&#8211;exit-status=</code><i>&lt;level&gt;</i></p>
<dd> Enable a non-zero exit status for non-halting system messages at or above &lt;level&gt;. Default: 5 (disabled).</p>
<dt><code>&#8211;debug</code></p>
<dd> Enable debug-level system messages and diagnostics.</p>
<dt><code>&#8211;no-debug</code></p>
<dd> Disable debug output. (default)</p>
<dt><code>&#8211;warnings=</code><i>&lt;file&gt;</i></p>
<dd> Send the output of system messages to &lt;file&gt;.</p>
<dt><code>&#8211;traceback</code></p>
<dd> Enable Python tracebacks when Docutils is halted.</p>
<dt><code>&#8211;no-traceback</code></p>
<dd> Disable Python tracebacks. (default)</p>
<dt><code>&#8211;input-encoding=</code><i>&lt;name[:handler]&gt;</i>,<code>&nbsp;-i</code><i>&nbsp;&lt;name[:handler]&gt;</i></p>
<dd> Specify the encoding and optionally the error handler of input text. Default: &lt;locale-dependent&gt;:strict.</p>
<dt><code>&#8211;input-encoding-error-handler=</code><i>INPUT_ENCODING_ERROR_HANDLER</i></p>
<dd> Specify the error handler for undecodable characters. Choices: &quot;strict&quot; (default), &quot;ignore&quot;, and &quot;replace&quot;.</p>
<dt><code>&#8211;output-encoding=</code><i>&lt;name[:handler]&gt;</i>,<code>&nbsp;-o</code><i>&nbsp;&lt;name[:handler]&gt;</i></p>
<dd> Specify the text encoding and optionally the error handler for output. Default: UTF-8:strict.</p>
<dt><code>&#8211;output-encoding-error-handler=</code><i>OUTPUT_ENCODING_ERROR_HANDLER</i></p>
<dd> Specify error handler for unencodable output characters; &quot;strict&quot; (default), &quot;ignore&quot;, &quot;replace&quot;, &quot;xmlcharrefreplace&quot;, &quot;backslashreplace&quot;.</p>
<dt><code>&#8211;error-encoding=</code><i>&lt;name[:handler]&gt;</i>,<code>&nbsp;-e</code><i>&nbsp;&lt;name[:handler]&gt;</i></p>
<dd> Specify text encoding and error handler for error output. Default text encoding: system encoding. Default error handler: backslashreplace.</p>
<dt><code>&#8211;error-encoding-error-handler=</code><i>ERROR_ENCODING_ERROR_HANDLER</i></p>
<dd> Specify the error handler for unencodable characters in error output. Default: backslashreplace.</p>
<dt><code>&#8211;language=</code><i>&lt;name&gt;</i>,<code>&nbsp;-l</code><i>&nbsp;&lt;name&gt;</i></p>
<dd> Specify the language (as BCP 47 language tag). Default: en.</p>
<dt><code>&#8211;record-dependencies=</code><i>&lt;file&gt;</i></p>
<dd> Write output file dependencies to &lt;file&gt;.</p>
<dt><code>&#8211;config=</code><i>&lt;file&gt;</i></p>
<dd> Read configuration settings from &lt;file&gt;, if it exists.</p>
<dt><code>&#8211;version</code>,<code> -V</code></p>
<dd> Show this program&#8217;s version number and exit.</p>
<dt><code>&#8211;help</code>,<code> -h</code></p>
<dd> Show this help message and exit.</dl>
<h3>reStructuredText Parser Options</h3>
<dl>
<dt><code>&#8211;pep-references</code></p>
<dd> Recognize and link to standalone PEP references (like &quot;PEP 258&quot;).</p>
<dt><code>&#8211;pep-base-url=</code><i>&lt;URL&gt;</i></p>
<dd> Base URL for PEP references (default &quot;<i><a rel="nofollow" href="http://www.python.org/dev/peps/">http://www.python.org/dev/peps/</a></i>&quot;).</p>
<dt><code>&#8211;pep-file-url-template=</code><i>&lt;URL&gt;</i></p>
<dd> Template for PEP file part of URL. (default &quot;pep-%04d&quot;)</p>
<dt><code>&#8211;rfc-references</code></p>
<dd> Recognize and link to standalone RFC references (like &quot;RFC 822&quot;).</p>
<dt><code>&#8211;rfc-base-url=</code><i>&lt;URL&gt;</i></p>
<dd> Base URL for RFC references (default &quot;<i><a rel="nofollow" href="http://tools.ietf.org/html/">http://tools.ietf.org/html/</a></i>&quot;).</p>
<dt><code>&#8211;tab-width=</code><i>&lt;width&gt;</i></p>
<dd> Set number of spaces for tab expansion (default 8).</p>
<dt><code>&#8211;trim-footnote-reference-space</code></p>
<dd> Remove spaces before footnote references.</p>
<dt><code>&#8211;leave-footnote-reference-space</code></p>
<dd> Leave spaces before footnote references.</p>
<dt><code>&#8211;no-file-insertion</code></p>
<dd> Disable directives that insert the contents of external file (&quot;include&quot; &amp; &quot;raw&quot;); replaced with a &quot;warning&quot; system message.</p>
<dt><code>&#8211;file-insertion-enabled</code></p>
<dd> Enable directives that insert the contents of external file (&quot;include&quot; &amp; &quot;raw&quot;). Enabled by default.</p>
<dt><code>&#8211;no-raw</code></p>
<dd> Disable the &quot;raw&quot; directives; replaced with a &quot;warning&quot; system message.</p>
<dt><code>&#8211;raw-enabled</code></p>
<dd> Enable the &quot;raw&quot; directive. Enabled by default.</p>
<dt><code>&#8211;syntax-highlight=</code><i>&lt;format&gt;</i></p>
<dd> Token name set for parsing code with Pygments: one of &quot;long&quot;, &quot;short&quot;, or &quot;none (no parsing)&quot;. Default is &quot;long&quot;.</p>
<dt><code>&#8211;smart-quotes=</code><i>&lt;yes/no/alt&gt;</i></p>
<dd> Change straight quotation marks to typographic form: one of &quot;yes&quot;, &quot;no&quot;, &quot;alt[ernative]&quot; (default &quot;no&quot;).</p>
<dt><code>&#8211;smartquotes-locales=</code><i>&lt;language:quotes[,language:quotes,&#8230;]&gt;</i></p>
<dd> Characters to use as &quot;smart quotes&quot; for &lt;language&gt;.</p>
<dt><code>&#8211;word-level-inline-markup</code></p>
<dd> Inline markup recognized at word boundaries only (adjacent to punctuation or whitespace). Force character-level inline markup recognition with &quot;&quot; (backslash + space). Default.</p>
<dt><code>&#8211;character-level-inline-markup</code></p>
<dd> Inline markup recognized anywhere, regardless of surrounding characters. Backslash-escapes must be used to avoid unwanted markup recognition. Useful for East Asian languages. Experimental.</dl>
<h3>Standalone Reader</h3>
<dl>
<dt><code>&#8211;no-doc-title</code></p>
<dd> Disable the promotion of a lone top-level section title to document title (and subsequent section title to document subtitle promotion; enabled by default).</p>
<dt><code>&#8211;no-doc-info</code></p>
<dd> Disable the bibliographic field list transform (enabled by default).</p>
<dt><code>&#8211;section-subtitles</code></p>
<dd> Activate the promotion of lone subsection titles to section subtitles (disabled by default).</p>
<dt><code>&#8211;no-section-subtitles</code></p>
<dd> Deactivate the promotion of lone subsection titles. </p>
</dl>
