<h2>NAME</h2>
<p> <code>randombytes</code> &#8212; write random bytes generated via libnacl to stdout</p>
<h2>SYNOPSIS</h2>
<p> <code>randombytes</code></p>
<h2>DESCRIPTION</h2>
<p> Writes random bytes to stdout forever using the cryptographically secure random generator in libnacl. In practice, the output is piped to a program like <a href="/docs/linux/man/1-dd/">dd</a>(1) or <a href="/docs/linux/man/1-base64/">base64</a>(1).</p>
<h2>SEE ALSO</h2>
<p> <a href="/docs/linux/man/1-makekeys/">makekeys</a>(1) <a href="/docs/linux/man/1-randombytes/">randombytes</a>(1) &#8212; write secure random bytes to stdout =============================================</p>
<h2>SYNOPSIS</h2>
<p> <code>randombytes</code></p>
<h2>DESCRIPTION</h2>
<p> Writes random bytes to stdout forever using the cjdns secure random generator. In practice, the output is piped to a program like <a href="/docs/linux/man/1-dd/">dd</a>(1) or <a href="/docs/linux/man/1-base64/">base64</a>(1).</p>
