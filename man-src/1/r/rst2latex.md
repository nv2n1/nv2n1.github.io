<h2 class="name">NAME</h2>
<p> rst2latex &#8211; convert reST documents to LaTeX </p>
<h2>SYNOPSIS</h2>
<p> rst2latex [options] [&lt;source&gt; [&lt;destination&gt;]]</p>
<h2>DESCRIPTION</h2>
<p> Generates LaTeX documents from standalone reStructuredText sources. Reads from &lt;source&gt; (default is stdin) and writes to &lt;destination&gt; (default is stdout). See &lt;<i><a rel="nofollow" href="http://docutils.sourceforge.net/docs/user/latex.html">http://docutils.sourceforge.net/docs/user/latex.html</a></i>&gt; for the full reference.</p>

<h3>reStructuredText Parser Options</h3>

<dt><code>&#8211;pep-base-url=</code><i>&lt;URL&gt;</i></p>

<dd> Template for PEP file part of URL. (default &quot;pep-%04d&quot;)</p>

<dd> Recognize and link to standalone RFC references (like &quot;RFC 822&quot;).</p>

<dd> Base URL for RFC references (default &quot;<i><a rel="nofollow" href="http://tools.ietf.org/html/">http://tools.ietf.org/html/</a></i>&quot;).</p>
<dt><code>&#8211;tab-width=</code><i>&lt;width&gt;</i></p>
<dd> Set number of spaces for tab expansion (default 8).</p>

<dd> Remove spaces before footnote references.</p>
<dt><code>&#8211;leave-footnote-reference-space</code></p>
<dd> Leave spaces before footnote references.</p>
<dt><code>&#8211;no-file-insertion</code></p>
<dd> Disable directives that insert the contents of external file (&quot;include&quot; &amp; &quot;raw&quot;); replaced with a &quot;warning&quot; system message.</p>

<dd> Enable directives that insert the contents of external file (&quot;include&quot; &amp; &quot;raw&quot;). Enabled by default.</p>

<dd> Disable the &quot;raw&quot; directives; replaced with a &quot;warning&quot; system message.</p>
<dt><code>&#8211;raw-enabled</code></p>
<dd> Enable the &quot;raw&quot; directive. Enabled by default.</p>
<dt><code>&#8211;syntax-highlight=</code><i>&lt;format&gt;</i></p>
<dd> Token name set for parsing code with Pygments: one of &quot;long&quot;, &quot;short&quot;, or &quot;none (no parsing)&quot;. Default is &quot;long&quot;.</p>

<dd> Characters to use as &quot;smart quotes&quot; for &lt;language&gt;.</p>
<dt><code>&#8211;word-level-inline-markup</code></p>
<dd> Inline markup recognized at word boundaries only (adjacent to punctuation or whitespace). Force character-level inline markup recognition with &quot;&quot; (backslash + space). Default.</p>
<dt><code>&#8211;character-level-inline-markup</code></p>
<dd> Inline markup recognized anywhere, regardless of surrounding characters. Backslash-escapes must be used to avoid unwanted markup recognition. Useful for East Asian languages. Experimental.</dl>
