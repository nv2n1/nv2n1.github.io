<h2>NAME</h2>
<p> <i></i><code>r3.univar</code> &#8211; Calculates univariate statistics from the non-null 3d cells of a raster3d map.</p>
<h2>KEYWORDS</h2>
<p> raster3d, statistics</p>
<h2>SYNOPSIS</h2>
<p> <code>r3.univar</code><br />
 <code>r3.univar help</code><br />
 <code>r3.univar</code> [-<code>ge</code>] <code>input</code>=<i>name</i> [<code>percentile</code>=<i>integer</i>] [&#8211;<code>verbose</code>] [&#8211;<code>quiet</code>]</p>
<h3>Flags:</h3>
<dl>
<dt><code>-g</code></p>
<dd>
 Print the stats in shell script style</p>
<dt><code>-e</code></p>
<dd>
 Calculate extended statistics</p>
<dt><code>&#8211;verbose</code></p>
<dd>
 Verbose module output</p>
<dt><code>&#8211;quiet</code></p>
<dd>
 Quiet module output</dl>
<h3>Parameters:</h3>
<dl>
<dt><code>input</code>=<i>name</i></p>
<dd>
 Name of input raster3d map</p>
<dt><code>percentile</code>=<i>integer</i></p>
<dd>
 Percentile to calculate (requires extended statistics flag)<br />
 Options: <i>0-100</i><br />
 Default: <i>90</i></dl>
<h2>DESCRIPTION</h2>
<p> <i>r3.univar</i> calculates the univariate statistics for raster3d maps. This includes the number of cells counted, minimum and maximum cell values, range, arithmetic mean, population variance, standard deviation, and coefficient of variation. If the <code>-e</code> extended statistics flag is given the 1st quartile, median, 3rd quartile, and given <code>percentile</code> are calculated. If the <code>-g</code> flag is given the results are presented in a format suitable for use in a shell script.</p>
<h2>NOTES</h2>
<p> As with most GRASS raster3d modules, <i>r3.univar</i> operates on the cell array defined by the current 3d region settings, not the original extent and resolution of the input map. See <i>g.region</i>. </p>
<p> This module can use large amounts of system memory when the <code>-e</code> extended statistics flag is used with a very large region setting. If the region is too large the module should exit gracefully with a memory allocation error. Basic statistics can be calculated using any size input region.</p>
