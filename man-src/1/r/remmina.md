<h2 class="name">NAME</h2>
<p> <code>remmina</code> &#8211; Remmina the GTK+ Remote Desktop Client </p>
<h2>SYNOPSIS</h2>
<p> <code>remmina</code> [-<code>a|i|n|q|v</code> ] [-<code>c </code><i>FILE</i> ] [-<code>e </code><i>FILE</i> ] [-<code>p </code><i>TABINDEX</i> ] [-<code>s </code><i>SERVER</i> ] [-<code>t </code><i>PROTOCOL</i> ] [-<code>x </code><i>PLUGIN</i> ] [-<code>-update-profile</code> ] [-<code>-set-option </code><i>OPTION[=VALUE]</i> ] [-<code>-display </code><i>DISPLAY</i> ]</p>
<h2>DESCRIPTION</h2>
<p> Remmina is a remote desktop client written in GTK+, aiming to be useful for system administrators and travellers, who need to work with lots of remote computers in front of either large monitors or tiny netbooks. Remmina supports multiple network protocols in an integrated and consistent user interface. Currently RDP, VNC, SSH, SPICE, and WWW are supported. Lp Remmina is released in separated source packages: Lp<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;&quot;remmina&quot;, the main GTK+&nbsp;application<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;&quot;remmina-plugins&quot;, a set of plugins Lp Remmina is free and open-source software, released under GNU GPL license.</p>
<h2>FILES</h2>
<p> ${XDG_CONFIG_DIRS}/remmina.pref or ${XDG_CONFIG_HOME}/remmina/remmina.pref : Lp Remmina configuration files. Lp At the first Remmina execution the system wide Remmina configuration files, will be copied in the ${XDG_CONFIG_HOME} Lp ${XDG_DATA_DIRS}/FILE.remmina or ${XDG_DATA_HOME}/remmina/FILE.remmina : Lp Remmina profiles, the file name is autogenerated, but you can create manually your own files with the <code>FILE</code> name you prefer. It&#8217;s possible to specify a custom profile name and location.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, -help</code></p>
<dd> Show help options</p>
<dt><code>-a</code></p>
<dd> Show about dialog</p>
<dt><code>-c, -connect</code>=<i>FILE</i></p>
<dd> Connect directly either to a desktop using options described in a file, or a supported URI (RDP, VNC, SSH or SPICE). The filetype can be &quot;.remmina&quot; or one supported by a plugin capable of importing files</p>
<dt><code>-e, -edit</code>=<i>FILE</i></p>
<dd> Open and edit desktop connection using options described by file, file type can be either .remmina or one supported by a file import capable plugin</p>
<dt><code>-k, -kiosk</code></p>
<dd> Start Remmina in kiosk mode (thin client)</p>
<dt><code>-n, -new</code></p>
<dd> Create a new connection profile</p>
<dt><code>-p, -pref</code>=<i>TABINDEX</i></p>
<dd> Show preferences dialog page</p>
<dt><code>-x, -plugin</code>=<i>PLUGIN</i></p>
<dd> Execute the plugin</p>
<dt><code>-q, -quit</code></p>
<dd> Quit the application</p>
<dt><code>-s, -server</code>=<i>SERVER</i></p>
<dd> Use default server name (for <code>&#8211;new</code>)</p>
<dt><code>-t, -protocol</code>=<i>PROTOCOL</i></p>
<dd> Use default protocol (for <code>&#8211;new</code>)</p>
<dt><code>-i, -icon</code></p>
<dd> Start as tray icon</p>
<dt><code>-v, -version</code></p>
<dd> Show the application&#8217;s version</p>
<dt><code>&#8211;update-profile</code></p>
<dd> Modify connection profile, require also &#8211;set-option</p>
<dt><code>&#8211;set-option </code><i>OPTION[=VALUE]</i></p>
<dd> Set one or more profile settings, to be used with &#8211;update-profile</p>
<dt><code>&#8211;encrypt-password</code></p>
<dd> Encrypt a password</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</dl>
<h2>EXAMPLES</h2>
<p> Lp To connect using an exisitng connection profile use:</p>
<dl>
<dt>
<dd>
<pre>
<code>remmina -c FILE.remmina</code>
</pre>
</dl>
<p> Lp To quick connect using a URI:</p>
<dl>
<dt>
<dd>
<pre>
remmina -c <a href="rdp://username@server">rdp://username@server</a>
remmina -c <a href="rdp://domain\username@server">rdp://domain\username@server</a>
remmina -c <a href="vnc://username@server">vnc://username@server</a>
remmina -c <a href="vnc://server?VncUsername=username">vnc://server?VncUsername=username</a>
remmina -c <a href="ssh://user@server">ssh://user@server</a>
remmina -c <a href="spice://server">spice://server</a>
Lp To quick connect using a URI along with an encrypted password:
remmina -c <a href="rdp://username:encrypted-password@server">rdp://username:encrypted-password@server</a>
remmina -c <a href="vnc://username:encrypted-password@server">vnc://username:encrypted-password@server</a>
remmina -c <a href="vnc://server?VncUsername=username\">vnc://server?VncUsername=username\</a>&amp;VncPassword=encrypted-password
Lp To encrypt a password for use with a URI:
remmina --encrypt-password
Lp </pre>
</dl>
<p> Lp To update username and password and set a different resolution mode of a remmina connection profile use:</p>
<dl>
<dt>
<dd>
<pre><code>
echo "ausername
apassword" | remmina-- update - profile / PATH / TO / FOO.remmina-- set - option username-- set - option resolution_mode = 2 --set - option password
</code></pre>
<dl>
<dt>
<dd> Lp Lp</dl>
</dl>
