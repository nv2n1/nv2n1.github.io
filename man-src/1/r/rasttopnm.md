<h2 class="name">NAME</h2>
<p> rasttopnm &#8211; convert a Sun rasterfile into a portable anymap </p>
<h2>SYNOPSIS</h2>
<p> <code>rasttopnm</code> [<i>rastfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a Sun rasterfile as input. Produces a portable anymap as output. The type of the output file depends on the input file &#8211; if it&#8217;s black &amp; white, a <i>pbm</i> file is written, else if it&#8217;s grayscale a <i>pgm</i> file, else a <i>ppm</i> file. The program tells you which type it is writing.</p>
