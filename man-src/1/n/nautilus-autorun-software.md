<h2 class="name">NAME</h2>
<p> Run Software &#8211; helper tool</p>
<h2>SYNOPSIS</h2>
<p> <code>nautilus-autorun-software</code> <i>mount-uri</i> </p>
<h2>DESCRIPTION</h2>
<p> <code>nautilus-autorun-software</code> is a helper tool for the GNOME desktop to start software from media with Autostart files. </p>
<p> It is the default &quot;x-content/unix-software&quot; handler for the GNOME desktop. </p>
<h2>SEE ALSO</h2>
<p> Autostart files are described at <a rel="nofollow" href="https://specifications.freedesktop.org/autostart-spec/autostart-spec-latest.html">https://specifications.freedesktop.org/autostart-spec/autostart-spec-latest.html</a> </p>
