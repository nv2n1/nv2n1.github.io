<h2>NAME</h2>
<p> <code>npm-rm</code> &#8212; Remove a package</p>
<h2>SYNOPSIS</h2>
<pre>
npm rm &lt;name&gt;
npm uninstall &lt;name&gt;
</pre>
<h2>DESCRIPTION</h2>
<p> This uninstalls a package, completely removing everything npm installed on its behalf.</p>
