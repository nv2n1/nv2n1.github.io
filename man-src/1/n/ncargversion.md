<h2>NAME</h2>
<p> ncargversion &#8211; Display NCAR Graphics Version number</p>
<h2>SYNOPSIS</h2>
<p> <code>ncargversion</code></p>
<h2>DESCRIPTION</h2>
<p> This command allows you to determine what version of NCAR Graphics that you are currently using. This can be helpful when trying to get consulting help on NCAR Graphics.</p>
