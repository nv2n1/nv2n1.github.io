<h2 class="name">NAME</h2>
<p> nm-applet &#8211; network monitor and control GUI applet </p>
<h2>SYNOPSIS</h2>
<p> <code>nm-applet</code> [ <i>OPTIONS</i> ] </p>
<h2>DESCRIPTION</h2>
<p> <code>nm-applet</code> is a GTK-based GUI applet to monitor network status and devices and to start and stop network connections managed by NetworkManager. <i>nm-applet</i> is normally started at login by the desktop session manager and does not need to be run manually. <i>nm-applet</i> conforms to the XDG System Tray specification and requires that the desktop environment provide a System Tray implementation in which the applet will be embedded. </p>
