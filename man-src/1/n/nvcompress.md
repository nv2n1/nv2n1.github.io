<p> NVIDIA &#8211; manual page for NVIDIA Texture Tools 2.0 &#8211; Copyright NVIDIA Corporation 2007</p>
<h2>DESCRIPTION</h2>
<p> NVIDIA Texture Tools 2.0 &#8211; Copyright NVIDIA Corporation 2007 </p>
<p> usage: nvcompress [options] infile [outfile]</p>
<h3>Input options:</h3>
<dl>
<dt><code>-color</code></dt>
<dd> The input image is a color map (default).</dd>
<dt><code>-alpha</code></dt>
<dd> The input image has an alpha channel used for transparency.</dd>
<dt><code>-normal</code></dt>
<dd> The input image is a normal map.</dd>
<dt><code>-tonormal</code></dt>
<dd> Convert input to normal map.</dd>
<dt><code>-clamp</code></dt>
<dd> Clamp wrapping mode (default).</dd>
<dt><code>-repeat</code></dt>
<dd> Repeat wrapping mode.</dd>
<dt><code>-nomips</code></dt>
<dd> Disable mipmap generation.</dd></dl>
<h3>Compression options:</h3>
<dl>
<dt><code>-fast</code></dt>
<dd> Fast compression.</dd>
<dt><code>-nocuda</code></dt>
<dd> Do not use cuda compressor.</dd>
<dt><code>-rgb</code></dt>
<dd> RGBA format</dd>
<dt><code>-bc1</code></dt>
<dd> BC1 format (DXT1)</dd>
<dt><code>-bc1n</code></dt>
<dd> BC1 normal map format (DXT1nm)</dd>
<dt><code>-bc1a</code></dt>
<dd> BC1 format with binary alpha (DXT1a)</dd>
<dt><code>-bc2</code></dt>
<dd> BC2 format (DXT3)</dd>
<dt><code>-bc3</code></dt>
<dd> BC3 format (DXT5)</dd>
<dt><code>-bc3n</code></dt>
<dd> BC3 normal map format (DXT5nm)</dd>
<dt><code>-bc4</code></dt>
<dd> BC4 format (ATI1)</dd>
<dt><code>-bc5</code></dt>
<dd> BC5 format (3Dc/ATI2)</dd></dl>
