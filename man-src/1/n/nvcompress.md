<h2>NAME</h2>
<p> NVIDIA &#8211; manual page for NVIDIA Texture Tools 2.0 &#8211; Copyright NVIDIA Corporation 2007</p>
<h2>DESCRIPTION</h2>
<p> NVIDIA Texture Tools 2.0 &#8211; Copyright NVIDIA Corporation 2007 </p>
<p> usage: nvcompress [options] infile [outfile]</p>
<h3>Input options:</h3>
<dl>
<dt><code>-color</code></p>
<dd> The input image is a color map (default).</p>
<dt><code>-alpha</code></p>
<dd> The input image has an alpha channel used for transparency.</p>
<dt><code>-normal</code></p>
<dd> The input image is a normal map.</p>
<dt><code>-tonormal</code></p>
<dd> Convert input to normal map.</p>
<dt><code>-clamp</code></p>
<dd> Clamp wrapping mode (default).</p>
<dt><code>-repeat</code></p>
<dd> Repeat wrapping mode.</p>
<dt><code>-nomips</code></p>
<dd> Disable mipmap generation.</dl>
<h3>Compression options:</h3>
<dl>
<dt><code>-fast</code></p>
<dd> Fast compression.</p>
<dt><code>-nocuda</code></p>
<dd> Do not use cuda compressor.</p>
<dt><code>-rgb</code></p>
<dd> RGBA format</p>
<dt><code>-bc1</code></p>
<dd> BC1 format (DXT1)</p>
<dt><code>-bc1n</code></p>
<dd> BC1 normal map format (DXT1nm)</p>
<dt><code>-bc1a</code></p>
<dd> BC1 format with binary alpha (DXT1a)</p>
<dt><code>-bc2</code></p>
<dd> BC2 format (DXT3)</p>
<dt><code>-bc3</code></p>
<dd> BC3 format (DXT5)</p>
<dt><code>-bc3n</code></p>
<dd> BC3 normal map format (DXT5nm)</p>
<dt><code>-bc4</code></p>
<dd> BC4 format (ATI1)</p>
<dt><code>-bc5</code></p>
<dd> BC5 format (3Dc/ATI2)</dl>
<p> usage: nvcompress [options] infile [outfile]</p>
