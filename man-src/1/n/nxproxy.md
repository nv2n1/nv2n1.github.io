<h2>NAME</h2>
<p> nxproxy &#8211; NX Proxy Tool</p>
<h2>SYNOPSIS</h2>
<p> <code>nxproxy</code> &lt;options&gt; </p>
<h2>DESCRIPTION</h2>
<p> <code>nxproxy</code> is a tool that allows one to tunnel X sessions through the NX compression libraries. <code>nxproxy</code> is a backend application utilized by the X2GoClient GUI and some other NX/X2Go clients. </p>
<h2>OPTIONS</h2>
<p> For an insight in <code>nxproxy</code> options use <code>nxproxy -help</code> on the command line. </p>
