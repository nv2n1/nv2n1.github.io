<h2 class="name">NAME</h2>
<p> newer &#8211; compare file modification times </p>
<h2>SYNOPSIS</h2>
<p> <code>newer</code> [<i>option</i>] <i>src1 </i> [ <i>src2 &#8230; srcN</i> ] <i>target</i></p>
<h2>DESCRIPTION</h2>
<p> Exit successfully if files <i>src1 &#8230; srcN</i> exist and at least one of them is not older than <i>target</i>. Also exit successfully if <i>target</i> doesn&#8217;t exist.</p>
<h2>OPTIONS</h2>
<p> <code>newer</code> accepts the following options:</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Print help message and exit.</p>
<dt><code>&#8211;quiet, -q</code></p>
<dd> Do not print any output, including error messages.</p>
<dt><code>&#8211;version</code></p>
<dd> Print version information and exit.</p>
<dt><code>&#8211;verbose, -v</code></p>
<dd> List missing source files. This is the default. </p>
</dl>
