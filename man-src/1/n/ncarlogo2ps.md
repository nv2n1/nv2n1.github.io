<h2 class="name">NAME</h2>
 

 ncarlogo2ps - adds NCAR logos to pre-existing PostScript files generated by NCAR Graphics. 

<h2>SYNOPSIS</h2>

 usage: ncarlogo2ps [-s size] [-position x:y] [-angle ang] 
 
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>[-input input_file]&nbsp;<wbr>[-output output_file]

<h2>DESCRIPTION</h2>

 &quot;ncarlogo2ps&quot; takes as input a PostScript file created from NCAR Graphics 3.2 or later, or created from a &quot;ctrans -d ps.color&quot; command, and adds an NCAR logo to each frame. 

 The options are:
<dl>
<dt>-s size
<dd> Specifies the height of the logo in inches. The default is 0.517 inches.
<dt>-p position
<dd> x:y specifies the X-Y position of the center of the logo in inches. Only the &quot;-p&quot; is significant. The default is 7.35:2.3
<dt>-angle ang
<dd> Specifies the angle in degrees to rotate the logo from the defualt upright position.
<dt>-input input_file
<dd> Specifies the PostScript input file. This must have been generated by NCAR Graphics. If no input option is specified, the input defaults to standard in.
<dt>-output output_file
<dd> Specifies the PostScript output file. If no output option is specified, the output defaults to standard out. 

 The options may appear in any order and only the first character is significant.</dl>

<h2>EXAMPLE</h2>

 ncarglogo2ps -s 0.75 -p 7.0:0.75 &lt; input_file &gt; ouptut_file 

 would place in the output file a logo 7 inches from the left edge and 3/4&quot; from the bottom with a height of 3/4&quot;.
