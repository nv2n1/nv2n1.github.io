<pre><code>native2ascii</code> [ <i>inputfile</i> ] [ <i>outputfile</i> ]</pre>
<dl COMPACT>
<dt><i>inputfile</i></p>
<dd>The encoded file to be converted to ASCII.</p>
<dt><i>outputfile</i></p>
<dd>The converted ASCII file.</dl>
