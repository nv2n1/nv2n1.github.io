<h2>NAME</h2>
<p> nacl-sha256 &#8212; program to calculate the sha256 hash</p>
<h2>SYNOPSIS</h2>
<p> <code>nacl-sha256</code></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>nacl-sha256</code> command. </p>
<p> This manual page was written for the <code>Debian</code> distribution because the original program does not have a manual page. Instead, it has documentation in the GNU. </p>
<p> <code>nacl-sha256</code> is a program that uses NaCl to calculate the sha256 hash of the first 4096 bytes of input.</p>
<h2>OPTIONS</h2>
<p> These program expects input on standard input and prints the sha256 hash of the first 4096 bytes on standard output.</p>
