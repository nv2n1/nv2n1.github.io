<h2 class="name">NAME</h2>
<p> nautilus &#8211; a file manager for GNOME</p>
<h2>SYNOPSIS</h2>
<p> <code>nautilus</code> [<i>options</i>]<i> URIs</i>&#8230; </p>
<h2>DESCRIPTION</h2>
<p> <code>nautilus</code> is a file manager, designed for the GNOME 3 desktop. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-c</code>, <code>&#8211;check</code></p>
<dd> Perform a quick set of self-check tests. </p>
<dt><code>&#8211;version</code></p>
<dd> Show the version of the program. </p>
<dt><code>-w</code>, <code>&#8211;new-window</code></p>
<dd> Always open a new window for browsing specified URIs. </p>
<dt><code>-q</code>, <code>&#8211;quit</code></p>
<dd> Quit Nautilus. </p>
<dt><code>-s</code>, <code>&#8211;select</code></p>
<dd> Select specified URI in parent folder. </p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show a summary of options. </p>
<dt>Other standard GNOME options not listed here are also supported.</p>
<dd>
</dl>
