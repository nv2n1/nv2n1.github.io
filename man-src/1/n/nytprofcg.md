<h2 class="name">NAME</h2>
 

 nytprofcg - Convert an NYTProf profile into Callgrind format 

<h2>SYNOPSIS</h2>

 <pre>
 $ nytprofcg --file=nytprof.out --out=nytprof.callgrind
 $ nytprofcg    # same as above
</pre>

<h2>DESCRIPTION</h2>

 Reads a profile data file generated by Devel::NYTProf and writes out the subroutine call graph information it contains in Callgrind format. 

 The output Callgrind file can be loaded into the <tt>&quot;kcachegrind&quot;</tt> <font SIZE="-1">GUI</font> for interactive exploration. 

 For more information see &lt;<a rel="nofollow" HREF="http://kcachegrind.github.io/html/Home.html">http://kcachegrind.github.io/html/Home.html</a>&gt;
