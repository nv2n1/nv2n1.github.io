<h2>NAME</h2>
<p> nessus-mkrand &#8211; Creates a file with random bytes </p>
<h2>SYNOPSIS</h2>
<p> <code>nessus-mkrand&nbsp;<wbr>[</code><i>filename&nbsp;<wbr></i><code>[</code><i>entropy</i><code>]&nbsp;<wbr>]</code> </p>
<h2>DESCRIPTION</h2>
<p> The <code>Nessus Security Scanner</code> protects the communication between the client and the server by using SSL. To work securely, the OpenSSL library needs a suitable amount of random bytes. On most system, it uses EGD or <i>/dev/random </i> (or <i>/dev/urandom</i>). </p>
<p> On systems which have none of these, Nessus will provide OpenSSL with a file full of random bytes generated by <code>nessus-mkrand </code> which is stored by default under <i>$HOME/.rnd</i>. <code>nessus-mkcert</code> and <code>nessus-mkcert-client</code> require user input as a random seed. </p>
<p> By default, <code>nessus-mkrand </code> produces a file stored under <i>$HOME/.rnd </i> containing 1024 bytes of entropy. </p>
