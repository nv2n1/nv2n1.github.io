<h2 class="name">NAME</h2>
<p> nytprofcsv &#8211; (DEPRECATED) Devel::NYTProf::Reader CSV format implementation </p>
<h2>SYNOPSIS</h2>
<pre><code>
$ nytprofcsv[-h][-d][-o&lt;output directory&gt;][-f&lt;input file&gt;] perl - d : NYTProf some_perl_app.pl
                                                                          nytprofcsv
                                                                              Generating CSV Output...
</code></pre>
<h2>NOTE</h2>
<p> <code>nytprofcsv is deprecated and will be removed in a future release.</code></p>
<h2>DESCRIPTION</h2>
<p> <tt>&quot;nytprofcsv&quot;</tt> is a script that implements Devel::NYTProf::Reader to create comma-seperated value formatted reports from Devel::NYTProf databases. </p>
<p> See the Devel::NYTProf Perl code profiler for more information.</p>
<h2>COMMAND-LINE OPTIONS</h2>
<p> These are the command line options understood by <tt>&quot;nytprofcsv&quot;</tt></p>
<dl>
<dt>-f, &#8211;file &lt;filename&gt;</p>
<dd> Specifies the location of the input file. The input file must be the output of fprofpp. Default: nytprof.out</p>
<dt>-o, &#8211;out &lt;dir&gt;</p>
<dd> Where to place the generated report. Default: ./nytprof/</p>
<dt>-d, &#8211;delete</p>
<dd> Purge any existing database located at whatever -o (above) is set to</p>
<dt>-h, &#8211;help</p>
<dd> Print the help message</dl>
