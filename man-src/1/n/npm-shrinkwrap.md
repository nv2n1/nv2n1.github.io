<h2 class="name">NAME</h2>
<p> <code>npm-shrinkwrap</code> &#8211; Lock down dependency versions for publication </p>
<h3>Synopsis</h3>
<dl>
<dt>
<dd>
<pre>
npm shrinkwrap
</pre>
</dl>
<h3>Description</h3>
<p> This command repurposes <code>package-lock.json</code> into a publishable <code>npm-shrinkwrap.json</code> or simply creates a new one. The file created and updated by this command will then take precedence over any other existing or future <code>package-lock.json</code> files. For a detailed explanation of the design and purpose of package locks in npm, see npm help package-locks.</p>
