<h2 class="name">NAME</h2>
 

 nvme-list - List all recognized NVMe devices 

<h2>SYNOPSIS</h2>

 

 <pre>
<i>nvme list</i>
</pre>

<h2>DESCRIPTION</h2>

 

 Scan the sysfs tree for NVM Express devices and return the /dev node for those devices as well as some pertinent information about them.
