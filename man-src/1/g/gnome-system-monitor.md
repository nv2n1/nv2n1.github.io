<h2>NAME</h2>
<p> gnome-system-monitor &#8212; view and control processes</p>
<h2>SYNOPSIS</h2>
<p> <code>gnome-system-monitor</code> [<code>-s,</code><code>&#8211;simple</code>]</p>
<h2>gnome-system-monitor</h2>
<p> The gnome-system-monitor allows you to view and control the processes running on your system. You can access detailed memory maps, send signals, and terminate the processes. </p>
<p> In addition, the gnome-system-monitor provides an overall view of the resource usage on your system, including memory and CPU allocation.</p>
<h2>OPTIONS</h2>
<p> This program accepts all the standard GNOME and GTK+ options, which follow the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). In addition to those standard GNOME options, the gnome-system-monitor accepts the following options:</p>
<dl>
<dt><code>-s,</code> <code>&#8211;simple</code></p>
<dd> Show a simple dialog to end processes and log out.</dl>
