<h2 class="name">NAME</h2>
<p> guilt-next &#8211; Output the name of next patch to be pushed </p>
<h2>SYNOPSIS</h2>
<p> <i>guilt-next</i> [-p|&#8211;path]</p>
<h2>DESCRIPTION</h2>
<p> Output the name of next patch to be pushed. If linkguilt:guilt-push[1] is issued, this patch would be the topmost patch.</p>
<h2>OPTIONS</h2>
<p> -p, &#8211;path</p>
<dl>
<dt>
<dd> Output full path instead of just patch name.</dl>
