<h2 class="name">NAME</h2>
<p> gnome-software &#8211; Install applications </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gnome-software</code> [OPTION&#8230;]</dl>
<h2>DESCRIPTION</h2>
<dd>This manual page documents briefly the <code>gnome-software</code> command. </p>
<p> <code>gnome-software</code> allows you to add and remove applications and update your system.</p>
<h2>OPTIONS</h2>
<p> <code>-?</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Prints a short help text and exits.</dl>
<p> <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Prints the program version and exits.</dl>
<p> <code>&#8211;mode</code> <i>MODE</i></p>
<dl>
<dt>
<dd> Starts gnome-software in the given mode. <i>MODE</i> can be &#8216;updates&#8217;, &#8216;updated&#8217;, &#8216;installed&#8217; or &#8216;overview&#8217;. The default mode is &#8216;overview&#8217;.</dl>
