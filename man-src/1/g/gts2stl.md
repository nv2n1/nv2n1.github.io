<h2 class="name">NAME</h2>
<p> gts2stl &#8211; converts a GTS file to STL format</p>
<h2>SYNOPSIS</h2>
<p> <code>gts2stl</code> [<i>OPTIONS</i>]&nbsp;&lt;&nbsp;<i>input.gts&nbsp;</i>&gt;&nbsp;<i>output.stl</i> </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>gts2stl</code> command. </p>
<h2>OPTIONS</h2>
<p> This program follow the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-r</code>,&nbsp;<code>&#8211;revert</code></p>
<dd> Revert face normals.</p>
<dt><code>-v</code>,&nbsp;<code>&#8211;verbose</code></p>
<dd> Display surface statistics.</p>
<dt><code>-h</code>,&nbsp;<code>&#8211;help</code></p>
<dd> Display the help and exit. </p>
</dl>
