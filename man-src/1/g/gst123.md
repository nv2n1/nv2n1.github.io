<h2 class="name">NAME</h2>
<p> gst123 &#8211; A GStreamer based command line media player</p>
<h2>SYNOPSIS</h2>
<p> <code>gst123</code> [<i>OPTIONS</i>] [<i>URIS&#8230;</i>] </p>
<h2>DESCRIPTION</h2>
<p> <code>gst123</code> is a command line based media player released as free software under the GNU LGPL. </p>
<h2>OPTIONS</h2>
<p> <code>gst123</code> follows the usual GNU command line syntax, with long options starting with two dashes (&#8216;-&#8216;).</p>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Shows a brief help message.</dl>
<dl>
<dt><code>&#8211;version</code></p>
<dd> Prints out gst123 version.</dl>
<dl>
<dt><code>&#8211;full-version</code></p>
<dd> Prints out gst123 version and version of libraries used by gst123.</dl>
<dl>
<dt><code>-r</code>, <code>&#8211;repeat</code></p>
<dd> Repeat playlist forever.</dl>
<dl>
<dt><code>-z</code>, <code>&#8211;shuffle</code></p>
<dd> Shuffle playlist before playing.</dl>
<dl>
<dt><code>-Z</code>, <code>&#8211;random</code></p>
<dd> Play files in random order forever.</dl>
<dl>
<dt><code>-x</code>, <code>&#8211;novideo</code></p>
<dd> Do not play the video stream.</dl>
<dl>
<dt><code>-@</code> <i>&lt;playlist&gt;</i>, <code>&#8211;list</code> <i>&lt;playlist&gt;</i></p>
<dd> Load files to play from the playlist file.</dl>
<dl>
<dt><code>-a</code>, <code>&#8211;audio-output</code> <i>&lt;driver&gt;[=&lt;device&gt;]</i></p>
<dd> Set audio output driver (and device). See section audio drivers for details.</dl>
<dl>
<dt><code>-v</code>, <code>&#8211;visualization</code> <i>&lt;plugin_name&gt;</i></p>
<dd> Use a plugin for visualization during audio playback.</dl>
<dl>
<dt><code>-V</code>, <code>&#8211;visualization-list</code></p>
<dd> Show a list of available audio visualization plugins which can be used with the -v option.</dl>
<dl>
<dt><code>-k</code> <i>&lt;n&gt;</i>, <code>&#8211;skip</code> <i>&lt;n&gt;</i></p>
<dd> Skip the first &#8216;n&#8217; seconds of each file.</dl>
<dl>
<dt><code>-q</code>, <code>&#8211;quiet</code></p>
<dd> Don&#8217;t display any messages (title, codec, ui feedback).</dl>
<dl>
<dt><code>&#8211;verbose</code></p>
<dd> Print GStreamer pipeline used to play files</dl>
<p> Besides filenames, playlist entries or command line args can be directories. In this case, <code>gst123</code> recursively searches the directory and plays all files contained in it. </p>
<h2>INTERRUPT</h2>
<p> You can abort <code>gst123</code> at any time by pressing Ctrl-C. If you are playing multiple files, this will stop the current file and begin playing the next one. If you want to abort playing immediately instead of skipping to the next file, press Ctrl-C within the first second of the playback of a new file. </p>
<h2>KEYBOARD INPUT</h2>
<dl>
<dt><code>cursor left/right</code></p>
<dd> Seek 10 seconds backwards/forwards.</dl>
<dl>
<dt><code>cursor down/up</code></p>
<dd> Seek 1 minute backwards/forwards.</dl>
<dl>
<dt><code>page down/up</code></p>
<dd> Seek 10 minute backwards/forwards.</dl>
<dl>
<dt><code>space</code></p>
<dd> Toggle pause.</dl>
<dl>
<dt><code>+/-</code></p>
<dd> Increase/decrease volume by 10%.</dl>
<dl>
<dt><code>m</code></p>
<dd> Toggle mute/unmute.</dl>
<dl>
<dt><code>f</code></p>
<dd> Toggle fullscreen display (only for videos).</dl>
<dl>
<dt><code>1</code></p>
<dd> Normal video size (only for videos).</dl>
<dl>
<dt><code>n</code></p>
<dd> Play next file.</dl>
<dl>
<dt><code>q</code></p>
<dd> Quit <code>gst123</code>.</dl>
<dl>
<dt><code>?</code></p>
<dd> Show keyboard help.</dl>
<h2>CONFIGURATION FILE</h2>
<p> During start, gst123 will read ~/.gst123rc, if this file exists. Empty lines and lines starting with a # are ignored. The following commands are available:</p>
<dl>
<dt><code>audio_output</code> <i>&lt;driver&gt;[=&lt;device&gt;]</i></p>
<dd> This sets the default audio driver and the default audio device. It has the same effect as the -a / &#8211;audio-output command line option. When both are present, a config file entry and the command line option, the value from the command line option will be used. Read the section on audio drivers for details on the available drivers and syntax.</dl>
<dl>
<dt><code>visualization</code> <i>&lt;visualization_plugin&gt;</i></p>
<dd> Set default visualization plugin for audio files. This setting has the same effect as the -v / &#8211;visualization command line option. When both are present, the value from the command line option will be used.</dl>
<h2>AUDIO DRIVERS</h2>
<dl>
<dt><code>alsa</code>=[<i>&lt;device&gt;</i>]</p>
<dd> The ALSA driver; when used without argument (as in -a alsa), the ALSA driver uses the default device. To select an ALSA device, its possible to use for example alsa=hw:1 (which will use the hw:1 ALSA device).</dl>
<dl>
<dt><code>oss</code>=[<i>&lt;device&gt;</i>]</p>
<dd> The OSS driver; when used without argument (as in -a oss), the OSS driver uses the default device. The device can be specified using for example oss=/dev/dsp1 (which would use the OSS device /dev/dsp1).</dl>
<dl>
<dt><code>pulse</code>=[<i>&lt;device&gt;</i>]</p>
<dd> The PulseAudio driver. This driver optionally accepts a device name using the pulse=<i>&lt;device&gt;</i> syntax.</dl>
<dl>
<dt><code>jack</code></p>
<dd> The JACK driver. Device selection is not supported in this case.</dl>
<dl>
<dt><code>none</code></p>
<dd> Dummy output driver, will not output any audio.</dl>
