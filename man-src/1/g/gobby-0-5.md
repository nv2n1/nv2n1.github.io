<p><code>gobby</code> &#8211; a collaborative text editor </p>
<h2>Synopsis</h2>
<p><code>gobby</code> [<i>options</i>] [<i>file(s)</i>]</p>
<h2>Description</h2>
<p><code>gobby</code> is an editor which allows one to edit text documents and source files collaboratively over a network. Changes to the documents are synchronised instantly to the other clients. </p>

<p><code>gobby</code> was written by the 0x539 dev group &lt;crew [at] 0x539.de&gt;.</p>
