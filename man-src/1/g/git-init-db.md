<h2 class="name">NAME</h2>
<p> git-init-db &#8211; Creates an empty Git repository </p>
<h2>SYNOPSIS</h2>
<pre><code>
git init - db[-q | --quiet][--bare][--template = &lt;template_directory&gt;][--separate - git - dir&lt;git dir&gt;][--shared[=&lt;permissions&gt;]]
</code></pre>
<h2>DESCRIPTION</h2>
<p> This is a synonym for <code><a href="/docs/linux/man/1-git-init/">git-init</a></code>(1). Please refer to the documentation of that command.</p>
