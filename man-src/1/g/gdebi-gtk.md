<h2 class="name">NAME</h2>
<p> gdebi-gtk &#8211; Simple tool to install deb files </p>
<h2>SYNOPSIS</h2>
<p> <code>gdebi-gtk</code> [<i>package.deb</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> gdebi lets you install local deb packages resolving and installing its dependencies. apt does the same, but only for remote (http, ftp) located packages.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show this help message and exit.</p>
<dt><code>&#8211;n</code>, <code>&#8211;non-interactive</code></p>
<dd> Run non-interactive (dangerous!).</p>
<dt><code>&#8211;auto-close</code></p>
<dd> Auto close when the install is finished.</p>
<dt><code>&#8211;datadir=</code><i>DATADIR</i></p>
<dd> Use alternative datadir.</p>
<dt><code>-r</code>, <code>&#8211;remove</code></p>
<dd> Remove selected package.</p>
