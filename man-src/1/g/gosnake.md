<h2>NAME</h2>
<p> GoSnake &#8211; The Console Snake Game</p>
<h2>SYNOPSIS</h2>
<p> <code>gosnake [OPTIONS]</code></p>
<h2>DESCRIPTION</h2>
<p> GoSnake is a simple yet nice implementation of the well known snake game. It is designed to run under the GNU/Linux console (including terminal emulators). The aim of the game is simple: control your snake and move it around to eat food without hitting walls, or colliding with itself. The game includes 10 levels with an option to play levels randomly, and a highscore board. </p>
<p> The snake is controlled by using the arrows keys, or the &quot;awsd&quot; keys as shown below. </p>

<h2>OPTIONS</h2>
<dl>
<dt>-h, &#8211;help</p>
<dd> Print command line help </p>
<dt>-v, &#8211;version</p>
<dd> Display program version and exit </p>
<dt>-l, &#8211;level n</p>
<dd> Start playing from level &#8216;n&#8217; </p>
</dl>
<h2>FILES</h2>
<p> <i>~/.gosnake</i> Special file used to store highscores information. </p>
