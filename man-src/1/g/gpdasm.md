<h2>NAME</h2>
<p> gpdasm &#8211; GNU PIC disassembler</p>
<h2>SYNOPSIS</h2>
<p> <code>gpdasm [options] file</code></p>
<h2>WARNING</h2>
<p> The information in this man page is an extract from the full documentation of gputils and is limited to the meaning of the options. For complete and current documentation, refer to &quot;gputils.ps&quot; located in the gputils docs directory.</p>
<h2>DESCRIPTION</h2>
<p> <code>gpdasm</code> is an disassembler for Microchip (TM) PIC (TM) micro-controllers. <code>gpdasm</code> is part of gputils. Check the <code><a href="/docs/linux/man/1-gputils/">gputils</a></code>(1) manpage for details on other GNU PIC utilities.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-c</code>, <code>&#8211;mnemonics</code></p>
<dd> Decode special mnemonics.</p>
<dt><code>-h</code>, &#8211;help</p>
<dd> Show the usage message and exit.</p>
<dt><code>-i</code>, &#8211;hex-info</p>
<dd> Report extra information about input hex file. This information includes file size and hex format.</p>
<dt><code>-l</code>, &#8211;list-chips</p>
<dd> List the supported processors.</p>
<dt><code>-m</code>, &#8211;dump</p>
<dd> Display the contents of instruction memory.</p>
<dt><code>-p PROC</code>,<code> &#8211;processor PROC</code></p>
<dd> Select the processor.</p>
<dt><code>-s</code>, &#8211;short</p>
<dd> Output the short format. This format can be reassembled by gpasm.</p>
<dt><code>-v</code>, &#8211;version</p>
<dd> Show the version information and exit.</p>
<dt><code>-y</code>, &#8211;extended</p>
<dd> Enable 18xx extended mode.</p>
<dt><code>&#8211;strict</code></p>
<dd> Disassemble only opcodes generated by gpasm in case of instructions with several opcodes.</dl>
