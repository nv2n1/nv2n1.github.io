<p>gem3.0 &#8211; frontend to RubyGems, the Ruby package manager </p>
<h2>Synopsis</h2>
<p>gem3.0 command [arguments&#8230;] [options&#8230;]</p>
<h2>Description</h2>
<p>gem3.0 is the frontend to RubyGems, the standard package manager for Ruby. This is a basic help message containing pointers to more information. </p>
<p> Further help:</p>
<dl>
<dd><code>gem3.0 help commands</code> list all gem3.0 commands</p>
<dd><code>gem3.0 help examples</code> shows some examples of usage</p>
<dd><code>gem3.0 help COMMAND</code> show help on COMMAND, (e.g. &#8216;gem3.0 help install&#8217;)</dl>
<h2>Links</h2>
<p><a rel="nofollow" href="http://rubygems.org/">http://rubygems.org/</a></p>
<h2>Examples</h2>
<p>gem3.0 install rake gem3.0 list &#8211;local gem3.0 build package.gemspec gem3.0 help install</p>
