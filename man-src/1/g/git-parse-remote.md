<h2 class="name">NAME</h2>
<p> git-parse-remote &#8211; Routines to help parsing remote repository access parameters </p>
<h2>SYNOPSIS</h2>
<pre>
<i>. &quot;$(git --exec-path)/git-parse-remote&quot;</i>
</pre>
<h2>DESCRIPTION</h2>
<p> This script is included in various scripts to supply routines to parse files under $GIT_DIR/remotes/ and $GIT_DIR/branches/ and configuration variables that are related to fetching, pulling and pushing.</p>
<h2>GIT</h2>
<p> Part of the <code><a href="/docs/linux/man/1-git/">git</a></code>(1) suite </p>
