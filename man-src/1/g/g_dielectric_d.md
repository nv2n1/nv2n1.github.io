<h2>NAME</h2>
<p> g_dielectric &#8211; calculates frequency dependent dielectric constants </p>
<p> <code>VERSION 4.0.1</code></p>
<h2>SYNOPSIS</h2>
<p> <code>g_dielectric</code> <code>-f</code><i> dipcorr.xvg </i> <code>-d</code><i> deriv.xvg </i> <code>-o</code><i> epsw.xvg </i> <code>-c</code><i> cole.xvg </i> <code>-[no]h</code><i></i> <code>-nice</code><i> int </i> <code>-b</code><i> time </i> <code>-e</code><i> time </i> <code>-dt</code><i> time </i> <code>-[no]w</code><i></i> <code>-[no]xvgr</code><i></i> <code>-[no]fft</code><i></i> <code>-[no]x1</code><i></i> <code>-eint</code><i> real </i> <code>-bfit</code><i> real </i> <code>-efit</code><i> real </i> <code>-tail</code><i> real </i> <code>-A</code><i> real </i> <code>-tau1</code><i> real </i> <code>-tau2</code><i> real </i> <code>-eps0</code><i> real </i> <code>-epsRF</code><i> real </i> <code>-fix</code><i> int </i> <code>-ffn</code><i> enum </i> <code>-nsmooth</code><i> int </i></p>
<h2>DESCRIPTION</h2>
<p> dielectric calculates frequency dependent dielectric constants from the autocorrelation function of the total dipole moment in your simulation. This ACF can be generated by g_dipoles. For an estimate of the error you can run g_statistics on the ACF, and use the output thus generated for this program. The functional forms of the available functions are: </p>
<p> One parmeter : y = Exp[-a1 x] Two parmeters : y = a2 Exp[-a1 x] Three parmeter: y = a2 Exp[-a1 x] + (1 &#8211; a2) Exp[-a3 x] Startvalues for the fit procedure can be given on the commandline. It is also possible to fix parameters at their start value, use -fix with the number of the parameter you want to fix. </p>
<p> Three output files are generated, the first contains the ACF, an exponential fit to it with 1, 2 or 3 parameters, and the numerical derivative of the combination data/fit. The second file contains the real and imaginary parts of the frequency-dependent dielectric constant, the last gives a plot known as the Cole-Cole plot, in which the imaginary component is plotted as a function of the real component. For a pure exponential relaxation (Debye relaxation) the latter plot should be one half of a circle</p>
