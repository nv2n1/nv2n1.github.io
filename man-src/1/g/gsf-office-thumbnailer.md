<h2 class="name">NAME</h2>
<p> gsf-office-thumbnailer &#8211; office files thumbnailer for the GNOME desktop</p>
<h2>SYNOPSIS</h2>
<p> <code>gsf-office-thumbnailer</code> [<i>OPTIONS</i>] <i>infile</i> <i>outfile</i> </p>
<h2>DESCRIPTION</h2>
<p> This manual page briefly documents the <code>gsf-office-thumbnailer</code> command. </p>
<p> <code>gsf-office-thumbnailer</code> is used internally by GNOME applications such as <code>nautilus</code> to generate thumbnails of several types of office application files. While it is possible to invoke it manually, it is usually invoked automatically by <code>nautilus</code>. </p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with single letter options starting with a single dash (`-&#8216;) and longer options starting with two dashes (`&#8211;&#8216;). </p>
<h3>Main options</h3>
<dl>
<dt><code>-i, &#8211;input=</code><i>filename</i></p>
<dd> Name of file for which to create a thumbnail</p>
<dt><code>-o, &#8211;output=</code><i>filename</i></p>
<dd> Name of the file in which to store the thumbnail</p>
<dt><code>-s, &#8211;size=</code><i>N</i></p>
<dd> Size of thumbnail in pixels; the thumbnail will be at most N*N pixels large. </p>
</dl>
<h3>Help options</h3>
<dl>
<dt><code>-?, &#8211;help</code></p>
<dd> Display a brief usage message </p>
</dl>
