<h2 class="name">NAME</h2>
<p> geocpset &#8211; adds control points based on geometric position </p>
<h2>SYNOPSIS</h2>
<p> <code>geocpset</code> [<i>-o output.pto</i>] <i>input.pto</i></p>
<h2>DESCRIPTION</h2>
<p> <code>geocpset</code> is a tool for panoramas which contains featureless images, e.g. sky images. In this images a control point detector does not find control points. <code>geocpset</code> analyses the positions of the images in project files. Then it adds control points to these images which are not connected by control points. The control points are set only be the geometric positions of the images and not by the image content. So <code>geocpset</code> should only used with projects which have assigned rough image positions.</p>
<h2>USAGE</h2>
<dl>
<dt> <code>geocpset</code> <i>-o output.pto</i> <i>input.pto</i></p>
<dd></dl>
<p> If the <i>&#8211;output/-o</i> switch is missing then the suffix &#8220;_geo&#8221; is added to the filename. </p>
<p> The indented workflow is</p>
<dl>
<dt>#1 First create project file</p>
<dd> pto_gen -o project.pto *.jpg</p>
<dt>#2 Then assign rough positions to images</p>
<dd> pto_var &#8211;set y=i*20-40,p=0,r=0 -o project.pto project.pto</p>
<dt>#3 Now run a &quot;normal&quot; control point detector, e.g. only on overlapping images</p>
<dd> cpfind &#8211;prealigned -o project.pto project.pto</p>
<dt>#4 And finally connect all unconnected images</p>
<dd> geocpset -o project.pto project.pto</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-o|&#8211;output</code> <i>output.pto</i></p>
<dd> Output a pto file with the given filename. If not given it will append &#8220;_geo&#8221; to the input filename.</p>
<dt><code>-e|&#8211;each-overlap</code></p>
<dd> By default <code>geocpset</code> adds only control points to unconnected images. With this switch you can force to add a geometric control point to each overlap, which is not connect by control points or linked with image positions.</p>
<dt><code>&#8211;min-overlap=NUM</code></p>
<dd> By default <code>geocpset</code> takes only image pairs into account which overlap more than 10 %. If you have very narrow overlaps you can decrease this value to take also such small overlaps into account, e.g. <code>&#8211;min-overlap=1</code></p>
<dt><code>-h|&#8211;help</code></p>
<dd> Display help.</dl>
