<h2>NAME</h2>
<p> gmt5syntax &#8211; Convert old GMT script to use new &#8216;gmt &lt;module&gt;&#8217; syntax</p>
<h2>SYNOPSIS</h2>
<p> <code>gmt5syntax</code> old_script &gt; new_script</p>
<h2>DESCRIPTION</h2>
<p> <code>gmt5syntax</code> is a perl script that converts old-style GMT commands in, e.g., shell scripts, to the new <code>gmt &lt;module&gt;</code>-syntax. This utility is located in the tools subdirectory of the data directory. <code>gmt &#8211;show-datadir</code> will show the path to the latter.</p>
