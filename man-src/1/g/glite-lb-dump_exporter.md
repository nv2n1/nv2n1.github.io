<h2 class="name">NAME</h2>
<p> glite-lb-dump_exporter &#8211; L&amp;B dump exporter for Job Provenance </p>
<h2>SYNOPSIS</h2>
<p> <code>glite-lb-dump_exporter</code> [<i>OPTIONS</i>] </p>
<h2>DESCRIPTION</h2>
<p> <code>glite-lb-dump_exporter</code> parses a complete L&amp;B job events dump file, creates one file per every job, and updates information in the message directory for further processing. </p>
<p> This utility is used together with <code>glite-jp-importer</code> daemon for importing L&amp;B dumps to Job Provenance. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d</code>, &#8211;dump <i>FILE</i></p>
<dd> L&amp;B dump file location. The file is generated by the <code>glite-lb-purge</code> utility. </p>
<dt><code>-h</code>, &#8211;help</p>
<dd> Display help. </p>
<dt><code>-j</code>, &#8211;jpps <i>HOST:PORT</i></p>
<dd> Target Job Provenance Primary Storage, where the files should be uploaded. </p>
<dt><code>-m</code>, &#8211;lbmaildir <i>DIRECTORY</i></p>
<dd> Directory to store the message describing the file upload. It is read by <code>glite-jp-importer</code>. </p>
<dt><code>-s</code>, &#8211;store <i>DIRECTORY</i></p>
<dd> Directory where to store all dump files. </p>
</dl>
