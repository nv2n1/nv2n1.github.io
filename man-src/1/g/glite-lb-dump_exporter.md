<p> <code>glite-lb-dump_exporter</code> [<i>OPTIONS</i>] </p>
<p> <code>glite-lb-dump_exporter</code> parses a complete L&amp;B job events dump file, creates one file per every job, and updates information in the message directory for further processing. </p>
<p> This utility is used together with <code>glite-jp-importer</code> daemon for importing L&amp;B dumps to Job Provenance. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d</code>, &#8211;dump <i>FILE</i></dt>
<dd> L&amp;B dump file location. The file is generated by the <code>glite-lb-purge</code> utility. </dd>
<dt><code>-h</code>, &#8211;help</dt>
<dd> Display help. </dd>
<dt><code>-j</code>, &#8211;jpps <i>HOST:PORT</i></dt>
<dd> Target Job Provenance Primary Storage, where the files should be uploaded. </dd>
<dt><code>-m</code>, &#8211;lbmaildir <i>DIRECTORY</i></dt>
<dd> Directory to store the message describing the file upload. It is read by <code>glite-jp-importer</code>. </dd>
<dt><code>-s</code>, &#8211;store <i>DIRECTORY</i></dt>
<dd> Directory where to store all dump files. </dd>
</dl>
