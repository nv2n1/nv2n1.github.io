<h2 class="name">NAME</h2>
<p> gnome-session-properties &#8211; Configure applications to start on login </p>
<h2>SYNOPSIS</h2>
<p> <code>gnome-session-properties</code></p>
<h2>DESCRIPTION</h2>
<p> The <i>gnome-session-properties</i> program enables the users to configure what applications should be started on login, in addition to the default startup applications configured on the system. </p>
<p> It also proposes an interface to save a snapshot of the currently running applications so that they can automatically be restored to their current state on your next GNOME session.</p>
