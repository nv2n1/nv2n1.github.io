<h2 class="name">NAME</h2>
<p> glxgears &#8211; &#8220;gears&#8221; demo for GLX </p>
<h2>SYNOPSIS</h2>
<p> <code>glxgears</code> [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> The <i>glxgears</i> program is a port of the &#8220;gears&#8221; demo to GLX. It displays a set of rotating gears and prints out the frame rate at regular intervals. It has become quite popular as basic benchmarking tool.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-display </code><i>display</i></p>
<dd> Specify which X display to run on.</p>
<dt><code>-info</code></p>
<dd> Display OpenGL renderer information.</p>
<dt><code>-stereo</code></p>
<dd> Use a stereo enabled GLX visual.</p>
<dt><code>-fullscreen</code></p>
<dd> Run in fullscreen mode.</dl>
