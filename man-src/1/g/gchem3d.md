<h2 class="name">NAME</h2>
<p> gchem3d &#8211; a small chemical viewer application </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gchem3d</code> [<code>OPTION(S)</code>&#8230;] [<i>FILE</i>&#8230;]</dl>
<h2>DESCRIPTION</h2>
<p> <code>gchem3d</code></p>
<dd>is a small chemical viewer application, which can show several chemical file formats.</p>
<h2>OPTIONS</h2>
<p> The following options are accepted: </p>
<p> <code>-b </code><i>COLOR</i>, <code>&#8211;bgcolor=</code><i>COLOR</i></p>
<dl>
<dt>
<dd> Use the given color as background color. <i>COLOR</i> can be one of &quot;<i>black</i>&quot; (default), &quot;<i>white</i>&quot;, &quot;<i>#rrggbb</i>&quot; (don&#8217;t forget to escape the lq#rq character in the shell).</dl>
<p> <code>-d </code><i>MODEL</i>, <code>&#8211;display3d=</code><i>MODEL</i></p>
<dl>
<dt>
<dd> Choose how molecules are displayed. <i>MODEL</i> can be one of &quot;<i>BallnStick</i>&quot; (default), &quot;<i>SpaceFill</i>&quot;.</dl>
<p> <code>-?</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show application help options.</dl>
<p> <code>&#8211;help-all</code>, <code>&#8211;help-*</code></p>
<dl>
<dt>
<dd> Print all or just a group of help options. These options are not documented here. Instead see <code><a href="/docs/linux/man/7-gtk-options/">gtk-options</a></code>(7) and <code><a href="/docs/linux/man/7-gnome-options/">gnome-options</a></code>(7).</dl>
<p> <code>-v</code>, <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Print gchem3d version information.</dl>
