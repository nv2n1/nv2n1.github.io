<h2>NAME</h2>
<p> <code>grub-menulst2cfg</code> &#8212; Convert a configuration file from GRUB 0.xx to GRUB 2.xx format. </p>
<h2>SYNOPSIS</h2>
<p> <code>grub-menulst2cfg</code> [<i>INFILE</i> [<i>OUTFILE</i>]] </p>
<h2>DESCRIPTION</h2>
<p> <code>grub-menulst2cfg</code> converts a configuration file from GRUB 0.xx to the current format. </p>
