<h2 class="name">NAME</h2>
<p> grepjar &#8211; search files in a jar file for a pattern </p>
<h2>SYNOPSIS</h2>
<p> grepjar [<code>-bcinsw</code>] <code>-e</code> <i></i><font SIZE="-1"><i>PATTERN</i></font><i></i> | <i></i><font SIZE="-1"><i>PATTERN</i></font><i></i> <i>files</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> The <tt>&quot;grepjar&quot;</tt> program can be used to search files in a jar file for a pattern.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-b</code></p>
<dd> Print byte offset of match.</p>
<dt><code>-c</code></p>
<dd> Print number of matches.</p>
<dt><code>-i</code></p>
<dd> Compare case-insensitively.</p>
<dt><code>-n</code></p>
<dd> Print line number of each match.</p>
<dt><code>-s</code></p>
<dd> Suppress error messages.</p>
<dt><code>-w</code></p>
<dd> Force <i></i><font SIZE="-1"><i>PATTERN</i></font><i></i> to match only whole words.</p>
<dt><code>-e</code> <i></i><font SIZE="-1"><i>PATTERN</i></font><i></i></p>
<dd> Use <i></i><font SIZE="-1"><i>PATTERN</i></font><i></i> as regular expression.</p>
<dt><code>&#8211;help</code></p>
<dd> Print help, then exit.</p>
<dt><code>-V</code></p>
<dd>
<dt><code>&#8211;version</code></p>
<dd> Print version number, then exit.</dl>
