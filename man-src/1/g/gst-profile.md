<h2>NAME</h2>
<p> gst-doc &#8211; GNU Smalltalk profiler</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
</dt><dd> gst-doc [ flag &#8230; ] class &#8230;</dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></dt>
<dd> look for classes in the given image</dd>
<dt><code>-p</code> <code>&#8211;package</code>=<i>PKG</i></dt>
<dd> look for classes in the given package</dd>
<dt><code>-f</code> <code>&#8211;file</code>=<i>FILE</i></dt>
<dd> look for classes in the given file</dd>
<dt> <code>-n</code> <code>&#8211;namespace</code>=<i>NAMESP</i> load files in the given namespace</dt>
<dt><code>-o</code> <code>&#8211;output</code>=<i>FILE</i></dt>
<dd>
</dd><dd>emit documentation in the given file (default=stdout)</dd>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></dt>
<dd> use the specified kernel directory</dd>
<dt><code>-F</code> <code>&#8211;output-format</code>=<i>KIND</i></dt>
<dd> use the given publisher (HTML or default=Texinfo)</dd>
<dt><code>-h</code> <code>&#8211;help</code></dt>
<dd> show this message</dd>
<dt><code>-v</code> <code>&#8211;verbose</code></dt>
<dd> print extra information while processing</dd>
<dt><code>&#8211;version</code></dt>
<dd> print version information and exit</dd></dl>
<h2>SEE ALSO</h2>
<p> The full documentation for <code>gst-doc</code> is maintained as a Texinfo manual. If the <code>info</code> and <code>gst-doc</code> programs are properly installed at your site, the command</p>
<dl>
<dt>
</dt><dd> <code>info gst</code></dd></dl>
<p> should give you access to the complete manual. </p>
