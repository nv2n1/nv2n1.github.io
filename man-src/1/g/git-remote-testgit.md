<h2 class="name">NAME</h2>
<p> git-remote-testgit &#8211; Example remote-helper </p>
<h2>SYNOPSIS</h2>
<pre>
git clone testgit::&lt;source-repo&gt; [&lt;destination&gt;]
</pre>
<h2>DESCRIPTION</h2>
<p> This command is a simple remote-helper, that is used both as a testcase for the remote-helper functionality, and as an example to show remote-helper authors one possible implementation. </p>
<p> The best way to learn more is to read the comments and source code in <i>git-remote-testgit</i>.</p>
