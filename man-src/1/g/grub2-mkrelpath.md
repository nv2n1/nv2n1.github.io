<h2>NAME</h2>
<p> <code>grub-mkrelpath</code> &#8212; Generate a relative GRUB path given an OS path. </p>
<h2>SYNOPSIS</h2>
<p> <code>grub-mkrelpath</code> <i>FILE</i> </p>
<h2>DESCRIPTION</h2>
<p> <code>grub-mkrelpath</code> takes an OS filesystem path for <i>FILE</i> and returns a relative path suitable for use in a GRUB configuration file. </p>
