<h2>NAME</h2>
<p> gst-load &#8211; test and load packages into a GNU Smalltalk image</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
</dt><dd> gst-load [ flag &#8230; ] package &#8230;</dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-q</code> <code>&#8211;quiet</code></dt>
<dd> hide the output</dd>
<dt><code>-v</code> <code>&#8211;verbose</code></dt>
<dd> show loaded files</dd>
<dt><code>-f</code> <code>&#8211;force</code></dt>
<dd> reload package if already loaded</dd>
<dt><code>-n</code> <code>&#8211;dry-run</code></dt>
<dd> don&#8217;t save the image after loading</dd>
<dt><code>-t</code> <code>&#8211;test</code></dt>
<dd> run SUnit tests if available</dd>
<dt><code>&#8211;start</code>[=<i>ARG</i>]</dt>
<dd> start the package and keep running the image</dd>
<dt><code>-i</code> <code>&#8211;rebuild-image</code></dt>
<dd> load into a newly-created image</dd>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></dt>
<dd> load into the specified image</dd>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></dt>
<dd> use the specified kernel directory</dd>
<dt><code>-h</code> <code>&#8211;help</code></dt>
<dd> show this message</dd>
<dt><code>&#8211;version</code></dt>
<dd> print version information and exit</dd></dl>
