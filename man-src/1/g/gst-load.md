<h2>NAME</h2>
<p> gst-load &#8211; test and load packages into a GNU Smalltalk image</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> gst-load [ flag &#8230; ] package &#8230;</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-q</code> <code>&#8211;quiet</code></p>
<dd> hide the output</p>
<dt><code>-v</code> <code>&#8211;verbose</code></p>
<dd> show loaded files</p>
<dt><code>-f</code> <code>&#8211;force</code></p>
<dd> reload package if already loaded</p>
<dt><code>-n</code> <code>&#8211;dry-run</code></p>
<dd> don&#8217;t save the image after loading</p>
<dt><code>-t</code> <code>&#8211;test</code></p>
<dd> run SUnit tests if available</p>
<dt><code>&#8211;start</code>[=<i>ARG</i>]</p>
<dd> start the package and keep running the image</p>
<dt><code>-i</code> <code>&#8211;rebuild-image</code></p>
<dd> load into a newly-created image</p>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></p>
<dd> load into the specified image</p>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></p>
<dd> use the specified kernel directory</p>
<dt><code>-h</code> <code>&#8211;help</code></p>
<dd> show this message</p>
<dt><code>&#8211;version</code></p>
<dd> print version information and exit</dl>
