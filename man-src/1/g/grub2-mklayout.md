<h2>NAME</h2>
<p> <code>grub-mklayout</code> &#8212; Generate a GRUB keyboard layout file. </p>
<h2>SYNOPSIS</h2>
<p> <code>grub-mklayout</code> [-i | &#8211;input=<i>FILE</i>] [-o | &#8211;output=<i>FILE</i>]</p>
<dl>
<dt>
<dd> [-v | &#8211;verbose] </p>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>grub-mklayout</code> generates a GRUB keyboard layout description which corresponds with the Linux console layout description given as input. </p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;input=<i>FILE</i></p>
<dd> Use <i>FILE</i> as the input. The default value is the standard input device. </p>
<dt>&#8211;output=<i>FILE</i></p>
<dd> Use <i>FILE</i> as the output. The default value is the standard output device. </p>
<dt>&#8211;verbose</p>
<dd> Print verbose messages. </p>
</dl>
