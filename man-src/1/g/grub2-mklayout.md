<h2>NAME</h2>
<p> <code>grub-mklayout</code> &#8212; Generate a GRUB keyboard layout file. </p>
<p> <code>grub-mklayout</code> [-i | &#8211;input=<i>FILE</i>] [-o | &#8211;output=<i>FILE</i>]</p>
<dl>
<dt>
</dt><dd> [-v | &#8211;verbose] </dd>
</dl>
<p> <code>grub-mklayout</code> generates a GRUB keyboard layout description which corresponds with the Linux console layout description given as input. </p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;input=<i>FILE</i></dt>
<dd> Use <i>FILE</i> as the input. The default value is the standard input device. </dd>
<dt>&#8211;output=<i>FILE</i></dt>
<dd> Use <i>FILE</i> as the output. The default value is the standard output device. </dd>
<dt>&#8211;verbose</dt>
<dd> Print verbose messages. </dd>
</dl>
