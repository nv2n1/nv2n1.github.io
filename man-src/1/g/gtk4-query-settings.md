<h2 class="name">NAME</h2>
<p> gtk4-query-settings &#8211; Print name and value of GTK settings </p>
<h2>SYNOPSIS</h2>
<pre>
<code>gtk4-query-settings</code> [PATTERN]
</pre>
<h2>DESCRIPTION</h2>
<p> <code>gtk4-query-settings</code> prints both name and value of all properties available in the <code>GtkSettings</code> class. Optionally, you can filter which properties to list by specifying a <code>PATTERN</code>. </p>
