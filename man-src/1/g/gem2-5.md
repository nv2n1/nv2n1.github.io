<p>gem2.5 &#8211; frontend to RubyGems, the Ruby package manager </p>
<h2>Synopsis</h2>
<p>gem2.5 command [arguments&#8230;] [options&#8230;]</p>
<h2>Description</h2>
<p>gem2.5 is the frontend to RubyGems, the standard package manager for Ruby. This is a basic help message containing pointers to more information. </p>
<p> Further help:</p>
<dl>
<dd><code>gem2.5 help commands</code> list all gem2.5 commands</p>
<dd><code>gem2.5 help examples</code> shows some examples of usage</p>
<dd><code>gem2.5 help COMMAND</code> show help on COMMAND, (e.g. &#8216;gem2.5 help install&#8217;)</dl>
<h2>Links</h2>
<p><a rel="nofollow" href="http://rubygems.org/">http://rubygems.org/</a></p>
<h2>Examples</h2>
<p>gem2.5 install rake gem2.5 list &#8211;local gem2.5 build package.gemspec gem2.5 help install</p>
