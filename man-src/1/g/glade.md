<h2 class="name">NAME</h2>
<p> glade &#8211; Create GTK+ user interfaces </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>glade </code><code>[OPTION&#8230;]</code><code>[FILE&#8230;]</code></dl>
<h2>DESCRIPTION</h2>
<p> <code>glade</code></p>
<dd>is a tool to create or edit user interfaces for GTK+ or GNOME applications. It saves the user interface descriptions in xml files which can be read by the GtkBuilder API that is part of GTK+.</p>
<h2>OPTIONS</h2>
<p> The following options can be specified: </p>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show help options.</dl>
<p> <code>&#8211;help-all</code></p>
<dl>
<dt>
<dd> Show all help options.</dl>
<p> <code>&#8211;help-debug</code></p>
<dl>
<dt>
<dd> Show Glade debug options.</dl>
<p> <code>&#8211;help-gtk</code></p>
<dl>
<dt>
<dd> Show GTK+ options.</dl>
<p> <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Output version information and exit.</dl>
<p> <code>&#8211;without-devhelp</code></p>
<dl>
<dt>
<dd> Disable devhelp integration.</dl>
<p> <code>&#8211;display=DISPLAY</code></p>
<dl>
<dt>
<dd> X display to use.</dl>
