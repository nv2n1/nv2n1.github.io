<dl>
<dt> <code>glade </code><code>[OPTION&#8230;]</code><code>[FILE&#8230;]</code></dt></dl>
<p> <code>glade</code></p>
<dd>is a tool to create or edit user interfaces for GTK+ or GNOME applications. It saves the user interface descriptions in xml files which can be read by the GtkBuilder API that is part of GTK+.</dd>
<h2>OPTIONS</h2>
<p> The following options can be specified: </p>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
</dt><dd> Show help options.</dd></dl>
<p> <code>&#8211;help-all</code></p>
<dl>
<dt>
</dt><dd> Show all help options.</dd></dl>
<p> <code>&#8211;help-debug</code></p>
<dl>
<dt>
</dt><dd> Show Glade debug options.</dd></dl>
<p> <code>&#8211;help-gtk</code></p>
<dl>
<dt>
</dt><dd> Show GTK+ options.</dd></dl>
<p> <code>&#8211;version</code></p>
<dl>
<dt>
</dt><dd> Output version information and exit.</dd></dl>
<p> <code>&#8211;without-devhelp</code></p>
<dl>
<dt>
</dt><dd> Disable devhelp integration.</dd></dl>
<p> <code>&#8211;display=DISPLAY</code></p>
<dl>
<dt>
</dt><dd> X display to use.</dd></dl>
