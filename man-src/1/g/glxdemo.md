<h2 class="name">NAME</h2>
<p> glxdemo &#8211; a demonstration of the GLX functions </p>
<h2>SYNOPSIS</h2>
<p> <code>glxdemo</code></p>
<h2>DESCRIPTION</h2>
<p> The <i>glxdemo</i> program shows how to use the GLX functions in order to create an OpenGL program running on top of an X server. This program is most useful when studied in its source code form.</p>
