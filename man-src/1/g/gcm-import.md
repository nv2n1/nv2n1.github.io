<h2 class="name">NAME</h2>
<p> gcm-import &#8211; GNOME Color Manager Import Tool </p>
<h2>SYNOPSIS</h2>
<p> <code>gcm-import</code> [ <code>&#8211;verbose</code> ] </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>gcm-import</code> command. </p>
<p> <code>gcm-import</code> allows you to import ICC files supplied by vendors.</p>
