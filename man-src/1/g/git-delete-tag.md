<h2>NAME</h2>
<p> <code>git-delete-tag</code> &#8211; Delete tags</p>
<h2>SYNOPSIS</h2>
<p> <code>git-delete-tag</code> &lt;tagname&gt;</p>
<h2>DESCRIPTION</h2>
<p> Deletes local and remote tag named &lt;tagname&gt;.</p>
<h2>OPTIONS</h2>
<p> &lt;tagname&gt; </p>
<p> The name of the tag to delete. If multiple tags are provided, then they will all be deleted.</p>
<h2>EXAMPLES</h2>
<pre>
$ git delete-tag 0.0.1
$ git delete-tag 0.0.1 0.0.2
</pre>
