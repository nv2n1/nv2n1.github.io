<h2>NAME</h2>
<p> gnome-phone-manager &#8211; Manage your mobile phone</p>
<h2>USAGE</h2>
<p> <code>gnome-phone-manager</code> [&#8211;identify&nbsp;<wbr>&lt;baddr&gt;] [&#8211;config] [-d|&#8211;debug]] [&#8211;display=DISPLAY]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>gnome-phone-manager</code> command. </p>
<p> <code>gnome-phone-manager</code> is a program created to allow you to control aspects of your mobile phone from your GNOME 2 desktop.</p>
<dl>
<dt>Current features include:</p>
<dd> <code>&#8211;</code> Runs in the background; indicates status on the panel notification area,<br />
 <code>&#8211;</code> Display on-screen alert when text message (SMS) arrives,<br />
 <code>&#8211;</code> Text message (SMS) sending facility,<br />
 <code>&#8211;</code> Evolution Addressbook integration.</dl>
<h2>OPTIONS</h2>
<h3>Help Options:</h3>
<dl>
<dt><code>-?, &#8211;help</code></p>
<dd> Show help options</p>
<dt><code>&#8211;help-all</code></p>
<dd> Show all help options</p>
<dt><code>&#8211;help-gtk</code></p>
<dd> Show GTK+ Options</p>
<dt><code>&#8211;help-gst</code></p>
<dd> Show GStreamer Options</dl>
<h3>Application Options:</h3>
<dl>
<dt><code>&#8211;identify</code><i> &lt;bdaddr&gt;</i></p>
<dd> Show model name of the device with Bluetooth address <i>bdaddr</i>.</p>
<dt><code>&#8211;config</code></p>
<dd> Write the configuration file for gnokii debugging</p>
<dt><code>-d, &#8211;debug</code></p>
<dd> Enable debug</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</dl>
