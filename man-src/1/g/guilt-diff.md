<h2 class="name">NAME</h2>
<p> guilt-diff &#8211; Outputs various diffs </p>
<h2>SYNOPSIS</h2>
<p> <i>guilt-diff</i> [-z] [&lt;path&gt;&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> Outputs top-most applied diff and any additional changes in the working directory to standard output.</p>
<h2>OPTIONS</h2>
<p> -z</p>
<dl>
<dt>
<dd> Output a interdiff against the top-most applied patch. This should produce the same diff as &quot;guilt-new -f foo&quot;.</dl>
<p> &lt;path&gt;&#8230;</p>
<dl>
<dt>
<dd> Restrict diff output to a given set of files.</dl>
