<h2 class="name">NAME</h2>
<p> gnome-keyring &#8211; The gnome-keyring commandline tool </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gnome-keyring import </code><code>FILE</code></p>
<dt> <code>gnome-keyring certificate-exception</code></p>
<dt> <code>gnome-keyring version</code></dl>
<h2>DESCRIPTION</h2>
<dd>The <code>gnome-keyring</code> tool can be used to interact with gnome-keyring-daemon.</p>
<h2>COMMANDS</h2>
<p> The following commands can be used: </p>
<p> <code>import </code><code>FILE</code></p>
<dl>
<dt>
<dd> Import keys or certificates from a PKCS file.</dl>
<p> <code>certificate-exception</code></p>
<dl>
<dt>
<dd> Not implemented.</dl>
<p> <code>version</code></p>
<dl>
<dt>
<dd> Print the version number and exit.</dl>
