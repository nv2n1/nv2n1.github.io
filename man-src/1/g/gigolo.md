<h2 class="name">NAME</h2>
<p> Gigolo &#8212; a simple frontend to easily connect to remote filesystems with GIO/GVfs </p>
<h2>SYNOPSIS</h2>
<p> <code>gigolo</code> [<code>option</code>]</p>
<h2>DESCRIPTION</h2>
<p> Gigolo is a frontend to easily manage connections to local and remote filesystems using GIO/GVfs. It allows you to quickly mount a remote filesystem and manage bookmarks to such. </p>
<p> Homepage: <a rel="nofollow" href="http://www.uvena.de/gigolo/">http://www.uvena.de/gigolo/</a></p>
<h2>OPTIONS</h2>
<p> If called without any arguments, the Gigolo main window is shown.</p>
<dl>
<dt><code>-a</code>, <code>&#8211;auto-connect</code></p>
<dd> Connect all bookmarks which are marked as &#8216;auto connect&#8217; and exit.</p>
<dt><code>-i</code>, <code>&#8211;new-instance</code></p>
<dd> Don&#8217;t find and show an already running instance of Gigolo, instead force opening a new instance.</p>
<dt><code>-l</code>, <code>&#8211;list-schemes</code></p>
<dd> Print a list of supported URI schemes and exit.</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Be verbose and print some more information to stdout.</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Show version information.</p>
<dt><code>-?</code>, <code>&#8211;help</code></p>
<dd> Show help information and exit.</dl>
<p> Gigolo supports all generic GTK options, a list is available on the help screen.</p>
