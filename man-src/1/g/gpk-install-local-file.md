<h2>NAME</h2>
<p> gpk-install-local-file &#8211; GNOME PackageKit Local File Helper</p>
<h2>SYNOPSIS</h2>
<p> <code>gpk-install-local-file</code> [ <code>&#8211;verbose</code> ] [ <code>filename</code> ]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>gpk-install-local-file</code> command. </p>
<p> <code>gpk-install-local-file</code> allows you to install a local package file such as an rpm or deb file.</p>
