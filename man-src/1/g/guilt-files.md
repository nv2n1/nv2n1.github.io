<h2 class="name">NAME</h2>
<p> guilt-files &#8211; Print the list of files that the topmost patch changes </p>
<h2>SYNOPSIS</h2>
<p> <i>guilt-files</i> [-v] [-a] [-l]</p>
<h2>DESCRIPTION</h2>
<p> Print the list of files that the topmost patch changes.</p>
<h2>OPTIONS</h2>
<p> -v</p>
<dl>
<dt>
<dd> Verbose output</dl>
<p> -a</p>
<dl>
<dt>
<dd> List all files in all applied patches</dl>
<p> -l</p>
<dl>
<dt>
<dd> Add patch name to the output</dl>
