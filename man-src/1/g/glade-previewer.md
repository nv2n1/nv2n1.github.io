<h2 class="name">NAME</h2>
<p> glade-previewer &#8211; Preview glade user interface definitions </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>glade-previewer </code><code>[OPTION&#8230;]</code></dl>
<h2>DESCRIPTION</h2>
<p> <code>glade-previewer</code></p>
<dd>is a tool that can load and display a User Interface that has been defined with glade. glade itself uses glade-previewer, but it can also be used as a standalone utility.</p>
<h2>OPTIONS</h2>
<p> The following options can be specified: </p>
<p> <code>-f FILENAME</code>, <code>&#8211;filename=FILENAME</code></p>
<dl>
<dt>
<dd> Name of the file to preview.</dl>
<p> <code>-t TOPLEVEL</code>, <code>&#8211;toplevel=TOPLEVEL</code></p>
<dl>
<dt>
<dd> Name of the toplevel to preview.</dl>
<p> <code>-l</code>, <code>&#8211;listen</code></p>
<dl>
<dt>
<dd> Listen on standard input.</dl>
<p> <code>-v</code>, <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Output version information and exit.</dl>
<p> <code>&#8211;display=DISPLAY</code></p>
<dl>
<dt>
<dd> X display to use.</dl>
<p> One of the <code>&#8211;filename</code> or <code>&#8211;listen</code> options has to be specified.</p>
