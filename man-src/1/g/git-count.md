<h2>NAME</h2>
<p> <code>git-count</code> &#8211; Show commit count</p>
<h2>SYNOPSIS</h2>
<p> <code>git-count</code> [&#8211;all]</p>
<h2>DESCRIPTION</h2>
<p> Show commit count.</p>
<h2>OPTIONS</h2>
<p> &#8211;all </p>
<p> Show commit count details.</p>
<h2>EXAMPLES</h2>
<p> Output commit total:</p>
<dl>
<dt>
<dd>
<pre>
$ git count
total 1844
</pre>

<dd></dl>
