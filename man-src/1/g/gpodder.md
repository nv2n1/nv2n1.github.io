<h2>NAME</h2>
<p> gpodder &#8211; A Media aggregator and Podcast catcher</p>
<h2>SYNOPSIS</h2>
<p> <code>gpodder</code> [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> gPodder enables you to subscribe to RSS feeds and download podcast episodes from these feeds. </p>
<p> Downloaded podcasts can either be synchronized to portable MP3 players (including iPods) or played back on the user&#8217;s desktop. </p>
<p> See <a href="/docs/linux/man/1-gpo/">gpo</a>(1) for the command-line interface.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;version</code></p>
<dd> show program&#8217;s version number and exit</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Print debugging output to stdout</p>
<dt><code>-m</code>, <code>&#8211;maemo</code></p>
<dd> Start the Maemo 4 user interface</p>
<dt><code>-f</code>, <code>&#8211;fremantle</code></p>
<dd> Start the Maemo 5 user interface</p>
<dt><code>-s</code> URL, <code>&#8211;subscribe</code>=<i>URL</i></p>
<dd> Subscribe to the given URL </p>
</dl>
