<h2>NAME</h2>
<p> gst-doc &#8211; GNU Smalltalk documentation generator</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> gst-doc [ flag &#8230; ] class &#8230;</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></p>
<dd> look for classes in the given image</p>
<dt><code>-p</code> <code>&#8211;package</code>=<i>PKG</i></p>
<dd> look for classes in the given package</p>
<dt><code>-f</code> <code>&#8211;file</code>=<i>FILE</i></p>
<dd> look for classes in the given file</p>
<dt> <code>-n</code> <code>&#8211;namespace</code>=<i>NAMESP</i> load files in the given namespace</p>
<dt><code>-o</code> <code>&#8211;output</code>=<i>FILE</i></p>
<dd>
<dd>emit documentation in the given file (default=stdout)</p>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></p>
<dd> use the specified kernel directory</p>
<dt><code>-F</code> <code>&#8211;output-format</code>=<i>KIND</i></p>
<dd> use the given publisher (HTML or default=Texinfo)</p>
<dt><code>-h</code> <code>&#8211;help</code></p>
<dd> show this message</p>
<dt><code>-v</code> <code>&#8211;verbose</code></p>
<dd> print extra information while processing</p>
<dt><code>&#8211;version</code></p>
<dd> print version information and exit</dl>
<h2>SEE ALSO</h2>
<p> The full documentation for <code>gst-doc</code> is maintained as a Texinfo manual. If the <code>info</code> and <code>gst-doc</code> programs are properly installed at your site, the command</p>
<dl>
<dt>
<dd> <code>info gst</code></dl>
<p> should give you access to the complete manual. </p>
