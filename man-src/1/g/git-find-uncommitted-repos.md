<h2 class="name">NAME</h2>
<p> git-find-uncommitted-repos &#8211; Recursively list repositories with uncommitted changes </p>
<h2>SYNOPSIS</h2>
<p> <code>git-find-uncommitted-repos</code> [<i>DIR</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> Recursively list repositories with uncommitted changes.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>,<code>&nbsp;<wbr>&#8211;help</code></p>
<dd> show usage information.</p>
<dt><code>-v</code>,<code>&nbsp;<wbr>&#8211;verbose</code></p>
<dd> print more details about what is being done.</p>
<dt><code>-u</code>,<code>&nbsp;<wbr>&#8211;untracked</code></p>
<dd> count untracked files as &#8216;uncommitted&#8217;</p>
<dt><i>DIR</i>&#8230;</p>
<dd> the directories to scan, or current directory if none is specified.</dl>
