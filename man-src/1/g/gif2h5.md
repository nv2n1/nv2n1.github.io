<h2>NAME</h2>
<p> gif2h5 &#8211; Converts a GIF file to an HDF5 file.</p>
<h2>SYNOPSIS</h2>
<p> <code>gif2h5</code> gif_file h5_file</p>
<h2>DESCRIPTION</h2>
<p> gif2h5 accepts as input the GIF file gif_file and produces the HDF5 file h5_file as output.</p>
