<p>gst-stats-1.0 &#8211; print info gathered from a GStreamer log file </p>
<h2>Synopsis</h2>
<p><code>gst-stats-1.0 [OPTION&#8230;] FILE</code></p>
<h2>Description</h2>
<p><i>gst-stats-1.0</i> is a tool that analyses information collected from a log file based on <i>GStreamer tracer messages. </i></p>
<h2>Options</h2>
<p><i>gst-stats-1.0</i> accepts the following arguments and options:</p>
<dl>
<dt><code>FILE</code></p>
<dd>Name of a file</p>
<dt><code>-h, &#8211;help</code></p>
<dd>Print help synopsis and available FLAGS</p>
<dt><code>&#8211;gst-help-all</code></p>
<dd>Show all help options</p>
<dt><code>&#8211;gst-help-gst</code></p>
<dd>Show FIGstreamer options</dl>
