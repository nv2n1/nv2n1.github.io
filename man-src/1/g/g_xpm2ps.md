<h2>NAME</h2>
<p> xpm2ps &#8211; convert XPM (XPixelMap) file to postscript </p>
<p> <code>VERSION 4.0.1</code></p>
<h2>SYNOPSIS</h2>
<p> <code>xpm2ps</code> <code>-f</code><i> root.xpm </i> <code>-f2</code><i> root2.xpm </i> <code>-di</code><i> ps.m2p </i> <code>-do</code><i> out.m2p </i> <code>-o</code><i> plot.eps </i> <code>-xpm</code><i> root.xpm </i> <code>-[no]h</code><i></i> <code>-nice</code><i> int </i> <code>-[no]w</code><i></i> <code>-[no]frame</code><i></i> <code>-title</code><i> enum </i> <code>-[no]yonce</code><i></i> <code>-legend</code><i> enum </i> <code>-diag</code><i> enum </i> <code>-size</code><i> real </i> <code>-bx</code><i> real </i> <code>-by</code><i> real </i> <code>-rainbow</code><i> enum </i> <code>-gradient</code><i> vector </i> <code>-skip</code><i> int </i> <code>-[no]zeroline</code><i></i> <code>-legoffset</code><i> int </i> <code>-combine</code><i> enum </i> <code>-cmin</code><i> real </i> <code>-cmax</code><i> real </i></p>
<h2>DESCRIPTION</h2>
<p> xpm2ps makes a beautiful color plot of an XPixelMap file. Labels and axis can be displayed, when they are supplied in the correct matrix format. Matrix data may be generated by programs such as do_dssp, g_rms or g_mdmat. </p>
<p> Parameters are set in the <code> m2p</code> file optionally supplied with <code> -di</code>. Reasonable defaults are provided. Settings for the y-axis default to those for the x-axis. Font names have a defaulting hierarchy: titlefont &#8211; legendfont; titlefont &#8211; (xfont &#8211; yfont &#8211; ytickfont) &#8211; xtickfont, e.g. setting titlefont sets all fonts, setting xfont sets yfont, ytickfont and xtickfont. </p>
<p> When no <code> m2p</code> file is supplied, many setting are set by command line options. The most important option is <code> -size</code> which sets the size of the whole matrix in postscript units. This option can be overridden with the <code> -bx</code> and <code> -by</code> options (and the corresponding parameters in the <code> m2p</code> file), which set the size of a single matrix element. </p>
<p> With <code> -f2</code> a 2nd matrix file can be supplied, both matrix files will be read simultaneously and the upper left half of the first one (<code> -f</code>) is plotted together with the lower right half of the second one (<code> -f2</code>). The diagonal will contain values from the matrix file selected with <code> -diag</code>. Plotting of the diagonal values can be suppressed altogether by setting <code> -diag</code> to <code> none</code>. In this case, a new color map will be generated with a red gradient for negative numbers and a blue for positive. If the color coding and legend labels of both matrices are identical, only one legend will be displayed, else two separate legends are displayed. With <code> -combine</code> an alternative operation can be selected to combine the matrices. The output range is automatically set to the actual range of the combined matrix. This can be overridden with <code> -cmin</code> and <code> -cmax</code>. </p>
<p> <code> -title</code> can be set to <code> none</code> to suppress the title, or to <code> ylabel</code> to show the title in the Y-label position (alongside the Y-axis). </p>
<p> With the <code> -rainbow</code> option dull grey-scale matrices can be turned into attractive color pictures. </p>
<p> Merged or rainbowed matrices can be written to an XPixelMap file with the <code> -xpm</code> option.</p>

&nbsp;<wbr>Display frame, ticks, labels, title and legend </p>

&nbsp;<wbr>Show title at:&nbsp;<wbr><code>&nbsp;<wbr>top</code>,&nbsp;<wbr><code>&nbsp;<wbr>once</code>,&nbsp;<wbr><code>&nbsp;<wbr>ylabel</code>&nbsp;<wbr>or&nbsp;<wbr><code>&nbsp;<wbr>none</code> </p>

&nbsp;<wbr>Show y-label only once </p>
<p> <code>-legend</code><i> enum</i><code> both</code><br />
&nbsp;<wbr>Show legend:&nbsp;<wbr><code>&nbsp;<wbr>both</code>,&nbsp;<wbr><code>&nbsp;<wbr>first</code>,&nbsp;<wbr><code>&nbsp;<wbr>second</code>&nbsp;<wbr>or&nbsp;<wbr><code>&nbsp;<wbr>none</code> </p>
<p> <code>-diag</code><i> enum</i><code> first</code><br />
&nbsp;<wbr>Diagonal:&nbsp;<wbr><code>&nbsp;<wbr>first</code>,&nbsp;<wbr><code>&nbsp;<wbr>second</code>&nbsp;<wbr>or&nbsp;<wbr><code>&nbsp;<wbr>none</code> </p>
<p> <code>-size</code><i> real</i><code> 400 </code><br />
&nbsp;<wbr>Horizontal size of the matrix in ps units </p>
<p> <code>-bx</code><i> real</i><code> 0 </code><br />
&nbsp;<wbr>Element x-size, overrides -size&nbsp;<wbr>(also y-size when -by is not set) </p>

<p> <code>-gradient</code><i> vector</i><code> 0 0 0</code><br />
