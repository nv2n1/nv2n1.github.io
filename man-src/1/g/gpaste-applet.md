<h2>NAME</h2>
<p> GPaste-Applet &#8211; An applet for the GPaste clipboard manager </p>
<h2>SYNOPSIS</h2>
<p> <code>gpaste applet</code> </p>
<h2>APPLET USAGE</h2>
<dl>
<dt><code>Clic on the icon</code></p>
<dd> Display the history, the first element, in bold, is the one in the clipboard </p>
<dt><code>Clic on an item</code></p>
<dd> Select the item </p>
<dt><code>Clic on the cross next to an item</code></p>
<dd> Delete the item </p>
<dt><code>Settings</code></p>
<dd> Launch the configuration tool </p>
<dt><code>Empty history</code></p>
<dd> Empty the history </p>
<dt><code>About</code></p>
<dd> Display the about dialog </p>
<dt><code>Quit</code></p>
<dd> Exit the applet </p>
</dl>
