<h2>NAME</h2>
<p> GPaste-Applet &#8211; An applet for the GPaste clipboard manager </p>
<h2>SYNOPSIS</h2>
<p> <code>gpaste applet</code> </p>
<h2>APPLET USAGE</h2>
<dl>
<dt><code>Clic on the icon</code></dt>
<dd> Display the history, the first element, in bold, is the one in the clipboard </dd>
<dt><code>Clic on an item</code></dt>
<dd> Select the item </dd>
<dt><code>Clic on the cross next to an item</code></dt>
<dd> Delete the item </dd>
<dt><code>Settings</code></dt>
<dd> Launch the configuration tool </dd>
<dt><code>Empty history</code></dt>
<dd> Empty the history </dd>
<dt><code>About</code></dt>
<dd> Display the about dialog </dd>
<dt><code>Quit</code></dt>
<dd> Exit the applet </dd>
</dl>
