<h2>NAME</h2>
<p> gst-sunit &#8211; unit testing tool for GNU Smalltalk</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> gst-sunit [ flag &#8230; ] class.tests &#8230;</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-q</code> <code>&#8211;quiet</code></p>
<dd> hide the output</p>
<dt><code>-v</code> <code>&#8211;verbose</code></p>
<dd> show passed tests</p>
<dt><code>-f</code> <code>&#8211;file</code>=<i>FILE</i></p>
<dd> load file before running subsequent tests</p>
<dt><code>-p</code> <code>&#8211;package</code>=<i>PACKAGE</i></p>
<dd> load package and run its tests</p>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></p>
<dd> run tests on the specified image file</p>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></p>
<dd> use the specified kernel directory</p>
<dt><code>-h</code> <code>&#8211;help</code></p>
<dd> show this message and exit</p>
<dt><code>&#8211;version</code></p>
<dd> print version information and exit</dl>
