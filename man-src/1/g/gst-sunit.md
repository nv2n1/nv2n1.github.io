<h2>NAME</h2>
<p> gst-sunit &#8211; unit testing tool for GNU Smalltalk</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
</dt><dd> gst-sunit [ flag &#8230; ] class.tests &#8230;</dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-q</code> <code>&#8211;quiet</code></dt>
<dd> hide the output</dd>
<dt><code>-v</code> <code>&#8211;verbose</code></dt>
<dd> show passed tests</dd>
<dt><code>-f</code> <code>&#8211;file</code>=<i>FILE</i></dt>
<dd> load file before running subsequent tests</dd>
<dt><code>-p</code> <code>&#8211;package</code>=<i>PACKAGE</i></dt>
<dd> load package and run its tests</dd>
<dt><code>-I</code> <code>&#8211;image-file</code>=<i>FILE</i></dt>
<dd> run tests on the specified image file</dd>
<dt><code>&#8211;kernel-dir</code>=<i>PATH</i></dt>
<dd> use the specified kernel directory</dd>
<dt><code>-h</code> <code>&#8211;help</code></dt>
<dd> show this message and exit</dd>
<dt><code>&#8211;version</code></dt>
<dd> print version information and exit</dd></dl>
