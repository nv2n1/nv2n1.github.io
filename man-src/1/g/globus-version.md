<h2 class="name">NAME</h2>
<p> globus-version &#8211; Display the Globus Toolkit version </p>
<h2>SYNOPSIS</h2>
<p> <code>globus-version</code> [OPTIONS]</p>
<h2>DESCRIPTION</h2>
<p> The <code>globus-version</code> command displays the installed Globus version. </p>
<p> The full set of command-line options to <code>globus-version</code> are: </p>
<p> <code>-help</code></p>
<dl>
<dt>
<dd> Print help and exit</dl>
<p> <code>-full</code></p>
<dl>
<dt>
<dd> Show expanded version information</dl>
<p> <code>-dirt</code></p>
<dl>
<dt>
<dd> Show source code branch and timestamp</dl>
