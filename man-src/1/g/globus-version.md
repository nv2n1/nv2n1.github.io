<p> <code>globus-version</code> [OPTIONS]</p>
<p> The <code>globus-version</code> command displays the installed Globus version. </p>
<p> The full set of command-line options to <code>globus-version</code> are: </p>
<p> <code>-help</code></p>
<dl>
<dt>
</dt><dd> Print help and exit</dd></dl>
<p> <code>-full</code></p>
<dl>
<dt>
</dt><dd> Show expanded version information</dd></dl>
<p> <code>-dirt</code></p>
<dl>
<dt>
</dt><dd> Show source code branch and timestamp</dd></dl>
