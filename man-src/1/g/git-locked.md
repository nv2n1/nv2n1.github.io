<h2>NAME</h2>
<p> <code>git-locked</code> &#8211; ls files that have been locked</p>
<h2>SYNOPSIS</h2>
<p> <code>git-locked</code></p>
<h2>DESCRIPTION</h2>
<p> List local files that have been locked</p>
<h2>EXAMPLES</h2>
<pre>
$ git lock config/database.yml
$ git locked
config/database.yml
</pre>
