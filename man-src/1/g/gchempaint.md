<h2 class="name">NAME</h2>
<p> gchempaint &#8211; 2D chemical structures editor for the GNOME2 desktop </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gchempaint</code> [<code>OPTIONS</code>&#8230;] [<i>FILE</i>&#8230;]</dl>
<h2>DESCRIPTION</h2>
<p> <code>gchempaint</code></p>
<dd>is a 2D chemical structures editor for the GNOME2 desktop. It is a multi document application. You can read different file types with <code>gchempaint</code>. E.g. chemical/x-cml, chemical/x-mdl-molfile, chemical/x-mdl-sdfile or chemical/x-pdb. But be aware, that you will maybe loose 3D-data from these file-formats.</p>
<h2>OPTIONS</h2>
<p> Currently the following options are supported: </p>
<p> <code>-e</code>, <code>&#8211;edit-residue</code></p>
<dl>
<dt>
<dd> Open residues dialog.</dl>
<p> <code>-?</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show application help options.</dl>
<p> <code>&#8211;help-all</code>, <code>&#8211;help-*</code></p>
<dl>
<dt>
<dd> Print all or just a group of help options. These options are not documented here. Instead see <code><a href="/docs/linux/man/7-gtk-options/">gtk-options</a></code>(7) and <code><a href="/docs/linux/man/7-gnome-options/">gnome-options</a></code>(7).</dl>
<p> <code>-v</code>, <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Print gchempaint version information.</dl>
