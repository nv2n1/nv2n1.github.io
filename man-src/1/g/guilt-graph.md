<h2 class="name">NAME</h2>
<p> guilt-graph &#8211; Create a patch dependency graph </p>
<h2>SYNOPSIS</h2>
<p> <i>guilt-graph</i> [&lt;patchname&gt;]</p>
<h2>DESCRIPTION</h2>
<p> Create a <a href="/docs/linux/man/1-dot/">dot</a>(1) directed graph showing the dependencies between applied patches.</p>
<h2>OPTIONS</h2>
<p> &lt;patchname&gt;</p>
<dl>
<dt>
<dd> Instead of starting with the topmost applied patch, start with &lt;patchname&gt;.</dl>
