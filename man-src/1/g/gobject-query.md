<h2 class="name">NAME</h2>
<p> gobject-query &#8211; display a tree of types </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gobject-query</code> froots [OPTION&#8230;]</p>
<dt> <code>gobject-query</code> tree [OPTION&#8230;]</dl>
<h2>DESCRIPTION</h2>
<p> <code>gobject-query</code></p>
<dd>is a small utility that draws a tree of types. </p>
<p> <code>gobject-query</code> takes a mandatory argument that specifies whether it should iterate over the fundamental types or print a type tree.</p>
<h2>COMMANDS</h2>
<p> <code>froots</code></p>
<dl>
<dt>
<dd> iterate over fundamental roots</dl>
<p> <code>tree</code></p>
<dl>
<dt>
<dd> print type tree</dl>
<h2>OPTIONS</h2>
<p> <code>-r</code> <i>TYPE</i></p>
<dl>
<dt>
<dd> specify the root type</dl>
<p> <code>-n</code></p>
<dl>
<dt>
<dd> don&#8217;t descend type tree</dl>
<p> <code>-b</code> <i>STRING</i></p>
<dl>
<dt>
<dd> specify indent string</dl>
<p> <code>-i</code> <i>STRING</i></p>
<dl>
<dt>
<dd> specify incremental indent string</dl>
<p> <code>-s</code> <i>NUMBER</i></p>
<dl>
<dt>
<dd> specify line spacing</dl>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Print brief help and exit.</dl>
<p> <code>-v</code>, <code>&#8211;version</code></p>
<dl>
<dt>
<dd> Print version and exit.</dl>
