<h2>NAME</h2>
<p> <code>GRFMerge</code> &#8211; A tool to apply a binary GRF diff, generated by GRFDiff, to a GRF.</p>
<h2>SYNOPSIS</h2>
<p> <code>grfmerge</code> [-<code>hlyv</code> ] <i>GRD-file</i> [<i>GRF-file</i> ] </p>
<p> Change sprites in the GRF file to the new ones from the GRD file. If the GRF file is not specified, GRFMerge will modify the one which the GRD file was generated from.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code></p>
<dd> Display the help message.</p>
<dt><code>-l</code></p>
<dd> Only show which sprites the GRD file contains, don&#8217;t integrate them.</p>
<dt><code>-y</code></p>
<dd> Answer &#8216;y&#8217; to all questions.</p>
<dt><code>-v</code></p>
<dd> Display the version.</dl>
