<h2 class="name">NAME</h2>
<p> gtester-report &#8211; test report formatting utility </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gtester-report</code> [option&#8230;] [gtester-log]</dl>
<h2>DESCRIPTION</h2>
<p> <code>gtester-report</code></p>
<dd>is a script which converts the XML output generated by gtester into HTML. </p>
<p> Since GLib 2.62, <code>gtester-report</code> is deprecated. Use TAP for reporting test results instead, and feed it to the test harness provided by your build system.</p>
<h2>OPTIONS</h2>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> print help and exit</dl>
<p> <code>-v</code>, <code>&#8211;version</code></p>
<dl>
<dt>
<dd> print version information and exit</dl>
<p> <code>-s</code>, <code>&#8211;subunit</code></p>
<dl>
<dt>
<dd> Output subunit. Needs python-subunit.</dl>
