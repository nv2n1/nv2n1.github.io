<h2 class="name">NAME</h2>
<p> <code>gnome-session-remmina</code> &#8211; GNOME Shell session script for Remmina </p>
<h2>DESCRIPTION</h2>
<p> <code>gnome-session-remmina</code> This script is part of the Remmina kiosk mode. If you have a freedesktop compliant Login Manager, a Remmina kiosk mode will be added in the list of available sessions.</p>
