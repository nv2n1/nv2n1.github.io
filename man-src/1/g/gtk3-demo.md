<h2 class="name">NAME</h2>
<p> gtk3-demo &#8211; Demonstrate GTK+ widgets </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gtk3-demo</code> [&#8211;help] [&#8211;list] [&#8211;run&nbsp;<wbr><i>EXAMPLE</i>] [&#8211;autoquit]</dl>
<h2>DESCRIPTION</h2>
<p> <code>gtk3-demo</code></p>
<dd>is a collection of examples. Its purpose is to demonstrate many GTK+ widgets in a form that is useful to application developers. </p>
<p> The application shows the source code for each example, as well as other used resources, such as ui files and icons.</p>
<h2>OPTIONS</h2>
<p> The following options are understood: </p>
<p> <code>-h</code>, <code>&#8211;help</code></p>
<dl>
<dt>
<dd> Show help options</dl>
<p> <code>&#8211;list</code></p>
<dl>
<dt>
<dd> List available examples.</dl>
<p> <code>-run </code><i>EXAMPLE</i></p>
<dl>
<dt>
<dd> Run the named example. Use <code>&#8211;list</code> to see the available examples.</dl>
<p> <code>&#8211;autoquit</code></p>
<dl>
<dt>
<dd> Quit after a short timeout. This is intended for use with <code>&#8211;run</code>, e.g. when profiling.</dl>
