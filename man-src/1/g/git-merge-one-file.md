<h2 class="name">NAME</h2>
<p> git-merge-one-file &#8211; The standard helper program to use with git-merge-index </p>
<h2>SYNOPSIS</h2>
<pre>
<i>git merge-one-file</i>
</pre>
<h2>DESCRIPTION</h2>
<p> This is the standard helper program to use with <i>git merge-index</i> to resolve a merge after the trivial merge done with <i>git read-tree -m</i>.</p>
<h2>GIT</h2>
<p> Part of the <code><a href="/docs/linux/man/1-git/">git</a></code>(1) suite </p>
