<h2 class="name">NAME</h2>
<p> glacier2router &#8211; The Glacier2 router daemon.</p>
<h2>SYNOPSIS</h2>
<p> glacier2router [options] </p>
<h2>DESCRIPTION</h2>
<p> Glacier2 is a lightweight firewall traversal solution for Ice applications. Full documentation for Glacier2 is available online at:<br />
 &quot;<a rel="nofollow" href="http://doc.zeroc.com/display/Ice/Glacier2">http://doc.zeroc.com/display/Ice/Glacier2</a>&quot;. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>
 Displays help message. </p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> Displays the Ice version. </p>
<dt><code>&#8211;nowarn</code></p>
<dd>
 Suppress warnings. </p>
<dt><code>&#8211;daemon</code></p>
<dd>
 Run as a daemon. </p>
<dt><code>&#8211;pidfile</code> <code>FILE</code></p>
<dd>
 Write process ID into FILE. </p>
<dt><code>&#8211;noclose</code></p>
<dd>
 Do not close open file descriptors. </p>
<dt><code>&#8211;nochdir</code></p>
<dd>
 Do not change the current working directory. </p>
</dl>
