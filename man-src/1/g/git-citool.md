<h2 class="name">NAME</h2>
<p> git-citool &#8211; Graphical alternative to git-commit </p>
<h2>SYNOPSIS</h2>
<pre>
<i>git citool</i>
</pre>
<h2>DESCRIPTION</h2>
<p> A Tcl/Tk based graphical interface to review modified files, stage them into the index, enter a commit message and record the new commit onto the current branch. This interface is an alternative to the less interactive <i>git commit</i> program. </p>
<p> <i>git citool</i> is actually a standard alias for git gui citool. See <code><a href="/docs/linux/man/1-git-gui/">git-gui</a></code>(1) for more details.</p>
<h2>GIT</h2>
<p> Part of the <code><a href="/docs/linux/man/1-git/">git</a></code>(1) suite </p>
