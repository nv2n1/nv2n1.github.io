<h2 class="name">NAME</h2>
<p> gnome-documents &#8211; A document manager application for GNOME </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>gnome-documents</code></dl>
<h2>DESCRIPTION</h2>
<p> <code>gnome-documents</code></p>
<dd>is a document manager application designed to work with GNOME 3. You can view your local and online documents, search through them, print or mark them as favorites. It&#8217;s included in the default set of core applications since GNOME 3.2.</p>
