<h2 class="name">NAME</h2>
<p> grub-render-label &#8211; generate a .disk_label for Apple Macs. </p>
<h2>SYNOPSIS</h2>
<p> <code>grub-render-label</code> [<i>,OPTION/</i>&#8230;] [<i>,OPTIONS/</i>]</p>
<h2>DESCRIPTION</h2>
<p> Render Apple .disk_label.</p>
<dl>
<dt><code>-b</code>, <code>&#8211;bgcolor</code>=<i>,COLOR/</i></p>
<dd> use COLOR for background</p>
<dt><code>-c</code>, <code>&#8211;color</code>=<i>,COLOR/</i></p>
<dd> use COLOR for text</p>
<dt><code>-f</code>, <code>&#8211;font</code>=<i>,FILE/</i></p>
<dd> use FILE as font (PF2).</p>
<dt><code>-i</code>, <code>&#8211;input</code>=<i>,FILE/</i></p>
<dd> read text from FILE.</p>
<dt><code>-o</code>, <code>&#8211;output</code>=<i>,FILE/</i></p>
<dd> set output filename. Default is STDOUT</p>
<dt><code>-t</code>, <code>&#8211;text</code>=<i>,STRING/</i></p>
<dd> set the label to render</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> print verbose messages.</p>
<dt>-?, <code>&#8211;help</code></p>
<dd> give this help list</p>
<dt><code>&#8211;usage</code></p>
<dd> give a short usage message</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> print program version</dl>
<p> Mandatory or optional arguments to long options are also mandatory or optional for any corresponding short options.</p>
