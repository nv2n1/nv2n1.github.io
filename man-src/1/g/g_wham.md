<h2>NAME</h2>
<p> g_wham &#8211; weighted histogram analysis after umbrella sampling </p>
<p> <code>VERSION 4.0.1</code></p>
<h2>SYNOPSIS</h2>
<p> <code>g_wham</code> <code>-o</code><i> profile.xvg </i> <code>-hist</code><i> histo.xvg </i> <code>-[no]h</code><i></i> <code>-nice</code><i> int </i> <code>-[no]w</code><i></i> <code>-[no]xvgr</code><i></i> <code>-min</code><i> real </i> <code>-max</code><i> real </i> <code>-bins</code><i> int </i> <code>-[no]prof</code><i></i> <code>-temp</code><i> real </i> <code>-[no]flip</code><i></i> <code>-tol</code><i> real </i></p>
<h2>DESCRIPTION</h2>
<p> This is an analysis program that implements the Weighted Histogram Analysis Method (WHAM). It is intended to analyze .pdo files generated by mdrun using umbrella sampling tocreate a potential of mean force (PMF). The options are </p>
<p> <code> -o</code> name of the PMF output file </p>
<p> <code> -hist</code> name of the histograms output file </p>
<p> <code> -min</code> minimum coordinate to use </p>
<p> <code> -max</code> maximum coordinate to use </p>
<p> Note: the program will throw out any data that is outside of min &#8211; max. The program will output the true min and max after completion, so you can use these values the next time. or you can use: </p>
<p> <code> -noprof</code> only calculate min and max </p>
<p> <code> -bins</code> number of bins to use in calculation </p>
<h2>FILES</h2>
<p> <code>-o</code><i> profile.xvg</i> <code>Output</code><br />
&nbsp;<wbr>xvgr/xmgr file&nbsp;<wbr> </p>
<p> <code>-hist</code><i> histo.xvg</i> <code>Output</code><br />
&nbsp;<wbr>xvgr/xmgr file&nbsp;<wbr> </p>

<p> <code>-[no]h</code><i>no </i><br />
&nbsp;<wbr>Print help info and quit </p>

<p> <code>-min</code><i> real</i><code> 0 </code><br />
&nbsp;<wbr>Minimum coordinate in profile </p>
<p> <code>-max</code><i> real</i><code> 0 </code><br />
&nbsp;<wbr>Maximum coordinate in profile </p>
<p> <code>-bins</code><i> int</i><code> 100</code><br />
&nbsp;<wbr>Number of bins in profile </p>
<p> <code>-[no]prof</code><i>yes </i><br />
&nbsp;<wbr>Only calculate min and max </p>
<p> <code>-temp</code><i> real</i><code> 298 </code><br />
&nbsp;<wbr>Temperature </p>
<p> <code>-[no]flip</code><i>no </i><br />
&nbsp;<wbr>Combine halves of profile </p>
