<h2>NAME</h2>
<p> <code>git-show-merged-branches</code> &#8211; Show merged branches</p>
<h2>SYNOPSIS</h2>
<p> <code>git-show-merged-branches</code></p>
<h2>DESCRIPTION</h2>
<p> Show all branches merged in to current HEAD.</p>
<h2>EXAMPLES</h2>
<pre>
$ git show-merged-branches
</pre>
