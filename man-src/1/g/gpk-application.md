<h2>NAME</h2>
<p> gpk-application &#8211; GNOME PackageKit Package Application</p>
<h2>SYNOPSIS</h2>
<p> <code>gpk-application</code> [ <code>&#8211;verbose</code> ]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>gpk-application</code> command. </p>
<p> <code>gpk-application</code> allows you to install and remove packages.</p>
