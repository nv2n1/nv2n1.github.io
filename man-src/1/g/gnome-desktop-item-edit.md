<h2>NAME</h2>
<p> gnome-desktop-item-edit &#8212; tool to edit .desktop file</p>
<h2>SYNOPSIS</h2>
<p> <code>gnome-desktop-item-edit</code> [<code>&#8211;create-new </code>] [<code>&#8211;help </code>]</p>
<h2>DESCRIPTION</h2>
<p> <code>gnome-desktop-item-edit</code> allows you to edit .desktop file.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;create-new</code></p>
<dd> Create new file in the given directory.</p>
<dt><code>&#8211;help</code></p>
<dd> Display help</dl>
