<h2 class="name">NAME</h2>
<p> guilt-add &#8211; Add a file to git and guilt </p>
<h2>SYNOPSIS</h2>
<p> <i>guilt-add</i> &lt;file&gt;&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Adds the files specified to git using git-add making it available to guilt.</p>
<h2>OPTIONS</h2>
<p> &lt;files&gt;</p>
<dl>
<dt>
<dd> Files to add</dl>
<h2>EXAMPLES</h2>
<p> Create and add a new file example.c </p>
<dl>
<dt>
<dd>
<pre>
$ touch example.c
$ guilt-add example.c
</pre>
</dl>
