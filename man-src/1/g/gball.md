<h2>NAME</h2>
<p> GBall &#8211; The Console Ball and Racket Game</p>
<h2>SYNOPSIS</h2>
<p> <code>gball [OPTIONS]</code></p>
<h2>DESCRIPTION</h2>
<p> GBall is a simple yet nice implementation of the well known ball and racket game. It is designed to run under the GNU/Linux console (including terminal emulators). The aim of the game is simple: control your racket and move it around to bounce the ball and hit all the bricks. If the ball hits a wall, it will bounce. If it fell down the screen without bouncing on the racket, you lose. The game includes 10 levels with an option to play levels randomly, and a high score board. </p>
<p> The racket is controlled by using the arrows keys, or the &quot;a&quot; and &quot;d&quot; keys as shown below. </p>

<h2>OPTIONS</h2>
<dl>
<dt>-h, &#8211;help</p>
<dd> Print command line help </p>
<dt>-v, &#8211;version</p>
<dd> Display program version and exit </p>
<dt>-l, &#8211;level n</p>
<dd> Start playing from level &#8216;n&#8217; </p>
</dl>
<h2>FILES</h2>
<p> <i>~/.gball</i> Special file used to store highscores information. </p>
