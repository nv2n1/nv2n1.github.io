<h2 class="name">NAME</h2>
<p> genior &#8211; Utility for creating a stringified IOR</p>
<h2>SYNOPSIS</h2>
<p> <code>genior</code> [-x] &lt;Type ID&gt; &lt;hostname&gt; &lt;port number&gt; [object key] </p>
<h2>DESCRIPTION</h2>
<p> genior generates a stringified object reference from the arguments supplied to it. If an object key argument isn&#8217;t supplied, it will use an object key generated by omniORB2. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-x</code></p>
<dd> Interpret the object key as a hexadecimal value. This value should begin with &quot;0x&quot; </p>
</dl>
