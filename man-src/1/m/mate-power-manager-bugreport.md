<h2>NAME</h2>
<p> mate-power-manager-bugreport &#8211; collect system information for mate power manager bugreports</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-power-manager-bugreport</code></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>mate-power-manager-bugreport</code> command. </p>
<p> <code>mate-power-manager-bugreport</code> is a helper script to gather system information for proper mate-power-manager bug reports.</p>
<h2>OPTIONS</h2>
<p> This script does not have any known options.</p>
