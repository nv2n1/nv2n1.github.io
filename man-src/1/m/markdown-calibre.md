<h2 class="name">NAME</h2>
<p> <code> markdown-calibre </code>&#8211; markdown tool for calibre </p>
<h2>USAGE</h2>
<p> markdown-calibre INPUTFILE [options]</p>
<h2>DESCRIPTION</h2>
<h2>MAIN OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit <code>-f</code> OUTPUT_FILE, <code>&#8211;file</code>=OUTPUT_FILE write output to OUTPUT_FILE</p>
<dt><code>-e</code> ENCODING, <code>&#8211;encoding</code>=ENCODING</p>
<dd> encoding for input and output files</p>
<dt><code>-q</code>, <code>&#8211;quiet</code></p>
<dd> suppress all messages <code>-v</code>, <code>&#8211;verbose</code> print info messages</p>
<dt><code>-s</code> SAFE_MODE, <code>&#8211;safe</code>=SAFE_MODE</p>
<dd> same mode (&#8216;replace&#8217;, &#8216;remove&#8217; or &#8216;escape&#8217; user&#8217;s HTML tag)</p>
<dt><code>&#8211;noisy</code></p>
<dd> print debug messages <code>-x</code> EXTENSION, <code>&#8211;extension</code>=EXTENSION load extension EXTENSION </p>
</dl>
