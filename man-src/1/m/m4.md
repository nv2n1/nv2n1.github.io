<h2 class="name">NAME</h2>
<p> m4 &#8211; macro processor </p>
<h2>SYNOPSIS</h2>
<p> <code>m4</code> [<i>,OPTION/</i>]&#8230; [<i>,FILE/</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Process macros in FILEs. If no FILE or if FILE is `-&#8216;, standard input is read. </p>
<p> Mandatory or optional arguments to long options are mandatory or optional for short options too.</p>
<h3>Operation modes:</h3>
<dl>
<dt><code>&#8211;help</code></dt>
<dd> display this help and exit</dd>
<dt><code>&#8211;version</code></dt>
<dd> output version information and exit</dd>
<dt><code>-E</code>, <code>&#8211;fatal-warnings</code></dt>
<dd> once: warnings become errors, twice: stop execution at first error</dd>
<dt><code>-i</code>, <code>&#8211;interactive</code></dt>
<dd> unbuffer output, ignore interrupts</dd>
<dt><code>-P</code>, <code>&#8211;prefix-builtins</code></dt>
<dd> force a `m4_&#8217; prefix to all builtins</dd>
<dt><code>-Q</code>, <code>&#8211;quiet</code>, <code>&#8211;silent</code></dt>
<dd> suppress some warnings for builtins</dd>
<dt><code>&#8211;warn-macro-sequence</code>[=<i>,REGEXP/</i>]</dt>
<dd> warn if macro definition matches REGEXP,</dd>
<dt>
</dt><dd> default \$\({[^}]*}\|[0-9][0-9]+\)</dd>
<dt><code>-W</code>, <code>&#8211;word-regexp</code>=<i>,REGEXP/</i></dt>
<dd> use REGEXP for macro name syntax</dd></dl>
<h3>Preprocessor features:</h3>
<dl>
<dt><code>-D</code>, <code>&#8211;define=NAME</code>[=<i>,VALUE/</i>]</dt>
<dd> define NAME as having VALUE, or empty</dd>
<dt><code>-I</code>, <code>&#8211;include</code>=<i>,DIRECTORY/</i></dt>
<dd> append DIRECTORY to include path</dd>
<dt><code>-s</code>, <code>&#8211;synclines</code></dt>
<dd> generate `#line NUM &quot;FILE&quot;&#8217; lines</dd>
<dt><code>-U</code>, <code>&#8211;undefine</code>=<i>,NAME/</i></dt>
<dd> undefine NAME</dd></dl>
<h3>Limits control:</h3>
<dl>
<dt><code>-g</code>, <code>&#8211;gnu</code></dt>
<dd> override <code>-G</code> to re-enable GNU extensions</dd>
<dt><code>-G</code>, <code>&#8211;traditional</code></dt>
<dd> suppress all GNU extensions</dd>
<dt><code>-H</code>, <code>&#8211;hashsize</code>=<i>,PRIME/</i></dt>
<dd> set symbol lookup hash table size [509]</dd>
<dt><code>-L</code>, <code>&#8211;nesting-limit</code>=<i>,NUMBER/</i></dt>
<dd> change nesting limit, 0 for unlimited [0]</dd></dl>
<h3>Frozen state files:</h3>
<dl>
<dt><code>-F</code>, <code>&#8211;freeze-state</code>=<i>,FILE/</i></dt>
<dd> produce a frozen state on FILE at end</dd>
<dt><code>-R</code>, <code>&#8211;reload-state</code>=<i>,FILE/</i></dt>
<dd> reload a frozen state from FILE at start</dd></dl>
<h3>Debugging:</h3>
<dl>
<dt><code>-d</code>, <code>&#8211;debug</code>[=<i>,FLAGS/</i>]</dt>
<dd> set debug level (no FLAGS implies `aeq&#8217;)</dd>
<dt><code>&#8211;debugfile</code>[=<i>,FILE/</i>]</dt>
<dd> redirect debug and trace output to FILE (default stderr, discard if empty string)</dd>
<dt><code>-l</code>, <code>&#8211;arglength</code>=<i>,NUM/</i></dt>
<dd> restrict macro tracing size</dd>
<dt><code>-t</code>, <code>&#8211;trace</code>=<i>,NAME/</i></dt>
<dd> trace NAME when it is defined</dd></dl>
<h3>FLAGS is any of:</h3>
<dl>
<dt>a</dt>
<dd> show actual arguments</dd>
<dt>c</dt>
<dd> show before collect, after collect and after call</dd>
<dt>e</dt>
<dd> show expansion</dd>
<dt>f</dt>
<dd> say current input file name</dd>
<dt>i</dt>
<dd> show changes in input files</dd>
<dt>l</dt>
<dd> say current input line number</dd>
<dt>p</dt>
<dd> show results of path searches</dd>
<dt>q</dt>
<dd> quote values as necessary, with a or e flag</dd>
<dt>t</dt>
<dd> trace for all macro calls, not only traceon&#8217;ed</dd>
<dt>x</dt>
<dd> add a unique macro call id, useful with c flag</dd>
<dt>V</dt>
<dd> shorthand for all of the above flags</dd></dl>
<p> If defined, the environment variable `M4PATH&#8217; is a colon-separated list of directories included after any specified by `-I&#8217;. </p>
<p> Exit status is 0 for success, 1 for failure, 63 for frozen file version mismatch, or whatever value was passed to the m4exit macro.</p>
