<h2 class="name">NAME</h2>
<p> m4 &#8211; macro processor </p>
<h2>SYNOPSIS</h2>
<p> <code>m4</code> [<i>,OPTION/</i>]&#8230; [<i>,FILE/</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Process macros in FILEs. If no FILE or if FILE is `-&#8216;, standard input is read. </p>
<p> Mandatory or optional arguments to long options are mandatory or optional for short options too.</p>
<h3>Operation modes:</h3>
<dl>
<dt><code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> output version information and exit</p>
<dt><code>-E</code>, <code>&#8211;fatal-warnings</code></p>
<dd> once: warnings become errors, twice: stop execution at first error</p>
<dt><code>-i</code>, <code>&#8211;interactive</code></p>
<dd> unbuffer output, ignore interrupts</p>
<dt><code>-P</code>, <code>&#8211;prefix-builtins</code></p>
<dd> force a `m4_&#8217; prefix to all builtins</p>
<dt><code>-Q</code>, <code>&#8211;quiet</code>, <code>&#8211;silent</code></p>
<dd> suppress some warnings for builtins</p>
<dt><code>&#8211;warn-macro-sequence</code>[=<i>,REGEXP/</i>]</p>
<dd> warn if macro definition matches REGEXP,</p>
<dt>
<dd> default \$\({[^}]*}\|[0-9][0-9]+\)</p>
<dt><code>-W</code>, <code>&#8211;word-regexp</code>=<i>,REGEXP/</i></p>
<dd> use REGEXP for macro name syntax</dl>
<h3>Preprocessor features:</h3>
<dl>
<dt><code>-D</code>, <code>&#8211;define=NAME</code>[=<i>,VALUE/</i>]</p>
<dd> define NAME as having VALUE, or empty</p>
<dt><code>-I</code>, <code>&#8211;include</code>=<i>,DIRECTORY/</i></p>
<dd> append DIRECTORY to include path</p>
<dt><code>-s</code>, <code>&#8211;synclines</code></p>
<dd> generate `#line NUM &quot;FILE&quot;&#8217; lines</p>
<dt><code>-U</code>, <code>&#8211;undefine</code>=<i>,NAME/</i></p>
<dd> undefine NAME</dl>
<h3>Limits control:</h3>
<dl>
<dt><code>-g</code>, <code>&#8211;gnu</code></p>
<dd> override <code>-G</code> to re-enable GNU extensions</p>
<dt><code>-G</code>, <code>&#8211;traditional</code></p>
<dd> suppress all GNU extensions</p>
<dt><code>-H</code>, <code>&#8211;hashsize</code>=<i>,PRIME/</i></p>
<dd> set symbol lookup hash table size [509]</p>
<dt><code>-L</code>, <code>&#8211;nesting-limit</code>=<i>,NUMBER/</i></p>
<dd> change nesting limit, 0 for unlimited [0]</dl>
<h3>Frozen state files:</h3>
<dl>
<dt><code>-F</code>, <code>&#8211;freeze-state</code>=<i>,FILE/</i></p>
<dd> produce a frozen state on FILE at end</p>
<dt><code>-R</code>, <code>&#8211;reload-state</code>=<i>,FILE/</i></p>
<dd> reload a frozen state from FILE at start</dl>
<h3>Debugging:</h3>
<dl>
<dt><code>-d</code>, <code>&#8211;debug</code>[=<i>,FLAGS/</i>]</p>
<dd> set debug level (no FLAGS implies `aeq&#8217;)</p>
<dt><code>&#8211;debugfile</code>[=<i>,FILE/</i>]</p>
<dd> redirect debug and trace output to FILE (default stderr, discard if empty string)</p>
<dt><code>-l</code>, <code>&#8211;arglength</code>=<i>,NUM/</i></p>
<dd> restrict macro tracing size</p>
<dt><code>-t</code>, <code>&#8211;trace</code>=<i>,NAME/</i></p>
<dd> trace NAME when it is defined</dl>
<h3>FLAGS is any of:</h3>
<dl>
<dt>a</p>
<dd> show actual arguments</p>
<dt>c</p>
<dd> show before collect, after collect and after call</p>
<dt>e</p>
<dd> show expansion</p>
<dt>f</p>
<dd> say current input file name</p>
<dt>i</p>
<dd> show changes in input files</p>
<dt>l</p>
<dd> say current input line number</p>
<dt>p</p>
<dd> show results of path searches</p>
<dt>q</p>
<dd> quote values as necessary, with a or e flag</p>
<dt>t</p>
<dd> trace for all macro calls, not only traceon&#8217;ed</p>
<dt>x</p>
<dd> add a unique macro call id, useful with c flag</p>
<dt>V</p>
<dd> shorthand for all of the above flags</dl>
<p> If defined, the environment variable `M4PATH&#8217; is a colon-separated list of directories included after any specified by `-I&#8217;. </p>
<p> Exit status is 0 for success, 1 for failure, 63 for frozen file version mismatch, or whatever value was passed to the m4exit macro.</p>
