<h2>NAME</h2>
<p> mkdocs &#8211; Create HTML documentation from markdown sources</p>
<h2>SYNOPSIS</h2>
<p> mkdocs [build|gh-deploy|new|serve] {options}</p>
<h2>DESCRIPTION</h2>
<p> MkDocs is a fast and simple way to create a website from source files written in Markdown, and configured with a YAML configuration file, the documentation can be hosted anywhere, even in free hosting services like Read the Docs and GitHub Pages.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;help</code></p>
<dd> display help and exit</p>
<dt><code>new</code></p>
<dd> <code>&lt;name&gt;</code> create a new project with under the <i>&lt;name&gt;</i> directory</p>
<dt><code>build</code></p>
<dd> make a HTML website from sources</p>
<dt><code>serve</code></p>
<dd> start a server to view in real time the documentation</p>
<dt><code>gh-deploy</code></p>
<dd> commit changes to a GitHub Page</dl>
