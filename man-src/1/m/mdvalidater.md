<h2>NAME</h2>
<p> mdvalidator &#8211; Validate XML Documents against the ECMA Documentation Schema</p>
<h2>SYNOPSIS</h2>
<p> <code>mdvalidator</code> PROVIDER [FILES]+</p>
<h2>DESCRIPTION</h2>
<p> <i>mdvalidator</i> has been obsoleted by <code><a href="/docs/linux/man/1-mdoc/">mdoc</a></code>(1). See the <code><a href="/docs/linux/man/1-mdoc-validate/">mdoc-validate</a></code>(1) man page. </p>
<p> <i>mdvalidator</i> is a program that validates the specified <i>FILES</i> against the ECMA Documentation Schema. </p>
<p> The Schema also supports the <i>index.xml</i> and <i>namespace-name.xml</i> files generated by <i>monodocer</i> , so all output produced by <i>monodocer</i> can be validated. </p>
<h2>PROVIDER</h2>
<p> The following providers are supported:</p>
<dl>
<dt><i>ecma</i></p>
<dd> Validate the input files against the ECMA Documentation Schema.</dl>
<h2>EXAMPLES</h2>
<p> To validate the <i>monodocer</i> output stored within a directory (and all ECMA documentation within all sub-directories, recursively), use: </p>
<pre>
        mdvalidator ecma /path/to/ecma/docs
</pre>
