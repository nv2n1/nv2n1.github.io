<h2 class="name">NAME</h2>
<p>&nbsp;mtx-fonts &#8211; ConTeXt Font Database Management </p>
<h2>SYNOPSIS</h2>
<p> <code>mtxrun &#8211;script fonts [</code> <i>OPTIONS &#8230;</i> <code>] [</code> <i>FILENAMES</i> <code>]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>ConTeXt Font Database Management</code></p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;convert</code></p>
<dd> save open type font in raw table</p>
<dt><code>&#8211;unpack</code></p>
<dd> save a tma file in a more readable format</p>
<dt><code>&#8211;reload</code></p>
<dd> generate new font database (use &#8211;force when in doubt)</p>
<dt><code>&#8211;reload</code></p>
<dd> &#8211;simple:generate luatex-fonts-names.lua (not for context!)</p>
<dt><code>&#8211;list</code></p>
<dd> &#8211;name: list installed fonts, filter by name [&#8211;pattern]</p>
<dt><code>&#8211;list</code></p>
<dd> &#8211;spec: list installed fonts, filter by spec [&#8211;filter]</p>
<dt><code>&#8211;list</code></p>
<dd> &#8211;file: list installed fonts, filter by file [&#8211;pattern]</p>
<dt><code>&#8211;pattern=str</code></p>
<dd> filter files using pattern</p>
<dt><code>&#8211;filter=list</code></p>
<dd> key-value pairs</p>
<dt><code>&#8211;all</code></p>
<dd> show all found instances (combined with other flags)</p>
<dt><code>&#8211;info</code></p>
<dd> give more details</p>
<dt><code>&#8211;trackers=list</code></p>
<dd> enable trackers</p>
<dt><code>&#8211;statistics</code></p>
<dd> some info about the database</p>
<dt><code>&#8211;names</code></p>
<dd> use name instead of unicodes</p>
<dt><code>&#8211;cache=str</code></p>
<dd> use specific cache (otl or otf)</dl>
