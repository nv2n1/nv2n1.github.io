<h2 class="name">NAME</h2>
<p> meanbias &#8211; CCD bias frame composition</p>
<h2>SYNOPSIS</h2>
<p> <code>meanbias </code><i>[options] source_file &#8230;</i> </p>
<h2>DESCRIPTION</h2>
<p> The meanbias program compose a set of bias-fields and performs one bias field called master-bias. It applies the robust median algorithm to the corresponding pixels to get the resulting value. Applying this function, you can achieve high quality correction frame to reduce the noise. </p>
<p> All source frames must be in FITS format and of same dimensions. Frames of the same exposition duration should be used. The output file is in FITS format too. </p>
<h2>OPTIONS</h2>
<p> The list of input files is usualy entered directly on the command line. If you are going to process a large set of files, you can use the question marks (for a single chars) or the asterisk (for a strings of chars). </p>
<p> The alternate way, how to process a large set of files, is the batch mode. In this mode, the list of input files is read from a given file or from the standard input. The directory file, for example named <i>dirfile</i>, must have the text format and the names of the input files are written on the separate lines. If the files are placed not in the current working directory, you have to specify the proper path in full or shortened form. </p>
<dl>
<dt><code>@</code><i>dirfile</i></p>
<dd> The program will read the list of source files from specified file.</p>
<dt><code>@</code></p>
<dd> The program will read the list of source files from stdin.</p>
<dt><code>out=</code><i>file</i>, <code>-o</code><i>file</i></p>
<dd> Name of the output file. Default is <i>meanbias.fts</i>.</p>
<dt><code>&#8211;help</code></p>
<dd> Prints short help.</p>
<dt><code>&#8211;license</code></p>
<dd> Prints the license.</p>
<dt><code>&#8211;version</code></p>
<dd> Prints the program name and its version.</p>
<dt><code>&#8211;quiet</code></p>
<dd> Quiet mode &#8212; inhibits the screen printouts.</p>
<dt><code>&#8211;debug</code></p>
<dd> Debug mode &#8212; extends the screen printouts. </p>
</dl>
<h2>EXAMPLES</h2>
<p> The following command computes mean of frames: &#8216;test1.fts&#8217;, &#8216;test2.fts&#8217; a &#8216;test3.fts&#8217; and stores the output frame fo &#8216;meanbias.fts&#8217;.</p>
<dl>
<dt>
<dd> <code>meanbias test1.fts test2.fts test3.fts</code> </p>
</dl>
<h2>EXIT STATUS</h2>
<p> meanbias returns a zero exist status if it succeeds to convert all specified file. Otherwise, it will stop immediately when the error occurs and returns nonzero code. </p>
