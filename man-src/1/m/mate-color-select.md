<h2>NAME</h2>
<p> mate-color-select &#8211; Select a color from a palette or from screen</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-color-select [&lt;gtk-options&gt;]</code></p>
<h2>DESCRIPTION</h2>
<p> The <i>mate-color-select</i> program is a tool to pick a color from a color palette or from screen. It is not meant to be used on its own, but as a MATE Desktop helper application.</p>
<h2>OPTIONS</h2>
<p> The <code>mate-color-select</code> tool supports all known GTK options, but has no options of its own.</p>
<h2>BUGS</h2>
<p> If you find bugs in the <i>mate-color-select</i> program, please report these on <a rel="nofollow" href="https://github.com/mate-desktop/mate-desktop/issues.">https://github.com/mate-desktop/mate-desktop/issues.</a> </p>
