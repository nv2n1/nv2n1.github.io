<h2 class="name">NAME</h2>
<p> mscore &#8211; Full featured WYSIWYG score editor </p>
<h2>SYNOPSIS</h2>
<p> <code>mscore</code> [<i>options</i>]<i>scorefile</i></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>mscore</code> command. </p>
<p> <code>MuseScore</code> is a free WYSIWYG music score typesetter for Linux, licenced under GNU GPL. Features:<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>WYSIWYG, notes are entered on a&nbsp;<wbr>&quot;virtual note sheet&quot;<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>unlimited number of staves<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>up to four voices/staff<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>easy and fast note entry with mouse, keyboard or midi<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>integrated sequencer and FluidSynth software synthesizer<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>import and export of MusicXml and standard midifiles&nbsp;<wbr>(SMF)<br />
&nbsp;<wbr>&nbsp;<wbr>*&nbsp;<wbr>platform independent code for Linux, Windows and Mac</p>
<h2>OPTIONS</h2>
<p> A summary of options is included below.</p>
<dl>
<dt><code>-v</code></p>
<dd> Show version of program.</p>
<dt><code>-d</code></p>
<dd> Debug mode.</p>
<dt><code>-s</code></p>
<dd> Disable the synthesizer.</p>
<dt><code>-m</code></p>
<dd> Disable MIDI I/O support.</p>
<dt><code>-i</code></p>
<dd> Dump MIDI input.</p>
<dt><code>-L</code></p>
<dd> Layout debug mode.</p>
<dt><code>-o file</code></p>
<dd> Export to file, format dependent on extension.
</dl>
