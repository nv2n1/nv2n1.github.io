<h2>NAME</h2>
<p> Moe &#8211; manual page for Moe 1.3</p>
<h2>SYNOPSIS</h2>
<p> <code>moe</code> [<i>global-options</i>] [[<i>+line</i>] <i>filename </i>[<i>file-options</i>]]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> GNU Moe &#8211; A powerful and user-friendly text editor.</p>
<dl>
<dt>
<dd> `global-options&#8217; are a mix of editor-options and default file-options. Most long option names have a negative form `&#8211;backup&#8217; `&#8211;no-backup&#8217;.</dl>
<h3>Editor options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> output version information and exit</p>
<dt><code>-b</code>, <code>&#8211;backup</code></p>
<dd> create backup files (default)</p>
<dt><code>-e</code>, <code>&#8211;exit-ask</code></p>
<dd> save-and-close always asks for confirmation</p>
<dt><code>-H</code>, <code>&#8211;smart-home</code></p>
<dd> go home, then go to first non-blank character</p>
<dt><code>-i</code>, <code>&#8211;ignore-case</code></p>
<dd> make search case insensitive by default</p>
<dt><code>-k</code>, <code>&#8211;keep-lines=</code>&lt;n&gt;</p>
<dd> number of lines to keep for PgUp/PgDn</p>
<dt><code>-m</code>, <code>&#8211;max-windows=</code>&lt;n&gt;</p>
<dd> max number of windows to show at once</p>
<dt><code>-n</code>, <code>&#8211;indent-step=</code>&lt;n&gt;</p>
<dd> number of spaces to add when indenting a block</p>
<dt><code>-1</code>, <code>&#8211;orphan</code></p>
<dd> put extra files in orphaned buffers</p>
<dt><code>-s</code>, <code>&#8211;search-wrap</code></p>
<dd> search wraps at end of file</p>
<dt><code>-u</code>, <code>&#8211;auto-unmark</code></p>
<dd> turn off highlighting after block copy or move</p>
<dt><code>-x</code>, <code>&#8211;rectangle</code></p>
<dd> rectangular block mode</dl>
<h3>File options:</h3>
<dl>
<dt><code>-a</code>, <code>&#8211;auto-indent</code></p>
<dd> auto indent</p>
<dt><code>-l</code>, <code>&#8211;lmargin=</code>&lt;col&gt;</p>
<dd> left margin</p>
<dt><code>-r</code>, <code>&#8211;rmargin=</code>&lt;col&gt;</p>
<dd> right margin</p>
<dt><code>-o</code>, <code>&#8211;read-only</code></p>
<dd> file is read-only</p>
<dt><code>-O</code>, <code>&#8211;overwrite</code></p>
<dd> insert mode off</p>
<dt><code>-w</code>, <code>&#8211;word-wrap</code></p>
<dd> word wrap</dl>
