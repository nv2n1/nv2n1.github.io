<h2>Name</h2>
<p> mkmanifest &#8211; makes list of file names and their DOS 8+3 equivalent </p>
<h2>Note of warning</h2>
<p> This manpage has been automatically generated from mtools&#8217;s texinfo documentation, and may not be entirely accurate or complete. See the end of this man page for details. </p>
<h2>Description</h2>
<p> The <tt>mkmanifest</tt> command is used to create a shell script (packing list) to restore Unix filenames. Its syntax is: </p>
<p> <tt>mkmanifest</tt> [ <i>files</i> ] </p>
<p> <tt>Mkmanifest</tt> creates a shell script that aids in the restoration of Unix filenames that got clobbered by the MS-DOS filename restrictions. MS-DOS filenames are restricted to 8 character names, 3 character extensions, upper case only, no device names, and no illegal characters. </p>
<p> The mkmanifest program is compatible with the methods used in <tt>pcomm, arc,</tt> and <tt>mtools</tt> to change perfectly good Unix filenames to fit the MS-DOS restrictions. This command is only useful if the target system which will read the diskette cannot handle VFAT long names. </p>
<h2>Example</h2>
<p> You want to copy the following Unix files to a MS-DOS diskette (using the <tt>mcopy</tt> command). </p>
<p>&nbsp; </p>
<pre>
<code>  very_long_name
  2.many.dots
  illegal:
  good.c
  prn.dev
  Capital
</code></pre>
<p>&nbsp; </p>
<p> <tt>ASCII</tt> converts the names to: </p>
<p>&nbsp; </p>
<pre>
<code>  very_lon
  2xmany.dot
  illegalx
  good.c
  xprn.dev
  capital
</code></pre>
<p>&nbsp; </p>
<p> The command:<br />
&nbsp; </p>
<pre>
<code>mkmanifest very_long_name 2.many.dots illegal: good.c prn.dev Capital &gt;manifest
</code></pre>
<p>&nbsp; would produce the following:<br />
&nbsp; </p>
<pre>
<code>  mv very_lon very_long_name
  mv 2xmany.dot 2.many.dots
  mv illegalx illegal:
  mv xprn.dev prn.dev
  mv capital Capital
</code></pre>
<p>&nbsp; </p>
<p> Notice that &quot;good.c&quot; did not require any conversion, so it did not appear in the output. </p>
<p> Suppose I&#8217;ve copied these files from the diskette to another Unix system, and I now want the files back to their original names. If the file &quot;manifest&quot; (the output captured above) was sent along with those files, it could be used to convert the filenames. </p>
<h2>Bugs</h2>
<p> The short names generated by <tt>mkmanifest</tt> follow the old convention (from mtools-2.0.7) and not the one from Windows 95 and mtools-3.0. </p>
