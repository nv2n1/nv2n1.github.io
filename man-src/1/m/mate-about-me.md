<h2>NAME</h2>
<p> mate-about-me &#8212; is a control center applet. </p>
<h2>SYNOPSIS</h2>
<p> <code>mate-about-me</code> </p>
<h2>DESCRIPTION</h2>
<p> MATE About Me is a control center applet to set user information. </p>
<p> It allows one to change user password and set user avatar image (~/.face file). </p>
