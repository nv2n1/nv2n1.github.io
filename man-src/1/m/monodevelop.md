<h2>NAME</h2>
<p> monodevelop &#8211; Free GNOME Development Environment</p>
<h2>SYNOPSIS</h2>
<p> <code>monodevelop</code> [options] [projectfile]</p>
<h2>DESCRIPTION</h2>
<p> <code>monodevelop</code> Free GNOME Development Environment</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;debug</code></p>
<dd> Run mono in debug mode</p>
<dt><code>&#8211;trace</code></p>
<dd> Run mono in trace mode</p>
<dt><code>&#8211;profile</code></p>
<dd> Run mono in profile mode</p>
<dt><code>&#8211;new-window</code></p>
<dd> force MD to open a new instance instead of passing to a running one. This option is forced if opening a combine.</dl>
<h2>ENVIRONMENT VARIABLES</h2>
<dl>
<dt><code>MONODEVELOP_CONSOLE_LOG_LEVEL</code></p>
<dd> The logging level, possible values are `fatal&#8217;, `error&#8217;, `warn&#8217;, `info&#8217; and `debug&#8217;. The default is to log fatal, error and warn.</p>
<dt><code>MONODEVELOP_CONSOLE_LOG_USE_COLOUR</code></p>
<dd> Use colour in log &#8211; true or false. The default is false.</p>
<dt><code>MONODEVELOP_LOG_FILE</code></p>
<dd> If set, log is written to the specified file.</p>
<dt><code>MONODEVELOP_FILE_LOG_LEVEL</code></p>
<dd> The logging level, possible values are `fatal&#8217;, `error&#8217;, `warn&#8217;, `info&#8217; and `debug&#8217;. Valid only if MONODEVELOP_LOG_FILE is specified. The default is to log fata, error, warn and info. </p>
</dl>
