<h2>NAME</h2>
<p> Mono CIL strip</p>
<h2>SYNOPSIS</h2>
<p> <code>mono-cil-strip assembly [output-assembly]</code></p>
<h2>DESCRIPTION</h2>
<p> mono-cil-strip is a tool which takes an assembly, and empty its method bodies. This is useful to reduce an assembly size when an assembly has already been compiled using Mono&#8217;s Ahead Of Time compiler (AOT), where the CIL code is no longer necessary, but the metadata still is.</p>
