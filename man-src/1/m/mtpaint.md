<h2>NAME</h2>

 mtpaint - A pixel based painting program

<h2>SYNOPSIS</h2>

 mtpaint&nbsp;<wbr>[option]&nbsp;<wbr>[imagefile ...&nbsp;<wbr>]

<h2>DESCRIPTION</h2>

 mtPaint is a <font SIZE="-1">GTK+1/2</font> based painting program designed for creating icons and pixel based artwork. It can edit indexed palette or 24 bit <font SIZE="-1">RGB</font> images and offers painting and palette manipulation tools. Its main file format is <font SIZE="-1">PNG</font>, although it can also handle <font SIZE="-1">JPEG</font>, <font SIZE="-1">GIF</font>, <font SIZE="-1">TIFF</font>, <font SIZE="-1">BMP</font>, <font SIZE="-1">XPM</font>, and <font SIZE="-1">XBM</font> files. Due to its simplicity and lack of dependencies it runs well on GNU/Linux, Windows and older <font SIZE="-1">PC</font> hardware. There is full documentation of mtPaint's features contained in a handbook. If you don't already have this, you can download it from the mtPaint website.

<h2>OPTIONS</h2>

 mtPaint can accept one of the following options: 

 <pre>
  --help        Output usage information
  --version     Output version information
  -s            Grab a screenshot
  -v            Start mtPaint in viewer mode
</pre>
