<h2>NAME</h2>
<p> mate-about &#8211; Learn more about MATE</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-about [&#8211;mate-version]</code></p>
<h2>DESCRIPTION</h2>
<p> The <i>mate-about</i> program is a tool to learn more about MATE and who creates MATE. It contains an introduction about the project, and lists all contributors. </p>
<p> The list of contributors used by <i>mate-about</i> is the list of MATE Foundation members.</p>
<h2>OPTIONS</h2>
<p> The following options are supported:</p>
<dl>
<dt><i>&#8211;mate-version</i></p>
<dd> Output the MATE version instead of running a graphical interface.</dl>
<h2>BUGS</h2>
<p> If you find bugs in the <i>mate-about</i> program, please report these on <a rel="nofollow" href="http://bugzilla.gnome.org.">http://bugzilla.gnome.org.</a> </p>
