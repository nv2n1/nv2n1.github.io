<h2>NAME</h2>
<p> mate-thumbnail-font &#8211; configure MATE network proxy</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-thumbnail-font</code> [<i>-h</i>|<i>-t &lt;TEXT&gt; -s &lt;SIZE&gt;</i>] <i>&lt;FONT_FILE&gt; &lt;OUTPUT_FILE&gt;</i></p>
<h2>DESCRIPTION</h2>
<p> This executable is part of the package &#8216;mate-control-center&#8217;: The MATE Control Center. </p>
<p> <code>mate-thumbnail-font</code> is a command-line tool for creating thumbnails of PCF fonts.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>|<code>&#8211;help</code></p>
<dd> Show some help text.</p>
<dt><code>-t</code> <i>&lt;TEXT&gt;</i>, <code>&#8211;text</code> <i>&lt;TEXT&gt;</i></p>
<dd> Text to thumbnail (default: Aa).</p>
<dt><code>-s</code> <i>&lt;SIZE&gt;</i>, <code>&#8211;size</code> <i>&lt;SIZE&gt;</i></p>
<dd> Font size (default: 64).</dl>
