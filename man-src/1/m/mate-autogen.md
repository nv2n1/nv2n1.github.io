<h2>NAME</h2>
<p> <code>mate-autogen </code>&#8211; generates all makefiles for MATE packages</p>
<h2>SYNOPSIS</h2>
<pre>
<code>mate-autogen</code>
</pre>
<h2>DESCRIPTION</h2>
<p> <code>mate-autogen</code> generates all makefiles for MATE packages </p>
<p> To make use of the common autogen script, create a stub autogen.sh script in your module. Take the example in autogen.sh.example file in mate-common documentation folder</p>
