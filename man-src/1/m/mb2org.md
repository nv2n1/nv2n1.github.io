<h2 class="name">NAME</h2>
<p> createPYMB, readPYBase, readPYMB, mb2org, scel2org &#8211; fcitx Pinyin related tools </p>
<h2>SYNOPSIS</h2>
<p> <code>createPYMB</code> <i>&lt;PinyinFile&gt;</i> <i>&lt;PhraseFile&gt;</i> </p>
<p> <code>readPYBase [</code><i>-b &lt;PinyinMBFile&gt;</i><code>] [</code><i>-h</i><code>]</code> </p>
<p> <code>readPYMB [</code><i>-f &lt;PhraseMBFile&gt;</i><code>] [</code><i>-s</i><code>] [</code><i>-h</i><code>]</code> </p>
<p> <code>mb2org [</code><i>-b &lt;PinyinMBFile&gt;</i><code>] [</code><i>-f &lt;PhraseMBFile&gt;</i><code>] [</code><i>-s</i><code>] [</code><i>-h</i><code>]</code> </p>
<p> <code>scel2org [</code><i>-o &lt;Phrase File&gt;</i><code>] [</code><i>-h</i><code>]</code></p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>-b &lt;PinyinMBFile&gt;</code></p>
<dd> If not specified, it will read system default pybase.mb.</p>
<dt><code>-f &lt;PhraseMBFile&gt;</code></p>
<dd> If not specified, it will read user default PhraseMBFile, <i>which is ~/.config/fcitx/pyusrphrase.mb</i>.</p>
<dt><code>-s</code></p>
<dd> If specified, it will read PhraseMBFile as system format, otherwise will read it as user format.</p>
<dt><code>-h</code></p>
<dd> display help and exit</p>
<dt><code>Pinyin File</code></p>
<dd> Pinyin File is a file with pinyin and one character per line, separated with space. One available file is in the source of fcitx, named <i>gbkpy.org</i>.</p>
<dt><code>Phrase File</code></p>
<dd> Phrase File is a file with full pinyin separated with &#8216; and the corresponding phrase. The default phrase file of fcitx can be downloaded at <a rel="nofollow" href="http://fcitx.googlecode.com/files/pinyin.tar.gz.">http://fcitx.googlecode.com/files/pinyin.tar.gz.</a></p>
<dt><code>Pinyin MB File</code></p>
<dd> Pinyin MB File is the binary format of Pinyin File.</p>
<dt><code>Phrase MB File</code></p>
<dd> Phrase MB File is the binary format of Pinyin File, user&#8217;s history phrase mb file is <i>~/.config/fcitx/pyuserphrase.mb</i>. There is two different format, one is system format which can only generated by <code>createPYMB</code> , and other is user format which can only generated while input with fcitx Pinyin IM.</p>
<dt>Output of createPYMB will be pybase.mb, which is Pinyin MB File, and pyphrase.mb, which is Phrase MB File.</p>
<dd>
<dt>Output of mb2org, readPYBase and readPYMB will be stdout. readPYBase and readPYMB are designed to output more debug message of Pinyin MB File and Phrase MB File. mb2org will output in the format of Phrase File.</p>
<dd>
<dt>scel2org is used for transform Sogou Scel File to Phrase File of fcitx. Output of scel2org will be stdout if <i>-o</i> is not used.</p>
<dd></dl>
