<h2 class="name">NAME</h2>
<p> mkjobtexmf &#8212; Generate a texmf tree for a particular job </p>
<h2>VERSION</h2>
<p> 2011-11-10 v0.8</p>
<h2>SYNOPSIS</h2>
<p> The progam <code>mkjobtexmf</code> runs a program and tries to find the used file names. Two methods are available, option <tt>&quot;-recorder&quot;</tt> of TeX (Web2C) or the program <code>strace</code>. </p>
<p> Then it generates a directory with a texmf tree. It checks the found files and tries sort them in this texmf tree. </p>
<p> It can be used for archiving purposes or to speed up following TeX runs. </p>
<pre>
    mkjobtexmf [options]
</pre>
<p> This runs TeX that can be configured by options. Both methods for getting the used file names are available. </p>
<pre><code>
mkjobtexmf[options]--&lt;cmd&gt;[args]
</code></pre>
<p> The latter form runs program <i>cmd</i> with arguments <i>args</i> instead of TeX. As method only program <code>strace</code> is available. </p>
<p> Options: </p>
<p>    &#8211;jobname &lt;name&gt;       Name of the job (mandatory).<br />
                              Usually this is the TeX file<br />
                              without extension<br />
    &#8211;texname &lt;file&gt;       Input file for TeX. Default is the<br />
                              job name with extension &#8216;.tex&#8217;<br />
    &#8211;texopt &lt;option&gt;      Option for TeX run<br />
    &#8211;destdir &lt;directory&gt;  Destination directory,<br />
                              default is `&lt;jobname&gt;.mjt&#8217;<br />
    &#8211;output               Add also output files<br />
    &#8211;strace               Use strace instead of TeX&#8217;s<br />
                              option -recorder<br />
    &#8211;copy                 Copy files instead of creating<br />
                              symbol links<br />
    &#8211;flat                 Junk paths, do not make directories<br />
                              inside the destination directory<br />
    &#8211;(no)texhash          Run texhash, use &#8211;notexhash for MiKTeX<br />
    &#8211;exclude-ext &lt;ext&gt;    Exclude files with extension &lt;ext&gt;.<br />
    &#8211;cmd-tex &lt;cmd&gt;        Command for the TeX compiler<br />
    &#8211;cmd-kpsewhich &lt;cmd&gt;  Command for kpsewhich<br />
    &#8211;cmd-texhash &lt;cmd&gt;    Command for texhash<br />
    &#8211;cmd-strace &lt;cmd&gt;     Command for strace<br />
    &#8211;verbose              Verbose output<br />
    &#8211;help                 Brief help message<br />
    &#8211;man                  Full documentation<br />
    &#8211;version              Print version identification</p>
<h2>DESCRIPTION</h2>
<p> <code>Running the program</code> </p>
<p> First <code>mkjobtexmf</code> runs a program, usually TeX. The TeX compiler is configured by option <tt>&quot;--cmd-tex&quot;</tt>. Option <tt>&quot;--texname&quot;</tt> can be used, if the file name extension differs from <i>.tex</i>: </p>
<pre>
    mkjobtexmf --jobname foo --texname foo.ltx
</pre>
<p> Even more complicate cases are possible: </p>
<pre><code>
mkjobtexmf-- jobname foo-- texname '\defbc{...}\input{foo}'
</code></pre>
<p> If another program than TeX should be used (dvips, &#8230;), then this program can be given after <tt>&quot;--&quot;</tt>: </p>
<pre>
    mkjobtexmf --jobname foo -- dvips foo
</pre>
<p> <code>File recording</code> </p>
<p> Two methods are available to get the used file names:</p>
<dl>
<dt>Recorder of TeX</p>
<dd> Some TeX distributions (e.g. Web2C) support the option <code>-recorder</code> for its TeX compilers. Then the TeX compiler generates a file with extension <i>.fls</i> that records the used input and output files.</p>
<dt>Program strace</p>
<dd> This program traces system calls and signals. It is used here to log the used files.
</dl>
<p> <code>Analyze and link/copy found files</code> </p>
<p> The result directory <i>jobname.mjt</i> is generated. Inside the result <font SIZE="-1">TEXMF</font> tree is created. Each found file is compared against a list of paths of <font SIZE="-1">TEXMF</font> trees. If a match is found, the file is linked/copied into the <font SIZE="-1">TEXMF</font> tree. The list of paths is generated by program <code>kpsewhich</code>. </p>
<p> If the file cannot be mapped to a <font SIZE="-1">TEXMF</font> tree and the file is a relative file name, then it is directly linked/copied into the result directory <i>jobname.mjt</i>. Absolute file names are not supported and neither paths with links to parent directories. </p>
<p> Symbolic links are created by default. The files are copied if option <tt>&quot;--copy&quot;</tt> is given or symbolic linking is not available.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;</code><code>-jobname</code>=&lt;<i>jobname</i>&gt;</p>
<dd> It is the name of the job. `&lt;<i>jobname</i>&gt;.tex&#8217; serves as default for the TeX file and &lt;<i>jobname</i>&gt; is used for naming various directories and files. See section &#8220;<font SIZE="-1">FILES</font>&#8221;.</p>
<dt><code>&#8211;</code><code>-texname</code>=&lt;<i>name</i>&gt;</p>
<dd> The name of the TeX input file, if it differs from &lt;<i>jobname</i>&gt;.tex.</p>
<dt><code>&#8211;</code><code>-texopt</code>=&lt;<i>opt</i>&gt;</p>
<dd> Additional option for the TeX compiler, examples are <tt>&quot;--ini&quot;</tt> or <tt>&quot;--shell-escape&quot;</tt>. This option can be given more than once.</p>
<dt><code>&#8211;</code><code>-destdir</code>=&lt;<i>directory</i>&gt;</p>
<dd> Specifies the name of the destination directory where the result is collected. As default a directory is generated in the current directory with the job name and extension `.mjt&#8217;.</p>
<dt><code>&#8211;</code><code>-output</code></p>
<dd> Also add output files.</p>
<dt><code>&#8211;</code><code>-strace</code></p>
<dd> Use method with program <code>strace</code>, see &#8220;<font SIZE="-1">DESCRIPTION</font>&#8221;.</p>
<dt><code>&#8211;</code><code>-copy</code></p>
<dd> Files are copied instead of creating symbolic links.</p>
<dt><code>&#8211;</code><code>-flat</code></p>
<dd> Files are linked or copied without path elements. The destination directory will contain a flat list of files or links without directory. </p>
<p> The files `ls-R&#8217; and `aliases&#8217; are ignored.</p>
<dt><code>&#8211;</code><code>-exclude-ext</code>=&lt;<i>ext</i>&gt;</p>
<dd> Files with extension &lt;<i>ext</i>&gt; are excluded. The option can be given several times or a comma separated list of extensions can be used. Examples: </p>
<pre>
    --exclude-ext aux --exclude-ext log --exclude-ext toc
</pre>
<p> is the same as </p>
<pre>
    --exclude-ext aux,log,toc
</pre>
<dt><code>&#8211;</code><code>-(no)texhash</code></p>
<dd> As default the file `ls-R&#8217; is generated in the `texmf&#8217; tree, because this is the file name database that might be used in TeX Live. Because MiKTeX uses a different mechanism, its `texhash&#8217; does not generate the `ls-R&#8217; files and <tt>&quot;--notexhash&quot;</tt> suppresses the call of `texhash&#8217;.</p>
<dt><code>&#8211;</code><code>-cmd-tex</code>=&lt;<i>cmd</i>&gt;</p>
<dd> Command for the TeX compiler. Default is pdflatex.</p>
<dt><code>&#8211;</code><code>-cmd-kpsewhich</code>=&lt;<i>cmd</i>&gt;</p>
<dd> Command for kpsewhich.</p>
<dt><code>&#8211;</code><code>-cmd-texhash</code>=&lt;<i>cmd</i>&gt;</p>
<dd> Command for updating the file name database of the generated texmf tree. Default is texmf.</p>
<dt><code>&#8211;</code><code>-cmd-strace</code>=&lt;<i>cmd</i>&gt;</p>
<dd> Command for strace.</p>
<dt><code>&#8211;</code><code>-verbose</code></p>
<dd> Verbose messages.</p>
<dt><code>&#8211;</code><code>-help</code></p>
<dd> Display help screen.</p>
<dt><code>&#8211;</code>B(-man&gt;</p>
<dd> Print manual page.</p>
<dt><code>&#8211;</code><code>-version</code></p>
<dd> Print version identification and exit.</dl>
<h2>EXAMPLES</h2>
<p> TeX file <i>test.tex</i> using TeX&#8217;s recorder method: </p>
<pre>
    mkjobtexmf --jobname test
</pre>
<p> TeX file <i>test.tex</i> using LaTeX: </p>
<pre>
    mkjobtexmf --jobname test --cmd-tex latex
</pre>
<p> Format generation: </p>
<pre>
    mkjobtexmf --jobname test --texopt -ini --texname pdflatex.ini
</pre>
<p> Example, how the new texmf tree (Linux/bash) can be used: </p>
<pre>
    TEXMF=!!test.mjt/texmf pdflatex test
</pre>
<p> Example for generating a zip archive (Linux/bash): </p>
<pre>
    (cd test.mjt &amp;&amp; zip -9r ../test .)
</pre>
<p> Example for generating a tar archive: </p>
<pre>
    tar cjhvf test.tar.bz2 -C test.mjt .
</pre>
<h2>UNSOLVED ISSUES, CAVEATS, TODOS</h2>
<dl>
<dt>Experimental software</p>
<dd> Options, defaults, how the program works might change in future versions.</p>
<dt><i>texmf.cnf</i></p>
<dd> Currently the method with <code>strace</code> records this files. TeX&#8217;s recorder does not. Useful are <i>texmf.cnf</i> files for variable settings. Because we have just one <font SIZE="-1">TEXMF</font> tree, the path sections should probably rewritten.</p>
<dt>Settings in environment variables</p>
<dd> They are not stored at all.</p>
<dt>Collisions</p>
<dd> The program uses one destination directory and at most one <font SIZE="-1">TEXMF</font> tree for the result. However, the source files can come from different directories and <font SIZE="-1">TEXMF</font> trees. Therefore name collisions are possible. </p>
<p> The program follows the strategy not to delete files in the destination directory. That allows to collect files from differnt runs. Thus collisions are resolved in the manner that the first entry that is made in the destination directory wins.</p>
<dt>Configuration file</p>
<dd> It would save the user from retyping the same options again and again.</p>
<dt>Uncomplete recording</p>
<dd> Bugs in TeX&#8217;s file recording might result in incomplete file recording (e.g. pdfTeX 1.40.3 does not record .pfb and .pk files).</p>
<dt>&#8230;</p>
<dd></dl>
<h2>FILES</h2>
<dl>
<dt><i>&lt;jobname&gt;.mjt/</i></p>
<dd> Directory where the resulting texmf tree and symbol links are stored. It can be changed by option <tt>&quot;--destdir&quot;</tt>.</p>
<dt><i>&lt;jobname&gt;.fls</i></p>
<dd> Name of TeX&#8217;s recorder file.</p>
<dt><i>&lt;jobname&gt;.strace</i></p>
<dd> Log file where the result of <code>strace</code> is stored.</dl>
