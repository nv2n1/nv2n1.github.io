<h2>NAME</h2>
<p> mate-network-properties &#8211; configure MATE network proxy</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-network-properties</code> [<i>OPTIONS&#8230;</i>]</p>
<h2>DESCRIPTION</h2>
<p> This executable is part of the package &#8216;mate-control-center&#8217;: The MATE Control Center. </p>
<p> The MATE network proxy preference tool enables you to configure how your system connects to networks. You can configure the desktop to connect to a proxy server, and specify the details of the proxy server. </p>
<p> A proxy server is a server that intercepts requests to another server, and fulfills the request itself, if it can. You can enter the Domain Name Service (DNS) name or the Internet Protocol (IP) address of the proxy server.</p>
<h2>OPTIONS</h2>
<p> This program accepts the standard MATE and GTK options.</p>
