<h2>NAME</h2>
<p> memflush &#8211; libmemcached Documentation </p>
<p> Reset a server or list of servers</p>
<h2>SYNOPSIS</h2>
<p> memflush [options]</p>
<h2>DESCRIPTION</h2>
<p> <code>memflush</code> resets the contents of <a href="/docs/linux/man/1-memcached/">memcached</a>(1) servers. This means that all data in the specified servers will be deleted.</p>
<h2>OPTIONS</h2>
<p> You can specify servers via the option:</p>
<dl>
<dt><code>&#8211;servers</code></p>
<dd>
<p> or via the environment variable:</p>
<dt><code>`MEMCACHED_SERVERS`</code></p>
<dd>
<p> For a full list of operations run the tool with option:</p>
<dt><code>&#8211;help</code></p>
<dd></dl>
