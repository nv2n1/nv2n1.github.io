<h2>Name</h2>
<p> mmount &#8211; mount an MSDOS disk </p>
<h2>Note of warning</h2>

<h2>Description</h2>
<p> The <tt>mmount</tt> command is used to mount an MS-DOS disk. It is only available on Linux, as it is only useful if the OS kernel allows configuration of the disk geometry. Its syntax is: </p>
<p> <tt>mmount</tt> <i>msdosdrive</i> [<i>mountargs</i>] </p>
<p> <tt>Mmount</tt> reads the boot sector of an MS-DOS disk, configures the drive geometry, and finally mounts it passing <tt>mountargs</tt> to <tt>mount. </tt> If no mount arguments are specified, the name of the device is used. If the disk is write protected, it is automatically mounted read only. </p>
