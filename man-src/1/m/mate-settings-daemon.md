<h2>NAME</h2>
<p> mate-settings-daemon &#8211; Handles the MATE session settings</p>
<h2>SYNOPSIS</h2>
<p> <code>mate-settings-daemon</code> [<code>&#8211;debug</code>] [<code>&#8211;replace</code>] [<code>&#8211;display</code>=<i>DISPLAY</i>]</p>
<h2>DESCRIPTION</h2>
<p> <i>mate-settings-daemon</i> is responsible for setting the various preference parameters of a MATE session and the applications that run under it.</p>
<h2>OPTIONS</h2>
<p> Help options</p>
<dl>
<dt>-?, <code>&#8211;help</code></p>
<dd> Show this help message</dl>
<p> Application options</p>
<dl>
<dt><code>&#8211;debug</code></p>
<dd> Enable debugging code</p>
<dt><code>&#8211;replace</code></p>
<dd> Replaces the current running daemon</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</dl>
