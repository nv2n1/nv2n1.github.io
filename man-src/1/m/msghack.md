<p> msghack &#8211; alter PO files in ways</p>
<h2>SYNOPSIS</h2>
<p> <code>msghack</code> [<i>OPTION</i>] <i>file.po </i>[<i>ref.po</i>]</p>
<h2>DESCRIPTION</h2>
<p> This program can be used to alter .po files in ways no sane mind would think about.</p>
<dl>
<dt><code>-o</code></dt>
<dd> result will be written to FILE</dd>
<dt><code>&#8211;invert</code></dt>
<dd> invert a po file by switching msgid and msgstr</dd>
<dt><code>&#8211;master</code></dt>
<dd> join any number of files in a master-formatted catalog</dd>
<dt><code>&#8211;empty</code></dt>
<dd> empty the contents of the .po file, creating a .pot</dd>
<dt><code>&#8211;append</code></dt>
<dd> append entries from ref.po that don&#8217;t exist in file.po</dd></dl>
<p> Note: It is just a replacement of msghack for backward support. </p>
