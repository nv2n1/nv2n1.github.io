<h2 class="name">NAME</h2>
<p> muffin-theme-viewer &#8211; view muffin themes </p>
<h2>SYNOPSIS</h2>
<p> <code>muffin-theme-viewer</code> [ <i>THEMENAME</i> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>muffin-theme-viewer</code> allows you to preview any installed Muffin theme. </p>
<p> When designing a new Muffin theme, you can use <code>muffin-theme-viewer</code> to measure the performance of a window frame option, and to preview the option.</p>
<h2>OPTIONS</h2>
<dl>
<dt><i>THEMENAME</i></p>
<dd> Name of the theme to be shown (<i>Atlanta</i> by default). It is case-sensitive.</dl>
<h2>FILES</h2>
<pre>
<dl>
<dt><i>/usr/share/themes</i>
<dd>system themes directory
<dt><i>/usr/share/themes/*/muffin-1/muffin-theme-1.xml</i>
<dd>theme specification file
</dl>
</pre>
