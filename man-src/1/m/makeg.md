<h2>NAME</h2>
<p> makeg &#8211; make a debuggable executable</p>
<h2>SYNOPSIS</h2>
<p> <code>makeg</code> [ <i>make-options &#8230;</i> ] [ <i>targets &#8230;</i> ]</p>
<h2>DESCRIPTION</h2>
<p> The <i>makeg</i> script runs <i>make,</i> passing it variable settings to create a debuggable target when used with a Makefile generated by <i>imake.</i> For example, it arranges for the C compiler to be called with the <code>-g</code> option.</p>
<h2>ENVIRONMENT</h2>
<dl>
<dt><code>MAKE</code></p>
<dd> The <i>make</i> program to use. Default &#8220;make&#8221;.</p>
<dt><code>GDB</code></p>
<dd> Set to a non-null value if using the <i>gdb</i> debugger on Solaris 2, which requires additional debugging options to be passed to the compiler.</dl>
