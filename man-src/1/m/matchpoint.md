<p> <code>matchpoint</code> [options] <i>image1.jpg</i> <i>output.key</i></p>
<p> <code>matchpoint</code> is an experimental tool for feature detection, see <i><a href="/docs/linux/man/1-cpfind/">cpfind</a></i>(1) for a working alternative.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-v</code></dt>
<dd> verbose output</dd>
<dt><code>-t</code></dt>
<dd> generate keypoint file for matlab test suite (file name is generated using formula: image1.jpg.key)</dd></dl>
<h2>ARGUMENTS</h2>
<dl>
<dt><code>image1.jpg</code></dt>
<dd> Path to image to be analyzed.</dd>
<dt><code>output.key</code></dt>
<dd> Output keypoint file..</dd></dl>
