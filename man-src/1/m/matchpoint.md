<h2 class="name">NAME</h2>
<p> matchpoint &#8211; Run feature detection and extraction </p>
<h2>SYNOPSIS</h2>
<p> <code>matchpoint</code> [options] <i>image1.jpg</i> <i>output.key</i></p>
<h2>DESCRIPTION</h2>
<p> <code>matchpoint</code> is an experimental tool for feature detection, see <i><a href="/docs/linux/man/1-cpfind/">cpfind</a></i>(1) for a working alternative.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-v</code></p>
<dd> verbose output</p>
<dt><code>-t</code></p>
<dd> generate keypoint file for matlab test suite (file name is generated using formula: image1.jpg.key)</dl>
<h2>ARGUMENTS</h2>
<dl>
<dt><code>image1.jpg</code></p>
<dd> Path to image to be analyzed.</p>
<dt><code>output.key</code></p>
<dd> Output keypoint file..</dl>
