<h2 class="name">NAME</h2>
<p> METACITY-MESSAGE &#8211; a command to send a message to Metacity </p>
<h2>SYNOPSIS</h2>
<p> <code>METACITY-MESSAGE</code> [restart|reload-theme|enable-keybindings|disable-keybindings|enable-mouse-button-modifiers|disable-mouse-button-modifiers|toggle-verbose]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>metacity-message</code>. This manual page was written for the Debian distribution because the original program does not have a manual page. </p>
<p> <code>metacity-message</code> send a specified message to <code><a href="/docs/linux/man/1-metacity/">metacity</a></code>(1).</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>restart</code></p>
<dd> Restart <code><a href="/docs/linux/man/1-metacity/">metacity</a></code>(1) which is running.</p>
<dt><code>reload-theme</code></p>
<dd> Reload a theme which is specified on gsettings database.</p>
<dt><code>enable-keybindings</code></p>
<dd> Enable all of keybindings which is specified on gsettings database.</p>
<dt><code>disable-keybindings</code></p>
<dd> Disable all of keybindings which is specified on gsettings database.</p>
<dt><code>enable-mouse-button-modifiers</code></p>
<dd> Enable move/resize operations while pressing a modifier key</p>
<dt><code>disable-mouse-button-modifiers</code></p>
<dd> Disable move/resize operations while pressing a modifier key</p>
<dt><code>toggle-verbose</code></p>
<dd> Turn debug messages on or off</dl>
