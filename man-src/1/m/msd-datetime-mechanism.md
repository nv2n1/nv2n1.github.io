<h2>NAME</h2>

 msd-datetime-mechanism - set system time via D-Bus

<h2>SYNOPSIS</h2>

 msd-datetime-mechanism

<h2>DESCRIPTION</h2>

 The <i>msd-datetime-mechanism</i> is used for setting the system time via D-Bus. <i>msd-datetime-mechanism</i> is a D-Bus wrapper that gets executed via D-Bus with root privileges. The execution of <i>msd-datetime-mechanism</i> gets triggered via the MATE clock applet.
