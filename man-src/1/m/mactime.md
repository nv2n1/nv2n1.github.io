<h2 class="name">NAME</h2>
<p> mactime &#8211; Create an ASCII time line of file activity </p>
<h2>SYNOPSIS</h2>
<p> <code>mactime [-b</code> <i>body</i> <code>] [-g </code> <i>group file</i> <code>] [-p </code> <i>password file</i> <code>] [-i</code> <i>(day|hour) index file</i> <code>] [-dhmVy] [-z</code> <i>TIME_ZONE</i> <code>] [DATE_RANGE]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>mactime</code> creates an ASCII time line of file activity based on the body file specified by &#8216;-b&#8217; or from STDIN. The time line is written to STDOUT. The body file must be in the time machine format that is created by &#8216;ils -m&#8217;, &#8216;fls -m&#8217;, or the mac-robber tool. </p>
<h2>ARGUMENTS</h2>
<dl>
<dt>-b body</p>
<dd> Specify the location of a body file. This file must be generated by a tool such as &#8216;fls -m&#8217; or &#8216;ils -m&#8217;. The &#8216;mac-robber&#8217; and &#8216;grave-robber&#8217; tools can also be used to generate the file.</p>
<dt>-g group file</p>
<dd> Specify the location of the group file. mactime will display the group name instead of the GID if this is given.</p>
<dt>-p password file</p>
<dd> Specify the location of the passwd file. mactime will display the user name instead of the UID of this is given.</p>
<dt>-i day|hour index file</p>
<dd> Specify the location of an index file to write to. The first argument specifies the granularity, either an hourly summary or daily. If the &#8216;-d&#8217; flag is given, then the summary will be separated by a &#8216;,&#8217; to import into a spread sheet.</p>
<dt>-d</p>
<dd> Display timeline and index files in comma delimited format. This is used to import the data into a spread sheet for presentations or graphs.</p>
<dt>-h</p>
<dd> Display header info about the session including time range, input source, and passwd or group files.</p>
<dt>-V</p>
<dd> Display version to STDOUT.</p>
<dt>-m</p>
<dd> The month is given as a number instead of name (does not work with -y).</p>
<dt>-y</p>
<dd> The date is displayed in ISO8601 format.</p>
<dt>-z TIME_ZONE</p>
<dd> The timezone from where the data was collected. The name of this argument is system dependent (examples include EST5EDT, GMT+1). Does not work with -y.</p>
<dt>-z list</p>
<dd> List valid timezones.</p>
<dt>DATE_RANGE</p>
<dd> The range of dates to make the time line for. The standard format is yyyy-mm-dd for a starting date and no ending date. For an ending date, use yyyy-mm-dd..yyyy-mm-dd. Date can contain time, use format yyyy-mm-ddThh:mm:ss for starting and/or ending date. </p>
</dl>
