<h2>NAME</h2>
<p> mdoc validate &#8211; Validate XML documents against a schema</p>
<h2>SYNOPSIS</h2>
<p> <code>mdoc validate</code> [OPTIONS]* PATHS+</p>
<h2>DESCRIPTION</h2>
<p> <code>mdoc validate</code> validates the specified <i>PATHS</i> against a specified format schema.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;format</code>=<i>FORMAT</i></p>
<dd> The documentation format to validate <i>PATHS</i> against. Supported formats include: <i>ecma</i>. </p>
<p> See the <i>FORMATS</i> section below for more information about these formats. </p>
<p> The default format (if none is specified) is <i>ecma</i>.</p>
<dt><code>-h</code>, <code>-?</code>, <code>&#8211;help</code></p>
<dd> Display a help message and exit.</dl>
<h2>FORMATS</h2>
<p> The following documentation formats are supported:</p>
<h3>ecma</h3>
<p> The <i>Mono ECMA Documentation Format</i> validates all output generated by <code><a href="/docs/linux/man/1-mdoc-update/">mdoc-update</a></code>(1) against an XML schema, including the <i>index.xml</i>, <i>ns-*.xml</i>, and <i>NamespaceName/TypeName.xml</i> files. </p>
<p> See <code><a href="/docs/linux/man/5-mdoc/">mdoc</a></code>(5) for details about this file format.</p>
<h2>EXAMPLES</h2>
<p> To validate the <code><a href="/docs/linux/man/1-mdoc-update/">mdoc-update</a></code>(1) output stored within a directory (and all documentation within that directory, recursively), use: </p>
<pre>
    mdoc validate /path/to/ecma/docs
</pre>
