<h2>NAME</h2>
<p> mx-create-image-cache &#8212; program to make a cache of a directory<br />
&nbsp;</p>
<h2>SYNOPSIS</h2>
<p> <code>mx-create-image-cache</code></p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>mx-create-image-cache</code> command. </p>
<p> This manual page was written for the <code>Debian</code> distribution because the original program does not have a manual page. </p>
<p> <code>mx-create-image-cache</code> is a prgram to make a cache for a directory which contains images. It will create a cached image inside /var/cache/mx for all the images inside that directory and its sub-directories.<br />
&nbsp;</p>
