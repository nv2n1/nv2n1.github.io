<h2>NAME</h2>
<p> <code>mdb-array </code>&#8211; Export data in an MDB database table to a C array.</p>
<h2>SYNOPSIS</h2>
<pre>
<code>mdb-array</code> <i>database</i> <i>table</i>
</pre>
<h2>DESCRIPTION</h2>
<p> <code>mdb-array</code> is a utility program distributed with MDB Tools. </p>
<p> <code>mdb-array</code> prints a C source code file to stdout, containing an array representing the data of the specified <i>table</i>.</p>
<h2>ENVIRONMENT</h2>
<dl>
<dt><code>MDB_JET3_CHARSET</code></dt>
<dd> Defines the charset of the input JET3 (access 97) file. Default is CP1252. See <code><a href="/docs/linux/man/1-iconv/">iconv</a></code>(1).</dd>
<dt><code>MDBICONV</code></dt>
<dd> Defines the output charset. Default is UTF-8. mdbtools must have been compiled with iconv.</dd>
<dt><code>MDBOPTS</code></dt>
<dd> semi-column separated list of options:</dd>
<dl>
<dl>
<dt>&bull;</dt>
<dd> use_index</dd>
<dt>&bull;</dt>
<dd> no_memo</dd>
<dt>&bull;</dt>
<dd> debug_like</dd>
<dt>&bull;</dt>
<dd> debug_write</dd>
<dt>&bull;</dt>
<dd> debug_usage</dd>
<dt>&bull;</dt>
<dd> debug_ole</dd>
<dt>&bull;</dt>
<dd> debug_row</dd>
<dt>&bull;</dt>
<dd> debug_props</dd>
<dt>&bull;</dt>
<dd> debug_all is a shortcut for all debug_* options</dd></dl>
</dl>
</dl>
