<h2 class="name">NAME</h2>
<p> Mozo &#8211; MATE Menu Editor </p>
<h2>SYNOPSIS</h2>
<p> <code>mozo</code></p>
<h2>DESCRIPTION</h2>
<p> Mozo is a menu editor for MATE using the freedesktop.org menu specification. It is a fork of Alacarte.</p>
