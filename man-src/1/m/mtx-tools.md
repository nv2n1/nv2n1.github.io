<p> <code>mtxrun &#8211;script tools [</code> <i>OPTIONS &#8230;</i> <code>] [</code> <i>FILENAMES</i> <code>]</code></p>
<p> <code>Some File Related Goodies</code></p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;disarmutfbomb</code></dt>
<dd> remove utf bomb if present</dd>
<dt><code>&#8211;force</code></dt>
<dd> remove indeed</dd>
<dt><code>&#8211;dirtoxml</code></dt>
<dd> glob directory into xml</dd>
<dt><code>&#8211;pattern</code></dt>
<dd> glob pattern (default: *)</dd>
<dt><code>&#8211;url</code></dt>
<dd> url attribute (no processing)</dd>
<dt><code>&#8211;root</code></dt>
<dd> the root of the globbed path (default: .)</dd>
<dt><code>&#8211;output</code></dt>
<dd> output filename (console by default)</dd>
<dt><code>&#8211;recurse</code></dt>
<dd> recurse into subdirecories</dd>
<dt><code>&#8211;stripname</code></dt>
<dd> take pathpart of given pattern</dd>
<dt><code>&#8211;longname</code></dt>
<dd> set name attributes to full path name</dd>
<dt><code>&#8211;downcase</code></dt>
<dd> lowercase names</dd>
<dt><code>&#8211;showstring</code></dt>
<dd> show unicode characters in given string</dd>
<dt><code>&#8211;showfile</code></dt>
<dd> show unicode characters in given file</dd>
<dt><code>&#8211;pattern</code></dt>
<dd> glob pattern (default: *)</dd>
<dt><code>&#8211;recurse</code></dt>
<dd> recurse into subdirecories</dd>
<dt><code>&#8211;force</code></dt>
<dd> downcase indeed</dd></dl>
