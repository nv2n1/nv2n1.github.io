<h2 class="name">NAME</h2>
<p>&nbsp;mtx-tools &#8211; Some File Related Goodies </p>
<h2>SYNOPSIS</h2>
<p> <code>mtxrun &#8211;script tools [</code> <i>OPTIONS &#8230;</i> <code>] [</code> <i>FILENAMES</i> <code>]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>Some File Related Goodies</code></p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;disarmutfbomb</code></p>
<dd> remove utf bomb if present</p>
<dt><code>&#8211;force</code></p>
<dd> remove indeed</p>
<dt><code>&#8211;dirtoxml</code></p>
<dd> glob directory into xml</p>
<dt><code>&#8211;pattern</code></p>
<dd> glob pattern (default: *)</p>
<dt><code>&#8211;url</code></p>
<dd> url attribute (no processing)</p>
<dt><code>&#8211;root</code></p>
<dd> the root of the globbed path (default: .)</p>
<dt><code>&#8211;output</code></p>
<dd> output filename (console by default)</p>
<dt><code>&#8211;recurse</code></p>
<dd> recurse into subdirecories</p>
<dt><code>&#8211;stripname</code></p>
<dd> take pathpart of given pattern</p>
<dt><code>&#8211;longname</code></p>
<dd> set name attributes to full path name</p>
<dt><code>&#8211;downcase</code></p>
<dd> lowercase names</p>
<dt><code>&#8211;showstring</code></p>
<dd> show unicode characters in given string</p>
<dt><code>&#8211;showfile</code></p>
<dd> show unicode characters in given file</p>
<dt><code>&#8211;pattern</code></p>
<dd> glob pattern (default: *)</p>
<dt><code>&#8211;recurse</code></p>
<dd> recurse into subdirecories</p>
<dt><code>&#8211;force</code></p>
<dd> downcase indeed</dl>
