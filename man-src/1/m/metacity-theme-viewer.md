<h2>NAME</h2>
<p> metacity-theme-viewer &#8211; view metacity themes</p>
<h2>SYNOPSIS</h2>
<p> <code>metacity-theme-viewer</code> [ <i>THEMENAME</i> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>metacity-theme-viewer</code> allows you to preview any installed Metacity theme. </p>
<p> When designing a new Metacity theme, you can use <code>metacity-theme-viewer</code> to measure the performance of a window frame option, and to preview the option.</p>
<h2>OPTIONS</h2>
<dl>
<dt><i>THEMENAME</i></p>
<dd> Name of the theme to be shown (<i>Atlanta</i> by default). It is case-sensitive.</dl>
<h2>FILES</h2>
<pre>
<dl>
<dt><i>/usr/share/themes</i>
<dd>system themes directory
<dt><i>/usr/share/themes/*/metacity-1/metacity-theme-1.xml</i>
<dd>theme specification file
</dl>
</pre>
