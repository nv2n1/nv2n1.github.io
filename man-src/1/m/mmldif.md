<h2 class="name">NAME</h2>
<p> mmldif &#8211; mmldif util </p>
<h2>SYNOPSIS</h2>
<p> <code>mmldif</code> [-c] [-D] [-o out.ldif] in1.ldif in2.ldif &#8230; </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>mmldif</code> command. </p>
<h2>OPTIONS</h2>
<p> A summary of options is included below:</p>
<dl>
<dt><code>-c</code></p>
<dd> Write a change file (.delta) for each input file</p>
<dt><code>-D</code></p>
<dd> Print debugging information</p>
<dt><code>-o</code></p>
<dd> Write authoritative data to this file</dl>
