<h2>NAME</h2>
<p> mysqueak &#8211; desktop frontend to Squeak</p>
<h2>SYNOPSIS</h2>
<p> <code>mysqueak</code></p>
<h2>DESCRIPTION</h2>
<p> <code>mysqueak</code> runs <code>inisqueak</code> in batch mode in the directory ~/MySqueak/default. If that directory does not exist it will be created, and inisqueak will populate it with an image file. </p>
<p> The primary purpose of mysqueak is to simplify starting <code>Squeak </code> from a menu, though it also simplifies starting squeak from the command line. </p>
<h2>INVOCATION</h2>
<p> <code>mysqueak</code> has no options or arguments.</p>
<h2>DIAGNOSTICS</h2>
<p> <code>mysqueak</code> outputs nothing and returns whatever inisqueak returns.</p>
<h2>FILES</h2>
<p> <i>~/MySqueak</i></p>
<dl>
<dt>
<dd> the user&#8217;s copies of a squeak.image, squeak.changes, and squeak.sources are kept here. </p>
</dl>
