<p> <code>bluefish</code> [[<code>-c</code>|<code>&#8211;curwindow</code>] | [<code>-n</code>|<code>&#8211;newwindow</code>]] <code>[</code><i>FILE(S)&#8230;</i><code>]</code> </p>
<p> <code>bluefish</code> {[<code>-?</code>|<code>&#8211;help</code>|<code>&#8211;help-all</code>|<code>&#8211;help-*</code>] | [<code>-v</code>|<code>&#8211;Version</code>]} </p>
<p> <code>bluefish</code> is an open-source editor for experienced web designers and programmers, supporting many programming and markup languages, but focusing on creating dynamic and interactive websites. </p>
<h2>OPTIONS</h2>
<p> <code>bluefish</code> currently supports the following options:</p>
<dl>
<dt><code>-c</code>, <code>&#8211;curwindow</code></dt>
<dd> Open a file in an existing window. This can be used to overwrite the chosen default.</dd>
<dt><code>-n</code>, <code>&#8211;newwindow</code></dt>
<dd> Open a file in a new window. This can be used to overwrite the chosen default.</dd>
<dt><code>-?</code>, <code>&#8211;help</code>, <code>&#8211;help-*</code>, <code>&#8211;help-all</code></dt>
<dd> Print all or just a group of help options. Some of these options may be documented in <code><a href="/docs/linux/man/7-gtk-options/">gtk-options</a></code>(7) and <code><a href="/docs/linux/man/7-gnome-options/">gnome-options</a></code>(7).</dd>
<dt><code>-v</code>, <code>&#8211;Version</code></dt>
<dd> Print version information. </dd>
</dl>
