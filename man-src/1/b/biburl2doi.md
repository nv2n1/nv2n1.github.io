<h2 class="name">NAME</h2>
<p> biburl2doi.pl &#8211; convert URLs pointing to doi.org to DOIs </p>
<h2>SYNOPSIS</h2>
<p> biburl2doi [<code>-D</code>] [<code>-o</code> <i>output</i>] <i>bib_file</i></p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-D</code></p>
<dd> Do not delete URLs converted to DOIs</p>
<dt><code>-o</code> <i>output</i></p>
<dd> Output file. If this option is not used, the name for the output file is formed by adding <tt>&quot;_cleaned&quot;</tt> to the input file</dl>
<h2>DESCRIPTION</h2>
<p> The script recognizes <font SIZE="-1">URL</font> fields of the kind <tt>&quot;<a rel="nofollow" href="http://dx.doi.org">http://dx.doi.org</a>&quot;</tt> and their variants and converts them to <font SIZE="-1">DOI</font> fields.</p>
