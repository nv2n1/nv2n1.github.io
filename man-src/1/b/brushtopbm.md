<h2 class="name">NAME</h2>
<p> brushtopbm &#8211; convert a doodle brush file into a portable bitmap </p>
<h2>SYNOPSIS</h2>
<p> <code>brushtopbm</code> [<i>brushfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads a Xerox doodle brush file as input. Produces a portable bitmap as output. </p>
<p> Note that there is currently no pbmtobrush tool.</p>
