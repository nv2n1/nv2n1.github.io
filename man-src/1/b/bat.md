<h2 class="name">NAME</h2>
<p>&nbsp;<wbr>bat &#8211; Bacula Administration Tool Console </p>
<h2>SYNOPSIS</h2>
<p> <code>bat</code> [options] </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>bat</code> command, the Qt4 version of the Bacula Administration Tool console. This is a GUI full featured program similar the bconsole program, but it is graphical oriented and more features. </p>
<h2>OPTIONS</h2>
<p> bat [-s] [-c config_file] [-d debug_level] [-t]</p>
<dl>
<dt><code>-c &lt;config&gt;</code></p>
<dd> Specify configuration file. Default is bat.conf.</p>
<dt><code>-d &lt;nn&gt;</code></p>
<dd> Set debug level to <i>nn</i>.</p>
<dt><code>-s</code></p>
<dd> No signals. Used in debugging only.</p>
<dt><code>-t</code></p>
<dd> Test config mode: read configuration and exit.</p>
<dt><code>-?</code></p>
<dd> Show version and usage of program.</dl>
