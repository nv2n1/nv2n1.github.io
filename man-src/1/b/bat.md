<p>&nbsp;<wbr>bat &#8211; Bacula Administration Tool Console </p>
<h2>SYNOPSIS</h2>
<p> <code>bat</code> [options] </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>bat</code> command, the Qt4 version of the Bacula Administration Tool console. This is a GUI full featured program similar the bconsole program, but it is graphical oriented and more features. </p>
<h2>OPTIONS</h2>
<p> bat [-s] [-c config_file] [-d debug_level] [-t]</p>
<dl>
<dt><code>-c &lt;config&gt;</code></dt>
<dd> Specify configuration file. Default is bat.conf.</dd>
<dt><code>-d &lt;nn&gt;</code></dt>
<dd> Set debug level to <i>nn</i>.</dd>
<dt><code>-s</code></dt>
<dd> No signals. Used in debugging only.</dd>
<dt><code>-t</code></dt>
<dd> Test config mode: read configuration and exit.</dd>
<dt><code>-?</code></dt>
<dd> Show version and usage of program.</dd></dl>
