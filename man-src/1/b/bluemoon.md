<h2 class="name">NAME</h2>
<p> bluemoon &#8211; Bluemoon configuration utility </p>
<h2>DESCRIPTION</h2>
<p> bluemoon &#8211; Bluemoon configuration utility Usage:</p>
<dl>
<dt>
</dt><dd> bluemoon [options]</dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-A</code>, <code>&#8211;bdaddr</code> [addr]</dt>
<dd> Set Bluetooth address</dd>
<dt><code>-F</code>, <code>&#8211;firmware</code> [file]</dt>
<dd> Load firmware</dd>
<dt><code>-C</code>, <code>&#8211;check</code> &lt;file&gt;</dt>
<dd> Check firmware image</dd>
<dt><code>-R</code>, <code>&#8211;reset</code></dt>
<dd> Reset controller</dd>
<dt><code>-B</code>, <code>&#8211;coldboot</code></dt>
<dd> Cold boot controller</dd>
<dt><code>-E</code>, <code>&#8211;exception</code></dt>
<dd> Trigger exception</dd>
<dt><code>-i</code>, <code>&#8211;index</code> &lt;num&gt;</dt>
<dd> Use specified controller</dd>
<dt><code>-h</code>, <code>&#8211;help</code></dt>
<dd> Show help options </dd>
</dl>
