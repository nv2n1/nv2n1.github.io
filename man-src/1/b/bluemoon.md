<h2 class="name">NAME</h2>
<p> bluemoon &#8211; Bluemoon configuration utility </p>
<h2>DESCRIPTION</h2>
<p> bluemoon &#8211; Bluemoon configuration utility Usage:</p>
<dl>
<dt>
<dd> bluemoon [options]</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-A</code>, <code>&#8211;bdaddr</code> [addr]</p>
<dd> Set Bluetooth address</p>
<dt><code>-F</code>, <code>&#8211;firmware</code> [file]</p>
<dd> Load firmware</p>
<dt><code>-C</code>, <code>&#8211;check</code> &lt;file&gt;</p>
<dd> Check firmware image</p>
<dt><code>-R</code>, <code>&#8211;reset</code></p>
<dd> Reset controller</p>
<dt><code>-B</code>, <code>&#8211;coldboot</code></p>
<dd> Cold boot controller</p>
<dt><code>-E</code>, <code>&#8211;exception</code></p>
<dd> Trigger exception</p>
<dt><code>-i</code>, <code>&#8211;index</code> &lt;num&gt;</p>
<dd> Use specified controller</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show help options </p>
</dl>
