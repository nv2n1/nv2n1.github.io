<h2 class="name">NAME</h2>
<p>&nbsp;<wbr>bgnome-console &#8211; Bacula&#8217;s management Console, GUI version. </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>bgnome-console</code> command, the Gnome GUI version of the Bacula administration console. </p>
<p> The Console allows the administrator or user to communicate with the Bacula Director. This is the Gnome version. It will also run under KDE. </p>
<p> This Gnome GUI interface is for the moment far from complete but is quite functional, having all the capabilities of the shell Console plus a number of GUI extensions that make interaction easier with point and click. <code>.SH</code>SEE<code>ALSO</code> <code><a href="/docs/linux/man/8-bacula-dir/">bacula-dir</a></code>(8), <code><a href="/docs/linux/man/1-bls/">bls</a></code>(1), <code><a href="/docs/linux/man/1-bextract/">bextract</a></code>(1). </p>
