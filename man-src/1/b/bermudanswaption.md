<p>BermudanSwaption &#8211; Example of using QuantLib</p>
<h2>Synopsis</h2>
<p><code>BermudanSwaption</code></p>
<h2>Description</h2>
<p><code>BermudanSwaption</code> is an example of using the <i>QuantLib</i> interest-rate model framework. </p>
<p> <code>BermudanSwaption</code> prices a bermudan swaption using different models calibrated to market swaptions. The calibration examples include Hull and White&#8217;s using both an analytic formula as well as numerically, and Black and Karasinski&#8217;s model. Using these three calibrations, Bermudan swaptions are priced for at-the-money, out-of-the-money and in-the-money volatilities.</p>
