<h2 class="name">NAME</h2>
<p>&nbsp;<wbr>bwx-console &#8211; Bacula&#8217;s management Console </p>
<h2>SYNOPSIS</h2>
<p> <code>bwx-console</code> [options] </p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>bwx-console</code> command, the wxWidgets version of the Bacula administration console. </p>
<h2>OPTIONS</h2>
<p> bwx-console [-s] [-c config_file] [-d debug_level] [-t]</p>
<dl>
<dt><code>-c &lt;config&gt;</code></p>
<dd> Specify configuration file.</p>
<dt><code>-d &lt;nn&gt;</code></p>
<dd> Set debug level to <i>nn</i>.</p>
<dt><code>-s</code></p>
<dd> No signals.</p>
<dt><code>-t</code></p>
<dd> Test config mode: read configuration and exit.</p>
<dt><code>-?</code></p>
<dd> Show version and usage of program.</dl>
