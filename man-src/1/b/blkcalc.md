<h2 class="name">NAME</h2>
<p> blkcalc &#8211; Converts between unallocated disk unit numbers and regular disk unit numbers. </p>
<h2>SYNOPSIS</h2>
<p> <code>blkcalc [-dsu unit_addr] [-vV] [-i imgtype] [-o imgoffset] [-b dev_sector_size] [-f fstype] image [images]</code></p>
<h2>DESCRIPTION</h2>
<p> <code>blkcalc</code> creates a disk unit number mapping between two images, one normal and another that only contains the unallocated units of the first (the default behavior of the <code><a href="/docs/linux/man/1-blkls/">blkls</a>(1)</code> program). One of the <code>-d, -s, </code> or <code>-u </code> options must be given. If the <code>-d</code> option is given, then the <code>unit_addr</code> value is the disk unit address in the regular image (i.e. from <code>dd</code> ). If the unit is unallocated, its address in an unallocated image is given. If the <code>-u</code> option is given, then the <code>unit_addr</code> value is the disk unit address in the unallocated unit image (i.e. from <code><a href="/docs/linux/man/1-blkls/">blkls</a>(1)</code> ). Its disk unit address in the original image is determined. If the <code>-s</code> option is given, then the <code>unit_addr</code> value is the disk unit address in the slack image (i.e. from blkls -s). The <code>image</code> is the full, original image (i.e. from dd). <code>blkcalc</code> was called <code>dcalc</code> in TSK versions prior to 3.0.0. </p>
<dl>
<dt>-f fstype</p>
<dd> Identify the File System type of the image. Use &#8216;-f list&#8217; to list the supported file system types. If not given, autodetection methods are used.</p>
<dt>-i imgtype</p>
<dd> Identify the type of image file, such as raw. Use &#8216;-i list&#8217; to list the supported types. If not given, autodetection methods are used.</p>
<dt>-o imgoffset</p>
<dd> The sector offset where the file system starts in the image.</p>
<dt>-b dev_sector_size</p>
<dd> The size, in bytes, of the underlying device sectors. If not given, the value in the image format is used (if it exists) or 512-bytes is assumed.</p>
<dt>-v</p>
<dd> Verbose output to STDERR.</p>
<dt>-V</p>
<dd> Display version.</p>
<dt>image [images]</p>
<dd> The disk or partition image to read, whose format is given with &#8216;-i&#8217;. Multiple image file names can be given if the image is split into multiple segments. If only one image file is given, and its name is the first in a sequence (e.g., as indicated by ending in &#8216;.001&#8217;), subsequent image segments will be included automatically. </p>
</dl>
<p> This is useful when keyword searching an image generated by <code>blkls.</code> This allows one to identify the original unit address and provides better documentation. </p>
<h2>EXAMPLE</h2>
<p> # blkcalc -u 64 images/wd0e </p>
