<h2 class="name">NAME</h2>
<p> unarj &#8211; Unarchive ARJ files </p>
<h2>SYNOPSIS</h2>
<p> <code>unarj</code> [<i>options</i>]<i> files</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> The <code>unarj</code> command is a simple wrapper to ease transition from the non-free unarj.</p>
<h2>OPTIONS</h2>
<p> This program has the same command line options as <code><a href="/docs/linux/man/1-arj/">arj</a></code>(1). It also supports to be called without any options as a synonim for <code>l</code>. For the full command line list please see <code><a href="/docs/linux/man/1-arj/">arj</a></code>(1) man page.</p>
