<h2>NAME</h2>
<p> udav &#8211; program for data visualization based on MathGL library</p>
<h2>SYNOPSIS</h2>
<p> <code>udav</code> [scriptfile]</p>
<h2>DESCRIPTION</h2>
<p> <code>udav</code> reads MGL scripts from <i>scriptfile</i> to produce plots of specified functions or data. The program will create a GUI window which show the script result and allow to edit the script itself.</p>
