<h2>NAME</h2>
<p> unify &#8211; manual page for unify 1.2.2</p>
<h2>SYNOPSIS</h2>
<p> <code>unify</code> [<i>,OPTION/</i>]&#8230; [<i>,FILE/</i>]</p>
<h2>DESCRIPTION</h2>
<p> unify &#8211; Transforms context diffs into unidiffs, or vice-versa.</p>
<dl>
<dt><code>-c</code>, <code>&#8211;context-diffs</code></p>
<dd> force output to context diffs</p>
<dt><code>-e</code>, <code>&#8211;echo-comments</code></p>
<dd> echo comments to standard error</p>
<dt><code>-o</code>, <code>&#8211;old-diffs</code></p>
<dd> output old-style diffs, no matter what</p>
<dt><code>-p</code>, <code>&#8211;patch-format</code></p>
<dd> generate patch format</p>
<dt><code>-P</code></p>
<dd> same as <code>-p</code></p>
<dt><code>-s</code>, <code>&#8211;strip-comments</code></p>
<dd> strip comment lines</p>
<dt><code>-u</code>, <code>&#8211;unidiffs</code></p>
<dd> force output to unidiffs</p>
<dt><code>-U</code></p>
<dd> same as <code>-p</code> and <code>-u</code></p>
<dt><code>-=</code>, <code>&#8211;use-equals</code></p>
<dd> replace spaces by equal signs in unidiffs</p>
<dt><code>&#8211;help</code></p>
<dd> display this help then exit</p>
<dt><code>&#8211;version</code></p>
<dd> display program version then exit</dl>
<p> If FILE is not specified, read standard input.</p>
