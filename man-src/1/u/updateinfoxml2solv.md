<h2 class="name">NAME</h2>
<p> updateinfoxml2solv &#8211; convert rpm-md&#8217;s updateinfo.xml format into a solv file </p>
<h2>SYNOPSIS</h2>
<p> <code>updateinfoxml2solv</code> [<i>OPTIONS</i>]</p>
<h2>DESCRIPTION</h2>
<p> The updateinfoxml2solv tool reads rpm-md&#8217;s updateinfo xml data from stdin, and writes it as solv file to standard output. Update elements are converted into special <code>patch:</code> pseudo packages.</p>
