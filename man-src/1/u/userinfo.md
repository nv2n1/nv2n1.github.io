<h2>NAME</h2>
<p> userinfo &#8211; A graphical equivilient to chfn.</p>
<h2>SYNOPSIS</h2>
<p> <code>userinfo</code> [ <i>options</i> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>userinfo</code> is a graphical tool to allow users to conveniently change their finger information.</p>
<h2>OPTIONS</h2>
<p> This program has no command line options of its own, but it does take the standard X program options like <code>-display</code> and such. See the <i><a href="/docs/linux/man/1-x/">X</a></i>(1) man page for some of the common options.</p>
<h2>SEE ALSO</h2>
<p> <i><a href="/docs/linux/man/1-chfn/">chfn</a></i>(1), <i><a href="/docs/linux/man/1-finger/">finger</a></i>(1), <i><a href="/docs/linux/man/5-passwd/">passwd</a></i>(5)</p>
<h2>BUGS</h2>
<p> Currently doesn&#8217;t give feedback to the user when the helper fails. (things like incorrect passwords and such) The next iteration should fix this bug.</p>
