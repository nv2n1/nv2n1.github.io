<h2 class="name">NAME</h2>
<p> unshield &#8211; extract CAB files from an InstallShield installer archive </p>
<h2>SYNOPSIS</h2>
<p> unshield [-c COMPONENT] [-d DIRECTORY] [-D LEVEL] [-g GROUP] [-h] [-j] [-L] [-n] [-o] [-O] [-r] [-v] [-V] c|g|l|t|x CABFILE</p>
<h2>DESCRIPTION</h2>
<p> Unshield extracts CAB files from InstallShield installers, used to install software on Microsoft Windows based machines.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-c</code> COMPONENT</p>
<dd> Only list/extract this component</p>
<dt><code>-d</code> DIRECTORY</p>
<dd> Extract files to DIRECTORY</p>
<dt><code>-D</code> LEVEL</p>
<dd> Set debug log level 0 &#8211; No logging (default) 1 &#8211; Errors only 2 &#8211; Errors and warnings 3 &#8211; Errors, warnings and debug messages</p>
<dt><code>-g</code> GROUP</p>
<dd> Only list/extract this file group</p>
<dt><code>-h</code></p>
<dd> Show help message</p>
<dt><code>-j</code></p>
<dd> Junk paths (do not make directories)</p>
<dt><code>-L</code></p>
<dd> Make file and directory names lowercase</p>
<dt><code>-n</code></p>
<dd> Never overwrite files</p>
<dt><code>-o</code></p>
<dd> Always overwrite files</p>
<dt><code>-O</code></p>
<dd> Use old compression</p>
<dt><code>-r</code></p>
<dd> Save raw data (do not decompress)</p>
<dt><code>-v</code></p>
<dd> Be verbose</p>
<dt><code>-V</code></p>
<dd> Print version information</dl>
<h3>Commands:</h3>
<dl>
<dt>c</p>
<dd> List components</p>
<dt>g</p>
<dd> List file groups</p>
<dt>l</p>
<dd> List files</p>
<dt>t</p>
<dd> Test files</p>
<dt>x</p>
<dd> Extract files</dl>
<h3>Other:</h3>
<dl>
<dt>CABFILE</p>
<dd> The InstallShield installer file to act upon</dl>
