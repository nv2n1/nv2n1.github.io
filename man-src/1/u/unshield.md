<p> unshield &#8211; extract CAB files from an InstallShield installer archive </p>
<h2>SYNOPSIS</h2>
<p> unshield [-c COMPONENT] [-d DIRECTORY] [-D LEVEL] [-g GROUP] [-h] [-j] [-L] [-n] [-o] [-O] [-r] [-v] [-V] c|g|l|t|x CABFILE</p>
<h2>DESCRIPTION</h2>
<p> Unshield extracts CAB files from InstallShield installers, used to install software on Microsoft Windows based machines.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-c</code> COMPONENT</dt>
<dd> Only list/extract this component</dd>
<dt><code>-d</code> DIRECTORY</dt>
<dd> Extract files to DIRECTORY</dd>
<dt><code>-D</code> LEVEL</dt>
<dd> Set debug log level 0 &#8211; No logging (default) 1 &#8211; Errors only 2 &#8211; Errors and warnings 3 &#8211; Errors, warnings and debug messages</dd>
<dt><code>-g</code> GROUP</dt>
<dd> Only list/extract this file group</dd>
<dt><code>-h</code></dt>
<dd> Show help message</dd>
<dt><code>-j</code></dt>
<dd> Junk paths (do not make directories)</dd>
<dt><code>-L</code></dt>
<dd> Make file and directory names lowercase</dd>
<dt><code>-n</code></dt>
<dd> Never overwrite files</dd>
<dt><code>-o</code></dt>
<dd> Always overwrite files</dd>
<dt><code>-O</code></dt>
<dd> Use old compression</dd>
<dt><code>-r</code></dt>
<dd> Save raw data (do not decompress)</dd>
<dt><code>-v</code></dt>
<dd> Be verbose</dd>
<dt><code>-V</code></dt>
<dd> Print version information</dd></dl>
<h3>Commands:</h3>
<dl>
<dt>c</dt>
<dd> List components</dd>
<dt>g</dt>
<dd> List file groups</dd>
<dt>l</dt>
<dd> List files</dd>
<dt>t</dt>
<dd> Test files</dd>
<dt>x</dt>
<dd> Extract files</dd></dl>
<h3>Other:</h3>
<dl>
<dt>CABFILE</dt>
<dd> The InstallShield installer file to act upon</dd></dl>
