<h2 class="name">NAME</h2>
<p> <code>ulockmgr_server</code> &#8211; Lock Manager Server for FUSE filesystems</p>
<h2>SYNOPSIS</h2>
<p> <code>ulockmgr_server</code> </p>
<h2>DESCRIPTION</h2>
<p> Filesystem in Userspace (FUSE) is a simple interface for userspace programs to export a virtual filesystem to the Linux kernel. It also aims to provide a secure method for non privileged users to create and mount their own filesystem implementations. </p>
<p> <code>ulockmgr_server</code> is the Userspace Lock Manager Server for FUSE filesystems. </p>
<h2>OPTIONS</h2>
<p> <code>ulockmgr_server</code> has no options. </p>
