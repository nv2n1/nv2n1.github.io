<p>asn1Parser &#8211; ASN.1 syntax tree generator for libtasn1</p>
<h2>Synopsis</h2>
<p><code>asn1Parser</code> [<i>,OPTION/</i>] <i>,FILE/</i></p>
<h2>Description</h2>
<p>Read FILE with ASN.1 definitions and generate a C array that is used with libtasn1 functions. </p>
<p> Mandatory arguments to long options are mandatory for short options too.</p>
<dl>
<dt><code>-c</code>, <code>&#8211;check</code></p>
<dd>checks the syntax only</p>
<dt><code>-o</code>, <code>&#8211;output</code>=<i>,FILE/</i></p>
<dd>output file</p>
<dt><code>-n</code>, <code>&#8211;name</code>=<i>,NAME/</i></p>
<dd>array name</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>display this help and exit</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd>output version information and exit</dl>
