<h2 class="name">NAME</h2>
<p> amqp-declare-queue &#8211; Declare (create or assert the existence of) a queue on an AMQP server </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>amqp-declare-queue</code> [<i>OPTION</i>&#8230;] [-d] {-q&nbsp;<wbr><i>queue name</i>}</dl>
<h2>DESCRIPTION</h2>
<p> <code>amqp-declare-queue</code></p>
<dd>attempts to create a queue on an AMQP server, and exits. If the empty-string is supplied as the queue name, a fresh queue name is generated by the server and returned. In all cases, if a queue was successfully declared, the (raw binary) name of the queue is printed to standard output, followed by a newline.</p>
<h2>OPTIONS</h2>
<p> <code>-q</code>, <code>&#8211;queue</code>=<i>queue name</i></p>
<dl>
<dt>
<dd> The name of the queue to declare. If the empty string is supplied, a fresh queue name is generated by the server.</dl>
<p> <code>-d</code>, <code>&#8211;durable</code></p>
<dl>
<dt>
<dd> Causes the queue to be declared with the &quot;durable&quot; flag set. Durable queues survive server restarts. By default, queues are declared in &quot;transient&quot; mode.</dl>
<h2>EXIT STATUS</h2>
<p> If the queue was successfully declared, the exit status is 0. If an error occurs, the exit status is 1.</p>
<h2>EXAMPLES</h2>
<p> Declare the durable queue &#8220;myqueue&#8221;, and display the name of the queue on standard output:</p>
<dl>
<dt>
<dd>
<dl>
<dt>
<dd>
<pre>
$ <code>amqp-declare-queue -d -q myqueue</code>
myqueue
</pre>
</dl>
</dl>
<p> Declare a fresh, server-named transient queue, and display the name of the queue on standard output (use <code><a href="/docs/linux/man/1-amqp-delete-queue/">amqp-delete-queue</a></code>(1) to delete it from the server once you&#8217;re done):</p>
<dl>
<dt>
<dd>
<dl>
<dt>
<dd>
<pre>
$ <code>amqp-declare-queue -q &quot;&quot;</code>
amq.gen-BW/wvociA8g6LFpb1PlqOA==
</pre>
</dl>
</dl>
