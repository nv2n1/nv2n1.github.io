<h2>NAME</h2>
<p> advmng &#8211; AdvanceCOMP MNG Compression Utility</p>
<h2>SYNOPSIS</h2>
<p> advmng [-l, &#8211;list] [-z, &#8211;recompress] </p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-x, &#8211;extract] [-a, &#8211;add RATE MNG_FILE PNG_FILES&#8230;]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-0, &#8211;shrink-store] [-1, &#8211;shrink-fast] [-2, &#8211;shrink-normal]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-3, &#8211;shrink-extra] [-4, &#8211;shrink-insane] [-i, &#8211;iter N]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-s, &#8211;scroll HxV] [-S, &#8211;scroll-square]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-e, &#8211;expand] [-r, &#8211;reduce]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-c, &#8211;lc] [-C, &#8211;vlc] [-f, &#8211;force] [-q, &#8211;quiet] [-v, &#8211;verbose]</p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>[-h, &#8211;help] [-V, &#8211;version] FILES&#8230;</p>
<h2>DESCRIPTION</h2>
<p> The main purpose of this utility is to recompress MNG files to get the smallest possible size. </p>
<p> Please note that this utility is not able to read a generic file. It&#8217;s granted to be able to read only the files generated by the AdvanceMAME emulator. </p>
<p> To compress the files this utility uses the following strategies:</p>
<dl>
<dt>&bull;</p>
<dd> Remove all ancillary chunks.</p>
<dt>&bull;</p>
<dd> Use the MNG Delta feature to compress video clips with only small changes between frames.</p>
<dt>&bull;</p>
<dd> Use the MNG Move feature to compress video clips with a scrolling background (option -s).</p>
<dt>&bull;</p>
<dd> Reduce the color depth to 8 bit (option -r).</p>
<dt>&bull;</p>
<dd> Use the 7zip Deflate implementation.</dl>
<h2>COMMANDS</h2>
<dl>
<dt><code>-l, &#8211;list FILES&#8230;</code></p>
<dd> List the content of the specified files.</p>
<dt><code>-z, &#8211;recompress FILES&#8230;</code></p>
<dd> Recompress the specified files. If the -1, -2, -3 options are specified, it&#8217;s used the smallest file choice from the previous compressed data and the new compression. If the -0 option is specified the file is always rewritten without any compression.</p>
<dt><code>-x, &#8211;extract FILES&#8230;</code></p>
<dd> Extract all the .png frames in the .mng clips. You can use the &#8211;shrink options to control the compression ratio of the .png files. The extracted images are always 24 bit images with alpha channel. You can remove the alpha channel with the -n option.</p>
<dt><code>-a, &#8211;add RATE MNG_FILE PNG_FILES&#8230;</code></p>
<dd> Compress all the .png files on the command line as a .mng file. All the .png files must have the same size and the same bit depth. You must also specify an integer frame rate to use in the</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-0, &#8211;shrink-store</code></p>
<dd> Disable the compression. The file is only stored and not compressed. The file is always rewritten also if it&#8217;s bigger.</p>
<dt><code>-1, &#8211;shrink-fast</code></p>
<dd> Set the compression level to &quot;fast&quot; using the zlib compressor.</p>
<dt><code>-2, &#8211;shrink-normal</code></p>
<dd> Set the compression level to &quot;normal&quot; using the 7z compressor. This is the default level of compression.</p>
<dt><code>-3, &#8211;shrink-extra</code></p>
<dd> Set the compression level to &quot;extra&quot; using the 7z compressor. You can define the compressor iterations with the -i, &#8211;iter option.</p>
<dt><code>-4, &#8211;shrink-insane</code></p>
<dd> Set the compression level to &quot;insane&quot; using the zopfli compressor. You can define the compressor iterations with the -i, &#8211;iter option.</p>
<dt><code>-i, &#8211;iter N</code></p>
<dd> Define an additional numer of iterations for the 7z and zopfli compressors for modes -3 and -4. More iterations usually give a better compression, but may require a lot more time. Try for example with 10, 15, 20, and so on.</p>
<dt><code>-s, &#8211;scroll HxV</code></p>
<dd> The &quot;-s HxV&quot; option specifies the size of the pattern (H width x V height) used to check for a scrolling background. The size is expressed in pixels and it must be bigger or equal than the scrolling speed of the background. For example take the game 1942 that scrolls vertically by 1 pixel every frame. If you recorded with an interleave factor of 2 the vertical scrolling speed is 1*2 = 2. In this case the minimum pattern is &quot;-s 0x2&quot;. Generally you can use &quot;-s 8&#215;8&quot; and use bigger values only for games scrolling faster. If the game scrolls only horizontally or vertically you can speed up a lot the compression with monodirectional patterns like &quot;-s 16&#215;0&quot; or &quot;-s 0x16&quot;.</p>
<dt><code>-S, &#8211;scroll-square N</code></p>
<dd> This option is like the option &quot;-s NxN&quot; but excludes big movement on both directions reducing the computation time. Specifically the check done is X+Y&lt;=N.</p>
<dt><code>-r, &#8211;reduce</code></p>
<dd> Force the color reduction to 8 bit. The reduction is really done only if any frame have less than 256 colors and if no alpha channel is present. To force the reduction also if an alpha channel is present use the -n option.</p>
<dt><code>-e, &#8211;expand</code></p>
<dd> Force the color expansion to 24 bit.</p>
<dt><code>-n, &#8211;noalpha</code></p>
<dd> Remove the alpha channel if present.</p>
<dt><code>-c, &#8211;lc</code></p>
<dd> Force the use of the MNG LC (Low Complexity) specifications. It disables the delta compression. The file is always rewritten also if it&#8217;s bigger.</p>
<dt><code>-C, &#8211;vlc</code></p>
<dd> Force the use of the MNG VLC (Very Low Complexity) specifications. It disables the delta compression and the precise timing. Warning! you may lose the correct timing information because the VLC format only supports integer frequency. The file is always rewritten also if it&#8217;s bigger.</p>
<dt><code>-f, &#8211;force</code></p>
<dd> Force the use of the new file also if it&#8217;s bigger.</p>
<dt><code>-q, &#8211;quiet</code></p>
<dd> Don&#8217;t print the filenames.</p>
<dt><code>-v, &#8211;verbose</code></p>
<dd> Print more information on the compression process.</dl>
<h2>EXAMPLES</h2>
<p> A good tradeoff of recompression and time is the command : </p>
<dl>
<dt>
<dd> advmng -z -r -S 16 *.mng</dl>
<p> To create a .mng file from a series of .png files use the command : </p>
<dl>
<dt>
<dd> advmng -a 30 video.mng video*.png</dl>
<p> To extract all the images in a .mng file use the command : </p>
<dl>
<dt>
<dd> advmng -x video.mng</dl>
