<h2>NAME</h2>
<p> anxenc &#8212; Encapsulate annotations and data into annodexed media<br />
&nbsp;<wbr></p>
<h2>SYNOPSIS</h2>
<p> <code>anxenc</code> [-o <code>filename</code> | &#8211;output <code>filename</code> ] [-h | &#8211;help ] <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt> [-t <code>content-type</code> | &#8211;type <code>content-type</code> ]<br />
 filename &#8230;</p>
<h2>Description</h2>
<p> <code>anxenc</code> encapsulates annotations and data into annodexed media.<br />
&nbsp;<wbr></p>
<h2>Options</h2>
<p> <code>anxenc</code> accepts the following options:<br />
&nbsp;<wbr></p>
<h3>CMML generation options</h3>
<dl>
<dt>-c, &#8211;cmml</p>
<dd> Extract annotations as a valid CMML file (default)<br />
&nbsp;<wbr></p>
<dt>&#8211;head</p>
<dd> Extract only the CMML head element<br />
&nbsp;<wbr></p>
<dt>-g, &#8211;granulerate</p>
<dd> Include information about media granulerates<br />
&nbsp;<wbr></dl>
<h3>Data track options</h3>
<dl>
<dt>-m, &#8211;media</p>
<dd> Extract media from annodexed media</dl>
<h3>Miscellaneous options</h3>
<dl>
<dt>-o <code>filename</code>, &#8211;output <code>filename</code></p>
<dd> Write output to the specified <code>filename</code> instead of printing it to standard output.<br />
&nbsp;<wbr></p>
<dt>-h, &#8211;help</p>
<dd> Display usage information and exit.</dl>
