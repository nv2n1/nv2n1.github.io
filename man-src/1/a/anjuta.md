<h2>NAME</h2>
<p> anjuta &#8211; GNOME Integrated Development Environment</p>
<h2>SYNTAX</h2>
<p> anjuta [<i>option</i>] [<i>files &#8230; </i>]</p>
<h2>DESCRIPTION</h2>
<p> Anjuta is a GNOME IDE and can be used to create either GNOME/GTK+ applications with glade or glade-gnome, or can be used for creating generic applications. It is primarily designed for use with C/C++ and features an easy to use debugger and compilation environment.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Output help Anjuta command-line options and exit.</p>
<dt><code>&#8211;help-gtk</code></p>
<dd> Output GTK+ command-line options and exit.</p>
<dt><code>&#8211;help-all</code></p>
<dd> Output all command-line options and exit.</p>
<dt><code>-v, &#8211;version</code></p>
<dd> Output version information and exit.</p>
<dt><code>-s, &#8211;no-splash</code></p>
<dd> Do not show the splashscreen at startup.</p>
<dt><code>-c, &#8211;no-client</code></p>
<dd> Start a new instance and do not open the file in an existing instance.</p>
<dt><code>-n, &#8211;no-session</code></p>
<dd> Do not open last session on startup.</p>
<dt><code>-f, &#8211;no-files</code></p>
<dd> Do not open last project and files on startup.</p>
<dt><code>-p, &#8211;proper-shutdown</code></p>
<dd> Shut down Anjuta properly, releasing all resources (for debugging).</p>
<dt><code>-g, &#8211;geometry string</code></p>
<dd> Specify the size and location of the main window, using the standard X window geometry syntax: WIDTHxHEIGHT+XOFF+YOFF.</p>
<dt>Anjuta supports all the generic GTK options, a full list is available on the Anjuta help screen using &#8211;help-gtk.</p>
<dd></dl>
