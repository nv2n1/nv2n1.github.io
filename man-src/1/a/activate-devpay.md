<h2>NAME</h2>
<p> activate-devpay &#8211; create the token and certificate files for Amazon S3</p>
<h2>SYNOPSIS</h2>
<p> <code>activate-devpay</code></p>
<h2>DESCRIPTION</h2>
<p> This program creates the token and certificate files for Amazon Devpay&#8217;s Simple Token Service (STS). You can then use those files with the S3 device. </p>
<p> This manual page was written for the Debian GNU/Linux distribution because the original program does not have a manual page. </p>
