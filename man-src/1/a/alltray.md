<h2>NAME</h2>
<p> AllTray &#8211; Dock any program into the system tray.</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>alltray</code> [program] [options]</dl>
<h2>DESCRIPTION</h2>
<dd>With <code>AllTray</code> you can dock any application with no native tray icon (like Evolution, Thunderbird, Terminals) into the system tray. A high-light feature is that a click on the &quot;close&quot; button will minimize back to system tray. It works well with Gnome, KDE, XFCE 4*, Fluxbox* and WindowMaker*. Xmms is supported in particular. </p>
<p> Click-Mode: Only run alltray and click on the window you would like to dock. (Abort with &lt;c&gt;)</p>
<h2>OPTIONS</h2>
<p> These programs follow the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-h</code> <code>&#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>-v</code> <code>&#8211;version</code></p>
<dd> Show version of program.</p>
<dt><code>-d</code> <code>&#8211;debug</code></p>
<dd> Show debug messages.</p>
<dt><code>-s</code> <code>&#8211;show</code></p>
<dd> Do not hide window after start.</p>
<dt><code>-i</code> <code>&#8211;icon</code></p>
<dd> Use a PNG image as an icon.</p>
<dt><code>-l</code> <code>&#8211;large_icons</code></p>
<dd> allow large icons (&gt; 24&#215;24).</p>
<dt><code>-st</code> <code>&#8211;sticky</code></p>
<dd> visible on all workspaces.</p>
<dt><code>-stask</code> <code>&#8211;skip-taskbar</code></p>
<dd> not visible in taskbar.</p>
<dt><code>-na</code> <code>&#8211;no-alltray</code></p>
<dd> no &quot;(Alltray)&quot; in window title.</p>
<dt><code>-m</code> <code>&#8211;menu</code></p>
<dd> Add entry &quot;menu text:command&quot; to popdown menu.</p>
<dt><code>-t</code> <code>&#8211;title</code></p>
<dd> Show title change for &lt;sec&gt; seconds. Probably most usefull for xmms.</p>
<dt><code>-g</code> <code>&#8211;geometry</code></p>
<dd> initial position. see man X.</p>
<dt><code>-conf</code> <code>&#8211;configure</code></p>
<dd> show KDE configuration dialog.</dl>
