<h2>NAME</h2>
<p> aria_ftdump &#8211; display full-text index information</p>
<h2>DESCRIPTION</h2>
<p> Use: aria_ft_dump &lt;table_name&gt; &lt;index_num&gt;</p>
<dl>
<dt><code>-?</code>, <code>-h</code>, <code>&#8211;help</code></p>
<dd> Display help and exit.</p>
<dt><code>-c</code>, <code>&#8211;count</code></p>
<dd> Calculate per-word stats (counts and global weights).</p>
<dt><code>-d</code>, <code>&#8211;dump</code></p>
<dd> Dump index (incl. data offsets and word weights).</p>
<dt><code>-l</code>, <code>&#8211;length</code></p>
<dd> Report length distribution.</p>
<dt><code>-s</code>, <code>&#8211;stats</code></p>
<dd> Report global stats.</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Be verbose.</dl>
