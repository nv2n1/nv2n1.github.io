<h2 class="name">NAME</h2>
<p> autokey-qt &#8211; keyboard automation utility for KDE and QT </p>
<h2>SYNOPSIS</h2>
<p> <code>autokey-qt</code> [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> This manual page briefly documents the <code>autokey-qt</code> command. </p>
<p> <code>autokey-qt</code> AutoKey is a desktop automation utility for Linux and X11. It allows the automation of virtually any task by responding to typed abbreviations and hotkeys. It offers a full-featured GUI that makes it highly accessible for novices, as well as a scripting interface offering the full flexibility and power of the Python language.<br />
 For more information refer to the online wiki at:<br />
&nbsp;<wbr><a rel="nofollow" href="http://code.google.com/p/autokey/w/list">http://code.google.com/p/autokey/w/list</a></p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>-l, &#8211;verbose</code></p>
<dd> Enable verbose (debug) logging.</p>
<dt><code>-c, &#8211;configure</code></p>
<dd> Show the configuration window on startup, even if this is not the first run.</dl>
