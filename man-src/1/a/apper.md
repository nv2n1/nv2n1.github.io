<h2 class="name">NAME</h2>
<p> apper &#8211; An application and package manager using PackageKit </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>apper</code> [<code>&#8211;updates</code>] [<code>&#8211;settings</code>] [<code>&#8211;backend-details</code>] [<code>&#8211;install-mime-type</code><i></p>
<dd>mime-type</i>] [<code>&#8211;install-package-name</code><i> name</i>] [<code>&#8211;install-provide-file</code><i> file</i>] [<code>&#8211;install-font-resource</code><i> font</i>] [<code>&#8211;install-catalog</code><i> file</i>] [<code>&#8211;remove-package-by-file</code><i> filename</i>] [KDE Generic Options] [Qt Generic Options]</dl>
<h2>DESCRIPTION</h2>
<p> Apper is the KDE interface for PackageKit </p>
<p> Apper is able to manage packages, applications and updates in a cross-distribution way thanks to the PackageKit project. </p>
<p> It is providing Linux users a single application that they can learn and use in whatever distribution they are.</p>
<h2>OPTIONS</h2>
<p> <code>&#8211;updates</code></p>
<dl>
<dt>
<dd> Show available updates</dl>
<p> <code>&#8211;settings</code></p>
<dl>
<dt>
<dd> Show Apper configuration page.</dl>
<p> <code>&#8211;backend-details</code> <i>name</i></p>
<dl>
<dt>
<dd> Display information about the backend PackageKit uses at time.</dl>
<p> <code>&#8211;install-mime-type</code> <i>mime-type</i></p>
<dl>
<dt>
<dd> Call the mime-type installer.</dl>
<p> <code>&#8211;install-package-name</code> <i>name</i></p>
<dl>
<dt>
<dd> Install package with the name <i>name</i>.</dl>
<p> <code>&#8211;install-provide-file</code> <i>file</i></p>
<dl>
<dt>
<dd> Install package providing file <i>file</i>.</dl>
<p> <code>&#8211;install-font-resource</code> <i>font</i></p>
<dl>
<dt>
<dd> Install a font resource.</dl>
<p> <code>&#8211;install-catalog</code> <i>file</i></p>
<dl>
<dt>
<dd> Install the package catalog in <i>file</i>.</dl>
<p> <code>&#8211;remove-package-by-file</code> <i>filename</i></p>
<dl>
<dt>
<dd> Remove a package containing file <i>filename</i>.</dl>
