<h2>NAME</h2>
<p> apachetop &#8211; display real-time web server statistics</p>
<h2>SYNOPSIS</h2>
<p> <code>apachetop [-f filename] [-H hits | -T time] [-q] [-l] [-s segments] [-p] [-r secs]</code></p>
<h2>DESCRIPTION</h2>
<p> ApacheTop watches a logfile generated by Apache (in standard common or combined logformat, and generates human-parsable output in realtime. [ <code>TIONS</code> ]</p>
<dl>
<dt>-f logfile</p>
<dd> Select which file to watch. Specify this option multiple times to watch multiple files.</p>
<dt>-H hits | -T time</p>
<dd> These options are mutually exclusive. Specify only one, if any at all. They work as follows. ApacheTop maintains a table of information internally containing all the relevant information about the hits it&#8217;s seen. This table can only be a finite size, so you need to decide how big it&#8217;s going to be. You have two options. You can either: Use -H to say &quot;remember &lt;this many&gt; hits&quot; or<tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>Use -T to say &quot;remember all hits in &lt;this many&gt; seconds&quot;<br />
 The default (at the moment) is to remember hits for 30 seconds. Setting this too large (whichever option you choose) will cause ApacheTop to use more memory and more CPU time. My experimentation finds that remembering no more than around 5000 requests works well.</p>
<dt>-q</p>
<dd> Instructs ApacheTop to keep the querystrings, not remove them.</p>
<dt>-l</p>
<dd> Instructs ApacheTop to lowercase all URLs, thus /FOO and /foo are treated as the same and accumulate the same statistics.</p>
<dt>-s segments</p>
<dd> Instructs ApacheTop to only keep the first &lt;segments&gt; parts of the path. Trailing slashes are kept if present. Statistics are then merged for each truncated url.</p>
<dt>-p</p>
<dd> Instructs ApacheTop to keep the protocol (http:// usually) at the front of its&#8217; referrer strings. Normal behaviour is to remove them to give more room to more useful information.</p>
<dt>-r secs</p>
<dd> Set default refresh delay, in seconds.</dl>
<h2>EXAMPLES</h2>
<dl>
<dt>apachetop -f /var/logs/httpd/access.log</p>
<dd></dl>
