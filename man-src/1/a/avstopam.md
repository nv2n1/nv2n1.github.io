<h2 class="name">NAME</h2>
<p> avstopam &#8211; convert an AVS X image to a Netpbm image </p>
<h2>SYNOPSIS</h2>
<p> <code>avstopam</code> [<i>avsfile</i>] </p>
<h2>DESCRIPTION</h2>
<p> This program is part of <code><a href="/docs/linux/man/1-netpbm/">Netpbm</a></code>(1) </p>
<p> <code>avstopam</code> reads a Stardent &lt;acronym xml:lang=&quot;en&quot; title=&quot;Application Visualization System&quot;&gt;AVS&lt;/acronym&gt; X image as input and produces a Netpbm image as output. </p>
<p> <i>avsfile</i> is the input file, which defaults to Standard Input. Output is always on Standard Output. </p>
