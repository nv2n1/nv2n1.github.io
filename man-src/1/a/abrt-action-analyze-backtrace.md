<h2 class="name">NAME</h2>
 

 abrt-action-analyze-backtrace - Analyzes C/C++ backtrace, generates duplication hash, backtrace rating, and identifies crash function in problem directory DIR. 

<h2>SYNOPSIS</h2>

 

 <i>abrt-action-analyze-backtrace</i> [-v] [-d DIR]

<h2>DESCRIPTION</h2>

 

 The tool reads a file named <i>backtrace</i> from problem directory, generates duplication hash, backtrace rating, and identifies crash function. Then it saves this data as new elements <i>duphash</i>, <i>rating</i>, <i>crash_function</i> in this problem directory.

<h3>Integration with libreport events</h3>

 

 <i>abrt-action-analyze-backtrace</i> can be used as a secondary analyzer, after backtrace has been generated. The data generated by <i>abrt-action-analyze-backtrace</i> is useful for reporting the crash to bug databases: rating makes it possible to prevent reporting of bugs with low quality (non-informative) backtraces, duplication hash is used to find already filed bugs about similar crashes. 

 Example usage in report_event.conf: 

<dl>
<dt>
<dd> <pre>
EVENT=analyze analyzer=CCpp
        abrt-action-generate-backtrace || exit $?
        abrt-action-analyze-backtrace
</pre></dl>

<h2>OPTIONS</h2>

 

 -d DIR
<dl>
<dt>
<dd> Path to problem directory.</dl>
 

 -v
<dl>
<dt>
<dd> Be more verbose. Can be given multiple times.</dl>
