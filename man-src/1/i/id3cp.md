<h2>NAME</h2>
<p> id3cp &#8211; Copies tags from one file to another.</p>
<h2>SYNOPSIS</h2>
<p> <code>id3cp</code> [ <i>OPTION</i> ]<code>&#8230;</code> [ <i>SOURCE</i> ] [ <i>DEST</i> ] </p>
<h2>DESCRIPTION</h2>
<p> <code>Id3cp</code> copies tags from SOURCE to DEST.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-1, &#8211;v1tag</code></p>
<dd> Render only the id3v1 tag</p>
<dt><code>-2, &#8211;v2tag</code></p>
<dd> Render only the id3v2 tag</p>
<dt><code>-h, &#8211;help</code></p>
<dd> Display help and exit</p>
<dt><code>-v, &#8211;version</code></p>
<dd> Display version information and exit</dl>
