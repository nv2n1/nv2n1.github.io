<h2>NAME</h2>
<p> im-chooser &#8211; GUI Application to switch Input Method</p>
<h2>SYNOPSIS</h2>
<p> <code>im-chooser</code></p>
<h2>DESCRIPTION</h2>
<p> <code>im-chooser</code> provides a graphical user interface to switch Input Method being managed under imsettings.</p>
