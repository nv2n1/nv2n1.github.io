<h2>NAME</h2>
<p> idevicedate &#8211; Display the current date or set it on a device.</p>
<h2>SYNOPSIS</h2>
<p> <code>idevicedate</code> [OPTIONS] </p>
<h2>DESCRIPTION</h2>
<p> Simple utility to manage the clock on a device. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d, &#8211;debug</code></p>
<dd> enable communication debugging.</p>
<dt><code>-u, &#8211;udid UDID</code></p>
<dd> target specific device by its 40-digit device UDID.</p>
<dt><code>-s, &#8211;set TIMESTAMP</code></p>
<dd> set UTC time described by TIMESTAMP</p>
<dt><code>-c, &#8211;sync</code></p>
<dd> set time of device to current system time</p>
<dt><code>-h, &#8211;help</code></p>
<dd> prints usage information </p>
</dl>
