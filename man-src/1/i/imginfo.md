<h2 class="name">NAME</h2>
<p> imginfo &#8211; Image information utility</p>
<h2>SYNOPSIS</h2>
<p> <code>imginfo</code> [<i>options</i>] </p>
<h2>DESCRIPTION</h2>
<p> The <code>imginfo</code> command displays information about an image. Please use the &#8211;help command line switch and the JasPer Software Reference Manual for more information. </p>
