<h2>NAME</h2>
<p> idevicename &#8211; Display the device name or set it to NAME if specified.</p>
<h2>SYNOPSIS</h2>
<p> <code>idevicename</code> [OPTIONS] [NAME] </p>
<h2>DESCRIPTION</h2>
<p> Simple utility to manage the device name. </p>
<p> If called without any extra argument this tool will print the current device name. </p>
<p> If <code>NAME</code> is given the device name will be set to the name specified. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d, &#8211;debug</code></p>
<dd> enable communication debugging.</p>
<dt><code>-u, &#8211;udid UDID</code></p>
<dd> target specific device by its 40-digit device UDID.</p>
<dt><code>-h, &#8211;help</code></p>
<dd> prints usage information </p>
</dl>
