<h2 class="name">NAME</h2>
<p> imgtoppm &#8211; convert an Img-whatnot file into a portable pixmap </p>
<h2>SYNOPSIS</h2>
<p> <code>imgtoppm</code> [<i>imgfile</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reads an Img-whatnot file as input. Produces a portable pixmap as output. The Img-whatnot toolkit is available for FTP on venera.isi.edu, along with numerous images in this format.</p>
