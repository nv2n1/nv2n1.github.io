<h2>NAME</h2>
<p> ipa-advise &#8211; Provide configurations advice for various use cases.</p>
<h2>SYNOPSIS</h2>
<p> ipa-advise ADVICE</p>
<h2>DESCRIPTION</h2>
<p> Provides customized advice for various IPA configuration issues.</p>
<dl>
<dt>For the list of possible ADVICEs available, run the ipa-advise with no arguments.</p>
<dd></dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;v</code>, <code>&#8211;verbose</code></p>
<dd> Print debugging information</p>
<dt><code>-d</code>, <code>&#8211;debug</code></p>
<dd> Alias for &#8211;verbose</p>
<dt><code>-q</code>, <code>&#8211;quiet</code></p>
<dd> Output only errors</p>
<dt><code>&#8211;log-file</code>=<i>FILE</i></p>
<dd> Log to the given file</dl>
<h2>EXIT STATUS</h2>
<p> 0 if the command was successful </p>
<p> 1 if an error occurred </p>
