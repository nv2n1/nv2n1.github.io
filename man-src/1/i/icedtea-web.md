<h2 class="name">NAME</h2>
<p> <code>icedtea-web </code> provides a Free Software web browser plugin running applets written in the Java programming language and an implementation of Java Web Start, originally based on the NetX project. </p>
<p> NetX allows Java applets and applications to be downloaded over the network, cached, and (by default) run in a secure sandbox environment. Subsequent runs of the applet download the latest version automatically. Update and security settings, among others, can be set using the itw-settings command.<br />
 icedtea-web also includes a plugin to enable Java applets (</p>
<p><a rel="nofollow" href="http://www.java.com/en/download/testjava.jsp)">http://www.java.com/en/download/testjava.jsp)</a> within web browsers. </p>

<h2>DESCRIPTION</h2>
<p> <code>NetX features: </code> </p>
<dl>
<dt>Modular</p>
<dd> Easily add JNLP capabilities to an application.</p>
<dt>Saves Memory</p>
<dd> Launch programs in a shared JVM.</p>
<dt>Fast startup</p>
<dd> Runs applications from a cache for fast starting.</p>
<dt>Security</p>
<dd> Run any application in a sandbox or log its activities.</p>
<dt>Auto-Update</p>
<dd> Applications can auto-update without special code.</p>
<dt>Network Deployment</p>
<dd> Deploy to the internet, not with installers.</p>
<dt>Open Source</p>
<dd> GNU Lesser General Public License. </p>
</dl>
