<h2 class="name">NAME</h2>
<p> i3 &#8211; an improved dynamic, tiling window manager </p>
<h2>SYNOPSIS</h2>
<p> i3 [-a] [-c configfile] [-C] [-d &lt;loglevel&gt;] [-v] [-V]</p>
<h2>OPTIONS</h2>
<p> -a</p>
<dl>
<dt>
<dd> Disables autostart.</dl>
<p> -c</p>
<dl>
<dt>
<dd> Specifies an alternate configuration file path.</dl>
<p> -C</p>
<dl>
<dt>
<dd> Check the configuration file for validity and exit.</dl>
<p> -d</p>
<dl>
<dt>
<dd> Specifies the debug loglevel. To see the most output, use -d all.</dl>
<p> -v</p>
<dl>
<dt>
<dd> Display version number (and date of the last commit).</dl>
<p> -V</p>
<dl>
<dt>
<dd> Be verbose.</dl>
<h2>DESCRIPTION</h2>
<h3>INTRODUCTION</h3>
<p> i3 was created because wmii, our favorite window manager at the time, didncqt provide some features we wanted (multi-monitor done right, for example), had some bugs, didncqt progress since quite some time and wasncqt easy to hack at all (source code comments/documentation completely lacking). Still, we think the wmii developers and contributors did a great job. Thank you for inspiring us to create i3. </p>
<p> Please be aware that i3 is primarily targeted at advanced users and developers.</p>
<h3>IMPORTANT NOTE TO nVidia BINARY DRIVER USERS</h3>
<p> If you are using the nVidia binary graphics driver (also known as <i>blob</i>) you need to use the &#8211;force-xinerama flag (in your .xsession) when starting i3, like so: </p>
<dl>
<dt>
<dd>
<pre>
exec i3 --force-xinerama -V &gt;&gt;~/.i3/i3log 2&gt;&amp;1
</pre>
</dl>
<p> See also docs/multi-monitor for the full explanation.</p>
<h3>TERMINOLOGY</h3>
<p> Client</p>
<dl>
<dt>
<dd> A client is X11-speak for a window.</dl>
<p> Table</p>
<dl>
<dt>
<dd> Your workspace is managed using a table. You can move windows around and create new columns (move a client to the right) or rows (move it to the bottom) implicitly. </p>
<p> By &quot;snapping&quot; a client in a specific direction, you increase its colspan/rowspan.</dl>
<p> Container</p>
<dl>
<dt>
<dd> A container contains a variable number of clients. Each cell of the table is a container. </p>
<p> Containers can be used in various modes. The default mode is called &quot;default&quot; and just resizes each client equally so that it fits.</dl>
<p> Workspace</p>
<dl>
<dt>
<dd> A workspace is a set of clients (technically speaking, itcqs just a table). Other window managers call this &quot;Virtual Desktops&quot;. </p>
<p> In i3, each workspace is assigned to a specific virtual screen. By default, screen 1 has workspace 1, screen 2 has workspace 2 and so on&#8230; However, when you create a new workspace (by simply switching to it), itcqll be assigned the screen you are currently on.</dl>
<p> Output</p>
<dl>
<dt>
<dd> Using XRandR, you can have an X11 screen spanning multiple real monitors. Furthermore, you can set them up in cloning mode or with positions (monitor 1 is left of monitor 2). </p>
<p> i3 uses the RandR API to query which outputs are available and which screens are connected to these outputs.</dl>
<h2>KEYBINDINGS</h2>
<p> Here is a short overview of the default keybindings: </p>
<p> j/k/l/;</p>
<dl>
<dt>
<dd> Direction keys (left, down, up, right). They are on your homerow (see the mark on your &quot;j&quot; key). Alternatively, you can use the cursor keys.</dl>
<p> Mod1+&lt;direction&gt;</p>
<dl>
<dt>
<dd> Focus window in &lt;direction&gt;.</dl>
<p> Mod3+&lt;direction&gt;</p>
<dl>
<dt>
<dd> Focus container in &lt;direction&gt;.</dl>
<p> Mod1+Shift+&lt;direction&gt;</p>
<dl>
<dt>
<dd> Move window to &lt;direction&gt;.</dl>
<p> Mod3+Shift+&lt;direction&gt;</p>
<dl>
<dt>
<dd> Move container to &lt;direction&gt;.</dl>
<p> Mod1+Control+&lt;direction&gt;</p>
<dl>
<dt>
<dd> Snap container to &lt;direction&gt;.</dl>
<p> Mod1+&lt;number&gt;</p>
<dl>
<dt>
<dd> Switch to workspace &lt;number&gt;.</dl>
<p> Mod1+Shift+&lt;number&gt;</p>
<dl>
<dt>
<dd> Move window to workspace &lt;number&gt;.</dl>
<p> Mod1+f</p>
<dl>
<dt>
<dd> Toggle fullscreen mode.</dl>
<p> Mod1+h</p>
<dl>
<dt>
<dd> Enable stacking layout for the current container.</dl>
<p> Mod1+e</p>
<dl>
<dt>
<dd> Enable default layout for the current container.</dl>
<p> Mod1+Shift+Space</p>
<dl>
<dt>
<dd> Toggle tiling/floating for the current window.</dl>
<p> Mod1+t</p>
<dl>
<dt>
<dd> Select the first tiling window if the current window is floating and vice-versa.</dl>
<p> Mod1+Shift+q</p>
<dl>
<dt>
<dd> Kills the current window. This is equivalent to &quot;clicking on the close button&quot;, meaning a polite request to the application to close this window. For example, Firefox will save its session upon such a request. If the application does not support that, the window will be killed and it depends on the application what happens.</dl>
<p> Mod1+Shift+r</p>
<dl>
<dt>
<dd> Restarts i3 in place (without losing any windows, but at this time, the layout and placement of windows is not retained).</dl>
<p> Mod1+Shift+e</p>
<dl>
<dt>
<dd> Exits i3.</dl>

<dl>
<dt>

<dl>
<dt>

<dl>
<dt>
<dd> 4. /etc/i3/config</dl>

<h3>~/.xsession</h3>
<p> This file is where you should configure your locales and start i3. It is run by your login manager (xdm, slim, gdm, &#8230;) as soon as you login. </p>
<p> <code>Sample xsession</code>. </p>
<dl>
<dt>
<dd>
<pre>
# Disable DPMS turning off the screen
xset dpms force on
xset s off
# Disable bell
xset -b
# Enable zapping (C-A-&lt;Bksp&gt; kills X)
setxkbmap -option terminate:ctrl_alt_bksp
# Enforce correct locales from the beginning
unset LC_COLLATE
export LC_CTYPE=de_DE.UTF-8
export LC_TIME=de_DE.UTF-8
export LC_NUMERIC=de_DE.UTF-8
export LC_MONETARY=de_DE.UTF-8
export LC_MESSAGES=C
export LC_PAPER=de_DE.UTF-8
export LC_NAME=de_DE.UTF-8
export LC_ADDRESS=de_DE.UTF-8
export LC_TELEPHONE=de_DE.UTF-8
export LC_MEASUREMENT=de_DE.UTF-8
export LC_IDENTIFICATION=de_DE.UTF-8
# Use XToolkit in java applications
export AWT_TOOLKIT=XToolkit
# Set background color
xsetroot -solid &quot;#333333&quot;
# Enable core dumps in case something goes wrong
ulimit -c unlimited
# Start i3 and log to ~/.i3/logfile
echo &quot;Starting at $(date)&quot; &gt;&gt; ~/.i3/logfile
exec /usr/bin/i3 -V -d all &gt;&gt; ~/.i3/logfile
</pre>
</dl>
