<h2>NAME</h2>
<p> intel_bios_reader &#8211; Parses an Intel BIOS and displays many of its tables</p>
<h2>SYNOPSIS</h2>
<p> <code>intel_bios_reader </code><i>filename</i></p>
<h2>DESCRIPTION</h2>
<p> <code>intel_bios_reader</code> is a tool to parse the contents of an Intel video BIOS file. The file can come from intel_bios_dumper. This can be used for quick debugging of video bios table handling, which is harder when done inside of the kernel graphics driver.</p>
