<h2>NAME</h2>
<p> <code>ibtoopdiff &#8211; Fabric Topology Matcher</code></p>
<h2>SYNOPSYS</h2>
<p> ibtopodiff [-v][-h] -t &lt;topo file&gt; -d &lt;subnet file&gt; -s &lt;start node name&gt;<br />
&nbsp;<wbr>&nbsp;<wbr>-p&nbsp;<wbr>&lt;start port num&gt;&nbsp;<wbr>-g&nbsp;<wbr>&lt;start port guid&gt;</p>
<h2>DESCRIPTION</h2>
<p> This utility performs matching between a given topology file (see man <code>ibdm-topology-file</code>) and a <code>subnet.lst file</code> (this file provides a dump of all links in the discovered fabric and generated by ibdiagnet or OpenSM).</p>
<h2>ARGUMENTS</h2>
<dl>
<dt>-t|&#8211;topology &lt;file&gt;</p>
<dd> Topology file. See man <code>ibdm-topology-file</code> for its definition.</p>
<dt>-d|&#8211;discovered &lt;file&gt;</p>
<dd> subnet.lst file produced by <code>OpenSM</code> or <code>ibdiagnet</code></p>
<dt>-s|&#8211;start-node &lt;name&gt;</p>
<dd> The name of the matching start node, also known as anchor node. E.g. H-1/U1</p>
<dt>-p|&#8211;port-num &lt;num&gt;</p>
<dd> The number of the matching start port, also known as anchor port</p>
<dt>-g|&#8211;port-guid &lt;guid&gt;</p>
<dd> The guid of the matching start port</dl>
<h2>OPTIONS</h2>
<dl>
<dt>-v|&#8211;verbose</p>
<dd> Verbsoe mode</p>
<dt>-h|&#8211;help</p>
<dd> Provides this help message</dl>
