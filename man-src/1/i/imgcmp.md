<h2 class="name">NAME</h2>
<p> imgcmp &#8211; Image comparison utility</p>
<h2>SYNOPSIS</h2>
<p> <code>imgcmp</code> [<i>options</i>] </p>
<h2>DESCRIPTION</h2>
<p> The <code>imgcmp</code> command compares two images of the same geometry with respect to a given metric. Please use the &#8211;help command line switch and the JasPer Software Reference Manual for more information. </p>
