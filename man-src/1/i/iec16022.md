<h2>NAME</h2>
<p> iec16022 &#8211; program to generate 2d barcodes</p>
<h2>SYNOPSIS</h2>
<p> <code>iec16022</code> [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>iec16022</code> command. </p>
<p> <code>iec16022</code> generates 2d barcodes conforming to the ISO/IEC 16022 standard (which is also known as Data Matrix and Semacode).</p>
<h2>OPTIONS</h2>
<p> These programs follow the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-s, &#8211;size WxH</code></p>
<dd> Sets the size of the generated barcode.</p>
<dt><code>-c, &#8211;barcode text</code></p>
<dd> Specifies the text to be encoded.</p>
<dt><code>&#8211;ecc 000|050|080|100|140|200</code></p>
<dd> Sets the type of ecc to be used.</p>
<dt><code>-i, &#8211;infile filename</code></p>
<dd> Read input data from file.</p>
<dt><code>-o, &#8211;outfile filenmae</code></p>
<dd> Save output to file (instead of standard output).</p>
<dt><code>-f, &#8211;format Text|EPS|Bin|Hex|Stamp|PNG</code></p>
<dd> Set the output type.</p>
<dt><code>-?, &#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>&#8211;usage</code></p>
<dd> Show short overview of options.</dl>
<h2>EXAMPLE</h2>
<p> To produce a datamatrix barcode for foobar in PNG format you need the following arguments:</p>
<dl>
<dt><code>iec16022 -f PNG -c foobar -o foobar.png</code></p>
<dd></dl>
