<h2 class="name">NAME</h2>
<p> insync &#8211; command line interface for the Insync process </p>
<h2>SYNOPSIS</h2>
<p> <code>insync [COMMAND] [ARGUMENT]&#8230;</code></p>
<h2>DESCRIPTION</h2>
<p> Command line interface for the Insync process. Insync is an application that syncs all your Google Drive &amp; OneDrive accounts to your local filesystem. It integrates with your file manager so you can use your Google Drive or OneDrive files locally while getting the benefits of the cloud. Sync any local folder, sync multiple accounts and sync across Linux, Windows and Mac. </p>
<h2>COMMANDS</h2>
<h3><code>Help command</code></h3>
<dl>
<dt><code>insync [COMMAND] &#8211;help</p>
<dd> If COMMAND is given, shows the help message for it; if not, show the basic help message.</dl>
<p> </code></p>
<h3><code>Commands for controlling Insync</code></h3>
<dl>
<dt><code>insync </code><i>start </i><code>[OPTION]&#8230;</p>
<dd> Start Insync. </p>
<p> Options: </p>
<p> &#8211;no-daemon &#8211; don&#8217;t detach from the terminal, log output to stdout </p>
<dt>insync </code><i>show</p>
<dd> Show Insync. </p>
<dt></i><code>insync </code><i>hide</p>
<dd> Hide Insync. </p>
</dl>
<p> </i></p>
<h3><code>File commands</code></h3>
<dl>
<dt><code>insync </code><i>open-gdlink-file </i><code>FULL_PATH</p>
<dd> Open the selected google docs link file (.gddocs) in Web browser. </p>
</dl>
<p> </code></p>
