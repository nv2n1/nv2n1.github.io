<h2>NAME</h2>
<p> <code>ipcluster &#8211; start a cluster for IPython parallel computing </code></p>
<h2>SYNOPSIS</h2>
<p> <code>ipcluster subcommand</code> [<i>options</i>] </p>
<h2>DESCRIPTION</h2>
<p> Start an IPython cluster for parallel computing. </p>
<p> For more information on how to use ipcluster, see &#8216;ipcluster &#8211;help&#8217;, or &#8216;ipcluster &#8211;help-all&#8217; for all available command-line options. </p>
