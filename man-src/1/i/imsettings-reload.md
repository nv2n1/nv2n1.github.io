<h2>NAME</h2>
<p> imsettings-reload &#8211; Reload imsettings-daemon</p>
<h2>SYNOPSIS</h2>
<p> <code>imsettings-reload</code> [ <code>-h</code> ] [ <code>&#8211;help</code> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>imsettings-reload</code> sends a request to imsettings-daemon to be restarted. this would particularly helps when the software is upgraded or something went wrong. pleaes note that this requires restarting Input Method as well.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
