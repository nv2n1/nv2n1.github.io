<h2>Name</h2>

 isnum - Return code telling whether the input string is numerical

<h2>Synopsis</h2>

 isnum string 

<h2>Description</h2>

 <i>isnum</i> is a utility for identifying and classifying an input string. &lt;B&gt;isnum&lt;/B&gt; returns an integer code depending on how it identifies the input number: 0: string is not any sort of number 1: String is an integer 2: String is a floating point number 3: String is a hh:mm:ss.ss time 4: String is a yyyy-mm-dd date
