<h2>NAME</h2>
<p> imlib_config &#8211; Imlib Configuration Editor</p>
<h2>SYNOPSIS</h2>
<p> <code>imlib_config</code></p>
<h2>DESCRIPTION</h2>
<p> <code>imlib_config</code> is a program that is used to customize the Imlib library run-time configuration. Customizable aspects of Imlib include the color palette, rendering characterstics, and color correction. </p>
<p> Note that <code>imlib_config</code> is not the same as the <code>imlib-config</code> script.</p>
