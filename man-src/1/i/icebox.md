<h2 class="name">NAME</h2>
<p> icebox &#8211; The IceBox C++ service daemon.</p>
<h2>SYNOPSIS</h2>
<p> icebox [options] </p>
<h2>DESCRIPTION</h2>
<p> IceBox is an easy-to-use framework for Ice application services. Full documentation for IceBox is available online at:<br />
 &quot;<a rel="nofollow" href="http://doc.zeroc.com/display/Ice/IceBox">http://doc.zeroc.com/display/Ice/IceBox</a>&quot;. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>
 Displays a help message. </p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> Displays the Ice version. </p>
<dt><code>&#8211;nowarn</code></p>
<dd>
 Suppress warnings. </p>
<dt><code>&#8211;daemon</code></p>
<dd>
 Run as a daemon. </p>
<dt><code>&#8211;pidfile</code> <code>FILE</code></p>
<dd>
 Write process ID into FILE. </p>
<dt><code>&#8211;noclose</code></p>
<dd>
 Do not close open file descriptors. </p>
<dt><code>&#8211;nochdir</code></p>
<dd>
 Do not change the current working directory. </p>
</dl>
