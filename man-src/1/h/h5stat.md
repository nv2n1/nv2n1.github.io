<h2>NAME</h2>
<p> h5stat: &#8211; Reports statistics regarding an HDF5 file and the objects in the file.</p>
<h2>SYNOPSIS</h2>
<p> <code>h5stat</code> [<i>OPTIONS</i>] <i>file</i></p>
<h2>DESCRIPTION</h2>
<dl>
<dt>
<dd> OPTIONS</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Print a usage message and exit</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print version number and exit</p>
<dt><code>-f</code>, <code>&#8211;file</code></p>
<dd> Print file information</p>
<dt><code>-F</code>, <code>&#8211;filemetadata</code></p>
<dd> Print file space information for file&#8217;s metadata</p>
<dt><code>-g</code>, <code>&#8211;group</code></p>
<dd> Print group information</p>
<dt><code>-G</code>, <code>&#8211;groupmetadata</code></p>
<dd> Print file space information for groups&#8217; metadata</p>
<dt><code>-d</code>, <code>&#8211;dset</code></p>
<dd> Print dataset information</p>
<dt><code>-D</code>, <code>&#8211;dsetmetadata</code></p>
<dd> Print file space information for datasets&#8217; metadata</p>
<dt><code>-T</code>, <code>&#8211;dtypemetadata</code></p>
<dd> Print datasets&#8217; datatype metadata</p>
<dt><code>-A</code>, <code>&#8211;attribute</code></p>
<dd> Print attribute information</dl>
