<h2>NAME</h2>
<p> HexChat &#8211; IRC Client</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> hexchat [OPTION&#8230;] URL</dl>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show help options</p>
<dt><code>&#8211;help-all</code></p>
<dd> Show all help options</p>
<dt><code>&#8211;help-gtk</code></p>
<dd> Show GTK+ Options</dl>
<h3>Application Options:</h3>
<dl>
<dt><code>-a</code>, <code>&#8211;no-auto</code></p>
<dd> Don&#8217;t auto connect to servers</p>
<dt><code>-d</code>, <code>&#8211;cfgdir</code>=<i>PATH</i></p>
<dd> Use a different config directory</p>
<dt><code>-n</code>, <code>&#8211;no-plugins</code></p>
<dd> Don&#8217;t auto load any plugins</p>
<dt><code>-p</code>, <code>&#8211;plugindir</code></p>
<dd> Show plugin auto-load directory</p>
<dt><code>-u</code>, <code>&#8211;configdir</code></p>
<dd> Show user config directory</p>
<dt><code>&#8211;url</code>=<i>URL</i></p>
<dd> Open an <a href="irc://server:port/channel?key">irc://server:port/channel?key</a> URL</p>
<dt><code>-c</code>, <code>&#8211;command</code>=<i>COMMAND</i></p>
<dd> Execute command:</p>
<dt><code>-e</code>, <code>&#8211;existing</code></p>
<dd> Open URL or execute command in an existing HexChat</p>
<dt><code>&#8211;minimize</code>=<i>level</i></p>
<dd> Begin minimized. Level 0=Normal 1=Iconified 2=Tray</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> Show version information</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use </p>
</dl>
