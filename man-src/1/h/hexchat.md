<h2>NAME</h2>
<p> HexChat &#8211; IRC Client</p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
</dt><dd> hexchat [OPTION&#8230;] URL</dd></dl>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></dt>
<dd> Show help options</dd>
<dt><code>&#8211;help-all</code></dt>
<dd> Show all help options</dd>
<dt><code>&#8211;help-gtk</code></dt>
<dd> Show GTK+ Options</dd></dl>
<h3>Application Options:</h3>
<dl>
<dt><code>-a</code>, <code>&#8211;no-auto</code></dt>
<dd> Don&#8217;t auto connect to servers</dd>
<dt><code>-d</code>, <code>&#8211;cfgdir</code>=<i>PATH</i></dt>
<dd> Use a different config directory</dd>
<dt><code>-n</code>, <code>&#8211;no-plugins</code></dt>
<dd> Don&#8217;t auto load any plugins</dd>
<dt><code>-p</code>, <code>&#8211;plugindir</code></dt>
<dd> Show plugin auto-load directory</dd>
<dt><code>-u</code>, <code>&#8211;configdir</code></dt>
<dd> Show user config directory</dd>
<dt><code>&#8211;url</code>=<i>URL</i></dt>
<dd> Open an <a href="irc://server:port/channel?key">irc://server:port/channel?key</a> URL</dd>
<dt><code>-c</code>, <code>&#8211;command</code>=<i>COMMAND</i></dt>
<dd> Execute command:</dd>
<dt><code>-e</code>, <code>&#8211;existing</code></dt>
<dd> Open URL or execute command in an existing HexChat</dd>
<dt><code>&#8211;minimize</code>=<i>level</i></dt>
<dd> Begin minimized. Level 0=Normal 1=Iconified 2=Tray</dd>
<dt><code>-v</code>, <code>&#8211;version</code></dt>
<dd> Show version information</dd>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></dt>
<dd> X display to use </dd>
</dl>
