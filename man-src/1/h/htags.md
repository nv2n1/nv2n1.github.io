<h2>NAME</h2>
<p> htags &#8211; generate hypertext from source code.</p>
<h2>SYNOPSIS</h2>
<p> <code>htags</code> [-acDfFghInosTvwx][-d <i>dbpath</i>][-m <i>name</i>][-S <i>cgidir</i>][-t <i>title</i>][<i>dir</i>] </p>
<h2>DESCRIPTION</h2>
<p> <code>Htags</code> makes hypertext of C, C++, Yacc, Java, PHP and Assembly source code. </p>
<p> In advance of using this command, you must execute <code><a href="/docs/linux/man/1-gtags/">gtags</a></code>(1) from the root directory of the source tree. Then you can execute <code>htags</code> from the same place. <code>Htags</code> makes an directory named &#8216;HTML&#8217; and generates hypertext in it. You can start browsing from &#8216;HTML/index.html&#8217;. </p>
<p> Since <code>htags</code> generates static hypertext as long as the <code>-D</code> or <code>-f</code> option is not specified, you can move it anywhere and browse it by any browser without web server. </p>
<p> You must use same parser for both <code><a href="/docs/linux/man/1-gtags/">gtags</a></code>(1) and <code>htags</code>. If you use the default parser, it is not necessary to consider for it. </p>
<h2>OPTIONS</h2>
<p> If you are new on htags, it is recommended to invoke with the <code>&#8211;suggest</code> option. With the option, <code>htags</code> use popular options instead of you.<br />
 The following options are available:</p>
<dl>
<dt><code>-a</code>, <code>&#8211;alphabet</code></p>
<dd> Make an alphabetical function index which is suitable for a large project.</p>
<dt><code>&#8211;caution</code></p>
<dd> Include caution message to prohibit downloading.</p>
<dt><code>-c</code>, <code>&#8211;compact</code></p>
<dd> Compress html files by <code><a href="/docs/linux/man/1-gzip/">gzip</a></code>(1). You need to set up a web server so that <code><a href="/docs/linux/man/1-gzip/">gzip</a></code>(1) is invoked for each compressed file. See &#8216;HTML/.htaccess&#8217; that is generated by htags.</p>
<dt><code>&#8211;cvsweb</code> <i>url</i></p>
<dd> Include cvsweb URL. <i>url</i> is used as base of URL. When directory &#8216;CVS&#8217; exists in the root directory of source project, the content of &#8216;CVS/Repository&#8217; is used as the relative path from the base.</p>
<dt><code>&#8211;cvsweb-cvsroot</code> <i>cvsroot</i></p>
<dd> Specifies cvsroot in cvsweb URL.</p>
<dt><code>-D</code>, <code>&#8211;dynamic</code></p>
<dd> Generate object lists dynamically using CGI program. By default, object lists are generated statically. Though this option decrease both the size and the generation time of the hypertext, you need to set up a web server, and you cannot move the hypertext from the source directory.</p>
<dt><code>-d</code>, <code>&#8211;dbpath</code> <i>dbpath</i></p>
<dd> Specifies the directory in which &#8216;GTAGS&#8217; and &#8216;GRTAGS&#8217; exist. The default is the current directory.</p>
<dt><code>&#8211;disable-grep</code></p>
<dd> Disable grep in the search form(-f,&#8211;form).</p>
<dt><code>-F</code>, <code>&#8211;frame</code></p>
<dd> Use frame for each part of the contents.</p>
<dt><code>-f</code>, <code>&#8211;form</code></p>
<dd> Support search form using CGI program. You need to set up a web server, and you cannot move the hypertext from the source directory.</p>
<dt><code>&#8211;full-path</code></p>
<dd> List file names with full path in the file index. By default, list just the last component of a path.</p>
<dt><code>-g</code>, <code>&#8211;gtags</code></p>
<dd> Execute <code><a href="/docs/linux/man/1-gtags/">gtags</a></code>(1) before creating hypertext. The <code>-v</code>, <code>-w</code> and <i>dbpath</i> are passed to <code>gtags</code>.</p>
<dt><code>&#8211;gtagsconf</code> <i>file</i></p>
<dd> Load user&#8217;s configuration from <i>file</i>.</p>
<dt><code>&#8211;gtagslabel</code> <i>label</i></p>
<dd> <i>label</i> is used for the label of configuration file. The default is default.</p>
<dt><code>-h</code>, <code>&#8211;func-header</code>[=<i>position</i>]</p>
<dd> Insert function header for each function. By default, <code>htags</code> doesn&#8217;t generates it. You can specify the position using <i>position</i> argument, which allows one of before, right and after. The default position is after.</p>
<dt><code>-I</code>, <code>&#8211;icon</code></p>
<dd> Use icons instead of text for some links.</p>
<dt><code>&#8211;insert-footer</code> <i>file</i></p>
<dd> Insert custom footer derived from <i>file</i> before &lt;/body&gt; tag.</p>
<dt><code>&#8211;insert-header</code> <i>file</i></p>
<dd> Insert custom header derived from <i>file</i> after &lt;body&gt; tag.</p>
<dt><code>&#8211;item-order</code> <i>spec</i></p>
<dd> Specify order of items in the top page. The <i>spec</i> is a string consists of item signs in order. Each sign means as follows: <code>c</code>: caution, <code>s</code>: search form, <code>m</code>: mains, <code>d</code>: definition, <code>f</code>: files. The default is <i>csmdf</i>.</p>
<dt><code>-m</code>, <code>&#8211;main-func</code> <i>name</i></p>
<dd> Specify the main function name. The default is main.</p>
<dt><code>-n</code>, <code>&#8211;line-number</code>[=<i>columns</i>]</p>
<dd> Print line numbers. By default, doesn&#8217;t print line numbers. The default value of <i>columns</i> is 4.</p>
<dt><code>&#8211;no-map-file</code></p>
<dd> Doesn&#8217;t generate &#8216;MAP&#8217; and &#8216;FILEMAP&#8217; file. By default, <code>htags</code> generates them.</p>
<dt><code>-o</code>, <code>&#8211;other</code></p>
<dd> Pick up not only source files but also other files except for binary files.</p>
<dt><code>-S</code>, <code>&#8211;secure-cgi</code> <i>cgidir</i></p>
<dd> Write CGI programs into the <i>cgidir</i> to realize a centralised CGI program. Script alias is &#8216;/cgi-bin&#8217; by default. You can overwrite this value using config variable script_alias in &#8216;gtags.conf&#8217;.</p>
<dt><code>-s</code>, <code>&#8211;symbol</code></p>
<dd> Make anchors not only for object definitions and references but also other symbols.</p>
<dt><code>&#8211;statistics</code></p>
<dd> Print statistics information.</p>
<dt><code>&#8211;suggest</code></p>
<dd> <code>Htags</code> selects popular options instead of beginners. It is equivalent to &#8216;-afghInosTxv &#8211;show-position&#8217; now.</p>
<dt><code>-T</code>, <code>&#8211;table-flist</code>[=<i>fields</i>]</p>
<dd> Generate file list using &lt;table&gt; tag. The <i>fields</i> is used for field number in a line. The default is 5.</p>
<dt><code>-t</code>, <code>&#8211;title</code> <i>title</i></p>
<dd> The <i>title</i> of this hypertext. The default is the last component of the current directory.</p>
<dt><code>&#8211;table-list</code></p>
<dd> List tags using &lt;table&gt; tag.</p>
<dt><code>&#8211;tabs </code><i>number</i></p>
<dd> Tab stop. The default is 8.</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Verbose mode.</p>
<dt><code>-w</code>, <code>&#8211;warning</code></p>
<dd> Print warning messages.</p>
<dt><code>-x</code>, <code>&#8211;xhtml</code>[=<i>version</i>]</p>
<dd> Generate XHTML hypertext instead of HTML. If the <code>&#8211;frame</code> option is specified then generate XHTML-1.0 Frameset for index.html and generate XHTML-1.0 Transitional for other files, else if <i>version</i> is 1.1 or config variable xhtml_version is set to 1.1 then generate XHTML-1.1 else XHTML 1.0 Transitional.</p>
<dt><i>dir</i></p>
<dd> The directory in which hypertext is generated. The default is the current directory.</dl>
<h2>EXAMPLES</h2>
<pre>
        $ gtags -v
        $ htags -sanohITvt 'Welcome to XXX source tour!'
        $ firefox HTML/index.html
        $ htags --suggest
</pre>
<h2>FILES</h2>
<dl>
<dt>&#8216;GTAGS&#8217;</p>
<dd> Tag file for object definitions.</p>
<dt>&#8216;GRTAGS&#8217;</p>
<dd> Tag file for object references.</p>
<dt>&#8216;GSYMS&#8217;</p>
<dd> Tag file for other symbols.</p>
<dt>&#8216;GPATH&#8217;</p>
<dd> Tag file for path of source files.</p>
<dt>&#8216;/etc/gtags.conf&#8217;, &#8216;$HOME/.globalrc&#8217;</p>
<dd> Configuration file.</p>
<dt>&#8216;HTML/index.html&#8217;</p>
<dd> Index file for hypertext.</p>
<dt>&#8216;HTML/MAP&#8217;</p>
<dd> Mapping file for converting tag into path of hypertext. External systems can utilize this file.</p>
<dt>&#8216;HTML/FILEMAP&#8217;</p>
<dd> Mapping file for converting file name into path of hypertext. External systems can utilize this file.</p>
<dt>&#8216;HTML/style.css&#8217;</p>
<dd> Style sheet file. This file is generated when the <code>&#8211;xhtml</code> option is specified.</dl>
<h2>ENVIRONMENT</h2>
<p> The following environment variables affect the execution of <code>htags</code>:</p>
<dl>
<dt><code>TMPDIR</code></p>
<dd> If this variable is set, its value is used as the directory to make temporary files. The default is &#8216;/tmp&#8217;.</p>
<dt><code>GTAGSCONF</code></p>
<dd> If this variable is set, its value is used as the configuration file. The default is &#8216;$HOME/.globalrc&#8217;.</p>
<dt><code>GTAGSLABEL</code></p>
<dd> If this variable is set, its value is used as the label of configuration file. The default is default.</p>
<dt><code>GTAGSCACHE</code></p>
<dd> If this variable is set, its value is used as the size of B-tree cache. The default is 50000000 (bytes).</p>
<dt><code>GTAGSFORCECPP</code></p>
<dd> If this variable is set, each file whose suffix is &#8216;h&#8217; is treated as a C++ source file.</dl>
<h2>CONFIGURATION</h2>
<p> The following configuration variables affect the execution of <code>htags</code>: If the <code>&#8211;xhtml</code> option is specified then all definitions of HTML tag are ignored. Instead, you can customize the appearance using style sheet file (&#8216;style.css&#8217;).</p>
<dl>
<dt>body_begin(string)</p>
<dd> Begin tag for body. The default is &#8216;&lt;body text=#191970 bgcolor=#f5f5dc vlink=gray&gt;&#8217;.</p>
<dt>body_end(string)</p>
<dd> End tag for body. The default is &#8216;&lt;/body&gt;&#8217;.</p>
<dt>brace_begin(string)</p>
<dd> Begin tag for brace. The default is &#8216;&lt;font color=red&gt;&#8217;.</p>
<dt>brace_end(string)</p>
<dd> End tag for brace. The default is &#8216;&lt;/font&gt;&#8217;.</p>
<dt>colorize_warned_line(boolean)</p>
<dd> Colorize warned line using warned_line_begin and warned_line_end. The default is false.</p>
<dt>comment_begin(string)</p>
<dd> Begin tag for comments. The default is &#8216;&lt;i&gt;&lt;font color=green&gt;&#8217;.</p>
<dt>comment_end(string)</p>
<dd> End tag for comments. The default is &#8216;&lt;/font&gt;&lt;/i&gt;&#8217;.</p>
<dt>copy_files(boolean)</p>
<dd> Copy files instead of linking. When the <code>-f</code> option is used, <code>htags</code> make links of tag files in &#8216;cgi-bin&#8217; directory by default.</p>
<dt>datadir(string)</p>
<dd> Shared data directory. The default is &#8216;/usr/local/share&#8217; but you can change the value using configure script. <code>Htags</code> look up template files in the &#8216;gtags&#8217; directory in this data directory.</p>
<dt>definition_header(no|before|right|after)</p>
<dd> Position of function header. The default is &#8216;no&#8217;.</p>
<dt>disable_grep(boolean)</p>
<dd> Disable grep in search form(-f,&#8211;form). The default is false.</p>
<dt>dynamic(boolean)</p>
<dd> Generate object list dynamically.</p>
<dt>enable_idutils(boolean)</p>
<dd> Enable idutils in search form(-f,&#8211;form). The default is false.</p>
<dt>flist_fields(number)</p>
<dd> Field number of file index. The default is 5.</p>
<dt>full_path(boolean)</p>
<dd> List file names with full path in file index. By default, list just the last component of a path.</p>
<dt>gzipped_suffix(string)</p>
<dd> Suffix for compressed html file. The default is &#8216;ghtml&#8217;.</p>
<dt>hr(string)</p>
<dd> Horizontal rules. The default is &#8216;&lt;hr&gt;&#8217;.</p>
<dt>htags_options(string)</p>
<dd> Default options for <code>htags</code>. This value is inserted into the head of arguments.</p>
<dt>include_file_suffixes(comma separated list)</p>
<dd> Suffixes of include file. The default is &#8216;h,hxx,hpp,H,inc.php&#8217;.</p>
<dt>langmap(comma separated list)</p>
<dd> Language mapping. Each comma-separated map consists of the language name, a colon, and a list of file extensions. Default mapping is &#8216;c:.c.h,yacc:.y,asm:.s.S,java:.java,cpp:.c++.cc.cpp.cxx.hxx.hpp.C.H,php:.php.php3.phtml&#8217;.</p>
<dt>ncol(number)</p>
<dd> Columns of line number. The default is 4.</p>
<dt>normal_suffix(string)</p>
<dd> Suffix for normal html file. The default is &#8216;html&#8217;.</p>
<dt>no_map_file(boolean)</p>
<dd> Doesn&#8217;t generate &#8216;MAP&#8217; and &#8216;FILEMAP&#8217; file. The default is false.</p>
<dt>other_files(boolean)</p>
<dd> File index includes not only source files but also other files. The default is false.</p>
<dt>position_begin(string)</p>
<dd> Begin tag for position mark. The default is &#8216;&lt;font color=gray&gt;&#8217;.</p>
<dt>position_end(string)</p>
<dd> End tag for position mark. The default is &#8216;&lt;/font&gt;&#8217;.</p>
<dt>reserved_begin(string)</p>
<dd> Begin tag for reserved word. The default is &#8216;&lt;b&gt;&#8217;.</p>
<dt>reserved_end(string)</p>
<dd> End tag for reserved word. The default is &#8216;&lt;/b&gt;&#8217;.</p>
<dt>script_alias(string)</p>
<dd> Script alias for safe cgi script (<code>-S</code>).</p>
<dt>sharp_begin(string)</p>
<dd> Begin tag for &#8216;define&#8217;. The default is &#8216;&lt;font color=darkred&gt;&#8217;.</p>
<dt>sharp_end(string)</p>
<dd> End tag for &#8216;define&#8217;. The default is &#8216;&lt;/font&gt;&#8217;.</p>
<dt>show_position(boolean)</p>
<dd> Show position per function definition. The default is false.</p>
<dt>table_begin(string)</p>
<dd> Begin tag for table. The default is &#8216;&lt;table&gt;&#8217;.</p>
<dt>table_end(string)</p>
<dd> End tag for table. The default is &#8216;&lt;/table&gt;&#8217;.</p>
<dt>table_flist(boolean)</p>
<dd> Use &lt;table&gt; tag for file index. The default is false.</p>
<dt>table_list(boolean)</p>
<dd> List tags using &lt;table&gt; tag. The default is false.</p>
<dt>tabs(number)</p>
<dd> Tab stop. The default is 8.</p>
<dt>title_begin(string)</p>
<dd> Begin tag for Title. The default is &#8216;&lt;h1&gt;&lt;font color=#cc0000&gt;&#8217;.</p>
<dt>title_end(string)</p>
<dd> End tag for Title. The default is &#8216;&lt;/font&gt;&lt;/h1&gt;&#8217;.</p>
<dt>warned_line_begin(string)</p>
<dd> Begin tag for line which htags warned. The default is &#8216;&lt;span style=&quot;background-color:yellow&quot;&gt;&#8217;.</p>
<dt>warned_line_end(string)</p>
<dd> End tag for line which htags warned. The default is &#8216;&lt;/span&gt;&#8217;.</p>
<dt>xhtml_version(1.0|1.1)</p>
<dd> XHTML version. 1.0 and 1.1 are acceptable. The default is 1.0.</dl>
<h2>DIAGNOSTICS</h2>
<p> <code>Htags</code> exits with a non 0 value if an error occurred, 0 otherwise.</p>
<h2>MESSAGE FORMAT</h2>
<p> Verbose message has important level. The most important level is 0, the second it 1 and so on. All the message has level numbers leading blanks.</p>
