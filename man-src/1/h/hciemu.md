<h2 class="name">NAME</h2>
<p> hciemu &#8211; HCI emulator </p>
<h2>SYNOPSIS</h2>
<p> <code>hciemu</code> [<i>options</i>] <i>local_address</i> </p>
<h2>DESCRIPTION</h2>
<p> <code>hciemu</code> is used to emulate an HCI via <code>hci_vhci</code> kernel module </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-d&nbsp;<wbr></code><i>device</i></p>
<dd> use specified <i>device</i></p>
<dt><code>-b&nbsp;<wbr></code><i>bdaddr</i></p>
<dd> emulate <i>bdaddr</i></p>
<dt><code>-s&nbsp;<wbr></code><i>file</i></p>
<dd> create snoop file <i>file</i></p>
<dt><code>-n</code></p>
<dd> do not detach </p>
</dl>
