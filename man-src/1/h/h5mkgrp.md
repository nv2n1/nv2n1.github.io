<h2>NAME</h2>
<p> h5mkgrp: &#8211; Creates a new HDF5 group in a file</p>
<h2>DESCRIPTION</h2>
<p> usage: h5mkgrp [OPTIONS] FILE GROUP&#8230;</p>
<dl>
<dt>
<dd> OPTIONS</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Print a usage message and exit</p>
<dt><code>-l</code>, <code>&#8211;latest</code></p>
<dd> Use latest version of file format to create groups</p>
<dt><code>-p</code>, <code>&#8211;parents</code></p>
<dd> No error if existing, make parent groups as needed</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Print information about OBJECTS and OPTIONS</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print version number and exit</dl>
