<h2>NAME</h2>
<p> hppwd &#8212; print the current working directory on an HFS+ volume</p>
<h2>SYNOPSIS</h2>
<p> <code>hppwd</code></p>
<h2>Description</h2>
<p> <code>hppwd</code> prints the absolute pathname to the current directory on the previously mounted HFS+ volume. Note that individual volume and directory names in the path are separated with slashes &quot;/&quot; instead of the Macintosh-style colons &quot;:&quot;.<br />
&nbsp;</p>
