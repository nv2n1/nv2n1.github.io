<h2>NAME</h2>
<p> holland_cvmysqlsv &#8211; Holland Addon for CommVault Support</p>
<h2>SYNOPSIS</h2>
<p> holland_cvmysqlsv [&#8211;config-file|-c &lt;config-file&gt;]</p>
<h2>DESCRIPTION</h2>
<p> holland_cvmysqlsv is a wrapper script that is called by the commvault backup system. This script runs the backup subcommand with no arguments.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;config=</code><i>&lt;file&gt;</i></p>
<dd> Read configuration settings from &lt;file&gt;, if it exists.</p>
<dt><code>&#8211;quiet</code>,<code> -q</code></p>
<dd> Terbse output</p>
<dt><code>&#8211;verbose</code>,<code> -v</code></p>
<dd> Verbose output</p>
<dt><code>&#8211;version</code>,<code> -V</code></p>
<dd> Show this program&#8217;s version number and exit.</p>
<dt><code>&#8211;help</code>,<code> -h</code></p>
<dd> Show this help message and exit.</dl>
