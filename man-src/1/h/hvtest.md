<h2 class="name">NAME</h2>
<p> hvtest &#8211; test cases for QDBM Hovel</p>
<h2>SYNOPSIS</h2>
<p> <code>hvtest write</code> [-qdbm] [-s] <i>name</i> <i>rnum</i><br />
 <code>hvtest read</code> [-qdbm] <i>name</i> <i>rnum</i> </p>
<h2>DESCRIPTION</h2>
<p> The command `hvtest&#8217; is a utility for facility test and performance test. Check a database generated by the command or measure the execution time of the command. This command is used in the following format. `name&#8217; specifies a database name. `rnum&#8217; specifies the number of records. </p>
<dl>
<dt><code>hvtest write [-qdbm] [-s] name rnum</code></p>
<dd> Store records with keys of 8 bytes. They changes as `00000001&#8242;, `00000002&#8217;&#8230;</p>
<dt><code>hvtest read [-qdbm] name rnum</code></p>
<dd> Retrieve records of the database above.</dl>
<p> Options feature the following. </p>
<dl>
<dt>
<dd> <code>-qdbm</code> : use `gdbm_open2&#8242; and open the handle as Curia.<br />
 <code>-s</code> : make the file sparse.</dl>
<p> This command returns 0 on success, another on failure. </p>
