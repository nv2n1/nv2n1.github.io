<h2>NAME</h2>
<p> halberd &#8211; manual page for halberd 0.2.4 (14-Aug-2010)</p>
<h2>DESCRIPTION</h2>
<p> Usage: halberd [OPTION]&#8230; URL </p>
<p> Discover web servers behind HTTP load balancers.</p>
<h3>Options:</h3>
<dl>
<dt><code>&#8211;version</code></p>
<dd> show program&#8217;s version number and exit</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> explain what is being done</p>
<dt><code>-q</code>, <code>&#8211;quiet</code></p>
<dd> run quietly</p>
<dt><code>-d</code>, <code>&#8211;debug</code></p>
<dd> enable debugging information</p>
<dt><code>-t</code> NUM, <code>&#8211;time</code>=<i>NUM</i></p>
<dd> time (in seconds) to spend scanning the target</p>
<dt><code>-p</code> NUM, <code>&#8211;parallelism</code>=<i>NUM</i></p>
<dd> specify the number of parallel threads to use</p>
<dt><code>-u</code> FILE, <code>&#8211;urlfile</code>=<i>FILE</i></p>
<dd> read URLs from FILE</p>
<dt><code>-o</code> FILE, <code>&#8211;out</code>=<i>FILE</i></p>
<dd> write report to the specified file</p>
<dt><code>-a</code> ADDR, <code>&#8211;address</code>=<i>ADDR</i></p>
<dd> specify address to scan</p>
<dt><code>-r</code> FILE, <code>&#8211;read</code>=<i>FILE</i></p>
<dd> load clues from the specified file</p>
<dt><code>-w</code> DIR, <code>&#8211;write</code>=<i>DIR</i></p>
<dd> save clues to the specified directory</p>
<dt><code>&#8211;config</code>=<i>FILE</i></p>
<dd> use alternative configuration file</dl>
