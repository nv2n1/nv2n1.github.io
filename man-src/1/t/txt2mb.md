<h2 class="name">NAME</h2>
<p> mb2txt, txt2mb &#8211; fcitx table related tools </p>
<h2>SYNOPSIS</h2>
<p> <code>mb2txt </code><i>&lt;mbfile&gt;</i> </p>
<p> <code>txt2mb </code><i>&lt;txtfile&gt;</i></p>
<h2>DESCRIPTION</h2>
<p> <code>mb2txt</code> and <code>txt2mb</code> are tools for transform table file between binary format and text format. fcitx can only use binary format. All output of <code>mb2txt</code> and <code>txt2mb</code> will be stdout.</p>
