<p>trademgen_drawBookingArrivals &#8211; </p>
<pre> Script plotting booking arrival curves, as generated by the C++ Simulated Travel Demand Generation (TraDemGen) Library</pre>
<h2>Synopsis</h2>
<p><code>trademgen_drawBookingArrivals</code> [-h|&#8211;help] [-o|&#8211;output &lt;path-to-output-file&gt;] [-p|&#8211;plot] &lt;path-to-input-log-file&gt;</p>
<h2>Description</h2>
<p><i>trademgen_drawBookingArrivals</i> is a small Python script, extracting the booking requests from the log file produced by the trademgen_generateDemand binary. It produces booking curves, which can even be rendered by a simple Matplotlib user interface (when the <code>-p/&#8211;plot</code> option is given). </p>
<p> <i>trademgen_drawBookingArrivals</i> accepts the following options: </p>
<p> <code>-h</code>, <code>&#8211;help</code> </p>
<p>&nbsp;<wbr>Produce that message and show usage. </p>
<p> <code>-o</code>, <code>&#8211;output</code> &lt;path-to-output-file&gt; </p>
<p>&nbsp;<wbr>Path to the output file. If blank, the booking curves are dumped onto the standard output&nbsp;<wbr>(stdout). </p>
<p> <code>-p</code>, <code>&#8211;plot</code> </p>
<p>&nbsp;<wbr>Produce a plot, thanks to a simple Matplotlib user interface. When that option is not given, the booking curves are just dumped onto the output stream. </p>
<p> <code>&lt;path-to-input-log-file&gt;</code> </p>
<p>&nbsp;<wbr>Path to the input file, i.e., to the log file generated by the&nbsp;<wbr><code>trademgen_generateDemand</code>&nbsp;<wbr>utility. If blank, the default log file is&nbsp;<wbr>&#8216;trademgen_generateDemand.log&#8217;. </p>
<p> See the output of the `trademgen_drawBookingArrivals &#8211;help&#8217; command for default options.</p>
