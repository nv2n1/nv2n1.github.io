<h2 class="name">NAME</h2>
<p> texi2html &#8211; a Texinfo to HTML converter </p>
<h2>SYNOPSIS</h2>
<p> <code>texi2html [options] file</code></p>
<h2>DESCRIPTION</h2>
<p> <i>Texi2html</i> converts the given Texinfo file to a set of HTML files. It tries to handle most of the Texinfo commands. It creates hypertext links for cross-references, footnotes&#8230; </p>
<p> <i>Texi2html</i> may furthermore use latex2html to generate HTML (code and/or images) for @math and @iftex tags (see the <code>&#8211;l2h</code> option). </p>
<p> <i>Texi2html</i> creates several files depending on the contents of the Texinfo file and on the chosen options (see FILES). </p>
<p> The HTML files created by <i>texi2html</i> are in general closer to TeX than to Info. Using init files (see the <code>&#8211;init-file</code> option), other styles or output formats may be selected.</p>
<h2>OPTIONS</h2>
<p> Options may be abbreviated to th shortests unique prefix. The following is only an incomplete list of the available options:</p>
<dl>
<dt><code>&#8211;help [1|2]</code></p>
<dd> Print usage instructions and list the most important, all relevant, or all recognised (including obsolete) command-line options, and exit.</p>
<dt><code>&#8211;split chapter|section|node</code></p>
<dd> Split the output into several HTML files (one per main chapter/section or node).</p>
<dt><code>&#8211;ifinfo &#8211;iftex &#8211;ifxml &#8211;ifplaintext &#8211;ifhtml</code></p>
<dd> Expand @ifinfo, @iftex and @tex, @ifxml and @xml, @ifplaintext, @ifhtml and @html regions, and don&#8217;t expand @ifnot corresponding regions (default: ifhtml).</p>
<dt><code>&#8211;no-ifinfo &#8211;no-iftex &#8211;no-ifxml &#8211;no-ifplaintext &#8211;no-html</code></p>
<dd> Don&#8217;t expand @ifinfo, @iftex, @ifxml, @ifplaintext regions and expand @ifnot corresponding regions.</p>
<dt><code>-I </code><i>dir</i></p>
<dd> Append <i>dir</i> to the directory list searched for included files.</p>
<dt><code>-P </code><i>dir</i></p>
<dd> Prepend <i>dir</i> to the directory list searched for included files.</p>
<dt><code>&#8211;l2h</code></p>
<dd> Use latex2html for content of @math and @tex tags. Content must be such that both, latex and tex, can translate it correctly. I.e., no tex-only constructs must be used.</p>
<dt><code>&#8211;css-include </code><i>file</i></p>
<dd> Use css file <i>file</i>.</p>
<dt><code>&#8211;init-file </code><i>file</i></p>
<dd> Load init file <i>file</i> (see also FILES).</p>
<dt><code>&#8211;document-language </code><i>lang</i></p>
<dd> Use <i>lang</i> as document language.</p>
<dt><code>&#8211;macro-expand </code><i>file</i></p>
<dd> output macro expanded source in <i>file</i>.</p>
<dt><code>&#8211;no-menu</code></p>
<dd> Don&#8217;t show the Texinfo menus; by default they are shown.</p>
<dt><code>&#8211;no-number</code></p>
<dd> Don&#8217;t number the sections.</p>
<dt><code>&#8211;use-nodes</code></p>
<dd> Use nodes for sectionning.</p>
<dt><code>&#8211;prefix</code></p>
<dd> Use as prefix for output files, instead of basename.</p>
<dt><code>&#8211;node-files</code></p>
<dd> Produce one file per node for cross references.</p>
<dt><code>&#8211;l2h-l2h </code><i>prog</i></p>
<dd> Use <i>prog</i> as latex2html program (default <i>latex2html</i>). Program must be executable.</p>
<dt><code>&#8211;l2h-init </code><i>file</i></p>
<dd> Use <i>file</i> as latex2html init file. <i>file</i> should be used to specify in which way latex2html handles mathematical expressions and formulas. </p>
<dt><code>&#8211;l2h-tmp </code><i>dir</i></p>
<dd> Use <i>dir</i> as tmp dir for latex2html. This directory (resp. its path) must not contain a dot (i.e., a &quot;.&quot;).</p>
<dt><code>&#8211;l2h-clean</code></p>
<dd> remove all intermediate files generated by latex2html (prevents caching!)</p>
<dt><code>&#8211;l2h-skip</code></p>
<dd> Do not really run latex2html. Use (kept) files of previous runs, instead.</p>
<dt><code>&#8211;verbose</code></p>
<dd> Give a verbose output.</p>
<dt><code>&#8211;version</code></p>
<dd> Print version and exit.</dl>
<h2>FILES</h2>
<p> Initialisation options are read first from /usr/share/texi2html/texi2html/Config (the exact location being changeable with the &#8211;datadir=dir option to the configure script), then from /etc/texi2html/Config (the exact location being changeable with the &#8211;sysconfdir=dir option to the configure script), then from ./Config, from $HOME/.texi2html/Config, and from any command-line options including &#8211;init-file options; with later settings overriding earlier ones. </p>
<p> By default <i>texi2html</i> my creates the following files (foo being the name of the Texinfo file):</p>
<dl>
<dt><code>foo_toc.html</code></p>
<dd> The table of contents (if @contents is present).</p>
<dt><code>foo.html</code></p>
<dd> The document&#8217;s contents or the Top element.</p>
<dt><code>foo_fot.html</code></p>
<dd> The footnotes (if any).</p>
<dt><code>foo_abt.html</code></p>
<dd> An help section.</p>
<dt><code>foo_l2h_img*</code></p>
<dd> Images generated by latex2html (if any).</dl>
<p> When used with the <code>&#8211;split</code> option, it creates several files (one per chapter or node), named <code>foo_n.html</code> (n being the index of the chapter or node), and the <code>foo.html</code> file contains the Top element. </p>
<p> Otherwise it creates only one file: <code>foo.html</code></p>
