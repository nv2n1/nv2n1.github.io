<h2 class="name">NAME</h2>
<p> toc2cddb &#8211; translates a TOC file of <i></p>
<p> <a href="/docs/linux/man/1-cdrdao/">cdrdao</a>(1)</i> into a cddb file and prints it to stdout </p>
<h2>SYNOPSIS</h2>
<p> <code>toc2cddb</code> <i>toc_file</i> </p>
<p> <code>toc2cddb</code> <code>[</code>-h<code>|</code>-V<code>]</code> </p>
<h2>DESCRIPTION</h2>
<p> <code>toc2cddb</code> translates a TOC file of <i><a href="/docs/linux/man/1-cdrdao/">cdrdao</a>(1)</i> into a cddb file and prints it to stdout. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code></p>
<dd> Shows a short help message.</p>
<dt><code>-V</code></p>
<dd> Prints the version of toc2cddb. </p>
</dl>
