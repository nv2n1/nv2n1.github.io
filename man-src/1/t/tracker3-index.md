<h2 class="name">NAME</h2>
<p> tracker3-index &#8211; Index content using the Tracker filesystem miner </p>
<h2>SYNOPSIS</h2>
<pre><code>
tracker3 index
    tracker3 index-- add[--recursive]&lt;dir&gt; [[dir]...] tracker3 index-- remove&lt;path&gt; [[dir]...]
</code></pre>
<h2>DESCRIPTION</h2>
<p> This command causes the Tracker filesystem miner to process the given directories. These changes are persistent across future restarts. </p>
<p> If invoked without arguments, the currently indexed locations will be listed.</p>
