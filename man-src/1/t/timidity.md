<h2>NAME</h2>
<p> TiMidity++ - MIDI-to-WAVE converter and player  </p>
<p> <code>timidity</code> [options] filename [...]  </p>
<p> <code>TiMidity++</code> is a converter that converts some of MIDI files (supported formats: Standard MIDI files (*.mid), Recomposer files (*.rcp, *.r36, *.g18, *.g36) and Module files (*.mod)) into formatted audio files (e.g. RIFF WAVE). <code>TiMidity++</code> uses Gravis Ultrasound-compatible patch files or Soundfonts (*.sfx, *.sf2) to generate digital audio data from MIDI files. The digital audio data generated by <code>TiMidity++</code> can be stored in a file for processing, or played in real time through an audio device. <br />
 In real time playing, <code>TiMidity++</code> can show the lyrics contained in KAR or WRD files.  </p>
<h2>FILENAME</h2>
<p> You can use the following expressions as the <i>filename</i> argument: </p>
<dl>
<dt><code>-</code></dt>
<dd> <p> Read a MIDI file from standard input. </p>
 </dd>
<dt><code>path/filename</code></dt>
<dd> <p> Read a MIDI file from the specified path on a filesystem. </p>
 </dd>
<dt><code>dir:directory</code></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code>directory/</code></dt>
<dd> <p> Read and play all MIDI files in the specified <i>directory</i>. For example, </p>
<p> % timidity some/where/ </p>
<p> plays all files in the directory <code>some/where/</code>. </p>
 </dd>
<dt><code>Archive File</code></dt>
<dd> <p> Extract and play the file(s) in the archive. If you want to specify a certain MIDI file in the archive, append <code>#&lt;MIDI-filename&gt;</code> to the archive name. The path after `#&#8216; allows the use of the wildcard expressions (case insensitive). <br />
 You can use escape sequence <code>\xHH</code>, where `HH&#8217; is a ASCII number in hexadecimal integer. </p>
<p> For example: </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt>% timidity file.zip#file.mid</dt>
<dd> <p> Plays <code>file.mid</code> in <code>file.zip</code> </p>
 </dd>
<dt>% timidity file.lzh#*.mid</dt>
<dd> <p> Plays any files that match the wildcard expression <code>*.mid</code> in <code>file.lzh</code> </p>
 </dd>
<dt>% timidity file.tgz#*</dt>
<dd> <p> This expression is the same as <code>file.tgz</code> </p>
 </dd></dl>
<p> Since these mechanism are contained in <code>TiMidity++</code> itself, you can use this syntax even in the MS Windows environment. </p>
<p> <code>TiMidity++</code> can handle the following archive formats: </p>
<dl>
<dt><code>tar (*.tar)</code></dt>
<dd>  </dd>
<dt><code>tar+gzip (*.tar.gz, *.tgz)</code></dt>
<dd>  </dd>
<dt><code>zip (*.zip)</code></dt>
<dd>  </dd>
<dt><code>lzh (*.lzh, *.lha)</code></dt>
<dd> <p> (lh0, lh1, lh2, lh3, lh4, lh5, lh6, lz4, lzs and lz5 are available) </p>
 </dd></dl>
<p> Other archives can be expanded if expander command is specified on the compile phase. <code>TiMidity++</code> will pipe that command. </dl>
 </p>
<dt><code><a href="news://news-server[:port]/Message-ID">news://news-server[:port]/Message-ID</a></code></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code><a href="news://news-server[:port]/newsgroup[/first-last]">news://news-server[:port]/newsgroup[/first-last]</a></code></dt>
<dd> <p> Play the MIDI file in the specified article on the news server. If a newsgroup is specified <code>TiMidity++</code> plays all MIDI files found in any article posted to that newsgroup. <br />
 <code>TiMidity++</code> parses MIME Multi-part messages in case of <code><a href="news://*">news://*</a></code> scheme, extracts MIDI file that was post to that group, or in case of normal file, you can explicitly handle MIME documents by naming that file with *.mime extension, or prefix that file with <code>mime:</code> </p>
<p> The following MIME-types are allowed: </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>uu-encoded file</code></dt>
<dd> <p> <code>begin</code> <br />
 is required </p>
 </dd>
<dt><code>base64 encoded</code></dt>
<dd> <p> <code>Content-Transfer-Encoding: base64</code> <br />
 is required </p>
 </dd>
<dt><code>quoted-string</code></dt>
<dd> <p> <code>Content-Transfer-Encoding: quoted-string</code> <br />
 is required </p>
 </dd>
<dt><code>Mac BinHex format</code></dt>
<dd> <p> only HQX format is available </p>
 </dd></dl>
</dl>
<dt><code><a rel="nofollow" href="http://address">http://address</a></code></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code><a href="ftp://address">ftp://address</a></code></dt>
<dd> <p> Play the file specified in the URL. </p>
<p> For example: </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt>% timidity <a rel="nofollow" href="http://www.goice.co.jp/member/mo/dist/midi/impromptu.mid">http://www.goice.co.jp/member/mo/dist/midi/impromptu.mid</a></dt>
<dd> <p> plays the specified MIDI-file directly from the network. </p>
 </dd></dl>
<p> If these expression are used in the *.cfg files, you can even use patch-files (and others) from remote machines. </dl>
 </dl>
  </p>

<h2>OPTIONS</h2>
<p> The following command line options are accepted by <code>TiMidity++</code>: </p>
<dl>
<dt><code>-A </code><i>[n][,m](a)</i></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code>--amplification=</code><i>n</i></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code>--drumpower=</code><i>m</i></dt>
<dd> <p> <br />
 </p>
 </dd>
<dt><code>--[no-]volume-compensation</code></dt>
<dd> <p> Multiplies the master volume by <i>n</i>%. Default value is 70%. Higher amplification makes louder sounds. You can specify the drum power, ratio of drum volume from the other channels. The allowed values of amplification range from <code>0</code> (no sound) to <code>800</code>. <br />
 Optionally to put `a&#8217; character along with <code>-a</code> option, or to use <code>--volume-compensation</code>, instructs <code>TiMidity++</code> to regularize the volume. You can easily gain dynamic range. </p>
<p> For example: </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>-A90</code></dt>
<dd> <p> volume 90%, drum power 100%, compensation is off </p>
 </dd>
<dt><code>-A,120</code></dt>
<dd> <p> volume 70%, drum power 120%, compensation is off </p>
 </dd>
<dt><code>-A90,120</code></dt>
<dd> <p> volume 90%, drum power 120%, compensation is off </p>
 </dd>
<dt><code>-Aa</code></dt>
<dd> <p> volume 70%, drum power 100%, compensation is on </p>
 </dd>
<dt><code>-A90a</code></dt>
<dd> <p> volume 90%, drum power 100%, compensation is on </p>
 </dd>
<dt><code>-A,120a</code></dt>
<dd> <p> volume 70%, drum power 120%, compensation is on </p>
 </dd>
<dt><code>-A90,120a</code></dt>
<dd> <p> volume 90%, drum power 120%, compensation is on </p>
 </dd></dl>
</dl>
<dt><code>-a, --[no-]anti-alias</code></dt>
<dd> <p> Turns on anti-aliasing. Samples are run through a lowpass filter before playing, which reduces aliasing noise at low resampling frequencies. </p>
 </dd>
<dt><code>-B </code><i>n,m</i><code>, --buffer-fragments=</code><i>n,m</i></dt>
<dd> <p> For the Linux/FreeBSD/OSS/ALSA/Windows sound driver, selects the number of buffer fragments in interactive mode. Increasing the number of fragments may reduce choppiness when many processes are running. It will make <code>TiMidity++</code> seem to respond sluggishly to fast forward, rewind, and volume controls, and it will throw the status display off sync. Specify a fragments number of 0 to use the maximum number of fragments available. </p>
 </dd>
<dt><code>-C </code><i>n</i><code>, --control-ratio=</code><i>n</i></dt>
<dd> <p> Sets the ratio of sampling and control frequencies. This determines how often envelopes are recalculated -- small ratios yield better quality but use more CPU time. </p>
 </dd>
<dt><code>-c </code><i>file</i><code>, --config-file=</code><i>file</i></dt>
<dd> <p> Reads an extra configuration file. </p>
 </dd>
<dt><code>-D </code><i>n</i><code>, --drum-channel=</code><i>n</i></dt>
<dd> <p> Marks channel as a drum channel. If channel is negative, channel -<i>n</i> is marked as an instrumental channel. If <i>n</i> is <code>0</code>, all channels are marked as instrumental. </p>
 </dd>
<dt><code>-d </code><i>dir</i><code>, --interface-path=</code><i>dir</i></dt>
<dd> <p> Specifies the directory containing installed dynamic-link interface modules. </p>
 </dd>
<dt><code>-E </code><i>mode</i><code>, --ext=</code><i>mode</i></dt>
<dd> <p> Set <code>TiMidity++</code> extend modes. The following modes are available (capitalized switch means disable this feature): </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>w/W, --[no-]mod-wheel</code></dt>
<dd> <p> Enable/disable modulation controlling. </p>
 </dd>
<dt><code>p/P, --[no-]portamento</code></dt>
<dd> <p> Enable/disable portamento controlling. </p>
 </dd>
<dt><code>v/V, --[no-]vibrato</code></dt>
<dd> <p> Enable/disable NRPM vibration. </p>
 </dd>
<dt><code>s/S, --[no-]ch-pressure</code></dt>
<dd> <p> Enable/disable channel pressure controlling. </p>
 </dd>
<dt><code>e/E, --[no-]mod-envelope</code></dt>
<dd> <p> Enable/disable modulation envelope controlling. </p>
 </dd>
<dt><code>t/T, --[no-]trace-text-meta</code></dt>
<dd> <p> Enable/disable tracing all Text Meta Events. </p>
 </dd>
<dt><code>o/O, --[no-]overlap-voice</code></dt>
<dd> <p> Accept/reject pronouncing multiple same notes. </p>
 </dd>
<dt><code>z/Z, --[no-]temper-control</code></dt>
<dd> <p> Enable/disable MIDI Tuning Standard temperament controlling. </p>
 </dd>
<dt><code>m</code><i>HH</i><code>, --default-mid=</code><i>HH</i></dt>
<dd> <p> Sets the manufacturer ID to <i>HH</i> (where <i>HH</i> are two hex-digits). <br />
 <i>HH</i> values of <code>GS/gs</code>, <code>XG/xg</code> or <code>GM/gm</code> are understood as <code>41</code>, <code>43</code> and <code>7e</code> respectively. </p>
 </dd>
<dt><code>M</code><i>HH</i><code>, --system-mid=</code><i>HH</i></dt>
<dd> <p> Sets the system manufacturer ID to <i>HH</i> (where <i>HH</i> are two hex-digits). <br />
 In this option, the manufacture ID is set unchangeable. Manufacture ID from the input file would be ignored. </p>
 </dd>
<dt><code>b</code><i>n</i><code>, --default-bank=</code><i>n</i></dt>
<dd> <p> Use tone bank <i>n</i> as the default. </p>
 </dd>
<dt><code>B</code><i>n</i><code>, --force-bank=</code><i>n</i></dt>
<dd> <p> Sets the bank number of all channels to <i>n</i>. </p>
 </dd>
<dt><code>i</code><i>n[/m]</i><code>, --default-program=</code><i>n[/m]</i></dt>
<dd> <p> Use the program number as the default instrument. Any Program Change events in MIDI files will override this option. <br />
 If <i>n</i> is followed by <i>/m</i> the default program number of the channel <i>m</i> is specified by <i>n</i>. </p>
 </dd>
<dt><code>I</code><i>n[/m]</i><code>, --force-program=</code><i>n[/m]</i></dt>
<dd> <p> Similar to <code>-Ei</code> but this ignores all program changes. </p>
 </dd>
<dt><code>F </code><i>args</i></dt>
<dd> <p> For effects. See below. In <i>args</i> option, you can specify following effect options: </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>delay=</code><i>(d|l|r|b)[,msec]</i><code>, --delay=</code><i>(d|l|r|b)[,msec]</i></dt>
<dd> <p> Sets delay type. </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>d, 0</code></dt>
<dd> <p> Disabled delay effect. </p>
 </dd>
<dt><code>l, 1</code></dt>
<dd> <p> Left delay. </p>
 </dd>
<dt><code>r, 2</code></dt>
<dd> <p> Right delay. </p>
 </dd>
<dt><code>b, 3</code></dt>
<dd> <p> Swap left &amp; right. </p>
 </dd></dl>
<p> Optional <i>msec</i> is the delay time. </dl>
 </p>
<dt><code>chorus=</code><i>(d|n|s)[,level]</i><code>, --chorus=</code><i>(d|n|s)[,level]</i></dt>
<dd>  </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>d, 0</code></dt>
<dd> <p> Disable this effect. </p>
 </dd>
<dt><code>n, 1</code></dt>
<dd> <p> Enable MIDI chorus effect control. </p>
 </dd>
<dt><code>s, 2</code></dt>
<dd> <p> Surround sound, chorus detuned to a lesser degree (default). </p>
 </dd></dl>
<p> The optional parameter <i>level</i> specifies the chorus level <code>0</code> to <code>127</code>. </dl>
 </p>
<dt><code>reverb=</code><i>(d|n|g)[,level]</i><code>, --reverb=</code><i>(d|n|g)[,level]</i></dt>
<dd>  </dd>
<dt><code>reverb=</code><i>(f|G)[,level,scaleroom,offsetroom,predelay]</i></dt>
<dd>  </dd>
<dt><code>--reverb=</code><i>(f|G)[,level,scaleroom,offsetroom,predelay]</i></dt>
<dd>  </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>d, 0</code></dt>
<dd> <p> Disable MIDI reverb effect control. </p>
 </dd>
<dt><code>n, 1</code></dt>
<dd> <p> Enable MIDI reverb effect control. This effect is only available in stereo. </p>
 </dd>
<dt><code>g, 2</code></dt>
<dd> <p> Global reverb effect. </p>
 </dd>
<dt><code>f, 3</code></dt>
<dd> <p> Freeverb MIDI reverb effect control (default). </p>
 </dd>
<dt><code>G, 4</code></dt>
<dd> <p> Global Freeverb effect. </p>
 </dd></dl>
<p> The optional parameter <i>level</i> specifies the reverb level <code>0</code> to <code>127</code>. <br />
 For Freeverb effect, additional parameters <i>scaleroom</i>, <i>offsetroom</i> and <i>predelay</i> can be specified. <i>scaleroom</i> and <i>offsetroom</i> specify variables for the room size calculated as <br />
 roomsize = C * <i>scaleroom</i> + <i>offsetroom</i> <br />
 where C is the reverberation character. <i>predelay</i> specifies the factor for pre-delay time of reverberation in percent. Any of the optional parameters can be omitted. Default values are <code>0.28</code>, <code>0.7</code> and <code>100</code> respectively. </dl>
 </p>
<dt><code>vlpf=</code><i>(d|c|m)</i><code>, --voice-lpf=</code><i>(d|c|m)</i></dt>
<dd>  </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>d, 0</code></dt>
<dd> <p> Disable LPF effect. </p>
 </dd>

 </dd></dl>
</dl>
<dt><code>ns=</code><i>n</i><code>, --noise-shaping=</code><i>n</i></dt>
<dd> <p> Enable the <i>n</i> th degree noiseshaping filter. The distortion at decay stage is improved, but the noise on human auditory feeling increases because it shifts to a high frequency. In case of 8-bit linear encoding, valid values of <i>n</i> are in the interval from <code>0</code> (min) to <code>4</code> (max). Default value is <code>4</code>. In case of 16-bit linear encoding, valid values of n are in the interval from <code>0</code> to <code>4</code>. According to the value, it works as following. Default value is <code>4</code>. </p>
 </dd>
<dl>
<dd>  </dd>
<dl>
<dt><code>0</code></dt>
<dd> <p> No noise shaping. </p>
 </dd>
<dt><code>1</code></dt>
<dd> <p> Traditional noise shaping. </p>
 </dd>
<dt><code>2</code></dt>
<dd> <p> Overdrive-like soft-clipping + new noise shaping. </p>
 </dd>
<dt><code>3</code></dt>
<dd> <p> Tube-amplifier-like soft-clipping + new noise shaping. </p>
 </dd>
<dt><code>4</code></dt>
<dd> <p> New noise shaping. </p>
 </dd></dl>
</dl>
<dt><code>resamp=</code><i>(d|l|c|L|n|g)</i><code>, --resample=</code><i>(d|l|c|L|n|g)</i></dt>

 </dd>
<dt><code>l, 1</code></dt>
<dd> <p> Linear interpolation. </p>
 </dd>
<dt><code>c, 2</code></dt>
<dd> <p> Cubic spline interpolation. </p>
 </dd>
<dt><code>L, 3</code></dt>
<dd> <p> Lagrange method. </p>
 </dd>
<dt><code>n, 4</code></dt>
<dd> <p> Newton polynomial interpolation. </p>
 </dd>
<dt><code>g, 5</code></dt>
<dd> <p> Modified Gauss effect (default). </p>
 </dd></dl>
<p> This option affects the behavior of <code>-N</code> option. </dl>
 </dl>
 </dl>
 </dl>
 </dl>

<dt><code>-e, --evil</code></dt>
<dd> <p> Make <code>TiMidity++</code> evil. For the Win32 version, this increases the task priority by one. It can give better playback when you switch tasks at the expense of slowing all other tasks down. </p>
 </dd>
<dt><code>-F, --[no-]fast-panning</code></dt>
<dd> <p> Turns on fast panning to accommodate MIDI pieces that expect panning adjustments to affect notes that are already playing. Some files that don&#8217;t expect this have a habit of flipping balance rapidly between left and right, which can cause severe popping when the <code>-F</code> flag is used. <br />
 In the current version of <code>TiMidity++</code> this option is a toggle. </p>
 </dd>
<dt><code>-f, --[no-]fast-decay</code></dt>
<dd> <p> Toggles fast envelopes. This option makes <code>TiMidity++</code> faster but the release time of the notes are shortened. </p>
 </dd>
<dt><code>-g </code><i>sec</i><code>, --spectrogram=</code><i>sec</i></dt>
<dd> <p> Open the Sound-Spectrogram window. This option is activated if the system has support for the X Window System. </p>
 </dd>
<dt><code>-H </code><i>n</i><code>, --force-keysig=</code><i>n</i></dt>
<dd> <p> Specify the number of key signature. MIDI file is performed with transposition to the key of the number of sharp (when <i>n</i> is positive) or flat (when <i>n</i> is negative). Valid values of <i>n</i> are in the interval from <code>-7</code> to <code>7</code>. For example, if <i>n</i> is <code>1</code>, MIDI file with any tonality will be performed transposing to <code>1</code> flat (i.e., F major or D minor). Therefore, it is convenient to use for the accompaniment when practicing a musical instrument by the tonality which is easy to perform. </p>
 </dd>
