<h2>NAME</h2>
<p> TiMidity++ &#8211; MIDI-to-WAVE converter and player</p>
<h2>SYNOPSIS</h2>
<p> <code>timidity</code> [options] filename [&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> <code>TiMidity++</code> is a converter that converts some of MIDI files (supported formats: Standard MIDI files (*.mid), Recomposer files (*.rcp, *.r36, *.g18, *.g36) and Module files (*.mod)) into formatted audio files (e.g. RIFF WAVE). <code>TiMidity++</code> uses Gravis Ultrasound-compatible patch files or Soundfonts (*.sfx, *.sf2) to generate digital audio data from MIDI files. The digital audio data generated by <code>TiMidity++</code> can be stored in a file for processing, or played in real time through an audio device.<br />
 In real time playing, <code>TiMidity++</code> can show the lyrics contained in KAR or WRD files.</p>
<h2>FILENAME</h2>
<p> You can use the following expressions as the <i>filename</i> argument:</p>
<dl>
<dt><code>&#8211;</code></p>
<dd> Read a MIDI file from standard input.</p>
<dt><code>path/filename</code></p>
<dd> Read a MIDI file from the specified path on a filesystem.</p>
<dt><code>dir:directory</code></p>
<dd>
<dt><code>directory/</code></p>
<dd> Read and play all MIDI files in the specified <i>directory</i>. For example, </p>
<p> % timidity some/where/ </p>
<p> plays all files in the directory <code>some/where/</code>.</p>
<dt><code>Archive File</code></p>
<dd> Extract and play the file(s) in the archive. If you want to specify a certain MIDI file in the archive, append <code>#&lt;MIDI-filename&gt;</code> to the archive name. The path after `#&#8217; allows the use of the wildcard expressions (case insensitive).<br />
