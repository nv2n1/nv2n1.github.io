<h2>NAME</h2>
<p> tcpxtract &#8211; manual page for tcpxtract v1.0.1</p>
<h2>SYNOPSIS</h2>
<p> <code>tcpxtract</code> [<i>OPTIONS</i>] [[<i>-d &lt;DEVICE&gt;</i>] [<i>-f &lt;FILE&gt;</i>]]</p>
<h2>DESCRIPTION</h2>
<h3>Valid options include:</h3>
<dl>
<dt><code>&#8211;file</code>, <code>-f</code> &lt;FILE&gt;</p>
<dd> to specify an input capture file instead of a device</p>
<dt><code>&#8211;device</code>, <code>-d</code> &lt;DEVICE&gt;</p>
<dd> to specify an input device (i.e. eth0)</p>
<dt><code>&#8211;config</code>, <code>-c</code> &lt;FILE&gt;</p>
<dd> use FILE as the config file</p>
<dt><code>&#8211;output</code>, <code>-o</code> &lt;DIRECTORY&gt;</p>
<dd> dump files to DIRECTORY instead of current directory</p>
<dt><code>&#8211;version</code>, <code>-v</code></p>
<dd> display the version number of this program</p>
<dt><code>&#8211;help</code>, <code>-h</code></p>
<dd> display this lovely screen</dl>
<h2>SEE ALSO</h2>
<p> The full documentation for <code>tcpxtract</code> is maintained as a Texinfo manual. If the <code>info</code> and <code>tcpxtract</code> programs are properly installed at your site, the command</p>
<dl>
<dt>
<dd> <code>info tcpxtract</code></dl>
<p> should give you access to the complete manual. </p>
