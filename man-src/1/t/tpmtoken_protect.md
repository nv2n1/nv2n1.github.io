<p>TPM Management &#8211; tpmtoken_protect<br />
 </center></p>
<h2 class="name">NAME</h2>
<p> tpmtoken_protect &#8211; encrypt or decrypt data using a symmetric key stored in the user&#8217;s TPM PKCS#11 data store </p>
<h2>SYNOPSIS</h2>
<p> <code>tpmtoken_protect</code> [ OPTION ] </p>
<h2>DESCRIPTION</h2>
<p> <code>tpmtoken_protect</code> will encrypt or decrypt data using a symmetric key that is stored in the user&#8217;s data store. The key used to protect the data is a 256-bit AES key stored as a private Secret Key PKCS#11 object. The object has the PKCS#11 label attribute of &#8216;User Data Protection Key&#8217;. The key is generated by the TPM PKCS#11 implementation when it is needed the first time. Since it is generated as a private object, it is protected by the TPM on the platform. </p>
<p> This command requires the &#8216;-i&#8217; and &#8216;-o&#8217; command options to be specified. </p>
