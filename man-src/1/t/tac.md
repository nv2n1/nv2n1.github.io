<h2 class="name">NAME</h2>
<p> tac &#8211; concatenate and print files in reverse </p>
<h2>SYNOPSIS</h2>
<p> <code>tac</code> [<i>,OPTION/</i>]&#8230; [<i>,FILE/</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Write each FILE to standard output, last line first. </p>
<p> With no FILE, or when FILE is -, read standard input. </p>
<p> Mandatory arguments to long options are mandatory for short options too.</p>
<dl>
<dt><code>-b</code>, <code>&#8211;before</code></p>
<dd> attach the separator before instead of after</p>
<dt><code>-r</code>, <code>&#8211;regex</code></p>
<dd> interpret the separator as a regular expression</p>
<dt><code>-s</code>, <code>&#8211;separator</code>=<i>,STRING/</i></p>
<dd> use STRING as the separator instead of newline</p>
<dt><code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> output version information and exit</dl>
