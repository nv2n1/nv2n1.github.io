<h2 class="name">NAME</h2>
<p> thunar-volman &#8211; controls configuration of thunar&#8217;s removable media </p>
<h2>NOTE</h2>
<p> Note that usually this command is invoked by thunar itself and you should only use this if you are having problems adding the device as per the documentation cited at the end of this manpage.</p>
<h2>DESCRIPTION</h2>
<dl>
<dt>
<dd> thunar-volman [OPTION&#8230;]</p>
<dt><code>-a</code>, <code>&#8211;device-added</code> &lt;udi-of-your-device&gt;</p>
<dd> Manually tell thunar about a device</p>
<dt><code>-c</code>, <code>&#8211;configure</code></p>
<dd> Configure management of removable drives and media</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd> Print version information and exit</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</dl>
