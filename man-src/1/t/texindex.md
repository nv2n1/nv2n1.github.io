<h2 class="name">NAME</h2>
<p> texindex &#8211; sort Texinfo index files </p>
<h2>SYNOPSIS</h2>
<p> <code>texindex</code> [<i>,OPTION/</i>]&#8230; <i>,FILE/</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Generate a sorted index for each TeX output FILE. Usually FILE&#8230; is specified as `foo.??&#8217; for a document `foo.texi&#8217;.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> display version information and exit</p>
<dt><code>&#8212;</code></p>
<dd> end option processing</dl>
