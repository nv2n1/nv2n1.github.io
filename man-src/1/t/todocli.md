<h2>NAME</h2>
<p> todocli &#8211; Command line To Do application</p>
<h2>SYNOPSIS</h2>
<p> todocli [-h |-n &lt;item&gt; |-d &lt;id&gt; ]</p>
<h2>DESCRIPTION</h2>
<p> A command line ToDo application with SQLite backend powered by Python</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h </code></p>
<dd> &#8211;help show help message and exit</p>
<dt>
<dt><code>-n </code></p>
<dd>
<dd> &#8211;new &lt;ITEM&gt; new todo item</p>
<dt><code>-d </code></p>
<dd> &#8211;delete &lt;ID&gt; delete a todo item with id</dl>
