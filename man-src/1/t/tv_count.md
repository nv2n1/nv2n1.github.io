<h2 class="name">NAME</h2>
 

 tv_count - Count (and print) the number of channels and programmes in an XMLTV file. 

<h2>SYNOPSIS</h2>

 tv_count <font SIZE="-1">FILE</font>

<h2>DESCRIPTION</h2>

 Read <font SIZE="-1">XMLTV</font> listings and print a count of the number of channels and number of programmes in the file.

<h2>EXAMPLE</h2>

 Use <tt>&quot;tv_count listings.xml&quot;</tt> to count programmes in the file called <i>listings.xml</i>.
