<p>trademgen_extractBookingRequests &#8211; </p>
<pre> Script extracting booking requests, as generated by the C++ Simulated Travel Demand Generation (TraDemGen) Library</pre>
<h2>Synopsis</h2>
<p><code>trademgen_extractBookingRequests</code> [-h|&#8211;help] [-i|&#8211;input &lt;path-to-input-log-file&gt;</p>
<h2>Description</h2>
<p><i>trademgen_extractBookingRequests</i> is a small shell script, extracting the booking requests from the log file produced by the &#8216;trademgen_generateDemand&#8217; binary. </p>
<p> It produces an output with the following format: Logfile line number, Booking date, Orign-Destination, Departure date For instance: 39, 2009-May-26, SIN-HND, 2010-Feb-09 </p>
<p> See also the trademgen_drawBookingArrivals script, which plots booking arrival curves from those very same booking requests. Note that there is no dependency between those two scripts. </p>
<p> <i>trademgen_extractBookingRequests</i> accepts the following options: </p>
<p> <code>-h</code>, <code>&#8211;help</code> </p>
<p>&nbsp;<wbr>Produce that message and show usage. </p>
<p> <code>&lt;path-to-input-log-file&gt;</code> </p>
<p>&nbsp;<wbr>Path to the input file, i.e., to the log file generated by the&nbsp;<wbr><code>trademgen_generateDemand</code>&nbsp;<wbr>utility. If blank, the default log file is&nbsp;<wbr>&#8216;trademgen_generateDemand.log&#8217;. </p>
<p> See the output of the `trademgen_extractBookingRequests &#8211;help&#8217; command for default options.</p>
