<h2>NAME</h2>
<p> tn5250 &#8211; an implementation of the 5250 telnet protocol</p>
<h2>SYNOPSIS</h2>
<p> <code>tn5250</code> [<i>OPTIONS</i>] <i>HOSTNAME</i><br />
 <code>xt5250</code> [<i>OPTIONS</i>] <i>HOSTNAME</i><br />
 <code>tn5250 -version</code></p>
<h2>DESCRIPTION</h2>
<p> <code>tn5250</code> emulates IBM&#8217;s 5250 compatible terminals to connect over TCP/IP to an IBM AS/400. The terminal emulation works on any local terminal supported by curses, and provides 132&#215;27 and full colour support where possible. </p>
<p> An IBM 5250 terminal supports a number of special keys, and does a lot of processing itself before sending data to the host system. Because a standard ASCII terminal does not support all these keys, <code>tn5250</code> uses control sequences to perform the operations. </p>
<p> Named session support (with the <code>env.DEVNAME</code> option) is available for most versions of OS/400, but is only supplied with V4R3 and later versions. For V3R2, V3R7, V4R1 and V4R2, please see informational APAR II10918.</p>
<h2>OPTIONS</h2>
<p> <code>tn5250</code> options are described in the <code><a href="/docs/linux/man/5-tn5250rc/">tn5250rc</a></code>(5) man page.</p>
<h2>USAGE</h2>
<p> This manual assumes that the user is familiar with a real 5250 terminal, or another 5250 emulator, and only describes features relevant to <code>tn5250</code> itself.</p>

<h3>Display</h3>
<p> The screen display tries to be the same as a colour 5250 terminal. There are some unavoidable differences though:</p>
<dl>
<dt>&bull;</p>
<dd> ASCII terminals (and curses) do not support the 5250 column separators.</p>
<dt>&bull;</p>
<dd> Some terminals (mostly ones based on the VGA text mode) do not support underlining. If this is the case and <code>tn5250</code> does not detect it automatically, you should pass the <code>-u</code> option.</p>
<dt>&bull;</p>
<dd> Some terminals (such as <code>xterm</code>) do not support blinking text.</dl>
<h2>EXAMPLES</h2>
<p> These are some examples of the use of <code>tn5250</code>:</p>
<dl>
<dt><i>tn5250 as400sys</i></p>
<dd> Connect to the system <i>as400sys</i>, using the default translation map (37) and a generated session name (QPADEV<i>####</i>).</p>
<dt><i>tn5250 map=870 env.DEVNAME=session1 env.TERM=IBM-3477-FC as400sys</i></p>
<dd> Connect to <i>as400sys</i> using the translation map for CCSID 870 (Eastern Europe), the session name SESSION1 and with a terminal supporting colour and a 132&#215;27 display.</dl>
