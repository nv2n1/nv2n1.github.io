<p> thunar-volman-settings &#8211; controls configuration of thunar&#8217;s removable media </p>
<h2>NOTE</h2>
<p> Note that usually this command is invoked by thunar itself and you should only use this if you are having problems adding the device as per the documentation cited at the end of this manpage.  </p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dd> <p> thunar-volman-settings [OPTION...] </p>
 </dd></dl>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>--help</code></dt>
<dd> <p> Show help options </p>
 </dd>
<dt><code>--help-all</code></dt>
<dd> <p> Show all help options </p>
 </dd>
<dt><code>--help-gtk</code></dt>
<dd> <p> Show GTK+ Options </p>
 </dd></dl>
<p> GTK+ Options </p>
<dl>
<dt><code>--class</code>=<i>CLASS</i></dt>
<dd> <p> Program class as used by the window manager </p>
 </dd>
<dt><code>--name</code>=<i>NAME</i></dt>
<dd> <p> Program name as used by the window manager </p>
 </dd>
<dt><code>--screen</code>=<i>SCREEN</i></dt>
<dd> <p> X screen to use </p>
 </dd>
<dt><code>--sync</code></dt>
<dd> <p> Make X calls synchronous </p>
 </dd>
<dt><code>--gtk-module</code>=<i>MODULES</i></dt>
<dd> <p> Load additional GTK+ modules </p>
 </dd>
<dt><code>--g-fatal-warnings</code></dt>
<dd> <p> Make all warnings fatal </p>
 </dd></dl>
<h3>Application Options:</h3>
<dl>
<dt><code>--display</code>=<i>DISPLAY</i></dt>
<dd> <p> X display to use </p>
 </dd></dl>
