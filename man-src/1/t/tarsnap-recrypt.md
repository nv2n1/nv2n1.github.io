<h2>NAME</h2>
<p> <code>tarsnap-recrypt</code> &#8211; re-encrypts data stored using <a href="/docs/linux/man/1-tarsnap/">tarsnap</a>(1).</p>
<h2>SYNOPSIS</h2>
<p> &#8211;<code>-oldkey </code><i>old-key-file</i> &#8211;<code>-oldcachedir </code><i>old-cache-dir</i> &#8211;<code>-newkey </code><i>new-key-file</i> &#8211;<code>-newcachedir </code><i>new-cache-dir</i></p>
<h2>DESCRIPTION</h2>
<p> downloads and decrypts data using <i>old-key-file</i> and re-encrypts and uploads it using <i>new-key-file</i> After all the data has been re-uploaded, deletes the data using <i>old-key-file</i> so that the only remaining copy of the data is encrypted using <i>new-key-file</i> The key file <i>new-key-file</i> must have been generated by tarsnap-keyregen1 with <i>old-key-file</i> </p>
<p> checkpoints its progress after every 1-2 GB of data that it has copied; if it is interrupted it can be re-run and it will attempt to continue. </p>
<p> Note that after completes it will be possible to store more archives using the key <i>old-key-file</i> and the cache directory <i>old-cache-dir</i> so care should be taken to disable any automatic (e.g., <a href="/docs/linux/man/8-cron/">cron</a>(8)) archiving while is run.</p>
<h2>EXAMPLES</h2>
<p> The following sequence of commands will create new keys and re-encrypt data, assuming that the currently used keys are in /root/tarsnap.key and the current cache directory is /usr/local/tarsnap-cache </p>
<blockquote><p><tt></tt><code>tarsnap-keyregen &#8211;keyfile /root/tarsnap.key.new &#8211;oldkey /root/tarsnap.key &#8211;user </code><i>me [at] example.com &#8211;</i><code>-machine </code><i>myserver</i> </p></blockquote>
<blockquote><p><tt></tt><code>&#8211;oldkey /root/tarsnap.key &#8211;oldcachedir /usr/local/tarsnap-cache &#8211;newkey /root/tarsnap.key.new &#8211;newcachedir /usr/local/tarsnap-cache.new </code> </p></blockquote>
<blockquote><p><tt></tt><code>rm -r /usr/local/tarsnap-cache </code> </p></blockquote>
<blockquote><p><tt></tt><code>mv /usr/local/tarsnap-cache.new /usr/local/tarsnap-cache </code> </p></blockquote>
<blockquote><p><tt></tt><code>rm /root/tarsnap.key </code> </p></blockquote>
<blockquote><p><tt></tt><code>mv /root/tarsnap.key.new /root/tarsnap.key </code> </p></blockquote>
