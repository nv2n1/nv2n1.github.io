<h2 class="name">NAME</h2>
<p> xfce4-notifyd-config &#8211; configuration GUI for xfce4-notifyd </p>
<h2>SYNOPSIS</h2>
<dl>
<dt><code>xfce4-notifyd-config</code> [<code>-?</code>] [<code>-V</code>] [<code>-s</code> <i>SOCKET_ID</i>] [<code>&#8211;display</code>=<i>DISPLAY</i>]</p>
<dd></dl>
<h2>DESCRIPTION</h2>
<p> <code>xfce4-notifyd-config</code> will launch the configuration GUI for xfce4-notifyd.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-?</code>, <code>&#8211;help</code></p>
<dd> Show help</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Display version information</p>
<dt><code>-s</code>, <code>&#8211;socket-id</code>=<i>SOCKET_ID</i></p>
<dd> Settings manager socket</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</dl>
