<p>Xmark &#8211; summarize x11perf results </p>
<h2>Syntax</h2>
<p><code>Xmark</code> datafile</p>
<h2>Description</h2>
<p><code>Xmark</code> is a shell script that reads the indicated datafile and compiles a benchmark which it writes to standard output. It writes three numbers: </p>
<dl>
<dd>A weighted performance number for the <i>x11perf</i> results. </p>
<p> A weighted performance number for a standard SparcStation 1, with SunOS 4.1.2, X11R5 Xsun, and a CG3 dumb Color Frame Buffer. </p>
<p> The Xmark, which is the ratio of the two numbers above.</dl>
<p> The datafile must be an ordinary file, produced by x11perf in the following way: </p>
<p> <code>x11perf -display </code><i>display</i><code> -v1.3 -rop GXcopy GXxor -all &gt; </code><i>datafile</i> </p>
<p> It is possible to run the GXcopy and GXxor tests separately, as long as they are concatenated to the same output file: </p>
<pre><code>x11perf -display </code><i>display</i><code> -v1.3 -rop GXcopy -all &gt; </code><i>datafile</i>
<code>x11perf -display </code><i>display</i><code> -v1.3 -rop GXxor -all &gt;&gt; </code><i>datafile</i></pre>
<p>or </p>
<pre><code>x11perf -display </code><i>display</i><code> -v1.3 -rop GXxor -all &gt; </code><i>datafile</i>
<code>x11perf -display </code><i>display</i><code> -v1.3 -rop GXcopy -all &gt;&gt; </code><i>datafile</i></pre>
<h2>Files</h2>
<dl>
<dt><code>temp.$$</code></p>
<dd>Temporary file created in the current directory, deleted after use.</dl>
<h2>Diagnostics</h2>
<dl>
<dt><code>Usage: Xmark datafile</code></p>
<dd><i>Xmark</i> was invoked without arguments or with more than one argument, or with options. Xmark takes no options.</p>
<dt><code>Error: data file does not exist or is not ordinary.</code></p>
<dd><i>Xmark</i> cannot find the datafile named on its command line, or the datafile is a special file such as a directory.</p>
<dt><code>WARNING: datafile contains </code>nnn<code>, not 441 or 447 &#8216;trep&#8217; results;</code></p>
<dd>The file named on the command line does not seem to be a file generated by x11perf in the expected way.</p>
<dt><code>Diagnostic: ERROR: sum of weights =</code>nnn<code>, not equal to 4566.0;</code></p>
<dd>There is an internal error in Xmark.</dl>
