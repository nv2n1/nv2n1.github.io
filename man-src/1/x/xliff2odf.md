<h2>NAME</h2>
<p> xliff2odf &#8211; Convert XLIFF translation files to OpenDocument (ODF) files.</p>
<h2>SYNOPSIS</h2>
<p> <code>xliff2odf </code>[&#8211;version] [-h|&#8211;help] [&#8211;manpage] [&#8211;progress <i>PROGRESS</i>] [&#8211;errorlevel <i>ERRORLEVEL</i>] [-i|&#8211;input] <i>INPUT</i> [-x|&#8211;exclude <i>EXCLUDE</i>] [-o|&#8211;output] <i>OUTPUT</i> [-t|&#8211;template <i>TEMPLATE</i>] [-S|&#8211;timestamp]</p>
<h2>DESCRIPTION</h2>
<p> See: <a rel="nofollow" href="http://docs.translatehouse.org/projects/translate-toolkit/en/latest/commands/odf2xliff.html">http://docs.translatehouse.org/projects/translate-toolkit/en/latest/commands/odf2xliff.html</a> for examples and usage instructions.</p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;version</p>
<dd> show program&#8217;s version number and exit</p>
<dt>-h/&#8211;help</p>
<dd> show this help message and exit</p>
<dt>&#8211;manpage</p>
<dd> output a manpage based on the help</p>
<dt>&#8211;progress</p>
<dd> show progress as: dots, none, bar, names, verbose</p>
<dt>&#8211;errorlevel</p>
<dd> show errorlevel as: none, message, exception, traceback</p>
<dt>-i/&#8211;input</p>
<dd> read from INPUT in xlf format</p>
<dt>-x/&#8211;exclude</p>
<dd> exclude names matching EXCLUDE from input paths</p>
<dt>-o/&#8211;output</p>
<dd> write to OUTPUT in oth, odc, ots, oti, otg, odm, odp, ott, otc, ods, odf, odi, odg, otf, otp, odt formats</p>
<dt>-t/&#8211;template</p>
<dd> read from TEMPLATE in oth, odc, ots, oti, otg, odm, odp, ott, otc, ods, odf, odi, odg, otf, otp, odt formats</p>
<dt>-S/&#8211;timestamp</p>
<dd> skip conversion if the output file has newer timestamp </p>
</dl>
