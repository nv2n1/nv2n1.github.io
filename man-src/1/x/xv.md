<h2>NAME</h2>
<p> <code>xv</code> &#8211; interactive image display for the X Window System</p>
<h2>SYNTAX</h2>
<p> <code>xv</code> [<i>options</i>] [<i>filename</i>[<i>filename&#8230;</i>]]</p>
<h2>DESCRIPTION</h2>
<p> The <i>xv</i> program displays images on workstations and terminals running the X Window System, Version 11. Supported image formats include PBM, PGM, PPM, X11 bitmap, XWD, XPM, Utah Raster Toolkit RLE, PDS/VICAR, FITS, Sun Rasterfile, GIF, PCX, Targa/TGA, BMP, WBMP, IRIS RGB, Spectrum SCREEN$, PM, and optionally PNG, JPEG, JPEG 2000, JP2, TIFF, PostScript, PDF, G3 fax, MAG, PIC, MAKI (640&#215;400), PI, and PIC2. </p>
<p> Aside from the usage screen (available by typing &#8216;xv -help&#8217; at the command line), documentation for XV is now distributed <i>only</i> as a PostScript (or PDF) file, as it has gotten enormous and is no longer very well suited to the &#8216;man&#8217; page format. Print a copy of the (100-ish page) manual found in <i>docs/xvdocs.ps</i>. If you are unable to get the manual to print on your printer, you may purchase a printed copy of the XV manual. Click on &#8216;About XV&#8217; in the program to get further information. </p>
<p> If you don&#8217;t <i>have</i> the PostScript file, it is part of the standard XV distribution, the latest version of which can be obtained from <i><a rel="nofollow" href="http://www.trilon.com/xv/">http://www.trilon.com/xv/</a></i> or via anonymous ftp from <i><a href="ftp://ftp.cis.upenn.edu">ftp.cis.upenn.edu</a></i> in the directory pub/xv . </p>
<p> This version has been patched with the XV Jumbo Patches, available from <i><a rel="nofollow" href="http://pobox.com/~newt/greg_xv.html">http://pobox.com/~newt/greg_xv.html</a></i>. </p>
