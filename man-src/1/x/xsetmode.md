<h2 class="name">NAME</h2>
<p> xsetmode &#8211; set the mode for an X Input device </p>
<h2>SYNOPSIS</h2>
<p> <code>xsetmode</code> <i>device-name</i> <code>ABSOLUTE</code> | <code>RELATIVE</code></p>
<h2>DESCRIPTION</h2>
<p> Xsetmode sets the mode of an XInput device to either absolute or relative. This isn&#8217;t appropriate for all device types.</p>
