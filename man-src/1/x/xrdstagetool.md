<h2>NAME</h2>
<p> xrdstagetool &#8211; stage one or more files</p>
<h2>SYNOPSIS</h2>
<pre><code>
xrdstagetool[options] paths
        xrdstagetool[options] target -
    S source
</code></pre>
<h2>DESCRIPTION</h2>
<p> The <code>xrdstagetool</code> utility stages missing files into an xrootd server; optionally using a specific source server. The <code>xprep</code> command provides a similar, though not identical, set of features. Usage synopsis can be displayed by typing &quot;<code>xrdstagetool</code>&quot;. Currently, only the usage synopsis is available as documentation.</p>
<h2>NOTES</h2>
<p> Documentation for all components associated with <code>xrdstagetool</code> can be found at <a rel="nofollow" href="http://xrootd.org/docs.html">http://xrootd.org/docs.html</a></p>
<h2>DIAGNOSTICS</h2>
<p> Errors yield an error message and a non-zero exit status.</p>
