<h2 class="name">NAME</h2>
<p> xaumix &#8211; aumix wrapper for X</p>
<h2>DESCRIPTION</h2>
<p> <i>xaumix</i> is a wrapper to select one of rxvt, xterm, kterm, or one of the other possible xterm &quot;clones&quot;, and to launch that with aumix running in it. For some X terminal emulators an aumix colour scheme file is used to generate a sensible display (for example, rxvt and xterm behave differently with respect to the handling of colours). </p>
<p> This script was originally intended for use from the Debian <code>menu</code> system, but may also be invoked manually from a shell. The GTK+ interface to <i>aumix</i> largely supersedes it. </p>
