<h2>NAME</h2>
<p> xapian-config &#8211; report information about the installed version of xapian</p>
<h2>SYNOPSIS</h2>
<p> <code>xapian-config</code> <i>OPTION</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> xapian-config &#8211; report information about the installed version of xapian</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;cxxflags</code></p>
<dd> output all preprocessor and C++ compiler flags</p>
<dt><code>&#8211;libs</code></p>
<dd> output all linker flags</p>
<dt><code>&#8211;ltlibs</code></p>
<dd> output linker flags for linking using GNU libtool</p>
<dt><code>&#8211;static</code></p>
<dd> make other options report values for static linking</p>
<dt><code>&#8211;swigflags</code></p>
<dd> output preprocessor flags for use with SWIG</p>
<dt><code>&#8211;help</code></p>
<dd> output this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> output version information and exit</dl>
