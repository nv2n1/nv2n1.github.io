<h2>NAME</h2>
<p> xhydra &#8211; Gtk+2 frontend for thc-hydra</p>
<h2>SYNOPSIS</h2>
<p> Execute xhydra in a terminal to start the application.</p>
<h2>DESCRIPTION</h2>
<p> Hydra is a parallized login cracker which supports numerous protocols to attack. New modules are easy to add, beside that, it is flexible and very fast. </p>
<p> This tool gives researchers and security consultants the possiblity to show how easy it would be to gain unauthorized access from remote to a system. </p>
<p> Currently this tool supports:<br />
&nbsp;<wbr>AFP, Cisco AAA, Cisco auth, Cisco enable, CVS, Firebird, FTP, HTTP-FORM-GET,<br />
&nbsp;<wbr>HTTP-FORM-POST, HTTP-GET, HTTP-HEAD, HTTP-PROXY, HTTPS-FORM-GET, HTTPS-FORM-POST,<br />
&nbsp;<wbr>HTTPS-GET, HTTPS-HEAD, ICQ, IMAP, IRC, LDAP, MS-SQL, MYSQL, NCP, NNTP, PCNFS, POP3,<br />
&nbsp;<wbr>POSTGRES, RDP, REXEC, SAP/R3, SMB, SMTP, SNMP, SOCKS5, SSH(v1 and v2),<br />
&nbsp;<wbr>Subversion, Teamspeak&nbsp;<wbr>(TS2), TELNET, VMware-Auth, VNC and XMPP.</p>
