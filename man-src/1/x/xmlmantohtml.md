<h2>NAME</h2>
<p> xmlmantohtml &#8211; xml to html converter</p>
<h2>SYNOPSIS</h2>
<p> <code>xmlmantohtml </code><i>file.1.xml</i><code> &gt; file.1.html </code></p>
<h2>DESCRIPTION</h2>
<p> xmlmantohtml is a small script to convert xml/man to html. </p>
<p> You will find the dtd in <i>/usr/share/xmltoman/</i> on a debian system. There is also an xsl file to generate html using <code><a href="/docs/linux/man/1-xsltproc/">xsltproc</a>(1)</code>. See also <i>/usr/share/doc/xmltoman/examples</i> for examples. </p>
<p> If xsltproc proves to be a useful alternative, this program will be obsoleted.</p>
