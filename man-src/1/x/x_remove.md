<h2>NAME</h2>
<p> <code>x_remove</code> &#8211; Remove COEs for Selected Cruises from the Data Base</p>
<h2>SYNOPSIS</h2>
<p> <code>x_remove</code> <i>removefile</i> [ <code>-X</code><i>xbase</i> ] [ <code>-L</code><i>legbase</i> ] [ <code>-V</code> ]</p>
<h2>DESCRIPTION</h2>
<p> <code>x_remove</code> will read a list of &#8216;bad&#8217; cruises, read the <code>XSYSTEM</code> data base files, and write out new <code>XSYSTEM</code> files that do not include any COEs generated by the bad cruises. This is useful if certain cruises turn out to have systematic errors (e.g. the topography values were inadvertently given as fathoms instead of meters), and we would like to re-run <code>x_over/x_update</code> after the systematic errors have been rectified. The new file names will consist of the old file names with the suffix _new appended.</p>
<dl>
<dt><code>-X</code></p>
<dd> Indicates alternate xbase file [Default is <i>xx_base.b</i>].</p>
<dt><code>-L</code></p>
<dd> Indicates alternate legbase file [Default is <i>xx_legs.b</i>].</p>
<dt><code>-V</code></p>
<dd> Selects verbose mode, which will send progress reports to stderr [Default runs &quot;silently&quot;].</dl>
