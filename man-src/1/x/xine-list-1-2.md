<p>xine-list-1.2 &#8211; get supported filetype information from xine-lib</p>
<h2>Synopsis</h2>
<p><code>xine-list-1.2</code> [options&#8230;<i>] </i></p>
<h2>Description</h2>
<p><i>xine-list-1.2</i> is a tool that is used to list the MIME type and filename extension information known and supported by the installed <i>xine-lib</i>. It is of use in filling in MIME information in front ends&#8217; desktop files.</p>
<h2>Options</h2>
<p><i>xine-list-1.2</i> accepts the following options:</p>
<dl COMPACT>
<dt><code>-m</code></p>
<dd><code>&#8211;mime-types</code> List the MIME types known to <i>xine-lib</i>. (This is the default action.)</p>
<dt><code>-e</code></p>
<dd><code>&#8211;extensions</code> List the file types (filename extensions) known to <i>xine-lib</i>.</p>
<dt><code>-a</code></p>
<dd><code>&#8211;all</code> List the MIME types known to <i>xine-lib</i>, along with their filename extensions and descriptions.</p>
<dt><code>-p</code></p>
<dd><code>&#8211;pretty-print</code> Add line feeds; print each item on a line of its own.</dl>
