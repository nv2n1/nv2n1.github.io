<h2>NAME</h2>
<p> xmlsec1-config &#8211; detail installed version of xmlsec library</p>
<h2>SYNOPSIS</h2>
<p> <code>xmlsec1-config</code> [<i>OPTION</i>]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> Known values for OPTION are:</p>
<dl>
<dt><code>&#8211;prefix</code>=<i>DIR</i></p>
<dd> change XMLSEC prefix</p>
<dt><code>&#8211;exec-prefix</code>=<i>DIR</i></p>
<dd> change XMLSEC executable prefix</p>
<dt><code>&#8211;libs</code></p>
<dd> print library linking information</p>
<dt><code>&#8211;cflags</code></p>
<dd> print pre-processor and compiler flags</p>
<dt><code>&#8211;crypto</code></p>
<dd> print the default crypto library name</p>
<dt><code>&#8211;help</code></p>
<dd> display this help and exit</p>
<dt><code>&#8211;version</code></p>
<dd> output version information</p>
<dt><code>&#8211;crypto</code>=<i>LIB</i></p>
<dd> configure with XMLSEC crypto library (one of the following: none default openssl nss gnutls gcrypt) </p>
</dl>
