<p> <code>dwp</code> [<i>,options/</i>] [<i>,file/</i>&#8230;]</p>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></dt>
<dd> Print this help message</dd>
<dt><code>-e</code> EXE, <code>&#8211;exec</code> EXE</dt>
<dd> Get list of dwo files from EXE (defaults output to EXE.dwp)</dd>
<dt><code>-o</code> FILE, <code>&#8211;output</code> FILE</dt>
<dd> Set output dwp file name</dd>
<dt><code>-v</code>, <code>&#8211;verbose</code></dt>
<dd> Verbose output</dd>
<dt><code>&#8211;verify-only</code></dt>
<dd> Verify output file against exec file</dd>
<dt><code>-V</code>, <code>&#8211;version</code></dt>
<dd> Print version number</dd></dl>
