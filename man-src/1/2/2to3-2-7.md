<p>2to3-2.7 &#8211; Python2 to Python3 converter </p>
<h2>Synopsis</h2>
<p><code>2to3</code> [<i>options</i>] <i>file|dir </i>&#8230;</p>
<h2>Options</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>show this help message and exit</p>
<dt><code>-d</code>, <code>&#8211;doctests_only</code></p>
<dd>Fix up doctests only</p>
<dt><code>-f</code> FIX, <code>&#8211;fix</code>=<i>FIX</i></p>
<dd>Each FIX specifies a transformation; default: all</p>
<dt><code>-j</code> PROCESSES, <code>&#8211;processes</code>=<i>PROCESSES</i></p>
<dd>Run 2to3 concurrently</p>
<dt><code>-x</code> NOFIX, <code>&#8211;nofix</code>=<i>NOFIX</i></p>
<dd>Prevent a transformation from being run</p>
<dt><code>-l</code>, <code>&#8211;list-fixes</code></p>
<dd>List available transformations</p>
<dt><code>-p</code>, <code>&#8211;print-function</code></p>
<dd>Modify the grammar so that print() is a function</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd>More verbose logging</p>
<dt><code>&#8211;no-diffs</code></p>
<dd>Don&#8217;t show diffs of the refactoring</p>
<dt><code>-w</code>, <code>&#8211;write</code></p>
<dd>Write back modified files</p>
<dt><code>-n</code>, <code>&#8211;nobackups</code></p>
<dd>Don&#8217;t write backups for modified files </p>
</dl>
