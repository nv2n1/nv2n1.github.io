<h2 class="name">NAME</h2>
<p> dsktune &#8211; reports memory, network, and file system tuning settings which can affect the performance of the Directory Server </p>
<h2>SYNOPSIS</h2>
<p> <code>dsktune</code> [<i>-q</i>] [<i>-c</i>] [<i>-D</i>] [<i>-v</i>] [<i>-i installdir</i>]</p>
<h2>DESCRIPTION</h2>
<p> Reports memory, network, and file system tuning settings which can affect the performance of the Directory Server </p>
<h2>OPTIONS</h2>
<p> A summary of options is included below:</p>
<dl>
<dt><code>-q</code></p>
<dd> dsktune only reports essential settings</p>
<dt><code>-c</code></p>
<dd> dsktune only reports tuning information for client machines</p>
<dt><code>-D</code></p>
<dd> dsktune also reports the commands executed</p>
<dt><code>-v</code></p>
<dd> dsktune only reports its release version date</p>
<dt><code>-i installdir</code></p>
<dd> specify alternate server installation directory
</dl>
