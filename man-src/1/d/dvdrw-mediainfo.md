<p>dvd+rw-mediainfo &#8211; display information about dvd drive and disk</p>
<h2>Synopsis</h2>
<p><code>dvd+rw-mediainfo</code> <i>/dev/dvd</i> </p>
<h2>Description</h2>
<p>The <code>dvd+rw-mediainfo</code> command displays information about the drive and disk in the specified dvd drive (e.g. <i>/dev/dvd</i>). This is especially useful for debugging purposes and it is requested that its output be included when reporting bugs found in the <code>dvd+rw-tools</code><i> package. </p>
<p> </i></p>
<h2>Options</h2>
<dl>
<dt>This program does not accept any command line options.</p>
<dd></dl>
