<h2 class="name">NAME</h2>
<p> darktable-generate-cache &#8211; update darktable&#8217;s thumbnail cache </p>
<h2>SYNOPSIS</h2>
<pre><code>
darktable - generate - cache[-h, --help; --version][-m, --max - mip&lt;0 - 7&gt;][--core&lt;darktable options&gt;]
</code></pre>
<h2>DESCRIPTION</h2>
<p> <code>darktable</code> is a digital photography workflow application for <code>Linux</code>, <code>Mac </code><font SIZE="-1"><code>OS X</code></font> and several other <code>Unices</code>. It&#8217;s described further in <i><a href="/docs/linux/man/1-darktable/">darktable</a></i>(1). </p>
<p> <code>darktable-generate-cache</code> updates darktable&#8217;s thumbnail cache. You can start this program to generate all missing thumbnails in the background when your computer is idle.</p>
<h2>OPTIONS</h2>
<p> All parameters are optional. If started without parameters <code>darktable-generate-cache</code> uses reasonable defaults.</p>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Gives usage information and terminates.</p>
<dt><code>&#8211;version</code></p>
<dd> Gives copyright and version information and terminates.</p>
<dt><code>-m, &#8211;max-mip &lt;0-7&gt;</code></p>
<dd> <code>darktable</code> can handle and store thumbnails with up to eight different resolution steps for each image. This parameter defines which maximum resolution should be generated and defaults to <code>2</code>. There is normally no need to generate all possible resolutions here; missing ones will be automatically generated by darktable the moment they are needed.</p>
<dt><code>&#8211;core &lt;darktable options&gt;</code></p>
<dd> All command line parameters following <code>&#8211;core</code> are passed to the darktable core and handled as standard parameters. See <i><a href="/docs/linux/man/1-darktable/">darktable</a></i>(1) for a detailed description of the options.</dl>
