<h2>NAME</h2>
<p> dvdxchap &#8211; Extract chapter information from DVDs</p>
<h2>SYNOPSIS</h2>
<p> <code>dvdxchap</code> [<i>options</i>] <i>DVD-SOURCE</i></p>
<h2>DESCRIPTION</h2>
<p> This program extracts chapter information from a DVD and displays it in a form usable by <code><a href="/docs/linux/man/1-ogmmerge/">ogmmerge</a>(1)</code>.</p>
<dl>
<dt><code>-t</code>, <code>&#8211;title</code> <i>num</i></p>
<dd> Use title &#8216;<i>num</i>&#8216;. Default is 1.</p>
<dt><code>-c</code>, <code>&#8211;chapter</code> <i>start</i>[-<i>end</i>]</p>
<dd> Only output the given range of chapters and adjust all timecodes so that they start at 0. The default is to output all chapters.</p>
<dt><code>-v</code></p>
<dd> Increase verbosity</p>
<dt><code>-V</code></p>
<dd> Show version information</p>
<dt><code>-h</code></p>
<dd> Show help</dl>
<h2>EXAMPLES</h2>
<p> The output generated by <code>dvdxchap</code> will have the form </p>
<p> CHAPTER01=00:01:35.240<br />
 CHAPTER01NAME=Chapter 01<br />
 CHAPTER02=00:03:40:300<br />
 CHAPTER02NAME=Chapter 02<br />
 etc. </p>
<p> You should pipe its output to a file, edit the chapter names and use the resulting file as an input for <code><a href="/docs/linux/man/1-ogmmerge/">ogmmerge</a>(1)</code>.</p>
