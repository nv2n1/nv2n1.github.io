<p>doxysearch.cgi &#8211; search engine used for searching in doxygen documentation. </p>
<h2>Synopsis</h2>
<p><code>doxysearch.cgi</code></p>
<h2>Description</h2>
<p>CGI binary that is used by doxygen generated HTML output to search for words. The tool uses the search index called <code>doxysearch.db</code> produced by doxyindexer.</p>
