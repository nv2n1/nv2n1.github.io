<h2>NAME</h2>
<p> doxywizard &#8211; a tool to configure and run doxygen on your source files</p>
<h2>SYNOPSIS</h2>
<p> <code>doxywizard</code></p>
<h2>DESCRIPTION</h2>
<p> Doxywizard is an interactive frontend to the doxygen tool to configure and run doxygen on your source files. </p>
<p> You can optionally pass the name of a configuration file as the first argument to load it at startup.</p>
