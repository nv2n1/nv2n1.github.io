<h2>NAME</h2>
<p> doxytag &#8211; generates a tag file and/or a search index for a set of HTML files</p>
<h2>SYNOPSIS</h2>
<p> <code>doxytag</code> [<i>-t tag_file</i>] [<i>-s index_file</i>] [ <i>html_file </i>[<i>html_file</i>&#8230;] ]</p>
<h2>DESCRIPTION</h2>
<p> Generates a tag file and/or a search index for a set of HTML files. Use doxysearch as a CGI program to search the tag file generated by doxytag.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-t</code> &lt;tag_file&gt;</p>
<dd> Generate tag file &lt;tag_file&gt;.</p>
<dt><code>-s</code> &lt;index_file&gt;</p>
<dd> Generate search index &lt;index_file&gt;.</dl>
<p> If no HTML files are given all files in the current dir that have a .html extension are parsed.</p>
