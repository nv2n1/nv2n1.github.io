<h2>NAME</h2>
<p> djvudigital &#8211; creates DjVu files from PS or PDF files. </p>
<h2>SYNOPSIS</h2>
<p> <code>djvudigital [</code><i>options</i><code>] </code><i>inputfile</i><code> [</code><i>outputfile</i><code>]</code> </p>
<h2>DESCRIPTION</h2>
<p> This program creates a DjVu file from the PostScript (<code>.ps</code>), GZipped PostScript (<code>.ps.gz</code>), Encapsulated PostScript (<code>.eps</code>), or Portable Document Format (<code>.pdf</code>) file <i>inputfile</i>. </p>
<p> The output file name is either given by argument <i>outputfile</i> or generated by replacing the input file name suffixes by the DjVu suffix (<code>.djvu</code>). </p>
<h2>PREREQUISITES</h2>
<p> This program depends on a specific GhostScript driver. If your GhostScript program does not provide this driver, please check <code><a rel="nofollow" href="http://djvu.sourceforge.net/gsdjvu.html">http://djvu.sourceforge.net/gsdjvu.html</a></code>. </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8211;verbose</code>, <code>-v</code></p>
<dd> Displays more informational messages while converting the file.</p>
<dt><code>&#8211;quiet</code>, <code>-q</code></p>
<dd> Do not display informational messages while converting the file.</p>
<dt><code>&#8211;dpi=</code><i>resolution</i></p>
<dd> Specify the desired resolution to <i>resolution</i> dots per inch. The default is 300 dpi.</p>
<dt><code>&#8211;psrotate=</code><i>angle</i></p>
<dd> Rotate the PostScript file by <i>angle</i> degrees clockwise. Only the values <code>0</code>, <code>90</code>, <code>180</code>, and <code>270</code> are supported. This option only applies to PostScript files. PDF files are always converted according to their native orientation.</p>
<dt><code>&#8211;epsf=</code><i>disposition</i></p>
<dd> Specify how to handle Encapsulated PostScript files. Argument <i>disposition</i> can take the values <code>crop</code>, <code>fit</code>, and <code>ignore</code>. The default disposition <code>crop</code> creates a DjVu file whose size matches the bounding box of the Encapsulated PostScript file. Value <code>fit</code> rescales the graphics to the default page size. Value <code>ignore</code> disables all Encapsulated PostScript specific code. This option requires Ghostscript 7.07 or better.</p>
<dt><code>&#8211;exact-color</code></p>
<dd> Enables a more accurate rendering of the colors. This option requires GhostScript 6.52 or better.</p>
<dt><code>&#8211;threshold=</code><i>thres</i></p>
<dd> Specify a threshold for the foreground/background separation code. Acceptable values of <i>thres</i> range from 0 to 100. Larger values place more information into the foreground layer. The default threshold value is 80.</p>
<dt><code>&#8211;bg-subsample=</code><i>sub</i></p>
<dd> Specify the background subsampling ratio. Argument <i>sub</i> must be an integer between 1 and 6. The default value is 3.</p>
<dt><code>&#8211;bg-slices=</code><i>n</i><code>+&#8230;+</code><i>n</i></p>
<dd> Specify the encoding quality of the background layer. The syntax for the argument is similar to that described for the <code>-slice</code> option of command <code>c44</code>. The default is <code>72+11+10+10</code>.</p>
<dt><code>&#8211;fg-colors=</code><i>ncolors</i></p>
<dd> Specify the maximum number of distinct colors in the foreground layer. Argument <i>ncolors</i> can take integer values between 1 and 4000. The default value is 256.</p>
<dt><code>&#8211;fg-image-colors=</code><i>ncolors</i></p>
<dd> Specify the maximum number of distinct colors in an image for considering encoding it into the foreground layer. Argument <i>ncolors</i> can take integer values between 1 and 4000. The default value is 256.</p>
<dt><code>&#8211;words</code></p>
<dd> Extract the text from the PostScript code and incorporates this information into the DjVu file. This option records the location of every word.</p>
<dt><code>&#8211;lines</code></p>
<dd> Extract the text from the PostScript code and incorporates this information into the DjVu file. This option saves a few bytes by only recording the location of each line.</p>
<dt><code>&#8211;gsarg=</code><i>arg1</i><code>[,</code><i>arg2</i><code>,&#8230;,</code><i>argN</i><code>]</code></p>
<dd> Insert extra arguments on the GhostScript command line.</p>
<dt><code>&#8211;cseparg=</code><i>arg1</i><code>[,</code><i>arg2</i><code>,&#8230;,</code><i>argN</i><code>]</code></p>
<dd> Insert extra arguments on the command line of program <code>csepdjvu</code> or <code>msepdjvu</code>.</p>
<dt><code>&#8211;sepfile</code></p>
<dd> Produces a separated data file instead of a DjVu file. Program <code>csepdjvu</code> can then convert the separated data file into a DjVu file.</p>
<dt><code>&#8211;check</code></p>
<dd> Display the names of the two auxiliary programs found by <code>djvudigital</code>, namely a suitable ghostscript interpreter and a suitable backend encoder. See the next two section for details.</p>
<dt><code>&#8211;dryrun</code></p>
<dd> Simply display the ghostscript command line generated by <code>djvudigital</code> without running it. No output file is produced</p>
<dt><code>&#8211;help</code></p>
<dd> Display the manual page for <code>djvudigital</code>.</dl>
<h2>GHOSTSCRIPT ISSUES</h2>
<p> Program <code>djvudigital </code> internally relies on a specific Ghostscript driver named <code>djvusep</code>. This driver analyzes the logical structure of the sequence of PostScript rendering commands and decides to execute each command into either the foreground or the background layer. The GhostScript driver produces a separated data file that is then compressed using the DjVuLibre program <code>csepdjvu</code>. </p>
<p> Before processing the input file, program <code>djvudigital</code> searches a Ghostscript executable providing the <code>djvusep</code> driver. The search starts with the file specified by the environment variable <code>GSDJVU</code> and continues with command line executables named <code>gs</code> and <code>gsdjvu</code>. </p>
<p> The DjVuLibre source code contains instruction to compile such a GhostScript executable. More information can be obtained from <code><a rel="nofollow" href="http://djvu.sourceforge.net/gsdjvu.html">http://djvu.sourceforge.net/gsdjvu.html</a></code>. </p>
<h2>CSEPDJVU ISSUES</h2>
<p> The output of the <code>djvusep</code> GhostScript driver must be processed by the DjVuLibre program <code>csepdjvu</code>. This program can also be replaced by the the proprietary Lizardtech program <code>msepdjvu</code>. Before processing the input file, program <code>djvudigital</code> searches such an executable. The search starts with the file specified by the environment variable <code>CSEPDJVU</code> and continues with command line executables named <code>msepdjvu</code> and <code>csepdjvu</code>. </p>
