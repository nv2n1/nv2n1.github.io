<h2 class="name">NAME</h2>
<p> dh_listpackages &#8211; list binary packages debhelper will act on </p>
<h2>SYNOPSIS</h2>
<p> <code>dh_listpackages</code> [<i>debhelper options</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>dh_listpackages</code> is a debhelper program that outputs a list of all binary packages debhelper commands will act on. If you pass it some options, it will change the list to match the packages other debhelper commands would act on if passed the same options.</p>
