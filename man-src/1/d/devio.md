<h2 class="name">NAME</h2>
<p> devio &#8211; program to read and write from block devices </p>
<h2>SYNOPSIS</h2>
<p> <code>devio</code> [<i>options</i>]<i> files</i>&#8230;</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>devio</code> command. </p>
<p> <code>devio</code> is a command line program intended to read and write from block devices.</p>
<h2>OPTIONS</h2>
<p> This program follows the usual GNU command line syntax, with long options starting with two dashes (`-&#8216;). A summary of options is included below.</p>
<dl>
<dt><code>-h, &#8211;help</code></p>
<dd> Show summary of options.</p>
<dt><code>-v, &#8211;version</code></p>
<dd> Show version of program.</dl>
