<h2 class="name">NAME</h2>
<p> dh_scour &#8211; run scour optimizer on shipped SVG files </p>
<h2>SYNOPSIS</h2>
<p> <code>dh_scour</code> [<i>debhelper options</i>] [<code>&#8212;</code>&nbsp;<i>params</i>]</p>
<h2>DESCRIPTION</h2>
<p> dh_scour is a debhelper program that will run the scour <font SIZE="-1">SVG</font> image scrubber on all shipped <font SIZE="-1">SVG</font> files.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>&#8212;</code> <i>params</i></p>
<dd> Pass &#8220;params&#8221; to <i><a href="/docs/linux/man/1-scour/">scour</a></i>(1). By default, no extra arguments are passed.</dl>
