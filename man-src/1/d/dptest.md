<h2 class="name">NAME</h2>
<p> dptest &#8211; test cases for QDBM Depot</p>
<h2>SYNOPSIS</h2>
<p> <code>dptest write</code> [-s] <i>name</i> <i>rnum</i> <i>bnum</i><br />
 <code>dptest read</code> [-wb] <i>name</i><br />
 <code>dptest rcat</code> [-c] <i>name</i> <i>rnum</i> <i>bnum</i> <i>pnum</i> <i>align</i><br />
 <code>dptest combo</code> <i>name</i><br />
 <code>dptest wicked</code> [-c] <i>name</i> <i>rnum</i> </p>
<h2>DESCRIPTION</h2>
<p> The command `dptest&#8217; is a utility for facility test and performance test. Check a database generated by the command or measure the execution time of the command. This command is used in the following format. `name&#8217; specifies a database name. `rnum&#8217; specifies the number of the records. `bnum&#8217; specifies the number of the elements of the bucket array. `pnum&#8217; specifies the number of patterns of the keys. `align&#8217; specifies the basic size of alignment. `fbpsiz&#8217; specifies the size of the free block pool. </p>
<dl>
<dt><code>dptest write [-s] name rnum bnum</code></p>
<dd> Store records with keys of 8 bytes. They change as `00000001&#8242;, `00000002&#8217;&#8230;</p>
<dt><code>dptest read [-wb] name</code></p>
<dd> Retrieve all records of the database above.</p>
<dt><code>dptest rcat [-c] name rnum bnum pnum align fbpsiz</code></p>
<dd> Store records with partway duplicated keys using concatenate mode.</p>
<dt><code>dptest combo name</code></p>
<dd> Perform combination test of various operations.</p>
<dt><code>dptest wicked [-c] name rnum</code></p>
<dd> Perform updating operations selected at random.</dl>
<p> Options feature the following. </p>
<dl>
<dt>
<dd> <code>-s</code> : make the file sparse.<br />
 <code>-wb</code> : use the function `dpgetwb&#8217; instead of the function `dpget&#8217;.<br />
 <code>-c</code> : perform comparison test with map of Cabin.</dl>
<p> This command returns 0 on success, another on failure. The environment variable `QDBMDBGFD&#8217; specifies the file descriptor to output the history of updating the variable `dpecode&#8217;. </p>
