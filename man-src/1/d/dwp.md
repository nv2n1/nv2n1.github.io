<h2 class="name">NAME</h2>
<p> dwp &#8211; The DWARF packaging utility </p>
<h2>SYNOPSIS</h2>
<p> <code>dwp</code> [<i>,options/</i>] [<i>,file/</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Print this help message</p>
<dt><code>-e</code> EXE, <code>&#8211;exec</code> EXE</p>
<dd> Get list of dwo files from EXE (defaults output to EXE.dwp)</p>
<dt><code>-o</code> FILE, <code>&#8211;output</code> FILE</p>
<dd> Set output dwp file name</p>
<dt><code>-v</code>, <code>&#8211;verbose</code></p>
<dd> Verbose output</p>
<dt><code>&#8211;verify-only</code></p>
<dd> Verify output file against exec file</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print version number</dl>
