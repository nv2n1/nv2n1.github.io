<h2 class="name">NAME</h2>
<p> dbxtool &#8211; modify the dbx revokation list </p>
<h2>SYNOPSIS</h2>
<p> dbxtool [CMD]</p>
<h2>DESCRIPTION</h2>
<p> This manual page documents briefly the <code>dbxtool</code> command. </p>
<p> <code>dbxtool</code> allows a user to operate on the UEFI dbx revokation list. This tool can be used to list the current dbx contents or update it to a newer version.</p>
<h2>OPTIONS</h2>
<p> The dbxtool command takes various options depending on the action. Run <code>dbxtool &#8211;help</code> for the full list.</p>
