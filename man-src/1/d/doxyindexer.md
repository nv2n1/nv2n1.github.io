<h2 class="name">NAME</h2>
<p> doxyindexer &#8211; creates a search index from raw search data </p>
<h2>SYNOPSIS</h2>
<p> <code>doxyindexer</code> [<i>-o output_dir</i>] <i>searchdata.xml </i>[<i>searchdata2.xml</i>&#8230;]</p>
<h2>DESCRIPTION</h2>
<p> Generates a search index called <code>doxysearch.db</code> from one or more search data files produced by doxygen. Use doxysearch.cgi as a CGI program to search the data indexed by doxyindexer.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-o</code> &lt;output_dir&gt;</p>
<dd> The directory where to write the doxysearch.db to. If omitted the current directory is used.</dl>
