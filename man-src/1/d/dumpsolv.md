<h2 class="name">NAME</h2>
<p> dumpsolv &#8211; print a solv file into a human readable format </p>
<h2>SYNOPSIS</h2>
<p> <code>dumpsolv</code> [<i>OPTIONS</i>] [<i>FILE.solv</i>]</p>
<h2>DESCRIPTION</h2>
<p> The dumpsolv tool reads a solv files and writes its contents to standard output. If no input file is given, it reads the solv file from standard input. </p>
<p> <code>-j</code></p>
<dl>
<dt>
<dd> Write the contents in JSON format.</dl>
