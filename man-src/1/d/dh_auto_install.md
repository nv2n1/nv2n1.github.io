<h2 class="name">NAME</h2>
<p> dh_auto_install &#8211; automatically runs make install or similar </p>
<h2>SYNOPSIS</h2>
<p> <code>dh_auto_install</code> [<i>build system options</i>] [<i>debhelper options</i>] [<code>&#8212;</code> <i>params</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>dh_auto_install</code> is a debhelper program that tries to automatically install built files. It does so by running the appropriate command for the build system it detects the package uses. For example, if there&#8217;s a <i>Makefile</i> and it contains a <code>install</code> target, then this is done by running <code>make</code> (or <font SIZE="-1"><code>MAKE</code></font>, if the environment variable is set). If there is a <i>setup.py</i> or <i>Build.PL</i>, it is used. Note that the Ant build system does not support installation, so <code>dh_auto_install</code> will not install files built using Ant. </p>
<p> Unless <code>&#8211;destdir</code> option is specified, the files are installed into debian/<i>package</i>/ if there is only one binary package. In the multiple binary package case, the files are instead installed into <i>debian/tmp/</i>, and should be moved from there to the appropriate package build directory using <i><a href="/docs/linux/man/1-dh_install/">dh_install</a></i>(1). </p>
<p> <font SIZE="-1"><code>DESTDIR</code></font> is used to tell make where to install the files. If the Makefile was generated by MakeMaker from a <i>Makefile.PL</i>, it will automatically set <code>PREFIX=/usr</code> too, since such Makefiles need that. </p>
<p> This is intended to work for about 90% of packages. If it doesn&#8217;t work, or tries to use the wrong install target, you&#8217;re encouraged to skip using <code>dh_auto_install</code> at all, and just run make install manually.</p>
<h2>OPTIONS</h2>
<p> See &quot;<font SIZE="-1"><code>BUILD SYSTEM OPTIONS</code></font>&quot; in <i><a href="/docs/linux/man/7-debhelper/">debhelper</a></i>(7) for a list of common build system selection and control options.</p>
<dl>
<dt><code>&#8211;destdir=</code><i>directory</i></p>
<dd> Install files into the specified <i>directory</i>. If this option is not specified, destination directory is determined automatically as described in the &quot;<font SIZE="-1"><code>DESCRIPTION</code></font>&quot; section.</p>
<dt><code>&#8212;</code> <i>params</i></p>
<dd> Pass <i>params</i> to the program that is run, after the parameters that <code>dh_auto_install</code> usually passes.</dl>
