<h2 class="name">NAME</h2>
<p> dex </p>
<h2>SYNOPSIS</h2>
<p> dex [-c command] [-t tag] [-r rcfile] [-V] [file]&#8230;</p>
<h2>DESCRIPTION</h2>
<p> A small and flexible text editor.</p>
<h2>COMMAND LINE OPTIONS</h2>
<p> -c command</p>
<dl>
<dt>
<dd> Run this command after reading the rc file and opening any files specified on command line.</dl>
<p> -r rcfile</p>
<dl>
<dt>
<dd> Read this rc file instead of ~/.dex/rc or /usr/share/dex/rc.</dl>
<p> -t tag</p>
<dl>
<dt>
<dd> Go to tag. Requires tags file generated by Exuberant Ctags.</dl>
<p> -R</p>
<dl>
<dt>
<dd> Don&#8217;t read the rc file.</dl>
<p> -V</p>
<dl>
<dt>
<dd> Display the version number and exit.</dl>
<h2>BASIC USAGE</h2>
<p> Here&#8217;s some of the default key bindings. <code>M-x</code> means meta-x or alt-x and <code>^V</code> is ctrl-v. See /usr/share/dex/bindings/default for more keys.</p>
<dl>
<dt>
<dd>
<dl>
<dt>M-s</p>
<dd> select</p>
<dt>^V</p>
<dd> select lines</p>
<dt>^Y</p>
<dd> copy current line or selection</p>
<dt>^D</p>
<dd> cut current line or selection</p>
<dt>^P</p>
<dd> paste</p>
<dt>^E</p>
<dd> undo</p>
<dt>^R</p>
<dd> redo</p>
<dt>^C</p>
<dd> enter command line</p>
<dt>M-/</p>
<dd> search</p>
<dt>M-n</p>
<dd> search next</p>
<dt>M-p</p>
<dd> search previous</p>
<dt>M-<i>N</i></p>
<dd> activate <i>N</i>th tab</dl>
</dl>
<p> On the command line you can use tab to complete commands and most of their parameters. Run <code>next</code> or <code>prev</code> to switch to next or previous file. The commands <code>open</code>, <code>save</code> and <code>quit</code> should be obvious.</p>

<p> hi &lt;name&gt; [fg-color [bg-color]] [attribute]&#8230;</p>
<dl>
<dt>
<dd> Set highlight color.</dl>
<dl>
<dt>
<dd> Colors:</p>
<dl>
<dt>
<dd> keep (-2) default (-1) black (0) red green yellow blue magenta cyan gray darkgray lightred lightgreen lightyellow lightblue lightmagenta lightcyan white</dl>
</dl>
<dl>
<dt>
<dd> Color can be given as a numeric value too (-2..255).</dl>
<dl>
<dt>
<dd> Colors 16-255 are supported by modern xterm compatible terminal emulators. There&#8217;s a 6x6x6 color cube at indexes 16..231. For these colors it is easiest to use the R/G/B syntax where R, G and B are values between 0 and 5.</dl>
<dl>
<dt>
<dd> Indexes 232..255 contain 24 grayscale values which can be used to specify grayscale value more accurately than using the R/G/B syntax.</dl>
<dl>
<dt>
<dd> Attributes:</p>
<dl>
<dt>
<dd> bold lowintensity italic underline blink reverse invisible keep</dl>
</dl>
<dl>
<dt>
<dd> The color and attribute value &quot;keep&quot; is useful in selected text to keep fg-color and attributes and change only bg-color.</dl>
<dl>
<dt>
<dd> NOTE: Because &quot;keep&quot; is both color and attribute you need to specify both fg-color and bg-color if you want to set the &quot;keep&quot; attribute.</dl>
<dl>
<dt>
<dd> If you omit any color it is set to default (-1).</dl>
<dl>
<dt>
<dd> Unset fg/bg colors are inherited from highlight color &quot;default&quot;. If you don&#8217;t set fg/bg for the highlight color &quot;default&quot; then terminal&#8217;s default fg/bg is used.</dl>

<h2>OPTIONS</h2>
<p> Options can be changed using the <code>set</code> command. Enumerated option values can also be <code>toggle</code>d. To see which options are enumerated type &quot;toggle &quot; on command line and press tab. You can also use the <code>option</code> command to set filetype/filename specific options.</p>
<h3>Local and global options</h3>
<p> Global values of these options serve as default values for local (per-file) options. </p>
<p> auto-indent [true]</p>
<dl>
<dt>
<dd> Automatically insert indentation when pressing enter. Indentation is copied from previous non-empty line. If also the <code>indent-regex</code> local option is set then indentation is automatically increased if the regular expression matches current line.</dl>
<p> detect-indent [&quot;&quot;]</p>
<dl>
<dt>
<dd> Comma separated list of indent widths (1-8) to detect automatically when file is opened. Set to &quot;&quot; to disable. Tab indentation is detected if the value is not &quot;&quot;. Adjusts following options if indentation style is detected: <code>emulate-tab</code>, <code>expand-tab</code>, <code>indent-width</code>.</dl>
<dl>
<dt>
<dd> Example:</p>
<dl>
<dt>

<h2>COMMAND SYNTAX</h2>
<p> Command syntax is similar to shell but simpler. </p>
<p> Commands are separated either by newline or &quot;;&quot; character. To make a command span multiple lines in a rc file escape the newline (put \ at end of line). </p>
<p> Rc files can contain comments at beginning of line. Comment begins with # character and can be indented, but you can&#8217;t put comment on same line with a command. This decision was made to make it possible to include # in commands without escaping. </p>
<p> Commands can contain environment variables. Variable always expands into a single argument even if it contains whitespace. Variables inside single or double quotes are NOT expanded. This makes it possible to bind a key to command which contains variable (inside single or double quotes) and the variable is expanded just before the command is executed. </p>
<p> Example:</p>
<dl>
<dt>
<dd> alias x &quot;run chmod 755 $FILE&quot;</dl>
<p> $FILE is expanded when the alias x is executed. The command works even if $FILE contains whitespace.</p>
<h3>Special variables</h3>
<p> These are always defined and override environment variables of same name. </p>
<p> $PKGDATADIR</p>
<dl>
<dt>
<dd> Usually /usr/share/dex</dl>
<p> $FILE</p>
<dl>
<dt>
<dd> Current file. Empty string if there&#8217;s no filename.</dl>
<p> $WORD</p>
<dl>
<dt>
<dd> Selected text or word under cursor. Empty string if there&#8217;s no selection and cursor is not on a word.</dl>
<h3>Single quoted strings</h3>
<p> Can&#8217;t contain single quote, no escaping possible.</p>
<h3>Double quoted strings</h3>
<dl>
<dt></p>
<dd> Bell</p>
<dt></p>
<dd> Backspace</p>
<dt>	</p>
<dd> Horizontal tab</p>
<dt>
</p>
<dd> New line</p>
<dt></p>
<dd> Vertical tab</p>
<dt></p>
<dd> Form feed</p>
<dt></p>
<dd> Carriage return</p>
<dt>\</p>
<dd> Literal \</p>
<dt>
</p>
<dd> Hexadecimal byte value 0x0a. Note that 0x00 is not supported because strings are NUL-terminated.</p>
<dt>€</p>
<dd> Four hex digit unicode code point U+20AC.</p>
<dt>€</p>
<dd> Eight hex digit unicode code point U+20AC.</dl>
