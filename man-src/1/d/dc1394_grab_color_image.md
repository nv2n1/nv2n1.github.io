<h2>NAME</h2>
<p> grab_color_image &#8211; grab an image using libdc1394</p>
<h2>SYNOPSIS</h2>
<p> <code>grab_color_image [</code><i>&#8211;guid=/dev/video1394/x</i>] [filename.ppm]</p>
<h2>DESCRIPTION</h2>
<p> Get one image using libdc1394 and store it as a portable pix map (ppm) image.</p>
<h2>OPTIONS</h2>
<dl>
<dt>&#8211;guid</p>
<dd> specifies camera to use. default is the first camera found in the system. <code>&#8211;help</code> print help message</dl>
