<h2 class="name">NAME</h2>
<p> dh_installdeb &#8211; install files into the DEBIAN directory </p>
<h2>SYNOPSIS</h2>
<p> <code>dh_installdeb</code> [<i>debhelper options</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>dh_installdeb</code> is a debhelper program that is responsible for installing files into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directories in package build directories with the correct permissions.</p>
<h2>FILES</h2>
<dl>
<dt><i>package</i>.postinst</p>
<dd>
<dt><i>package</i>.preinst</p>
<dd>
<dt><i>package</i>.postrm</p>
<dd>
<dt><i>package</i>.prerm</p>
<dd> These maintainer scripts are installed into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directory. </p>
<p> Inside the scripts, the token <code>#DEBHELPER#</code> is replaced with shell script snippets generated by other debhelper commands.</p>
<dt><i>package</i>.triggers</p>
<dd>
<dt><i>package</i>.shlibs</p>
<dd> These control files are installed into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directory. </p>
<p> Note that <i>package</i>.shlibs is only installed in compat level 9 and earlier. In compat 10, please use <i><a href="/docs/linux/man/1-dh_makeshlibs/">dh_makeshlibs</a></i>(1).</p>
<dt><i>package</i>.conffiles</p>
<dd> This control file will be installed into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directory. </p>
<p> In v3 compatibility mode and higher, all files in the <i>etc/</i> directory in a package will automatically be flagged as conffiles by this program, so there is no need to list them manually here.</p>
<dt><i>package</i>.maintscript</p>
<dd> Lines in this file correspond to <i><a href="/docs/linux/man/1-dpkg-maintscript-helper/">dpkg-maintscript-helper</a></i>(1) commands and parameters. However, the &#8220;maint-script-parameters&#8221; should <i>not</i> be included as debhelper will add those automatically. </p>
<p> Example: </p>
<pre>
    # Correct
    rm_conffile /etc/obsolete.conf 0.2~ foo
    # INCORRECT
    rm_conffile /etc/obsolete.conf 0.2~ foo -- &quot;$@&quot;
</pre>
<p> In compat 10 or later, any shell metacharacters will be escaped, so arbitrary shell code cannot be inserted here. For example, a line such as <tt>&quot;mv_conffile /etc/oldconffile /etc/newconffile&quot;</tt> will insert maintainer script snippets into all maintainer scripts sufficient to move that conffile. </p>
<p> It was also the intention to escape shell metacharacters in previous compat levels. However, it did not work properly and as such it was possible to embed arbitrary shell code in earlier compat levels. </p>
<p> The <code>dh_installdeb</code> tool will do some basic validation of some of the commands listed in this file to catch common mistakes. The validation is enabled as a warning since compat 10 and as a hard error in compat 12.</dl>
