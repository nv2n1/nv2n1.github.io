<h2>SYNOPSIS</h2>
<dl>
<dt><code>dnsname</code> [OPTIONS] &lt;address&gt; [&lt;address&gt; &#8230;]</p>
<dd>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>dnsname</code> is a handy tool to resolve name of the DNS server. You can pass IP address of a DNS server and <code>dnsname</code> would resolve it for you. </p>

<dd>
&nbsp;<wbr>print this help</p>

<dd>
&nbsp;<wbr>print version information </p>
</dl>
