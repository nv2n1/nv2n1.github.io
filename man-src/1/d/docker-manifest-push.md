<h2 class="name">NAME</h2>
<p> docker-manifest-push &#8211; Push a manifest list to a repository </p>
<h2>SYNOPSIS</h2>
<p> <code>docker manifest push [OPTIONS] MANIFEST_LIST</code> </p>
<h2>DESCRIPTION</h2>
<p> Push a manifest list to a repository </p>
<h2>OPTIONS</h2>
<p> <code>-h</code>, <code>&#8211;help</code>[=false] <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>help for push</p>
<p> <code>&#8211;insecure</code>[=false] <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>Allow push to an insecure registry</p>
<p> <code>-p</code>, <code>&#8211;purge</code>[=false] <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;</tt>Remove the local manifest list after push</p>
