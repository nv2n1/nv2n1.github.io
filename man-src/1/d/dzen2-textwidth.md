<h2>NAME</h2>
<p> dzen2-textwidth &#8211; calculate the width in pixels of text for a given font.</p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>dzen2-textwidth</code> <i>fontname</i> <i>string</i></dl>
<h2>DESCRIPTION</h2>
<p> <code>textwidth</code></p>
<dd>is a simple utility to calculate the width in pixels of text with a given font. </p>
<p> This tool is provided as part of the <code>dzen2 (1)</code> package.</p>
<h2>OPTIONS</h2>
<p> A summary of options is included below.</p>
<dl>
<dt><code>fontname</code></p>
<dd> Set the font.</p>
<dt><code>string</code></p>
<dd> Set the string.</dl>
