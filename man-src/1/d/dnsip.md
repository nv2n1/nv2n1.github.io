<h2>SYNOPSIS</h2>
<dl>
<dt><code>dnsip</code> [<code>OPTIONS</code>] &lt;domain-name&gt; [&lt;domain-name&gt; &#8230;]</p>
<dd>
</dl>
<h2>DESCRIPTION</h2>
<p> <code>dnsip</code> serves the sole task of resolving a given domain-name to it&#8217;s IPv4 address. <code>dnsip</code> supports following options: </p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h &#8211;help</code></p>
<dd>
&nbsp;<wbr>print this help</p>
<dt><code>-n &#8211;new</code></p>
<dd>
&nbsp;<wbr>use new output style</p>
<dt><code>-v &#8211;version</code></p>
<dd>
&nbsp;<wbr>print version information </p>
</dl>
