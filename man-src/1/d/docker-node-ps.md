<h2 class="name">NAME</h2>
<p> docker-node-ps &#8211; List tasks running on one or more nodes, defaults to current node </p>
<h2>SYNOPSIS</h2>
<p> <code>docker node ps [OPTIONS] [NODE&#8230;]</code> </p>
<h2>DESCRIPTION</h2>
