<h2 class="name">NAME</h2>
<p> dh_installdebconf &#8211; install files used by debconf in package build directories </p>
<h2>SYNOPSIS</h2>
<p> <code>dh_installdebconf</code> [<i>debhelper options</i>] [<code>-n</code>] [<code>&#8212;</code> <i>params</i>]</p>
<h2>DESCRIPTION</h2>
<p> <code>dh_installdebconf</code> is a debhelper program that is responsible for installing files used by debconf into package build directories. </p>
<p> It also automatically generates the <i>postrm</i> commands needed to interface with debconf. The commands are added to the maintainer scripts by <code>dh_installdeb</code>. See <i><a href="/docs/linux/man/1-dh_installdeb/">dh_installdeb</a></i>(1) for an explanation of how that works. </p>
<p> Note that if you use debconf, your package probably needs to depend on it (it will be added to <code>${misc:Depends}</code> by this program). </p>
<p> Note that for your config script to be called by <code>dpkg</code>, your <i>postinst</i> needs to source debconf&#8217;s confmodule. <code>dh_installdebconf</code> does not install this statement into the <i>postinst</i> automatically as it is too hard to do it right.</p>
<h2>FILES</h2>
<dl>
<dt>debian/<i>package</i>.config</p>
<dd> This is the debconf <i>config</i> script, and is installed into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directory in the package build directory. </p>
<p> Inside the script, the token <code>#DEBHELPER#</code> is replaced with shell script snippets generated by other debhelper commands.</p>
<dt>debian/<i>package</i>.templates</p>
<dd> This is the debconf <i>templates</i> file, and is installed into the <i></i><font SIZE="-1"><i>DEBIAN</i></font><i></i> directory in the package build directory.</p>
<dt><i>debian/po/</i></p>
<dd> If this directory is present, this program will automatically use <i><a href="/docs/linux/man/1-po2debconf/">po2debconf</a></i>(1) to generate merged templates files that include the translations from there. </p>
<p> For this to work, your package should build-depend on <i>po-debconf</i>.</dl>
<h2>OPTIONS</h2>
<dl>
<dt><code>-n</code>, <code>&#8211;no-scripts</code></p>
<dd> Do not modify <i>postrm</i> script.</p>
<dt><code>&#8212;</code> <i>params</i></p>
<dd> Pass the params to <code>po2debconf</code>.</dl>
