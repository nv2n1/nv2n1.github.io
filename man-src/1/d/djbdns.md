<h2 class="name">NAME</h2>
<p> <code>djbdns</code> &#8211; djbdns DNS tools</p>
<h2>DESCRIPTION</h2>
<p> <code>djbdns</code> is a collection of DNS tools, originally written by Dr D J Bernstein. This release of djbdns includes the following ones </p>
<dl>
<dt>+ dnscache</p>
<dd>
<dt>+ dnsfilter</p>
<dd>
<dt>+ dnsip</p>
<dd>
<dt>+ dnsipq</p>
<dd>
<dt>+ dnsmx</p>
<dd>
<dt>+ dnsname</p>
<dd>
<dt>+ dnsq</p>
<dd>
<dt>+ dnsqr</p>
<dd>
<dt>+ dnstrace</p>
<dd>
<dt>+ dnstracesort</p>
<dd>
<dt>+ dnstxt</p>
<dd>
<dt>+ tinydns</p>
<dd>
<dt>+ tinydns-data</p>
<dd>
<dt>+ tinydns-edit</p>
<dd>
<dt>+ tinydns-get</p>
<dd>
</dl>
