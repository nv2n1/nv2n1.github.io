<h2>NAME</h2>
<p> euscale-describe-notification-configurations &#8211; Describe notification actions associated with auto-scaling groups</p>
<h2>SYNOPSIS</h2>
<p> euscale-describe-notification-configurations [&#8211;show-empty-fields]</p>
<dl>
<dt>[-U URL]</p>
<dd> [&#8211;region USER [at] REGION] [-I KEY_ID] [-S KEY] [&#8211;security-token TOKEN] [&#8211;debug] [&#8211;debugger] [&#8211;version] [-h] [ASGROUP [ASGROUP &#8230;]]</dl>
<h2>DESCRIPTION</h2>
<p> Describe notification actions associated with auto-scaling groups</p>
<h3>positional arguments:</h3>
<dl>
<dt>ASGROUP</p>
<dd> limit results to specific auto-scaling groups</dl>
<h3>optional arguments:</h3>
<dl>
<dt><code>&#8211;show-empty-fields</code></p>
<dd> show empty values as &quot;(nil)&quot;</p>
<dt><code>-U</code> URL, <code>&#8211;url</code> URL</p>
<dd> auto-scaling service endpoint URL</p>
<dt><code>&#8211;region</code> USER [at] REGION</p>
<dd> region and/or user names to search when looking up config file data</p>
<dt> <code>-I</code> KEY_ID, <code>&#8211;access-key-id</code> KEY_ID</p>
<dt> <code>-S</code> KEY, <code>&#8211;secret-key</code> KEY</p>
<dt> <code>&#8211;security-token</code> TOKEN</p>
<dt><code>&#8211;debug</code></p>
<dd>
<dd>show debugging output</p>
<dt><code>&#8211;debugger</code></p>
<dd> launch interactive debugger on error</p>
<dt><code>&#8211;version</code></p>
<dd> show the program&#8217;s version and exit</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit </p>
</dl>
