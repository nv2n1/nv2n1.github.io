<h2 class="name">NAME</h2>
<p> etex &#8211; extended (plain) TeX </p>
<h2>SYNOPSIS</h2>
<p> <code>etex</code> [<i>options</i>] [<i></i><code>&amp;</code>format] [<i>file</i>|<i></i><code>\</code>commands]</p>
<h2>DESCRIPTION</h2>
<p> Run the e-TeX typesetter on <i>file</i>, by default creating <i>file.dvi</i>. If the file argument has no extension, &quot;.tex&quot; will be appended to it. Instead of a filename, a set of e-TeX commands can be given, the first of which must start with a backslash. With a <code>&amp;</code><i>format</i> argument e-TeX uses a different set of precompiled commands, contained in <i>format</i><code>.fmt</code>; it is usually better to use the <code>-fmt</code> <i>format</i> option instead. </p>
<p> e-TeX is the first concrete result of an international research &amp; development project, the NTS Project, which was established under the aegis of DANTE e.V. during 1992. The aims of the project are to perpetuate and develop the spirit and philosophy of TeX, whilst respecting Knuth&#8217;s wish that TeX should remain frozen. </p>
<p> e-TeX can be used in two different modes: in <i>compatibility mode</i> it is supposed to be completely interchangable with standard TeX. In <i>extended mode</i> several new primitives are added that facilitate (among other things) bidirectional typesetting. </p>
<p> An extended mode format is generated by prefixing the name of the source file for the format with an asterisk (*). </p>
<p> e-TeX&#8217;s handling of its command-line arguments is similar to that of the other TeX programs in the <i>web2c</i> implementation.</p>
<h2>OPTIONS</h2>
<p> This version of e-TeX understands the following command line options.</p>
<dl>
<dt><code>-fmt</code><i>&nbsp;format</i></p>
<dd> Use <i>format</i> as the name of the format to be used, instead of the name by which e-TeX was called or a <i>%&amp;</i> line.</p>
<dt><code>-enc</code></p>
<dd> Enable the encTeX extensions. This option is only effective in combination with <code>-ini</code>. For documentation of the encTeX extensions see <code><a rel="nofollow" href="http://www.olsak.net/enctex.html">http://www.olsak.net/enctex.html</a></code>.</p>
<dt><code>-etex</code></p>
<dd> Enable the e-TeX extensions. This option is only effective in combination with <code>-ini</code>.</p>
<dt><code>-file-line-error</code></p>
<dd> Print error messages in the form <i>file:line:error</i> which is similar to the way many compilers format them.</p>
<dt><code>-no-file-line-error</code></p>
<dd> Disable printing error messages in the <i>file:line:error</i> style.</p>
<dt><code>-file-line-error-style</code></p>
<dd> This is the old name of the <code>-file-line-error</code> option.</p>
<dt><code>-halt-on-error</code></p>
<dd> Exit with an error code when an error is encountered during processing.</p>
<dt><code>-help</code></p>
<dd> Print help message and exit.</p>
<dt><code>-ini</code></p>
<dd> Start in <i>INI</i> mode, which is used to dump formats. The <i>INI</i> mode can be used for typesetting, but no format is preloaded, and basic initializations like setting catcodes may be required.</p>
