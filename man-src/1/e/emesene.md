<h2>NAME</h2>
<p> Emesene &#8211; MSN Messenger Client. </p>
<h2>SYNOPSIS</h2>
<p> <code>emesene</code> [<i>OPTIONS</i>] </p>
<h2>DESCRIPTION</h2>
<p> <code>Emesene</code> is a multiplattform MSN messenger client written in Python and PyGTK.</p>
<h2>OPTIONS</h2>
<p> Emesene options:</p>
<dl>
<dt><code>-m, &#8211;minimized</code></p>
<dd> Start emesene minimized.</p>
<dt><code>-i, &#8211;iconified</code></p>
<dd> Start emesene iconified.</p>
<dt><code>&#8211;user=</code><i>mail [at] address</i></p>
<dd> Login as mail [at] address</p>
<dt><code>&#8211;safe</code></p>
<dd> Don&#8217;t use cache for the userlist.</p>
<dt><code>&#8211;leakdebug</code></p>
<dd> Print leak debug messages. </p>
</dl>
