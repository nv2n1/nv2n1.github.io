<h2>NAME</h2>
<p> empathy-accounts &#8211; Accounts configuration dialog for Empathy instant messaging client</p>
<h2>SYNOPSIS</h2>
<p> empathy-accounts [<i>options</i>]</p>
<h2>DESCRIPTION</h2>
<p> Accounts configuration dialog for Empathy instant messaging client </p>
<p> This utility allows you to configure your instant messaging accounts for Empathy.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-h</code>,&nbsp;<wbr><code>&#8211;hidden</code></p>
<dd> Don&#8217;t display any dialogs; do any work (eg, importing) and exit</p>
<dt><code>-n</code>,&nbsp;<wbr><code>&#8211;if-needed</code></p>
<dd> Don&#8217;t display any dialogs if there are any non-salut accounts</p>
<dt><code>-s&nbsp;<wbr></code><i>account-id</i></p>
<dd> <code>&#8211;select-account=</code><i>account-id</i> Initially select given account (eg, gabble/jabber/foo_40example_2eorg0)</dl>
