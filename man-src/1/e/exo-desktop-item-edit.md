<h2 class="name">NAME</h2>
<p> exo-desktop-item-edit &#8211; Edit freedesktop.org .desktop files </p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> exo-desktop-item-edit [OPTION?] [FILE|FOLDER]</dl>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show help options</p>
<dt><code>&#8211;help-all</code></p>
<dd> Show all help options</p>
<dt><code>&#8211;help-gtk</code></p>
<dd> Show GTK+ Options</dl>
<h3>Application Options:</h3>
<dl>
<dt><code>-c</code>, <code>&#8211;create-new</code></p>
<dd> Create a new desktop file in the given directory</p>
<dt><code>-t</code>, <code>&#8211;type</code></p>
<dd> Type of desktop file to create (Application or Link)</p>
<dt><code>&#8211;name</code></p>
<dd> Preset name when creating a desktop file</p>
<dt><code>&#8211;comment</code></p>
<dd> Preset comment when creating a desktop file</p>
<dt><code>&#8211;command</code></p>
<dd> Preset command when creating a launcher</p>
<dt><code>&#8211;url</code></p>
<dd> Preset URL when creating a link</p>
<dt><code>&#8211;icon</code></p>
<dd> Preset icon when creating a desktop file</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print version information and exit</p>
<dt><code>&#8211;display</code>=<i>,DISPLAY/</i></p>
<dd> X display to use</dl>
