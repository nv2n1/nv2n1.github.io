<h2>NAME</h2>
<p> epiphany &#8211; simple to use web browser for GNOME</p>
<h2>SYNOPSIS</h2>
<p> <code>epiphany</code> [<i>OPTION</i>&#8230;] [url]</p>
<h2>DESCRIPTION</h2>
<p> Help options</p>
<dl>
<dt>-?, <code>&#8211;help</code></p>
<dd> Show help options</dl>
<p> Application options</p>
<dl>
<dt><code>-n</code>, <code>&#8211;new-tab</code></p>
<dd> Open a new tab in an existing browser window</p>
<dt><code>&#8211;new-window</code></p>
<dd> Open a new browser window</p>
<dt><code>-b</code>, <code>&#8211;bookmarks-editor</code></p>
<dd> Launch the bookmarks editor</p>
<dt><code>&#8211;import-bookmarks</code>=<i>FILE</i></p>
<dd> Import bookmarks from the given file</p>
<dt><code>-l</code>, <code>&#8211;load-session</code>=<i>FILE</i></p>
<dd> Load the given session file</p>
<dt><code>-t</code>, <code>&#8211;add-bookmark</code>=<i>URL</i></p>
<dd> Add a bookmark</p>
<dt><code>&#8211;private-instance</code></p>
<dd> Start a private instance</p>
<dt><code>&#8211;profile</code>=<i>FILE</i></p>
<dd> Profile directory to use in the private instance</p>
<dt><code>&#8211;display</code>=<i>DISPLAY</i></p>
<dd> X display to use</p>
<dt><code>&#8211;version</code></p>
<dd> Show version</dl>
<p> Epiphany has a comprehensive help system. Run the browser and select <code>Help</code> from the menu.</p>
