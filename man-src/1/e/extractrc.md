<h2 class="name">NAME</h2>
<p> extractrc &#8211; Extract message strings from UI and GUI-RC files </p>
<h2>SYNOPSIS</h2>
<dl>
<dt> <code>extractrc</code> [<i>filename</i>]</dl>
<h2>DESCRIPTION</h2>
<p> <code>extractrc</code></p>
<dd>finds all text tags and other message strings in the given files and writes the corresponding i18n() calls to standard output so that xgettext can parse them. </p>
<p> It understands both (Qt(TM)/KDE) designer&#8217;s UI files and XML GUI-RC files. </p>
<p> This utility is part of the KDE Software Development Kit.</p>
