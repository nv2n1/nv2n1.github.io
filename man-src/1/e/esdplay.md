<h2 class="name">NAME</h2>
 

 esddsp - attempt to reroute audio device to esd 

<h2>DESCRIPTION</h2>

 Plays the <font SIZE="-1">FILE</font> on EsounD.

<h2>USAGE</h2>

 esdplay [<font SIZE="-1">OPTIONS</font>] <font SIZE="-1">FILE</font> 

 Options: 

 <tt>&quot;-s&quot;</tt>, --server=HOSTNAME set EsounD server 

 <tt>&quot;-h&quot;</tt>, --help display this help and exit 

 <tt>&quot;-v&quot;</tt>, --version output version information and exit
