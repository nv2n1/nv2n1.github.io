<h2>NAME</h2>
<p> ef &#8211; Utility to run a program under the Electric Fence memory debugger </p>
<h2>SYNOPSIS</h2>
<p> <code>ef</code> PROGRAM [ARGS&#8230;] </p>
<h2>DESCRIPTION</h2>
<p> The <i>ef</i> command is used to launch another program under the Electric Fence memory debugger. It sets up appropriate environment variables and then launches the specified program with the specified arguments. See efence (3) manual page for more details about Electric Fence. </p>
