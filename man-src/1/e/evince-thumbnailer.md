<h2 class="name">NAME</h2>
<p> evince-thumbnailer &#8211; create png thumbnails from PostScript and PDF documents </p>
<h2>SYNOPSIS</h2>
<p> <code>evince-thumbnailer</code> [-s <code>size</code>] <code>input</code> <code>output</code></p>
<h2>DESCRIPTION</h2>
<p> evince-thumbnailer is a GNOME program to create thumbnails from PostScript (PS), Portable Document Format (PDF), DjVu and DVI files.</p>
<h2>OPTIONS</h2>
<p> evince obeys all normal GNOME and GTK+ command line options. The only option -s <i>size </i>makes it possible to choose the vertical size of the created thumbnail.</p>
