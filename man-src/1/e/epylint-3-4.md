<p><code>epylint</code> &#8211; Emacs and Flymake compatible Pylint </p>
<h2>Description</h2>
<p><code>epylint</code> is a Emacs and Flymake compatible Pylint. It runs Pylint from outside the current package to avoid import error messages. See <code>pylint</code> &#8216;s manpage for information about all available options. </p>
