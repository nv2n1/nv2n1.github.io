<h2 class="name">NAME</h2>
<p> exo-preferred-applications &#8211; Select preferred applications for Xfce desktop environment </p>
<h2>DESCRIPTION</h2>
<h3>Usage:</h3>
<dl>
<dt>
<dd> exo-helper-1 [OPTION?]</dl>
<h3>Help Options:</h3>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> Show help options</p>
<dt><code>&#8211;help-all</code></p>
<dd> Show all help options</p>
<dt><code>&#8211;help-gtk</code></p>
<dd> Show GTK+ Options</dl>
<h3>Application Options:</h3>
<dl>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd> Print version information and exit</p>
<dt><code>-c</code>, <code>&#8211;configure</code></p>
<dd> Open the Preferred Applications</dl>
<p> configuration dialog</p>
<dl>
<dt><code>-s</code>, <code>&#8211;socket-id</code>=<i>,SOCKET/</i> ID</p>
<dd> Settings manager socket</p>
<dt><code>-l</code>, <code>&#8211;launch</code>=<i>,TYPE/</i> [PARAMETER]</p>
<dd> Launch the default helper of TYPE with the optional PARAMETER, where TYPE is one of the following values.</p>
<dt><code>-q</code>, <code>&#8211;query</code>=<i>,TYPE/</i> [PARAMETER]</p>
<dd> Query the default helper of TYPE, where TYPE is one of the following values.</p>
<dt><code>&#8211;display</code>=<i>,DISPLAY/</i></p>
<dd> X display to use</dl>
<p> The following TYPEs are supported for the <code>&#8211;launch</code> and <code>&#8211;query</code> commands:</p>
<dl>
<dt>WebBrowser</p>
<dd> &#8211; The preferred Web Browser.</p>
<dt>MailReader</p>
<dd> &#8211; The preferred Mail Reader.</p>
<dt>FileManager</p>
<dd> &#8211; The preferred File Manager.</p>
<dt>
<dd> TerminalEmulator &#8211; The preferred Terminal Emulator. </p>
</dl>
