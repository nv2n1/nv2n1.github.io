<h2>NAME</h2>
<p> euimage-pack-image &#8211; ***TECH PREVIEW***</p>
<h2>SYNOPSIS</h2>
<p> euimage-pack-image [&#8211;progress | <code>&#8211;no-progress]</code> [&#8211;debug] [&#8211;debugger]</p>
<dl>
<dt>[&#8211;version] [-h]</p>
<dd> IMAGE_FILE MD_FILE</dl>
<h2>DESCRIPTION</h2>
<p> ***TECH PREVIEW***</p>
<h2>DESCRIPTION</h2>
<p> Pack an image for simple installation in a cloud</p>
<h3>positional arguments:</h3>
<dl>
<dt>IMAGE_FILE</p>
<dd> the image to pack (required)</p>
<dt>MD_FILE</p>
<dd> metadata for the image to pack (required)</dl>
<h3>optional arguments:</h3>
<dl>
<dt><code>&#8211;progress</code></p>
<dd> show progress (the default when run interactively)</p>
<dt><code>&#8211;no-progress</code></p>
<dd> do not show progress (the default when run non-interactively)</p>
<dt><code>&#8211;debug</code></p>
<dd> show debugging output</p>
<dt><code>&#8211;debugger</code></p>
<dd> launch interactive debugger on error</p>
<dt><code>&#8211;version</code></p>
<dd> show the program&#8217;s version and exit</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit </p>
</dl>
