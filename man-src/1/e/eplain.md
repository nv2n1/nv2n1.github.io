<h2 class="name">NAME</h2>
<p> eplain &#8211; expanded plain TeX </p>
<h2>SYNOPSIS</h2>
<p> <code>eplain</code> [ first-line ]</p>
<h2>DESCRIPTION</h2>
<p> <code>eplain</code> is an extension of plain TeX originally described in the book <i>TeX for nroff for the Impatient</i>. It adds these features (among others) to plain TeX:</p>
<dl>
<dt>&bull;</p>
<dd> left-justified displays</p>
<dt>&bull;</p>
<dd> double-column output</p>
<dt>&bull;</p>
<dd> tables of contents</p>
<dt>&bull;</p>
<dd> <i>\hrule</i> and <i>rule</i> with a different default than 0.4pt</p>
<dt>&bull;</p>
<dd> time of day</p>
<dt>&bull;</p>
<dd> verbatim file listing</p>
<dt>&bull;</p>
<dd> generalized footnotes</p>
<dt>&bull;</p>
<dd> blank and black boxes</p>
<dt>&bull;</p>
<dd> citations using BibTeX</dl>
<h2>FILES</h2>
<dl>
<dt><i>eplain/doc/eplain.texi</i></p>
<dd> TeXable documentation of <code>etex</code> macros in <code>texinfo</code> format.</p>
<dt><i>eplain.info*</i></p>
<dd> Online GNU Emacs <code><a href="/docs/linux/man/1-info/">info</a></code>(1) files produced from <i>eplain.texi</i>.</dl>
