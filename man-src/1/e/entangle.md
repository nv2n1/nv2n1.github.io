<h2 class="name">NAME</h2>
 

 entangle - tethered camera control &amp; capture 

<h2>SYNOPSIS</h2>

 entangle [<font SIZE="-1">OPTION...</font>]

<h2>DESCRIPTION</h2>

 Entangle provides a graphical interface for ``tethered shooting'', aka taking photographs with a digital camera completely controlled from the computer. 

 Valid command options:
<dl>
<dt>--debug-entangle
<dd> Enable debugging of the Entangle application code
<dt>--debug-gphoto
<dd> Enable debugging of the gphoto library code
<dt>--help
<dd> Show command line option summary
<dt>--help-all
<dd> Show all command line options
<dt>--help-gtk
<dd> Show <font SIZE="-1">GTK+</font> command line options
<dt>--help-entangle
<dd> Show Entangle command line options</dl>
