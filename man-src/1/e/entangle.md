entangle - tethered camera control &amp; capture 

<h2>SYNOPSIS</h2>

 entangle [OPTION...]

<h2>DESCRIPTION</h2>

 Entangle provides a graphical interface for ``tethered shooting'', aka taking photographs with a digital camera completely controlled from the computer. 

 Valid command options:
<dl>
<dt>--debug-entangle
</dt><dd> Enable debugging of the Entangle application code
</dd><dt>--debug-gphoto
</dt><dd> Enable debugging of the gphoto library code
</dd><dt>--help
</dt><dd> Show command line option summary
</dd><dt>--help-all
</dt><dd> Show all command line options
</dd><dt>--help-gtk
</dt><dd> Show GTK+ command line options
</dd><dt>--help-entangle
</dt><dd> Show Entangle command line options</dd></dl>
