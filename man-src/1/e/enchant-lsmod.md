<h2 class="name">NAME</h2>
<p> enchant-lsmod &#8211; Show information about available spell-checking modules and dictionaries. </p>
<h2>SYNOPSIS</h2>
<p> enchant-lsmod [-lang [language_tag]] [-list-dicts] [-h] [-v]</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-lang [language_tag]</code></p>
<dd> Show dictionary to be used for given language_tag. If language_tag is not given show default dictionary for current language setting.</p>
<dt><code>-list-dicts</code></p>
<dd> List preferred dictionaries for language tags.</p>
<dt><code>-h</code></p>
<dd> Show help info and exit.</p>
<dt><code>-v</code></p>
<dd> Show version and exit.</dl>
