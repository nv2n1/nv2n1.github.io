<h2 class="name">NAME</h2>
<p> e2rm &#8211; removes files and directories on an ext2 filesystem </p>
<h2>SYNOPSIS</h2>
<p> <code>e2rm</code> [<i>options</i>]<i> files&#8230;</i></p>
<h2>DESCRIPTION</h2>
<p> The <code>e2rm</code> command removes files and directories on an ext2 filesystem.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-r</code></p>
<dd> Recursively delete files if a directory name is given.</p>
<dt><code>-v</code></p>
<dd> Be verbose.</dl>
