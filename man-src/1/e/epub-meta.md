<h2 class="name">NAME</h2>
<p> <code> epub-meta </code>&#8211; read and write metadata from an EPUB ebook file </p>
<h2>USAGE</h2>
<p> epub-meta [options] myfile.epub</p>
<h2>DESCRIPTION</h2>
<p> Read and write metadata from an ebook file. </p>
<p> Whenever you pass arguments to epub-meta that have spaces in them, enclose the arguments in quotation marks.</p>
<h2>MAIN OPTIONS</h2>
<dl>
<dt><code>&#8211;version</code></p>
<dd> show program&#8217;s version number and exit</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd> show this help message and exit</p>
<dt><code>-t</code> TITLE, <code>&#8211;title</code>=TITLE</p>
<dd> Set the book title</p>
<dt><code>-a</code> AUTHORS, <code>&#8211;authors</code>=AUTHORS</p>
<dd> Set the authors</p>
<dt><code>&#8211;comment</code>=COMMENT</p>
<dd> Set the comment</p>
<dt><code>&#8211;tags</code>=TAGS</p>
<dd> A comma separated list of tags to set</p>
<dt><code>&#8211;series</code>=SERIES</p>
<dd> The series to which this book belongs</p>
<dt><code>&#8211;series-index</code>=SERIES_INDEX</p>
<dd> The series index</p>
<dt><code>&#8211;language</code>=LANGUAGE</p>
<dd> The book language</p>
<dt><code>&#8211;get-cover</code></p>
<dd> Extract the cover</dl>
