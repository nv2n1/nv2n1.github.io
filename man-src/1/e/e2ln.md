<h2 class="name">NAME</h2>
<p> e2ln &#8211; create hard links on an ext2 filesystem </p>
<h2>SYNOPSIS</h2>
<p> <code>e2ln</code> [<i>options</i>]<i> source destination</i></p>
<h2>DESCRIPTION</h2>
<p> The <code>e2ln</code> command is used to create hard links on an ext2 filesystem.</p>
<h2>OPTIONS</h2>
<dl>
<dt><code>-f</code></p>
<dd> Force the operation to remove any existing files.</p>
<dt><code>-s</code></p>
<dd> Create a symlink.</p>
<dt><code>-v</code></p>
<dd> Be verbose.</dl>
<p> Note: creating symlinks is not operational at this time.</p>
