<p><code>runc start</code> &#8211; start a previously created container </p>
<h2>Synopsis</h2>
<p><code>runc start</code> <i>container-id</i> </p>
<h2>Description</h2>
<p>The <code>start</code> command executes the process defined in <i>config.json</i> in a container previously created by <code><a href="/docs/linux/man/8-runc-create/">runc-create</a></code>(8). </p>
