<p><code>runc-state</code> &#8211; show the state of a container </p>
<h2>Synopsis</h2>
<p><code>runc state</code> <i>container-id</i> </p>
<h2>Description</h2>
<p>The <code>state</code> command outputs current state information for the specified <i>container-id</i> in a JSON format. </p>
