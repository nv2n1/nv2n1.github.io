<p>rmail &#8211; handle remote mail received via uucp</p>
<h2>Synopsis</h2>
<p><code>rmail</code> [<code>-D</code> <i>domain</i>] [<code>-T</code>] <i>user &#8230;</i></p>
<h2>Description</h2>
<p><code>Rmail</code> interprets incoming mail received via <a href="/docs/linux/man/1-uucp/">uucp</a>(1), collapsing &#8220;From&#8221; lines in the form generated by <a href="/docs/linux/man/8-mail-local/">mail.local</a>(8) into a single line of the form &#8220;return-path!sender&#8221;, and passing the processed mail on to <a href="/docs/linux/man/8-sendmail/">sendmail</a>(8). </p>
<p> <code>Rmail</code> is explicitly designed for use with uucp and sendmail.</p>
<h3>Flags</h3>
<dl>
<dt><code>-D</code></p>
<dd>Use the specified <i>domain</i> instead of the default domain of &#8220;UUCP&#8221;.</p>
<dt><code>-T</code></p>
<dd>Turn on debugging.</dl>
<h2>See Also</h2>
<p><a href="/docs/linux/man/1-uucp/">uucp</a>(1), <a href="/docs/linux/man/8-mail-local/">mail.local</a>(8), <a href="/docs/linux/man/8-sendmail/">sendmail</a>(8)</p>
<h2>History</h2>
<p>The <code>rmail</code> program appeared in 4.2BSD.</p>
<h2>Bugs</h2>
<p><code>Rmail</code> should not reside in /bin. </p>
