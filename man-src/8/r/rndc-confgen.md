<p>rndc-confgen &#8211; rndc key generation tool</p>
<h2>Synopsis</h2>
<dl>
<dt> <code>rndc-confgen</code> [<code>-a</code>] [<code>-b&nbsp;<wbr></code><i>keysize</i>] [<code>-c&nbsp;<wbr></code><i>keyfile</i>] [<code>-h</code>] [<code>-k&nbsp;<wbr></code><i>keyname</i>] [<code>-p&nbsp;<wbr></code><i>port</i>] [<code>-r&nbsp;<wbr></code><i>randomfile</i>] [<code>-s&nbsp;<wbr></code><i>address</i>] [<code>-t&nbsp;<wbr></code><i>chrootdir</i>] [<code>-u&nbsp;<wbr></code><i>user</i>]</dl>
<h2>Description</h2>
<p><code>rndc-confgen</code></p>
<dd>generates configuration files for <code>rndc</code>. It can be used as a convenient alternative to writing the <i>rndc.conf</i> file and the corresponding <code>controls</code> and <code>key</code> statements in <i>named.conf</i> by hand. Alternatively, it can be run with the <code>-a</code> option to set up a <i>rndc.key</i> file and avoid the need for a <i>rndc.conf</i> file and a <code>controls</code> statement altogether.</p>
<h2>Options</h2>
<p>-a</p>
<dl>
<dd>Do automatic <code>rndc</code> configuration. This creates a file <i>rndc.key</i> in <i>/etc</i> (or whatever <i>sysconfdir</i> was specified as when BIND was built) that is read by both <code>rndc</code> and <code>named</code> on startup. The <i>rndc.key</i> file defines a default command channel and authentication key allowing <code>rndc</code> to communicate with <code>named</code> on the local host with no further configuration. </p>
<p> Running <code>rndc-confgen -a</code> allows BIND 9 and <code>rndc</code> to be used as drop-in replacements for BIND 8 and <code>ndc</code>, with no changes to the existing BIND 8 <i>named.conf</i> file. </p>
<p> If a more elaborate configuration than that generated by <code>rndc-confgen -a</code> is required, for example if rndc is to be used remotely, you should run <code>rndc-confgen</code> without the <code>-a</code> option and set up a <i>rndc.conf</i> and <i>named.conf</i> as directed.</dl>
<p> -b <i>keysize</i></p>
<dl>
<dd>Specifies the size of the authentication key in bits. Must be between 1 and 512 bits; the default is 128.</dl>
<p> -c <i>keyfile</i></p>
<dl>
<dd>Used with the <code>-a</code> option to specify an alternate location for <i>rndc.key</i>.</dl>
<p> -h</p>
<dl>
<dd>Prints a short summary of the options and arguments to <code>rndc-confgen</code>.</dl>
<p> -k <i>keyname</i></p>
<dl>
<dd>Specifies the key name of the rndc authentication key. This must be a valid domain name. The default is <code>rndc-key</code>.</dl>
<p> -p <i>port</i></p>
<dl>
<dd>Specifies the command channel port where <code>named</code> listens for connections from <code>rndc</code>. The default is 953.</dl>
<p> -r <i>randomfile</i></p>
<dl>
<dd>Specifies a source of random data for generating the authorization. If the operating system does not provide a <i>/dev/random</i> or equivalent device, the default source of randomness is keyboard input. <i>randomdev</i> specifies the name of a character device or file containing random data to be used instead of the default. The special value <i>keyboard</i> indicates that keyboard input should be used.</dl>
<p> -s <i>address</i></p>
<dl>
<dd>Specifies the IP address where <code>named</code> listens for command channel connections from <code>rndc</code>. The default is the loopback address 127.0.0.1.</dl>
<p> -t <i>chrootdir</i></p>
<dl>
<dd>Used with the <code>-a</code> option to specify a directory where <code>named</code> will run chrooted. An additional copy of the <i>rndc.key</i> will be written relative to this directory so that it will be found by the chrooted <code>named</code>.</dl>
<p> -u <i>user</i></p>
<dl>
<dd>Used with the <code>-a</code> option to set the owner of the <i>rndc.key</i> file generated. If <code>-t</code> is also specified only the file in the chroot area has its owner changed.</dl>
<h2>Examples</h2>
<p>To allow <code>rndc</code> to be used with no manual configuration, run </p>
<p> <code>rndc-confgen -a</code> </p>
<p> To print a sample <i>rndc.conf</i> file and corresponding <code>controls</code> and <code>key</code> statements to be manually inserted into <i>named.conf</i>, run </p>
<p> <code>rndc-confgen</code></p>
