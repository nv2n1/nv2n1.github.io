<h2>Synopsis</h2>
<p>Use the Puppet RAL to directly interact with the system.</p>
<h2>Usage</h2>
<dl>
<dt><code>ralsh [-h|&#8211;help] [-d|&#8211;debug] [-v|&#8211;verbose] [-e|&#8211;edit] [-H|&#8211;host &lt;host&gt;]</code></p>
<dd>[-p|&#8211;param &lt;param&gt;] [-t|&#8211;types] type &lt;name&gt;</dl>
<h2>Description</h2>
<p>This command provides simple facilities for converting current system state into Puppet code, along with some ability to use Puppet to affect the current state. </p>
<p> By default, you must at least provide a type to list, which case ralsh will tell you everything it knows about all instances of that type. You can optionally specify an instance name, and ralsh will only describe that single instance. </p>
<p> You can also add +&#8211;edit+ as an argument, and ralsh will write its output to a file, open that file in an editor, and then apply the file as a Puppet transaction. You can easily use this to use Puppet to make simple changes to a system.</p>
<h2>Options</h2>
<p>Note that any configuration parameter thataqs valid in the configuration file is also a valid long argument. For example, aqssldiraq is a valid configuration parameter, so you can specify aq&#8211;ssldir &lt;directory&gt;aq as an argument. </p>
<p> See the configuration file documentation at <i><a rel="nofollow" href="http://puppetlabs.com/trac/puppet/wiki/ConfigurationReference">http://puppetlabs.com/trac/puppet/wiki/ConfigurationReference</a></i> for the full list of acceptable parameters. A commented list of all configuration options can also be generated by running puppet with aq&#8211;genconfigaq. </p>
<p> debug: Enable full debugging. </p>
<p> edit: </p>
<p> Write the results of the query to a file, open the file in an editor, and read the file back in as an executable Puppet manifest. </p>
<p> host: </p>
<p> When specified, connect to the resource server on the named host and retrieve the list of resouces of the type specified. </p>
<p> help: </p>
<p> Print this help message. </p>
<p> param: </p>
<p> Add more parameters to be outputted from queries. </p>
<p> types: </p>
<p> List all available types. </p>
<p> verbose: Print extra information.</p>
<h2>Example</h2>
<p>This example uses <code>ralsh</code> to return Puppet configuration for the user <code>luke</code>: </p>
<pre><code>$ ralsh user luke
user { aqlukeaq:
    home =&gt; aq/home/lukeaq,
    uid =&gt; aq100aq,
    ensure =&gt; aqpresentaq,
    comment =&gt; aqLuke Kanies,,,aq,
    gid =&gt; aq1000aq,
    shell =&gt; aq/bin/bashaq,
    groups =&gt; [aqsysadminaq,aqaudioaq,aqvideoaq,aqpuppetaq]
}</code></pre>
