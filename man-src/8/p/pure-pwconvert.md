<p>pure-pwconvert &#8211; Generate a virtual users file from system accounts</p>
<h2>Syntax</h2>
<p>pure-pwconvert</p>
<h2>Description</h2>
<p>This program scans system accounts (<code>/etc/passwd</code>) and outputs a FTP virtual users list, suitable to the <code>pure-pw</code> command.</p>
<h2>Files</h2>
<p><i>/etc/passwd</i><br />
 <i>/etc/shadow</i><br />
 <i>/etc/master.passwd</i></p>
