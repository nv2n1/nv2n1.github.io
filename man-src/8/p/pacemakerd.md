<p>Pacemaker &#8211; Part of the Pacemaker cluster resource manager</p>
<h2>Synopsis</h2>
<p><code>pacemakerd</code> <i>mode </i>[<i>options</i>]</p>
<h2>Description</h2>
<p>pacemakerd &#8211; Start/Stop Pacemaker</p>
<h2>Options</h2>
<dl>
<dt>-?, <code>&#8211;help</code></p>
<dd>This text</p>
<dt>-$, <code>&#8211;version</code></p>
<dd>Version information</p>
<dt><code>-V</code>, <code>&#8211;verbose</code></p>
<dd>Increase debug output</p>
<dt><code>-S</code>, <code>&#8211;shutdown</code></p>
<dd>Instruct Pacemaker to shutdown on this machine</p>
<dt><code>-F</code>, <code>&#8211;features</code></p>
<dd>Display the full version and list of features Pacemaker was built with</dl>
<h3>Additional Options:</h3>
<dl>
<dt><code>-f</code>, <code>&#8211;foreground</code></p>
<dd>(Ignored) Pacemaker always runs in the foreground</p>
<dt><code>-p</code>, <code>&#8211;pid-file</code>=<i>value</i></p>
<dd>(Ignored) Daemon pid file location</dl>
