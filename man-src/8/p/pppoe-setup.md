<p>pppoe-setup &#8211; Shell script to configure Roaring Penguin PPPoE client</p>
<h2>Synopsis</h2>
<p><code>pppoe-setup</code> </p>
<h2>Description</h2>
<p><code>pppoe-setup</code> is a shell script which prompts you for various pieces of information and sets up an /etc/sysconfig/network-scripts/ifcfg-ppp0 configuration script for the <code>pppoe-start</code>, <code>pppoe-stop</code> and +<code>pppoe-connect</code> scripts. </p>
<h2>Author</h2>
<p><code>pppoe-setup</code> was written by David F. Skoll &lt;dfs [at] roaringpenguin.com&gt;. </p>
