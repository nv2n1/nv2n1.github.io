<p><code>puppet-filebucket</code> &#8211; Store and retrieve files in a filebucket</p>
<h2>Synopsis</h2>
<p>A stand-alone Puppet filebucket client.</p>
<h2>Usage</h2>
<p>puppet filebucket <i>mode</i> [-h|&#8211;help] [-V|&#8211;version] [-d|&#8211;debug] [-v|&#8211;verbose] [-l|&#8211;local] [-r|&#8211;remote] [-s|&#8211;server <i>server</i>] [-b|&#8211;bucket <i>directory</i>] <i>file</i> <i>file</i> &#8230; </p>
<p> Puppet filebucket can operate in three modes, with only one mode per call: </p>
<p> backup: Send one or more files to the specified file bucket. Each sent file is printed with its resulting md5 sum. </p>
<p> get: Return the text associated with an md5 sum. The text is printed to stdout, and only one file can be retrieved at a time. </p>
<p> restore: Given a file path and an md5 sum, store the content associated with the sum into the specified file path. You can specify an entirely new path to this argument; you are not restricted to restoring the content to its original location.</p>
<h2>Description</h2>
<p>This is a stand-alone filebucket client for sending files to a local or central filebucket. </p>
<p> Note that &#8216;filebucket&#8217; defaults to using a network-based filebucket available on the server named &#8216;puppet&#8217;. To use this, you&#8217;ll have to be running as a user with valid Puppet certificates. Alternatively, you can use your local file bucket by specifying &#8216;&#8211;local&#8217;.</p>
<h2>Options</h2>
<p>Note that any configuration parameter that&#8217;s valid in the configuration file is also a valid long argument. For example, &#8216;ssldir&#8217; is a valid configuration parameter, so you can specify &#8216;&#8211;ssldir <i>directory</i>&#8216; as an argument. </p>
<p> See the configuration file documentation at <a rel="nofollow" href="http://docs.puppetlabs.com/references/stable/configuration.html">http://docs.puppetlabs.com/references/stable/configuration.html</a> for the full list of acceptable parameters. A commented list of all configuration options can also be generated by running puppet with &#8216;&#8211;genconfig&#8217;.</p>
<dl>
<dt>&#8211;debug</p>
<dd>Enable full debugging.</p>
<dt>&#8211;help</p>
<dd>Print this help message</p>
<dt>&#8211;local</p>
<dd>Use the local filebucket. This will use the default configuration information.</p>
<dt>&#8211;remote</p>
<dd>Use a remote filebucket. This will use the default configuration information.</p>
<dt>&#8211;server</p>
<dd>The server to send the file to, instead of locally.</p>
<dt>&#8211;verbose</p>
<dd>Print extra information.</p>
<dt>&#8211;version</p>
<dd>Print version information.</dl>
<h2>Example</h2>
<pre>$ puppet filebucket backup /etc/passwd
/etc/passwd: 429b225650b912a2ee067b0a4cf1e949
$ puppet filebucket restore /tmp/passwd 429b225650b912a2ee067b0a4cf1e949</pre>
