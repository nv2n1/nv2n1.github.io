<p>pulseaudio_selinux &#8211; Security Enhanced Linux Policy for the pulseaudio processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the pulseaudio processes via flexible mandatory access control. The pulseaudio processes execute with the pulseaudio_t SELinux type. You can check if you have these processes running by executing the <code>ps</code> command with the <code>-Z</code> qualifier. For example: <code>ps -eZ | grep pulseaudio_t</code> </p>
<h2>Entrypoints</h2>
<p>The pulseaudio_t SELinux type can be entered via the <code>pulseaudio_exec_t</code> file type. </p>
<p> The default entrypoint paths for the pulseaudio_t domain are the following: </p>
<p> /usr/bin/pulseaudio</p>

<p> Note: File context can be temporarily modified with the chcon command. If you want to permanently change the file context you need to use the <code>semanage fcontext</code> command.
