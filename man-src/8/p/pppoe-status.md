<p>pppoe-status &#8211; Shell script to report on status of PPPoE link</p>
<h2>Synopsis</h2>
<p><code>pppoe-status </code>[<i>config_file</i>] </p>
<h2>Description</h2>
<p><code>pppoe-status</code> is a shell script which checks the status of the PPPoE link established by the Roaring Penguin user-space PPPoE client. If you omit <i>config_file</i>, the default file <code>/etc/sysconfig/network-scripts/ifcfg-ppp0</code> is used. </p>
