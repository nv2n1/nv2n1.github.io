<p>chrome_selinux &#8211; Security Enhanced Linux Policy for the chrome processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the chrome processes via flexible mandatory access control. </p>
<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. chrome policy is extremely flexible and has several booleans that allow you to manipulate the policy and run chrome with the tightest access possible. </p>
<p> If you want to allow unconfined users to transition to the chrome sandbox domains when running chrome-sandbo, you must turn on the unconfined_chrome_sandbox_transition boolean. </p>
<p> <code>setsebool -P unconfined_chrome_sandbox_transition 1</code></p>
