<p>cardmgr_selinux &#8211; Security Enhanced Linux Policy for the cardmgr processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the cardmgr processes via flexible mandatory access control. The cardmgr processes execute with the cardmgr_t SELinux type. You can check if you have these processes running by executing the <code>ps</code> command with the <code>-Z</code> qualifier. For example: <code>ps -eZ | grep cardmgr_t</code> </p>
<h2>Entrypoints</h2>
<p>The cardmgr_t SELinux type can be entered via the <code>cardctl_exec_t, cardmgr_exec_t</code> file types. </p>
<p> The default entrypoint paths for the cardmgr_t domain are the following: </p>
<p> /sbin/cardctl, /usr/sbin/cardctl, /sbin/cardmgr, /usr/sbin/cardmgr, /etc/apm/event.d/pcmcia</p>

<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. cardmgr policy is extremely flexible and has several booleans that allow you to manipulate the policy and run cardmgr with the tightest access possible. </p>
<p> If you want to allow all daemons to write corefiles to /, you must turn on the daemons_dump_core boolean. Disabled by default. </p>
<p> <code>setsebool -P daemons_dump_core 1</code> </p>
<p> If you want to enable cluster mode for daemons, you must turn on the daemons_enable_cluster_mode boolean. Enabled by default. </p>
<p> <code>setsebool -P daemons_enable_cluster_mode 1</code> </p>
<p> If you want to allow all daemons to use tcp wrappers, you must turn on the daemons_use_tcp_wrapper boolean. Disabled by default. </p>
<p> <code>setsebool -P daemons_use_tcp_wrapper 1</code> </p>
<p> If you want to allow all daemons the ability to read/write terminals, you must turn on the daemons_use_tty boolean. Disabled by default. </p>
<p> <code>setsebool -P daemons_use_tty 1</code> </p>
<p> If you want to deny any process from ptracing or debugging any other processes, you must turn on the deny_ptrace boolean. Enabled by default. </p>
<p> <code>setsebool -P deny_ptrace 1</code> </p>
<p> If you want to allow all domains to use other domains file descriptors, you must turn on the domain_fd_use boolean. Enabled by default. </p>
<p> <code>setsebool -P domain_fd_use 1</code> </p>
<p> If you want to allow all domains to have the kernel load modules, you must turn on the domain_kernel_load_modules boolean. Disabled by default. </p>
<p> <code>setsebool -P domain_kernel_load_modules 1</code> </p>
<p> If you want to allow all domains to execute in fips_mode, you must turn on the fips_mode boolean. Enabled by default. </p>
<p> <code>setsebool -P fips_mode 1</code> </p>
<p> If you want to enable reading of urandom for all domains, you must turn on the global_ssp boolean. Disabled by default. </p>
<p> <code>setsebool -P global_ssp 1</code></p>

<h2>File Contexts</h2>
<p>SELinux requires files to have an extended attribute to define the file type. </p>
<p> You can see the context of a file using the <code>-Z</code> option to <code>lsP Policy governs the access confined processes have to these files. SELinux cardmgr policy is very flexible allowing users to setup their cardmgr processes in as secure a method as possible. </p>
<p> STANDARD FILE CONTEXT</code> </p>
<p> SELinux defines the file context types for the cardmgr, if you wanted to store files with these types in a diffent paths, you need to execute the semanage command to sepecify alternate labeling and then use restorecon to put the labels on disk. </p>
<p> <code>semanage fcontext -a -t cardmgr_var_run_t &#8216;/srv/mycardmgr_content(/.*)?&#8217;</code><br />
 <code>restorecon -R -v /srv/mycardmgr_content</code> </p>
<p> Note: SELinux often uses regular expressions to specify labels that match multiple files. </p>
<p> <i>The following file types are defined for cardmgr:</i> </p>
<p> <code>cardmgr_dev_t</code> </p>
<p> &#8211; Set files with the cardmgr_dev_t type, if you want to treat the files as cardmgr dev data. </p>
<p> <code>cardmgr_exec_t</code> </p>
<p> &#8211; Set files with the cardmgr_exec_t type, if you want to transition an executable to the cardmgr_t domain. </p>
<dl>
<dt>Paths:</p>
<dd>/sbin/cardmgr, /usr/sbin/cardmgr, /etc/apm/event.d/pcmcia </p>
</dl>
<p> <code>cardmgr_lnk_t</code> </p>
<p> &#8211; Set files with the cardmgr_lnk_t type, if you want to treat the files as cardmgr lnk data. </p>
<p> <code>cardmgr_var_lib_t</code> </p>
<p> &#8211; Set files with the cardmgr_var_lib_t type, if you want to store the cardmgr files under the /var/lib directory. </p>
<p> <code>cardmgr_var_run_t</code> </p>
<p> &#8211; Set files with the cardmgr_var_run_t type, if you want to store the cardmgr files under the /run or /var/run directory. </p>
<dl>
<dt>Paths:</p>
<dd>/var/lib/pcmcia(/.*)?, /var/run/stab, /var/run/cardmgr.pid </p>
</dl>
<p> Note: File context can be temporarily modified with the chcon command. If you want to permanently change the file context you need to use the <code>semanage fcontext</code> command. This will modify the SELinux labeling database. You will need to use <code>restorecon</code> to apply the labels.</p>
