<p>chntpw &#8211; utility to overwrite passwords of Windows systems</p>
<h2>Synopsis</h2>
<p><code>chntpw</code> [<i>options</i>] &lt;<i>samfile</i>&gt; [<i>systemfile</i>] [<i>securityfile</i>] [<i>otherreghive</i>] [&#8230;]</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>chntpw</code> command. This manual page was written for the Debian distribution because the original program does not have a manual page. <code>chntpw</code> is a utility to view some information and reset user passwords in a Windows NT/2000 SAM userdatabase file used by Microsoft Windows Operating System (in NT3.x and later versions). This file is usually located at \WINDOWS\system32
