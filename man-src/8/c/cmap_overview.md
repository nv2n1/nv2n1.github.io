<p>cmap_overview &#8211; Overview of the Configuration Map</p>
<h2>Overview</h2>
<p>The CMAP library is used to interact with the configuration database used by corosync. </p>
<p> The library provides a mechanism to: </p>
<p> * Create of new keys </p>
<p> * Change existing keys </p>
<p> * Remove keys </p>
<p> * Iterate keys with given prefix </p>
<p> * Track changes on keys </p>
<p> Description of most keys created by corosync itself can be found in cmap_keys (8).</p>
