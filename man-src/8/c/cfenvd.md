<p>cfengine &#8211; network configuration engine</p>
<h2>Synopsis</h2>
<p>/usr/local/sbin/cfenvd </p>
<h2>Description</h2>
<p><code>cfengine</code> is a language based system specifically designed for testing and configuring unix-like systems attached to a TCP/IP network. Cfenvd is part of the anomaly detection subsystem for cfagent. It is a &quot;plug&#8217;n&#8217;play&quot; module that provides machine learning support to the agent. Cfenvd requires no configuration. It is completely optional. If it is run, cfagent can extract useful data from it; if it is not run cfagent continues as usual. It is part of the on-going research in anomaly detection using cfengine. </p>
