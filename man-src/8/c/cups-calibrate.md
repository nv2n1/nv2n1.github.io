<p>cups-calibrate &#8211; ESP CUPS Printer Calibration Tool</p>
<h2>Synopsis</h2>
<p><code>cups-calibrate</code></p>
<h2>Description</h2>
<p>This program allows you to calibrate the color output of printers using the <code>Gutenprint</code> <i>CUPS</i> driver. Please note that this program <code>only</code> works with the <code>Gutenprint</code> <i>CUPS</i> driver. </p>
<p> These drivers are identified by the text <i>CUPS+Gutenprint</i> in the model description displayed by the CUPS web interface. </p>
<p> To make a calibration profile for all users, run this program as the <code>root</code> user. The program displays a series of prompts which should simply be followed.</p>
