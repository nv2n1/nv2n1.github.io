<p>consolehelper-gtk &#8211; A helper program for consolehelper</p>
<h2>Synopsis</h2>
<p><i>consolehelper-gtk</i></p>
<h2>Description</h2>
<p><code>consolehelper-gtk</code> is a program that accomplishes the same job as consolehelper, except graphically. It is executed by consolehelper if an X display is detected. This program is not intended to be run by users directly. </p>
