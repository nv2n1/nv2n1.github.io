<p>check_forensic &#8211; tool to extract mod_log_forensic output from apache log files</p>
<h2>Synopsis</h2>
<p><code>check_forensic</code> &lt;log_file&gt;</p>
<h2>Description</h2>
<p>chech_forensic is a simple shell script designed to help apache administrators to extract mod_log_forensic output from apache2 log files. It checks the forensic log for requests that did not complete and outputs the request log for each one. </p>
