<p>create-cracklib-dict &#8211; Check passwords using libcrack2</p>
<h2>Synopsis</h2>
<p><code>create-cracklib-dict wordlist &#8230;</code> </p>
<h2>Description</h2>
<p><code>create-cracklib-dict</code> takes one or more word list files as arguments and converts them into cracklib dictionaries for use by password checking programs. The results are placed in the default compiled-in dictionary location. If you wish to store the dictionary in a different location, use the cracklib-format and cracklib-packer commands directly. </p>
