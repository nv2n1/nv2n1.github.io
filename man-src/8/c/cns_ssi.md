<p>cns_ssi &#8211; administer a server side inventory</p>
<h2>Synopsis</h2>
<pre><code>cns_ssi</code> <i>command</i> [<i>options</i>] <i>dirpath</i></pre>
<h2>Description</h2>
<p>The <code>cns_ssi</code> utility displays and maintains server side inventory files created by the <code>XrdCnsd</code> daemon. Complete HTML documentation can be found at </p>
<p> <center> <a rel="nofollow" href="http://xrootd.org/doc/prod/cms_config.htm">http://xrootd.org/doc/prod/cms_config.htm</a><br />
 </center></p>
<h2>Notes</h2>
<p>Documentation for all components associated with <code>cns_ssi</code> can be found at <a rel="nofollow" href="http://xrootd.org/docs.html">http://xrootd.org/docs.html</a></p>
<h2>Diagnostics</h2>
<p>Errors yield an error message and a non-zero exit status.</p>
