<p>shinken &#8211; Shinken packs and modules manager</p>
<h2>Synopsis</h2>
<p>shinken [OPTION]&#8230; FILE</p>
<h2>Description</h2>
<p>Shinken packs and modules manager </p>
<p> Shinken is a usefull tool to manage your Shinken packs and modules and can be used to download packs and modules from <a rel="nofollow" href="http://shinken.io">http://shinken.io</a> and also to publish yours.</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;version</code></p>
<dd>Show version number and exit</p>
<dl>
<dd></dl>
<dt><code>-A </code>API_KEY, &#8211;api-keys API_KEY</p>
<dd>Your API key for uploading the package to the Shinken.io website. If you don&#8217;t have one, please go to your account page</p>
<dl>
<dd></dl>
<dt><code>-l, &#8211;list</code></p>
<dd>List available commands</p>
<dl>
<dd></dl>
<dt><code>&#8211;init</code></p>
<dd>Initialize/refill your shinken.ini file (default home directory)</p>
<dl>
<dd></dl>
<dt><code>-D</code></p>
<dd>Enable the debug mode</p>
<dl>
<dd></dl>
<dt><code>-c </code>INICONFIG, &#8211;config INICONFIG</p>
<dd>Path to your shinken.ini file.</p>
<dl>
<dd></dl>
<dt><code>-h, &#8211;help</code></p>
<dd>Print detailed help screen.</p>
<dl>
<dd></dl>
</dl>
