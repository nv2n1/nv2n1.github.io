<p>stop-dirsrv &#8211; stop script for Directory Server</p>
<h2>Synopsis</h2>
<p><code>start-dirsrv</code> [<i>&lt;instance&gt;</i>]</p>
<h2>Description</h2>
<p>stop-dirsrv stops all Directory Server instances on a system, or only a single instance if specified </p>
<h2>Options</h2>
<dl>
<dt><code>&lt;instance&gt;</code></p>
<dd>Specifies a single Directory Server instance to stop
</dl>
<h2>Usage</h2>
<p>Sample usage:</p>
<dl>
<dt><code>stop-dirsrv example</code></p>
<dd></dl>
