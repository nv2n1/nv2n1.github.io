<p>selinux-polgengui &#8211; SELinux Policy Generation Tool</p>
<h2>Synopsis</h2>
<p><code>selinux-polgengui</code> </p>
<h2>Description</h2>
<p><code>selinux-polgengui</code> is a graphical tool, which can be used to create a framework for building SELinux Policy.</p>
<h2>Options</h2>
<p>None</p>
<h2>Files</h2>
<p>/usr/bin/selinux-polgengui</p>
<h2>Examples</h2>
<p>To run the program type: selinux-polgengui </p>
