<p>stop-ds-admin &#8211; stop script for Admin Server</p>
<h2>Synopsis</h2>
<p><code>stop-ds-admin</code></p>
<h2>Description</h2>
<p>stop-ds-admin stops the Admin Server instance NOTE: On systems that provide the <i>service</i> command or <i>systemctl</i> or other similar command, that command should be used instead of this script. This script is only for those installations that do not support such mechanisms. e.g.<br />
&nbsp;<wbr>service dirsrv-admin stop </p>
<h2>Usage</h2>
<p>Sample usage:</p>
<dl>
<dt><code>stop-ds-admin</code></p>
<dd></dl>
