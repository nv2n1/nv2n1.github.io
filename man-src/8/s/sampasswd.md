<p>sampasswd &#8211; reset passwords of users in the SAM user database</p>
<h2>Synopsis</h2>
<p><code>sampasswd</code> [<i>options</i>] -u<i>user</i> &lt;<i>samfile</i>&gt;</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>sampasswd</code> command. This manual page was written for the Debian distribution because the original program does not have a manual page. <code>sampasswd</code> is a non-interactive command line utility that can reset a user&#8217;s password and/or the user&#8217;s account bits from the SAM user database file of a Microsoft Windows system (Windows NT, 2000, XP, Vista, 7, 8.1, etc.). This file is usually located at \WINDOWS\system32
