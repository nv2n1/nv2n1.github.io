snapd-env-generator - internal tool to set /snap/bin to PATH

<h2>Synopsis</h2>

snapd-env-generator

<h2>Description</h2>

The <i>snapd-env-generator</i> is run by systemd to ensure that the snap bin dir (usually /snap/bin) is path of PATH.
