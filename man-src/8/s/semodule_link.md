<p>semodule_link &#8211; Link SELinux policy module packages together </p>
<h2>Synopsis</h2>
<p><code>semodule_link [-Vv] [-o outfile] basemodpkg modpkg1 [modpkg2]&#8230;</code></p>
<h2>Description</h2>
<p>semodule_link is a developer tool for manually linking together a set of SELinux policy module packages into a single policy module package. This tool is not necessary for normal operation of SELinux. In normal operation, such linking is performed internally by libsemanage in response to semodule commands. Module packages are created by semodule_package. </p>
<h2>Options</h2>
<dl>
<dt><code>-V</code></p>
<dd>show version</p>
<dt><code>-v</code></p>
<dd>verbose mode</p>
<dt><code>-o &lt;output file&gt; </code></p>
<dd>Linked policy module package generated by this tool. </p>
</dl>
