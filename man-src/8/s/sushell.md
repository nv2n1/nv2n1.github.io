<p>sushell &#8211; execute the single-user shell</p>
<h2>Synopsis</h2>
<p><code>sushell</code></p>
<h2>Description</h2>
<p><code>sushell</code> executes the single-user shell. By default, this is <i>/bin/bash</i> This can be configured via the <code>SUSHELL</code> environment variable.</p>
<h2>Notes</h2>
<p><code>sushell</code> is an implementation detail, required for proper SELinux usage. It is not intended to be run regularly. </p>
