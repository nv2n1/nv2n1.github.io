<p>xxqs_name_sxx_coshepherd &#8211; xxQS_NAMExx single job-controlling agent</p>
<h2>Synopsis</h2>
<p><code>xxqs_name_sxx_coshepherd</code></p>
<h2>Description</h2>
<p><i>xxqs_name_sxx_coshepherd</i> is needed to run the token manipulation executables if Grid Engine is run in an AFS environment.
