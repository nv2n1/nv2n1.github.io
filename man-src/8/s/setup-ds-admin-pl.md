<p>setup-ds-admin.pl &#8211; Set up an instance of Directory Server and Admin Server</p>
<h2>Synopsis</h2>
<p><code>setup-ds-admin.pl</code> [<i>&#8211;options</i>] <i>&#8212; </i>[<i>args</i>]</p>
<h2>Description</h2>
<p>Set up a Directory Server and Admin Server. Creates the configuration files for an instance of Directory Server based on a few parameters like the hostname, port number, and directory manager information. Creates the configuration files for the Admin Server. Starts up the servers. This command does the set up necessary for the use of the Console and the Admin Express web interface. If the Admin Server has already been set up, this command will create a new instance of Directory Server and register it with the Admin Server so that it can be managed with the Console. Use this command with the <code>&#8211;update</code> option after an upgrade to refresh the server information (version, build number, etc.) in the Console. Can be run in interactive mode with different levels of verbosity, or in silent mode with parameters supplied in a .inf format file or on the command line. </p>
<h2>Options</h2>
<p>A summary of options is included below:</p>
<dl>
<dt><code>&#8211;help</code></p>
<dd>This message</p>
<dt><code>&#8211;version</code></p>
<dd>Print the version and exit</p>
<dt><code>&#8211;debug</code></p>
<dd>Turn on debugging</p>
<dt><code>&#8211;silent</code></p>
<dd>Use silent setup &#8211; no user input</p>
<dt><code>&#8211;file</code>=<i>name</i></p>
<dd>Use the file &#8216;name&#8217; in .inf format to supply the default answers</p>
<dt><code>&#8211;keepcache</code></p>
<dd>Do not delete the temporary .inf file generated by this program</p>
<dt><code>&#8211;logfile</code></p>
<dd>Log setup messages to this file &#8211; otherwise, a temp file will be used</p>
<dt><code>&#8211;update</code></p>
<dd>Refresh the information used by the Console for all servers on this machine. Use this after an upgrade to make sure the Console reports the correct information.</dl>
<p> For all options, you can also use the short name e.g. <code>-h</code>, <code>-d</code>, etc. For the <code>-d</code> argument, specifying it more than once will increase the debug level e.g. <code>-ddddd</code> </p>
<p> args: You can supply default .inf data in this format:</p>
<dl>
<dd>section.param=value</dl>
<p> e.g.</p>
<dl>
<dd>General.FullMachineName=foo.example.com</dl>
<p> or</p>
<dl>
<dd>&quot;slapd.Suffix=dc=example, dc=com&quot;</dl>
<p> Values passed in this manner will override values in an .inf file given with the <code>-f</code> argument.</p>
