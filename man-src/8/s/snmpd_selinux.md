<p>snmpd_selinux &#8211; Security Enhanced Linux Policy for the snmpd processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the snmpd processes via flexible mandatory access control. The snmpd processes execute with the snmpd_t SELinux type. You can check if you have these processes running by executing the <code>ps</code> command with the <code>-Z</code> qualifier. For example: <code>ps -eZ | grep snmpd_t</code> </p>
<h2>Entrypoints</h2>
<p>The snmpd_t SELinux type can be entered via the <code>snmpd_exec_t</code> file type. </p>
<p> The default entrypoint paths for the snmpd_t domain are the following: </p>
<p> /usr/sbin/snmpd, /usr/sbin/snmptrapd</p>

<h2>File Contexts</h2>
<p>SELinux requires files to have an extended attribute to define the file type. </p>
<p> You can see the context of a file using the <code>-Z</code> option to <code>lsP Policy governs the access confined processes have to these files. SELinux snmpd policy is very flexible allowing users to setup their snmpd processes in as secure a method as possible. </p>
<p> EQUIVALENCE DIRECTORIES</code> </p>
<p> snmpd policy stores data with multiple different file context types under the /var/run/snmpd directory. If you would like to store the data in a different directory you can use the semanage command to create an equivalence mapping. If you wanted to store this data under the /srv dirctory you would execute the following command: </p>
<p> <code>semanage fcontext -a -e /var/run/snmpd /srv/snmpd</code><br />
 <code>restorecon -R -v /srv/snmpd</code> </p>
<p> <code>STANDARD FILE CONTEXT</code> </p>
<p> SELinux defines the file context types for the snmpd, if you wanted to store files with these types in a diffent paths, you need to execute the semanage command to sepecify alternate labeling and then use restorecon to put the labels on disk. </p>
<p> <code>semanage fcontext -a -t snmpd_var_run_t &#8216;/srv/mysnmpd_content(/.*)?&#8217;</code><br />
 <code>restorecon -R -v /srv/mysnmpd_content</code> </p>
<p> Note: SELinux often uses regular expressions to specify labels that match multiple files. </p>
