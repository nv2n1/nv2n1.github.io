<p>system-config-date &#8211; graphical interface for changing system date and time</p>
<h2>Synopsis</h2>
<p><code>system-config-date</code></p>
<h2>Description</h2>
<p><code>system-config-date</code> provides a graphical interface that allows the user to change the system date and time. It also allows the user to configure the system time zone and to setup the NTP daemon to synchronize the time of the system with a NTP time server. </p>
<h2>Options</h2>
<p>None</p>
<h2>Files</h2>
<p><i>/usr/bin/system-config-date</i><br />
 <i>/usr/share/system-config-date/*</i></p>
<h2>Examples</h2>
<p>To run the program type: system-config-date </p>
