<p>samunlock &#8211; unlock users in the SAM user database</p>
<h2>Synopsis</h2>
<p><code>samunlock</code> [<i>options</i>] -u<i>user</i> &lt;<i>samfile</i>&gt;</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>samunlock</code> command. <code>samunlock</code> is a non-interactive command line utility that can unlock a user and/or the user&#8217;s account bits from the SAM user database file of a Microsoft Windows system (Windows NT, 2000, XP, Vista, 7, 8.1, etc.). This file is usually located at \WINDOWS\system32
