<p>system-config-users &#8211; User and Group Management tool</p>
<h2>Synopsis</h2>
<p><code>system-config-users</code> </p>
<h2>Description</h2>
<p><code>system-config-users</code> provides a graphical interface for adding and removing users and groups to the system. Once started <code>system-config-users</code> provides a help feature to assist in learning the interface. </p>
<h2>Options</h2>
<p>None</p>
<h2>Files</h2>
<p>/usr/bin/system-config-users<br />
 /usr/share/doc/system-config-users*</p>
<h2>Examples</h2>
<p>To run the program type: system-config-users </p>
