<p>system-config-selinux &#8211; SELinux Management tool</p>
<h2>Synopsis</h2>
<p><code>system-config-selinux</code> </p>
<h2>Description</h2>
<p><code>system-config-selinux</code> provides a graphical interface for managing the SELinux configuration. </p>
<h2>Options</h2>
<p>None</p>
<h2>Files</h2>
<p>/usr/bin/system-config-selinux</p>
<h2>Examples</h2>
<p>To run the program type: system-config-selinux </p>
