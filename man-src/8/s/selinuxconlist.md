<p>selinuxconlist &#8211; list all SELinux context reachable for user</p>
<h2>Synopsis</h2>
<p><code>selinuxconlist [-l level] user [context]</code> </p>
<h2>Description</h2>
<p><code>selinuxconlist</code> reports the list of context reachable for user from the current context or specified context <code>-l level</code> mcs/mls level</p>
