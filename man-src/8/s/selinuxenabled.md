<p>selinuxenabled &#8211; tool to be used within shell scripts to determine if selinux is enabled</p>
<h2>Synopsis</h2>
<p><code>selinuxenabled</code></p>
<h2>Description</h2>
<p>Indicates whether SELinux is enabled or disabled.</p>
<h2>Exit Status</h2>
<p>It exits with status 0 if SELinux is enabled and 1 if it is not enabled.</p>
