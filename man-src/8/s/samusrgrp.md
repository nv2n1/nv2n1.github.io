<p>samusrgrp &#8211; add or remove users from groups in SAM database files</p>
<h2>Synopsis</h2>
<p><code>samusrgrp</code> [<i>options</i>] &lt;<i>samfile</i>&gt;</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>samusrgrp</code> command. This manual page was written for the Debian distribution because the original program does not have a manual page. <code>samusrgrp</code> is a non-interactive command line utility that can add or remove a user from a local group that exists in the SAM user database of a Microsoft Windows system (Windows NT, 2000, XP, Vista, 7, 8.1, etc.). This file is usually located at \WINDOWS\system32
