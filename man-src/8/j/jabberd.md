<p>jabberd &#8211; jabberd startup script</p>
<h2>Synopsis</h2>
<p><code>jabberd</code> <i>[-h] [-c config] [-D]</i></p>
<h2>Description</h2>
<p><code>jabberd</code> is a script that runs the various components that make up the jabberd &quot;server&quot;.</p>
<h2>Options</h2>
<dl>
<dt><code>-h</code></dt>
<dd>Show summary of options.</dd>
<dt><code>-c</code></dt>
<dd>Alternate configuration file to use. The compiled-in default is /etc/jabberd/jabberd.cfg</dd>
<dt><code>-D</code></dt>
<dd>Print debugging output. You should configure jabberd with the &#8211;enable-debug switch to enable this.</dd></dl>
