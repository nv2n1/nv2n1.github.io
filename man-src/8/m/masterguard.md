<p>masterguard &#8211; Driver for Masterguard UPS equipment</p>
<h2>Note</h2>
<p>This man page only documents the hardware-specific features of the masterguard driver. For information about the core driver, see <code><a href="/docs/linux/man/8-nutupsdrv/">nutupsdrv</a></code>(8).</p>
<h2>Supported Hardware</h2>
<p>This driver supports Masterguard UPS equipment.</p>
<h2>Extra Arguments</h2>
<p><code>CS</code></p>
<dl>
<dd>Cancel the shutdown procedure.</dl>
