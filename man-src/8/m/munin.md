munin - Munin manpage hub

<h2>Description</h2>

Munin is a group of programs to gather data from hosts, graph them, create html-pages, and optionally warn contacts about any off-limit values. 

 The Munin master contains the following programs: 
&nbsp;<wbr>munin-update - to gather data from machines running munin-node. 
&nbsp;<wbr>munin-graph&nbsp;<wbr>&nbsp;<wbr>- to create graphs from data contained in rrd-files. 
&nbsp;<wbr>munin-limits - to check for any off-limit values. 
&nbsp;<wbr>munin-html&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>- to draw html-pages on an Munin installation 
&nbsp;<wbr>munin-cron&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>- to batch other munin programs
