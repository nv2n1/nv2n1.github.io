<p>fpga_load &#8211; Xorcom Astribank (xpp) firmware tool</p>
<h2>Synopsis</h2>
<p><code>fpga_load </code> [<code>-g</code>] [<code>-r</code>] [<code>-v</code>] <code>-D </code>{/proc/bus/usb|/dev/bus/usb}/<i>BUS/DEV</i> <code>fpga_load </code> [<code>-g</code>] [<code>-v</code>] <code>-D </code>{/proc/bus/usb|/dev/bus/usb}/<i>BUS/DEV</i> <code>-I </code><i>firmware.hex</i> [<code>-b </code><i>dump.bin</i>] [<code>-i</code>] <code>fpga_load -h</code> </p>
<h2>Description</h2>
<p><code>fpga_load </code> loads the FPGA firmware to the Xorcom Astribank device. The syntax resembles that of <a href="/docs/linux/man/8-fxload/">fxload</a>(8). </p>
<h2>Options</h2>
<p><code>-b</code> <i>dump.bin</i></p>
<dl>
<dd>Before writing firmware, bump the processed binary file to <i>dump.bin</i>.</dl>
<p> <code>-D </code> <i>DEVICE</i></p>
<dl>
<dd>Required. The device to read from/write to. On modern UDEV-based system this is usually /dev/bus/usb/<i>bus_num</i>/<i>device_num</i>, where <i>bus_num</i> and <i>device_num</i> are the first two numbers in the output of <a href="/docs/linux/man/8-lsusb/">lsusb</a>(8). On older systems that use usbfs, it is usually /proc/bus/usb/<i>bus_num</i>/<i>device_num</i>.</dl>
<p> <code>-r</code></p>
<dl>
<dd>Reset the Astribank and renumerate its USB connection to power on product ID.</dl>
<p> <code>-g</code></p>
<dl>
<dd>Dump all eeprom data to standard output.</dl>
<p> <code>-I</code> <i>fireware_file</i></p>
<dl>
<dd>The firmware file to write to the device.</dl>
<p> <code>-i</code></p>
<dl>
<dd>Show information about the firmware file (valid only with <code>-I</code> option). Example: </p>
<p> <tt>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr></tt>./FPGA_1151.hex: Version=3297 Checksum=58270</p>
<p> In particular, the calculated checksum should match the output of <i><a href="/docs/linux/man/1-sum/">sum</a>(1)</i> on the binary firmware file generated by the <code>-b</code> option.</dl>
<p> <code>-v</code></p>
<dl>
<dd>Increase verbosity. May be used multiple times.</dl>
<p> <code>-h</code></p>
<dl>
<dd>Displays usage message.</dl>
