<p>fence_ilo4_ssh &#8211; Fence agent for HP iLO over SSH fence_ilo3_ssh &#8211; Fence agent for HP iLO3 over SSH (symlink) fence_ilo4_ssh &#8211; Fence agent for HP iLO4 over SSH (symlink) </p>
<h2>Description</h2>
<p>fence_ilo_ssh is a fence agent that connects to iLO device. It logs into device via ssh and reboot a specified outlet. </p>
<p> fence_ilo4_ssh accepts options on the command line as well as from stdin. Fenced sends parameters through stdin when it execs the agent. fence_ilo4_ssh can be run by itself with command line options. This is useful for testing and for turning outlets on or off from scripts. </p>
<p> Vendor URL: <a rel="nofollow" href="http://www.hp.com">http://www.hp.com</a></p>
