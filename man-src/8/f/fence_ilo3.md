<h2>Description</h2>
<p>fence_ipmilan is an I/O Fencing agentwhich can be used with machines controlled by IPMI.This agent calls support software ipmitool (<a rel="nofollow" href="http://ipmitool.sf.net/">http://ipmitool.sf.net/</a>). WARNING! This fence agent might report success before the node is powered off. You should use -m/method onoff if your fence device works correctly with that option. </p>
<p> fence_ilo3 accepts options on the command line as well as from stdin. Fenced sends parameters through stdin when it execs the agent. fence_ilo3 can be run by itself with command line options. This is useful for testing and for turning outlets on or off from scripts. </p>
