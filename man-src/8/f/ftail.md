<p>ftail &#8211; runs Frysk&#8217;s dogtail testsuite</p>
<h2>Synopsis</h2>
<dl>
<dt> <code>ftail</code></dl>
<h2>Description</h2>
<p><code>ftail</code></p>
<dd>runs Frysk&#8217;s dogtail testsuite, which exercises the GNOME interface. </p>
<p> The dogtail testsuite exercises Frysk&#8217;s GNOME interface using the current X display. To run the testsuite headless, run <code>ftail</code> using <code>dogtail-run-headless</code>.</p>
<h2>Exit Status</h2>
<p>Exits with zero status if the testsuite run was successful, non-zero otherwize.</p>
<h2>Example</h2>
<dl>
<dd>
<pre>dogtail-run-headless /usr/lib/frysk/ftail</pre>
</dl>
