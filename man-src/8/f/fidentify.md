<p>fidentify &#8211; Determine file type using PhotoRec database</p>
<h2>Synopsis</h2>
<p><code>fidentify [&#8211;check] [directory|file]</code> <code>fidentify &#8211;version</code> </p>
<h2>Description</h2>
<p><code>fidentify</code>&nbsp;<wbr>identify the file type, the&nbsp;<wbr>&quot;extension&quot;, by using the same database than PhotoRec.<br />
When a file or directory is specified, fidentify will output the type of file, or files under the specified directory.<br />
If given no arguments, fidentify will output type of files under current directory.<br />
fidentify is similar to&nbsp;<wbr><a href="/docs/linux/man/1-file/">file</a>(1).</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;check</code></p>
<dd>check the file format like PhotoRec does by default</dl>
