<p>foomatic-preferred-driver &#8211; set default drivers in Foomatic database</p>
<h2>Synopsis</h2>
<p><code>foomatic-preferred-driver</code> </p>
<h2>Description</h2>
<p>This command reads the printer database overview and puts default driver entries (&lt;driver&gt;..&lt;/driver&gt;) into every printer&#8217;s XML database entry. It is very unlikely you need to do this. </p>
