fts_server

<h2>Synopsis</h2>

fts_server [options]

<h2>Description</h2>

fts_server starts the FTS3 server.

&nbsp;<wbr>&nbsp;<wbr>-q&nbsp;<wbr>[&nbsp;<wbr>--quiet&nbsp;<wbr>]&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>Quiet operation. 
&nbsp;<wbr>&nbsp;<wbr>-v&nbsp;<wbr>[&nbsp;<wbr>--verbose&nbsp;<wbr>]&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>Be more verbose. 
&nbsp;<wbr>&nbsp;<wbr>-s&nbsp;<wbr>[&nbsp;<wbr>--service&nbsp;<wbr>]&nbsp;<wbr>arg&nbsp;<wbr>&nbsp;<wbr>Use the transfer service at the specified URL. 
&nbsp;<wbr>&nbsp;<wbr>-r&nbsp;<wbr>[--rush]&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>Quick start and stop. Not intended for production.
