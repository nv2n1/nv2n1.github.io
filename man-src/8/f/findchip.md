<p>findchip &#8211; checks the FIR chipset.</p>
<h2>Synopsis</h2>
<p><code>findchip</code> [ <i>-d dongle</i> ] [ <i>-v</i> ] [ <i>-l</i> ] [ <code>&lt;chip1 .. chipN&gt;</code> ] [ <i>-h</i> ] </p>
<h2>Options</h2>
<p><code>-d</code> enables debug output </p>
<p> <code>-v</code> be verbose </p>
<p> <code>-l</code> lists supported chipsets </p>
<p> <code>-h</code> prints help message</p>
<h2>Description</h2>
<p><code>findchip</code> checks the FIR chipset. </p>
<p> <code>findchip</code> must be run as root or installed setuid root, as it requires root privileges.</p>
