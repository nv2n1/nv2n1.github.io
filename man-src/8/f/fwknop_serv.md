<p><code>fwknop_serv</code> &#8211; Fwknop server for the TOR network. </p>
<h2>Description</h2>
<p><code>fwknop_serv</code> is a simplisitc TCP server that is only used if SPA packets are sent over the TOR anonymizing network (<a rel="nofollow" href="http://www.torproject.org">http://www.torproject.org</a>). Use of this server results in bidirectional communication, so it technically breaks the usual unidirectional nature of the SPA protocol; More informations can be found at the following : url <a rel="nofollow" href="http://www.cipherdyne.org/fwknop/docs/talks/dc14_fwknop_slides.pdf.">http://www.cipherdyne.org/fwknop/docs/talks/dc14_fwknop_slides.pdf.</a> </p>
