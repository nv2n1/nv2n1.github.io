<p>frm_admin &#8211; administer file residency parameters</p>
<h2>Synopsis</h2>
<pre><code>frm_admin</code> [<i>options</i>] [<i>command</i> [<i>cmdopts</i>]]</pre>
<h2>Description</h2>
<p>The <code>frm_admin</code> utility displays and alters data server space attributes associated with file residency. These attributes are used by the <code>frm_purged</code>, <code>frm_xfrd</code>, and <code>xrootd</code> daemons to manage file residency. Usage synopsis can be displayed by typing &quot;<code>frm_admin -h</code>&quot;. Complete HTML documentation can be found at </p>
<p> <center> <a rel="nofollow" href="http://xrootd.org/doc/prod/frm_config.htm">http://xrootd.org/doc/prod/frm_config.htm</a><br />
 </center></p>
<h2>Notes</h2>
<p>Documentation for all components associated with <code>frm_admin</code> can be found at <a rel="nofollow" href="http://xrootd.org/docs.html">http://xrootd.org/docs.html</a></p>
<h2>Diagnostics</h2>
<p>Configuration errors yield an error message and a non-zero exit status.</p>
