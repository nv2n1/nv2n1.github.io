<p>fence_ilo &#8211; Fence agent for HP iLO fence_ilo2 &#8211; Fence agent for HP iLO2 (symlink) </p>
<h2>Description</h2>
<p>fence_ilo is an I/O Fencing agent used for HP servers with the Integrated Light Out (iLO) PCI card.The agent opens an SSL connection to the iLO card. Once the SSL connection is established, the agent is able to communicate with the iLO card through an XML stream. </p>
<p> fence_ilo accepts options on the command line as well as from stdin. Fenced sends parameters through stdin when it execs the agent. fence_ilo can be run by itself with command line options. This is useful for testing and for turning outlets on or off from scripts. </p>
<p> Vendor URL: <a rel="nofollow" href="http://www.hp.com">http://www.hp.com</a></p>
