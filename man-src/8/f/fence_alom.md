<p>fence_alom &#8211; Fence agent for Sun ALOM</p>
<h2>Description</h2>
<p>fence_alom is an I/O Fencing agent which can be used with ALOM connected machines. fence_alom accepts options on the command line as well as from stdin. Fenced sends parameters through stdin when it execs the agent. fence_alom can be run by itself with command line options. This is useful for testing and for turning outlets on or off from scripts. </p>
<p> Vendor URL: <a rel="nofollow" href="http://www.sun.com">http://www.sun.com</a></p>

</dl>
