<p>tpm_updatepcrhash</p>
<h2>Synopsis</h2>
<p><code>tpm_updatepcrhash</code> [<code>-hv</code>] OLD-HASH-FILE PCR-VALUE-FILE NEW_HASH-FILE</p>
<h2>Description</h2>
<p>This program updates the PCR composite hash in file OLD-HASH-FILE to produce the file NEW-HASH-FILE. The new composite hash is computed from the data in the file PCR-VALUE-FILE, which contains a list of PCR index=value pairs. The format of this file as the same as PCR value file generated by <code>tpm_getpcrhash.</code></p>
<dl>
<dt>-h</p>
<dd>Display command usage info.</p>
<dt>-v</p>
<dd>Display command version info.</dl>
