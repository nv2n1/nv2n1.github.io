<p>tpm_mkuuid</p>
<h2>Synopsis</h2>
<p><code>tpm_uuid</code> [<code>-hv</code>] UUID-FILE</p>
<h2>Description</h2>
<p>The program generates a TPM UUID and stores it in the file UUID-FILE.</p>
<dl>
<dt>-h</p>
<dd>Display command usage info.</p>
<dt>-v</p>
<dd>Display command version info.</dl>
