<p>ipsec__import_crl &#8211; helper program for importing a crl to the NSS database</p>
<h2>Description</h2>
<p><i>_import_crl</i> is spawned by <code>pluto</code> in order to add or update a CRL in the NSS database (default: /etc/ipsec.d)</p>
