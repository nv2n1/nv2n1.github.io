<p>ivtscd &#8211; driver for the IVT Solar Controller Device</p>
<h2>Note</h2>
<p>This man page only documents the hardware-specific features of the <code>ivtscd</code> driver. For information about the core driver, see <code><a href="/docs/linux/man/8-nutupsdrv/">nutupsdrv</a></code>(8).</p>
<h2>Description</h2>
<p>This driver allows to access the IVT SCD-series devices.</p>
<h2>Extra Arguments</h2>
<p>This driver does not support any extra argument.</p>
