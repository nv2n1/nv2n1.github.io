<p>intltool-merge &#8211; merge translated strings into various types of file</p>
<h2>Synopsis</h2>
<p><code>intltool-merge</code> <i>[option]&#8230; PO_DIRECTORY FILENAME OUTPUT_FILE</i> </p>
<h2>Description</h2>
<p>Merge translated strings in po files in <i>PO_DIRECTORY</i> with the original application file <i>FILENAME</i>, and output the file <i>OUTPUT_FILE</i> containing both original and localized strings. If <i>FILENAME</i> is an XML file, <i>OUTPUT_FILE</i> will contain repeated xml nodes, where each node contains one of the localized strings with &quot;xml:lang&quot; attribute. </p>
<h2>Options</h2>
<h3>Mode of operation</h3>
<dl>
<dt><code>-b</code></p>
<dd>
<dt><code>&#8211;ba-style</code></p>
<dd>Merge files in bonobo-activation style, which is used for bonobo servers.</p>
<dt><code>-d</code></p>
<dd>
<dt><code>&#8211;desktop-style</code></p>
<dd>Merge files in desktop style, which is similar to the Windows .ini file format.</p>
<dt><code>-k</code></p>
<dd>
<dt><code>&#8211;keys-style</code></p>
<dd>Merge files in keys style, which is used for metadata.</p>
<dt><code>-o</code></p>
<dd>
<dt><code>&#8211;oaf-style</code></p>
<dd>(OBSOLETE) Same as <code>-b</code>/<code>&#8211;ba-style</code>.</p>
<dt><code>-r</code></p>
<dd>
<dt><code>&#8211;rfc822deb-style</code></p>
<dd>Merge files in RFC 822 style, which is usually used in Debian configuration files.</p>
<dt><code>&#8211;quoted-style</code></p>
<dd>Merge files in quoted string style, which just translates any strings within &quot;&quot;.</p>
<dt><code>-x</code></p>
<dd>
<dt><code>&#8211;xml-style</code></p>
<dd>Merge files in standard XML style, both as attributes and as raw pcdata. </p>
</dl>
<h3>Other options</h3>
<dl>
<dt><code>-u</code></p>
<dd>
<dt><code>&#8211;utf8</code></p>
<dd>Convert all strings to UTF-8 before merging.</p>
<dt><code>-p</code></p>
<dd>
<dt><code>&#8211;pass-through</code></p>
<dd>Use strings as is in .po files without conversion (STRONGLY unrecommended with -x).</p>
<dt><code>-c</code></p>
<dd>
<dt><code>&#8211;cache</code></p>
<dd>(TBD)</p>
<dt><code>-q</code></p>
<dd>
<dt><code>&#8211;quiet</code></p>
<dd>Be quiet while running.</p>
<dt><code>-v</code></p>
<dd>
<dt><code>&#8211;version</code></p>
<dd>Show version information.</p>
<dt><code>-h</code></p>
<dd>
<dt><code>&#8211;help</code></p>
<dd>Show usage and basic help information. </p>
</dl>
<h2>Files</h2>
<dl>
<dt><code>po/.intltool-merge-cache</code></p>
<dd>Cache file generated by <code>intltool-merge</code>, that contains all strings in all po files separated by . </p>
</dl>
