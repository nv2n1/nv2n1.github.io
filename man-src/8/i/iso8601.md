<p>Pacemaker &#8211; Part of the Pacemaker cluster resource manager</p>
<h2>Synopsis</h2>
<p><code>iso8601</code> <i>command </i>[<i>output modifier</i>]</p>
<h2>Description</h2>
<p>iso8601 &#8211; Display and parse ISO8601 dates and times</p>
<h2>Options</h2>
<dl>
<dt>-?, <code>&#8211;help</code></p>
<dd>This text</p>
<dt>-$, <code>&#8211;version</code></p>
<dd>Version information</p>
<dt><code>-V</code>, <code>&#8211;verbose</code></p>
<dd>Increase debug output</dl>
<h3>Commands:</h3>
<dl>
<dt><code>-n</code>, <code>&#8211;now</code></p>
<dd>Display the current date/time</p>
<dt><code>-d</code>, <code>&#8211;date</code>=<i>value</i></p>
<dd>Parse an ISO8601 date/time. Eg. &#8216;2005-01-20 00:30:00 +01:00&#8217; or &#8216;2005-040&#8217;</p>
<dt><code>-p</code>, <code>&#8211;period</code>=<i>value</i></p>
<dd>Parse an ISO8601 date/time with interval/period (wth start time). Eg. &#8216;2005-040/2005-043&#8217;</p>
<dt><code>-D</code>, <code>&#8211;duration</code>=<i>value</i></p>
<dd>Parse an ISO8601 date/time with duration (wth start time). Eg. &#8216;2005-040/P1M&#8217;</p>
<dt><code>-E</code>, <code>&#8211;expected</code>=<i>value</i></p>
<dd>Parse an ISO8601 date/time with duration (wth start time). Eg. &#8216;2005-040/P1M&#8217;</dl>
<h3>Output Modifiers:</h3>
<dl>
<dt><code>-s</code>, <code>&#8211;seconds</code></p>
<dd>Show result as a seconds since 0000-001 00:00:00Z</p>
<dt><code>-S</code>, <code>&#8211;epoch</code></p>
<dd>Show result as a seconds since EPOCH (1970-001 00:00:00Z)</p>
<dt><code>-L</code>, <code>&#8211;local</code></p>
<dd>Show result as a &#8216;local&#8217; date/time</p>
<dt><code>-O</code>, <code>&#8211;ordinal</code></p>
<dd>Show result as an &#8216;ordinal&#8217; date/time</p>
<dt><code>-W</code>, <code>&#8211;week</code></p>
<dd>Show result as an &#8216;calendar week&#8217; date/time</dl>
<p> For more information on the ISO8601 standard, see: <a rel="nofollow" href="http://en.wikipedia.org/wiki/ISO_8601">http://en.wikipedia.org/wiki/ISO_8601</a></p>
