<p>intltool-prepare &#8211; Prepare software to make use of intltool</p>
<h2>Synopsis</h2>
<p><code>intltool-prepare</code> [<i>option</i>] [<i></i><font SIZE="-1"><i>KEYWORD</i></font><i></i>]&#8230; </p>
<h2>Description</h2>
<p>For software packages that include some specific type of translatable files (such as .desktop and .soundlist), before they make use of <code>intltool</code>, translators have to dig through them one by one, and add their localization into each file. This process is error prone, since translators may include typing errors, or add their localization in wrong encoding. Besides, translators may not alwas know other files (beside .po files) are translatable. <i>intltool</i> avoids all the problems above by extracting strings inside those translatable files into po template (.pot) file. All translators need to care about is just translating po files. Afterwards, <code><a href="/docs/linux/man/8-intltool-merge/">intltool-merge</a></code>(8) will merge localized strings into those files. Before your software becomes intltool-aware, a few issues have to be sorted out, and <code>intltool-prepare</code> tries to take care of all of them. <code>intltool-prepare</code> will:</p>
<dl>
<dt>&bull;</p>
<dd>Extract all localized strings in .desktop style files (including &quot;.desktop&quot;, &quot;.soundlist&quot;, &quot;.keys&quot; and &quot;.directory&quot;) into corresponding po files.</p>
<dt>&bull;</p>
<dd>Convert the translatable files into templates that don&#8217;t contain any localization.</p>
<dt>&bull;</p>
<dd>Add the list of template files above into <code>POTFILES.in</code>.</p>
<dt>&bull;</p>
<dd>Add the list of old translatable files into <code>.cvsignore</code> (since they will be generated by <i>intltool</i> later).</p>
<dt>&bull;</p>
<dd>Add the rules for generating these files into Makefile.am.</dl>
<p> NOTE: You must change working directory to the top level source directory before running <code>intltool-prepare</code>. </p>
<h2>Options</h2>
<p><i>KEYWORD</i> is a list of additional keywords beside &quot;Name&quot;, &quot;Comment&quot; and &quot;description&quot;. <code>intltool-prepare</code> will recognize any line starting with those <i>KEYWORD</i> and extract localized strings after equal sign (&quot;=&quot;).</p>
<dl>
<dt><code>-x</code></p>
<dd>
<dt><code>&#8211;verbose</code></p>
<dd>Be verbose to give user additional feedback.</p>
<dt><code>-v</code></p>
<dd>
<dt><code>&#8211;version</code></p>
<dd>Show version information.</p>
<dt><code>-h</code></p>
<dd>
<dt><code>&#8211;help</code></p>
<dd>Show usage and basic help information. </p>
</dl>
