<p>ipvsadm-save &#8211; save the IPVS table to stdout</p>
<h2>Synopsis</h2>
<p><code>ipvsadm-save </code>[<code>-n</code>]</p>
<h2>Description</h2>
<p>ipvsadm-save prints the IPVS table to stdout.</p>
<h2>Options</h2>
<p>The option that is recognized by <code>ipvsadm-save</code> is:</p>
<dl>
<dt><code>-n</code></p>
<dd>print out the table in numeric format.</dl>
