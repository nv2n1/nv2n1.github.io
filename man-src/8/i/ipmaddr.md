<p><code>ipmaddr</code> &#8211; adds, deletes, and displays multicast addresses<br />
&nbsp;<wbr></p>
<h2>Synopsis</h2>
<p><code>/usr/sbin/ipmaddr</code> [&lt;<code>operation</code>&gt;] [&lt;<code>args</code>&gt;] </p>
<h2>Note</h2>
<p>This program is obsolete. For replacement check <code>ip maddr</code>.</p>
<h2>Description</h2>
<p>The <code>ipmaddr</code> command can perform one of the following operations: <code>add</code> &#8211; add a multicast address <code>del</code> &#8211; delete a multicast address <code>show</code> &#8211; list multicast addresses </p>
