<p>ipsec__updown.netkey &#8211; klips manipulation script</p>
<h2>Synopsis</h2>
<p><i>_updown</i> is invoked by pluto when it has brought up a new connection. This script is used to insert the appropriate routing entries for IPsec operation. The interface to the script is documented in the pluto man page.</p>
