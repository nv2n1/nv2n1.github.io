<p>xrootd &#8211; eXtended ROOT daemon</p>
<h2>Synopsis</h2>
<pre><code>xrootd</code> [<i>options</i>] [<i>exports</i>]</pre>
<h2>Description</h2>
<p>The <code>xrootd</code> daemon provides LAN/WAN access to data in stand-alone nodes, clustered nodes, as well as globally federated clusters. Usage synopsis can be displayed by typing &quot;<code>xrootd -h</code>&quot;. Complete HTML documentation can be found at </p>
<p> <center> <a rel="nofollow" href="http://xrootd.org/doc/prod/xrd_config.htm">http://xrootd.org/doc/prod/xrd_config.htm</a><br />
 </center></p>
<h2>Notes</h2>
<p>Documentation for all components associated with <code>xrootd</code> can be found at <a rel="nofollow" href="http://xrootd.org/docs.html">http://xrootd.org/docs.html</a></p>
<h2>Diagnostics</h2>
<p>Configuration errors yield an error message and a non-zero exit status. The program never exits upon success. Use the kill command or &quot;/etc/init.d/xrootd stop&quot; to terminate the program.</p>
<h2>License</h2>
<p>License terms can be displayed by typing &quot;<code>xrootd -H</code>&quot;.</p>
<h2>Support Level</h2>
<p>The <code>xrootd</code> daemon is supported by the xrootd collaboration. Contact information can be found at <center> <a rel="nofollow" href="http://xrootd.org/contact.html">http://xrootd.org/contact.html</a><br />
 </center></p>
