<p><code>xqmstats</code> &#8211; Display XFS quota manager statistics from /proc</p>
<h2>Synopsis</h2>
<p><i>/usr/sbin/xqmstats</i></p>
<h2>Description</h2>
<p><code>xqmstat</code> queries the kernel for the XFS Quota Manager dquot statistics. It displays: </p>
<dl>
<dd>
<dl>
<dt>&bull;</p>
<dd>Reclaims</p>
<dt>&bull;</p>
<dd>Missed reclaims</p>
<dt>&bull;</p>
<dd>Dquot dups</p>
<dt>&bull;</p>
<dd>Cache misses</p>
<dt>&bull;</p>
<dd>Cache hits</p>
<dt>&bull;</p>
<dd>Dquot wants</p>
<dt>&bull;</p>
<dd>Shake reclaims</p>
<dt>&bull;</p>
<dd>Inact reclaims</dl>
</dl>
<h2>Options</h2>
<p>None.</p>
