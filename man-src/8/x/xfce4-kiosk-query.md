<p>xfce4-kiosk-query &#8211; Queries Xfce4 kiosk capabilities</p>
<h2>Synopsis</h2>
<p><code>xfce4-kiosk-query</code> [<i>options</i>]<i>module</i>capability&#8230;</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>xfce4-kiosk-query</code> command. </p>
<p> <code>xfce4-kiosk-query</code> is a program that queries the given capabilities of module for the current user and reports whether the user has the capabilities or not. This tool is mainly meant for system administrators to test their Kiosk setup.</p>
<h2>Options</h2>
<p>A summary of options is included below.</p>
<dl>
<dt><code>-h</code></p>
<dd>Show summary of options.</p>
<dt><code>-v</code></p>
<dd>Show version of program.</dl>
