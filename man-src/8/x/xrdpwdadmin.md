<p>xrdpwdadmin &#8211; administer pwd security protocol passwords</p>
<h2>Synopsis</h2>
<pre><code>xrdpwdadmin</code> [<code>-m</code> <i>mode</i>] <i>command</i> [<i>options</i>]</pre>
<h2>Description</h2>
<p>The <code>xrdpwdadmin</code> utility displays and maintains password and auto-login files used by the password (<code>pwd</code>) security protocol. Complete HTML documentation can be found at </p>
<p> <center> <a rel="nofollow" href="http://xrootd.org/doc/prod/sec_config.htm">http://xrootd.org/doc/prod/sec_config.htm</a><br />
 </center></p>
<h2>Notes</h2>
<p>Documentation for all components associated with <code>xrdpwdadmin</code> can be found at <a rel="nofollow" href="http://xrootd.org/docs.html">http://xrootd.org/docs.html</a></p>
<h2>Diagnostics</h2>
<p>Errors yield an error message and a non-zero exit status.</p>

 </center></p>
