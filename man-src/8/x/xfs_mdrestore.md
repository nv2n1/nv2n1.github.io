<p>xfs_mdrestore &#8211; restores an XFS metadump image to a filesystem image</p>
<h2>Synopsis</h2>
<p><code>xfs_mdrestore</code> [ <code>-g</code> ] <i>source</i> <i>target</i><br />
 <code>xfs_mdrestore -V</code></p>
<h2>Description</h2>
<p><code>xfs_mdrestore</code> is a debugging tool that restores a metadata image generated by <code><a href="/docs/linux/man/8-xfs_metadump/">xfs_metadump</a></code>(8) to a filesystem. The <i>source</i> argument specifies the location of the metadump image and the <i>target</i> argument specifies the destination for the filesystem image. If the <i>source</i> is -, then the metadata image is read from stdin. This allows the output of be another program such as a compression application to be redirected to <code>xfs_mdrestore</code>. The <i>target</i> can be either a file or a device. <code>xfs_mdrestore</code> should not be used to restore metadata onto an existing filesystem unless you are completely certain the <i>target</i> can be destroyed. </p>
<h2>Options</h2>
<dl>
<dt><code>-g</code></p>
<dd>Shows restore progress on stdout.</p>
<dt><code>-V</code></p>
<dd>Prints the version number and exits.</dl>
<h2>Diagnostics</h2>
<p><code>xfs_mdrestore</code> returns an exit code of 0 if all the metadata is successfully restored or 1 if an error occurs.</p>
