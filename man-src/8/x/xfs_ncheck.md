<p>xfs_ncheck &#8211; generate pathnames from i-numbers for XFS</p>
<h2>Synopsis</h2>
<p><code>xfs_ncheck</code> [ <code>-i</code> <i>ino</i> ] &#8230; [ <code>-f</code> ] [ <code>-s</code> ] [ <code>-l</code> <i>logdev</i> ] <i>device</i><br />
 <code>xfs_ncheck -V</code></p>
<h2>Description</h2>
<p><code>xfs_ncheck</code> with no <code>-i</code> arguments generates an inode number and pathname list of all files on the given filesystem. Names of directory files are followed by <code>/.</code>. The output is not sorted in any particular order. The filesystem to be examined is specified by the <i>device</i> argument, which should be the disk or volume device for the filesystem. Filesystems stored in files can also be checked, using the <code>-f</code> flag.</p>
<h2>Options</h2>
<dl>
<dt><code>-f</code></p>
<dd>Specifies that the filesystem image to be processed is stored in a regular file at <i>device</i> (see the <code>mkfs.xfs -d</code> <i>file</i> option). This might happen if an image copy of a filesystem has been made into an ordinary file.</p>
<dt><code>-l</code><i> logdev</i></p>
<dd>Specifies the device where the filesystem&#8217;s external log resides. Only for those filesystems which use an external log. See the <code>mkfs.xfs -l</code> option, and refer to <code><a href="/docs/linux/man/5-xfs/">xfs</a></code>(5) for a detailed description of the XFS log.</p>
<dt><code>-s</code></p>
<dd>Limits the report to special files and files with setuserid mode. This option may be used to detect violations of security policy.</p>
<dt><code>-i</code><i> ino</i></p>
<dd>Limits the report to only those files whose inode numbers follow. May be given multiple times to select multiple inode numbers.</p>
<dt><code>-V</code></p>
<dd>Prints the version number and exits.</dl>
<p> If the filesystem is seriously corrupted, or very busy and looks like it is corrupt, a message of the form that would be generated by the <code><a href="/docs/linux/man/8-xfs_db/">xfs_db</a></code>(8) &quot;check&quot; command may appear. </p>
<p> <code>xfs_ncheck</code> is only useful with XFS filesystems.</p>
