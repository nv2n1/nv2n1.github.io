<p>etapro &#8211; Driver for ETA UPS equipment</p>
<h2>Note</h2>
<p>This man page only documents the hardware-specific features of the etapro driver. For information about the core driver, see <code><a href="/docs/linux/man/8-nutupsdrv/">nutupsdrv</a></code>(8).</p>
<h2>Supported Hardware</h2>
<p>This driver supports ETA UPS equipment with the &quot;PRO&quot; option for smart mode.</p>
<h2>Extra Arguments</h2>
<p>This driver does not support any extra settings in the <code><a href="/docs/linux/man/5-ups-conf/">ups.conf</a></code>(5).</p>
