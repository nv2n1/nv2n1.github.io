<p>ecryptfs-manager &#8211; eCryptfs key manager.</p>
<h2>Description</h2>
<p><code>ecryptfs-manager</code> is an application that manages eCryptfs objects such as keys. You can use <code>ecryptfs-manager</code> to ask key modules to generate new keys for you, for instance. </p>
