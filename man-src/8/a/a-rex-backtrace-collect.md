<p>a-rex-backtrace-collect &#8211; processes core file(s) generated by arched and produces backtrace(s). </p>
<h2>Description</h2>
<p><code>a-rex-backtrace-collect</code> processes core file(s) collected in ARC_LOGS_DIR/arccore folder and produces their backtraces. The backtrace(s) are stored in files &lt;core_name&gt;.backtrace. The ARC instalation location can be adjusted using ARC_LOCATION environment variable. The location of configuration file can be specified using ARC_CONFIG environment variable. </p>
<h2>Synopsis</h2>
<p>a-rex-backtrace-collect </p>
<h2>Options</h2>
<p>No options are supported.</p>
