<p>aoe-version &#8211; print AoE-related software version information</p>
<h2>Synopsis</h2>
<pre><code>aoe-version</code></pre>
<h2>Description</h2>
<p>The <i>aoe-version</i> script collects information on running and installed ATA over Ethernet software, displaying a summary.</p>
<h2>Example</h2>
<dl>
<dd>
<pre>ellijay:~# aoe-version 
 aoetools: 17
 installed aoe driver: 50
 running aoe driver: 50</pre>
</dl>
