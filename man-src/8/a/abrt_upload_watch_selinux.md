<p>abrt_upload_watch_selinux &#8211; Security Enhanced Linux Policy for the abrt_upload_watch processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the abrt_upload_watch processes via flexible mandatory access control. The abrt_upload_watch processes execute with the abrt_upload_watch_t SELinux type. You can check if you have these processes running by executing the <code>ps</code> command with the <code>-Z</code> qualifier. For example: <code>ps -eZ | grep abrt_upload_watch_t</code> </p>
<h2>Entrypoints</h2>
<p>The abrt_upload_watch_t SELinux type can be entered via the <code>abrt_upload_watch_exec_t</code> file type. </p>
<p> The default entrypoint paths for the abrt_upload_watch_t domain are the following: </p>

<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. abrt_upload_watch policy is extremely flexible and has several booleans that allow you to manipulate the policy and run abrt_upload_watch with the tightest access possible. </p>
<p> If you want to allow all daemons to write corefiles to /, you must turn on the daemons_dump_core boolean. Disabled by default. </p>
<p> <code>setsebool -P daemons_dump_core 1</code> </p>
<p> If you want to enable cluster mode for daemons, you must turn on the daemons_enable_cluster_mode boolean. Enabled by default. </p>
<p> <code>setsebool -P daemons_enable_cluster_mode 1</code> </p>
<p> If you want to allow all daemons to use tcp wrappers, you must turn on the daemons_use_tcp_wrapper boolean. Disabled by default. </p>
<p> <code>setsebool -P daemons_use_tcp_wrapper 1</code> </p>

<p> <code>setsebool -P daemons_use_tty 1</code> </p>

<h2>Sharing Files</h2>
<p>If you want to share files with multiple domains (Apache, FTP, rsync, Samba), you can set a file context of public_content_t and public_content_rw_t. These context allow any of the above domains to read the content. If you want a particular domain to write to the public_content_rw_t domain, you must set the appropriate boolean.</p>
<dl>
<dt>Allow abrt_upload_watch servers to read the /var/abrt_upload_watch directory by adding the public_content_t file type to the directory and by restoring the file type.</p>
<dd></dl>
<p> <code>semanage fcontext -a -t public_content_t &quot;/var/abrt_upload_watch(/.*)?&quot;</code><br />
 <code>restorecon -F -R -v /var/abrt_upload_watch</code></p>
<dl>
