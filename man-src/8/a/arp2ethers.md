<p>arp2ethers &#8211; convert arpwatch address database to ethers file format</p>
<h2>Synopsis</h2>
<p><code>arp2ethers</code></p>
<h2>Description</h2>
<p><code>arp2ethers</code> converts file <i>arp.dat</i> in the current directory into <code><a href="/docs/linux/man/5-ethers/">ethers</a>(5)</code> format on <i>stdout</i>. Usually <i>arp.dat</i> is an ethernet/ip database file generated by <code><a href="/docs/linux/man/8-arpwatch/">arpwatch</a>(8)</code>. The arpwatch daemon in Debian will create different <i>arp.dat</i> depending on its configuration. All of them will be available at <i>/var/lib/arpwatch/</i>.</p>
<h2>Files</h2>
<pre>/var/lib/arpwatch - default directory for arp.dat
arp.dat - ethernet/ip address database</pre>
