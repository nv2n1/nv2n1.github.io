<p>arpsnmp &#8211; keep track of ethernet/ip address pairings</p>
<h2>Synopsis</h2>
<p><code>arpsnmp</code> [ <code>-d</code> ] [ <code>-f</code> <i>datafile</i> ] [ <code>-e</code> <i>username</i> ] [ <code>-s</code> <i>username</i> ] <i>file</i> [ <i>&#8230;</i> ]</p>
<h2>Description</h2>
<p><code>Arpsnmp</code> keeps track for ethernet/ip address pairings. It syslogs activity and reports certain changes via email. <code>Arpsnmp</code> reads information from a file (usually generated by <code><a href="/docs/linux/man/1-snmpwalk/">snmpwalk</a></code>(1)). The <code>-d</code> flag is used enable debugging. This also inhibits mailing the reports. Instead, they are sent to <i>stderr</i>. The <code>-f</code> flag is used to set the ethernet/ip address database filename. The default is <i>arp.dat</i>. Note that an empty <i>arp.dat</i> file must be created before the first time you run <code>arpsnmp</code>. If the <code>-e </code> flag is used, <code>arpsnmp</code> sends e-mail messages to <i>username</i> rather than the default (root). If a single `-&#8216; character is given for the username, sending of e-mail is suppressed, but logging via syslog is still done as usual. (This can be useful during initial runs, to collect data without being flooded with messages about new stations.) If the <code>-s </code> flag is used, <code>arpsnmp</code> sends e-mail messages with <i>username</i> as the return address, rather than the default (root). </p>
<h2>Report Messages</h2>
<p>(See the <code><a href="/docs/linux/man/8-arpwatch/">arpwatch</a></code>(8) man page for details on the report messages generated by <code><a href="/docs/linux/man/8-arpsnmp/">arpsnmp</a></code>(8).)</p>
<h2>Files</h2>
<pre>/var/lib/arpwatch - default directory
arp.dat - ethernet/ip address database
ethercodes.dat - vendor ethernet block list</pre>
