<p>nordugridmap &#8211; ARC grid-mapfile generator</p>
<h2>Synopsis</h2>
<p><code>nordugridmap</code> [<code>-t</code>, <code>&#8211;test</code>] [<code>-c</code>, <code>&#8211;config</code> <i>FILE</i>] [<code>-h</code>, <code>&#8211;help</code>]</p>
<h2>Description</h2>
<p>The nordugridmap utility is usually run as a crontab entry in order to automatically generate grid-mapfile(s). All information about mapfiles to generate, sources of information and other related options are stored in a single configuration file. Common Nordugrid ARC configuration file <code><a href="/docs/linux/man/5-arc-conf/">arc.conf</a></code>(5) used if not redefined via command line option. </p>
<h2>Extended Description</h2>
<p>The sources of information supported by nordugridmap are the following:</p>
<dl>
<dt><code>http(s)://</code></p>
<dd>URL to plain text file. File should contain a list of DNs &#8211; one DN per line.</p>
<dt><code>voms(s)://</code></p>
<dd>URL to VOMS-Admin interface.</p>
<dt><code>nordugrid</code></p>
<dd>NorduGrid VO members</p>
<dt><code>file://</code></p>
<dd>Local file (stand-alone or dynamicaly generated by nordugridmap). File should contain a list of DNs with optional mapped unixid: &quot;user DN&quot; [mapped unixID]</p>
<dt><code>vo://</code></p>
<dd>Reference to another VO configuration block</dl>
<p> We are STRONGLY RECOMMEND TO READ tne Nordugruid ARC documentation, <code><a href="/docs/linux/man/5-arc-conf/">arc.conf</a></code>(5) manual page and/or the <code>arc.conf.reference</code> to learn all details about nordugridmap configuration options usage.</p>
<h2>Options</h2>
<dl>
<dt><code>-t</code>, <code>&#8211;test</code></p>
<dd>Does not actually create grid-mapfile(s), but perform test run in debug mode.</p>
<dt><code>-c</code>, <code>&#8211;config </code><i>FILE</i></p>
<dd>Specifies the configuration file to be used. By default the <code><a href="/docs/linux/man/5-arc-conf/">arc.conf</a></code>(5) is used. nordugridmap utilize [nordugridmap] section for general options fine-tunung and processes all the [vo] blocks from the config.</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>Show help options</dl>
