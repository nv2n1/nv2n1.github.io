<p>ngc &#8211; Next Generation init Control.</p>
<h2>Synopsis</h2>
<p><code>ngc</code> &#8211;<i>h</i></p>
<h2>Description</h2>
<p>ngdc is the same as ngc, but is controlling a faker or debug initng that does not run as pid 1.</p>
<h2>Options</h2>
<p>The options that your ngdc command can do, varies to what plugins that are added.</p>
<dl>
<dt>Please do ngdc -h, to get a full list and description.</p>
<dd></dl>
