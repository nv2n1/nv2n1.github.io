<p>ntfs-config &#8211; Enable/disable write support for NTFS with a simple click.</p>
<h2>Synopsis</h2>
<p><code>ntfs-config</code> [<i>options</i>]</p>
<h2>Description</h2>
<p>Add write support for all your NTFS partition with this tool. It will configure them to use the open source driver ntfs-3g that allow full read/write capability.</p>
<h2>Options</h2>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>show this help message and exit</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd>Show version of the application and exit.</p>
<dt><code>-q</code> DEVICE, <code>&#8211;query-database</code>=<i>DEVICE</i></p>
<dd>Query database for DEVICE. Set DEVICE to all to print full database.</p>
<dt><code>-d</code>, <code>&#8211;debug</code></p>
<dd>Print debugging information.</dl>
