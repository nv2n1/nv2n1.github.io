<p>nepomukserver &#8211; KDE daemon &#8211; The Nepomuk server application.</p>
<h2>Synopsis</h2>
<dl>
<dt> <code>nepomukserver</code> [&#8211;help] [Generic options] [Qt(TM)-options] [KDE-options]</dl>
<h2>Description</h2>
<p><code>nepomukserver</code></p>
<dd>starts the Nepomuk server which manages all Nepomuk services and provides a DBus API. </p>
<p> It uses <code>nepomukservicestub</code> to run all configured Nepomuk services.</p>
<h2>Generic Options</h2>
<p><code>&#8211;author</code></p>
<dl>
<dd>Show author information.</dl>
<p> <code>&#8211;help</code></p>
<dl>
<dd>Show help about options.</dl>
<p> <code>&#8211;help-all</code></p>
<dl>
<dd>Show all options.</dl>
<p> <code>&#8211;help-kde</code></p>
<dl>
<dd>Show KDE specific options.</dl>
<p> <code>&#8211;help-qt</code></p>
<dl>
<dd>Show Qt(TM) specific options.</dl>
<p> <code>&#8211;license</code></p>
<dl>
<dd>Show license information.</dl>
<p> <code>-v</code> <code>&#8211;version</code></p>
<dl>
