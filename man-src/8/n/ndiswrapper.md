<p>ndiswrapper &#8211; install/modify/remove ndis driver (wrapper)</p>
<h2>Synopsis</h2>
<p><code>ndiswrapper</code> [<i>options</i>]</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>ndiswrapper</code> command. </p>
<p> <code>ndiswrapper</code> is a wrapper for the version-specific <code>ndiswrapper-X.X</code> programs (where -X.X is the version number of the utils; ie, <code>ndiswrapper-1.8</code>). It simply figures out which version should be called, and calls the appropriate binary. Each version&#8217;s man page contains its usage details.</p>
