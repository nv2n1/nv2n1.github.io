<p>newaliases &#8211; update /etc/aliases database</p>
<h2>Synopsis</h2>
<p><code>newaliases</code></p>
<h2>Description</h2>
<p>This is a link to the ssmtp binary. It invokes <code>/usr/sbin/sendmail</code> with the <code>-bi</code> option. It is provided for compatibility with the sendmail program. </p>
<p> In Fedora sSMTP supports /etc/aliases as a text file so there is no need to regenerate a database.</p>
