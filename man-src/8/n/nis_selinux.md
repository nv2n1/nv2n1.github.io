<p>ypbind_selinux &#8211; Security Enhanced Linux Policy for the ypbind processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the ypbind processes via flexible mandatory access control. </p>
<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. ypbind policy is extremely flexible and has several booleans that allow you to manipulate the policy and run ypbind with the tightest access possible. </p>
<p> If you want to allow system to run with NI, you must turn on the allow_ypbind boolean. </p>
<p> <code>setsebool -P allow_ypbind 1</code></p>
