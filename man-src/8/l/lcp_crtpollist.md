<p>lcp_crtpollist &#8211; create an Intel(R) TXT policy list</p>
<h2>Synopsis</h2>
<p><code>lcp_crtpollist</code> <i>COMMAND</i> [<i>OPTION</i>]</p>
<h2>Description</h2>
<p><code>lcp_crtpollist</code> is used to create an Intel(R) TXT policy list.</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;create</code></p>
<dd>Create an TXT policy list. The following options are available:</p>
<dl>
<dd>
<dl>
<dt><code>&#8211;out&nbsp;<wbr></code><i>file</i></p>
<dd>policy list file</p>
<dt>[<code>&#8211;ver&nbsp;<wbr></code><i>version</i>]</p>
<dd>version</p>
<dt>[<i>file</i>]&#8230;</p>
<dd>policy element files</dl>
</dl>
<dt><code>&#8211;sigh</code></p>
<dd>Sign an TXT policy list.</p>
<dl>
<dd>
<dl>
<dt><code>&#8211;pub </code><i>key-file</i></p>
<dd>PEM file of public key</p>
<dt><code>&#8211;out&nbsp;<wbr></code><i>file</i></p>
<dd>policy list file</p>
<dt>[<code>&#8211;priv </code><i>key-file</i>]</p>
<dd>PEM file of private key</p>
<dt>[<code>&#8211;rev </code><i>rev-ctr</i>]</p>
<dd>revocation counter value</p>
<dt>[<code>&#8211;nosig</code>]</p>
<dd>don&#8217;t add SigBlock</dl>
</dl>
<dt><code>&#8211;addsig</code></p>
<dd>
<dl>
<dd>
<dl>
<dt><code>&#8211;sig&nbsp;<wbr></code><i>file</i></p>
<dd>file containing signature (big-endian)</p>
<dt><code>&#8211;out&nbsp;<wbr></code><i>file</i></p>
<dd>policy list file</dl>
</dl>
<dt><code>&#8211;show </code><i>file</i></p>
<dd>policy list file</p>
<dt><code>&#8211;help</code></p>
<dd>Print out the help message.</p>
<dt><code>&#8211;verbose</code></p>
<dd>Enable verbose output; can be specified with any command.</dl>
<h2>Examples</h2>
<h3>Create policy list:</h3>
<p>Assuming there have been two element file <i>mle.elt</i> and <i>pconf.elt</i> generated by <code><a href="/docs/linux/man/8-lcp_crtpolelt/">lcp_crtpolelt</a></code>(8) The following example can create an unsigned policy list: <code>lcp_crtpollist &#8211;create &#8211;out </code><i>list-unsig.lst mle.elt pconf.elt </i></p>
<h3>Sign policy list:</h3>
<p>Unsigned policy list can be signed by the command <code><a href="/docs/linux/man/8-lcp_crtpollist/">lcp_crtpollist</a></code>(8) or <code><a href="/docs/linux/man/1-openssl/">openssl</a></code>(1). The <code><a href="/docs/linux/man/1-openssl/">openssl</a></code>(1) signing is supported for cases where the signing environment is separate from the policy creation environment and the software allowed to run there is strictly controlled and already supports <code><a href="/docs/linux/man/1-openssl/">openssl</a></code>(1). The following example uses <code><a href="/docs/linux/man/1-openssl/">openssl</a></code>(1) to sign the list: </p>
<table>
<tr VALIGN=top>
<td>1</td>
<td> <code>openssl rsa -pubout -in </code><i>privkey.pem </i><code>-out </code><i>pubkey.pem </i>
</td>
</tr>
<tr VALIGN=top>
<td>2</td>
<td> <code>cp </code><i>list-unsig.lst list-sig.lst </i>
</td>
</tr>
<tr VALIGN=top>
<td>3</td>
<td> <code>lcp_crtpollist &#8211;sigh &#8211;pub </code><i>pubkey.pem </i><code>&#8211;nosig &#8211;out </code><i>list-sig.lst </i>
</td>
</tr>
<tr VALIGN=top>
<td>4</td>
<td> <code>openssl genrsa -out </code><i>privkey.pem 2048 </i>
</td>
</tr>
<tr VALIGN=top>
<td>5</td>
<td> <code>openssl dgst -sha1 -sign </code><i>privkey.pem </i><code>-out </code><i>list.sig list-sig.lst </i>
</td>
</tr>
<tr VALIGN=top>
<td>6</td>
<td> <code>lcp_crtpollist &#8211;addsig &#8211;sig </code><i>list.sig </i><code>&#8211;out </code><i>list-sig.lst </i>
</td>
</tr>
</table>
<p> <code>lcp_crtpollist</code> can also be used to sigh a policy list. The following example are intended to be mutually exclusive with the preceding example. </p>
<table>
<tr VALIGN=top>
<td>1</td>
<td> <code>openssl genrsa -out </code><i>privkey.pem 2048 </i>
</td>
</tr>
<tr VALIGN=top>
<td>2</td>
<td> <code>openssl rsa -pubout -in </code><i>privkey.pem </i><code>-out </code><i>pubkey.pem </i>
</td>
</tr>
<tr VALIGN=top>
<td>3</td>
<td> <code>cp </code><i>list-unsig.lst list-sig.lst </i>
</td>
</tr>
<tr VALIGN=top>
<td>4</td>
<td> <code>lcp_crtpollist &#8211;sign &#8211;pub </code><i>pubkey.pem </i><code>&#8211;priv </code><i>privkey.pem </i><code>&#8211;out </code><i>list-sig.lst </i>
</td>
</tr>
</table>
