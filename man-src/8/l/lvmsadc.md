<p>lvmsadc &#8212; LVM system activity data collector</p>
<h2>Synopsis</h2>
<p><code>lvmsadc</code></p>
<h2>Description</h2>
<p>lvmsadc is not supported under LVM2. The device-mapper statistics facility provides similar performance metrics using the <code><a href="/docs/linux/man/8-dmstats/">dmstats</a>(8)</code> command.</p>
