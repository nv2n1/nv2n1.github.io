<p>loadndisdriver &#8211; load ndis driver (wrapper)</p>
<h2>Synopsis</h2>
<p><code>loadndisdriver</code> [<i>options</i>]</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>loadndisdriver</code> command. </p>
<p> <code>loadndisdriver</code> is a wrapper for the version-specific <code>loadndisdriver-X.X</code> programs (where -X.X is the version number of the utils; ie, <code>loadndisdriver-1.8</code>). It simply figures out which version should be called, and calls the appropriate binary. Each version&#8217;s man page contains its usage details.</p>
