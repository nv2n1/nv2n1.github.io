<p>grub-md5-crypt &#8211; Encrypt a password in MD5 format</p>
<h2>Synopsis</h2>
<p><code>grub-md5-crypt</code> [<i>OPTION</i>]</p>
<h2>Description</h2>
<p>Encrypt a password in MD5 format.</p>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>print this message and exit</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd>print the version information and exit</p>
<dt><code>&#8211;grub-shell</code>=<i>FILE</i></p>
<dd>use FILE as the grub shell</dl>
