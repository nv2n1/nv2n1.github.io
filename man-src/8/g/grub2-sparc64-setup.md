<p><code>grub-sparc64-setup</code> &#8212; Set up a device to boot a sparc64 GRUB image. </p>
<h2>Synopsis</h2>
<p><code>grub-sparc64-setup</code> [OPTIONS]. </p>
<h2>Description</h2>
<p>You should not normally run this program directly. Use grub-install instead. </p>
