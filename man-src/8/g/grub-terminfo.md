<p>grub-terminfo &#8211; Generate a terminfo command from a terminfo name</p>
<h2>Synopsis</h2>
<p><code>grub-terminfo</code> <i>TERMNAME</i></p>
<h2>Description</h2>
<p>Generate a terminfo command from a terminfo name.</p>
<dl>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>print this message and exit</p>
<dt><code>-v</code>, <code>&#8211;version</code></p>
<dd>print the version information and exit</dl>
