<p><code>gpt-uninstall</code> &#8211; Uninstall any <font SIZE="-1">GPT</font> package.</p>
<h2>Synopsis</h2>
<p>gpt-uninstall [&#8211;force &#8211;help -name ] pkgname-flavor-pkgtype</p>
<h2>Description</h2>
<p><code>gpt-uninstall</code> will uninstall a package from the system.</p>
<h2>Options</h2>
<dl>
<dt><code>-force</code></p>
<dd>This will force actions to take place.</p>
<dt><code>-native</code></p>
<dd>Use native package manager (Only works with rpm).</p>
<dt><code>pkgname-flavor-pkgtype</code></p>
<dd>Expression describing the packages that should be removed.</p>
<dt><code>-help</code></p>
<dd>Print a brief help message and exits.</p>
<dt><code>-man</code></p>
<dd>Prints the manual page and exits.</p>
<dt><code>-version</code></p>
<dd>Prints the version of <font SIZE="-1">GPT</font> and exits.</dl>
<h2>Examples</h2>
<pre> gpt-uninstall -name=foo</pre>
<p>removes all flavors and package types with the name &#8220;foo&#8221;. </p>
<pre> gpt-uninstall foo</pre>
<p>Also removes all flavors and package types with the name &#8220;foo&#8221;. </p>
<pre> gpt-uninstall 'foo-*-*'</pre>
<p>A third way of typing the same uninstall. Note the single quotes. </p>
<pre> gpt-uninstall '*-noflavor-*'</pre>
<p>Remove all of the packages with a &#8216;noflavor&#8217; build flavor. </p>
<pre> gpt-uninstall '*-*-*'</pre>
<p>Remove all packages. Note that files generated by gpt-postinstall will not be removed</p>
<h2>Bugs</h2>
<p>Currently the flavor check that gpt-uninstall uses only works if the flavor is installed by gpt-build. And so for example: </p>
<pre> gpt-uninstall foo-gcc32-*</pre>
<p>will <code>not</code> work. The work around is to uninstall the packages individually using something like: </p>
<pre> gpt-uninstall -name=foo -flavor=gcc32 -pkgtype=pgm</pre>
<p>Or use a wild card for the flavor to uninstall all flavors of the package. </p>
<pre> gpt-uninstall foo-*-*</pre>
