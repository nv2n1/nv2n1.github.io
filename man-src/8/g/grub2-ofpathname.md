<p><code>grub-ofpathname</code> &#8212; Generate an IEEE-1275 device path for a specified device. </p>
<h2>Synopsis</h2>
<p><code>grub-ofpathname</code> <i>DEVICE</i> </p>
<h2>Description</h2>
<p><code>grub-ofpathname</code> generates an IEEE-1275 device path for the specified <i>DEVICE</i>. </p>
