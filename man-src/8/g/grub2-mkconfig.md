<p><code>grub-mkconfig</code> &#8212; Generate a GRUB configuration file. </p>
<h2>Synopsis</h2>
<p><code>grub-mkconfig</code> [-o | &#8211;output=<i>FILE</i>] </p>
<h2>Description</h2>
<p><code>grub-mkconfig</code> generates a configuration file for GRUB. </p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;output</code>=<i>FILE</i></p>
<dd>Write generated output to <i>FILE</i>. </p>
</dl>
