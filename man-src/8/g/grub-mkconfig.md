<p>grub-mkconfig &#8211; generate a GRUB configuration file</p>
<h2>Synopsis</h2>
<p><code>grub-mkconfig</code> [<i>,OPTION/</i>]</p>
<h2>Description</h2>
<p>Generate a grub config file</p>
<dl>
<dt><code>-o</code>, <code>&#8211;output</code>=<i>,FILE/</i></p>
<dd>output generated config to FILE [default=stdout]</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>print this message and exit</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd>print the version information and exit</dl>
