<p>dahdi_tool &#8211; Shows status of DAHDI interfaces</p>
<h2>Synopsis</h2>
<p><code>dahdi_tool</code> </p>
<h2>Description</h2>
<p>dahdi_tool shows the current status the DAHDI inteface cards plugged to the computer. It displays values like Current Alarms, SyncSource, Tx/Rx Levels for each DAHDI interface. </p>
