<p>qemu_selinux &#8211; Security Enhanced Linux Policy for the qemu processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the qemu processes via flexible mandatory access control. </p>
<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. qemu policy is extremely flexible and has several booleans that allow you to manipulate the policy and run qemu with the tightest access possible. </p>
<p> If you want to allow qemu to use cifs/Samba file system, you must turn on the qemu_use_cifs boolean. </p>
<p> <code>setsebool -P qemu_use_cifs 1</code> </p>
<p> If you want to allow qemu to use serial/parallel communication port, you must turn on the qemu_use_comm boolean. </p>
<p> <code>setsebool -P qemu_use_comm 1</code> </p>
<p> If you want to allow qemu to use nfs file system, you must turn on the qemu_use_nfs boolean. </p>
<p> <code>setsebool -P qemu_use_nfs 1</code> </p>
<p> If you want to allow qemu to use usb device, you must turn on the qemu_use_usb boolean. </p>
<p> <code>setsebool -P qemu_use_usb 1</code> </p>
<p> If you want to allow qemu to connect fully to the networ, you must turn on the qemu_full_network boolean. </p>
<p> <code>setsebool -P qemu_full_network 1</code> </p>
<p> If you want to allow xend to run qemu-dm. Not required if using paravirt and no vfb, you must turn on the xend_run_qemu boolean. </p>
<p> <code>setsebool -P xend_run_qemu 1</code></p>
