<p>upsimage.cgi &#8211; Image-generating helper for upsstats.cgi</p>
<h2>Synopsis</h2>
<p><code>upsimage.cgi</code> </p>
<h2>Note</h2>
<p>As a CGI program, this should be invoked through your web server. If you run it from the command line, it will either complain about unauthorized access or spew a PNG at you.</p>
<h2>Description</h2>
<p><code>upsimage.cgi</code> generates the graphical bars that make up the right side of the page generated by <code><a href="/docs/linux/man/8-upsstats-cgi/">upsstats.cgi</a></code>(8). These represent the current battery charge, utility voltage, and UPS load where available. The images are in PNG format, and are created by linking to Boutell&#8217;s excellent gd library. </p>
<h2>Access Control</h2>
<p>upsstats will only talk to <code><a href="/docs/linux/man/8-upsd/">upsd</a></code>(8) servers that have been defined in your <code><a href="/docs/linux/man/5-hosts-conf/">hosts.conf</a></code>(5). If it complains about &quot;Access to that host is not authorized&quot;, check that file first.</p>
