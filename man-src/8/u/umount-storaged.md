<p>umount.storaged &#8211; unmount file systems that have been mounted by storaged</p>
<h2>Description</h2>
<p>The <code>umount.storaged</code> program is a helper for the <code><a href="/docs/linux/man/8-umount/">umount</a></code>(8) program. Its purpose is to clean up automatically created directories created at file system mount-time. It should never be called directly.</p>
