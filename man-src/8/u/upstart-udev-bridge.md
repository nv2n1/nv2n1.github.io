<p>upstart-udev-bridge &#8211; Bridge between Upstart and udev</p>
<h2>Synopsis</h2>
<p><code>upstart-udev-bridge</code> [<i>OPTIONS</i>]&#8230;</p>
<h2>Description</h2>
<p><code>upstart-udev-bridge</code> receives information about kernel uevents that <code><a href="/docs/linux/man/8-udev/">udev</a></code>(8) has completed and creates <code><a href="/docs/linux/man/8-init/">init</a></code>(8) events for them. </p>
<p> It emits events which match the pattern &quot;<i>S</i>-device-<i>A</i>&quot; where &#8216;S&#8217; is the udev <i>subsystem</i> and &#8216;A&#8217; is one of <i>added</i>, <i>changed</i> or <i>removed</i>, which correspond to the past tense of the udev &#8216;action&#8217;. </p>
<p> See <code><a href="/docs/linux/man/7-udev/">udev</a></code>(7) and for further details. </p>
<p> Assuming <i>/sys</i> is mounted, possible values for <i>subsystem</i> for your system are viewable via <i>/sys/class/</i>.</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;daemon</code></p>
<dd>Detach and run in the background.</p>
<dt><code>&#8211;debug</code></p>
<dd>Enable debugging output.</p>
<dt><code>&#8211;help</code></p>
<dd>Show brief usage summary.</p>
<dt><code>&#8211;no-strip</code></p>
<dd>Do not modify udev message contents. By default, all udev data will have non-printable bytes removed. This option reverts the behaviour to not modifying the data in any way. This option is not recommended since specifying it <i>could</i> result in <code><a href="/docs/linux/man/7-udev/">udev</a></code>(7) events not being emitted as Upstart events should any of your hardware expose non-printable characters to the kernel. You can establish whether this is happening by running <i>without</i> specifying this option but with the <code>&#8211;debug</code> option.</p>
<dt><code>&#8211;verbose</code></p>
<dd>Enable verbose output.</dl>
<h2>Examples</h2>
<p>Some examples of Upstart events generated by this bridge:</p>
<dl>
<dt>net-device-added</p>
<dd>Event emitted when a network device is added.</p>
<dt>net-device-removed</p>
<dd>Event emitted when a network device is removed.</p>
<dt>graphics-device-added</p>
<dd>Event emitted when a graphics device is available to the system.</dl>
