<p>update-catalog &#8211; create or update entry in SGML catalog file</p>
<h2>Synopsis</h2>
<p><code>update-catalog</code> [<i>options</i>] <code>&#8211;add</code> <i>centralized_catalog ordinary_catalog</i> </p>
<p> <code>update-catalog</code> [<i>options</i>] <code>&#8211;remove</code> <i>centralized_catalog ordinary_catalog</i> </p>
<p> <code>update-catalog</code> [<i>options</i>] <code>&#8211;update-super</code></p>
<h2>Description</h2>
<p><code>update-catalog</code> inserts, updates or removes entries in the SGML centralized catalogs located in <i>/etc/sgml</i>. To change the SGML super catalog located in <i>/etc/sgml/catalog</i> modify the directory contents of <i>/etc/sgml</i> to contain new files or symbolic links having a <code>.cat</code> extension or remove (or move) existing centralized catalogs and regenerate the super catalog using the <code>&#8211;update-super</code> option. See section <code>SUPER CATALOG</code> for details on the generation process.</p>
<h2>Options</h2>
<dl>
<dt><code>&#8211;add</code></p>
<dd>Adds an entry for the <i>ordinary_catalog</i> in the <i>centralized_catalog</i>.</p>
<dt><code>&#8211;remove</code></p>
<dd>Removes the entry for the <i>ordinary_catalog</i> from the <i>centralized_catalog</i>.</p>
<dt><code>&#8211;update-super</code></p>
<dd>Regenerates the SGML super catalog from the contents of the <i>/etc/sgml</i> directory. See section <code>SUPER CATALOG</code> for details on the super catalog generation.</p>
<dt><code>&#8211;quiet</code></p>
<dd>Prevents the usual diagnostic output.</p>
<dt><code>&#8211;test</code></p>
<dd>Prevents the update of the catalog and writes the resulting SGML catalog to standard output.</p>
<dt><code>&#8211;version</code></p>
<dd>Displays the version information and exits.</p>
<dt><code>&#8211;help</code></p>
<dd>Display the usage information and exits.</dl>
<h2>Super Catalog</h2>
<p>The super-catalog located in <i>/etc/sgml/catalog</i> cannot be directly modified. It is generated by the <i>update-catalog</i> <i>&#8211;update-super</i> command. The generation considers files in the <i>/etc/sgml</i> directory that have a <code>.cat</code> extension. For instance files ending in .old or .disabled are not considered. Before adding a catalog to the super catalog it is parsed and verified in order to not corrupt the super catalog. All referenced catalogs are verified to actually exist. If the check fails, a message is printed and the complete catalog is ignored. This check ensures that a catalog from a package, which is removed but not purged, is removed from the super catalog.</p>
