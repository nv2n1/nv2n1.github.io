<p>usb-creator-gtk &#8211; Ubuntu startup disk creation tool for Gtk+</p>
<h2>Synopsis</h2>
<p><code>usb-creator-gtk</code> [ -i | &#8211;iso &lt;img&gt; ]<br />
&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;<wbr>&nbsp;[&nbsp;-h | &#8211;help&nbsp;]&nbsp;[&nbsp;&#8211;version&nbsp;]</p>
<h2>Description</h2>
<p><code>usb-creator-gtk</code> takes an Ubuntu CD image file as input and writes it out in a usable form to a removable disk.</p>
<h2>Options</h2>
<dl>
<dt><code>-i, &#8211;iso &lt;img&gt;</code></p>
<dd>Provide a source image to pre- populate the UI.</p>
<dt><code>-h,</code>&#8211;help</p>
<dd>Print a summary of command line options and exit.</p>
<dt><code>&#8211;version</code></p>
<dd>Print the current version and exit.</dl>
