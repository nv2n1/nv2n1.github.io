<p>user_wine_selinux &#8211; Security Enhanced Linux Policy for the user_wine processes</p>
<h2>Description</h2>
<p>Security-Enhanced Linux secures the user_wine processes via flexible mandatory access control. The user_wine processes execute with the user_wine_t SELinux type. You can check if you have these processes running by executing the <code>ps</code> command with the <code>-Z</code> qualifier. For example: <code>ps -eZ | grep user_wine_t</code> </p>
<h2>Entrypoints</h2>
<p>The user_wine_t SELinux type can be entered via the <code>user_home_t, mount_ecryptfs_exec_t, wine_exec_t, mount_exec_t</code> file types. </p>
<p> The default entrypoint paths for the user_wine_t domain are the following: </p>
<p> /home/[^/]+/.+, /usr/sbin/mount.ecryptfs, /usr/sbin/umount.ecryptfs, /usr/sbin/mount.ecryptfs_private, /usr/sbin/umount.ecryptfs_private, /usr/bin/wine.*, /opt/teamviewer(/.*)?/bin/wine.*, /opt/google/picasa(/.*)?/bin/wdi, /opt/google/picasa(/.*)?/bin/wine.*, /opt/google/picasa(/.*)?/bin/msiexec, /opt/google/picasa(/.*)?/bin/notepad, /opt/google/picasa(/.*)?/bin/progman, /opt/google/picasa(/.*)?/bin/regedit, /opt/google/picasa(/.*)?/bin/regsvr32, /opt/google/picasa(/.*)?/Picasa3/.*exe, /opt/google/picasa(/.*)?/bin/uninstaller, /opt/cxoffice/bin/wine.*, /opt/picasa/wine/bin/wine.*, /usr/bin/msiexec, /usr/bin/notepad, /usr/bin/regedit, /usr/bin/regsvr32, /usr/bin/uninstaller, /home/[^/]+/cxoffice/bin/wine.+, /bin/mount.*, /bin/umount.*, /sbin/mount.*, /sbin/umount.*, /usr/bin/mount.*, /usr/bin/umount.*, /usr/sbin/mount.*, /usr/sbin/umount.*</p>

<h2>Booleans</h2>
<p>SELinux policy is customizable based on least access required. user_wine policy is extremely flexible and has several booleans that allow you to manipulate the policy and run user_wine with the tightest access possible. </p>
