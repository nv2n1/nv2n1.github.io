<p>vcstime &#8211; Show time in upper right hand corner of the console screen</p>
<h2>Synopsis</h2>
<p><code>vcstime</code> </p>
<h2>Description</h2>
<p><code>vcstime</code> shows the current time in the upper right-hand corner of the console screen. This simple program shows the current time in the corner of the console screen. It needs to be run by root, in order to have write permissions to <i>/dev/vcsa</i> </p>
