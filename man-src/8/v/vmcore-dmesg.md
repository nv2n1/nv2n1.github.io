<p>vmcore-dmesg &#8211; This is just a placeholder until real man page has been written</p>
<h2>Synopsis</h2>
<p><code>vmcore-dmesg</code> vmcore</p>
<h2>Description</h2>
<p><code>vmcore-dmesg</code> extracts the dmesg from a vmcore and write it to standard out. <code>vmcore-dmesg</code> works against either <code>/proc/vmcore</code> in a crash dump capture context or a copy of <code>/proc/vmcore</code> that has been saved for later analysis. A single build of <code>vmcore-dmesg</code> should work against any linux vmcore written created on any architecture. </p>
