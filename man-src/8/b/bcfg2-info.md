<p>bcfg2-info &#8211; Creates a local version of the bcfg2 server core for state observation</p>
<h2>Synopsis</h2>
<p><code>bcfg2-info [-C &lt;config file&gt;] [-h]</code></p>
<h2>Description</h2>
<p><code>bcfg2-info</code> Instantiate an instance of the Bcfg2 core for data examination and debugging purposes.</p>
<h2>Options</h2>
<p><code>-C &lt;config file&gt;</code></p>
<dl>
<dd>Specify an alternative location for bcfg2.conf. (Default /etc/bcfg2.conf)</dl>
<p> <code>-h</code></p>
<dl>
<dd>Give a bit of help about the command line arguments and options. After this bcfg2-info exits.</dl>
