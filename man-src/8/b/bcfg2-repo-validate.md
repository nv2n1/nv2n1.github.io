<p>bcfg2-repo-validate &#8211; Check Bcfg2 repository data against data schemas</p>
<h2>Synopsis</h2>
<p><code>bcfg2-repo-validate</code> <i>[-v] </i></p>
<h2>Description</h2>
<p><code>bcfg2-repo-validate</code> This script checks data against schemas, and it quite helpful in finding typos or malformed data.</p>
<h2>Options</h2>
<p><code>-C </code></p>
<dl>
<dd>Specify path to bcfg2.conf (default /etc/bcfg2.conf)</dl>
