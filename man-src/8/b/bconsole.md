<p>&nbsp;<wbr>bconsole &#8211; Bacula&#8217;s management Console</p>
<h2>Synopsis</h2>
<p><code>bconsole</code> [options]</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>bconsole</code> command. </p>
<h2>Options</h2>
<dl>
<dt><code>-D&nbsp;<wbr></code><i>dir</i></p>
<dd>Select a Director.</p>
<dt><code>-l</code></p>
<dd>List defined Directors.</p>
<dt><code>-c&nbsp;<wbr></code><i>config</i></p>
<dd>Specify configuration file.</p>
<dt><code>-d&nbsp;<wbr></code><i>nn</i></p>
<dd>Set debug level to <i>nn</i>.</p>
<dt><code>-dt</code></p>
<dd>Print timestamp in debug output.</p>
<dt><code>-n</code></p>
<dd>No conio (for scripting).</p>
<dt><code>-s</code></p>
<dd>No signals (for debugging).</p>
<dd>Set command execution timeout to <i>nn</i> seconds</p>
<dt><code>-t</code></p>
<dd>Test the configuration file and report errors.</p>
<dt><code>-?</code></p>
<dd>Show version and usage of program.</dl>
