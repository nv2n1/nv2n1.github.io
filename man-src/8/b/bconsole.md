<p>&nbsp;<wbr>bconsole &#8211; Bacula&#8217;s management Console</p>
<h2>Synopsis</h2>
<p><code>bconsole</code> [options]</p>
<h2>Description</h2>
<p>This manual page documents briefly the <code>bconsole</code> command. </p>
<h2>Options</h2>
<dl>
<dt><code>-D&nbsp;<wbr></code><i>dir</i></dt>
<dd>Select a Director.</dd>
<dt><code>-l</code></dt>
<dd>List defined Directors.</dd>
<dt><code>-c&nbsp;<wbr></code><i>config</i></dt>
<dd>Specify configuration file.</dd>
<dt><code>-d&nbsp;<wbr></code><i>nn</i></dt>
<dd>Set debug level to <i>nn</i>.</dd>
<dt><code>-dt</code></dt>
<dd>Print timestamp in debug output.</dd>
<dt><code>-n</code></dt>
<dd>No conio (for scripting).</dd>
<dt><code>-s</code></dt>
<dd>No signals (for debugging).</dd>
<dd>Set command execution timeout to <i>nn</i> seconds</dd>
<dt><code>-t</code></dt>
<dd>Test the configuration file and report errors.</dd>
<dt><code>-?</code></dt>
<dd>Show version and usage of program.</dd></dl>
