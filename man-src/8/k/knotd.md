<p><code>knotd</code> &#8211; Knot DNS server daemon</p>
<h2>Synopsis</h2>
<p><code>knotd</code> [<i>parameters</i>]</p>
<h2>Description</h2>
<h3>Parameters:</h3>
<dl>
<dt><code>-c</code>, <code>&#8211;config</code> <i>file</i></p>
<dd>Select configuration file.</p>
<dt><code>-d</code>, <code>&#8211;daemonize</code>=[<i>dir</i>]</p>
<dd>Run server as a daemon. Working directory may be set.</p>
<dt><code>-V</code>, <code>&#8211;version</code></p>
<dd>Print version of the server.</p>
<dt><code>-h</code>, <code>&#8211;help</code></p>
<dd>Print help and usage.</dl>
