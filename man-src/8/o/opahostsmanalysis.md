<p>opahostsmanalysis </p>
<p> <code>(All)</code> Performs analysis against the local server only. It is assumed that both the host SM and the FastFabric are installed on the same system. </p>
<p> The host SM analysis tool checks the following:</p>
<dl>
<dt>&bull;</p>
<dd>Host SM software version</p>
<dt>&bull;</p>
<dd>Host SM configuration file (simple text compare using FF_DIFF_CMD)</p>
<dt>&bull;</p>
<dd>Host SM health (for example, is it running?)</dl>
<h2>Syntax</h2>
<p>opahostsmanalysis [-b|-e] [-s] [-d <i>dir</i>]</p>
<h2>Options</h2>
<dl>
<dt>&#8211;help</p>
<dd>Produces full help text.</p>
<dt>-b</p>
<dd>Baseline mode. Default is the compare/check mode.</p>
<dt>-e</p>
<dd>Evaluates health only. Default is the compare/check mode.</p>
<dt>-s</p>
<dd>Saves history of failures (errors/differences).</p>
<dt>-d <i>dir</i></p>
<dd>Top-level directory for saving baseline and history of failed checks. Default = /var/lib/opa-ff/analysis</dl>
<h2>Example</h2>
<p>opahostsmanalysis</p>
<h2>Environment Variables</h2>
<p>The following environment variables are also used by this command:</p>
<dl>
<dt><code>FF_ANALYSIS_DIR</code></p>
<dd>Top-level directory for baselines and failed health checks.</p>
<dt><code>FF_CURTIME</code></p>
<dd>Timestamp to use on the directory created in FF_DIFF_CMD.</p>
<dt><code>FF_DIFF_CMD</code></p>
<dd>Linux* command to use to compare baseline to latest snapshot.</dl>
<h2>Details</h2>
<p>All files generated by opahostsmanalysis start with hostsm in the file name. </p>
<p> The opahostsmanalysis tool generates files such as the following within FF_ANALYSIS_DIR. The actual file names reflect the individual chassis commands that have been configured using the <code>FF_CHASSIS_HEALTH</code> and <code>FF_CHASSIS_CMDS</code> parameters: </p>
<p> <code>Health Check</code> </p>
<dl>
<dt>&bull;</p>
<dd>latest/hostsm.smstatus #8217#8211; Output of the sm_query smShowStatus command.</dl>
<p> <code>Baseline</code> </p>
<dl>
<dt>&bull;</p>
<dd>baseline/hostsm.smver #8217#8211; Host SM version.</p>
<dt>&bull;</p>
<dd>baseline/hostsm.smconfig #8217#8211; Copy of opafm.config.</dl>
<p> During a baseline run, the files are also created in FF_ANALYSIS_DIR/latest. </p>
<p> <code>Full Analysis</code> </p>
<dl>
<dt>&bull;</p>
<dd>latest/hostsm.smstatus #8217#8211; Output of the sm_query smShowStatus command.</p>
<dt>&bull;</p>
<dd>latest/hostsm.smver #8217#8211; Host SM version. latest/hostsm.smver.diff &#8211; diff of the baseline and latest host SM version. </p>
<dt>&bull;</p>
<dd>latest/hostsm.smconfig #8217#8211; Copy of opafm.xml.</p>
<dt>&bull;</p>
<dd>latest/hostsm.smconfig.diff #8217#8211; diff of the baseline and the latest opafm.xml.</dl>
<p> The .diff files are only created if differences are detected. </p>
<p> If the -s option is used and failures are detected, files related to the checks that failed are also copied to a time-stamped directory name under FF_ANALYSIS_DIR.</p>
<h2>Host SM Items Checked Against the Baseline</h2>
<dl>
<dt>&bull;</p>
<dd>SM configuration file.</p>
<dt>&bull;</p>
<dd>Version of the SM rpm installed on the system.</dl>
<h2>Host SM Items Also Checked During Health Check</h2>
<dl>
<dt>&bull;</p>
<dd>The SM is in the running state. </p>
</dl>
