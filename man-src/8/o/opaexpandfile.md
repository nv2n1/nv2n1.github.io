<p>opaexpandfile </p>
<p> <code>(Linux)</code> Expands a Intel(R) Omni-Path Fabric Suite FastFabric hosts, chassis, or switches file. This tool expands and filter outs blank and commented lines. This can be useful when building other scripts that may use these files as input.</p>
<h2>Syntax</h2>
<p>opaexpandfile <i>file</i></p>
<h2>Options</h2>
<dl>
<dt>&#8211;help</p>
<dd>Produces full help text. </p>
<dt>
&nbsp;<wbr><i>file</i>&nbsp;<wbr></p>
<dd>FastFabric file to be processed. </p>
</dl>
<h2>Example</h2>
<p>opaexpandfile allhosts </p>
