<p><code>ods-getconf</code> &#8211; OpenDNSSEC get configuration values </p>
<h2>Synopsis</h2>
<p><code>ods-getconf </code> [<code>-c</code> <i>FILE</i>] [<code>-h</code>] [<code>-V</code>]<code>expr</code> </p>
<h2>Description</h2>
<p>ods-getconf is part of the OpenDNSSEC software. With this tool, you can extract the value of a configuration option by giving the appropriate expression. For more information, go to <code><a rel="nofollow" href="http://www.opendnssec.org">http://www.opendnssec.org</a></code> and visit the Documentation page. </p>
<h2>Options</h2>
<dl>
<dt><code>-c</code><i> FILE</i></p>
<dd>Read configuration from file, instead of using the default.</p>
<dt><code>-h</code></p>
<dd>Show this help.</p>
<dt><code>-V</code></p>
<dd>Show version and exit.</dl>
