pskc_done(3)

pskc_done – API function

Synopsis

#include <pskc.h>
void pskc_done(pskc_t *container);

Arguments

pskc_t * container
a pskc_t handle, from pskc_init().

Description

This function releases the resources associated with the PSKC container handle.
