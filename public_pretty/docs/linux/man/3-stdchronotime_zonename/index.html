stdchronotime_zonename(3)

std::chrono::time_zone::name - std::chrono::time_zone::name

Synopsis

std::string_view name() const noexcept; (since C++20) Obtains the name of this time zone.

Return value

The name of this time zone (e.g., "America/New_York").
