bson_iter_overwrite_double(3)

NAME

bson_iter_overwrite_double() – The bson_iter_overwrite_double() function shall overwrite the contents of a BSON_TYPE_DOUBLE element in place.

SYNOPSIS


void bson_iter_overwrite_double(bson_iter_t *iter,
                                double value);

PARAMETERS

iter
A bson_iter_t \&.
value
The new double value.

DESCRIPTION

The bson_iter_overwrite_double(3) function shall overwrite the contents of a BSON_TYPE_DOUBLE element in place.

This may only be done when the underlying bson document allows mutation.

It is a programming error to call this function when iter is not obvserving an element of type BSON_TYPE_DOUBLE.
