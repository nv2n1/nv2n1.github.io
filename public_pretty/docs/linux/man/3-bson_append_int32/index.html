bson_append_int32(3)

NAME

bson_append_int32() – The bson_append_int32() function shall append a new element to bson containing a 32-bit signed integer.

SYNOPSIS


bool bson_append_int32(bson_t *bson,
                       const char *key,
                       int key_length,
                       int32_t value);

PARAMETERS

bson
A bson_t \&.
key
An ASCII C string containing the name of the field.
key_length
The length of key in bytes, or -1 to determine the length with strlen(3) \&.
value
An int32_t.

DESCRIPTION

The bson_append_int32(3) function shall append a new element to bson containing a 32-bit signed integer.

RETURNS

true if the operation was applied successfully, otherwise false and bson should be discarded.
