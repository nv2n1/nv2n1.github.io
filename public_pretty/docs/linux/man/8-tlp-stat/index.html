tlp-stat(8)

tlp-stat – show power management settings

Synopsis

tlp-stat [option]

Description

This command shows the configuration, affected power management settings and additional system info.

Options

-b, –battery
Show battery data.
-c, –config
Show configuration.
-d, –disk
Show disk data.
-e, –pcie
Show PCI(e) device data.
-p, –processor
Show processor data.
-r, –rfkill
Show radio device data.
-s, –system
Show system information.
-t, –temp
Show temperatures and fan speed.
-u, –usb
Show USB device data.
-w, –warn
Show warnings.
-P, –pev
Monitor power supply udev events.
-T, –trace
Show trace output.
-v, –verbose
Be more verbose.

Files

/etc/default/tlp

System configuration file containing all power management settings.

See Also

tlp(8).
