ncl_gdawk(3)

GDAWK (Deactivate workstation) - deactivates a workstation.

Synopsis

CALL GDAWK (WKID)

C-Binding Synopsis

#include <ncarg/gks.h>

void gdeactivate_ws(Gint ws_id);

Description

WKID
(Integer, Input) - A number identifying the workstation to be deactivated. WKID must be the same as that used in some previous GACWK call.

Usage

The specified workstation is removed from the set of active workstations. GKS output primitives are not sent to workstations that are not active.

Access

To use GKS routines, load the NCAR GKS-0A library ncarg_gks.
