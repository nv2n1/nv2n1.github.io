mtx-profile(1)

NAME

 mtx-profile – ConTeXt MkIV LuaTeX Profiler

SYNOPSIS

mtxrun –script profile [ OPTIONS … ] [ FILENAMES ]

DESCRIPTION

ConTeXt MkIV LuaTeX Profiler

OPTIONS

–analyze
analyze lua calls
–trace
analyze tex calls
