lxpanelctl(1)

lxpanelctl – controller for lxpanel.

Synopsis

lxpanelctl {command}

DESCRIPTION

This manual page documents briefly the lxpanelctl command.

lxpanelctl is a program that controls lxpanel.

COMMANDS

menu

show system menu

run

show run dialog

restart

restart lxpanel

exit

exit lxpanel

SEE ALSO

lxpanel (1).
