stdpolarstdcomplex(3)

std::polar(std::complex) - std::polar(std::complex)

Synopsis

Defined in header<complex>
    template <class T>
    complex<T> polar(const T &r, const T &theta = T());

Returns a complex number with magnitude r and phase angle theta. The behavior is undefined if r is negative or NaN, or if theta is infinite.

Parameters

r - magnitude theta - phase angle

Return value

a complex number determined by r and theta Defect reports The following behavior-changing defect reports were applied retroactively to previously published C++ standards.
