Inserts the given value value to the container.
1) Results in iter = container->insert(iter, value);
++iter;
2) Results in iter = container->insert(iter, std::move(value));
++iter;

Parameters

value - the value to insert

Return value

*this

Notes

This function exploits the signature compatibility between hinted insert for associative containers (such as std::set::insert) and positional insert for sequential containers (such as std::vector::insert).

Example

// Run this code 

#include <iostream>
#include <iterator>
#include <deque>
int main()
{
std::deque<int> q;
std::insert_iterator<std::deque<int>> it(q, q.begin());
for (int i = 0; i < 10; ++i)
it = i; // inserts i
for (auto &elem : q)
std::cout << elem << ’ ‘;
}
