pacemaker_remoted(8)

Pacemaker – Part of the Pacemaker cluster resource manager

Synopsis

pacemaker_remoted [options]

Description

pacemaker_remoted – Pacemaker Remote daemon for extending pacemaker functionality to remote nodes.

Options

-?, –help
This text
-$, –version
Version information
-V, –verbose
Increase debug output
-l, –logfile=value
Send logs to the additional named logfile
