ck_bitmap_union(3)

NAME

ck_bitmap_union – generates union of two bitmaps

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_bitmap.h Ft void Fn ck_bitmap_union ck_bitmap_t *dst ck_bitmap_t *src

DESCRIPTION

The Fn ck_bitmap_union function sets all bits in the bitmap pointed to by Fa src in the bitmap pointed to by Fa dst .

RETURN VALUES

This function has no return value.
