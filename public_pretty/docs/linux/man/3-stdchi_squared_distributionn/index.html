stdchi_squared_distributionn(3)

std::chi_squared_distribution<RealType>::n - std::chi_squared_distribution<RealType>::n

Synopsis

RealType n() const; (since C++11) Returns the n parameter the distribution was constructed with. It specifies the degrees_of_freedom of the distribution. The default value is 1.0.

Parameters

(none)

Return value

The n distribution parameter.
