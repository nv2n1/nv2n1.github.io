ncl_shgeti(3)

SHGETI - Retrieves the value of an internal parameter of type INTEGER.

Synopsis

CALL SHGETI (PNAM,IVAL)

Description

PNAM
A character string that specifies the name of the parameter to get. The name must appear as the first three characters of the string.
IVAL
An INTEGER variable that is the name of the variable into which the value of the internal parameter specified by PNAM is to be retrieved.

Usage

This routine allows you to retrieve the current value of Shgrid parameters. For a complete list of parameters available in this utility, see the shgrid_params man page.

Access

To use SHGETI, load the NCAR Graphics library ngmath.

See Also

shgrid, shgrid_params, shseti, shgetnp.

Complete documentation for Shgrid is available at URL http://ngwww.ucar.edu/ngdoc/ng/ngmath/shgrid/shhome.html
