gtg_new_task(1)

NAME

gtg_new_task – Adds a task to the Getting Things GNOME! organizer

SYNOPSIS

gtg_new_task

DESCRIPTION

gtg_new_task creates a new task in the Getting Things GNOME! organizer for the GNOME desktop via the DBUS message bus. Getting Things GNOME! must be running for the command to work.

FILES

None

SEE ALSO

gtg (1)

BUGS

Please report any bug you may experience to the GTG Developers, that can be reached at https://edge.launchpad.net/gtg
