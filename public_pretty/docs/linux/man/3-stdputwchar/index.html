stdputwchar(3)

std::putwchar - std::putwchar

Synopsis

Defined in header <cwchar>
wint_t putwchar( wchar_t ch );

Writes a wide character ch to stdout

Parameters

ch - wide character to be written

Return value

ch on success, WEOF on failure.
