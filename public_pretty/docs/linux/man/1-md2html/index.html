md2html(1)

NAME

md2html – Convert markdown to HTML

SYNOPSIS

Usage: md2html [options] <file>

OPTIONS

–dialect=DIALECT
Valid dialects are Gruber (the default) or Maruku Enable growl notifications

REPORTING BUGS

Please report bugs on the GitHub issue tracker: <https://github.com/evilstreak/markdown-js/issues>
