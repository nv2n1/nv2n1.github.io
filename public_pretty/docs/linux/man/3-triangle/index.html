triangle(3)

triangle – Draws a filled triangle. Allegro game programming library.

Synopsis

#include <allegro.h>
void triangle(BITMAP *bmp, int x1, y1, x2, y2, x3, y3, int color);

Description

Draws a filled triangle between the three points.
