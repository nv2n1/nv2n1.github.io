ck_ht_hash(3)

NAME

ck_ht_hash – generate a hash value for a hash table

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_ht.h Ft void Fn ck_ht_hash ck_ht_hash_t *h ck_ht_t *ht const void *key uint16_t key_length

DESCRIPTION

The Fn ck_ht_hash function will generate a hash value in the object pointed to by the Fa h argument. The hash value is valid for use in the hash table pointed to by the Fa ht argument for the key (of bytestring type) specified by the Fa key argument. The length of the key is specified by the Fa key_length argument.

RETURN VALUES

Fn ck_ht_hash has no return value.

ERRORS

Behavior is undefined if Fa key is NULL or if Fa ht is uninitialized.
