autosp(1)

NAME

autosp – preprocessor to generate note-spacing commands for MusiXTeX scores

SYNOPSIS

autosp [-v | –version | -h | –help]

autosp [-d | –dotted] [-l | –log] infile[.aspc] [outfile[.tex]]

DESCRIPTION

This program makes it easier to create MusiXTeX scores by converting (non-standard) commands of the form notes … n into one or more conventional note-spacing commands ( otes \Notes \NOtes …), determined by the actual note values, with \sk spacing commands inserted as necessary. The coding for an entire measure can be entered one part at a time, without concern for note-spacing changes within the part or spacing requirements of other parts.

For example, if applied to 

    notes\qa J\qa K&
