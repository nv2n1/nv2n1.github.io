grub-terminfo(8)

grub-terminfo – Generate a terminfo command from a terminfo name

Synopsis

grub-terminfo TERMNAME

Description

Generate a terminfo command from a terminfo name.

-h, –help
print this message and exit
-v, –version
print the version information and exit

Reporting Bugs

Report bugs to <bug-grub [at] gnu.org>.

See Also

The full documentation for grub-terminfo is maintained as a Texinfo manual. If the info and grub-terminfo programs are properly installed at your site, the command

info grub-terminfo

should give you access to the complete manual.
