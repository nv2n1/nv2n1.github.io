texindex(1)

NAME

texindex – sort Texinfo index files

SYNOPSIS

texindex [,OPTION/]… ,FILE/…

DESCRIPTION

Generate a sorted index for each TeX output FILE. Usually FILE… is specified as `foo.??’ for a document `foo.texi’.

OPTIONS

-h, –help
display this help and exit
–version
display version information and exit
—
end option processing

REPORTING BUGS

Email bug reports to bug-texinfo [at] gnu.org, general questions and discussion to help-texinfo [at] gnu.org.
Texinfo home page: https://www.gnu.org/software/texinfo/
