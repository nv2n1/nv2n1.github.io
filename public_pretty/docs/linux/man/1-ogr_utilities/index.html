ogr_utilities(1)

NAME

ogr_utilities – OGR Utility Programs The following utilities are distributed as part of the OGR Simple Features toolkit:

•
ogrinfo – Lists information about an OGR supported data source
•
ogr2ogr – Converts simple features data between file formats
•
ogrtindex – Creates a tileindex
•
ogrlineref – Create linear reference and provide some calculations using it
