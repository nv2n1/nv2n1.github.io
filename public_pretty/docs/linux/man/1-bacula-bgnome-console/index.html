bacula-bgnome-console(1)

NAME

 bgnome-console – Bacula’s management Console, GUI version.

DESCRIPTION

This manual page documents briefly the bgnome-console command, the Gnome GUI version of the Bacula administration console.

The Console allows the administrator or user to communicate with the Bacula Director. This is the Gnome version. It will also run under KDE.

This Gnome GUI interface is for the moment far from complete but is quite functional, having all the capabilities of the shell Console plus a number of GUI extensions that make interaction easier with point and click. .SHSEEALSO bacula-dir(8), bls(1), bextract(1).
