stdchronomonth_weekday(3)

std::chrono::month_weekday - std::chrono::month_weekday

Synopsis

Defined in header <chrono> class month_weekday; (since C++20) The class month_weekday represents the n-th weekday of a specific month, of some yet to be specified year. month_weekday is a TriviallyCopyable StandardLayoutType.
