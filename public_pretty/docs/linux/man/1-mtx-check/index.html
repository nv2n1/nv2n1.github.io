mtx-check(1)

NAME

 mtx-check – Basic ConTeXt Syntax Checking

SYNOPSIS

mtxrun –script check [ OPTIONS … ] [ FILENAMES ]

DESCRIPTION

Basic ConTeXt Syntax Checking

OPTIONS

–check
check tex file for errors
