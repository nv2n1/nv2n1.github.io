lou_checktable(1)

NAME

lou_checktable – Test a liblouis Braille translation table

SYNOPSIS

lou_checktable [OPTION] TABLE

DESCRIPTION

Test a Braille translation table. If the table contains errors, appropriate messages are displayed. If there are no errors the message "no errors found." is shown unless you specify the –quiet option.

-h, –help
display this help and exit
-v, –version
display version information and exit
-q, –quiet
do not write to standard error if there are no errors.
