irq_cpu_online(9)

irq_cpu_online – Invoke all irq_cpu_online functions.

Synopsis

void irq_cpu_online(void);

Arguments

void

no arguments

Description

Iterate through all irqs and invoke the chip.irq_cpu_online for each.
