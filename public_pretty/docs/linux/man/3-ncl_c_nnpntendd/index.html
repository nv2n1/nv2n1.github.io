ncl_c_nnpntendd(3)

c_nnpntendd - exit single point mode

Function Prototype

void c_nnpntendd();

Synopsis

void c_nnpntendd();

Usage

This function terminates single point mode. It should be called after entering single point mode using c_nnpntinitd and interpolating at individual points with c_nnpntd.

Access

To use c_nnpntendd, load the NCAR Graphics library ngmath.

See Also

natgrid, natgrid_params, c_natgridd, c_nnpntinitd, c_nnpntd.

Complete documentation for Natgrid is available at URL http://ngwww.ucar.edu/ngdoc/ng/ngmath/natgrid/nnhome.html
