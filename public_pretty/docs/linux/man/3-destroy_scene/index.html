destroy_scene(3)

NAME

destroy_scene – Deallocates the memory used by a scene. Allegro game programming library.

SYNOPSIS

#include <allegro.h>

void destroy_scene();

DESCRIPTION

Deallocate memory previously allocated by create_scene. Use this to avoid memory leaks in your program.
