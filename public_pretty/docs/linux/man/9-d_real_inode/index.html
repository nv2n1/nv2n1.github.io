d_real_inode(9)

d_real_inode – Return the real inode

Synopsis

struct inode *d_real_inode(const struct dentry *dentry);

Arguments

dentry

The dentry to query

Description

If dentry is on an union/overlay, then return the underlying, real inode. Otherwise return d_inode.
