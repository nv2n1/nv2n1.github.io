stderror_condition(3)

std::error_condition - std::error_condition

Synopsis

Defined in header <system_error> class error_condition; (since C++11) std::error_condition is a platform-independent error code. Like std::error_code, it is uniquely identified by an integer value and a std::error_category, but unlike std::error_code, the value is not platform-dependent. A typical implementation holds one integer data member (the value) and a pointer to an std::error_category.
