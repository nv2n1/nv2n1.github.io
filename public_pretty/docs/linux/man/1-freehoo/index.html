freehoo(1)

NAME

freehoo – manual page for freehoo messenger

SYNOPSIS

freehoo [OPTION…]

DESCRIPTION

Freehoo is a free console based messenger for Yahoo IM Service with GNU Bash like tab completion / editing and GNU Emacs like extensibility.

-s, –status=STATUS
Default login status number
-u, –user=YAHOOID
User login account name
-?, –help
Give this help list
–usage
Give a short usage message
-V, –version
Print program version

Mandatory or optional arguments to long options are also mandatory or optional for any corresponding short options.

REPORTING BUGS

Report bugs to freehoo-users [at] nongnu.org.

SEE ALSO

The full documentation for freehoo is maintained as a Texinfo manual. If the info and freehoo programs are properly installed at your site, the command

info freehoo

should give you access to the complete manual.
