atapi_xlat – Initialize PACKET taskfile

Synopsis

unsigned int atapi_xlat(struct ata_queued_cmd *qc);

Arguments

qc

command structure to be initialized

Description

LOCKING: spin_lock_irqsave(host lock)

Return

Zero on success, non-zero on failure.
