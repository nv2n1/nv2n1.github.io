upscli_sendline(3)

upscli_sendline – send a single command to a UPS

Synopsis

#include <upsclient.h>
int upscli_sendline(UPSCONN_t *ups, const char *buf, size_t buflen);

Description

The upscli_sendline() function takes the pointer ups to a UPSCONN_t state structure and transmits a buffer buf of size buflen to the server.

The data in buf must be a fully formatted protocol command as no parsing of the buffer occurs within this function.

Return Value

The upscli_sendline() function returns 0 on success, or -1 if an error occurs.
