ncl_gset_marker_type(3)

gset_marker_type (Set marker type) – sets the type of polymarker to be used in subsequent GPM calls.

Synopsis

#include <ncarg/gks.h>

void gset_marker_type(Gint marker_type);

Description

marker_type
(Input) – Selects the type of marker to be drawn. Options are:
< 0
implementation dependent (not used in NCAR GKS-0A)
1
 . (dot)
2
 + (plus)
3
 * (asterisk) This is the default
4
 o (circle)
5
 X (cross)
≥ 6
 reserved for registration or future standardization

Access

To use the GKS C-binding routines, load the ncarg_gks and ncarg_c libraries.
