gnutls_x509_ext_import_aia(3)

NAME

gnutls_x509_ext_import_aia – API function

SYNOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_aia(const gnutls_datum_t * ext, gnutls_x509_aia_t aia, unsigned int flags);

ARGUMENTS

const gnutls_datum_t * ext
The DER-encoded extension data
gnutls_x509_aia_t aia
The authority info access structure
unsigned int flags
should be zero

DESCRIPTION

This function extracts the Authority Information Access (AIA) extension from the provided DER-encoded data; see RFC 5280 section 4.2.2.1 for more information on the extension. The AIA extension holds a sequence of AccessDescription (AD) data.

RETURNS

On success, GNUTLS_E_SUCCESS (0) is returned, otherwise a negative error value.

SINCE

3.3.0
