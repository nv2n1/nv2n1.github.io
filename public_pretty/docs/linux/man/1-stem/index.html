stem(1)

NAME

stem – Stem Documentation

Stem is a Python controller library for Tor. With it you can use Tor’s control protocol to script against the Tor process, or build things such as arm. Stem’s latest version is 1.4.1 (released May 18th, 2015). .SH AUTHOR Damian Johnson (atagar [at] torproject.org)
