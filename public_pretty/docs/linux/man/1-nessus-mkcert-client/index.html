nessus-mkcert-client(1)

NAME

nessus-mkcert-client – Creates a client certificate

SYNOPSIS

nessus-mkcert-client

DESCRIPTION

The Nessus Security Scanner protects the communication between the client and the server by using SSL. SSL requires the server to present a certificate to the client, and the client can optionally present a certificate to the server.

This script nessus-mkcert-client generates a client certificate.
