abrt-sqlite3(7)

SQLite3 database plugin for abrt(8)

Description

abrt is a daemon that watches for application crashes. When a crash occurs, it collects the crash data and takes action according to its configuration. This manual page describes the SQLite3 database plugin for abrt. This is a database plugin: abrt needs a database in which to store its metadata. You can choose one by specifying "Database" in the abrt.conf configuration file. Currently SQLite3 is the only choice supported.

Invocation

The plugin is invoked in the abrt.conf configuration file, like this:
[common]
Database = SQLite3

Configuration

The SQLite3.conf configuration file contains one entry:

DBPath

The path to the database.
