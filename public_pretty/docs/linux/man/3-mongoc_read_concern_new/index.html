mongoc_read_concern_new(3)

mongoc_read_concern_new() – None

Synopsis

mongoc_read_concern_t *
mongoc_read_concern_new (void);

Returns

Creates a newly allocated read concern that can be configured based on user preference. This should be freed with mongoc_read_concern_destroy(3) when no longer in use.
