lda-schema-to-gconf(1)

NAME

lda-schema-to-gconf – A script which converts keyfile-based schemas into GConf schemas for libdesktop-agnostic.

SYNOPSIS

lda-schema-to-gconf

DESCRIPTION

lda-schema-to-gconf is a script which converts keyfile-based schemas into GConf schemas. It is used for libraries and programs which use libdesktop-agnostic’s configuration library.
