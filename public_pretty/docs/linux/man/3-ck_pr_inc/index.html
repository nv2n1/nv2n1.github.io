DESCRIPTION

The Fn ck_pr_inc 3 family of functions atomically increment the value pointed to by Fa target .

RETURN VALUES

The ck_pr_inc_zero family of functions set the value pointed to by Fa z to true if the result of the increment operation was 0. The functions set the value pointed to by Fa z false otherwise.
