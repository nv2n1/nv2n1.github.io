create-cracklib-dict(8)

create-cracklib-dict – Check passwords using libcrack2

Synopsis

create-cracklib-dict wordlist …

Description

create-cracklib-dict takes one or more word list files as arguments and converts them into cracklib dictionaries for use by password checking programs. The results are placed in the default compiled-in dictionary location. If you wish to store the dictionary in a different location, use the cracklib-format and cracklib-packer commands directly.
