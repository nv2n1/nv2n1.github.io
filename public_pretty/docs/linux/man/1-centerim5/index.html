centerim5(1)

NAME

centerim5 – a text-mode IM client for Linux, *BSD, Solaris and other Unices that uses libpurple as a communication backend.

SYNOPSIS

centerim5 [ option ] …

DESCRIPTION

This manual page documents briefly the centerim5 command.

OPTIONS

-a, –ascii
use ASCII characters to draw lines and boxes
-h, –help
display command line usage
-v, –version
show the program version info
-b, –basedir <directory>
specify another base directory; useful for having several IM identities under the same UNIX account
-o, –offline
start with all accounts set offline
