ellipse(3)

NAME

ellipse – Draws an ellipse. Allegro game programming library.

SYNOPSIS

#include <allegro.h>

void ellipse(BITMAP *bmp, int x, int y, int rx, int ry, int color);

DESCRIPTION

Draws an ellipse with the specified centre and radius.
