unnamedobj(3)

UnNamedObj – widget from X tookit

Synopsis

#include <X11/Intrinsic.h>

Description

UnNamedObj is a widget which is defined in the X Toolkit. We document its existence here for completeness. Please refer to the X Window System documentation for the real information regarding this widget.
