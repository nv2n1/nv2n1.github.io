packet-nfs-nfs(3)

packet.nfs.nfs – NFS module

Description

Process the NFS layer and return the correct NFS object. The function returns either a NULL(), CB_NULL, COMPOUND or CB_COMPOUND object.

Functions

NFS(rpc, callback)
