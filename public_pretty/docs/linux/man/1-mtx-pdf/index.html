mtx-pdf(1)

NAME

 mtx-pdf – ConTeXt PDF Helpers

SYNOPSIS

mtxrun –script pdf [ OPTIONS … ] [ FILENAMES ]

DESCRIPTION

ConTeXt PDF Helpers

OPTIONS

–info
show some info about the given file
–metadata
show metadata xml blob
–pretty
replace newlines in metadata
–fonts
show used fonts (–detail)

AUTHOR
