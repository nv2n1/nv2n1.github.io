ipmaddr(8)

ipmaddr – adds, deletes, and displays multicast addresses
 

Synopsis

/usr/sbin/ipmaddr [<operation>] [<args>]

Note

This program is obsolete. For replacement check ip maddr.

Description

The ipmaddr command can perform one of the following operations: add – add a multicast address del – delete a multicast address show – list multicast addresses

ip(8).
