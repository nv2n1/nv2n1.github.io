bson_append_utf8(3)

NAME

bson_append_utf8() – The bson_append_utf8() function shall append a UTF-8 encoded string to bson.

SYNOPSIS


bool bson_append_utf8(bson_t *bson,
                      const char *key,
                      int key_length,
                      const char *value,
                      int length);

PARAMETERS

bson
A bson_t \&.
key
An ASCII C string containing the name of the field.
key_length
The length of key in bytes, or -1 to determine the length with strlen(3) \&.
value
A UTF-8 encoded string.
length
The number of bytes in value excluding the trailing
