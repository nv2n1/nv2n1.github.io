smoltgui(1)

smoltGui – GUI for Smolt hardware profile submission

Synopsis

smoltGui

Description

smoltGui is a graphical user interface that can be used to submit Smolt hardware profiles to a Smoon server. Smolt is a cross-desktop hardware reporting tool for GNU/Linux based systems.

Options

smoltGui has no command-line options.

See Also

smoltSendProfile(1), smoltDeleteProfile(1).
