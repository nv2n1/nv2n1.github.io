ck_pr_or(3)

NAME

ck_pr_or_ptr ck_pr_or_char ck_pr_or_uint ck_pr_or_int ck_pr_or_64 ck_pr_or_32 ck_pr_or_16 ck_pr_or_8 – atomic bitwise-or operations

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_pr.h Ft void Fn ck_pr_or_ptr void *target uintptr_t delta Ft void Fn ck_pr_or_char char *target char delta Ft void Fn ck_pr_or_uint unsigned int *target unsigned int delta Ft void Fn ck_pr_or_int int *target int delta Ft void Fn ck_pr_or_64 uint64_t *target uint64_t delta Ft void Fn ck_pr_or_32 uint32_t *target uint32_t delta Ft void Fn ck_pr_or_16 uint16_t *target uint16_t delta Ft void Fn ck_pr_or_8 uint8_t *target uint8_t delta

DESCRIPTION

The Fn ck_pr_or 3 family of functions atomically compute and store the result of a bitwise-or of the value pointed to by Fa target and Fa delta into the value pointed to by Fa target .

RETURN VALUES

This family of functions does not have a return value.
