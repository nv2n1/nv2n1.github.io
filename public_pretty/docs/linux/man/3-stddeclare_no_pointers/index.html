stddeclare_no_pointers(3)

std::declare_no_pointers - std::declare_no_pointers

Synopsis

Defined in header <memory> void declare_no_pointers( char *p, std::size_t n ); (since C++11) Informs the garbage collector or leak detector that the specified memory region (n bytes beginning at the byte pointed to by p) contains no traceable pointers. If any part of the region is within an allocated object, the entire region must be contained in the same object.

Parameters

p - pointer to the beginning of the range n - the number of bytes in the range

Return value

(none)

Exceptions

None
