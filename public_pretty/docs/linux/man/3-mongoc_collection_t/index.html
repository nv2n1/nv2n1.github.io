mongoc_collection_t(3)

mongoc_collection_t – #include <mongoc.h>

typedef struct _mongoc_collection_t mongoc_collection_t;

Synopsis

#include <mongoc.h>
typedef struct _mongoc_collection_t mongoc_collection_t;

mongoc_collection_t provides access to a MongoDB collection. This handle is useful for actions for most CRUD operations, I.e. insert, update, delete, find, etc.

Read Preferences And Write Concerns

Read preferences and write concerns are inherited from the parent client. They can be overridden by set_* commands if so desired.

Lifecycle

It is an error to call mongoc_collection_destroy(3) on a collection that has operations pending. It is required that you release mongoc_cursor_t structures before calling mongoc_collection_destroy(3) \&.
