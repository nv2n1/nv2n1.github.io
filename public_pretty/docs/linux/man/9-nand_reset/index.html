nand_reset(9)

nand_reset – Reset and initialize a NAND device

Synopsis

int nand_reset(struct nand_chip *chip, int chipnr);

Arguments

chip

The NAND chip

chipnr

Internal die id

Description

Returns 0 for success or negative error code otherwise
