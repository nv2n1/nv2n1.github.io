smoltdeleteprofile(1)

smoltDeleteProfie – Delete Smolt hardware profile from server

Synopsis

smoltDeleteProfile [options]

Description

smoltDeleteProfile deletes the machine’s profile from a remote Smoon server. Smolt is a cross-desktop hardware reporting tool for GNU/Linux based systems.

Options

-s SMOON_URL, –server=SMOON_URL
Specify the URL of the server
-u USERAGENT, –useragent=USERAGENT, –user_agent=USERAGENT
Specify HTTP user agent (default "smolt/0.97")
-t TIMEOUT, –timeout=TIMEOUT
Specify HTTP timeout in seconds (default 60.0 seconds)
–uuidFile=UUIDFILE
Specify which UUID to use; useful for debugging and testing
-d, –debug
Enable debug information
–version
Show program’s version number and exit
-h, –help
Show this help message and exit

See Also

smoltSendProfile(1), smoltGui(1).
