dvdrw-mediainfo(1)

dvd+rw-mediainfo – display information about dvd drive and disk

Synopsis

dvd+rw-mediainfo /dev/dvd

Description

The dvd+rw-mediainfo command displays information about the drive and disk in the specified dvd drive (e.g. /dev/dvd). This is especially useful for debugging purposes and it is requested that its output be included when reporting bugs found in the dvd+rw-tools package.

Options

This program does not accept any command line options.

See Also

Most up-to-date information on dvd+rw-tools is available at http://fy.chalmers.se/~appro/linux/DVD+RW/.
