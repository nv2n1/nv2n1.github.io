fcblanksadd(3)

FcBlanksAdd – Add a character to an FcBlanks

Synopsis

#include <fontconfig/fontconfig.h>

FcBool FcBlanksAdd (FcBlanks *b, FcChar32 ucs4);

Description

FcBlanks is deprecated. This function always returns FALSE.
