funit-slave(8)

funit-slave – forks, execs, and clones on receipt of specific signals

Synopsis

funit-slave

Description

A small slave program, used by funit as part of frysk’s JUnit testsuite.

Examples

Run on a 32-bit system. 

/usr/lib/frysk/funit-slave

Run on a 64-bit system. 

/usr/lib64/frysk/funit-slave

See Also

frysk(7) funit(8)
