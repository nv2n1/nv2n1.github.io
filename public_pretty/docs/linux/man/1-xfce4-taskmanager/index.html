xfce4-taskmanager(1)

NAME

xfce4-taskmanager – a task (system process) manager for Xfce.

SYNOPSIS

xfce4-taskmanager

DESCRIPTION

xfce4-taskmanager is a GUI task (system process) manager for the Xfce Desktop Environment.
