ncid(5)

ncid.conf – ncid configuration file

Description

The ncid.conf file contains the configuration information for ncid, the Network Caller ID Client. Use ncid.conf to configure ncid everytime it is started, but use ncidmodules.conf to configure ncid for a particular output module. For example, use ncid.conf to configure ncid for the server address, but use ncidmodules.conf to configure ncid to for ncid-page.

The ncid.conf file is a tcl/tk configuration file used to set options.

The ncid.conf file understands 3 types of lines:

blank line
skip it
comment line, beginning with ‘#’
skip it
command lines, beginning with ‘set’

See ncid.conf for a complete list of variables to set and what the default values are.

Examples

Set ncid to use the page output module:

       set EXTPROG ncid-page

Set ncid to format its output for the US and include the 1. The number output display will be 1-XXX-XXX-XXXX instead of XXX-XXX-XXXX:

 set NoOne       0

Set ncid to format its number output display for Sweden: The number output display will be 0X-XXXXXXXX, 0XX-XXXXXXX, 0XXX-XXXXX, etc:

 set Country     "SE"
