gnutls_pcert_import_openpgp(3)

NAME

gnutls_pcert_import_openpgp – API function

SYNOPSIS

#include <gnutls/abstract.h>

int gnutls_pcert_import_openpgp(gnutls_pcert_st * pcert, gnutls_openpgp_crt_t crt, unsigned int flags);

ARGUMENTS

gnutls_pcert_st * pcert
The pcert structure
gnutls_openpgp_crt_t crt
The raw certificate to be imported
unsigned int flags
zero for now

DESCRIPTION

This convenience function will import the given certificate to a gnutls_pcert_st structure. The structure must be deinitialized afterwards using gnutls_pcert_deinit();

RETURNS

On success, GNUTLS_E_SUCCESS (0) is returned, otherwise a negative error value.

SINCE

3.0
