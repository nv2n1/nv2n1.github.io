rbldns-2(8)

rbldns – Real time Block List DNS server.

Synopsis

rbldns [OPTIONS]

Description

rbldns is a Real time Block List DNS server. It accepts iterative DNS queries from clients seeking information about IP addresses. It provides responses showing whether the addresses are listed on the locally configured Real time Block List(RBL) or Dialup Users List(DUL). When invoked, rbldns reads from the configuration file and listens on UDP port 53 for the incoming requests. When the request is received, rbldns answers it by looking in the data.cdb file placed under the ROOT directory specified in the configuration file.

Options

-d <value>
 print debug messages as per the debug level, 1, 2 or 3.
-D
 run as a daemon
-h –help
 print this help.
-v –version
 print version information.

Files

 /etc/ndjbdns/rbldns.conf

 /var/log/rbldns.log
