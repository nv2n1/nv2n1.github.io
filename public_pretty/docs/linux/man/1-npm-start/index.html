npm-start(1)

NAME

npm-start – Start a package

Synopsis

npm start [-- <args>]

Description

This runs an arbitrary command specified in the package’s "start" property of its "scripts" object. If no "start" property is specified on the "scripts" object, it will run node server.js.

As of npm [at] 2.0.0 https://blog.npmjs.org/post/98131109725/npm-2-0-0, you can use custom arguments when executing scripts. Refer to npm help run-script for more details.
