fts-delegation-init(1)

NAME

fts-delegation-init

SYNOPSIS

fts-delegation-init [options]

DESCRIPTION

fts-delegation-init is a tool for delegating a proxy certificate to FTS3 endpoint.

OPTIONS

  -h [ –help ]         Print this help text and exit.   -q [ –quite ]        Quiet operation.   -v [ –verbose ]      Be more verbose.   -s [ –service ] arg  Use the transfer service at the specified URL.   -V [ –version ]      Print the version number and exit.   -j [ –json ]         The output should be printed in JSON format

  –rest                Use the RESTful interface.   –capath arg          Path to the GRID security certificates (e.g.                    /etc/grid-security/certificates).   –proxy arg           Path to the proxy certificate (e.g. /tmp/x509up_u500).   -I [ –id ] arg       Delegation with ID as the delegation identifier.   -e [ –expire ] arg   Expiration time of the delegation in minutes.
