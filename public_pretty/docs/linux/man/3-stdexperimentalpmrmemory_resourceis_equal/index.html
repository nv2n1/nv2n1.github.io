stdexperimentalpmrmemory_resourceis_equal(3)

std::experimental::pmr::memory_resource::is_equal - std::experimental::pmr::memory_resource::is_equal

Synopsis

bool is_equal(const memory_resource& other) const noexcept; (library fundamentals TS) Compares *this for equality with other. Two memory_resources compare equal if and only if memory allocated from one memory_resource can be deallocated from the other and vice versa. Equivalent to return do_is_equal(other);.
