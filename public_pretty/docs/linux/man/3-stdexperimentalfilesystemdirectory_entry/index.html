stdexperimentalfilesystemdirectory_entry(3)

std::experimental::filesystem::directory_entry - std::experimental::filesystem::directory_entry

Synopsis

Defined in header <experimental/filesystem> class directory_entry; (filesystem TS) Represents a directory entry. The objects stores a path and two file_status objects: one for file status and the second for the pointed-to file status if the directory entry refers to a symbolic link.
