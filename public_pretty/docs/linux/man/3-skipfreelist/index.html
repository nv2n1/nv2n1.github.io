skipfreelist(3)

skipFreeList – free a skip list.

Synopsis

#include <util/skiplist.h>
void skipFreeList(skipList list);

Arguments

list – list to free.

Description

Release all resources used by <list> including all key/value pairs. MT-Level: Safe for unique <list>.

Return Value

None.

See Also

skipDelete(3), skipFreeList(3), skipRelease(3), skipInsert(3), skipSearch(3), skipNext(3), skipNewList
