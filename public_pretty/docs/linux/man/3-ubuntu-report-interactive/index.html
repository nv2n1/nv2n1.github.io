ubuntu-report-interactive(3)

ubuntu-report-interactive – Interactive mode, alias to running this tool without any subcommands.

Synopsis

ubuntu-report interactive [flags]

Description

Interactive mode, alias to running this tool without any subcommands.

Options

-h, –help[=false]
    help for interactive

-u, –url=" <https://metrics.ubuntu.com">
    server url to send report to. Leave empty for default.

Options Inherited From Parent Commands

-f, –force[=false]
    collect and send new report even if already reported

-v, –verbose[=0]
    issue INFO (-v) and DEBUG (-vv) output
