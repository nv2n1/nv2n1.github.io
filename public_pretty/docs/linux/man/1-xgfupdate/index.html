xgfupdate(1)

NAME

xgfupdate – updates an Xgridfit program file to the latest version.

SYNOPSIS

xgfupdate file

DESCRIPTION

Xgfupdate is a utility that updates an Xgridfit program file so that it validates against the current xgridfit-strict.rnc schema. If XMLStarlet is found in the system, it is used to prettify the output. Xgfupdate outputs the updated file to stdout. To capture the output in a file, use this syntax:

  $xgfupdate infile > outfile

FILES

/usr/share/xgridfit/util/xgf-update.xsl
An XSLT script that does the updating.
/usr/share/xgridfit/util/add-blanks.sed
A Sed script that does some formatting of the output.

SEE ALSO

xgridfit(1), xmlstarlet(1).
