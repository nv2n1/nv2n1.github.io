stringprep_ucs4_nfkc_normalize(3)

stringprep_ucs4_nfkc_normalize – API function

Synopsis

#include <stringprep.h>

uint32_t * stringprep_ucs4_nfkc_normalize(const uint32_t * str, ssize_t len);

Arguments

const uint32_t * str
a Unicode string.
ssize_t len
length of str array, or -1 if str is nul-terminated.

Description

Converts a UCS4 string into canonical form, see stringprep_utf8_nfkc_normalize() for more information.

Return Value

a newly allocated Unicode string, that is the NFKC normalized form of str.
