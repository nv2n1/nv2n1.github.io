fts_server(8)

fts_server

Synopsis

fts_server [options]

Description

fts_server starts the FTS3 server.

Options

  -h [ –help ]         Print this help text and exit.   -q [ –quiet ]        Quiet operation.   -v [ –verbose ]      Be more verbose.   -s [ –service ] arg  Use the transfer service at the specified URL.   -r [–rush]           Quick start and stop. Not intended for production.   -V [ –version ]      Print the version number and exit.
