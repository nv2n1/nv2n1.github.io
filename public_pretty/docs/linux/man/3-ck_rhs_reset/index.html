ck_rhs_reset(3)

NAME

ck_rhs_reset – remove all keys from a hash set

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_rhs.h Ft bool Fn ck_rhs_reset ck_rhs_t *hs

DESCRIPTION

The Fn ck_rhs_reset 3 function will remove all keys stored in the hash set pointed to by the Fa hs argument.

RETURN VALUES

If successful, Fn ck_rhs_reset 3 will return true and will otherwise return false on failure. This function will only fail if a replacement hash set could not be allocated internally.

ERRORS

Behavior is undefined if Fa hs is uninitialized. Behavior is undefined if this function is called by a non-writer thread.
