mysqueak(1)

NAME

mysqueak – desktop frontend to Squeak

SYNOPSIS

mysqueak

DESCRIPTION

mysqueak runs inisqueak in batch mode in the directory ~/MySqueak/default. If that directory does not exist it will be created, and inisqueak will populate it with an image file.

The primary purpose of mysqueak is to simplify starting Squeak from a menu, though it also simplifies starting squeak from the command line.

INVOCATION

mysqueak has no options or arguments.

DIAGNOSTICS

mysqueak outputs nothing and returns whatever inisqueak returns.

FILES

~/MySqueak

the user’s copies of a squeak.image, squeak.changes, and squeak.sources are kept here.
