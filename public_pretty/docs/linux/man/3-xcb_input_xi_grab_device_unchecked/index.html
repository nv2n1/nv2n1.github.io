Description

Return Value

Returns an xcb_input_xi_grab_device_cookie_t. Errors have to be handled when calling the reply function xcb_input_xi_grab_device_reply.

If you want to handle errors in the event loop instead, use xcb_input_xi_grab_device_unchecked. See xcb-requests(3) for details.

Errors

This request does never generate any errors.
