struct_w1_family(9)

struct_w1_family – reference counted family structure.

Synopsis

struct w1_family {
    struct list_head family_entry;
    u8 fid;
    struct w1_family_ops *fops;
    atomic_t refcnt;
};

Members

family_entry

family linked list

fid

8 bit family identifier

fops

operations for this family

refcnt

reference counter
