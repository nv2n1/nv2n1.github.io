geographiclib-get-magnetic(8)

geographiclib-get-magnetic — a GeographicLib administrative tool

Description

geographiclib-get-magnetic downloads and installs the magnetic datasets used by GeographicLib, <http://geographiclib.sf.net>. For documentation, supply the -h option:
 geographiclib-get-magnetic -h By default, the datasets are installed in /usr/share/GeographicLib/magnetic and the script requires write access to this directory.
