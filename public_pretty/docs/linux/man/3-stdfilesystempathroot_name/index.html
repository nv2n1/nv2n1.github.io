stdfilesystempathroot_name(3)

std::filesystem::path::root_name - std::filesystem::path::root_name

Synopsis

path root_name() const; (since C++17) Returns the root name of the generic-format path. If the path (in generic format) does not include root name, returns path().

Parameters

(none)

Return value

The root name of the path.

Exceptions

(none)

Example

// Run this code 

#include <iostream>
#include <filesystem>
namespace fs = std::filesystem;
int main()
{
std::cout << "Current root name is: " << fs::current_path().root_name() << ‘\n’;
}

Possible output:

  Current root name is: "C:"
