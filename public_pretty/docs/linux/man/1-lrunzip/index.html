lrunzip(1)

NAME

lrunzip - Uncompress LRZ files

SYNOPSIS


lrunzip[options] FILE[... FILE]

DESCRIPTION

lrunzip is identical to "lrzip -d" used to decompress files.

OPTIONS

See lrzip(1).

ENVIRONMENT

None.

FILES

None.

SEE ALSO

lrzip.conf(5), lrzip(1), lrzcat(1), lrztar(1), lrzuntar(1), bzip2(1), gzip(1), lzop(1), rzip(1), zip(1)
