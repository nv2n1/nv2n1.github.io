meatclient(8)

stonith – extensible interface for remotely powering down a node in the cluster

Synopsis

meatclinet [ -c nodename ]

Description

meatclient is a program that confirms that a manual reset has been done when stonith needed an operator to power-cycle a node on it’s behalf.

Options

-c nodename:
manual power reset has been done on the node.

See Also

heartbeat (8) stonith (8)
