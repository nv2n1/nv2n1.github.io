panel-test-applets(1)

NAME

panel-test-applets — display installed applets

SYNOPSIS

panel-test-applets [–help ]

DESCRIPTION

panel-test-applets display installed applets in a dialog box and does nothing else.

OPTIONS

–help
Display help
