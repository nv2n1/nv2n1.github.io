ata_xfer_mode2mask(9)

ata_xfer_mode2mask – Find matching xfer_mask for XFER_*

Synopsis

unsigned long ata_xfer_mode2mask(u8 xfer_mode);

Arguments

xfer_mode

XFER_* of interest

Description

Return matching xfer_mask for xfer_mode.

LOCKING: None.

Return

Matching xfer_mask, 0 if no match found.
