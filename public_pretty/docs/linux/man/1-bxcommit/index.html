bxcommit(1)

NAME

bxcommit – Interactive Tool to Commit Redologs into flat Disk Images for Bochs

USAGE

bxcommit

DESCRIPTION

Bxcommit is an easy to use console based tool for committing redologs into flat disk images, particularly for use with Bochs. It is completely interactive, so no command line arguments are needed to use bxcommit.
