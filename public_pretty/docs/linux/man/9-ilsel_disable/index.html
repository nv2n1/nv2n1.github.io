ilsel_disable(9)

ilsel_disable – Disable an ILSEL set

Synopsis

void ilsel_disable(unsigned int irq);

Arguments

irq

Bit position for ILSEL set value (retval from enable routines)

Description

Disable a previously enabled ILSEL set.
