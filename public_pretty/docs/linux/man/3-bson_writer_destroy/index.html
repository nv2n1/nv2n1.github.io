bson_writer_destroy(3)

NAME

bson_writer_destroy() – Cleanup after writer and release any allocated memory. Note that the buffer supplied to bson_writer_new() is NOT freed from this method. The caller is responsible for that.

SYNOPSIS


void bson_writer_destroy(bson_writer_t *writer);

PARAMETERS

writer
A bson_writer_t \&.

DESCRIPTION

Cleanup after writer and release any allocated memory. Note that the buffer supplied to bson_writer_new(3) is NOT freed from this method. The caller is responsible for that.
