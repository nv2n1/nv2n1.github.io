mcreate(3)

mCreate – initialize a mutex.

Synopsis

#include <util/ulocks.h>
NEOERR *mCreate(pthread_mutex_t *mutex);

Arguments

mutex – mutex to initialize.

Description

Initializes the mutex <mutex>.

MT-Level: Safe for unique <mutex>.

Return Value

None.
