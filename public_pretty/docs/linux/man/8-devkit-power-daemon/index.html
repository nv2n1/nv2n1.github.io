devkit-power-daemon(8)

devkit-power-daemon – DeviceKit-power Daemon

Synopsis

devkit-power-daemon [–help]

Description

devkit-power-daemon

provides the org.freedesktop.DeviceKit.Power service on the system message bus. Users or administrators should never need to start this daemon as it will be automatically started by dbus-daemon(1) whenever an application calls into the org.freedesktop.DeviceKit.Power service.

Options

–help

Show help options.

Author

Written by David Zeuthen davidz [at] redhat.com with a lot of help from many others.
