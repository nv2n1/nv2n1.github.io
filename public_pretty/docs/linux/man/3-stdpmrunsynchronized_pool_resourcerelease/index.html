stdpmrunsynchronized_pool_resourcerelease(3)

std::pmr::unsynchronized_pool_resource::release - std::pmr::unsynchronized_pool_resource::release

Synopsis

void release();
(since C++ 17)

Releases all memory owned by this resource by calling the deallocate function of the upstream memory resource as needed. Memory is released back to the upstream resource even if deallocate has not been called for some of the allocated blocks.
