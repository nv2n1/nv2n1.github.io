bson_iter_visit_all(3)

NAME

bson_iter_visit_all() – A convenience function to iterate all remaining fields of iter using the callback vtable provided by visitor.

SYNOPSIS


bool bson_iter_visit_all(bson_iter_t *iter,
                         const bson_visitor_t *visitor,
                         void *data);

PARAMETERS

iter
A bson_iter_t \&.
visitor
A bson_visitor_t \&.
data
Optional data for visitor \&.

DESCRIPTION

A convenience function to iterate all remaining fields of iter using the callback vtable provided by visitor \&.

RETURNS

true if visitation was pre-maturely stopped by a callback function. Otherwise false.
