ncl_gqops(3)

GQOPS (Inquire operating state value) - returns the operating state of GKS.

Synopsis

CALL GQOPS (OPSTA)

C-Binding Synopsis

#include <ncarg/gks.h>

void ginq_op_st(Gop_st *op_st);

Description

OPSTA
(Integer, Output) - Returns the GKS operating state:
0
GKS is closed
1
GKS is open
2
Additionally, a workstation is open
3
Additionally, a workstation is active
4
Additionally, a segment is open

Access

To use GKS routines, load the NCAR GKS-0A library ncarg_gks.
