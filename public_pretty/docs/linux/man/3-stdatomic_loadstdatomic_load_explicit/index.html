  1. Atomically obtains the value pointed to by obj as if by obj->load()
  2. Atomically obtains the value pointed to by obj as if by obj->load(order)

Parameters

obj - pointer to the atomic object to modify order - the memory synchronization ordering for this operation: only std::memory_order_relaxed, std::memory_order_consume, std::memory_order_acquire and std::memory_order_seq_cst are permitted.

Return value

The value that is held by the atomic object pointed to by obj
