ucwidth(3)

ucwidth – Low level helper function for testing Unicode text data. Allegro game programming library.

Synopsis

#include <allegro.h>
int ucwidth(int c);

Description

Low level helper function for testing Unicode text data.

Return Value

Returns the number of bytes that would be occupied by the specified character value, when encoded in the current format.

See Also

uwidth_max(3), ugetc(3), ugetx(3), usetc(3), uwidth(3), uisok(3)
