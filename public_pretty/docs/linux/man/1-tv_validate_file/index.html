tv_validate_file(1)

NAME

tv_validate_file – Validate that a file contains valid xmltv data.

SYNOPSIS

tv_validate_file –help

tv_validate_grabber [–dtd-file <dtdfile>] <file>

DESCRIPTION

OPTIONS

–dtd <dtdfile> Use the specified file as the xmltv dtd instead of downloading it from the web.
