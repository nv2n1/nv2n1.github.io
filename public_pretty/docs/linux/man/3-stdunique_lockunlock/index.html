stdunique_lockunlock(3)

std::unique_lock<Mutex>::unlock - std::unique_lock<Mutex>::unlock

Synopsis

void unlock();
(since C++ 11)

Unlocks the associated mutex and releases ownership. std::system_error is thrown if there is no associated mutex or if the mutex is not locked.

Parameters

(none)

Return value

(none)

Exceptions

  • Any exceptions thrown by mutex()->unlock()

  • If there is no associated mutex or the mutex is not locked, std::system_error with an error code of std::errc::operation_not_permitted
