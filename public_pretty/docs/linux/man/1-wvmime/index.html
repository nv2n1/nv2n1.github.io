wvmime(1)

wvMime – view MSWord documents

Synopsis

wvMime word_doc

Description

wvMime will view your word documents using ggv,gv,ghostview,etc… instead of acting as a conversion engine.

Requirements

wvPS, (one of) ggv, gv, ghostview

More Information

http://wvware.sourceforge.net

See Also
