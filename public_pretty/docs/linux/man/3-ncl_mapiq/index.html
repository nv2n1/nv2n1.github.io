ncl_mapiq(3)

MAPIQ - Terminates a string of calls to MAPIT.

Synopsis

CALL MAPIQ

C-Binding Synopsis

#include <ncarg/ncargC.h>

void c_mapiq()

Description

MAPIQ has no arguments.

Usage

MAPIQ flushes MAPIT's buffers. It is particularly important that this be done before a STOP or a CALL FRAME, and before changing the color index, dash pattern, etc.

For more information, see the man page for MAPIT.

Examples

Use the ncargex command to see the following relevant examples: cmpgci, cmptra, mpexfi.

Access

To use MAPIQ or c_mapiq, load the NCAR Graphics libraries ncarg, ncarg_gks, and ncarg_c, preferably in that order.
