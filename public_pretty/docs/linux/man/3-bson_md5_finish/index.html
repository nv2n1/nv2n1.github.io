bson_md5_finish(3)

NAME

bson_md5_finish() – Completes the MD5 algorithm and stores the digest in digest.

SYNOPSIS


void bson_md5_finish(bson_md5_t *pms,
                     uint8_t digest[16]);

PARAMETERS

pms
A bson_md5_t \&.
digest
A location for the digest.

DESCRIPTION

Completes the MD5 algorithm and stores the digest in digest \&.
