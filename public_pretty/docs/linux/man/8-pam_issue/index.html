pam_issue(8)

pam_issue – PAM module to add issue file to user prompt

Synopsis

pam_issue.so [noesc] [issue=issue-file-name]

Description

pam_issue is a PAM module to prepend an issue file to the username prompt. It also by default parses escape codes in the issue file similar to some common getty’s (using ormat).

Recognized escapes:

\d

current day

\l

name of this tty

\m

machine architecture (uname -m)

machine’s network node hostname (uname -n)

\o

domain name of this system

release number of operating system (uname -r)

current time

\s

operating system name (uname -s)
