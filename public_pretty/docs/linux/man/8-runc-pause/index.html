runc-pause(8)

runc-pause – suspend all processes inside the container

Synopsis

runc pause container-id

Description

The pause command suspends all processes in the instance of the container identified by container-id. Use runc list to identify instances of containers and their current status.

See Also

runc-list(8), runc-resume(8), runc(8).
