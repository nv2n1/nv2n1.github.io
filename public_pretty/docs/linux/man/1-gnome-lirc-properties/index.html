gnome-lirc-properties(1)

NAME

gnome-lirc-properties – A control panel to configure remote controls.

SYNOPSIS

gnome-lirc-properties

DESCRIPTION

This control panel updates lirc’s configuration files to match your choices. It also allows editing, uploading and downloading of custom remote control configuration files.

AUTHORS

Written by Murray Cumming and Mathias Hasselmann..

SEE ALSO

The full documentation for the gnome-lirc-properties command is available in the GNOME help system: <ghelp:gnome-lirc-properties>.
