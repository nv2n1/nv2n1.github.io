cslinker(1)

NAME

cslinker – manual page for cslinker 1.3.2

SYNOPSIS

cslinker [options] proj.err […], where options are:

DESCRIPTION

–cwelist arg
(re)assign CWE numbers to defects by the given CSV list
–inifile arg
load scan properties from the given INI file
–mapfile arg
load defect IDs from comma-separated mapfile
-q [ –quiet ]
do not report non-fatal errors
–help
produce help message
–version
print version
