cdestroy(3)

cDestroy – destroy a condition variable.

Synopsis

#include <util/ulocks.h>
void cDestroy(pthread_cond_t *cond);

Arguments

cond – condition variable to destroy.

Description

Destroys the condition variable <cond> that was initialized by cCreate().

MT-Level: Safe for unique <cond>.

Return Value

None.
