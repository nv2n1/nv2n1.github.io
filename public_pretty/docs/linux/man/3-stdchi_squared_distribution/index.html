stdchi_squared_distribution(3)

std::chi_squared_distribution - std::chi_squared_distribution

Synopsis

Defined in header <random>
template< class RealType = double >  (since C++11)
class chi_squared_distribution;

The chi_squared_distribution produces random numbers x>0 according to the Chi-squared_distribution:       f(x;n) =       x(n/2)-1       e-x/2       Γ(n/2) 2n/2 Γ is the Gamma_function (See also std::tgamma) and n are the degrees_of_freedom (default 1). std::chi_squared_distribution satisfies all requirements of RandomNumberDistribution

Template parameters

RealType - The result type generated by the generator. The effect is undefined if this is not one of float, double, or long double.
