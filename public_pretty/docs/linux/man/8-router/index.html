router(8)

router – XML packet distributor

Synopsis

router [-h] [-c config] [-D]

Description

router is the core component of the jabberd system. It passes XML packets between the components, and manages the entry and exit of components onto the network.

Options

-h
Show summary of options.
-c
Alternate configuration file to use. The compiled-in default is /etc/jabberd/router.xml.
-D
Print debugging output. You should configure jabberd with the –enable-debug switch to enable this.

See Also

jabberd(8) c2s(8) s2s(8) sm(8)
