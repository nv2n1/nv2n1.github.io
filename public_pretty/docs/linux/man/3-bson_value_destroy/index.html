bson_value_destroy(3)

NAME

bson_value_destroy() – Releases any resources associated with value.

SYNOPSIS


void bson_value_destroy(bson_value_t *value);

PARAMETERS

value
A bson_value_t \&.

DESCRIPTION

Releases any resources associated with value \&.
