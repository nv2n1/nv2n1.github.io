edsadmin(1)

NAME

EDSAdmin – the Erudite Directory Service Admin tool

SYNOPSIS

edsadmin [–raw_mode]

DESCRIPTION

This manual page documents briefly the edsadmin command.

OPTIONS

–raw_mode
Show raw LDAP properties for objects in the directory.

OPTIONAL FEATURES

If the python-dns package and/or the mdnsresponder and ctypes packages are installed, EDSAdmin will use them to automatically detect LDAP servers on the network.
