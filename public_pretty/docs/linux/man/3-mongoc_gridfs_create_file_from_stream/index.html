mongoc_gridfs_create_file_from_stream(3)

mongoc_gridfs_create_file_from_stream() – This function shall create a new mongoc_gridfs_file_t and fill it with the contents of stream. Note that this function will read from stream until End of File, making it bet suited for file-backed streams.

Synopsis

mongoc_gridfs_file_t *
mongoc_gridfs_create_file_from_stream (mongoc_gridfs_t *gridfs,
 mongoc_stream_t *stream,
 mongoc_gridfs_file_opt_t *opt);

Parameters

gridfs
A mongoc_gridfs_t(3) \&.
stream
A mongoc_stream_t \&.
opt
A mongoc_gridfs_file_opt_t to specify file options.

Description

This function shall create a new mongoc_gridfs_file_t and fill it with the contents of stream \&. Note that this function will read from stream until End of File, making it bet suited for file-backed streams.

Returns

A newly allocated mongoc_gridfs_file_t that should be freed with mongoc_gridfs_file_destroy(3) when no longer in use.
