eventfd_fget(9)

eventfd_fget - Acquire a reference of an eventfd file descriptor.

Synopsis

struct file *eventfd_fget(int fd);

Arguments

fd

[in] Eventfd file descriptor.

Description

Returns a pointer to the eventfd file structure in case of success, or the following error pointer:

-EBADF : Invalid fd file descriptor. -EINVAL : The fd file descriptor is not an eventfd file.
