mongoc_bulk_operation_t(3)

mongoc_bulk_operation_t – Bulk Write Operations

Synopsis

typedef struct _mongoc_bulk_operation_t mongoc_bulk_operation_t;

The opaque type mongoc_bulk_operation_t provides an abstraction for submitting multiple write operations as a single batch.

After adding all of the write operations to the mongoc_bulk_operation_t , call mongoc_bulk_operation_execute(3) to execute the operation.

NOTE

It is only valid to call mongoc_bulk_operation_execute(3) once. The mongoc_bulk_operation_t must be destroyed afterwards.
