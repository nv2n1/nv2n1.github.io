nvimgdiff(1)

NAME

NVIDIA – manual page for NVIDIA Texture Tools – Copyright NVIDIA Corporation 2007

DESCRIPTION

NVIDIA Texture Tools – Copyright NVIDIA Corporation 2007

usage: nvimgdiff [options] original_file updated_file [output]

Diff options:

-normal
Compare images as if they were normal maps.
-alpha
Compare alpha weighted images.
