ck_hs_reset_size(3)

NAME

ck_hs_reset_size – remove all keys from a hash set

LIBRARY

Concurrency Kit (libck, -lck)

SYNOPSIS

In ck_hs.h Ft bool Fn ck_hs_reset_size ck_hs_t *hs unsigned long size

DESCRIPTION

The Fn ck_hs_reset_size 3 function will remove all keys stored in the hash set pointed to by the Fa hs argument and create a new generation of the hash set that is preallocated for Fa size entries.

RETURN VALUES

If successful, Fn ck_hs_reset_size 3 will return true and will otherwise return false on failure. This function will only fail if a replacement hash set could not be allocated internally.

ERRORS

Behavior is undefined if Fa hs is uninitialized. Behavior is undefined if this function is called by a non-writer thread.
