fts-set-priority(1)

NAME

fts-set-priority

SYNOPSIS

fts-set-priority [options] JOB_ID PRIORITY

DESCRIPTION

fts-set-priority is a tool for setting the priority of a transfer job

OPTIONS

  -h [ –help ]         Print this help text and exit.   -q [ –quite ]        Quiet operation.   -v [ –verbose ]      Be more verbose.   -s [ –service ] arg  Use the transfer service at the specified URL.   -V [ –version ]      Print the version number and exit.
