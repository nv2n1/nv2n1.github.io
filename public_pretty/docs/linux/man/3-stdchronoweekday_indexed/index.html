stdchronoweekday_indexed(3)

std::chrono::weekday_indexed - std::chrono::weekday_indexed

Synopsis

Defined in header <chrono> class weekday_indexed; (since C++20) The class weekday_indexed combines a weekday, representing a day of the week in the Gregorian calendar, with a small index n in the range [1, 5]. It represents the first, second, third, fourth, or fifth weekday of some month. weekday_indexed is a TriviallyCopyable StandardLayoutType.
