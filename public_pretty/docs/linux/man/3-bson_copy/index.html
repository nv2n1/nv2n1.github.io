bson_copy(3)

NAME

bson_copy() – The bson_copy() function shall copy the contents of a bson document into a new bson_t.

SYNOPSIS


bson_t *
bson_copy(const bson_t *bson);

PARAMETERS

bson
A bson_t \&.

DESCRIPTION

The bson_copy(3) function shall copy the contents of a bson document into a new bson_t \&.

The resulting bson_t should be freed with bson_destroy(3) \&.

RETURNS

A newly allocated bson_t that should be freed with bson_destroy(3) \&.
