glutkeyboardfunc(3)

glutKeyboardFunc – Sets the Keyboard callback for the current window.

Library

OpenGLUT – input

Synopsis

Description

This callback registration allows you to handle traditional ASCII keyboard input. A general rule of thumb is that if a key has a common ASCII code, then OpenGLUT assigns that code to the key and calls the Keyboard Bf Sy

Caveats

This function is not very international-friendly.

Windows created via glutCreateMenuWindow() always cascade keyboard and mouse events to their parent.
