native2ascii – Native-to-ASCII Converter

Converts a file with characters in any supported character encoding to one with ASCII and/or Unicode escapes, or visa versa.

Synopsis

native2ascii [options] [inputfile [outputfile]]

Description

native2ascii converts files that are encoded to any character encoding that is supported by the Java runtime environment to files encoded in ASCII, using Unicode escapes ("
