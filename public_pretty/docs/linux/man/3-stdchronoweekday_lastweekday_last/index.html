stdchronoweekday_lastweekday_last(3)

std::chrono::weekday_last::weekday_last - std::chrono::weekday_last::weekday_last

Synopsis

explicit constexpr weekday_last(const chrono::weekday& wd) noexcept; (since C++20) Constructs a weekday_last object storing the weekday wd.

Notes

A more convenient way to construct a weekday_last is with weekday’s operator[], i.e., wd[std::chrono::last].
