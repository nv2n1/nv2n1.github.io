stdmake_error_codestderrc(3)

std::make_error_code(std::errc) - std::make_error_code(std::errc)

Synopsis

Defined in header <system_error> std::error_code make_error_code( std::errc e ) noexcept; (since C++11) Creates error code value for errc enum e. Equivalent to std::error_code(static_cast<int>(e), std::generic_category())

Parameters

e - error code enum to create error code for

Return value

Error code corresponding to e.
