dnsip(1)

SYNOPSIS

dnsip [OPTIONS] <domain-name> [<domain-name> …]

DESCRIPTION

dnsip serves the sole task of resolving a given domain-name to it’s IPv4 address. dnsip supports following options:

OPTIONS

-h –help
 print this help
-n –new
 use new output style
-v –version
 print version information
