stdfilesystempathformat(3)

std::filesystem::path::format - std::filesystem::path::format

Synopsis

enum format {
    native_format,
    generic_format,  (since C++17)
    auto_format
};

Determines how string representations of pathnames are interpreted by the constructors of std::filesystem::path that accept strings.

Constants

Defined in header <filesystem> Value Explanation native_format Native pathname format generic_format Generic pathname format auto_format Implementation-defined pathname format, auto-detected where possible

Notes

On POSIX systems, there is no difference between native and generic format.
