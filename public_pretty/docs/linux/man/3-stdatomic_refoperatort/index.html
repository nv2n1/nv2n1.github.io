stdatomic_refoperatort(3)

std::atomic_ref<T>::operatorT - std::atomic_ref<T>::operatorT

Synopsis

operator T() const noexcept; (since C++20) Atomically loads and returns the current value of the referenced object. Equivalent to load().

Parameters

(none)

Return value

The current value of the referenced object.
