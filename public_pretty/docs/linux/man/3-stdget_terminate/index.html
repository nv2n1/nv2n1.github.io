stdget_terminate(3)

std::get_terminate - std::get_terminate

Synopsis

Defined in header <exception> std::terminate_handler get_terminate() noexcept; (since C++11) Returns the currently installed std::terminate_handler, which may be a null pointer. This function is thread-safe. Prior call to std::set_terminate synchronizes-with (see std::memory_order) this function. (since C++11)

Parameters

(none)

Return value

The currently installed std::terminate_handler.
