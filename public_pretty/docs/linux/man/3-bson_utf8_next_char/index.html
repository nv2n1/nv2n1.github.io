bson_utf8_next_char(3)

NAME

bson_utf8_next_char() – Advances within utf8 to the next UTF-8 character, which may be multiple bytes offset from utf8. A pointer to the next character is returned.

SYNOPSIS


const char *
bson_utf8_next_char(const char *utf8);

PARAMETERS

utf8
A UTF-8 encoded string.

DESCRIPTION

Advances within utf8 to the next UTF-8 character, which may be multiple bytes offset from utf8 \&. A pointer to the next character is returned.
