jbd2_journal_ack_err(9)

jbd2_journal_ack_err – Ack journal err.

Synopsis

void jbd2_journal_ack_err(journal_t *journal);

Arguments

journal

journal to act on.

Description

An error must be cleared or acked to take a FS out of readonly mode.
