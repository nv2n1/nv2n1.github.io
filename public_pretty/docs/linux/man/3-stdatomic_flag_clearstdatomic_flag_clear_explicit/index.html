Atomically changes the state of a std::atomic_flag pointed to by p to clear (false).

Parameters

p - pointer to std::atomic_flag to access order - the memory synchronization ordering for this operation: only std::memory_order_relaxed, std::memory_order_release, or std::memory_order_seq_cst are permitted.

Return value

none.

Possible implementation

First version
