bconsole(8)

 bconsole – Bacula’s management Console

Synopsis

bconsole [options]

Description

This manual page documents briefly the bconsole command.

Options

-D dir
Select a Director.
-l
List defined Directors.
-c config
Specify configuration file.
-d nn
Set debug level to nn.
-dt
Print timestamp in debug output.
-n
No conio (for scripting).
-s
No signals (for debugging).
Set command execution timeout to nn seconds
-t
Test the configuration file and report errors.
-?
Show version and usage of program.

See Also

bacula-dir(8), bls(1), bextract(1).
