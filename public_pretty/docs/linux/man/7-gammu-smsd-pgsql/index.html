gammu-smsd-pgsql(7)

gammu-smsd-pgsql - gammu-smsd(1) backend using PostgreSQL database server as a message storage

Description

gammu-smsd(1) supports several backends. Actual backend is chosen in a config file gammu-smsdrc(5). PGSQL backend stores all data in a PostgreSQL database server, which parameters are defined by configuration (see gammu-smsdrc(5) for description of configuration options). For tables description see gammu-smsd-tables(7).

See Also

gammu-smsd(1), gammu-smsdrc(5), gammu(1), gammurc(5), gammu-smsd-tables(7)
