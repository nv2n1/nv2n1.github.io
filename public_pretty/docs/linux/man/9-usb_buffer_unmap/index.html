usb_buffer_unmap(9)

usb_buffer_unmap – free DMA mapping(s) for an urb

Synopsis

void usb_buffer_unmap(struct urb *urb);

Arguments

urb

urb whose transfer_buffer will be unmapped

Description

Reverses the effect of usb_buffer_map.
