glutinitdisplaystring(3)

glutInitDisplayString – Set the window creation display mode.

Library

OpenGLUT – window

Synopsis

In openglut.h Ft void Fn glutInitDisplayString const char *displayMode

Parameters

Bf Em
 displayMode Ef
    Requested display mode string.

Description

glutInitDisplayString() permits you to define a display mode for subsequent windows that you open. In most regards, control is at least as fine as with glutInitDisplaymode().

The Bf Sy
 displayMode Ef
