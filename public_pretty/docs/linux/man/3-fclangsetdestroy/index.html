fclangsetdestroy(3)

FcLangSetDestroy – destroy a langset object

Synopsis

#include <fontconfig/fontconfig.h>

void FcLangSetDestroy (FcLangSet *ls);

Description

FcLangSetDestroy destroys a FcLangSet object, freeing all memory associated with it.
