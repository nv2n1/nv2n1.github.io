euform-get-template(1)

NAME

euform-get-template – Show a stack’s template

SYNOPSIS

euform-get-template [–show-empty-fields] [-U URL]

[–region USER [at] REGION] [-I KEY_ID] [-S KEY]
[–security-token TOKEN] [–debug] [–debugger] [–version] [-h] STACK

DESCRIPTION

Show a stack’s template

positional arguments:

STACK
name or ID of the stack (names cannot be used for deleted stacks) (required)

optional arguments:

–show-empty-fields
show empty values as "(nil)"
-U URL, –url URL
deployment templating service endpoint URL
–region USER [at] REGION
region and/or user names to search when looking up config file data
-I KEY_ID, –access-key-id KEY_ID
-S KEY, –secret-key KEY
–security-token TOKEN
–debug
show debugging output
–debugger
launch interactive debugger on error
–version
show the program’s version and exit
-h, –help
show this help message and exit
