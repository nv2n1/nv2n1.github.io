stdhashstdvector(3)

std::hash(std::vector<bool>) - std::hash(std::vector<bool>)

Synopsis

template <class Allocator> struct hash<vector<bool, Allocator>>; (since C++11) The template specialization of std::hash for std::vector<bool> allows users to obtain hashes of objects of type std::vector<bool>.
