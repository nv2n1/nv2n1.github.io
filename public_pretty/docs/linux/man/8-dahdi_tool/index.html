dahdi_tool(8)

dahdi_tool – Shows status of DAHDI interfaces

Synopsis

dahdi_tool

Description

dahdi_tool shows the current status the DAHDI inteface cards plugged to the computer. It displays values like Current Alarms, SyncSource, Tx/Rx Levels for each DAHDI interface.

See Also

dahdi_monitor(8), asterisk (8).
