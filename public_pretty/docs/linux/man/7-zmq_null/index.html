zmq_null(7)

zmq_null – no security or confidentiality

Synopsis

The NULL mechanism is defined by the ZMTP 3.0 specification: m[blue]http://rfc.zeromq.org/spec:23m[]. This is the default security mechanism for ZeroMQ sockets.
