ncidmodules(5)

ncidmodules.conf – ncid module configuration file

Description

The ncidmodules.conf file contains the configuration information for a ncid, output module and its init or rc file. Use ncidmodules.conf to to configure ncid for a particular output module, but use ncid.conf to configure ncid everytime it is started. For example, use ncid.conf to configure ncid for the server address, but use ncidmodules.conf to configure ncid to for ncid-page.

The ncidmodules.conf file is used to set options for:

ncid-kpopup
ncid-mythtv
ncid-page
ncid-samba
ncid-speak
ncid-tivo
ncid-yac

The ncidmodules.conf file understands 3 types of lines:

blank line
skip it
comment line, beginning with ‘#’
skip it
shell variable set lines.

See ncidsmodules.conf for more details on the variables that can be set.

Examples

ncid command line options to call ncid-page at ring number 4:

       ncid –call-prog –program ncid-page –ring 4

set the email address for ncid-page in ncidmodules.conf:

       PageTo=cellphone [at] isp.com
