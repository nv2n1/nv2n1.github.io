Description

Return Value

Returns an xcb_void_cookie_t. Errors (if any) have to be handled in the event loop.

If you want to handle errors directly with xcb_request_check instead, use xcb_xkb_set_geometry_checked. See xcb-requests(3) for details.

Errors

This request does never generate any errors.
