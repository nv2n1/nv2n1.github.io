rio_release_inb_pwrite(9)

rio_release_inb_pwrite – release inbound port-write message service associated with specific RapidIO device

Synopsis

int rio_release_inb_pwrite(struct rio_dev *rdev);

Arguments

rdev

RIO device which registered for inbound port-write callback

Description

Removes callback from the rio_dev structure. Returns 0 if the request has been satisfied.
