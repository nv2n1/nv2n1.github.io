BB Code Editor

Welcome to the online bb code editor! Edit your text and click the "[BBCODE]" button to get your bb code.

BB Code Editor shortcuts

  • Bold: ctrl + b
  • Italic: ctrl + i
  • Underline: ctrl + u
  • Insert image: ctrl + shift + 1
  • Link: ctrl + shift + 2
  • Code: ctrl + shift + 4
  • Quote: ctrl + shift + 3
