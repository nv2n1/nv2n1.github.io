## Linux man pages are back

The Linux man pages section has been restored from the SysTutorials archives:

[Browse the Linux man pages](/docs/linux/man/){: .button}

Manuals are organized in sections: 1 is user commands, 2 system calls, 3 library functions, 5 file formats, and 8 administration commands. When a name appears in several sections, pass the section first: `man 5 passwd`.

Of course, every Linux system ships its own manuals: run `man ls` on a Linux box to read them locally, `apropos` to search by keyword, and `whatis` for a one-line summary.
