## Linux man pages

The full Linux man pages collection, 56,856 pages recovered from the SysTutorials archives, is available online again:

[Browse the Linux man pages](/docs/linux/man/){: .button}

Manuals are organized in sections: [1 user commands](/docs/linux/man/1/), [2 system calls](/docs/linux/man/2/), [3 library functions](/docs/linux/man/3/), [4 special files](/docs/linux/man/4/), [5 file formats](/docs/linux/man/5/), [7 miscellaneous](/docs/linux/man/7/), [8 administration and privileged commands](/docs/linux/man/8/), and [9 kernel routines](/docs/linux/man/9/). Each section has a browsable index, and every page links to the other manual pages it references.

Each page also carries its one-line description, so you can search the whole collection by name or by description from the man pages home, similar to `apropos` on a Linux box. For example, searching "printf" lists printf(1), printf(3), and every page mentioning it.

Every Linux system ships its own manuals too: run `man ls` locally to read them, `apropos` to search by keyword, and `whatis` for a one-line summary. When a name appears in several sections, pass the section first: `man 5 passwd`.
