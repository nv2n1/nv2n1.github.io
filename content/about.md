## About SysTutorials

SysTutorials publishes tutorials and Q&A on Linux, systems, and software.
The site started in 2010 as a WordPress blog and was recently migrated to
a static site (Hugo + GitHub Pages), developed in the open at
[github.com/nv2n1/nv2n1.github.io](https://github.com/nv2n1/nv2n1.github.io).

To leave comments or report issues, please create a PR or report an issue
at [github.com/nv2n1/nv2n1.github.io](https://github.com/nv2n1/nv2n1.github.io).

## Topics Covered

- **Linux & Unix**: System administration, shell scripting, kernel, distributions
- **Programming**: C, C++, Go, Python, shell, build systems, debugging
- **Systems**: Networking, storage, virtualization, containers, performance
- **Tools**: Editors, version control, CI/CD, monitoring, utilities
- **Web**: Servers, proxies, SSL/TLS, APIs, frontend tooling

## Technology Stack

- **Static Site Generator**: Hugo
- **Hosting**: GitHub Pages
- **Source**: [github.com/nv2n1/nv2n1.github.io](https://github.com/nv2n1/nv2n1.github.io)
- **Content**: Markdown with Hugo front matter
- **Styles**: Custom CSS, no JavaScript frameworks

## Community & Contributions

- **Issues & PRs**: Welcome at the [GitHub repository](https://github.com/nv2n1/nv2n1.github.io)
- **Content**: Tutorials, fixes, and improvements accepted via PR
- **Discussion**: Use GitHub Issues for questions and feedback
